# 참조 흐름 세 개 — bpmn.io 에서 열어 보고, 포털로 가져와 연결하기

수업 시나리오 A · B · C 가 실제로 도는 흐름 그림이다. [demo.bpmn.io](https://demo.bpmn.io) 의 "Open file"로 열리고, 포털 **흐름 가져오기**에 그대로 올릴 수 있다.
강사 스택이 쓰는 정의(`scripts/c3_flows.py`)와 같은 모양 · 같은 연결이다(`tests/test_student_reference_flows.py` 가 지킨다).

| 시나리오 | 그림 | 연결 값 | 흐름 이름 |
|---|---|---|---|
| A 긴급 대응 (HYD-01 쿨러 과열) | `cooling-emergency.bpmn` | `cooling-emergency.mapping.json` | 냉각 긴급 대응 |
| B 정기 점검 (HYD-02) | `pm-planning.bpmn` | `pm-planning.mapping.json` | 정기 정비 |
| C 재고 보충 (HYD-03 씰 키트) | `spare-purchase.bpmn` | `spare-purchase.mapping.json` | 예비품 구매 |

세 흐름의 승인 단계는 같다: 에이전트 제안 → 담당자가 **승인 또는 거절** → 승인하면 처리, 거절하면 처리 없이 "결과 보고: 거절"로 끝.
승인하지 않으면 그 자리에서 계속 기다리고, 10분(20배속에서는 실제 30초)이 지나면 "승인 지연 알림"만 나간다(자동 취소 없음).

## 가져와 연결하는 순서 (포털 → 흐름 가져오기)

1. `.bpmn` 파일을 고르고 **흐름 id** 를 내 것으로 적는다(예: `my_cooling`). `c3_…` 과 기준 흐름 id 는 쓰지 않는다.
2. **시작 조건**: "설비 경보로 시작"을 고르고 아래 표의 경보 하나만 체크한다(처음에는 감지기 경보 셋이 체크돼 있다 — 나머지는 끈다).
3. **단계마다 부품 · 담당**을 아래 표대로 고른다. 에이전트 단계는 에이전트를, 승인 단계는 역할을 고른다.
4. **분기 조건 · 타이머**를 아래 표대로 넣는다.
5. **사전 검사**가 통과하면 **등록** → **배포**. 배포하면 그 경보는 가장 최근에 배포한 흐름이 연다(경보 → 흐름 표에 "내가 배포한 흐름"으로 보인다).
6. 다 쓰면 **기준 흐름으로 되돌리기** — 내 흐름이 경보 경로에서 내려가고 기준 흐름이 다시 연다(등록한 판본은 남는다).

한 시스템을 여럿이 같이 쓰면 **마지막에 배포한 사람의 흐름**이 그 경보를 가져간다.

## 화면에 칸이 없는 설정은 연결 값 파일로

결과 보고의 제목 · 요약, 메일 받는 사람 같은 시스템 단계의 세부 설정은 아직 포털 화면에 칸이 없다. 위 표의 선택이 모두 담긴
`*.mapping.json` 을 그대로 넣으면 된다(흐름 id 가 `my_cooling` 일 때):

```bash
python3 - <<'PY'
import json, urllib.request
api, flow, name = "http://127.0.0.1:8080", "my_cooling", "cooling-emergency"
def call(method, path, body):
    req = urllib.request.Request(api + path, json.dumps(body).encode(), {"Content-Type": "application/json"}, method=method)
    return json.load(urllib.request.urlopen(req))
call("POST", "/api/flows/import", {"xml": open(f"{name}.bpmn", encoding="utf-8").read(), "file_name": f"{name}.bpmn", "definition_id": flow})
view = call("PUT", f"/api/flows/{flow}/mapping", {"mapping": json.load(open(f"{name}.mapping.json", encoding="utf-8"))})
print("사전 검사:", "통과" if view["check"]["ok"] else view["check"]["problems"])
PY
```

그 뒤 등록 · 배포는 포털 화면에서 한다. 사전 검사가 막으면 사유와 그 단계가 화면에 나온다 — 고쳐서 다시 검사한다.
