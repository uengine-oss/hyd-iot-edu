# 바이브코딩 랩 키트 (실라버스 2~7일차)

실라버스 2~7일차 랩 20행(23~25 · 34~36 · 44~47 · 57~59 · 67~70 · 79~81)과 71행의 연결 안내가 요구하는 자료다.
HYD(유압설비 공장)와 분리된 **소형 냉각장치** 하나로 랩이 차례로 이어진다. 11일차 종합 랩 키트는 `students/_template/`이다.

| 폴더 | 누가 쓰나 | 내용 |
|---|---|---|
| `kit/` | 학생 | 랩 안내(랩마다 한 쪽) · 자료 · 랩용 실행 환경(`compose.yaml`) · 공용 도구(`labkit/`) · 자동 확인(`labcheck/`). **학생에게는 이 폴더만 나눠 준다** |
| `instructor/` | 강사 | 정답 예 · 정답 예로 완주하는 도구 · 틀린 결과로 자동 확인을 시험하는 도구 |

시작은 `kit/README.md`(학생), `instructor/README.md`(강사).

랩용 실행 환경은 루트 `compose.yaml`과 별개다(프로젝트 이름 `cooler-lab`, 포트 17474 · 17687 · 15432 · 18198). HYD 스택을 켠 채로 함께 켜도 된다.
