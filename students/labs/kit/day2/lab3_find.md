# 2-3 · 설비 이름으로 센서와 부품 찾기

## 만들 것

설비 번호나 이름을 주면 그 설비의 센서와 부품을 돌려주는 조회 프로그램 `work/find_related.py`.

## 왜 만드나

앞에서 설계한 관계가 실제 질문에 답하는 순간을 봅니다. 그래프는 관계를 따라가서 답을 찾기 때문에, 관계가 없으면 연결된 결과도 없습니다. 없는 설비를 물었을 때 무엇이 나오는지도 함께 확인합니다.

## 주어지는 자료

- 앞 랩에서 채운 연습용 그래프
- `cooler/schema_guide.md`의 관계 표

## Claude Code에 전달할 요구사항의 뼈대

- **목표**: 설비 번호(`--id`)나 설비 이름(`--name`)을 받아 그 설비에 연결된 센서와 부품을 찾는다.
- **입력 자료**: 연습용 그래프. 연결은 `labkit.graph`.
- **꼭 지킬 것**
  - 물은 설비의 것만 나온다(다른 설비의 센서가 섞이지 않는다).
  - `--limit` 숫자를 주면 센서 · 부품을 각각 그 개수까지만 돌려준다.
  - 없는 설비를 물으면 오류로 죽지 않고 빈 결과를 돌려준다.
- **출력 모양**(화면에 JSON으로)

```json
{"found": true, "asset": {"id": "CL-01", "name": "…"}, "sensors": [{"id": "…", "name": "…", "kind": "…", "unit": "…", "tag": "…"}], "components": [{"id": "…", "name": "…", "kind": "…"}]}
```

  없는 설비면 `found`는 `false`, `asset`은 `null`, 두 목록은 빈 목록.
- **완료 기준**: `python work/find_related.py --id CL-01`과 `--name "소형 냉각장치 2호"`가 각자의 센서 · 부품만 돌려준다.

프로그램이 만들어지면 다음을 차례로 해 봅니다.

1. Neo4j Browser에서 `MATCH (a:Asset) RETURN a`로 설비 목록을 봅니다.
2. Claude Code가 만든 Cypher를 Browser에 붙여 넣고, `WHERE`로 설비 번호를 한정한 결과를 봅니다.
3. `LIMIT`을 1, 2로 바꿔 봅니다. 없는 번호 `CL-99`도 넣어 봅니다.
4. 이 질의가 어떤 관계를 어느 방향으로 따라갔는지 Claude Code에게 설명해 달라고 합니다.

## 무엇이 나오면 성공

```
python -m labcheck 2-3
```

- CL-01 · CL-02 각각 그 설비의 센서 · 부품만 나온다
- 이름으로 찾아도 같은 결과다
- `--limit 1`이면 하나씩만 나온다
- 없는 설비 번호는 `found`가 `false`이고 빈 결과다
