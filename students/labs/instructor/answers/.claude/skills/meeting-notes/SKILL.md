# 회의 메모 정리

## 목표
형식이 제각각인 회의 메모를 언제나 같은 칸으로 정리한다. 메모에 없는 내용은 만들지 않는다.

## 정리 순서
1. 메모 전체를 읽고 제목과 날짜를 찾는다. 날짜는 `YYYY-MM-DD` 로 적는다.
2. **결정사항**을 고른다. "~하기로 했다", "~로 정했다", "확정" 처럼 이미 정해진 것만 넣는다. "다음에 다시 이야기한다" 처럼 미룬 것은 결정사항이 아니다.
3. **할 일**을 고른다. 누군가 앞으로 해야 하는 일이다. 할 일마다 **담당자**와 기한을 메모에서 찾아 적는다.
4. 기한은 `YYYY-MM-DD` 로 적는다. 메모에 해가 없으면 회의 날짜의 해를 쓴다. 기한이 없으면 `null`.
5. **담당자가 없는 할 일**을 표시한다. 메모에 맡을 사람이 없거나 "정하지 못했다"고 적힌 할 일은 `owner` 를 `null`, `unassigned` 를 `true` 로 적고 `unassigned_todos` 에도 넣는다. 담당자를 짐작해서 채우지 않는다.
6. 결과를 JSON 파일로 저장하고, 같은 내용을 표로 보여 준다. 담당자 없는 할 일은 표 아래에 따로 적는다.

## 필수 출력 칸
`work/meeting/<메모 파일 이름>.result.json` 에 저장한다.

```json
{
  "title": "회의 제목",
  "date": "YYYY-MM-DD",
  "decisions": ["결정사항 한 문장"],
  "todos": [{"task": "할 일", "owner": "담당자 이름 또는 null", "due": "YYYY-MM-DD 또는 null", "unassigned": false}],
  "unassigned_todos": ["담당자가 없는 할 일"]
}
```

## 확인
- 결정사항과 할 일이 섞이지 않았는가.
- 모든 할 일의 담당자 · 기한이 메모의 문장과 맞는가.
- 담당자가 있는 할 일은 예전과 똑같이 정리되는가(`unassigned` 는 `false`, `unassigned_todos` 에 없음).
