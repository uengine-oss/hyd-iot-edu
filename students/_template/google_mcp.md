# T5 구글 MCP 연결 안내 (강사용)

구글 계정 · 인증(토큰 받기 · 갱신)은 **강사가 정한 방법대로 강사가 한다.** 이 안내는 받은 토큰과 서버를 **포털에 넣는 자리**만 다룬다.
어느 구글 MCP 서버를 쓸지도 강사가 고른다. 서버 이름 · 도구 이름은 아래 표의 빈칸에 **포털 화면에 보이는 그대로** 적는다(지어내지 않는다).

## 1. 비밀 값 넣기 — 토큰은 설정에 적지 않는다

1. 포털 → 도구(MCP) → 맨 위 **비밀 값** 펼치기.
2. 이름: 대문자 · 숫자 · 밑줄 (예: `GOOGLE_TOKEN`). 값: 받은 토큰. → **저장**.
3. 저장한 값은 다시 보이지 않는다. 목록에 "저장됨"이 뜨면 된다. 토큰이 만료되면 같은 이름으로 다시 저장한다.

값은 포털 화면 · API 응답 · 구성 내보내기 파일 어디에도 실리지 않는다. 연결 검사 · 에이전트 실행 · 승인 뒤 시스템 task 직전에만 채워진다.
포털 대신 서버 환경 변수 `HYD_SECRET_<이름>`(예: `HYD_SECRET_GOOGLE_TOKEN`)으로 둘 수도 있다 — 포털에 저장한 값이 이긴다.

## 2. 서버 등록 — 넣는 자리

포털 → 도구(MCP) → **서버 등록**.

| 서버가 | 전송 방식 | 넣는 칸 | 쓰는 법 |
|---|---|---|---|
| 주소로 열린 서버 | HTTP (streamable) 또는 SSE | 주소 · **접속 헤더** | 헤더 한 줄: `Authorization=Bearer ${SECRET:GOOGLE_TOKEN}` |
| 명령으로 띄우는 서버 | 명령형 (stdio) | 명령 · 인자 · **환경변수** | 환경변수 한 줄: `<서버가 읽는 변수 이름>=${SECRET:GOOGLE_TOKEN}` |

- `${SECRET:이름}` 은 **접속 헤더 · 환경변수에만** 쓴다. 주소 · 명령 · 인자에 쓰면 등록이 거절된다.
- 명령형 명령은 `npx · uvx · uv · node · python · python3 · deno · bunx · pipx` 만 받는다. 명령은 process 컨테이너 안에서 뜬다 — 인증 파일 경로를 쓰는 서버면 그 파일이 컨테이너 안에 있어야 한다.
- 주소는 process 컨테이너에서 닿아야 한다(내 PC 의 서버면 `host.docker.internal`).
- 이름은 소문자 · 숫자 · 하이픈. 이 이름을 에이전트 도구 칸과 흐름 매핑(server)에 적는다. 예시 묶음은 `gdrive` · `gcal` 로 적었다.
- **검사 후 등록**을 누른다. 연결 검사를 통과해야 저장된다.

## 3. 읽기 · 쓰기 도구 구분

등록하면 도구마다 판정이 붙는다. 규칙은 포털 코드(`mcp_check.read_only_verdict`)와 같다.

| 판정 | 조건 | 쓰는 곳 |
|---|---|---|
| 읽기 전용 | 서버가 `readOnlyHint=true` 표시 **그리고** 이름에 쓰기 낱말 없음 | 에이전트 도구 · 포털 "써 보기" |
| 강사 확인 읽기 | 표시만 없고 이름이 쓰기 낱말이 아닌 도구 → 강사가 **읽기로 확인**(확인한 사람 · 이유 기록) | 에이전트 도구 · 써 보기 |
| 쓰기 | `readOnlyHint=false` · `destructiveHint` 표시, 또는 이름에 쓰기 낱말(create · update · delete · send · insert · patch · set · run …) | 승인 뒤 시스템 task(`svc:mcp-call`)만. 에이전트에는 붙지 않는다 |

강사가 고른 서버의 도구 목록으로 채울 칸:

| 서버(등록 이름) | 도구 이름 (포털 목록 그대로) | 하는 일 | 판정 | 어디에 |
|---|---|---|---|---|
| 드라이브 | | 파일 검색 | 읽기 / 강사 확인 읽기 | 에이전트 |
| 드라이브 | | 파일 읽기 | 읽기 / 강사 확인 읽기 | 에이전트 |
| 캘린더 | | 빈 시간(free/busy) 조회 | 읽기 / 강사 확인 읽기 | 에이전트 |
| 캘린더 | | 일정 하나 읽기(참석 응답) | 읽기 | 시스템 task "참석 응답 확인" |
| 캘린더 | | 일정 만들기 | 쓰기 | 시스템 task "일정 등록 · 초대 발송"(승인 뒤) |
| 메일 (선택) | | 안내 메일 | 쓰기 | 시스템 task. 수업 메일함이면 `hyd-effects` · `send_mail` |

## 4. 확인할 결과
- 서버 카드에 "연결 검사 통과", 도구 목록에 읽기 · 쓰기 칩이 위 표대로 보인다.
- 읽기 도구 하나를 **써 보기**로 불러 결과가 나온다(토큰 값은 화면에 없다).
- 쓰기 도구는 "써 보기"가 막혀 있고, 에이전트 도구로 고를 수 없다.
- 비밀 값 목록에 "값 없음"이 없다.

## 5. 막혔을 때

| 보이는 문구 | 할 일 |
|---|---|
| 인증 실패 (HTTP 401/403) — 인증이 만료되었거나 없습니다 | 토큰을 새로 받아 비밀 값에 같은 이름으로 저장 → 연결 검사 다시 |
| … 비밀 값 GOOGLE_TOKEN 이(가) 없습니다 | 비밀 값 이름이 헤더 · 환경변수의 `${SECRET:…}` 와 글자까지 같은지 |
| 비밀 자리표시자는 headers · env 값에만 쓸 수 있습니다 | 주소 · 인자에 쓴 `${SECRET:…}` 를 헤더 · 환경변수로 옮긴다 |
| MCP 끝점이 아닙니다 (HTTP 404 …) | 주소 끝 경로(보통 `/mcp` 또는 `/sse`) |
| 연결 거부 · 주소를 찾을 수 없습니다 | 서버가 켜졌는지, 주소가 컨테이너에서 닿는지(`host.docker.internal`) |
| '…' 명령을 이 서비스에서 찾을 수 없습니다 | 허용 실행기(npx · uvx …)로 띄우는지 |
| 읽기 도구인데 "붙일 수 없음" | 표시만 없는 도구면 **읽기로 확인**. 이름이 쓰기 낱말이면 확인할 수 없다 — 시스템 task 로 쓴다 |
