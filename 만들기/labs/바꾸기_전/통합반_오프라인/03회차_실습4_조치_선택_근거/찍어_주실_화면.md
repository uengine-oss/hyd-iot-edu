# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 지표, 입력, 결과, 결정표 폴더와 판정.py가 보이고 지표 폴더가 펼쳐져 있게.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
3. 위 요청에 대한 Copilot의 답. 네 지표를 풀어 쓴 부분, C01의 후보별 네 지표 표, 답의 끝에서 정해 달라고 묻는 부분이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
4. 2단계 요청에 대한 Copilot의 계획. 처리 순서와 「더 정해 주셔야 하는 것」이 보이게. 값을 실행할 때마다 파일에서 읽겠다는 줄, 요청하지 않았는데 들어온 단계, 다시 물어 온 항목에 테두리를 얹는다.
5. Copilot이 터미널 명령 실행의 허용을 묻는 화면. 명령 글자(python 비교.py)와 「허용/계속」 버튼이 보이게. 파일을 만들 때의 「유지/허용」 물음도 뜬다면 한 장 더.
6. 비교 결과 md의 미리 보기와 판정 결과 md를 좌우로 나란히 연 VS Code 화면. 비교 결과 쪽은 C01의 표와 추천 사유가 보이게.
7. 위 요청에 Copilot이 비교표를 고치지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 방법을 제안하는 부분에 테두리를 얹는다.
8. Copilot이 비교.py에 「두 판단」 절을 쓰는 부분을 더한 변경 화면. 새로 생긴 줄이 초록색으로 표시되고, 지표를 계산하는 부분은 바뀌지 않은 것이 보이게.
9. 되돌려 준 뒤 Copilot이 비교.py의 바뀐 부분을 보여 주는 화면(바뀐 줄이 초록색으로 표시된 화면).
