# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 입력, 사람, 온톨로지, 결과 폴더와 에이전트.py가 펼쳐져 보이게.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
3. 위 요청에 대한 Copilot의 답. 요청 열 건의 표와, 답의 끝에서 정해 달라고 묻는 부분이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
4. 2단계 요청에 대한 Copilot의 계획. 「지금 입력에서 나올 결과」 표와 「정해 주셔야 하는 것」(권하는 답이 붙은 목록)이 보이게. 그 두 곳에 테두리를 얹는다.
5. Copilot이 터미널 명령 실행의 허용을 묻는 화면. 명령 글자(python 요청_처리.py)와 「허용/계속」 버튼이 보이게.
6. 위 요청에 대한 Copilot의 답. 요청마다 실행 전과 후의 상태를 견준 표와, 반영되지 않은 답(R05의 S7)을 설명하는 부분이 보이게.
7. 위 요청에 Copilot이 답변.json을 고치지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 방법을 제안하는 부분에 테두리를 얹는다.
8. 위 요청에 대한 Copilot의 답. 세 결정이 각각 반영되었는지를 적은 표와, 지금 확정인 요청을 적은 부분이 보이게.
