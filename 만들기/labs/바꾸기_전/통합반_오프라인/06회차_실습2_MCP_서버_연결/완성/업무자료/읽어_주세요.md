# 설비보전팀 공유 폴더

유압 파워팩(1~3호기)의 보전에 쓰는 문서를 모아 둔 폴더다. 고친 내용은 Git 이력으로 남긴다.

| 폴더 | 무엇이 있나 | 관리 |
|---|---|---|
| `매뉴얼/` | 설비 매뉴얼 (HM-8 쿨러 · 팬) | 설비보전팀 |
| `점검/` | 정기 점검표(PM-02), 점검 메모와 점검 기록 | 설비보전팀 |
| `예비품/` | 예비품 관리 · 구매 기준서(PR-07) | 설비보전팀 · 구매팀 |
| `회의록/` | 정기 회의록, 주간 협의 메모 | 그 회의의 기록자 |

- 회의록 파일의 이름은 `회의한 날_회의 이름.txt`로 한다.
- 문서를 고치면 무엇을 왜 고쳤는지를 커밋 메시지에 적는다.
