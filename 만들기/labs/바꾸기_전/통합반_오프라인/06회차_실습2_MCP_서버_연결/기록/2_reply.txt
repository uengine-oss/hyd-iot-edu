계획만 말씀드립니다. 파일은 고치지 않았고, 확인을 받은 뒤에 고치겠습니다. 계획에는 정해 주셔야 할 것이 하나 남아 있습니다(맨 아래).

## 순서

**1단계 — 시간 서버만 연결**

- **제가 할 일:** `.vscode/mcp.json`의 `servers`에 `time` 하나만 넣습니다.
  ```json
  {
    "servers": {
      "time": {
        "type": "stdio",
        "command": "python",
        "args": ["${workspaceFolder}/서버/시간_서버.py", "--local-timezone", "Asia/Seoul"]
      }
    }
  }
  ```
- **직접 하실 일:** 서버를 시작하고, 로그에 `기본 시간대: Asia/Seoul`이 찍히는지와 도구가 `get_current_time`, `convert_time` 둘로 보이는지 확인해 주세요.
- **제가 할 일:** 도구가 제게 연결되면 그 두 도구를 불러 돌아온 결과를 그대로 보여 드립니다.
- **직접 하실 일:** 결과를 보고 다음 단계로 가도 되는지 알려 주세요.

**2단계 — 나머지 둘 연결 (1단계 확인을 받은 뒤)**

- **제가 할 일:** 같은 파일에 `filesystem`과 `git`을 더합니다.
  ```json
  "filesystem": {
    "type": "stdio",
    "command": "python",
    "args": ["${workspaceFolder}/서버/파일시스템_서버.py", "--read-only", "${workspaceFolder}/업무자료"]
  },
  "git": {
    "type": "stdio",
    "command": "python",
    "args": ["${workspaceFolder}/서버/깃_서버.py", "--repository", "${workspaceFolder}/업무자료"]
  }
  ```
- **직접 하실 일:** 두 서버를 시작하고 아래를 확인해 주세요.
  - `filesystem`: 로그에 `허용된 폴더: …/업무자료 · 읽기 전용: 예`가 찍히고, 도구가 다섯 개이며 `write_file`이 없어야 합니다.
  - `git`: 로그에 `저장소: …/업무자료`가 찍히고, 도구가 네 개여야 합니다.

**3단계 — 견준 기록 (2단계 확인을 받은 뒤)**

- 서버마다 도구를 두 개씩 부르고 `결과/서버_비교.md`에 여섯 칸으로 적습니다. 다섯 줄이 넘는 결과는 앞의 다섯 줄만 옮기고 줄였다고 밝힙니다.
- 부르지 않은 도구도 한 줄씩 적되 `부른 인수`와 `돌아온 결과` 칸에는 "부르지 않음"이라고 적을 생각입니다. 부른 도구만 적기를 원하시면 알려 주세요.
- 실패한 호출이 생기면 `결과/실패_기록.md`에 네 칸으로, 돌아온 오류 문장 그대로 적습니다.
- `결과/`에 이미 파일이 하나 있습니다. 쓰기 전에 무엇인지 먼저 보고, 덮어쓰게 되면 그 전에 묻겠습니다.

## 미리 알아 두실 것

- **서버 시작과 중지는 전부 직접 하셔야 합니다.** 규칙 4에 따라 저는 터미널 명령을 실행하지 않습니다.
- **`python`이 실행되지 않을 수 있습니다.** 명령은 규칙에 `python`으로 정해져 있어 제가 `python3` 등으로 바꾸지 않습니다. 시작에 실패하면 오류 문장을 알려 주세요.
- **지금 제 세션에는 이 서버들의 도구가 없습니다.** `.vscode/mcp.json`을 고치고 서버를 시작한 뒤에도 도구가 제게 나타나지 않으면, 규칙 2에 따라 파일 읽기나 기억으로 대신하지 않고 `서버 미연결`로 적겠습니다. 다른 설정 파일을 만드는 것은 규칙상 할 수 없습니다.
- **`.git` 유무는 확인하지 않았습니다.** `업무자료`에 `.git`이 없으면 Git 서버는 뜨지만 도구마다 오류가 돌아옵니다. 그 경우도 실패 기록에 그대로 적습니다.

## 정해 주셔야 하는 것

"서버마다 두 개씩"은 정해 주셨는데, 어느 두 개인지는 아직 정해지지 않았습니다. 시간 서버는 도구가 둘뿐이라 정해졌습니다. 3단계 전까지만 알려 주시면 됩니다.

- **`filesystem`** (다섯 가운데 둘): `list_allowed_directories`, `list_directory`, `read_text_file`, `get_file_info`, `search_files`
- **`git`** (넷 가운데 둘): `git_status`, `git_log`, `git_diff`, `git_show`

`read_text_file`, `get_file_info`, `search_files`, `git_show`를 고르시면 인수(경로, 찾을 낱말, 커밋 번호)도 함께 알려 주세요.
