## 2. 서울 14:00 → UTC

- **부른 도구:** `convert_time` (time 서버)
- **부른 인수:** `{"source_timezone": "Asia/Seoul", "time": "14:00", "target_timezone": "UTC"}`
- **돌아온 결과 (그대로):**
  ```json
  {
    "source": {
      "timezone": "Asia/Seoul",
      "datetime": "2026-10-13T14:00:00+09:00",
      "day_of_week": "화요일"
    },
    "target": {
      "timezone": "UTC",
      "datetime": "2026-10-13T05:00:00+00:00",

  }
  ```
