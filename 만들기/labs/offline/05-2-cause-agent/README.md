# 05-2-cause-agent — 설비 이상의 원인을 추론하는 에이전트 (강사용)

통합반 오프라인 5회차 실습 2. 학생에게 나가는 폴더는 `산출물/실습/통합반_오프라인/05회차_실습2_원인_추론_에이전트/코드/` 하나다. 이 폴더(`만들기/labs/offline/`)의 것은 학생에게 나가지 않는다.

## 무엇이 어디에 있나

| 경로 | 내용 |
|---|---|
| `산출물/실습/통합반_오프라인/05회차_실습2_원인_추론_에이전트/코드/` | 학생이 받아 VS Code로 여는 폴더. 실습 가이드는 그 옆의 `가이드.html`이다(`build_guide.py`가 만든다) |
| `solution/` | 끝까지 마친 상태. `tools.py`, `agent.py`, 사례 열한 건의 `plan/`, 재생용 실행 기록 `recorded/` 포함 |
| `산출물/실습/통합반_온라인/05일차_실습2_원인_추론/코드/` | 온라인 학생에게 주는 완성본. `solution/`에서 접속 양식을 뺀 것이다. 키 없이 실행하면 저장된 실행 기록을 재생한다 |
| `screenshots.md` | 가이드의 「화면 1~10」 자리에 넣을 사진 목록 |
| `record/README.md` | 실제로 돌린 것과 확인하지 못한 것 |
| `record/prompts/` | 가이드에 실은 요청 글 원문 |
| `record/runs/` | 단계별 실행 결과와 그때의 설정 |
| `build_guide.py` | `가이드.html`을 만든다. 스타일은 `../guide.css` |

## 수업 전에 준비할 것

- 학생마다 LLM 서버 접속 정보 세 값(`OPENAI_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`)을 나눠 준다. 학생은 받은 폴더의 `.env`를 열어 등호 뒤에 값을 적는다. 저장소의 `.env`는 값이 비어 있어야 한다. 값을 적은 채로 커밋하지 않는다.
- 학생 PC에서 서버에 닿는지 확인한다: 학생 폴더에서 `python llm_client.py`.
- Python 3(표준 라이브러리만 쓴다), VS Code, GitHub Copilot 채팅.

## 완성본을 돌려 보려면

`solution/`에서 `.env.example`을 `.env`로 복사해 접속 정보를 적고 `python agent.py`를 실행한다. 열한 건에 1분쯤 걸린다. `.env`는 저장소에 올리지 않는다.

`.env`가 없으면 서버를 부르지 않고 `recorded/replies.json`의 답을 재생한다. 실행 기록을 새로 저장하려면 `.env`를 둔 채 `LLM_RECORD=1 python agent.py`를 실행하고, `solution/`을 `산출물/실습/통합반_온라인/05일차_실습2_원인_추론/코드/`로 다시 복사한다(`.env`와 `.env.example`은 빼고).
