# 기록 — 05-2-cause-agent

2026-10-13에 다시 만들었다. 이전 판(모델을 부르지 않는 파이썬 프로그램, 한글 파일 이름)은 저장소의 커밋 `ee2a5c2`에 있다.

## 무엇이 바뀌었나
- 에이전트가 LLM 서버(OpenAI 호환)를 실제로 부른다. 모델은 도구를 골라 부르고 원인을 판정한다. `agent.py`는 허용 목록, 호출 기록, 멈춤, 대조를 맡는다. 판정 규칙은 코드가 아니라 `agent_config.json`의 `rules`에 문장으로 둔다.
- 폴더·파일·함수·JSON 키 이름을 영어로 바꿨다. 학생 폴더와 강사 폴더를 나눴다(`만들기/labs/STRUCTURE.md`).
- 가이드는 실습 진행에 필요한 것만 남겼고, 본문 문장은 gpt-6-astra로 한 번 윤문했다(아래).

## 실제로 돌린 것
환경: macOS, Python 3.14, 사내 LLM 서버(OpenAI 호환, `temperature` 0, 생각 과정 끔).

| 무엇 | 결과 | 파일 |
|---|---|---|
| 접속 확인 `python llm_client.py` | 연결됨, 인사 한 문장 | — |
| 도구 둘, 규칙 일곱 줄, S01 | UNKNOWN. 도구 호출 5번. 대조 3건(조치 칸에 절 번호 `HM-8.4`) | `runs/step3_S01.*`, 설정 `runs/config_step3.json` |
| 도구 셋, S01 | SUPPORTED. 도구 호출 9번. 대조 1건(`HM-8.4`) | `runs/step4_S01.*` |
| 도구 셋, 열한 건 | 모두 답을 냄. 대조: 절차 번호(S01·S02·S03·S07·S08·S09), status(S03), verdict(S10) | `runs/step4_all.*`, 설정 `runs/config_step4.json` |
| 도구 넷, 규칙 여덟 줄, 열한 건 | 54초. S03이 도구를 19번 부르고 횟수 한도에 닿아 답을 내지 못함(증거에 없는 TS1을 구간만 바꿔 열 번 읽음). 대조는 S10의 verdict 1건 | `runs/step7_all.*` |
| 규칙 아홉 줄(읽을 값을 증거로 한정), 열한 건 | 53초. 열한 건 모두 답을 냄. 대조: S02 verdict, S03 status, S10 verdict | `solution/plan/` |

- 대조의 verdict · status 확인은 뒤에 더했다. `step3_S01`, `step4_S01`, `step7_all`의 `mismatches`는 저장된 답에 새 대조를 다시 댄 것이다(서버는 다시 부르지 않았다). `step4_all`과 `solution/plan`은 새 대조로 처음부터 돌렸다.
- 연결 파일 이름을 `llm_client.py` · `.env`로 바꾼 뒤에는 접속 확인과 S01 한 건만 다시 돌렸다(로직은 같다).
- 한글 이름이던 앞선 실행과 견주면, 같은 서버인데도 영어 이름으로 바꾼 뒤 S03의 동작이 달라졌다(앞선 실행에서는 열한 건 모두 답을 냈다). 8단계의 소재를 이 실제 실패로 바꿨다.
- 멈춤 조건이 없던 첫 시험에서는 모델이 마지막 호출을 서른 번 가까이 되풀이했다. 같은 호출을 되풀이하면 도구를 거두고 답을 요구하게 한 뒤로 답이 나온다.

## 온라인 완성본의 재생
- 온라인 학생이 서버를 부르지 않고 완성본을 실행해 볼 수 있도록, `solution/llm_client.py`는 `.env`가 없으면 `recorded/replies.json`에 저장한 서버의 답을 순서대로 돌려준다. 도구 실행 · 호출 기록 · 대조는 재생에서도 실제로 돈다.
- 규칙 아홉 줄, 도구 넷으로 열한 건을 실제로 실행하며 저장했고(`LLM_RECORD=1`), `.env`를 지운 뒤 다시 실행해 화면 출력과 `plan.json`이 실제 실행과 같음을 확인했다. `solution/plan/`은 이 실행의 결과다.
- 설정이나 사례를 바꾸면 재생하지 못하고 멈춘다. 학생 폴더(`산출물/실습/통합반_오프라인/`)의 `llm_client.py`에는 재생이 없다.

## 가이드 문장의 윤문
- `build_guide.py --collect`로 가이드 문장 221개(약 9천 자)만 모아, 로그인된 Codex에서 gpt-6-astra를 한 번 불렀다(17,571 토큰). 코드, 실행 결과, 요청 글은 보내지 않았다.
- 111개가 바뀌었고 108개는 그대로 돌아왔다. 2개는 길이 검사에서 걸려 원문을 두었다. 바뀐 문장은 `<code>` 안의 글, 숫자, 대문자 값, 「」 안의 글이 원문과 같은지 검사해 통과한 것만 `guide_polish.json`에 담았다.
- 문장을 고치면 그 문장은 윤문이 적용되지 않은 원문으로 실린다.

## 확인하지 못한 것
- **가이드의 요청 글 여덟 개는 Copilot에 보내 보지 않았다.** `solution/`의 `tools.py`와 `agent.py`는 제작자가 직접 썼다. Copilot이 이 요청으로 같은 것을 만드는지는 확인하지 않았다.
- Copilot과 GPT-6 Luna, Windows에서의 실행. 사진 자리 10곳.
- 실습 시간(50분) 안에 끝나는지.
- 학생 PC에서 서버에 닿는지. 여러 명이 동시에 부를 때의 응답 시간.
- 실행마다의 변동. 같은 설정으로 여러 번 돌려 보지 않았다. 가이드는 「예시 실행」이라고 밝히고 실었다.
