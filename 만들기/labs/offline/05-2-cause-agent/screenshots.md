# 찍어 주실 화면

가이드의 「화면 1~10」 자리와 번호가 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍는다. 키가 보이는 화면(`.env`를 연 편집기)은 찍지 않는다.

| 번호 | 단계 | 찍을 화면 |
|---|---|---|
| 1 | 준비 | 받은 폴더를 연 VS Code. 왼쪽 탐색기에 .github, cases, ontology, plan 폴더와 .env, agent_config.json, llm_client.py가 보이게 |
| 2 | 1단계 | Copilot 채팅이 열린 VS Code 전체. 입력 칸 아래의 에이전트와 GPT-6 Luna에 테두리 |
| 3 | 1단계 | 첫 요청에 대한 Copilot의 답. 관계를 한 줄씩 적은 부분, S01 비교표, 끝의 질문에 ①②③ 테두리 |
| 4 | 2단계 | Copilot의 구현 계획. tools.py와 agent.py에 둘 것이 나뉘어 적힌 부분 |
| 5 | 3단계 | plan/plan.md의 미리 보기. S01의 근거 상태(UNKNOWN), 대조, 호출 기록이 보이게 |
| 6 | 4단계 | 터미널에 사례 열한 건이 한 줄씩 출력된 화면 |
| 7 | 5단계 | plan/plan.md와 cases/cases.json을 좌우로 나란히 연 화면 |
| 8 | 6단계 | Copilot이 사례 파일을 고치지 않고 어느 규칙 때문인지 밝힌 답 |
| 9 | 7단계 | plan/plan.md의 S01 점검 순서. 근거와 조치(절차 번호)가 보이게 |
| 10 | 8단계 | 규칙을 더한 뒤 다시 실행한 터미널. 열한 건이 모두 답을 낸 화면 |
