# 나중에 채울 화면

실제 캡처를 만들지 않았습니다. 각 자리는 아래 장면과 판정 근거가 보이도록 채웁니다. 개인 정보·비밀값을 제외합니다.

## 02-01 · 판본과 시작 상태 기록
판본·폴더 구조·기대 상태 표. 비밀 설정값 제외
확인 기준: 이번 환경의 판본과 범위를 적고, 켜야 하는 서비스·일회성 준비 작업·외부 의존성을 구분합니다.

## 02-02 · 도구와 엔진 구분
도구 버전과 엔진 상태를 구분한 화면
확인 기준: 도구 설치, 엔진 실행, 서비스 상태를 각각 판정합니다. 버전 출력만으로 서비스 정상이라 하지 않습니다.

## 02-03 · 실행 순서 읽고 적용 범위 정하기
판본에 맞는 실행 절차와 단계별 준비 확인. 토큰·키 제외
확인 기준: 각 준비 단계의 선행 조건·명령 위치·확인 기준을 적습니다. 내려받기·설치·복구 시간은 별도입니다.

## 02-04 · 상태를 종류별로 판정
장기 실행 상태, 일회성 종료 코드·로그, 기대/관측 비교
확인 기준: Exited라는 표시만으로 실패라 하지 않고, 실행 중이라는 표시만으로 모든 기능이 정상이라 하지 않습니다.

## 02-05 · 접속 결과와 미확인 구분
포털 접속 결과와 환경 확인표. 미확인 항목 포함
확인 기준: 기대/관측/근거/판정 표가 완성됩니다. 서비스 개수나 전부 Up이라는 문구로 완료 처리하지 않습니다.
