## SLIDE 08 — 스킬이 놓이는 자리: 작업 폴더의 스킬 폴더
### 화면 내용
- 유형: 코드
- 메시지: 스킬은 이름과 같은 폴더에 든 SKILL.md 한 파일이며, 실행이 시작될 때 에이전트의 작업 폴더에 놓인다.
- 코드: 작업 폴더 /   context/ /     task.json /   .claude/skills/ /     cooling-emergency-response/ /       SKILL.md /   output/ /     result.json
- 요소:
  1. 작업 폴더 | 에이전트가 한 번의 실행 동안 쓰는 전용 폴더이다.
  2. context/task.json | 이번에 맡은 일의 입력이 들어 있다.
  3. **스킬 폴더** | 배정된 스킬이 폴더째 놓인다. 폴더 이름이 곧 스킬 이름이다.
  4. output/result.json | 에이전트가 결과를 써 넣는 파일이다.
- 노트: 스킬이 실제로 놓이는 자리입니다. 에이전트는 실행마다 작업 폴더 하나를 받고, 그 안에 이번 일의 입력과 배정된 스킬과 결과를 쓸 자리가 있습니다. 쿨러 경보의 실행 기록은 배정된 스킬 하나를 작업 폴더에 넣고 실행한다는 줄로 시작합니다. 입력, 지침, 결과가 한 폴더 안에서 각자의 자리를 가집니다.
### 화면 구성

## SLIDE 56 — 연결 검사의 실패 사유와 분류
### 화면 내용
- 유형: 표
- 메시지: 연결 검사는 실패를 빈 성공으로 넘기지 않고, 무엇이 막혔는지를 분류와 사람이 읽는 사유로 돌려준다.
- 머리: 분류 | 뜻 | 다음에 확인할 곳
- 요소:
  1. refused | 주소에 닿았으나 응답하는 서버가 없다 | 서버가 켜져 있는지, 주소 · 포트
  2. unreachable | 주소 자체를 찾지 못했다 | 서비스 이름 · 호스트 이름
  3. **timeout** | 정해진 시간 안에 응답이 없다 | 서버가 느리거나 방화벽이 막는지
  4. auth | 인증이 만료되었거나 없다 | 토큰을 새로 받아 다시 연결
  5. not_mcp | 응답이 MCP 형식이 아니다 | 주소의 경로(보통 /mcp)
  6. exec | stdio 서버의 명령을 찾거나 실행하지 못했다 | 명령을 띄우는 쪽의 PC
- 노트: 서버를 등록하거나 도구를 시험할 때 연결이 실패하면, 검사는 빈 목록을 성공처럼 돌려주지 않고 실패로 알립니다. 실패에는 분류와 사람이 읽는 사유가 함께 붙습니다. 응답하는 서버가 없는지, 주소를 못 찾았는지, 시간이 넘었는지, 인증이 만료됐는지에 따라 다음에 확인할 곳이 달라집니다. 도구 목록을 받지 못하면 그 서버는 연결되지 않은 것으로 남습니다.
### 화면 구성
표 한 장(분류 · 뜻 · 다음 확인). 셋째 행(시간 초과)을 강조한다. 분류 이름은 화면의 원문이며 대본은 뜻으로 말한다.
### 제작 기준
[저장소] 연결 검사 · 호출 실패의 분류 `error_kind`(config · exec · refused · unreachable · timeout · auth · not_mcp · protocol · server · closed · too_large, 비밀값 문제는 secret)와 「폴백 · 빈 성공은 없다: 도구 목록을 받지 못하면 status 는 'failed'」(`it/process/procsvc/mcp_check.py` 머리말), 각 분류의 사유 원문(같은 파일 223 · 354 · 432 · 435 · 440 · 443행: 「연결 거부 — … 서버가 켜져 있는지, 주소·포트가 맞는지 확인하세요」 「주소를 찾을 수 없습니다 — … 컨테이너 서비스 이름 … 이나 호스트 이름을 확인하세요」 「… 응답하지 않았습니다 (시간 초과). 서버가 느리거나 방화벽이 막고 있을 수 있습니다」 「인증 실패 (HTTP …) — 인증이 만료되었거나 없습니다 … 토큰을 새로 받아」 「MCP 끝점이 아닙니다 … 주소 경로(보통 /mcp 또는 /sse)를 확인하세요」 「명령형(stdio) 서버는 워커가 도는 PC 에서 실행되므로」): 사실표 6.3.4. 열한 분류 가운데 실습 1에서 학생이 만날 여섯만 실었다. 실라버스 행 3의 「실패 · 타임아웃」을 연결 쪽에서 보강한 장(기준 41번, 2026-10-16 이론 합 하한 미달에 따른 보강 — 새 사실은 코드 근거).
