## SLIDE [N10] — 실습에서 다시 확인하는 두 결말과 남기는 것
### 화면 내용
- 유형: 흐름
- 아이콘: rocket, circle-check, ban, arrow-back-up, device-floppy
- 메시지: 고친 정의는 승인과 거절을 모두 다시 실행해야 정상 종료와 명령 없는 거절 종결을 함께 확인할 수 있다.
- 요소:
  1. 다시 검사해 배포한다 | 고친 정의를 / 사전 검사에 넣고 / 새 판본으로 배포한다
  2. 승인으로 실행한다 | 명령과 재관측을 거쳐 / 정상으로 끝나는지 / 확인한다
  3. 거절로 실행한다 | 설비 명령 없이 / 거절 종결에 닿는지 / 확인한다
  4. **되돌린다** | 경보를 받는 흐름을 / 기준 흐름으로 / 되돌린다
  5. 남긴다 | BPMN 파일과 / 처리 건의 결과를 / 보존한다
- 노트: 마지막 실습에서는 고친 정의를 다시 실행합니다. 사전 검사를 다시 거쳐 새 판본으로 등록하고 배포합니다. 쿨러 성능 저하 경보로 처리 건을 열어 승인한 경우에는 정상으로 끝나는지를, 거절한 경우에는 설비 명령 없이 거절 종결에 닿아 닫히는지를 확인합니다. 수업을 마치기 전에 쿨러 성능 저하 경보를 받는 흐름을 처음부터 배포되어 있던 기준 흐름으로 되돌려, 다음 경보가 기준 흐름에서 열리게 합니다. 끝으로 완성한 BPMN 파일과 처리 건의 결과를 보존합니다.
### 화면 구성

### 제작 기준
