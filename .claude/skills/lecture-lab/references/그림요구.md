# 실습 화면과 그림 도구의 한계

`가이드그림.py` 를 돌리기 전, 그리고 사람이 찍어야 할 그림이 있을 때 읽는다.
현재 도구로 직접 캡처할 수 있으면 직접 확인한다. 아래 「사람에게 요구」 절차는 접근할 수 없을 때만 적용한다.
경로·테마·해상도는 대상 강의 계약과 실제 학생 환경에서 정한다. 아래 고정값은 기본 예시다.
도구 한계 목록은 도구 소스와 실제 산출물에서 재확인하며, 성공했다고 추정하지 않는다.

### VS Code 안에서는 우리가 못 친다 — 셸로 대신 친다

**우리는 강사 PC 의 VS Code 터미널에 직접 입력할 수 없다.** 그래서 —

**`cmd` · `PowerShell` 로 진짜 돌리고, 나온 로그를 VS Code 터미널 모양으로 그린다.**
셸이 다를 뿐 **명령도 출력도 진짜다.** 지어내는 것이 아니다.
`쳐보기` 가 그 실행을 맡고, 명령 · 출력 · `exit` · 걸린 시간을 세션에 함께 적어 둔다.

### 참고할 실제 화면이 없으면 사람에게 요구한다

**「이런 화면일 것이다」로 채우지 않는다. 요구서를 내고 답을 기다린다.**

| 순서 | 할 것 |
|---|---|
| 1 | **필요한 그림을 가이드 md 에 `![캡션](파일명.png)` 으로 먼저 적는다.** `대조` 는 가이드가 이미 부르는 그림만 센다. 안 적으면 목록에 영원히 안 뜬다 |
| 2 | `python $SK/lecture-lab/가이드그림.py 대조` 를 돌려 **없는 그림 목록**을 뽑는다 |
| 3 | 그 목록을 **우리가 만들 것 / 사람이 찍을 것**으로 가른다. 위 표가 기준이다 |
| 4 | 사람 몫을 **요구서 표**로 낸다 — 파일명 · 무엇이 보여야 하나 · 어느 단계에서 찍나 · 규격(아래 「사람이 찍는 규격」) |
| 5 | **답이 오기 전에는 그 자리를 비워 둔다.** 자리표시 그림 · 설명 문장 · 유사 화면으로 대체하지 않는다 |
| 6 | 같은 요구서에 **확인이 필요한 값**을 함께 묻는다 (아래 표) |
| 7 | 보고에 **「사람이 찍을 것 N건 · 답 대기 M건」**을 남긴다 |

| 확인이 필요한 값 | 안 물으면 |
|---|---|
| **프롬프트에 찍힐 경로 확정값** | `--보일경로` 가 우리 폴더가 되어 학생 화면과 다르다 |
| **프롬프트 모양** — venv 접두 · git 브랜치 · 커스텀 프롬프트가 붙는가 | 붙는다면 만든 그림이 전부 틀렸다 |
| **학생이 쓸 셸** — VS Code 통합 PowerShell · cmd · pwsh | `PS` 가 붙은 그림을 보고 cmd 를 연 학생은 다른 창을 연다 |
| **첫 실행 상태** — 모델·패키지가 미리 받아져 있는가 | 학생 첫 실행에는 다운로드·진행바가 나온다. 우리 그림엔 없다 |
| **자른 그림 승인** — 캡션에 「일부」를 적을지, 출력을 줄여 다시 찍을지 | 「이 화면이 나오면 정상」인데 실제로는 위아래에 수십 줄이 더 나온다 |
| **긴 줄이 나오는 명령 목록** | 117칸을 넘는 줄은 **경고 없이 잘린다** |
| **에러 그림 목록** — 어떤 실수에서 나오는 어떤 에러를, 진짜 재현해도 되는지 | 합성하게 된다 |
| **배포본 폴더 구조 확정** | `--트리` 결과가 학생 화면과 달라진다 |

### 도구 사용 규칙

| 규칙 | |
|---|---|
| **서브커맨드와 위치인자를 먼저 쓰고 플래그를 뒤에 붙인다** | `argparse` 가 아니다. 플래그를 위치인자 앞에 두면 세션 이름 자리에 플래그가 들어가 깨진다. 모르는 플래그는 조용히 무시된다 |
| **강의 프로젝트 폴더 안에서 돌린다** | 인계 문서를 위로 찾아 루트를 잡는다. 못 찾으면 그대로 종료한다 |
| **셀폭 「맞음」이 나와야 한다** | 어긋나면 실제 화면과 글자 크기가 다르다 |
| **PNG 파일이 실제로 생겼는지 확인한다** | Playwright 가 없으면 **메시지만 찍고 종료코드 0 으로 조용히 실패한다** |
| **`--이어서` 로 여러 명령을 한 세션에 쌓는다** | 명령마다 그림을 따로 만들지 않는다 |
| **`--이어서` 로 쌓은 그림에 `cd`·가상환경 활성화·환경변수를 섞지 않는다** | 블록마다 새 셸이다. **그림은 이어진 한 터미널로 보이지만 학생이 그대로 따라 치면 상태가 안 넘어간다** |
| **`exit≠0` 경고가 뜨면 그 그림을 「정상입니다」에 쓰지 않는다** | 랩을 고치고 다시 친다. 에러 화면으로 쓸 것이면 캡션에 그렇다고 적는다 (아래 「절대 지어내면 안 되는 것」 1·3) |
| **`--보일경로` 로 계정 이름을 지운다** | 도구는 `USERNAME` 이 보일 때만 경고한다 |
| **로그 본문의 비밀은 우리가 눈으로 잡는다** | 도구는 본문을 검사하지 않는다. **API 키 · 이메일 · 프로젝트 ID · 실제 경로가 그대로 그림에 박힌다** |
| **`편집기` 의 탐색기는 폴더를 읽어 그린다** | 손으로 적지 않는다. 적어 두면 파일이 늘 때마다 그림이 거짓이 된다 |
| **`정답/`·인계 문서·`실행화면/` 은 자동으로 빠진다** | 그래도 남는 것은 `--빼기` 로 지운다. **정답은 배포본 자체에서 빼는 것이 먼저다** — 숨김은 그림에만 걸린다 |

### 도구가 그려 주지 못하는 것

| 못 하는 것 | 결과 |
|---|---|
| **실제 ANSI 색 재현** | 컬러 로그가 무채색이 된다. 그림의 노랑·청록은 우리가 칠한 것이다 |
| **자동 줄바꿈** | 폭이 고정이라 **117칸을 넘는 줄은 잘려 사라지고, 잘렸다는 표시가 없다** |
| **stdout 과 stderr 가 섞인 실제 순서** | 캡처는 stdout 뒤에 stderr 를 이어 붙인다 |
| **첫 실행의 다운로드·진행바** | 잡음 필터와 진행바 접기가 지운다. 캐시가 찬 PC 기준 화면이다 |
| **빨간 네모 여럿 · 화살표 여럿 · 번호 뱃지** | 네모는 첫 매치 한 개뿐이다 |
| **터미널 창 틀 · 탭 · 스크롤바 · 선택 영역** | 없다 |
| **에디터의 미니맵 · 여러 탭 · 상태표시줄 · 오류 물결선 · git 색** | 없다. 아이콘 2개 · 탭 1개다 |
| **`--찾기` 의 본문 하이라이트와 「1/N」 카운트** | 위젯만 그린다 |
| **`.txt` 소스의 진짜 명령줄** | 프롬프트와 명령을 지어낸다. `--명령` 으로 실제 친 명령을 넘긴다 |
| **`회귀` 폴백의 시간 측정** | 없다. 「랩 실행시간 실측」이라 적으면 거짓이 된다 |
| **대화형 입력 · TUI** | 표준입력이 닫혀 있다 |

### 절대 지어내면 안 되는 것

| # | |
|---|---|
| 1 | **「✔ 정상입니다」 칸의 로그 본문 한 줄이라도.** `쳐보기`·`수집` 의 `exit=0` 결과여야 한다 |
| 2 | **숫자 전부** — 소요 초 · 처리 건수 · 청크 수 · 점수 · 토큰 수 · 파일 크기 · 모델명 · 버전 |
| 3 | **에러 메시지 문구.** 진짜 깨뜨려 다시 친다 |
| 4 | **브라우저에 뜨는 모든 것** — 콘솔 UI · 버튼 위치 · 요금 표시 · 로그인 화면 |
| 5 | **GUI 대화상자·메뉴에 뜨는 모든 것** — 명령팔레트 항목 · 확장 이름 · 설정 항목 · 마법사 단계 |
| 6 | **계정 흔적** — 이메일 · 프로젝트 ID · API 키 · 사용자 이름이 든 경로 |

### 사람이 찍는 규격

| | |
|---|---|
| 해상도 | **1536 × 864** — 터미널 그림이 이 기준이다 |
| 테마 | **어두운 테마.** 터미널 그림 배경이 어두워 밝은 테마면 튄다 |

| 폰트 | 한글이 되는 글꼴. 이모지는 글리프가 없어 네모로 깨진다 |
| ⚠ | **계정 이메일·실명·경로에 든 사용자명이 보이면 가린다.** 학생 전원에게 나간다 |
