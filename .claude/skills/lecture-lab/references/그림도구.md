# `가이드그림.py` — 서브커맨드 여섯

**언제 여나** — 가이드에 넣을 터미널 화면이나 편집기 화면을 만들 때, 또는 그림이 빠졌는지
대조할 때. 그림을 안 만드는 작업이면 열 필요가 없다.

**`$SK`** = 이 저장소의 `.claude/skills`. 저장소 루트에서는 `SK=.claude/skills`.
도구는 `../lecture-common/프로젝트탐지.py`로 강의 프로젝트의 루트(인계 문서가 있는 폴더)를 찾는다. 터미널 그림의 PNG는 Playwright 크로미움이 있어야 나온다.

```bash
# ① 셸에서 진짜 친다 — 파이썬이 아닌 것도 (docker · git · pip · ros2 · nvidia-smi)
python $SK/lecture-lab/가이드그림.py 쳐보기 "<칠 명령>" --이름 <세션> [--셸 pwsh|cmd] [--폴더 <돌릴곳>] \
    [--보일경로 "D:\실습코드"] [--이어서] [--시간제한 300]

# ② 파이썬 랩 하나를 통째로 돌린다
python $SK/lecture-lab/가이드그림.py 수집 <랩파일> --이름 <출력이름>

# ③ 터미널 화면 그림으로 만든다
python $SK/lecture-lab/가이드그림.py 그림 <세션|출력이름> <그림이름> \
    [--자름 <앞에서버릴줄>] [--줄 <쓸줄수>] [--경로 "<보일 경로>"] \
    [--짚기 "<빨간 네모 칠 말>"] [--라벨 "<옆에 붙일 한 줄>"] [--강조 "<밝게 할 말>"] \
    [--명령 "<실제 친 명령 — .txt 출력을 그릴 때>"]

# ④ 편집기 화면 — 코드는 실제 파일에서 읽는다
python $SK/lecture-lab/가이드그림.py 편집기 <파일경로> <그림이름> \
    [--표식 "빈칸 1"] [--위 16] [--아래 5] [--강조줄 <줄번호>] [--찾기 "빈칸 1"] \
    [--트리 <탐색기 뿌리>] [--빼기 "그림,메모"]

# ⑤ 가이드가 부르는데 없는 그림을 찾아 체크리스트 표까지 만든다
python $SK/lecture-lab/가이드그림.py 대조

# ⑥ 랩이 여전히 도는가
python $SK/lecture-lab/가이드그림.py 회귀
```

**`--이어서` 는 세션에 블록을 쌓는 것이다.** 문서에 덧붙이라는 뜻이 아니다.
