# HYD 이론 강의 영상

덱의 장 그림 위에 최종 이론 대본을 강사 복제 음성으로 읽힌 소리와 자막을 얹어 영상으로 만드는 절차다. 도구는 `제작용/기존제작/tools/video/강의영상.py` 하나다. 규칙은 기준 문서에 있고, 이 문서는 순서 · 명령과 기준 절 번호만 적는다(「기준_X Yn」은 `문서/교재/기준_X.md`의 Yn절, 「Yn-k」는 그 k항). 경로는 저장소 루트 기준이고 명령은 저장소 루트에서 돌린다.

실습 영상은 이 스킬의 일이 아니다(기준_실습, 포털은 hyd-portal-video, 그 밖의 도구는 `제작용/촬영/<도구>/촬영준비.md`).

## 먼저 읽는다

1. `문서/교재/기준_공통.md` 끝까지, `문서/교재/기준_대본.md`의 S9(이론 강의 영상)와 기준_공통 G6 「음성」. 음성 전 대본 대조는 기준_대본 S9-2, 쉼은 기준_대본 S9-3에 있다. 대본 자체를 고치는 일이면 기준_대본(S5-4 구간 첫 문장 · S8-2 화면 대조).
2. `제작용/촬영/README.md`의 음성 설정, `course/videos/README.md`(지금 있는 영상). 음성 값 · 크레딧 · 견적의 지난 기록은 로컬 `.evidence/인계/인계_영상과대본점검.md`(이 PC에 없으면 의존성으로 적는다, 기준_공통 G3-5).
3. 만들 회차의 대본 폴더 `산출물/<과정>/이론/NN회차/대본/`. 대본 파일 하나 = 촬영 구간 하나 = 영상 하나(기준_대본 S5-2).

## 시작하기 전에 확인한다

하나라도 아니면 만들지 않고 사용자에게 무엇이 모자란지 알린다.

| 확인 | 어떻게 |
|---|---|
| 덱 · 대본 반영과 검사가 끝났다 | 기준_대본 S9-1. 덱 렌더 PDF의 `제작용/기존제작/tools/deck/글겹침.py` 0곳(기준_대본 S9-2) |
| 사용자가 범위를 말했다 | 범위는 대본 파일 단위. 듣기 전에는 음성도 영상도 만들지 않는다(기준_대본 S9-1) |
| 대본과 덱의 장 번호가 맞다 | `--dry`가 파일마다 `## [SLIDE NN]` 번호가 같은 회차 덱(`대본/` 위의 `<과정>_NN일차.pptx`) 장 수 안에 있는지, 겹치거나 거꾸로 가지 않는지 보고 멈춘다 |
| 첫 문장 | `--dry`가 이음말로 시작하는 첫 문장을 잡고 멈춘다(기준_대본 S5-4) |
| 키가 있다 | 환경변수 `ELEVENLABS_API_KEY`, 없으면 `--env <키 파일>`. 값은 출력하지 않는다(기준_공통 G6-15) |
| 맑은 고딕이 있다 | `fc-list \| grep -i malgun`. 없으면 장 그림이 다른 글꼴로 그려지니 멈추고 알린다 |
| 프로그램이 있다 | `soffice`, `pdftoppm`, `ffmpeg`, `ffprobe` |

## 순서

### 1. 글자 수를 재고 비용을 알린다 (비용 없음)

```bash
python3 제작용/기존제작/tools/video/강의영상.py <출력 폴더> 산출물/통합반/이론/01회차/대본/*.md --breath --dry
```

- 인자는 출력 폴더와 대본 파일(여러 개 가능). 영상 이름은 `<과정>_NN회차_<대본 파일 이름>.mp4`. `--target`(목표 초)은 주지 않는다(기준_대본 S9-3).
- `--dry`는 파일마다 장 범위 · 글자 수 · 점검 결과만 찍고 끝난다. `SLIDE NN~MM` 구획(실습 간지 + 설명 장)은 첫 문장과 그 뒤 쉼까지 간지를, 둘째 문장부터 설명 장을 보여 준다.
- 글자 수와 견적을 사용자에게 먼저 알린다(기준_공통 G4-4, 기준_공통 G6-14). 새 음성은 약 0.57 크레딧/자이고, 실제로 쓴 크레딧은 4의 시간표에 찍힌다.

### 1-1. 음성 전에 대본을 화면과 대조한다 (비용 없음)

장 그림(`제작용/기존제작/tools/video/슬라이드/<덱>/s-NN.png`)과 대본을 열고 기준_대본 S8-2대로 대사가 가리키는 위치 · 모양이 그 장에 실제로 있는지, 실습 안내가 실습의 목적을 말하는지, 한 장 안에서 예고 · 맺음이 겹치지 않는지(S5-5) 본다. 확정 대본은 문체를 고치지 않고 고칠 곳만 전 · 후로 보여 승인받는다(기준_공통 G6-7, 기준_공통 G4-2). 뽑은 뒤에 고치면 그 장 음성을 다시 사야 한다.

같은 덱을 쓰는 다른 과정 대본이 본문까지 같으면(예: 실전반 1회차 = 통합반 1회차) 음성 캐시를 그대로 다시 쓰므로 크레딧이 들지 않는다. 출력 폴더만 `course/videos/<그 과정>`으로 바꿔 같은 명령을 돈다.

### 2. 음성을 뽑는다 (비용이 드는 단계)

```bash
python3 제작용/기존제작/tools/video/강의영상.py <출력 폴더> <대본 파일 …> --breath \
  --pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
```

- 장마다 음성을 `제작용/기존제작/tools/video/음성_저장/`에 둔다. 글 · 목소리 · 모델 · 빠르기가 같은 장은 다시 뽑지 않는다. 목소리 · 모델의 기본값은 바꾸지 않는다(기준_공통 G6-13).
- 처음 돌리면 쉴 자리가 적히지 않은 장마다 `제작용/기존제작/tools/video/쉼_저장/`에 `"쉼": null`인 파일을 만들고 멈춘다. 정상이다.

### 3. 쉴 자리를 채운다 (비용 없음)

`쉼_저장/`의 파일마다 `"문장"` 목록이 있다. `"쉼"`을 문장 사이의 수(문장 수 - 1)만큼 0~3 정수로 채운다. 각 단계의 뜻은 기준_대본 S9-3. 작업하는 세션이 문장을 읽고 직접 정한다(바깥 모델에 맡기지 않는다). 빈 파일을 다 채운 뒤 2의 명령을 다시 돌린다. 음성은 저장되어 있어 다시 돈이 들지 않는다.

### 4. 영상이 만들어지면 확인한다

- 출력 폴더에 `<과정>_NN회차_<대본 파일 이름>.mp4`, 그 옆 `_작업/영상_자막_기록/`에 자막(`.srt`)과 시간표(`_시간표.md`: 쓴 크레딧, 말한 시간, 쉼의 분포, 장별 시작 시각)가 생긴다.
- 완료 판정은 기준_대본 S9-4의 네 항목(말머리 잘림 0, 화면 전환 시각 = 시간표의 장 시작 시각, 소리와 화면 길이 일치, 자막 문장 단위)이다. 검사 도구:

```bash
python3 제작용/기존제작/tools/video/검사/말머리_잘림.py <영상>                 # 0곳
python3 제작용/기존제작/tools/video/검사/장넘김_싱크.py <영상> <시간표.md>      # 못 맞춘 기대 0
```

- 쉼의 분포는 `ffmpeg`의 `silencedetect`, 화면이 바뀐 시각은 `select='gt(scene,0.02)'`로 잴 수 있다.
- 도구 동작: 쉼은 문장 사이에서 소리가 가장 작은 곳에 넣는다(ElevenLabs 글자 시각이 실제 말머리보다 늦을 수 있어서다). 조용한 곳이 없으면 장 번호와 초를 대며 멈춘다. 숫자 사이의 점(1.1)은 문장 끝으로 보지 않고, 장 시작 시각은 인코딩된 구획의 실제 길이로 센다.
- 작업하는 세션은 소리를 들을 수 없다. 들어 본 확인은 사용자가 하고 보고에 그렇게 적는다(기준_대본 S9-4, 기준_공통 G4-7).

### 5. 고칠 때 돈을 아끼는 법

| 바뀐 것 | 다시 드는 비용 |
|---|---|
| 쉼의 길이(`--pause-*`, `--gap`) | 없다. 2의 명령을 값만 바꿔 다시 돌린다 |
| 쉴 자리(`쉼_저장/`) | 없다 |
| 덱만(대본은 그대로) | 없다. PPTX가 바뀌면 장 그림만 다시 만든다 |
| 대본의 몇 장 | 그 장의 음성만 새로 든다. 바뀐 장의 쉴 자리는 다시 채운다 |
| 목소리 · 모델 · 빠르기 | 전부 다시 든다. 바꾸지 않는다(기준_공통 G6-13, 기준_대본 S9-5) |

## 산출물과 올리지 않는 것

- 영상 · 음성 · 자막 · 시간표는 main이 아니라 `other-pc`에만(기준_공통 G5-1, 올리는 법은 기준_실습 P12를 참고). 장 그림은 다시 만들 수 있어 어디에도 올리지 않는다. `제작용/기존제작/tools/video/.gitignore`가 `음성_저장/` · `슬라이드/`를, `course/videos/.gitignore`가 영상 폴더의 파일을 막는다. 커밋 전에 `git status`로 다시 본다.
- 출력 폴더는 `course/videos/<과정>/` 아래나 저장소 밖에 둔다.
- `쉼_저장/`의 JSON은 글이므로 올린다(다시 채우는 품을 덜기 위해).
- 영상을 만들거나 고쳤으면 `course/videos/README.md`를 고치고, 진행 기록은 로컬 `.evidence/기록/`에 남긴다(기준_공통 G5-6).

## 보고

항목별로 요구 → 결과 → 근거를 대조해 적는다: 만든 영상과 길이, 쓴 크레딧, 기준_대본 S9-4 네 항목의 측정값(도구 출력), 1-1 대조에서 고친 곳, 청취는 `미확인`(사용자 몫). 상태어는 기준_공통 G4-7.
