# HYD 이론 강의 영상

덱의 장 그림 위에 최종 대본을 강사의 복제 음성으로 읽힌 소리와 자막을 얹어 영상으로 만드는 절차다. 도구는 `production/tools/video/강의영상.py` 하나다. 경로는 모두 저장소 루트 기준이고 명령은 저장소 루트에서 돌린다.

실습 영상은 이 스킬의 일이 아니다. 실습 영상은 강사가 직접 조작하며 말하고 더빙하지 않는다(`문서/교재/2_기준.md` 58번).

## 먼저 읽는다

1. `문서/교재/2_기준.md` 9절(음성과 영상), 8절 49번(영상 첫 문장), 15절(대본의 형식). 규칙은 여기에만 있다.
2. `문서/교재/4_만드는_법.md` 3부 2절(도구와 비용), `course/videos/README.md`(지금 있는 영상).
3. 만들 일차 대본 맨 위의 「이 일차의 구성」 표. 실라버스 행마다 첫 장과 끝 장이 적혀 있다.

## 시작하기 전에 확인한다

하나라도 아니면 만들지 않고 사용자에게 무엇이 모자란지 알린다.

| 확인 | 어떻게 |
|---|---|
| 사용자가 범위를 말했다 | 범위를 듣기 전에는 음성도 영상도 만들지 않는다(9절 53번). 범위는 실라버스 행 단위다. 행 하나가 영상 하나다 |
| 대본이 최종본이고 덱과 번호가 맞다 | `course/scripts/integrated/통합반_NN일차_대본…_윤문2.md`의 `## [SLIDE NN]` 번호가 `course/slides/integrated/통합반_NN일차.pptx`의 장 번호와 같아야 한다. 덱을 고친 뒤 대본을 맞추지 않았으면 그림과 말이 어긋난다 |
| 키가 있다 | 환경변수 `ELEVENLABS_API_KEY`. 없으면 `--env <키 파일>`. 값은 출력하지 않는다 |
| 맑은 고딕이 있다 | `fc-list \| grep -i malgun`. 도구는 PPTX를 LibreOffice로 그림으로 바꾸므로, 글꼴이 없으면 영상의 장 그림이 다른 글꼴로 그려진다. 없으면 멈추고 알린다 |
| 프로그램이 있다 | `soffice`, `pdftoppm`, `ffmpeg`, `ffprobe` |
| 첫 문장 | 영상마다 첫 장의 첫 문장이 「그럼 · 그러면 · 그래서 · 자 · 이제 · 이어서」로 시작하지 않는다(49번). 영상은 행마다 따로 재생된다 |

## 순서

### 1. 글자 수를 재고 비용을 알린다

```bash
python3 production/tools/video/강의영상.py 01 4 9 0 <출력 폴더> --polished2 --breath --dry
```

- 인자는 차례로 일차 두 자리, 첫 장, 끝 장, 목표 초, 출력 폴더다. 목표 초는 **0**으로 둔다. 쉼을 늘이거나 줄여 시간을 맞추지 않는다(9절 51번).
- `--dry`는 장 수와 글자 수만 찍고 끝난다. 돈이 들지 않는다.
- 음성은 비용이 드는 일이다. 글자 수와 함께 사용자에게 먼저 알리고 승인을 받는다(12절 70번). 지난 기록으로는 하루치에 5,000 크레딧 안팎이 들었다(`4_만드는_법.md` 3부 2절). 실제로 쓴 크레딧은 4의 시간표에 찍힌다.

### 2. 음성을 뽑는다 (비용이 드는 단계)

```bash
python3 production/tools/video/강의영상.py 01 4 9 0 <출력 폴더> --polished2 --breath \
  --pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
```

- 장마다 음성을 뽑아 `production/tools/video/음성_저장/`에 둔다. 글 · 목소리 · 모델 · 빠르기가 같은 장은 다시 뽑지 않는다. 목소리와 모델(`eleven_v4`)의 기본값은 도구에 정해져 있으니 바꾸지 않는다(9절 50번).
- 처음 돌리면 쉴 자리가 적히지 않은 장마다 `production/tools/video/쉼_저장/`에 `"쉼": null`인 파일을 만들고 멈춘다. 정상이다.

### 3. 쉴 자리를 채운다 (비용 없음)

`쉼_저장/`의 파일마다 `"문장"` 목록이 있다. `"쉼"`을 문장 사이의 수(문장 수 - 1)만큼 0~3으로 채운다. 작업하는 세션이 문장을 읽고 직접 정한다. 바깥 모델에 맡기지 않는다.

| 단계 | 뜻 |
|---|---|
| 0 | 잇는다. 앞 문장을 받아 바로 풀어 주는 말, 나열의 중간 |
| 1 | 짧게 쉰다. 같은 이야기 안에서 한 박자 끊는 곳 |
| 2 | 한 호흡 쉰다. 한 이야기가 끝난 곳, 중요한 말 뒤, 물음 뒤 |
| 3 | 크게 쉰다. 화제가 바뀌는 곳. 한 장에 많아야 한두 곳 |

빈 파일을 한꺼번에 다 채운 뒤 2의 명령을 다시 돌린다. 음성은 저장되어 있어 다시 돈이 들지 않는다.

### 4. 영상이 만들어지면 확인한다

- 출력 폴더에 `통합반_NN일차_SLIDE첫장-끝장_윤문2.mp4`, 그 옆 `_작업/영상_자막_기록/`에 자막(`.srt`)과 시간표(`_시간표.md`: 쓴 크레딧, 말한 시간, 쉼의 분포, 장별 시작 시각)가 생긴다.
- 볼 것: 영상 길이와 시간표, 장 그림이 대본의 장과 맞는가, 자막이 문장 단위로 끊기는가. 쉼의 분포는 `ffmpeg`의 `silencedetect`로 잴 수 있다.
- 작업하는 세션은 소리를 들을 수 없다. 들어 본 확인은 사용자가 한다. 보고에 그렇게 적는다.

### 5. 고칠 때 돈을 아끼는 법

| 바뀐 것 | 다시 드는 비용 |
|---|---|
| 쉼의 길이(`--pause-*`, `--gap`) | 없다. 2의 명령을 값만 바꿔 다시 돌린다 |
| 쉴 자리(`쉼_저장/`) | 없다 |
| 덱만(대본은 그대로) | 없다. PPTX가 바뀌면 장 그림만 다시 만든다 |
| 대본의 몇 장 | 그 장의 음성만 새로 든다. 바뀐 장의 쉴 자리는 다시 채운다 |
| 목소리 · 모델 · 빠르기 | 전부 다시 든다. 바꾸지 않는다 |

## 산출물과 올리지 않는 것

- 영상, 음성, 장 그림, 자막과 시간표는 저장소에 올리지 않는다(13절 76번). `production/tools/video/.gitignore`가 `음성_저장/` · `슬라이드/`를, `course/videos/.gitignore`가 영상 폴더의 파일을 막는다. 커밋 전에 `git status`로 다시 본다.
- 출력 폴더는 `course/videos/<과정>/` 아래에 두거나 저장소 밖에 둔다.
- `쉼_저장/`의 JSON은 글이므로 올린다. 다시 채우는 품을 덜기 위해서다.
- 영상을 만들거나 고쳤으면 `course/videos/README.md`(있는 영상의 목록), `문서/교재/3_현황.md` 0절의 「강의 영상」 줄, `문서/교재/6_남은_일.md`를 고친다.
