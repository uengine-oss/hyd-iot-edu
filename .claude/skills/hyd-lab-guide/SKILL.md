# 가이드 — 입구

이 스킬은 입구다. 이 산출물의 목적 · 가치 · 배경, 작업 컨텍스트, 작업 요령, 인수 조건은 모두 `문서/교재/가이드.md` 한 곳에 있다(Codex도 같은 문서를 읽는다). 다른 교재 문서를 함께 읽을 필요는 없다.

## 순서

1. `문서/교재/가이드.md`를 끝까지 읽는다. 대화가 요약 · 재개된 뒤에도 다시 끝까지 읽는다(요약을 믿지 않는다).
2. 작업 컨텍스트에서 이번 일의 입력(실라버스 행 · 본보기 · 앞뒤 산출물 · 지금 상태)을 실물로 확인한다.
3. 작업 요령대로 만든다. 도구 · 명령 · 경로는 그 문서의 작업 컨텍스트(도구 · 경로 표)와 작업 요령에 있다. 로컬 Windows는 `PYTHONUTF8=1 .venv314/Scripts/python.exe`(uv는 `~/.local/bin/uv.exe`), 클라우드는 `python3`.
4. 끝내기 전에, 만든 사람이 아닌 검토자(서브에이전트 opus, 문서와 산출물만 받고 고치지 않고 목록만)가 그 문서의 인수 조건 표 전 항목을 판정한다.
5. 불통과를 고치고, 고친 범위를 다시 판정한다. 불통과 0이 되기 전에는 끝났다고 쓰지 않는다.

## 보고

- 인수 조건 N항목 중 통과 · 불통과 · 해당 없음(까닭) 숫자, 불통과 목록(번호 · 근거 위치).
- 실행하지 않은 것 · 열어 보지 않은 것은 `미확인`으로 따로 적는다.
- 사용자 확인 · 허락은 「상황 → 제안 → 이렇게 해도 될까요」로, 전문을 읽게 하지 않는다.
