# 외부 자료 반영과 근거 보존

받은 지시서·핸드오프·리서치·검토안을 반영할 때 읽는다.

1. 원본을 읽고 출처·버전 또는 해시를 기록한다. 받은 파일의 내용을 우리 판정으로 고치지 않는다.
2. 항목마다 원문 위치, 채택·기각·미결 및 이유, 현재 문서 위치를 대응표에 기록한다.
3. 채택한 항목과 그 영향 문서를 갱신하고 실제 반영된 문장을 다시 확인한다.
4. 현행 계약에는 현재 결정을, 원본에는 근거 역할을 부여한다. 역할 구분으로 정본 혼동을 막는다.
5. 원본은 보존한다. 배포 묶음에서는 명시적으로 제외하고 실제 ZIP 구성으로 확인한다.
   이름 앞 `_`만 붙이면 모든 도구가 제외할 것이라고 가정하지 않는다.

원본 삭제는 반영 절차에 포함되지 않는다. 구체적인 삭제 요청이 있을 때만 별도로 처리한다.
미결 항목이 남으면 해당 요구는 완료로 세지 않고 다음 판단에 필요한 정보를 남긴다.
