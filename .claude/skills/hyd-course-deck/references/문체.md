# 슬라이드·대본·가이드 문체

설명 흐름이나 문장을 작성·검토할 때 읽는다. 강의별 승인된 예시·템플릿·청중 수준을 먼저 따른다.

- 슬라이드는 한눈에 비교·구조·핵심을 볼 수 있게, 대본은 실제로 읽을 수 있는 연결된 말로 쓴다.
- 가이드는 학생이 행동하고 결과를 관찰하고 다음 판단을 할 수 있게 쓴다.
- 처음 쓰는 용어는 필요한 시점에 설명하고, 대본과 덱에서 같은 개념에 같은 이름을 쓴다.
- 접속사는 인과·대조·추가 관계에 맞게 쓴다. 특정 접속사만 허용하거나 말끝을 기계적으로 교대하지 않는다.
- 문장을 읽어 앞 문장에서 다음 문장으로 자연스럽게 이어지는지 확인한다. 반복·뜬금없는 질문·과장된 격려를 줄인다.
- 수치와 단정은 근거에 맞춘다. 근거 없는 수치는 만들지 않으며, 가정·예시는 그 성격을 표시한다.
- 출처를 모든 문장에 낭독시키지 않아도 되지만, 검증 가능한 출처를 자료의 적절한 위치에 남긴다.
- 강사용 해설과 학생용 문제의 답 공개 수준을 구분한다. 모든 강의를 빈칸 실습으로 강제하지 않는다.

검토는 실제 문단을 읽어 판단한다. 금지어 검색 통과만으로 자연스러움·교육 효과를 판정하지 않는다.

## 이론 교재(PPTX)의 문장

HYD 이론 덱의 화법 규칙은 `workspace/강의제작/지침/덱.md`가 소유한다. 문장을 쓸 때 바로 볼 절:

- 대상과 깊이: D-36 · D-37. 용어 · 약어: D-68 · D-69.
- 제목 · 메시지: D-64 ~ D-67. 화면 글의 문어체 · 윤문: D-71.
- 쓰지 않는 말: D-72. 회차를 잇는 말: D-32 · D-33. 포털 따라 하기 · 조작 순서: D-52.
- 구현 사정 · 단서 · 면책: D-16.
- 비유: D-70.
- 실습 장: D-53 ~ D-56.
- 발표자 노트의 꼴과 말투: D-113 ~ D-124.

기준 절에 없는 요점:

- 메시지는 강사가 그대로 읽을 말이다.
- 「오늘 처음 만난 말」 같은 표현을 화면에 쓰지 않는다.
- 「표준과는 다르지만」 식의 비교를 화면에도 노트에도 쓰지 않는다.
