# 강의 스킬

이 저장소의 교재와 실습 자료를 만들 때 쓰는 스킬이다. 스킬 원본은 이 폴더 한 곳에 둔다. 경로는 저장소 루트 기준이다. 스킬은 입구다 — 산출물 하나에 스킬 하나이고, 그 산출물의 목적 · 가치 · 배경, 작업 컨텍스트, 작업 요령, 인수 조건은 `workspace/강의제작/지침/`의 그 산출물 문서 하나가 모두 갖는다(Codex도 같은 문서를 읽는다). 스킬은 인수 조건을 다시 적지 않는다.

무엇을 시키든 맨 먼저 `hyd-task`(작업 폴더 → 문서 하나 → 만들기 · 검사 → 제자리 → 동기화 → 정리)를 따르고, 강의 산출물이면 아래 스킬을 이어 쓴다.

| 스킬 | 산출물 | 문서 | 스킬 폴더의 도구 · 자료 |
|---|---|---|---|
| `hyd-task` | 모든 작업의 순서(작업 폴더 · 제자리 · 동기화 · 정리) | `workspace/README.md` 색인 | `SKILL.md` |
| `hyd-syllabus` | 실라버스 엑셀 네 시트 · 노션 실라버스 | `workspace/강의제작/지침/실라버스.md` | `SKILL.md` |
| `hyd-course-deck` | 이론 덱(덱 MD · PPTX, 실전반 압축판, 오프라인 덱) | `workspace/강의제작/지침/덱.md` | `SKILL.md`, `scripts/deck2pptx.py` · `scripts/find_icon.py`, `references/`(덱MD-PPTX형식 · 문체 · 예시), `assets/`(아이콘 · 로고) |
| `hyd-script` | 이론 대본 · 온라인 덱의 발표자 노트 | `workspace/강의제작/지침/대본.md` | `SKILL.md` |
| `hyd-video` | 이론 강의 영상 · 모든 실습 영상 · 실습 대본 · 촬영 · 음성 · 자막 · 게시 | `workspace/강의제작/지침/영상.md` | `SKILL.md` (도구별 값 · 함정은 `workspace/강의제작/제작도구/촬영/<도구>/촬영준비.md`) |
| `hyd-coding-lab` | 코딩 랩 과제 · 제공물 · 시작본 · 완성 판정 · 시작 도구 | `workspace/강의제작/지침/코딩랩.md` | `SKILL.md` |
| `hyd-lab-guide` | 실습 가이드 · 학생 패키지 · 받기 시험 · 게시 | `workspace/강의제작/지침/가이드.md` | `SKILL.md` |
