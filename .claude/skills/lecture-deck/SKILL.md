# 덱 · PPTX

이론 교재 덱을 만든다. 덱 MD(화면 원고)가 원본이고, `scripts/deck2pptx.py`가 덱 MD를 읽어 고정된 디자인의 PPTX를 찍는다. 같은 덱 MD는 언제나 같은 디자인으로 나온다.

경로는 모두 저장소 루트 기준이다. 이 스킬의 상대 경로는 이 스킬 폴더 기준이다.

이 저장소의 HYD 과정 덱은 `hyd-course-deck` 스킬(절차 · 점검)과 `문서/교재/기준_공통.md` · `문서/교재/기준_이론덱.md`(규칙)를 먼저 따른다. 이 스킬은 덱 MD의 형식과 생성 도구를 맡는다(기준_이론덱 머리말 「이 갈래의 스킬」, D9-4).

## 입력 확인

HYD 교육과정 덱은 만들기 전에 아래를 읽는다. 다른 강의면 그 강의의 제작 기준을 먼저 찾는다.

1. 기준 `문서/교재/기준_공통.md`와 `문서/교재/기준_이론덱.md` 끝까지 — 대상과 수준, 덱의 틀(D4), 장 쓰는 법(D5), 회차 사이 경계(D2-4), 검사(D9). 규칙은 거기에만 있다. 이 스킬 문서에 복사하지 않는다.
2. 사실의 근거(기준_공통 G3-1): 기술사실표 `문서/교재/사실표/`(예: `통합반_01일차_기술사실표.md`, `통합반_02-04일차_기술사실표.md`). 확인하지 못한 것은 쓰지 않는다.
3. 실라버스 정본 `문서/교재/실라버스/피지컬AI_실라버스_최종본.xlsx` — 행 · 제목 · 상세 항목 · 순서 · 이론/실습 구분(기준_공통 G2, 대응은 기준_이론덱 D9-2).
4. 본보기(기준_이론덱 D0): 덱을 새로 짜면 본보기 덱 하나를 렌더로 처음부터 끝까지 넘겨 본다. 그림체 샘플 `제작용/온라인/decks/integrated/sample/샘플.md`, 실제 덱 `제작용/온라인/decks/integrated/day01/통합반_01일차.md`. 짧은 발췌는 [1일차 앞부분 예시](references/examples/덱MD_예시_1일차_앞부분.md).

## 작업

1. **장 목록을 먼저 짠다.** 단원별로 장의 제목과 메시지를 쓰고, 메시지만 이어 읽어 이야기가 되는지 본다(기준_이론덱 D5-5 · D5-4).
2. **덱 MD를 쓴다.** 장마다 `### 화면 내용` / `### 화면 구성` / `### 제작 기준`을 둔다. 스크립트는 화면 내용만 읽는다. 유형, 칸, 요소 수, 아이콘 규칙은 [덱 MD → PPTX 형식](references/덱MD-PPTX형식.md)을 따른다. 제작 기준 칸은 기준_이론덱 D9-3.
3. **삽화와 그래프를 그린다.** 직접 그린 SVG(글자 없음)와 실제 데이터 그래프를 덱 폴더의 그림 폴더(`figures/` 또는 `그림/`)에 그리는 스크립트와 함께 둔다. 라벨은 덱 MD의 요소로 얹는다(기준_이론덱 D6).
4. **아이콘을 고른다.** `scripts/find_icon.py <낱말> [--preview <png>]`로 찾는다(한국어 낱말도 된다).
5. **빌드한다.**
   ```bash
   uv run --no-project --with python-pptx --with pymupdf python .claude/skills/lecture-deck/scripts/deck2pptx.py <덱.md> <출력.pptx> [--render <새 PNG 폴더>]
   ```
   스크립트가 멈추면 문구를 다듬거나 장을 나누거나 유형을 바꾼다. 도구의 한계는 우회하지 않고 도구를 고친다(기준_이론덱 D9-4).
6. **렌더해 본다.** `--render`는 LibreOffice(soffice)와 pdftoppm이 필요하고 한 번에 하나씩 돈다. 렌더 폴더는 새 이름으로 쓴다. 묶음 그림은 `제작용/기존제작/tools/deck/시트.py`로 만든다.

## 검증

HYD 덱은 `hyd-course-deck`의 「점검」 체크리스트(기준_이론덱 D9-7)를 따른다. 다른 강의도 최소한 다음을 한다.

- 화면 문구와 노트를 처음부터 끝까지 한 문장씩 읽는다. 낱말 검색으로 갈음하지 않는다.
- 렌더한 모든 장을 읽을 수 있는 크기로 본다(한 묶음 9장 이하). 넘침, 겹침, 잘린 글자, 큰 빈 칸, 같은 형태의 긴 연속을 고친다.
- 앞뒤 회차 덱 MD와 용어, 약어 풀네임, 같은 예의 값을 대조한다.
- 하지 않은 렌더를 완료로 쓰지 않는다.

## 산출물과 미결

덱 MD, PPTX, 그림 폴더의 실제 경로와 최종 장수를 전달한다. 못 본 장, 확인하지 못해 뺀 사실, 실라버스와 달라 구현을 따른 곳을 항목별로 적는다(기준_이론덱 D9-8). 기존 PPTX와 받은 예시는 덮어쓰지 않고 새 파일로 만든다(확정 덱은 다시 빌드하지 않는다, D9-5). 기본 `pptx` 스킬은 기존 PPTX를 읽거나 국소 수정할 때 쓴다.
