# workspace — 작업 자료

학생이 받는 코드는 main 브랜치에 있다. 이 폴더는 강의를 만들고 시스템을 고치는 데 쓰는 자료 전부이고, 통째로 workspace 브랜치가 된다.
무엇이든 시작할 때는 아래 표에서 **하려는 일의 문서 하나**를 끝까지 읽는다. 함께 읽을 것이 있는 일만 하나 더 읽어 많아야 2개다. 사실표 · 포털 기능 표 · main 코드는 통독하지 않고 필요한 대목만 찾아보는 자료라 이 수에 세지 않는다. 작업 순서(작업 폴더 → 만들기 · 검사 → 제자리 → 동기화 → 정리)는 스킬 `hyd-task`. 브랜치: main은 학생이 받는 시스템 코드, 이 폴더(workspace)는 제작 자료이고 한 체크아웃에 함께 있다.
