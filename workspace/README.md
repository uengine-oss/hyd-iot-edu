# workspace — 작업 자료

학생이 받는 코드는 main 브랜치에 있고, 강의를 만들고 시스템을 고치는 자료는 이 폴더(workspace 브랜치)에 있다. 두 브랜치의 파일은 한 체크아웃에 함께 들어 있다.
시작할 때 아래 표에서 하려는 일의 「읽을 문서」를 찾아 끝까지 읽는다. 작업 순서는 스킬 `hyd-task`가 정한다. 예를 들어 「통합반 2~3회차부터」라고 맡기면 통합반 2회차·3회차 순으로 진행하고, 뒤에 「실전반 2회차」를 맡기면 통합반의 대응 단원을 읽어 실전반을 만든다. 담당 과정과 산출물은 [hyd-task 1절](../.claude/skills/hyd-task/SKILL.md)에서 정한다.
