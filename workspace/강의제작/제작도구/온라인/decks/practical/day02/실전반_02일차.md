## SLIDE 06 — 한계를 둘 자리: 속성과 관계
### 화면 내용
- 유형: 비교
- 메시지: 한계 같은 값은 그 대상의 칸에 두고, 센서에서 그 값을 읽으려면 상태 변수로 건너가는 관계를 따라간다.
- 요소:
  1. 속성 — 데이터 속성(Data Property) | 값이 그 인스턴스의 칸 안에 있다 / 유온 센서의 tag 'TS1' · unit '℃' / 이 설비에서는 유온 normal 48 · limit 65 ℃ | 인스턴스와 값
  2. **관계 — 객체 간 관계(Object Property)** | 유온 센서 → OBSERVES → 유온 / 유온은 상태 변수(StateVariable): 설비의 상태를 나타내는 물리량 / 한계는 건너간 유온에서 읽는다 / 채널을 하나 더 두어도 유온 1개 · 한계 1개 | 인스턴스와 인스턴스
- 노트: [짚을 곳] 왼쪽 속성의 센서 값과 유온의 정상값 · 한계 → 오른쪽 강조한 읽는 관계 → 상태 변수 → 한계를 읽는 길 → 마지막 줄 / · 온톨로지 책의 데이터 속성 · 객체 간 관계 = 이 과정의 속성 · 관계 / · 태그와 단위는 센서 칸 안의 값, 정상값과 한계는 유온 칸 안의 값 → 모두 속성 / · 상태 변수 = 설비의 상태를 나타내는 물리량. 센서는 재는 쪽, 유온은 재어지는 쪽 / · 센서에서 한계를 알려면 읽는 관계로 유온에 한 번 건너간다. 센서를 바꾸거나 같은 유온을 재는 채널을 하나 더 두어도 관리할 유온은 하나 → 한계를 채널마다 적으면 두 군데, 한쪽만 고치면 한계가 둘 / · 헷갈리는 짝: 글자냐 숫자냐가 기준이 아니다. 값이 그 대상의 칸에 있나, 이어진 다른 대상에 있나 / [다음] 관계 그림의 이름들은 어느 클래스인가
