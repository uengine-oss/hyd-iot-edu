## SLIDE 09 — 거절 시나리오를 적은 예
### 화면 내용
- 유형: 코드
- 메시지: 기대 결과를 한 줄에 하나씩 적으면 어떤 약속이 깨졌는지 구분해 확인할 수 있다.
- 코드: Feature: 추천안 승인 /   Scenario: 담당자가 추천안을 거절한다 /     Given 추천안이 승인 대기 중이다 /     When 운전원이 사유를 적고 거절한다 /     Then 설비 명령은 0건이다 /     And 결과 보고의 결과는 반려다 /     And 보고 요약에 입력한 사유가 남는다
- 요소:
  1. 서식 | 기능(Feature)과 시나리오(Scenario)를 적는 서식이 **Gherkin**이다.
  2. Given | 시험이 시작될 때 이미 갖춰진 상태다.
  3. When | 운전원의 거절이 시험할 행동이다.
  4. **Then · And** | And는 앞의 결과에 확인할 사실을 하나 더한다.

- 노트: [짚을 곳] 왼쪽 Feature·Scenario → Given·When → Then과 두 And / · 같은 거절 시험에서 관찰할 기대를 Gherkin 예문으로 적었다 / · 명령 수와 보고 결과를 각각 검사하고 보고 요약에 입력 사유가 있는지도 검사한다 / · 서식으로 적은 예문과 실제로 도는 파이썬 시험을 구별한다 / [다음] 기대를 측정할 수 있게 쓰기
### 화면 구성
