## SLIDE 47 — MATCH와 RETURN
### 화면 내용
- 유형: 코드
- 메시지: **MATCH**는 적은 패턴에 맞는 것을 그래프에서 모두 찾고, **RETURN**은 찾은 것 가운데 돌려받을 값을 정한다.
- 코드: MATCH (:Asset {code: 'EQ-02'}) /       -[:HAS_COMPONENT]->(c:Component) / RETURN c.name
- 요소:
  1. **절**(Clause) | MATCH · RETURN처럼 첫 낱말로 시작해 / 할 일 하나를 맡는 부분
  2. MATCH 절 | 2호기에서 가진다로 이어진 / 구성 요소를 모두 찾는다
  3. RETURN 절 | 찾은 구성 요소 c의 이름(c.name)을 돌려받는다
  4. 결과 3행 | 주 펌프 · 쿨러 팬 · 오일 쿨러
- 노트: [짚을 곳] 오른쪽 절 → MATCH 절(코드 위 두 줄) → RETURN 절(셋째 줄) → 오른쪽 결과 / · 쿼리는 절로 나뉜다. MATCH · RETURN처럼 첫 낱말로 시작해 할 일 하나를 맡는 부분이 절. 이 쿼리는 MATCH 절과 RETURN 절 둘 / · MATCH = 뒤에 적은 패턴에 맞는 것을 그래프에서 모두 찾는다. 2호기에서 가진다로 이어진 구성 요소가 셋이라 셋을 모두 찾는다 / · RETURN = 찾은 것 가운데 무엇을 돌려받을지. c.name은 변수 c로 부른 구성 요소의 이름 / · 결과는 행으로 나온다. 찾은 구성 요소마다 한 행, 세 행 / · 앞에서 본 쿼리가 이것이다. 이제 두 절이 하는 일까지 읽힌다. 패턴이 길어 관계 앞에서 줄을 나눴고, 줄을 나눠도 같은 패턴이다 / [다음] 셋 가운데 오일 쿨러만 받으려면
