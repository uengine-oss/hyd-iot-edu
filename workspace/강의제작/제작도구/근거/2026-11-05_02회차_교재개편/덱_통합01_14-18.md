# 통합반 2회차 01편 덱 14~18장 및 현장 9장

직전 9~13장 덱 단계의 마지막 커밋에 든 PPTX·원고·조각 메모를 받았다. 12장에서 조작·영향과 관계의 속성, 13장에서 공통 쿨러의 들어오고 나가는 선을 구별했다. 오프라인 8장에서는 쿨러 → 유온 센서 → 유온을 읽었다. 이번 단원은 온라인 실라버스 17행 「관계 유형·방향·카디널리티(1:1, 1:N, N:M)」와 「언제 속성이나 관계로 표현해야 하는지」, 현장 14행의 「관계 유형·방향·카디널리티」에 해당한다.

처음 정의한 용어는 온라인 15장·현장 9장의 카디널리티(Cardinality)다. 흰 원 한 개에서 파란 원을 보고 파란 원 한 개에서 상대를 거꾸로 찾아, 지금 보이는 수와 허용하는 수를 나눈다. 비유는 쓰지 않았다. 온라인 18장에서 관계의 속성은 12장의 정의를 공급 관계에 적용한다. 끝 문장은 “같은 회사의 팬 베어링과 다른 회사의 씰 키트 견적은 각각 다른 연결에 있다.”이다. 19~22장에는 부품과 공급사에 독자적인 속성과 연결이 있어 둘을 클래스로 구별한다는 질문을 넘긴다. 현장 다음 장은 10장 「새 클래스를 정의하는 기준」이다.

현장 9장의 기본 계획은 1교시 7~9분(2분)이다. 첫 칸에서 양쪽 한 개를 확인하고 셋째 칸을 중심으로 비교한다. 답이 갈리면 유온 센서가 읽는 물리량 수와 유온에 더 달 수 있는 채널 수를 한쪽씩 짚는다. 두 방향에서 스스로 답하면 다음 장으로 간다. 네 교시 중 실습 시수는 건드리지 않았다. 실제 현장 측정값은 아니다.

온라인 덱 79장·본문 53장, 오프라인 41장·본문 28장. 대본은 별도 단계라 현재 14~18장 낭독 추정은 36.1·184.2·106.4·107.8·135.2초로 유지된다. 14장을 제외한 본문 합계는 8.89분이다. 클래스 이론 행은 배정 50분, 현재 본문 35분, 하한 40분이다. 이후 15장 두 방향, 16장 데이터 반례, 17장 같은 호기의 두 모델, 18장 두 고정 조건과 네 견적 행의 읽는 순서에 맞춰 대본을 확정한 뒤 첫 행 전체를 잰다. 15장 마지막 칸 원인·고장/부품·공급사, 17장 교체 날짜, 18장 코드 낭독과 전체 공급 목록은 새 화면으로 짚을 수 없으므로 해당 낭독을 최신 화면에 맞춘다. 14장의 간지를 늘려 분량을 채우지 않는다. 영상은 15~18장의 표시 대상·가림·발화 위치를 다시 잡고, 14장의 무강조 사유는 간지 역할에서 점검한다. 기존 17~18장 시작·끝 낱말 불일치도 해당 영상 단계에서 고친다.

## 낭독과 영상에 넘길 범위

현재 낭독은 01_이론_클래스와인스턴스.md의 [SLIDE 14]~[SLIDE 18]이다. 대본 담당은 13장의 두 채널에서 14장의 세 번째 채널 물음으로 이어 간다. 15장에서 카디널리티를 처음 풀고 같은 관계를 양쪽에서 읽는다. 16장은 팬 인버터의 실제 조작 대상과 가정한 추가 연결, 17장은 공통 쿨러와 호기별 쿨러의 조회 질문, 18장은 같은 부품을 고정한 비교와 같은 공급사를 고정한 비교를 이 순서로 짚는다. 19장에 넘기는 일은 공통 정의가 필요할 때 클래스를 나누는 판단이다.

기존 01편 강조 설정에서 14~18장의 표시 수는 장 순서대로 0·5·2·3·3개다. 15~18장의 13개는 최종 화면과 낭독으로 좌표·가림·표시 구간을 확인해야 한다. 15장의 넷째 칸은 쿨러와 채널의 관계이고, 18장은 공급 견적표이므로 옛 그림과 코드 박스의 좌표를 그대로 쓰지 않는다. 이번 대조에서 기존 '강조좌표.py --검사'는 해당 구간의 표시 27(17장 시작 문장)과 표시 30(18장 끝 문장)에서 오류를 냈다. 17·18장은 기존 음성 키의 쉼 파일도 미저장 상태다. 영상 담당은 최종 낭독으로 쉼을 확정한 뒤 실제 입력에 저장한다. 14장의 강조 유무 및 까닭도 최종판 그림·낭독에서 정해 장별점검표에 적는다. 음성 말머리, 재생 중 강조 시각, 장 넘김, 자막 싱크와 청취는 영상 생성 후 확인한다.

## 인용 및 공유 자료

2회차 통합 실습 ZIP 4개와 학생용·실습 완성본 ZIP 2개의 실제 항목명과 텍스트를 확인했다. 이 다섯 장의 제목, 교재 PPTX 파일명, 직접 인용 그림·발췌 파일은 없었다. 17장에서 인용한 통합 실습 4의 schema.json과 graph.json은 설비별 장치 수의 근거다. 기술사실표는 같은 검증기를 설명하는 다른 반에서도 읽는다. 후속 실전반 작업에서는 온라인 15~19장, 현장 9·10·31장의 출처와 실제 수강 순서를 대조한다. 이 조각의 확정 범위는 통합반이다.
