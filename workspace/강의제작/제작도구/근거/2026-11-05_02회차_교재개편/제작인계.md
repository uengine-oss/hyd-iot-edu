## 저장소 루트에서 실행하는 무료 검증

Python 3와 지정 글꼴·LibreOfficeDev가 준비된 환경에서 실행한다. `D`는 대본 폴더, `W`는 새 작업 폴더, `H`는 이번 단원의 근거 폴더다.
```bash
set -e
G=workspace/강의제작
K="$G/제작도구/검사"
T="$G/제작도구/기존제작/tools/video"
H="$G/제작도구/근거/2026-11-05_02회차_교재개편"
D="$G/산출물/통합반/이론/02회차/대본"
C="$G/제작도구/구성/통합반/02회차"
W="$(pwd)/작업/통합반02_재개"
V=1PdAOcPlPTz12RwMyFVp
mkdir -p "$W"
python3 "$K/판본검사.py" 통합2
python3 "$K/덱측정.py" "$W/덱측정.json" 통합2
python3 .claude/skills/hyd-course-deck/scripts/deck2pptx.py "${D%/대본}/통합반_02일차.pptx" --render "$W/공식렌더"
python3 "$G/제작도구/기존제작/tools/deck/글겹침.py" "$W/공식렌더/통합반_02일차.pdf"
python3 "$K/낱말줄찾기.py" "$W/공식렌더"
EP=02_이론_스키마설계
MARK="강조_통합반_02회차_${EP}.json"
mkdir -p "$W/단원강조"
python3 "$T/강조좌표.py" "$W/공식렌더/통합반_02일차.pdf" "$D" "$H/강조계획_02_29-36.json" --출력 "$W/단원강조/$MARK"
python3 "$T/강조좌표.py" --검사 "$D/$EP.md" "$W/단원강조/$MARK"
mkdir -p "$W/강조용슬라이드"
pdftoppm -r 150 -png "$W/공식렌더/통합반_02일차.pdf" "$W/강조용슬라이드/s"
python3 "$T/강조미리보기.py" "$W/강조용슬라이드" "$W/단원강조/$MARK" "$W/단원강조/미리보기"
python3 "$T/쉼옮기기.py" "$D/$EP.md" --장 29-36 --파형 --voice "$V" --출력 "$W/쉼대조.json"
python3 "$T/강의영상.py" "$W/dry" "$D"/*.md --breath --dry
python3 "$T/음성견적.py" "$D/$EP.md" --voice "$V"
```

29~36장 26개 표시는 편별 제작 설정에 반영했다. 재생 전에 편 전체에서 변경된 대본과 강조를 검사한다.

## 편별 인수와 유료 집행 승인 뒤 사용할 명령

현재 상태는 세 편 모두 제작 대기다. 아래 명령은 다음 제작 담당자에게 남긴다. 진행할 편을 `EP`에 지정하고 승인된 해당 편 누계 크레딧 상한을 `CAP`에 설정한다. 볼륨·속도·모델은 제작 도구의 기본 설정을 따른다. 지금 새 구획의 예상 비용은 01편 2,528.40, 02편 3,218.32, 03편 1,949.71크레딧이며 대본을 고치면 다시 계산한다.
```bash
set -e
: "${EP:?EP에 확정 대본의 확장자 없는 파일명을 지정}"
: "${CAP:?CAP에 승인된 해당 편의 누계 크레딧 상한을 지정}"
OUT="$W/$EP/영상"
LEDGER="$W/$EP/음성기록.json"
MARK="강조_통합반_02회차_${EP}.json"
mkdir -p "$OUT"
python3 "$T/강조좌표.py" --검사 "$D/$EP.md" "$C/$MARK"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$LEDGER" "$D/$EP.md" --voice "$V" --한도 1 --상한 "$CAP"
# 첫 구획의 실지출과 누계 잔액을 대조한 뒤 다음 줄부터 실행한다.
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$LEDGER" "$D/$EP.md" --voice "$V" --상한 "$CAP"
python3 "$T/쉼옮기기.py" "$D/$EP.md" --파형 --voice "$V" --출력 "$W/$EP/제작파형.json"
# '조용한곳없음' 0과 쉼 구획 완성을 확인한 뒤 굽는다.
python3 "$T/강의영상.py" "$OUT" "$D/$EP.md" --breath --voice "$V" --audio-ledger "$LEDGER" --pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
STEM="통합반_02회차_${EP}"
python3 "$T/강조표시.py" "$OUT/$STEM.mp4" "$C/$MARK" "$W/$EP/${STEM}_강조.mp4"
```

완성 음성의 말머리, 장 넘김, 자막 일치와 강조 시점은 `영상.md`의 길 9~11을 따른다. 이 문서의 예행 시각은 제작 음성에서 다시 확인한다.
