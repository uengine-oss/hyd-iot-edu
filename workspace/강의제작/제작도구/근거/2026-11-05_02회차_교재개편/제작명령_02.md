# 통합반 2회차 02편 제작 명령

실행 대상은 23~43장이다. 본문 예행 32분 9.580초에는 기존 강사 음성 86.240초와 무료 한국어 예행 1,843.340초가 들어간다. 제작용 대본·덱·강조·쉼의 SHA-256은 `제작도구/구성/통합반/02회차/제작입력_02.json`에 있다. 27장 강사 음성을 재사용하고 20개 구획 13,312자를 구매할 예정이다. 글자당 약 0.49크레딧을 적용한 견적은 6,522.88크레딧이다.

후속 단원에서 공용 PPTX가 바뀌어도 같은 화면을 재현할 수 있게 제작입력 파일이 추가된 커밋에서 시작한다. 저장소 루트에서 다음 명령을 한 셸에서 차례로 실행한다. 지정 글꼴과 LibreOfficeDev, Poppler, FFmpeg, Python을 준비한다.

```bash
set -eu
M=workspace/강의제작/제작도구/구성/통합반/02회차/제작입력_02.json
REV="$(git log -1 --diff-filter=A --format=%H -- "$M")"
test -n "$REV"
PROD_DIR="$(mktemp -d)/hyd02-ep02"
git worktree add --detach "$PROD_DIR" "$REV"
cd "$PROD_DIR"
python3 - "$M" <<'CHECK'
import hashlib, json, sys
from pathlib import Path
m=json.loads(Path(sys.argv[1]).read_text(encoding="utf-8"))
for item, key in [(m["덱"],"경로"), (m["대본"],"경로"), (m["강조"],"설정")]+[(f,"제작쉼") for f in m["쉼"]["파일"]]+[(f,"경로") for f in m["예행의_근거"]]:
    path=Path(item[key])
    assert hashlib.sha256(path.read_bytes()).hexdigest()==item["SHA256"], path
CHECK
```

희소 체크아웃에서는 27장 재사용 음성키 `15ff91fab7a7d0a3`의 MP3·정렬 JSON이 실제 `$T/음성_저장/`에 있어야 견적과 구매가 일치한다. 기존 캐시를 복구한 뒤 대본·덱·강조 해시와 신규 구획 수를 대조한다. 글자당 약 0.49크레딧 예상치와 실제 유료 누계를 구별한다.

```bash
: "${CAP:?승인된 편별 누계 상한을 지정합니다}"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$LEDGER" "$D/$EP.md" --voice "$V" --한도 1 --상한 "$CAP"
# 첫 새 구획의 실제 사용량과 잔여 상한을 확인한 뒤 이어서 실행한다.
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$LEDGER" "$D/$EP.md" --voice "$V" --상한 "$CAP"
python3 "$T/쉼옮기기.py" "$D/$EP.md" --파형 --voice "$V" --출력 "$W/$EP/제작파형.json"
# 모든 구획의 쉼 저장과 조용한곳없음 0건을 확인한다.
python3 "$T/강의영상.py" "$OUT" "$D/$EP.md" --breath --voice "$V" --audio-ledger "$LEDGER" --pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
python3 "$T/검사/말머리_잘림.py" "$OUT/$STEM.mp4"
python3 "$T/검사/장넘김_싱크.py" "$OUT/$STEM.mp4" "$SIDE/${STEM}_시간표.md"
python3 "$K/자막대조.py" "$SIDE" "$D/$EP.md"
python3 "$T/강조표시.py" "$OUT/$STEM.mp4" "$MARK" "$W/$EP/${STEM}_강조.mp4" --확인 "$W/$EP/강조프레임"
ffprobe -v error -show_entries stream=codec_type,duration -of json "$W/$EP/${STEM}_강조.mp4"
```

V-12는 말머리 잘림 0, 기대 화면 전환 누락 0, 자막 어긋남 0, 화면·음성 길이 일치를 각각 확인한다. V-11은 강조프레임과 자막을 함께 보며 대상, 가림, 앞·뒤 표시 겹침을 확인한다.
