## 1. 구성 · 차례 판단

절 차례(연결 → 무엇이 들어 있나 → CREATE → MATCH · RETURN → WHERE → MERGE · SET → 관계 잇기 → SET → 지우기 → 설비 데이터 세기 → 한 단계 → 두 단계 경로 → 답 맞춰 보기)는 그대로 두는 것이 맞다. 까닭은 셋이다.

- 이론은 MATCH부터 가르쳤지만 실습이 CREATE부터 하는 것이 노베이스 학생에게 더 쉽다. 내가 만든 노드 둘만 있는 결과가 가장 작은 결과라서, 「만들었다 → 정말 들어갔나 찾아본다 → 일부만 받는다」로 까닭이 저절로 이어진다. 20개짜리 설비 데이터를 먼저 조회하면 첫 결과부터 낯선 이름이 쏟아진다.
- 지우기(10절)를 설비 데이터 조회 앞에 둔 것도 맞다. 우리가 만든 것이 다 지워진 뒤 20개를 다시 세어(11절) 「원래 데이터는 그대로」를 확인하고 넘어가므로, 뒤 절의 수(여섯 · 셋 · 다섯)가 흔들리지 않는다.
- 한 단계 → 두 단계 → 조건 · 집계 대조는 쉬운 것에서 어려운 것으로 쌓인다.

절 안의 설명 차례는 네 곳을 바꾸자고 제안한다(자세한 글은 지적 표).

1. 2절: 지금은 「포털 쪽 DB도 이름이 같아요 → 주소로 가립니다」(g0203)가 먼저 나오고 「포털의 지식 지도가 담긴 다른 DB가 있다」(g0204)가 뒤에 나온다. DB가 둘이라는 것과 왜 가려야 하는지를 먼저 말하고, 가리는 법(주소 끝 숫자)을 그다음에 한 번만 말하는 차례가 쉽다(가-1).
2. 4절: 첫 쿼리를 괄호 → 중괄호(속성) → 다시 앞으로 돌아가 레이블 → 더 앞의 변수 → 맨 끝 세미콜론 차례로 읽는다. 화면 글자의 왼쪽부터(레이블 → 속성 → 세미콜론) 읽는 차례가 이론 52장의 차례와도 같고 눈이 되돌아가지 않는다. 쓰지 않는 변수 `a` · `b`는 쿼리에서 빼는 쪽을 제안한다(가-2).
3. 8절: 셋째 줄(관계) → 넷째 줄(RETURN) → 다시 셋째 줄(관계 유형의 한글 · MERGE)로 되돌아간다. 셋째 줄 이야기를 끝낸 뒤 RETURN으로 가게 문장 하나를 옮긴다(나-8).
4. 12절: g1202가 세부(쌍점 앞이 비었다)부터 말하고 그 쿼리가 무엇을 찾는지를 뒤에 말한다. 무엇을 찾아 무엇을 돌려받는지를 먼저 말한다(가-3의 고칠 글에 함께 넣었다).

11절(레이블마다 묶어 세기)을 더 쉬운 `count` 하나(스물)로 바꾸고 묶어 세기를 14절에서 처음 푸는 안도 따져 봤다. 지금 차례를 두는 쪽이 낫다고 판단했다. 레이블이라는 쉬운 대상으로 「묶어서 묶음마다 센다」를 먼저 해 봐야 14절에서 경로 위의 집계를 한 번에 알아듣고, 레이블별 수(여섯 · 다섯 · 셋 · 하나)가 뒤 절의 「구성 요소는 여섯이었는데」를 받쳐 준다. 다만 「처음과 같은지 확인」이라는 목적만 말하고 왜 레이블마다 세는지는 말하지 않으므로 그 까닭 한 마디를 더한다(나-6).

## 4. 사용자에게 물어야 할 애매한 곳

1. 칸 2-1에서 쓰지 않는 변수 `a` · `b`를 빼도 되는가(가-2). 빼면 안내 문서 · 칸 원고 · 길뚫기 출력을 함께 고치고 다시 돌려야 한다. 칸 10-2의 `p` → `pt`(가-4)도 같다.
2. 실전반 2회차 05의 배정은 15분인데(실전반 이론 01편 16줄의 회차 구성 표) 이 영상은 계획 28.3분이다. 영상 V-1은 배정을 넘는 것을 허용하지만 거의 두 배라서, 그대로 공통으로 쓸지 사용자가 정해야 한다.
3. 실전반 이론은 구성 요소 → 센서 관계를 「계측 관계」로, 통합반 이론은 「감시된다」로 불렀다. 공통 영상은 「감시된다」로 간다(대본 제작 확인용 261줄이 「계측된다」를 쓰지 않을 말로 정했다). 가-3의 고칠 글대로 이론을 가리키지 않으면 실전반 학생도 알아듣지만, 두 반의 이름이 갈린 것 자체는 실전반 이론을 새 판으로 바꿀 때 풀 일이다.
4. g1308은 물음의 답인 품번을 소리 내 읽지 않고 「이 값이에요」로 짚기만 한다(대본 S-7의 식별자 읽기 기준을 따른 것으로 보인다). 통합반 이론 59장은 답 CC-2040을 읽었다. 답을 한 번 읽을지는 음성으로 들어 보고 정할 일이다.
5. g1106의 창고 비유(품목마다 세기)는 통합반 이론 03편 171줄의 변수 비유(「창고에서 파란 상자를 찾아서 그것의 무게를」)와 같은 「창고」 장면을 쓴다. 대본 S-3은 같은 비유 낱말을 다른 개념에 쓰지 말라고 하지만, 같은 창고에서 이어지는 장면이라 학생이 틀린 결론을 낼 자리는 아니라고 보고 지적하지 않았다. 다른 장면으로 바꾸기를 원하면 알려 주어야 한다.
6. 미검증 화면 동작(길뚫기에서 볼 것에 더한다): 표 보기로 둔 뒤 새로 돌린 노드 결과가 그림으로 뜨는지(나-3), 값만 받은 결과에 Graph 단추가 없는지(나-4), 결과 카드 머리에 쿼리 글자가 다 보이는지(나-3 · 나-7), 붙여 넣은 뒤에도 바로 아래 앞 결과 카드가 펼쳐진 채 보이는지(나-7의 g0705 · g1003).
