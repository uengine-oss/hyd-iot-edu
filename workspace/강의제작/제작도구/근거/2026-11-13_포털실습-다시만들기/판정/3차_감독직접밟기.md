# 3차 — 감독이 직접 밟은 길 (2026-11-16, DoD 29 · 34 · 35 · 36)

밟은 사람은 감독(메인 세션)이고, 작업자는 누르지 않았다. 실제 브라우저(Playwright, 1440×900)로 화면의 단추를 눌렀고, 단계마다 그림을 찍어 감독이 직접 열어 봤다. 그림은 git 밖 `작업/2026-11-16_포털-lite-참고/감독걷기/` · `감독걷기2/`에 있고, 스크립트는 세션 스크래치(`walk.py` · `walk2.py`)다. 스택은 재생 모드(키 길이 0 · 워커 `AI_MODE=replay`)다.
