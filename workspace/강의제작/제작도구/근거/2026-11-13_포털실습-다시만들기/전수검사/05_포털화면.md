## 5. 문제 없던 것

- `requestJ`(app.js:12-36): 시간 초과 · 연결 끊김 · 영문 기본 문구를 한국어 한 줄로 바꾸고, `requireList`로 응답 꼴이 틀리면 빈 목록 대신 실패로 보인다.
- 처리 건 단계 패널(instances.js:466-475): 누른 뒤 다시 읽기가 끝날 때까지 단추를 꺼서 두 번 제출을 막는다. 입력 중에는 다시 그리지 않아 한글 조합이 끊기지 않는다(105-110행).
- 담당자(inbox.js:15, 35): 담당자 행이 없으면 다른 사람으로 대신하지 않고 까닭을 보인다. 승인 · 제출 폼은 담당자가 없으면 단추를 끄고 `pickMe` 한 줄로 막는다.
- 지우기 · 기준으로 되돌리기는 대부분 `UI.confirm`(위험 단추 빨강, 기본 초점 취소): 에이전트 · 도구 연결 · 출발본 · 흐름 가져오기 · 질문 기록 · 개정 적재(hitl.js:733).
- 수업 경계(courseAccess.js): 막힌 단추 옆에 서버가 준 까닭 한 줄, 읽기 실패는 잠금이 아니라 다시 시도.
- 처리 과정(trace.js): 키 단위 부분 갱신으로 펼친 상자가 접히지 않는다. 걸린 시간은 「1분 60초」가 나오지 않게 반올림한다.
- 셸(shell.js): 화면 모듈이 없거나 그리다 실패하면 [다시 시도]가 있는 오류 블록, 없는 주소는 홈으로 옮기고 알린다.
- 지식 관리 3단계 진행줄(hitl.js:547-569): 등록만 한 문서에는 절 · 절차 · 검증 칸을 그리지 않는다(목록 A-3이 반영돼 있다).
- nginx.conf: 서비스 꺼짐 · 시간 초과 · 크기 초과를 서비스 이름이 든 한국어 JSON 한 줄로 돌려준다. 같은 출처 길만 열어 다른 웹 페이지의 쓰기를 막는다.
- 재생 모드 문구: 화면 코드에 「강사」 · 「녹화」가 재생 화면 문구로 나오는 곳은 없다(「강사에게 알리세요」는 화면 프로그램 오류 · 배율 불일치 안내에만 있다).
