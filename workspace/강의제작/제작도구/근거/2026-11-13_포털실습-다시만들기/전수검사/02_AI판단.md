## 3. 찾을 것 (a)~(f) 답

- (a) 지시문 · 스킬 글의 정답 힌트: 시드 스킬 네 개(seed.sql 135~224행)에는 정답을 미리 알려 주는 문장이 없다(절차 · 지는 안 설명 요구만). 정답 힌트는 도구 · 폼 · 프롬프트의 예시 값이다 — 지적 2.
- (b) 순위가 한 안만 이기도록 짜였는가: 엔진은 모든 후보에 같은 식을 계산하고 지는 안의 점수 · 제외 사유 · 손익을 남긴다(cards.evaluate 359~461행, whatif.evaluate). 한 안 고정의 증거는 없다. 다만 식이 쿨러 유온 기준 하나다 — 지적 13, 선례 항은 늘 0 — 지적 12.
- (c) 재생 모드: 화면 모양은 실제와 같다(같은 이벤트 · 같은 결과 검사). 지원하지 않는 행동(녹화 없는 자리 · 이어 하기 · 재평가 · 재작업 · 다른 설비)은 NotRecorded로 멈춘다(ai_replay.py 635~660행). 성공처럼 돌려주는 곳은 「녹화된 읽기 결과를 지금 처리 건의 결과로 내는 것」이다 — 지적 1.
- (d) 승인 전 쓰기: 에이전트의 쓰기는 판단 카드 등록(submit_decision · submit_purchase)뿐이다. 셸 도구는 막고(settings.BLOCKED_SHELL_TOOLS), 파일은 Landlock으로 작업 폴더만, 메일은 effects-mcp가 process 토큰으로만, enterprise-mcp 도구는 모두 읽기다. 틈은 지적 14 · 15(지금은 결함 아님).
- (e) 관문 상한 비켜 가기: 찾지 못했다. 강의 중계 키는 process만 쥐고(env_guard · course_access.permit이 CLI 환경의 다른 키를 비운다), 토큰은 점유 · 임대 · 서명 · 기한에 묶이고, 모델 이름이 다르면 보내지 않고, 동시 실행 1 · 실행 · 작업 · PC 상한을 같은 잠금 안에서 잰다. process 안의 다른 AI 호출 경로(LLM_RELAY_URL 사용처)는 관문 하나뿐이다(grep 확인). 상한이 잘못 차는 쪽은 지적 16.
- (f) 12번: 지적 3으로 확정. 화면은 compare.js 160행 「원천을 읽고 판단 단계만 돌립니다. 제출 · 명령은 하지 않습니다.」, ui.js 31행 「규칙 비교 · 모의 순위 / 실제 승인 · 실행 준비는 확인하지 않음」만 말하고, AI 모델을 부르지 않는다는 사실은 어디에도 없다.

## 4. 훑었지만 문제 없던 것

- 관문(course_model · course_ledger · worker_credentials): 토큰 서명 · 기한 · 점유 · 임대 확인, 요청 크기 · 출력 상한 선기록, 스트리밍 빈 답 판정, 끝난 점유의 장부 닫기(작업 행 기준).
- 수업 경계(course_policy): 단계 선언 서명 검사(깨지면 process가 뜨지 않음), PBL 기한 판정, AI 자리 판정, 경로 문지기, 수업 흐름 표시의 내부 호출 한정.
- 워커 격리: env_guard 비밀 제거, Landlock 실제 적용 시험(cli_sandbox.verify), 승인 스킬 읽기 전용 묶음, 작업 폴더 링크 · 특수 파일 거절, 비밀 가림(diagnostics.HiddenRepo), 점유 펜싱(expected_consumer) · 임대 갱신 · DB 끊김 한도, 고아 CLI 프로세스 그룹 정리.
- 도구 게이트(bridge.gate_servers · mcp_registry): 기준 서버 수정 · 삭제 거절, 학생 서버는 설정 해시가 같은 검사 도장의 읽기 도구만, 비밀 값 없는 서버 제외, 질문 창구의 허용 목록 이중 확인.
- 판단 엔진: 순위 식 AST 화이트리스트(ranking.py), hitPolicy 선언 대조, 원천 실패는 FactUnavailable(값 없음으로 바꾸지 않음), 승인 전 재평가(approval.assess — 규정 · 카드 내용 · 업무 입력 · 물리 출처 변화 · 예측 악화 · 권한), 가드레일, 결정 승인의 feasible · 권한 확인(decisions.approve), 제출 범위(decision_scope).
- ask.py: 근거 질의를 실제 도구 호출 기록과 정확히 대조, 근거 없는 답은 「답할 수 없음」.
- 결과 해석(outcome · task_deferral · hitl): 비표준 숫자 거절, 보류 · 사람 질문을 결과와 섞지 않음, 결과 파일 우선.
- effects-mcp: process 토큰 필수, 수업 도메인만, 멱등 키 지문.
- agent_authoring: 기본 행 보호, 고치기는 전 칸 필수, 실행 중 삭제 거절, 지울 때 열린 단계 기본 담당으로 되돌림.
