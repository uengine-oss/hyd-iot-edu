## 제작 명령


저장소 루트의 Bash에서 다음 변수를 설정한다. `W`는 작업용 절대 경로다.

```bash
set -euo pipefail
B=workspace/강의제작
K="$B/제작도구/검사"
T="$B/제작도구/기존제작/tools/video"
C="$B/제작도구/구성/통합반/06회차"
D="$B/산출물/통합반/이론/06회차"
S="$D/대본"
W="$PWD/작업/통합반_06회차_이론"
V=1PdAOcPlPTz12RwMyFVp
mkdir -p "$W"
sha256sum "$D/통합반_06일차.pptx"
python3 "$K/판본검사.py" 통합6
python3 "$K/덱측정.py" "$W/본문시간.json" 통합6
python3 "$T/강의영상.py" "$W/dry" "$S"/*.md --breath --dry
python3 "$T/음성견적.py" "$S"/*.md --voice "$V"
```

**그림과 파형 대조.** 제작입력 파일의 PPTX와 검증에 사용한 렌더를 맞춘다. 다른 환경이나 다른 글꼴로 새 그림을 만들면 해당 장의 강조 미리보기와 가림을 다시 확인한다. 장별 점검표의 생략 사유와 표시 수, 각 구획의 쉼 파일을 대조한다.

**이후 제작자가 쓸 명령.** 아래 명령은 해당 편의 온라인 검증과 음성 비용 승인이 끝난 뒤에만 실행한다. 아래 표에서 사전 검증이 끝난 편에만 이 명령을 적용한다. `승인상한`은 실제 승인받은 크레딧, `편`은 확정한 편 번호(01~03)다. 한 구획 구입 후 기록의 차감액을 확인하고 나머지를 산다. 구매와 굽기 사이에는 해당 편의 새 음성 파형을 검사한다.

```bash
: "${편:?확정 편 번호 01~03}" "${승인상한:?승인받은 크레딧 상한}"
scripts=("$S/${편}_"*.md)
s=${scripts[0]}
n=$(basename "$s" .md)
vname="통합반_06회차_$n"
out="$W/영상출력/$편/영상"
ledger="$W/${편}_음성기록.json"
mkdir -p "$out"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$ledger" "$s" --voice "$V" --한도 1 --상한 "$승인상한"
# 한 구획의 실제 차감액을 확인한 뒤 계속한다.
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$ledger" "$s" --voice "$V" --상한 "$승인상한"
python3 "$T/쉼옮기기.py" "$s" --파형 --voice "$V" --출력 "$W/${편}_구매뒤_쉼확인.json"
# 위 결과의 '조용한곳없음'과 '파형_음성없음'을 확인하고 시작한다.
python3 "$T/강의영상.py" "$out" "$s" --breath --voice "$V" --audio-ledger "$ledger" --pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
python3 "$T/강조표시.py" "$out/$vname.mp4" "$C/강조_$vname.json" "$out/${vname}_강조.mp4" --확인 "$W/${편}_강조확인"
```

오프라인 6회차는 온라인 세 편이 확정되면 같은 반의 실라버스 50분 이론 행과 첫 조각의 직접 대응(온라인 5·7·9·11·12·14 → 현장 5~10장)을 받아 진행한다. 독립 검토에서 확인한 학생의 판단 근거를 현장 질문·발표자 노트에 반영하고 각 단원을 닫는다.
