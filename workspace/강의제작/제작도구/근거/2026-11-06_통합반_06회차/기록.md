# 통합반 6회차 인계

**다시 시작할 곳은 온라인 01편 1~14장의 지정 글꼴 렌더와 강조 대조다.** 이 조각은 미확정이다. 음성 구매·MP4 제작·노션 게시를 제외한 사용자 위임에 따라 원고와 낭독을 실제로 고쳤다. 이번 판에서 닫은 단원은 0개다. 15장부터의 단원과 현장판 작업은 앞 조각이 닫힌 뒤에 진행한다.

## 받은 판과 변경 범위

출발점은 `workspace@62810ed5b56fae6738d87e9657d94c638ebedbaf`다. 6회차 이론 원본의 직전 변경은 `dd9760f3e3594ea5cf643806a347024c3ec43061`, 기존 영상 중단 인계는 `f369d63b067cc3cc8858c3373229387a24539482`다. 원래 작업 폴더가 없는 환경에서 이 브랜치를 받아 지침을 읽었다. `남은일.md`의 5·6회차 292구획은 두 반·두 회차를 합친 구판 기록이다. 이번 범위의 실제 PPTX는 78장이고 대본은 25·20·28음성 구획이다. 옛 장부에 78장이 적혀 있으나 최신 지침의 정지 프레임 대조와 이번 사용자 요청이 적용된다. 5회차의 마지막 센서 시각화 실습 결과를 받아 6회차를 열었다.

PPTX 15~78장의 화면과 노트는 원본과 각각 바이트가 같았다. 단원 독립 검토의 두 지적과 고친 위치는 [검토 목록](01편_1-14장_독립검토.json), 상태별 근거는 [덱 판정](01편_1-14장_덱판정.json)과 [대본 판정](01편_1-14장_대본판정.json)에 있다.

고친 뒤 덱과 대본의 규칙 판정은 각각 통과 14, 불통과 0, 해당 없음 4, 미확인 6이다. 장부에 이번 기준으로 닫은 장을 추가하지 않았다.

각 행의 본문 추정에는 표지·간지·실습 소개·고정 마무리·대기 시간을 넣지 않았다. 새 강사 음성이 필요한 13구획은 7,093자이다. 기존 음성은 모델·속도·강사·원문이 같은 MP3와 글자 정렬 JSON 쌍으로 확인했다. 현재 판에서 일치하는 60구획은 글자 정렬 불일치 0, 파형상 조용한 지점을 찾지 못한 곳 0이었다. 1~14장은 무료 한국어 시험 낭독을 따로 생성했고 최종 발화를 기준으로 14/14구획의 문장 경계 186곳에 쉼을 저장했다. 새 강사 원음의 발음·파형과 강조가 뜨고 사라지는 실제 재생 시각은 구매 이후에 확인한다.

01편에는 현 단계의 표시 45개가 있고 그중 첫 조각 14개가 기존 좌표 후보이다. 이 조각에서 좌표를 새로 찾을 표시 16개는 별도 계획에 있다. 세 편 모두 대본 앵커·모양 검사는 문제 0건이다. 대체 글꼴로 시험 렌더한 1~15장에서는 한글이 빠졌다. 첫 조각은 기존 좌표 14개와 새 후보 16개를 합친 정지 미리보기에서 한글 위치·가림을 확인해야 한다. 11장은 한 화면을 짚는 시간이 추정 129.6초라 다섯 절차와 보류 조건을 순서대로 따라갈 수 있는지 살핀다. 렌더 이외에 Docker 실행 파일이 없어 현행 그래프 조회도 남았다. 14장의 역사적 식별자는 사실표 5.2.4의 보존 기록과 대조했다.

세 편의 정확한 파일·해시·첫 문장·끝 문장·재사용 음원 수, 첫 14장의 낭독 경계·쉼 파일·시험 음성 길이는 [편별 입력 기록](편별입력_미확정.json)에 있다. 기존 좌표와 추가 계획은 [강조 검토·실행 명령](01편_1-14장_강조검토.md)에 있다.

## 재개와 제작 명령

저장소 루트의 Bash에서 다음 변수를 설정한다. `W`는 작업용 절대 경로다.

```bash
set -euo pipefail
B=workspace/강의제작
K="$B/제작도구/검사"
T="$B/제작도구/기존제작/tools/video"
C="$B/제작도구/구성/통합반/06회차"
D="$B/산출물/통합반/이론/06회차"
S="$D/대본"
W="$PWD/작업/통합반_06회차_이론"
V=1PdAOcPlPTz12RwMyFVp
mkdir -p "$W"
sha256sum "$D/통합반_06일차.pptx"
python3 "$K/판본검사.py" 통합6
python3 "$K/덱측정.py" "$W/본문시간.json" 통합6
python3 "$T/강의영상.py" "$W/dry" "$S"/*.md --breath --dry
python3 "$T/음성견적.py" "$S"/*.md --voice "$V"
```

**첫 조각 재개.** 이 판의 PPTX를 지정 환경에서 PDF로 내보낸다. 사용자 PC에서 내보낸 경우 같은 PPTX의 SHA-256과 PDF를 함께 받는다. 클라우드 지정 환경이 준비된 경우 다음 명령을 쓴다. 1~14장과 경계 15장을 먼저 열고, [강조 검토](01편_1-14장_강조검토.md)의 추가 계획을 실행해 글자 가림을 확인한다. 단원별로 독립 판정과 지적 수정을 끝내고 원격 반영을 확인한다. 15~25장부터 같은 절차를 이어가고 1~78장의 장별점검표와 편별 해시를 확정한다.

```bash
PATH=/usr/local/lo268/bin:$PATH bash "$K/렌더1.sh" "$D/통합반_06일차.pptx" "$W/공식렌더"
python3 "$K/낱말줄찾기.py" "$W/공식렌더"
export PDF="$W/공식렌더/통합반_06일차.pdf" PNG="$W/공식렌더" OUT="$W/강조재측정"
python3 "$T/쉼옮기기.py" "$S/01_이론_재사용가능한업무지침.md" --장 1-14 --파형 --voice "$V" --출력 "$W/01_쉼확인.json"
```

**이후 제작자가 쓸 명령.** 아래 명령은 해당 편의 온라인 검증과 음성 비용 승인이 끝난 뒤에만 실행한다. 이 체크포인트에서는 세 편 모두 제작 대기다. `승인상한`은 실제 승인받은 크레딧, `편`은 확정한 편 번호(01~03)다. 한 구획 구입 후 기록의 차감액을 확인하고 나머지를 산다. 구매와 굽기 사이에는 해당 편의 새 음성 파형을 검사한다.

```bash
: "${편:?확정 편 번호 01~03}" "${승인상한:?승인받은 크레딧 상한}"
scripts=("$S/${편}_"*.md)
s=${scripts[0]}
n=$(basename "$s" .md)
vname="통합반_06회차_$n"
out="$W/영상출력/$편/영상"
ledger="$W/${편}_음성기록.json"
mkdir -p "$out"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$ledger" "$s" --voice "$V" --한도 1 --상한 "$승인상한"
# 한 구획의 실제 차감액을 확인한 뒤 계속한다.
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$ledger" "$s" --voice "$V" --상한 "$승인상한"
python3 "$T/쉼옮기기.py" "$s" --파형 --voice "$V" --출력 "$W/${편}_구매뒤_쉼확인.json"
# 위 결과의 '조용한곳없음'과 '파형_음성없음'을 확인하고 시작한다.
python3 "$T/강의영상.py" "$out" "$s" --breath --voice "$V" --audio-ledger "$ledger" --pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
python3 "$T/강조표시.py" "$out/$vname.mp4" "$C/강조_$vname.json" "$out/${vname}_강조.mp4" --확인 "$W/${편}_강조확인"
```

오프라인 6회차는 온라인 세 편이 확정되면 같은 반의 실라버스 50분 이론 행과 첫 조각의 직접 대응(온라인 5·7·9·11·12·14 → 현장 5~10장)을 받아 진행한다. 독립 검토에서 확인한 학생의 판단 근거를 현장 질문·발표자 노트에 반영하고 각 단원을 닫는다.
