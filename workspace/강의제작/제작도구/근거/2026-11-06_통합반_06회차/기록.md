원고의 시작 기준은 workspace `62810ed5`, 과거 마지막 6회차 이론 변경은 `dd9760f3`, 중단된 영상 인계는 `f369d63b`다. 첫 단원의 초기 수정본은 `45b414d1`에 보존했다. 맑은 고딕을 포함한 실제 렌더 검증에서 찾은 이슈는 장별 검토 기록에 반영했다. 최종 렌더에 쓴 LibreOffice 세부 버전과 코드 글꼴은 해당 렌더 기록에서 확인한다.

## 제작 명령


저장소 루트의 Bash에서 다음 변수를 설정한다. `W`는 작업용 절대 경로다.

```bash
set -euo pipefail
B=workspace/강의제작
K="$B/제작도구/검사"
T="$B/제작도구/기존제작/tools/video"
C="$B/제작도구/구성/통합반/06회차"
D="$B/산출물/통합반/이론/06회차"
S="$D/대본"
W="$PWD/작업/통합반_06회차_이론"
V=1PdAOcPlPTz12RwMyFVp
mkdir -p "$W"
sha256sum "$D/통합반_06일차.pptx"
python3 "$K/판본검사.py" 통합6
python3 "$K/덱측정.py" "$W/본문시간.json" 통합6
python3 "$T/강의영상.py" "$W/dry" "$S"/*.md --breath --dry
python3 "$T/음성견적.py" "$S"/*.md --voice "$V"
```

**그림과 파형 대조.** 제작입력 파일의 PPTX와 검증에 사용한 렌더를 맞춘다. 다른 환경이나 다른 글꼴로 새 그림을 만들면 해당 장의 강조 미리보기와 가림을 다시 확인한다. 장별 점검표의 생략 사유와 표시 수, 각 구획의 쉼 파일을 대조한다.

**렌더 환경.** 새 리눅스 제작 PC의 렌더러는 LibreOffice 26.8.1.1이며 본문에는 맑은 고딕, 강조 글씨에는 맑은 고딕 Bold를 사용한다. `CLAUDE.md` 7절의 렌더 환경을 설치하고 아래 명령으로 실제 경로를 확인한다. Windows에서는 같은 문서 6절의 PATH 설정을 사용한다.

```bash
export PATH="/usr/local/lo268/bin:$PATH"
soffice --version | grep -F '26.8.1.1'
command -v pdftoppm ffmpeg ffprobe
fc-match -f '%{family} %{style}\n' 'Malgun Gothic:style=Bold' | grep -Ei 'Malgun Gothic.*Bold'
export EMPH_FONT="$(fc-match -f '%{file}' 'Malgun Gothic:style=Bold')"
test -r "$EMPH_FONT"
```

**이후 제작자가 쓸 명령.** 아래 명령은 해당 편의 온라인 검증과 음성 비용 승인이 끝난 뒤에만 실행한다. 위 변수를 설정한 같은 Bash에서 실행한다. 예를 들어 02편은 `EPISODE=02`로 설정하고, `CREDIT_CAP`에 이 편의 실제 승인 누계 상한(정수)을 넣는다. 한 구획 구입 후 기록의 차감액을 확인하고 나머지를 산다. 구매와 굽기 사이에는 해당 편의 새 음성 파형을 검사한다.

```bash
: "${EPISODE:?확정 편 번호 01~03}" "${CREDIT_CAP:?승인받은 크레딧 상한}"
scripts=("$S/${EPISODE}_"*.md)
s=${scripts[0]}
n=$(basename "$s" .md)
vname="통합반_06회차_$n"
out="$W/영상출력/${EPISODE}/영상"
ledger="$W/${EPISODE}_음성기록.json"
python3 - "$C/${EPISODE}편_제작입력.json" "$s" <<'PYINPUT'
import hashlib, json, sys
from pathlib import Path

manifest = Path(sys.argv[1])
if not manifest.is_file():
    sys.exit(f"{manifest.name}이 없습니다. 해당 편의 사전 검증을 확인하세요.")
spec = json.loads(manifest.read_text(encoding="utf-8"))
if spec.get("상태") != "음성 생성 전 제작 입력 확정":
    sys.exit(f"{manifest.name} 제작 보류. 기록.md의 해당 편을 확인하세요.")
if Path(spec["대본"]["파일"]).resolve() != Path(sys.argv[2]).resolve():
    sys.exit("선택한 대본이 확정 파일과 다릅니다.")
deck = spec.get("현재_제작용_PPTX", spec["확정당시_PPTX"])
for item in [deck, spec["대본"], spec["강조"], *(row["쉼파일"] for row in spec["구획"])]:
    file = Path(item["파일"])
    if not file.is_file() or hashlib.sha256(file.read_bytes()).hexdigest() != item["SHA256"]:
        sys.exit(f"확정 파일 확인 필요: {file}")
cache = Path("workspace/강의제작/제작도구/기존제작/tools/video/음성_저장")
for row in spec["구획"]:
    if row["구매상태"] == "기존 강사 음성 재사용":
        for ext in (".mp3", ".json"):
            if not (cache / (row["음성캐시키"] + ext)).is_file():
                sys.exit(f'{row["장"][0]}장 기존 강사 음원 또는 문자 정렬 파일을 먼저 받아 주세요.')
print(f'{spec["편"]:02}편 대본·덱·강조·{len(spec["구획"])}개 쉼·기존 음원 확인')
PYINPUT
mkdir -p "$out"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$ledger" "$s" --voice "$V" --한도 1 --상한 "$CREDIT_CAP"
```

첫 구획 생성 기록에서 실제 차감액과 남은 상한을 확인한 후 다음 블록을 별도로 실행한다.

```bash
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$ledger" "$s" --voice "$V" --상한 "$CREDIT_CAP"
python3 "$T/쉼옮기기.py" "$s" --파형 --voice "$V" --출력 "$W/${EPISODE}_구매뒤_쉼확인.json"
# 새 강사 음원과 글자 정렬이 모두 도착하고 모든 쉼 위치를 확인한 뒤 굽는다.
python3 - "$W/${EPISODE}_구매뒤_쉼확인.json" <<'PYWAVE'
import json, sys
from pathlib import Path
d = json.loads(Path(sys.argv[1]).read_text(encoding="utf-8"))
if d["조용한곳없음"] or d["요약"].get("파형_음성없음", 0) or d["구획"]:
    sys.exit("음원·정렬·쉼 확인이 남았습니다. 해당 장을 확인하세요.")
PYWAVE
python3 "$T/강의영상.py" "$out" "$s" --breath --voice "$V" --audio-ledger "$ledger" --pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
python3 "$T/강조표시.py" "$out/$vname.mp4" "$C/강조_$vname.json" "$out/${vname}_강조.mp4" --확인 "$W/${EPISODE}_강조확인"
```

**명령 검증 결과.** 위 Bash 블록의 구문을 검사하고, 구매 전 파일 검사까지만 실제로 실행했다. 01편 25구획과 02편 20구획은 덱·대본·강조·쉼 파일 및 기존 음원 확인에 성공했다. 같은 검사에서 03편은 제작 보류 메시지와 종료 코드 1을 돌려주었다. 구매 뒤 단계는 각 편의 강사 음원이 준비되면 실행한다.

현장 덱은 오프라인 실라버스 46행의 50분 이론을 기준으로 한다. 대응 표에서 재사용하는 온라인 본문·복습·퀴즈만 원본으로 삼는다. 62~67장·70~71장에 기대는 마지막 노트의 실습 연결은 학생 배포 자료에서 확인할 수 있는 활동을 쓰고, 미충족 목표는 작업 기록에 남긴다.
