# 03편 54~61장 화면·발화·강조 대조

55장에서는 워커의 파일 접근 지시와 결과 경로를 짚는다. 56장은 같은 비밀값이 없을 때 포털 검사는 누락을 알리고 워커 실행은 해당 서버를 제외하는 차이를 읽는다. 별표 여덟 개는 화면에 표시할 인증 헤더를 가린 값이다. 57장은 모델 토큰과 작업 폴더의 서버 설정을 구분한다. 58장의 두 비교 결과는 128,466자와 128,468자다. 글자 수, 다시 읽을 계획, 실제로 이어진 호출과 판단 근거를 서로 다른 자리에서 찾게 했다. 59~61장에서는 정상 조회의 0행, 미확인 값, 호출 시각과 관측 시각, 로컬 프로세스와 HTTP 서버의 접근 권한을 구분한다.

이 범위에 있던 표시 22개를 현재 화면과 발화에 대조해 30개를 저장했다. 범위 밖 설정은 직전 커밋과 객체별로 일치한다. 같은 PDF와 그 PDF에서 글자만 지운 판을 Poppler 150 dpi로 렌더하고 1920×1080으로 줄였다. 두 그림 RGB의 채널 차이가 4/255를 넘는 글자 픽셀과 실제 순번으로 그린 선의 불투명도 4/255 초과 픽셀을 대조했다. 글자와 겹친 선은 0개다.
