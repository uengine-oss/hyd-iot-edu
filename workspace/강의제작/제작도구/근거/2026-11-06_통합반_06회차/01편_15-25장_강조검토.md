# 01편 15~25장 강조와 낭독 대조

15~25장의 기존 31개 표시와 26장 시작 화면을 실제 PDF·PNG에서 대조했다. 16·20·25장처럼 구획이나 카드 전체를 다시 그리던 표시를 줄이고, 경보 발생·승인 시각, 설비 조건, 지침·조치의 두 식별자, 사건별 관측값처럼 학생이 읽어야 하는 부분에 맞췄다. 19장에서는 가운데 칸의 지침 이름을 먼저 짚고 오른쪽 칸의 조치 식별자로 넘어간다. 23장에서는 회의록 두 행 전체를 묶지 않고 반복 규칙과 이번 한 번의 목적을 각각 짚는다. 24장에서는 서버 열 전체 대신 실제로 다른 두 서버 이름을 짚는다. 15장 간지는 장별점검표에 무표시 사유를 적었다.

확인한 PPTX SHA-256은 `8d5e7c684e49111cbca3383660daa7638b70937a7a3ca0a828785bf9be43c856`, PDF SHA-256은 `8f4f62329a475061db2f3dcbbc088c60985bcbd720a5045ea3e6bc97c0bc9f8d`이다. 지정 맑은 고딕을 등록한 LibreOfficeDev 26.8.0.0.alpha0와 150dpi Poppler 렌더를 사용했다. 1~14장의 모든 PNG는 직전 판과 RGB 픽셀이 일치하고 첫 30개 표시도 그대로다. 이 단원의 표시 24개는 실제 영상 그리기 순번 31~54로 마스크를 만들었고 불투명 선과 실제 글자 픽셀의 교차가 모두 0이다. 마스크·글자 분류 기준은 [첫 단원 검토](01편_1-14장_강조검토.md)와 같다.

아래 시각은 장 시작 기준이다. 17·22장은 기존 강사 음원의 글자 정렬, 나머지는 검사용 한국어 음원의 낱말 이벤트를 사용하고 지정 문장 쉼을 적용했다. 같은 문장에서 두 값 또는 두 식별자를 대조하는 20·21·24장은 표시 둘이 함께 보일 수 있다. 세 개 이상 겹치는 발화 구간은 없다. 실제 생산 음성 시각은 영상 도구가 해당 음원의 글자 정렬로 다시 맞춘다.
