# 첫 단원 강조 검토 · 시각 검증 대기

`산출물/통합반/이론/06회차/통합반_06일차.pptx` 1~14장의 XML 텍스트 런과 도형 위치를 01편 대본에 대조했다. 아래의 유지 표시는 이전 설정의 좌표를 인계한 후보이다. 모양의 실제 가장자리, 한글 줄바꿈, 마스크와 본문 가림, 낭독과 나타남·사라짐 시각은 정본 렌더에서 확인해야 한다. 현 환경에서 `fc-match 'Malgun Gothic'`는 DejaVu Sans를 반환했다. 공식 렌더와 마스크 합성은 대기 중이다.

PPTX 텍스트 상자의 위치도 확인했다. 1920×1080 환산 시 6장 지침 도형 글 상자는 왼쪽 754, 위 294이며 시각 문구는 왼쪽 72, 위 147이다. 13장 두 응답 본문은 왼쪽 130/1061, 위 541에서 시작한다. 14장의 출력 텍스트 상자는 왼쪽 115, 위 357이며 오른쪽 한글 설명은 왼쪽 1202의 별도 상자에 있다. 이 값은 PPTX 도형 원점으로, 강조 픽셀 좌표와 구별한다.

## 범위와 재실행

기준 커밋 `62810ed5b56fae6738d87e9657d94c638ebedbaf`의 01편 설정과 현재 파일을 비교했다. 첫 단원은 기존 39개 중 14개의 앵커를 갱신하여 유지하고, 추가 후보 16개는 좌표 없는 별도 계획으로 두었다. 15장 이후 31개 표시의 첫 객체부터 파일 끝까지 11,985바이트의 SHA-256은 두 버전 모두 `a065e2b405ca8de9bbeb087af070d29dbd940c947a6f6b47c38060a88d316b32`이다. `강조좌표.py --검사`에서 01편 45개, 02편 57개, 03편 59개의 문장·낱말·끝문장 및 모양 오류가 각각 0이었다.

공식 PDF와 장 PNG가 있는 환경에서 저장소 루트를 기준으로 아래를 실행한다. `PDF`, `PNG`, `OUT`은 담당자가 실제 파일·디렉터리 경로로 지정한다. 6장의 메시지 띠와 8장의 제목 중복을 함께 처리하도록 6장에만 검색 높이 제한을 푼다. 두 결과는 **추가 후보만** 담는다. 8장 검색 결과가 왼쪽 트리인지, 14장 한글 뜻과 식별자가 각각 올바른 열인지 먼저 확인한다. 그런 다음 합격한 표시만 기존 설정에 해당 장의 낭독 순서대로 병합하고, 합친 설정으로 미리보기·가림·문장 끝과 실제 낭독 대조를 마친다.

```bash
set -eu
: "${PDF:?공식 PDF 경로}" "${PNG:?공식 장 PNG 폴더}" "${OUT:?검토 출력 폴더}"
b=workspace/강의제작
t="$b/제작도구/기존제작/tools/video"
s="$b/산출물/통합반/이론/06회차/대본"
plan="$b/제작도구/근거/2026-11-06_통합반_06회차/01편_1-14장_추가강조계획.json"
mkdir -p "$OUT"
python3 - "$plan" "$OUT" <<'PY'
import json, sys
from pathlib import Path
marks = json.loads(Path(sys.argv[1]).read_text())['표시']
for name, header in [('header', True), ('body', False)]:
    selected = [m for m in marks if (m['장'] == 6) == header]
    (Path(sys.argv[2]) / (name + '.json')).write_text(json.dumps({'표시': selected}, ensure_ascii=False))
PY
for kind in body header; do
  top=104
  if [ "$kind" = header ]; then top=0; fi
  python3 "$t/강조좌표.py" "$PDF" "$s" "$OUT/$kind.json" --위 "$top" --출력 "$OUT/$kind-좌표.json"
  python3 "$t/강조미리보기.py" "$PNG" "$OUT/$kind-좌표.json" "$OUT/$kind-대조"
done
for f in "$s"/[0-9][0-9]_*.md; do
  name=$(basename "$f" .md)
  python3 "$t/강조좌표.py" --검사 "$f" "$b/제작도구/구성/통합반/06회차/강조_통합반_06회차_$name.json"
done
```

추가 계획의 문장도 PDF 없이 재검사할 수 있다. 위와 같은 `t`, `s`, `plan` 값을 사용한다. 이 검사는 좌표를 생성하지 않는다.

```bash
PYTHONDONTWRITEBYTECODE=1 python3 - "$t" "$s" "$plan" <<'PY'
import json, sys
from pathlib import Path
sys.path.insert(0, sys.argv[1])
from 강조좌표 import blocks
slides = blocks(sys.argv[2])
marks = json.loads(Path(sys.argv[3]).read_text())['표시']
for m in marks:
    sentences = slides[m['장']][1]
    start, word, end = m['문장'], m['낱말'], m['끝문장']
    assert sentences.count(start) == sentences.count(end) == 1, m
    assert start.count(word) == 1 and sentences.index(start) < sentences.index(end), m
print(f'추가 계획 {len(marks)}개 · 대본 앵커 문제 0')
PY
```
