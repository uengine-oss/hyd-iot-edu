# 02편 26~32장 강조·낭독 대조

27장의 `hyd-dmn diagnose(asset, pattern, alert_id)`는 서버, 도구, 입력 항목이 한 줄에 붙어 있다. PDF 글자의 위치를 따로 잡아 발화 순서대로 밑줄을 바꿨다. 28장은 관리할 조합 9개와 규약을 구현할 주체 6개의 서로 다른 단위를 짚는다. 중앙 규약 띠는 대본이 색과 위치를 직접 알려 준다.

29장은 둘째 행의 `tools/call`과 `diagnose`를 비교해 요청 종류와 도구 이름을 구분한다. 30장은 네모 구획이나 가로줄 전체에 색을 덮던 표시를 덜고 모델·클라이언트 라벨과 실제 진단 요청이 지나는 가운데 서버만 짚는다. 31장은 에이전트의 호스트·설정 파일과 포털 시험 때의 별도 백엔드 연결, 도구의 입력 스키마를 찾는다. 32장 정비·구매 조회 서버는 각자의 행에서 4개·3개를 비교한다. 상단 세 서버와 개별 표 행 전체를 겹쳐 칠하던 표시는 생략했다. 26장 단원 간지의 무표시 사유는 장별점검표에 적었다.

이 단원에서 확인한 PPTX SHA-256은 `9af31e10700ff835981fe2de7419800c343be90abe83d40950b0ad5ed79af4b7`, PDF는 `c4d99969043480d8ff83ed52cd8d3fc12c5ee749008b9e2a8a6a8af75203a734`, 02편 대본은 `5519b19611d802927adf07f810b1e9685673cec9484df47e8cd450e110137ff8`이다. 25장→26장과 32장→33장 전환 화면을 확인했다. 150dpi PNG를 영상 프레임과 같은 1920×1080으로 맞췄다. 21개 밑줄을 실제 그리기 순번으로 만들고 텍스트 제거 전후의 픽셀 차이와 비교했다. 글자 픽셀과 선의 교차는 모두 0이다.
