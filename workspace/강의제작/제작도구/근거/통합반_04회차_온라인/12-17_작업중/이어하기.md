# 통합반 온라인 4회차 12~17장 검증과 재개

이 조각은 진행 중이다. 발표자가 소리 내어 안내할 곳, 원문의 조건, 화면 세부와 노트를 수정했다. 지정 글꼴 렌더와 라이브 그래프 대조가 남아 있어 이 패치는 확정 산출물 폴더와 분리했다. 12~17장을 닫기 전에 18장으로 넘어가지 않는다.

## 수정본을 재현한다

workspace 브랜치의 깨끗한 작업트리, 저장소 루트의 Bash에서 실행한다. 62810ed5 이후 같은 파일을 다른 사람이 바꿨으면 먼저 인계 기록과 차이를 확인한다. 패치에는 1편 대본, 온라인 덱 원고·PPTX, 구성 파일 2개, 쉼 파일 6개가 들어 있다. 편집본과 패치를 재적용한 11파일의 Git 블롭이 모두 일치했다.

```bash
set -eu
W=workspace/강의제작
K="$W/제작도구/검사"
T="$W/제작도구/기존제작/tools/video"
C="$W/제작도구/구성/통합반/04회차"
D="$W/산출물/통합반/이론/04회차"
S="$D/대본"
E="$W/제작도구/근거/통합반_04회차_온라인/12-17_작업중"
Q="$PWD/작업/통합04검증/12-17"
P1="$S/01_이론_문서에서검증된지식으로.md"
P2="$S/02_이론_온톨로지에서판단근거까지.md"
F="$D/통합반_04일차.pptx"
V=1PdAOcPlPTz12RwMyFVp
mkdir -p "$Q"
git apply --check "$E/12-17.patch"
git apply "$E/12-17.patch"
sha256sum "$F" "$P1" "$P2"
python3 "$K/판본검사.py" 통합4
python3 "$K/덱측정.py" "$Q/측정.json" 통합4
python3 "$T/강의영상.py" "$Q/무료" "$P1" "$P2" --breath --dry
python3 "$T/음성견적.py" "$P1" "$P2" --voice "$V"
```

## 화면과 식별자를 확인한다

맑은 고딕이 설치된 수업 PC 또는 `CLAUDE.md` 7절의 동등한 렌더 환경에서 첫 명령을 실행한다. 해당 PPTX에서 수업 PC가 직접 출력한 PDF를 받았으면 같은 판인지 확인한 뒤 `$Q/렌더/통합반_04일차.pdf`에 두고 73장의 PNG를 `pdftoppm -r 150 -png "$Q/렌더/통합반_04일차.pdf" "$Q/렌더/s"`로 만들어 이어간다. 실제 발표 순서 11~18장을 열어 14장 표식 두 곳, 15장 인용과 작업 이름, 17장의 감점 근거 마지막 줄을 확인한다. PPTX 내부 slide 파일 번호는 실제 장 번호와 다를 수 있다.

```bash
bash "$K/렌더1.sh" "$F" "$Q/렌더"
python3 "$K/낱말줄찾기.py" "$Q/렌더"
python3 "$W/제작도구/기존제작/tools/deck/글겹침.py" "$Q/렌더/통합반_04일차.pdf"
python3 "$T/강조좌표.py" "$Q/렌더/통합반_04일차.pdf" "$S" "$E/강조계획.json" --출력 "$Q/단원강조.json"
python3 "$T/강조미리보기.py" "$Q/렌더" "$Q/단원강조.json" "$Q/강조" --장 12,13,15,17
```

13장에서는 원격 자동 모드의 전제와 모드 확인 행동, 24시간 한도, 15분 재관측, 승인 역할을 각각 가리킨다. 17장은 두 작업·비교 기호·인용의 ‘넘으면’·‘20만 원을 감점’ 네 곳에서만 표시한다. 15장은 두 출력값을 한 상자로 함께 가리킨다. 14·16장의 생략 사유는 `무표시.json`에 있다. 미리보기에서 표식이 가리키는 글·지워지는 문장·이웃 행을 확인하고, 고칠 곳이 있으면 해당 계획만 고쳐 다시 계산한다.

수업 문서가 적재된 Neo4j와 시스템 코드가 있는 수업 PC에서 다음을 실행한다. 이 세션에서는 HM-8.5~8.8과 SOP-COOL-11·12 및 `rule:hm-8-8-fan-life-penalty`의 출처·값을 매뉴얼과 코드로 대조했다. 식별자의 실제 적재 여부가 남았다.

```bash
python3 "$K/식별자대조.py" "$W/제작도구/온라인/decks/integrated/day04/통합반_04일차.md" "$P1" --출력 "$Q/식별자.json"
```

지정 렌더에서 위치를 확인한 뒤에만 새 좌표를 1편 설정에 합친다. 먼저 작업 폴더에 만들고 검사를 통과한 파일을 반영한다.

```bash
A="강조_통합반_04회차_$(basename "$P1" .md).json"
B="강조_통합반_04회차_$(basename "$P2" .md).json"
python3 - "$C/$A" "$Q/단원강조.json" "$Q/$A" <<'PY'
from pathlib import Path
import json, sys
old, unit, dest = map(Path, sys.argv[1:])
cfg = json.loads(old.read_text(encoding="utf-8"))
marks = json.loads(unit.read_text(encoding="utf-8"))["표시"]
assert marks and all(12 <= x["장"] <= 17 for x in marks)
cfg["표시"] = sorted([x for x in cfg["표시"] if not 12 <= x["장"] <= 17] + marks,
                   key=lambda x: x["장"])
dest.write_text(json.dumps(cfg, ensure_ascii=False, indent=1) + "\n", encoding="utf-8")
PY
python3 "$T/강조좌표.py" --검사 "$P1" "$Q/$A"
python3 "$T/강조좌표.py" --검사 "$P2" "$C/$B"
cp "$Q/$A" "$C/$A"
python3 "$T/쉼옮기기.py" "$P1" --장 12-17 --출력 "$Q/쉼재확인.json" --파형 --voice "$V"
python3 "$K/장별점검_생성.py" 통합4 --어림 --장 12-17 --까닭 "$E/무표시.json" --출력 "$C/장별점검.md"
```

원고·대본의 장확정 장부와 세 판정표에 실제 검사 근거를 남기고 커밋한다. 키 검사 후 push, 원격 SHA 확인, 완료 범위와 다음 시작점 기록까지 마치면 18장에서 재개한다. 최종 편별 제작 명령은 상위 인계 기록에 있다.
