## 수업 그래프 확인

문서가 적재된 강의 PC에서 다음 읽기 검사를 실행한다. 이 검사는 이름만 확인한다. 누락된 이름이 있으면 출력의 파일·행과 적재된 판본을 먼저 대조한다. 39~42장의 학생 활동 대응은 별도로 확인한다.

```bash
W=workspace/강의제작
mkdir -p 작업/통합04검증
python3 "$W/제작도구/검사/식별자대조.py" \
  "$W/제작도구/온라인/decks/integrated/day04/통합반_04일차.md" \
  "$W/산출물/통합반/이론/04회차/대본/"*.md \
  --출력 작업/통합04검증/식별자_강의PC.json
```

이름 점검이 끝나면 같은 수업 DB에서 아래 읽기 질의로 세 작업의 실제 단계를 확인한다. 각 작업에 대응하는 문서와 절·단계의 인용을 실습 원문과 대조한다. 핀 세척은 8.7절의 준비 1단계와 세척 후 냉각 효율 기준, 벨트 교체는 8.2절의 30분 시운전, 팬 점검은 8.1절의 진동 확인이다. 빈 행이나 다른 절에 도달한 경우를 점검 기록에 남긴다.

```cypher
UNWIND ['SOP-COOL-14', 'SOP-FAN-12', 'SOP-FAN-11'] AS requested
OPTIONAL MATCH (work:Skill {sopId: requested})-[:HAS_STEP]->(step:Step)
OPTIONAL MATCH (step)-[:REFERS_TO]->(section:ManualSection)
OPTIONAL MATCH (section)-[:PART_OF]->(doc:KnowledgeSource)
RETURN requested, step.order, step.text, section.ref, doc.id
ORDER BY requested, step.order
```

## 편별 제작 명령

저장소 루트의 Bash에서 한 편씩 진행한다. `PART=01` 또는 `PART=02`로 고른다. 무료 점검은 보류 중인 편에도 실행할 수 있다. 확정 당시의 체크아웃을 쓰거나, 이후 덱에서 해당 편 화면이 같다는 대조를 마친 뒤 갱신한 설정을 쓴다.

```bash
set -eu
PART=${PART:-01}
W=workspace/강의제작
T="$W/제작도구/기존제작/tools/video"
K="$W/제작도구/검사"
C="$W/제작도구/구성/통합반/04회차"
J="$C/${PART}편_제작입력.json"
P=$(python3 -c 'import json,sys; print(json.load(open(sys.argv[1]))["대본"]["파일"])' "$J")
V=$(python3 -c 'import json,sys; print(json.load(open(sys.argv[1]))["설정"]["voice"])' "$J")
NAME=$(basename "$P" .md)
MOVIE="통합반_04회차_$NAME"
MARK="$C/강조_$MOVIE.json"
OUT="$PWD/작업/통합04영상/$NAME/영상"
SIDE="$(dirname "$OUT")/_작업/영상_자막_기록"
mkdir -p "$OUT"
python3 "$K/판본검사.py" 통합4
python3 "$T/강의영상.py" "$OUT" "$P" --breath --dry
python3 "$T/강조좌표.py" --검사 "$P" "$MARK"
```

저장소 루트에서 해당 편 설정에 맞는 캐시를 먼저 확인한다. 전체 체크아웃에서는 기존 파일을 검증하고, sparse checkout에서는 현재 체크아웃한 커밋에 있는 쉼 파일과 재사용 음성만 복원한다. 설정의 빠르기 0.8은 캐시 이름을 구성하는 값이다. 실제 eleven_v4 요청에는 빠르기 인자가 들어가지 않는다.

```bash
python3 - "$J" "$T" "$V" <<'PY'
import hashlib, json, subprocess, sys
from pathlib import Path

j = json.loads(Path(sys.argv[1]).read_text(encoding="utf-8"))
tools = Path(sys.argv[2])
cfg = j["설정"]
if (sys.argv[3], cfg["model"], cfg["speed"]) != (cfg["voice"], "eleven_v4", 0.8):
    raise SystemExit("음성 ID·모델·빠르기와 제작 도구의 설정을 확인한다.")

def restore(path, sha256=None):
    if sha256 and path.is_file():
        if hashlib.sha256(path.read_bytes()).hexdigest() != sha256:
            raise SystemExit(f"기존 쉼 파일의 내용이 다름: {path}")
        return
    ref = "HEAD:" + path.as_posix()
    data = subprocess.check_output(["git", "cat-file", "blob", ref])
    if sha256 and hashlib.sha256(data).hexdigest() != sha256:
        raise SystemExit(f"제작 설정과 Git 판본이 다름: {path}")
    if path.exists():
        if path.read_bytes() != data:
            raise SystemExit(f"기존 파일의 내용이 다름: {path}")
        return
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("xb") as f:
        f.write(data)

for block in j["구획"]:
    pause = block.get("쉼파일")
    if pause:
        restore(Path(pause["파일"]), pause["SHA256"])
    if block["구매상태"] == "재사용":
        for ext in (".mp3", ".json"):
            restore(tools / "음성_저장" / (block["음성캐시키"] + ext))
print(f"재사용 음성 {j['재사용구획수']}구획. 제작 시 예상 신규 {len(j['신규구획시작장'])}구획 {j['신규글자']}자.")
PY
python3 "$T/음성견적.py" "$P" --voice "$V"
```

첫 구매 전 견적의 구획·신규·글자 수를 위 수와 대조한다. 견적에 신규로 잡힌 장 중 제작 설정의 신규 장에 없는 것이 있으면 캐시 복원부터 확인한다. 표본 구매 후에는 새로 산 구획만큼 신규 수가 줄어든다.

유료 표본을 만들기 전 제작상태와 파일 지문을 확인한다. 보류 이유가 있으면 해당 파일과 장을 출력하고 멈춘다. 준비 판정을 바꾸는 담당자는 실제 근거를 먼저 기록한다.

```bash
python3 - "$J" <<'PY'
import hashlib, json, sys
from pathlib import Path
j = json.loads(Path(sys.argv[1]).read_text(encoding="utf-8"))
for rec in [j[k] for k in ("검증판_PPTX", "대본", "강조")] + [x["쉼파일"] for x in j["구획"] if x.get("쉼파일")]:
    path = Path(rec["파일"])
    if hashlib.sha256(path.read_bytes()).hexdigest() != rec["SHA256"]:
        raise SystemExit(f"판본 불일치: {path}")
if j["사전검증_잔여"] or j["제작상태"] not in ("음성 생성 전 제작 입력 확정", "준비 완료"):
    for row in j["사전검증_잔여"]:
        print(row["파일"], row["장"], row["이유"])
    raise SystemExit(j["제작상태"])
PY
```

현재 견적에서 새 음성이 필요한 편은 승인한 표본 상한을 설정해 한 구획만 생성한다. 비용과 표본을 확인한 뒤 같은 장부에 전체 승인 상한을 적용한다. 새 음성이 0구획이면 표본을 생략하고 `PART_CAP=0`으로 재사용 장부를 만든다.

```bash

```

```bash

```
