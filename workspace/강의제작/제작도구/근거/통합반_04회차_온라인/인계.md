### 이번에 닫은 12~17장

12장은 현행 1.1판에서 작업 조건을 식별자에 연결한다. 13장은 절의 전제·개별 작업·승인 주체를 나눈다. 14장은 같은 15분 동안 유온 55℃ 미만과 경보 해제가 모두 유지돼야 회복으로 판정한다. 15장은 실제 문장의 ‘연속’과 ‘이내’를 출력값과 대조한다. 16장은 자정을 지난 연속 25시간과 날짜별 16·9시간을 비교한다. 17장은 HM-8.8 두 문장을 함께 보여 주어 정확히 24시간과 초과를 구별하고 20만 원 감점의 적용 범위를 판단한다.

맑은 고딕 보통·굵게를 사용한 실제 렌더에서 12장 ‘매핑’과 14장 ‘미만’ 단독 줄을 고쳤다. 수정 PPTX의 SHA-256은 `8e0b21ea258c62534a5b1dea573305bc346808d5754cc5972e80b81b7a119263`, 1편 대본은 `c776139c560a88fc4ba59dec88047f7fac353617dbc1c3780c1ea16892d61218`이다. 73장 글겹침 0곳, 해당 단원 낱말줄 후보 0곳, PPTX와 원고 간 노트 불일치 0장이다. 직전 확정판 5·7·11장의 강조 대상 13개가 전부 같은 위치에 들어왔고 중심 높이 차이는 최대 2.6픽셀이다. 사용한 LibreOfficeDev는 26.8.0.0.alpha0이며 수업 비교 환경은 26.8.1.1이다.

통합반 4회차 두 편은 제작 준비 중이다. 12~17장 화면에 쓰인 HM-8.5·SOP-COOL-11·HM-8.6·HM-8.8과 REMOTE_AUTO의 값은 학생 원문과 실습 데이터·main 코드로 확인했다. 문서가 적재된 수업 PC의 Neo4j 직접 조회가 남았다. 새 강사 음성 파형과 실제 영상의 전환·청취는 해당 제작 단계의 검증이다. 현재 단원의 덱·대본은 각각 18통과·5해당없음·1미확인, 19통과·4해당없음·1미확인이다. 영상 제작 입력은 14통과·4해당없음·5미확인이다.

### 다음 세션에서 정본을 복원할 때

현재 인계 커밋은 검증을 끝낸 원본 PPTX·대본·설정을 Git 바이너리 패치로 담는다. 이 단계에서 정본 경로는 이전 판이다. 깨끗한 workspace 브랜치의 루트에서 아래 두 명령을 차례로 실행하면 14파일이 시험한 판과 바이트 단위로 일치한다. 이미 반영된 파일이 있으면 겹치는 변경을 덮지 않고 먼저 해당 위치의 SHA와 비교한다.

```bash
P=workspace/강의제작/제작도구/근거/통합반_04회차_온라인/12-17/정본복원.patch
git apply --check "$P" && git apply "$P"
python3 workspace/강의제작/제작도구/검사/판본검사.py 통합4
```

## 편 확정 뒤 제작자가 실행할 명령

현재는 위의 무료 검증 단계다. 전 단원의 장별점검과 판정, 편별 SHA-256, 각 편의 쉼과 강조가 확정되고 음성 구매 상한을 정한 다음 내려간다. 아래 변수는 저장소 루트의 Bash에서 준비한다. 통합반 4회차 대본·강조 최종본 경로를 사용한다.

```bash
set -eu
W=workspace/강의제작
T="$W/제작도구/기존제작/tools/video"
K="$W/제작도구/검사"
S="$W/산출물/통합반/이론/04회차/대본"
C="$W/제작도구/구성/통합반/04회차"
V=1PdAOcPlPTz12RwMyFVp
O="$PWD/작업/통합04영상"
python3 "$K/판본검사.py" 통합4
python3 "$T/강의영상.py" "$O/무료" "$S"/*.md --breath --dry
python3 "$T/음성견적.py" "$S"/*.md --voice "$V"
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  python3 "$T/강조좌표.py" --검사 "$P" "$C/강조_통합반_04회차_${NAME}.json"
done
```

승인받은 1편 한 구획으로 비용을 실측한다. 두 예산 변수는 실행자가 승인된 정수 크레딧으로 설정한다. 2편은 전부 재사용할 경우 상한을 0으로 두어 캐시가 없으면 구매 전에 멈추게 한다. 두 편 모두 각 편의 음성기록을 만든 뒤에 그 기록을 굽기 명령에 넘긴다.

```bash
: "${SAMPLE_CAP:?승인된 표본 크레딧 상한}"
P="$S/01_이론_문서에서검증된지식으로.md"
NAME=$(basename "$P" .md)
OUT="$O/$NAME/영상"
mkdir -p "$OUT"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$OUT/음성기록.json" "$P" --voice "$V" --한도 1 --상한 "$SAMPLE_CAP"
```

표본 지출을 확인하고 남은 제작을 승인받은 뒤 같은 셸에서 실행한다. `PART1_CAP`은 표본 지출을 포함하는 1편 전체 상한이다.

```bash
: "${PART1_CAP:?승인된 1편 전체 크레딧 상한}"
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  OUT="$O/$NAME/영상"
  mkdir -p "$OUT"
  case "$NAME" in
    01_*) python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$OUT/음성기록.json" "$P" --voice "$V" --상한 "$PART1_CAP" ;;
    02_*) python3 "$T/음성사기.py" "$OUT/음성기록.json" "$P" --voice "$V" --상한 0 ;;
  esac
  python3 "$T/쉼옮기기.py" "$P" --출력 "$OUT/쉼파형.json" --파형 --voice "$V"
done
```

두 편의 파형 점검 목록에서 미저장·조용한 지점 없음이 0인 것을 확인한 뒤 굽는다. 영상과 시간표·자막의 검사는 `지침/영상.md` 길 9~10을 따른다.

```bash
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  OUT="$O/$NAME/영상"
  python3 "$T/강의영상.py" "$OUT" "$P" --breath --voice "$V" \
    --audio-ledger "$OUT/음성기록.json" --pause-short 0.15 --pause-mid 0.45 \
    --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
done
```
