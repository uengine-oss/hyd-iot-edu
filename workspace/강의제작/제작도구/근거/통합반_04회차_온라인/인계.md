## 제작 상태

현재 PPTX SHA-256은 `6bab85addea7ac39f7cc81821d18b103d41752c7517c1e2e41dde18d3496f592`이다. 지정 맑은 고딕으로 렌더했다. 사용한 LibreOfficeDev 26.8.0.0.alpha0와 수업 PC 비교판 26.8.1.1의 차이는 5·7·11장 승인 좌표 13곳에서 세로 중심 최대 2.6px이었다. 현재 단원의 보관본은 렌더 당시 PPTX와 모든 ZIP 항목이 동일하다.

- 현장 자료를 온톨로지 지식으로 전환하는 과정 이해하기 (4~38장) 배정 40분 · 본문 추정 32.37분 · 자리·실습 소개 추정 0.21분 · 본문 하한 30분 · 하한 이상
- 온톨로지 설계부터 지식 활용까지의 전체 과정 정리하기 (47~66장) 배정 30분 · 본문 추정 21.96분 · 자리·실습 소개 추정 0.36분 · 본문 하한 20분 · 하한 이상

1편 이론 본문은 5~38장의 순수 비교 낭독 1,821.568초다. 문장 쉼 75.3초와 학습 대기 8초는 제외했다. 42구획·문장 경계 353개·강조 81개를 확인했다. 원격 캐시 기준 새 음성 32구획 11,938자, 재사용 10구획이다. 2편은 검토 전이다.

지정 강사 음성이 없는 구획은 무료 한국어 시험 낭독으로 검증했다. 실제 강사 파형·영상 전환·청취는 제작 후 점검 항목이다. 수업 문서를 적재한 강의 PC의 Neo4j 직접 식별자 조회는 별도 인계한다. 4회차 온라인 전체와 현장 덱이 확정될 때까지 두 편은 준비 중이다.

## 편 확정 뒤 제작자가 실행할 명령

현재는 위의 무료 검증 단계다. 전 단원의 장별점검과 판정, 편별 SHA-256, 각 편의 쉼과 강조가 확정되고 음성 구매 상한을 정한 다음 내려간다. 아래 변수는 저장소 루트의 Bash에서 준비한다. 통합반 4회차 대본·강조 최종본 경로를 사용한다.

```bash
set -eu
W=workspace/강의제작
T="$W/제작도구/기존제작/tools/video"
K="$W/제작도구/검사"
S="$W/산출물/통합반/이론/04회차/대본"
C="$W/제작도구/구성/통합반/04회차"
V=1PdAOcPlPTz12RwMyFVp
O="$PWD/작업/통합04영상"
python3 "$K/판본검사.py" 통합4
python3 "$T/강의영상.py" "$O/무료" "$S"/*.md --breath --dry
python3 "$T/음성견적.py" "$S"/*.md --voice "$V"
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  python3 "$T/강조좌표.py" --검사 "$P" "$C/강조_통합반_04회차_${NAME}.json"
done
```

승인받은 1편 한 구획으로 비용을 실측한다. 표본 상한과 편별 전체 상한은 제작 시점의 견적·승인 금액으로 설정한다. 전부 재사용하는 편은 상한을 0으로 둔다. 두 편 모두 각 편의 음성기록을 만든 뒤에 그 기록을 굽기 명령에 넘긴다.

```bash
: "${SAMPLE_CAP:?승인된 표본 크레딧 상한}"
P="$S/01_이론_문서에서검증된지식으로.md"
NAME=$(basename "$P" .md)
OUT="$O/$NAME/영상"
mkdir -p "$OUT"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$OUT/음성기록.json" "$P" --voice "$V" --한도 1 --상한 "$SAMPLE_CAP"
```

표본 지출을 확인하고 남은 제작을 승인받은 뒤 같은 셸에서 실행한다. `PART1_CAP`은 표본 지출을 포함하는 1편 전체 상한이다.

```bash
: "${PART1_CAP:?승인된 1편 전체 크레딧 상한}"
: "${PART2_CAP:?승인된 2편 전체 크레딧 상한, 전부 재사용이면 0}"
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  OUT="$O/$NAME/영상"
  mkdir -p "$OUT"
  case "$NAME" in
    01_*) CAP="$PART1_CAP" ;;
    02_*) CAP="$PART2_CAP" ;;
  esac
  if [ "$CAP" -eq 0 ]; then
    python3 "$T/음성사기.py" "$OUT/음성기록.json" "$P" --voice "$V" --상한 0
  else
    python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$OUT/음성기록.json" "$P" --voice "$V" --상한 "$CAP"
  fi
  python3 "$T/쉼옮기기.py" "$P" --출력 "$OUT/쉼파형.json" --파형 --voice "$V"
done
```

두 편의 파형 점검 목록에서 미저장·조용한 지점 없음이 0인 것을 확인한 뒤 굽는다. 영상과 시간표·자막의 검사는 `지침/영상.md` 길 9~10을 따른다.

```bash
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  OUT="$O/$NAME/영상"
  python3 "$T/강의영상.py" "$OUT" "$P" --breath --voice "$V" \
    --audio-ledger "$OUT/음성기록.json" --pause-short 0.15 --pause-mid 0.45 \
    --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
done
```


### 완성 영상의 검사와 강조

각 편에서 생성한 기본 영상과 같은 편의 자막·시간표를 점검한다. 강조 설정의 이름과 영상 파일명을 같은 편으로 맞춘다. `강조표시.py`가 저장한 확인 그림에서 시작 낱말과 다음 문장 전환을 본 뒤 실제 영상 청취 결과를 기록한다.

```bash
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  MOVIE="통합반_04회차_$NAME"
  OUT="$O/$NAME/영상"
  SIDE="$O/$NAME/_작업/영상_자막_기록"
  python3 "$T/검사/말머리_잘림.py" "$OUT/$MOVIE.mp4"
  python3 "$T/검사/장넘김_싱크.py" "$OUT/$MOVIE.mp4" "$SIDE/${MOVIE}_시간표.md"
  python3 "$K/자막대조.py" "$SIDE" "$P"
  python3 "$T/강조표시.py" "$OUT/$MOVIE.mp4" "$C/강조_$MOVIE.json" \
    "$OUT/${MOVIE}_강조.mp4" --확인 "$O/$NAME/강조프레임"
done
```
