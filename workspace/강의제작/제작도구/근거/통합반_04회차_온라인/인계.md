## 편 확정 뒤 제작자가 실행할 명령

현재는 위의 무료 검증 단계다. 전 단원의 장별점검과 판정, 편별 SHA-256, 각 편의 쉼과 강조가 확정되고 음성 구매 상한을 정한 다음 내려간다. 아래 변수는 저장소 루트의 Bash에서 준비한다. 통합반 4회차 대본·강조 최종본 경로를 사용한다.

```bash
set -eu
W=workspace/강의제작
T="$W/제작도구/기존제작/tools/video"
K="$W/제작도구/검사"
S="$W/산출물/통합반/이론/04회차/대본"
C="$W/제작도구/구성/통합반/04회차"
V=1PdAOcPlPTz12RwMyFVp
O="$PWD/작업/통합04영상"
python3 "$K/판본검사.py" 통합4
python3 "$T/강의영상.py" "$O/무료" "$S"/*.md --breath --dry
python3 "$T/음성견적.py" "$S"/*.md --voice "$V"
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  python3 "$T/강조좌표.py" --검사 "$P" "$C/강조_통합반_04회차_${NAME}.json"
done
```

승인받은 1편 한 구획으로 비용을 실측한다. 두 예산 변수는 실행자가 승인된 정수 크레딧으로 설정한다. 2편은 전부 재사용할 경우 상한을 0으로 두어 캐시가 없으면 구매 전에 멈추게 한다. 두 편 모두 각 편의 음성기록을 만든 뒤에 그 기록을 굽기 명령에 넘긴다.

```bash
: "${SAMPLE_CAP:?승인된 표본 크레딧 상한}"
P="$S/01_이론_문서에서검증된지식으로.md"
NAME=$(basename "$P" .md)
OUT="$O/$NAME/영상"
mkdir -p "$OUT"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$OUT/음성기록.json" "$P" --voice "$V" --한도 1 --상한 "$SAMPLE_CAP"
```

표본 지출을 확인하고 남은 제작을 승인받은 뒤 같은 셸에서 실행한다. `PART1_CAP`은 표본 지출을 포함하는 1편 전체 상한이다.

```bash
: "${PART1_CAP:?승인된 1편 전체 크레딧 상한}"
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  OUT="$O/$NAME/영상"
  mkdir -p "$OUT"
  case "$NAME" in
    01_*) python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$OUT/음성기록.json" "$P" --voice "$V" --상한 "$PART1_CAP" ;;
    02_*) python3 "$T/음성사기.py" "$OUT/음성기록.json" "$P" --voice "$V" --상한 0 ;;
  esac
  python3 "$T/쉼옮기기.py" "$P" --출력 "$OUT/쉼파형.json" --파형 --voice "$V"
done
```

두 편의 파형 점검 목록에서 미저장·조용한 지점 없음이 0인 것을 확인한 뒤 굽는다. 영상과 시간표·자막의 검사는 `지침/영상.md` 길 9~10을 따른다.

```bash
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  OUT="$O/$NAME/영상"
  python3 "$T/강의영상.py" "$OUT" "$P" --breath --voice "$V" \
    --audio-ledger "$OUT/음성기록.json" --pause-short 0.15 --pause-mid 0.45 \
    --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
done
```


### 완성 영상의 검사와 강조

각 편에서 생성한 기본 영상과 같은 편의 자막·시간표를 점검한다. 강조 설정의 이름과 영상 파일명을 같은 편으로 맞춘다. `강조표시.py`가 저장한 확인 그림에서 시작 낱말과 다음 문장 전환을 본 뒤 실제 영상 청취 결과를 기록한다.

```bash
for P in "$S"/*.md; do
  NAME=$(basename "$P" .md)
  MOVIE="통합반_04회차_$NAME"
  OUT="$O/$NAME/영상"
  SIDE="$O/$NAME/_작업/영상_자막_기록"
  python3 "$T/검사/말머리_잘림.py" "$OUT/$MOVIE.mp4"
  python3 "$T/검사/장넘김_싱크.py" "$OUT/$MOVIE.mp4" "$SIDE/${MOVIE}_시간표.md"
  python3 "$K/자막대조.py" "$SIDE" "$P"
  python3 "$T/강조표시.py" "$OUT/$MOVIE.mp4" "$C/강조_$MOVIE.json" \
    "$OUT/${MOVIE}_강조.mp4" --확인 "$O/$NAME/강조프레임"
done
```
