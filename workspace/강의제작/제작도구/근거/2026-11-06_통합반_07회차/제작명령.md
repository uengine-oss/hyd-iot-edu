# 통합반 7회차 제작 명령

01편은 1~25장, 05편은 26~60장이다. 현재 두 편 모두 사전 검증 중이다. 아래 명령은 저장소 루트의 Bash에서 실행한다. 클라우드는 `python3`, 제작 PC는 `PYTHONUTF8=1`과 해당 PC의 제작 가상환경을 사용한다.

## 입력과 무료 점검

```bash
set -euo pipefail
G=workspace/강의제작
T="$G/제작도구/기존제작/tools/video"
K="$G/제작도구/검사"
C="$G/제작도구/구성/통합반/07회차"
H="$G/제작도구/근거/2026-11-06_통합반_07회차"
D="$G/산출물/통합반/이론/07회차"
PPTX="$D/통합반_07일차.pptx"
V=1PdAOcPlPTz12RwMyFVp
case "${HYD_EPISODE:?검증할 편 번호 01 또는 05를 지정한다}" in
  01) P="$D/대본/01_이론_사람의판단과승인.md" ;;
  05) P="$D/대본/05_이론_명세와변경검증.md" ;;
  *) exit 2 ;;
esac
NAME="통합반_07회차_$(basename "$P" .md)"
U="$PWD/작업/통합반07_영상제작/$NAME"
MARK="$C/강조_$NAME.json"
mkdir -p "$U"
python3 "$K/덱측정.py" "$U/본문시간.json" 통합7
python3 "$T/강의영상.py" "$U/무료검사" "$P" --breath --dry
python3 "$T/음성견적.py" "$P" --voice "$V"
python3 "$K/판본검사.py" 통합7
```

공식 렌더 PC에서 최신 배포 PPTX의 해시를 확인한 뒤 맑은 고딕 일반·굵은 글꼴로 PDF를 만든다. 새 폴더에 렌더하며 빌더의 글꼴 검사를 통과한 PDF로만 가림·잘림과 좌표를 확정한다. 01편 첫 단원에서는 아래 명령으로 후보를 다시 계산하고 시작·끝 문장과 정지 미리보기를 눈으로 맞춘다. 덱 수정 후 PDF를 받은 경우에는 함께 제공한 PPTX 해시와 먼저 대조한다.

## 편이 확정된 뒤

해당 편의 전 장에 대해 공식 렌더, 표시별 문장·낱말·끝문장, 문장 사이 쉼, 본문 시간, 독립 판정을 마치면 `구성.json`의 `제작점검`에 확인 범위와 최종 파일 지문을 기록한다. 다음 검사는 지금 파일에서 중단된다. 제작 승인을 받은 다음에만 같은 셸에서 진행한다.

```bash
python3 - "$C/구성.json" "$P" "$PPTX" "$MARK" "$T/쉼_저장" "$HYD_EPISODE" <<'PY'
import hashlib, json, sys
from pathlib import Path
cfg, script, slides, marks, pauses = map(Path, sys.argv[1:6])
episode = sys.argv[6]
conf = json.loads(cfg.read_text(encoding="utf8"))
unit = next(x for x in conf["units"] if Path(x["file"]).name == script.name)
check = unit.get("제작점검", {})
if check.get("상태") != "제작 입력 확정" or check.get("확인장") != unit["slides"]:
    sys.exit("편 전체의 제작 입력 미확정")
for p, k in [(script, "대본_SHA256"), (slides, "PPTX_SHA256"), (marks, "강조_SHA256")]:
    if not p.is_file() or hashlib.sha256(p.read_bytes()).hexdigest() != check.get(k):
        sys.exit(f"확정판과 다른 입력: {p.name}")
settings = json.loads((cfg.parent / f"{episode}편_제작입력.json").read_text(encoding="utf8"))
if settings["제작점검"] != check:
    sys.exit("구성표와 편별 제작 설정의 판이 다름")
for block in settings["구획별"]:
    file = pauses / block["쉼파일"]
    if not file.is_file() or hashlib.sha256(file.read_bytes()).hexdigest() != block["쉼_SHA256"]:
        sys.exit(f"{block['장']}장의 확정 쉼 설정 누락 또는 변경")
PY
python3 "$T/강조좌표.py" --검사 "$P" "$MARK"
: "${HYD_APPROVED_CAP:?승인받은 이 편의 누계 크레딧 상한을 입력한다}"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$U/음성기록.json" "$P" --voice "$V" --한도 1 --상한 "$HYD_APPROVED_CAP"
```

첫 구획의 실제 과금과 승인 잔여 한도를 확인한 뒤 나머지 음성을 생성한다. 새 음성 파형에서 쉼이 말머리·말끝을 자르는지 확인하고, 표시를 겹쳐 본 구간까지 통과하면 편 전체를 굽는다.

```bash
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$U/음성기록.json" "$P" --voice "$V" --상한 "$HYD_APPROVED_CAP"
python3 "$T/쉼옮기기.py" "$P" --파형 --voice "$V" --출력 "$U/생성후_쉼.json"
```

```bash
mkdir -p "$U/영상" "$U/강조"
```

구간 재생에서 표시가 실제 발화와 맞는지, 가림과 말머리 잘림이 없는지 듣고 확인한다. 그 뒤 같은 입력으로 전체 표시를 적용한다.

```bash
python3 "$T/강조표시.py" "$RAW" "$MARK" "$U/강조/$NAME.mp4"
```
