# 통합반 7회차 제작 명령

각 편을 저장소 루트의 Bash에서 하나씩 실행한다. 01편은 1~25장, 05편은 26~60장이다. 진행 상태는 회차 구성 폴더의 `구성.json`과 `01편_제작입력.json` 또는 `05편_제작입력.json`에서 읽는다. 제작 PC에서는 강사용 Python 가상환경을 활성화하고, 실행 파일 이름이 다르면 `HYD_PYTHON`에 그 경로를 지정한다.

## 입력과 무료 점검

```bash
set -euo pipefail
export PYTHONUTF8=1
export HYD_EPISODE=01       # 05편을 제작할 때는 이 줄을 05로 바꾼다.
PY=${HYD_PYTHON:-python3}
G=workspace/강의제작
T="$G/제작도구/기존제작/tools/video"
K="$G/제작도구/검사"
C="$G/제작도구/구성/통합반/07회차"
D="$G/산출물/통합반/이론/07회차"
PPTX="$D/통합반_07일차.pptx"
V=1PdAOcPlPTz12RwMyFVp
case "${HYD_EPISODE:?검증할 편 번호 01 또는 05를 지정한다}" in
  01) P="$D/대본/01_이론_사람의판단과승인.md" ;;
  05) P="$D/대본/05_이론_명세와변경검증.md" ;;
  *) exit 2 ;;
esac
NAME="통합반_07회차_$(basename "$P" .md)"
U="$PWD/작업/통합반07_영상제작/$NAME"
MARK="$C/강조_$NAME.json"
mkdir -p "$U"
"$PY" "$K/덱측정.py" "$U/본문시간.json" 통합7
"$PY" "$T/강의영상.py" "$U/무료검사" "$P" --breath --dry
"$PY" "$T/음성견적.py" "$P" --voice "$V"
"$PY" "$K/판본검사.py" 통합7
```

편별 최종 입력이 있는 판에서 공식 화면을 다시 볼 때 아래 명령을 사용한다. 맑은 고딕 일반·굵게, 공식 LibreOffice와 Poppler가 설치된 제작 PC에서 실행한다. 선택한 편의 기존 최종 강조 설정을 장 그림에 겹쳐 본다.

```bash
test -f "$MARK"
X="$U/공식렌더"
mkdir -p "$X"
"$PY" .claude/skills/hyd-course-deck/scripts/deck2pptx.py "$PPTX" --render "$X"
PDF="$X/통합반_07일차.pdf"
pdftoppm -scale-to-x 1920 -scale-to-y 1080 -png "$PDF" "$X/s"
"$PY" "$T/강조좌표.py" --검사 "$P" "$MARK"
"$PY" "$T/강조미리보기.py" "$X" "$MARK" "$U/강조미리보기"
"$PY" "$T/쉼옮기기.py" "$P" --파형 --voice "$V" --출력 "$U/문장사이쉼.json"
```

## 편이 확정된 뒤

아래 검사는 선택한 편의 확정 상태, 대본·PPTX·강조 지문과 모든 낭독 구획의 쉼 지문을 확인한다. 출력할 편의 제작 승인과 지출 상한을 받은 뒤 같은 셸에서 실행한다.

```bash
"$PY" - "$C/구성.json" "$P" "$PPTX" "$MARK" "$T/쉼_저장" "$HYD_EPISODE" <<'PY'
import hashlib, json, sys
from pathlib import Path
cfg, script, slides, marks, pauses = map(Path, sys.argv[1:6])
episode = sys.argv[6]
conf = json.loads(cfg.read_text(encoding="utf8"))
unit = next(x for x in conf["units"] if Path(x["file"]).name == script.name)
check = unit.get("제작점검", {})
if check.get("상태") != "제작 입력 확정" or check.get("확인장") != unit["slides"]:
    sys.exit("편 전체의 제작 입력 미확정")
for p, k in [(script, "대본_SHA256"), (slides, "PPTX_SHA256"), (marks, "강조_SHA256")]:
    if not p.is_file() or hashlib.sha256(p.read_bytes()).hexdigest() != check.get(k):
        sys.exit(f"확정판과 다른 입력: {p.name}")
settings = json.loads((cfg.parent / f"{episode}편_제작입력.json").read_text(encoding="utf8"))
if any(settings["제작점검"].get(k) != check.get(k) for k in
       ("상태", "확인장", "대본_SHA256", "PPTX_SHA256", "강조_SHA256")):
    sys.exit("구성표와 편별 제작 설정의 판이 다름")
for block in settings["구획별"]:
    file = pauses / block["쉼파일"]
    if not file.is_file() or hashlib.sha256(file.read_bytes()).hexdigest() != block["쉼_SHA256"]:
        sys.exit(f"{block['장']}장의 확정 쉼 설정 누락 또는 변경")
PY
"$PY" "$T/강조좌표.py" --검사 "$P" "$MARK"
: "${HYD_APPROVED_CAP:?승인받은 이 편의 누계 크레딧 상한을 입력한다}"
"$PY" "$T/음성키.py" 계정 "$V"
"$PY" "$T/음성키.py" 실행 "$PY" "$T/음성사기.py" "$U/음성기록.json" "$P" --voice "$V" --한도 1 --상한 "$HYD_APPROVED_CAP"
```

첫 구획의 실제 과금과 승인 잔여 한도를 확인한 뒤 나머지 음성을 생성한다. 새 음성 파형에서 쉼이 말머리·말끝을 자르는지 확인한다.

```bash
"$PY" "$T/음성키.py" 실행 "$PY" "$T/음성사기.py" "$U/음성기록.json" "$P" --voice "$V" --상한 "$HYD_APPROVED_CAP"
"$PY" "$T/쉼옮기기.py" "$P" --파형 --voice "$V" --출력 "$U/생성후_쉼.json"
"$PY" - "$U/생성후_쉼.json" <<'PYCODE'
import json, sys
from pathlib import Path
data = json.loads(Path(sys.argv[1]).read_text(encoding="utf8"))
if data["구획"] or data["조용한곳없음"] or data["요약"].get("파형_음성없음", 0):
    sys.exit("구획별 강사음과 쉼 파형을 확인한 뒤 굽기")
PYCODE
```

구간 재생에서 표시가 실제 발화와 맞는지, 가림과 말머리 잘림이 없는지 듣고 확인한다. 그 뒤 같은 입력으로 전체 표시를 적용한다.

```bash
"$PY" "$T/강조표시.py" "$RAW" "$MARK" "$U/강조/$NAME.mp4"
```
