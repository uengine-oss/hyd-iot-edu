# 통합반 5회차 제작 명령

저장소 루트의 Bash에서 실행한다. 현재 편별 상태와 남은 장은 [인계](인계.md)에 있다. 하나의 편에 속한 모든 단원의 정지 검토와 독립 검토가 닫힌 뒤 그 편을 제작한다. 음성의 지출 한도는 담당자가 받은 승인 값으로 설정한다.

## 현재 판 확인

```bash
set -euo pipefail
G=workspace/강의제작
T="$G/제작도구/기존제작/tools/video"
K="$G/제작도구/검사"
C="$G/제작도구/구성/통합반/05회차"
H="$G/제작도구/근거/통합반_05회차_교재"
S="$G/산출물/통합반/이론/05회차/대본"
PPTX="$S/../통합반_05일차.pptx"
P1="$S/01_이론_질문하는AI와일하는AI.md"
P2="$S/02_이론_정보와도구를쓰는원리.md"
V=1PdAOcPlPTz12RwMyFVp
W="$PWD/작업/통합05_영상준비"
mkdir -p "$W"
EXPECTED=c86470724623f640eac48791abbe81674b591a49ed17bcb8ad14cfa6d59bcc9f
if ! git apply --reverse --check "$H/01-14_작업중.patch" 2>/dev/null; then
  git apply --check "$H/01-14_작업중.patch"
  git apply "$H/01-14_작업중.patch"
fi
printf '%s  %s\n' "$EXPECTED" "$PPTX" | sha256sum -c -
git log -1 --format='%H %s' -- "$H/인계.md"
sha256sum "$PPTX"
python3 "$K/판본검사.py" 통합5
python3 "$K/덱측정.py" "$W/본문시간.json" 통합5
python3 "$T/강의영상.py" "$W/무료검사" "$P1" "$P2" --breath --dry
python3 "$T/음성견적.py" "$P1" "$P2" --voice "$V"
```

음성 견적은 전체 캐시가 있는 체크아웃에서 계산한다. 부분 체크아웃에서는 내려받지 않은 기존 구획도 신규로 집계될 수 있다.

## 첫 단원 정지 검증 재개

현재 PPTX를 맑은 고딕 일반·굵게가 설치된 지정 환경에서 렌더한다. 또는 이 PPTX를 PC에서 PDF로 내보내고 `PDF`에 그 파일 경로를 지정한다. PDF에는 1~14장 전체와 15장 이음새가 있어야 한다. 아래 명령은 전체 77장 PDF 기준이다.

```bash
X="$W/공식렌더"
PART="$W/단원좌표/강조_통합반_05회차_$(basename "$P1" .md).json"
mkdir -p "$X" "$W/단원좌표"
python3 .claude/skills/hyd-course-deck/scripts/deck2pptx.py "$PPTX" --render "$X"
PDF="$X/통합반_05일차.pdf"
pdftoppm -r 150 -png "$PDF" "$X/s"
python3 "$G/제작도구/기존제작/tools/deck/글겹침.py" "$PDF"
python3 "$K/낱말줄찾기.py" "$X"
python3 "$T/강조좌표.py" "$PDF" "$S" "$H/01_01-14_강조계획.json" --출력 "$PART"
python3 "$T/강조좌표.py" --검사 "$P1" "$PART"
python3 "$T/강조미리보기.py" "$X" "$PART" "$W/01_단원미리보기"
python3 "$T/쉼옮기기.py" "$P1" --장 1-14 --파형 --voice "$V" --출력 "$W/01_단원쉼.json"
```

PC PDF를 받아 쓰는 경우 렌더 명령을 건너뛰고, 받은 파일을 가리키도록 `PDF`를 지정한 뒤 같은 `pdftoppm` 명령부터 실행한다. 참고 렌더를 정본 폴더에 복사하거나 stamp를 쓰지 않는다. 그림과 낭독을 같이 보며 표시가 가리키는 글자와 표의 행, 처음·끝 문장, 문장 안의 낱말, 동시에 나타나는 표시의 가림을 확인한다. 구매 대상 구획은 지금 문장별 쉼을 확정하되 실제 파형은 구매 뒤 확인한다.

이 단원의 좌표를 위 정지 검토에서 승인한 뒤 같은 셸에서 다음 블록을 실행한다. 다른 단원의 표시는 유지한다.

```bash
M="$C/강조_통합반_05회차_$(basename "$P1" .md).json"
python3 - "$M" "$PART" "$H/01_01-14_강조계획.json" "$W/생략사유.json" <<'PY'
import json, sys
from pathlib import Path
dst, part, plan, omit = map(Path, sys.argv[1:])
current = json.loads(dst.read_text("utf-8"))
revised = json.loads(part.read_text("utf-8"))["표시"]
assert revised and all(1 <= int(mark["장"]) <= 14 for mark in revised)
current["표시"] = revised + [m for m in current["표시"] if int(m["장"]) > 14]
dst.write_text(json.dumps(current, ensure_ascii=False, indent=1) + "\n", "utf-8")
omit.write_text(json.dumps({"통합5": json.loads(plan.read_text("utf-8"))["생략"]}, ensure_ascii=False), "utf-8")
PY
python3 "$T/강조좌표.py" --검사 "$P1" "$M"
python3 "$K/장별점검_생성.py" 통합5 --어림 --장 1-14 --까닭 "$W/생략사유.json" --출력 "$C/장별점검.md"
```

다음 단원부터도 편·장 범위에 맞춰 좌표를 합치고 근거를 누적한다. 각 편에 필요한 사전 검사가 모두 통과했는지 확인한다. 마지막 단원까지 마치면 장별점검표가 77장을 덮는지 검사한다.

## 편 확정과 음성 비용 승인 뒤

두 편을 한 번에 처리하려면 두 편의 사전 검토가 모두 끝나야 한다. 한 편만 확정됐으면 해당 대본만 루프에 넣는다. `HYD_APPROVED_CAP`은 **그 편 장부에 이미 쓴 크레딧을 포함한 누계 상한**이다. 편마다 상한이 다르면 각 편을 따로 실행한다. 생성기에 필요한 키는 작업 환경이 제공한다.

```bash
: "${HYD_APPROVED_CAP:?이번 편에 승인된 누계 크레딧 상한을 먼저 지정한다}"
for P in "$P1" "$P2"; do
  NAME="통합반_05회차_$(basename "$P" .md)"
  MARK="$C/강조_${NAME}.json"
  U="$W/$NAME"
  mkdir -p "$U/영상" "$U/강조"
  python3 "$T/강조좌표.py" --검사 "$P" "$MARK"
  python3 "$T/음성견적.py" "$P" --voice "$V"
  python3 "$T/음성사기.py" "$U/음성기록.json" "$P" --voice "$V" --한도 1 --상한 "$HYD_APPROVED_CAP"
done
```

대표 구획의 실제 과금·단가·잔여 상한을 확인한 뒤 같은 셸에서 나머지를 생성한다.

```bash
for P in "$P1" "$P2"; do
  NAME="통합반_05회차_$(basename "$P" .md)"
  U="$W/$NAME"
  python3 "$T/음성사기.py" "$U/음성기록.json" "$P" --voice "$V" --상한 "$HYD_APPROVED_CAP"
  python3 "$T/쉼옮기기.py" "$P" --파형 --voice "$V" --출력 "$U/생성후_쉼.json"
done
```

각 편의 파형 목록을 열어 실제 음원 누락·미저장 쉼·조용한 곳 없는 경계를 모두 해소한 뒤 굽는다. 동일한 대본·음성·모델 캐시를 유지한다. 강조는 구간 시험과 재생 시각 대조 뒤 편 전체에 적용한다.

```bash
for P in "$P1" "$P2"; do
  NAME="통합반_05회차_$(basename "$P" .md)"
  U="$W/$NAME"
  python3 "$T/강의영상.py" "$U/영상" "$P" --breath --voice "$V" \
    --audio-ledger "$U/음성기록.json" --pause-short 0.15 --pause-mid 0.45 \
    --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
  RAW="$U/영상/$NAME.mp4"
  M="$C/강조_${NAME}.json"
  python3 "$T/검사/말머리_잘림.py" "$RAW"
  python3 "$T/검사/장넘김_싱크.py" "$RAW" "$U/_작업/영상_자막_기록/${NAME}_시간표.md"
  python3 "$K/자막대조.py" "$U/_작업/영상_자막_기록" "$P"
done
```

위 루프의 `NAME`, `U`, `RAW`, `M`을 확인할 편으로 설정한다. 그 편의 실측 시간표에서 표시 전후 구간을 찾아 초 단위로 넣는다.

```bash
: "${CHECK_FROM:?선택 구간 시작 초}" "${CHECK_TO:?선택 구간 끝 초}"
python3 "$T/강조표시.py" "$RAW" "$M" "$U/시험.mp4" --구간 "$CHECK_FROM" "$CHECK_TO" --확인 "$U/확인"
# 구간에서 소리·표시·가림을 확인한 후
python3 "$T/강조표시.py" "$RAW" "$M" "$U/강조/$NAME.mp4"
```
