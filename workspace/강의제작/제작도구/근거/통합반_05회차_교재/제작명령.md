# 통합반 5회차 제작 명령

저장소 루트의 Bash에서 실행한다. PC의 Git Bash에서 `python3`은 `PYTHONUTF8=1 .venv314/Scripts/python.exe`로 읽는다. 현재 편별 상태와 남은 장은 [인계](인계.md)에 있다. 하나의 편에 속한 모든 단원의 정지 검토와 독립 검토가 닫힌 뒤 그 편을 제작한다. 음성의 지출 한도는 담당자가 받은 승인 값으로 설정한다.

## 현재 판 확인

```bash
set -euo pipefail
G=workspace/강의제작
T="$G/제작도구/기존제작/tools/video"
K="$G/제작도구/검사"
C="$G/제작도구/구성/통합반/05회차"
H="$G/제작도구/근거/통합반_05회차_교재"
S="$G/산출물/통합반/이론/05회차/대본"
PPTX="$S/../통합반_05일차.pptx"
P1="$S/01_이론_질문하는AI와일하는AI.md"
P2="$S/02_이론_정보와도구를쓰는원리.md"
V=1PdAOcPlPTz12RwMyFVp
W="$PWD/작업/통합05_영상준비"
mkdir -p "$W"
git log -1 --format='%H %s' -- "$H/인계.md"
sha256sum "$PPTX"
python3 "$K/판본검사.py" 통합5
python3 "$K/덱측정.py" "$W/본문시간.json" 통합5
python3 "$T/강의영상.py" "$W/무료검사" "$P1" "$P2" --breath --dry
python3 "$T/음성견적.py" "$P1" "$P2" --voice "$V"
```

음성 견적은 전체 캐시가 있는 체크아웃에서 계산한다. 부분 체크아웃에서는 내려받지 않은 기존 구획도 신규로 집계될 수 있다.

## 닫힌 단원 확인과 다음 단원 렌더

회차의 실제 배포 PPTX·대본·구성·쉼 파일을 위 경로에서 읽는다. 첫 단원은 [인계](인계.md)의 닫힌 커밋에서 정본 설정을 이어받는다. 이미 확인한 표시의 좌표를 새 후보값으로 일괄 교체하지 않는다. 새 단원에서는 맑은 고딕 일반·굵은 글꼴을 쓰는 공식 렌더의 해당 장과 앞뒤를 확인한다. 다음 명령에서 각 편의 대본 앵커는 전부 확인하되, 미검토 뒤 단원의 좌표는 작업 기록에서 따로 구별한다.

```bash
X="$W/공식렌더"
mkdir -p "$X"
python3 .claude/skills/hyd-course-deck/scripts/deck2pptx.py "$PPTX" --render "$X"
PDF="$X/통합반_05일차.pdf"
pdftoppm -r 150 -png "$PDF" "$X/s"
python3 "$G/제작도구/기존제작/tools/deck/글겹침.py" "$PDF"
python3 "$K/낱말줄찾기.py" "$X"
for P in "$P1" "$P2"; do
  MARK="$C/강조_통합반_05회차_$(basename "$P" .md).json"
  python3 "$T/강조좌표.py" --검사 "$P" "$MARK"
  python3 "$T/강조미리보기.py" "$X" "$MARK" "$W/$(basename "$P" .md)_미리보기"
  python3 "$T/쉼옮기기.py" "$P" --파형 --voice "$V" --출력 "$W/$(basename "$P" .md)_쉼.json"
done
```

새로 사야 하는 장의 쉼은 구매 직후 파형을 다시 본다. 구간 자체의 정지 검토·화면 반영 범위·다음 시작점은 [인계](인계.md)의 단원별 기록을 따른다.

## 편 확정과 음성 비용 승인 뒤

편별로 실행한다. 먼저 비용 승인을 받은 편 번호를 `HYD_EPISODE=01` 또는 `HYD_EPISODE=02`로 지정하고, 누계 한도를 `HYD_APPROVED_CAP`에 넣는다. 아래 첫 명령은 최신 구성의 제작 입력 상태와 대본·강조 파일 지문을 점검한 뒤 그 편만 선택한다. `HYD_APPROVED_CAP`에는 그 편 장부에 이미 쓴 크레딧도 포함된다.

```bash
case "${HYD_EPISODE:?확정한 편 번호 01 또는 02를 지정한다}" in
  01) RUN=("$P1") ;;
  02) RUN=("$P2") ;;
  *) echo '편 번호는 01 또는 02여야 한다.' >&2; exit 1 ;;
esac
python3 - "$C/구성.json" "${RUN[0]}" <<'PYRUN'
import hashlib, json, sys
from pathlib import Path
cfg, script = map(Path, sys.argv[1:])
data = json.loads(cfg.read_text(encoding="utf-8"))
u = next(x for x in data["units"] if Path(x["file"]).name == script.name)
v = u.get("제작점검", {})
if v.get("상태") != "제작 입력 확정" or v.get("확인장") != u["slides"]:
    raise SystemExit("이 편의 모든 단원 사전 검토를 마친 뒤 실행한다.")
for f, key in [(script, "대본_SHA256"), (cfg.parent / v["강조설정"], "강조_SHA256")]:
    if hashlib.sha256(f.read_bytes()).hexdigest() != v[key]:
        raise SystemExit(f"{f.name}의 지문이 확정한 판과 다르다.")
PYRUN
: "${HYD_APPROVED_CAP:?이번 편에 승인된 누계 크레딧 상한을 먼저 지정한다}"
for P in "${RUN[@]}"; do
  NAME="통합반_05회차_$(basename "$P" .md)"
  MARK="$C/강조_${NAME}.json"
  U="$W/$NAME"
  mkdir -p "$U/영상" "$U/강조"
  python3 "$T/강조좌표.py" --검사 "$P" "$MARK"
  python3 "$T/음성견적.py" "$P" --voice "$V"
  python3 "$T/음성사기.py" "$U/음성기록.json" "$P" --voice "$V" --한도 1 --상한 "$HYD_APPROVED_CAP"
done
```

대표 구획의 실제 과금·단가·잔여 상한을 확인한 뒤 같은 셸에서 나머지를 생성한다.

```bash
for P in "${RUN[@]}"; do
  NAME="통합반_05회차_$(basename "$P" .md)"
  U="$W/$NAME"
  python3 "$T/음성사기.py" "$U/음성기록.json" "$P" --voice "$V" --상한 "$HYD_APPROVED_CAP"
  python3 "$T/쉼옮기기.py" "$P" --파형 --voice "$V" --출력 "$U/생성후_쉼.json"
done
```

각 편의 파형 목록을 열어 실제 음원 누락·미저장 쉼·조용한 곳 없는 경계를 모두 해소한 뒤 굽는다. 동일한 대본·음성·모델 캐시를 유지한다. 강조는 구간 시험과 재생 시각 대조 뒤 편 전체에 적용한다.

```bash
for P in "${RUN[@]}"; do
  NAME="통합반_05회차_$(basename "$P" .md)"
  U="$W/$NAME"
  python3 "$T/강의영상.py" "$U/영상" "$P" --breath --voice "$V" \
    --audio-ledger "$U/음성기록.json" --pause-short 0.15 --pause-mid 0.45 \
    --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
  RAW="$U/영상/$NAME.mp4"
  M="$C/강조_${NAME}.json"
  python3 "$T/검사/말머리_잘림.py" "$RAW"
  python3 "$T/검사/장넘김_싱크.py" "$RAW" "$U/_작업/영상_자막_기록/${NAME}_시간표.md"
  python3 "$K/자막대조.py" "$U/_작업/영상_자막_기록" "$P"
done
```

위 루프의 `NAME`, `U`, `RAW`, `M`을 확인할 편으로 설정한다. 그 편의 실측 시간표에서 표시 전후 구간을 찾아 초 단위로 넣는다.

```bash
: "${CHECK_FROM:?선택 구간 시작 초}" "${CHECK_TO:?선택 구간 끝 초}"
python3 "$T/강조표시.py" "$RAW" "$M" "$U/시험.mp4" --구간 "$CHECK_FROM" "$CHECK_TO" --확인 "$U/확인"
# 구간에서 소리·표시·가림을 확인한 후
python3 "$T/강조표시.py" "$RAW" "$M" "$U/강조/$NAME.mp4"
```
