# 길뚫기 확인(클라우드 VM, 2026-11-12)

실습 DB는 학생 ZIP(`산출물/통합반/실습/02회차/랩/02일차_실습1_관계조회.zip`)을 풀어 `prepare_example.py` → `lab_db.py --no-open`으로 만든 neo4j:5.26-community(20노드 · 19관계). 브라우저는 Playwright Chromium 새 프로필(처음 여는 학생과 같은 상태), CSS 1536×864 × 1.25.

| 확인한 것 | 결과 | 어떻게 |
|---|---|---|
| 연결 창 | 「Connect to instance」, Connection URL · Database user(neo4j)가 채워짐, Password 빈칸, Connect · Cancel 모두 화면 안(Cancel 아래 끝 846/864) | 화면 사진, 요소 위치 |
| 연결 직후 안내 창 | 「New · Work in tabs · Open a new tab to draft and run a query … 1/3 · Dismiss · Next」. 닫지 않으면 끝까지 떠 있음(옛 큐 무음 길뚫기 전 화면). Dismiss로 닫힘 | 새 프로필 시험 2회 |
| 왼쪽 패널 처음 화면 | Queries(No queries · Create new query) | 새 프로필 화면 |
| 그래프 배치 처음 값 | Force-based layout=true, Hierarchical layout=false | Select layout 메뉴의 aria-checked |
| 새 쿼리 탭 | 「+」(Add new tab) → Untitled Query 탭. 글을 넣으면 Drafts 아래 첫 줄 이름(설비 연결 탐색)으로 저장, 위에 Saved, 안내 창 「Discover more actions · Right-click a query … · OK, got it」 | 새 프로필 시험 |
| 받은 그림 | Download as PNG → visualisation.png, 브라우저 탭에서 그림으로 열림 | 옛 큐 길뚫기 · file:// 열기 |
| 받은 쿼리 파일 | Download all → `neo4j_query_saved_cypher_2026-11-12.csv`(170바이트, 칸 name · description · query · id · parentId · isFolder · isProtected). 브라우저 탭에서는 열리지 않고 내려받기가 됨. 새 프로필 Queries에서 Upload로 올리면 No queries → 「설비 연결 탐색」이 다시 생김 | 시험 스크립트(받기 → 새 프로필 → 올리기) |
| 관계를 만든 뒤 그림 | 원 둘이 위아래로 놓이며 펌프 원이 그림 아래 끝에 잘림(새 큐 무음 리허설 rh1 끝 프레임). 화면 맞춤 전에는 펌프 중심이 그림 밖 | 리허설 프레임 001307 |
| 안내 문서 복사 단추 | 복사 → 「복사했습니다. Neo4j Browser 위쪽 입력 칸에 붙여 넣고 Run을 누르세요.」, Neo4j 입력칸에 Ctrl+V로 붙은 글이 칸 글과 같음 | 옛 큐 길뚫기 guideCopy 큐(붙여 넣은 글 대조 통과) |
| 돌린 뒤 입력칸 | 쿼리 · 명령을 넣고 0.2초 넘게 있다가 돌리면 입력칸이 비워지고, 넣자마자(0.1초 안) 돌리거나 한 글자씩 치고 바로 엔터를 누르면 돌린 글이 입력칸에 남는다. 넣은 뒤 기다린 시간별(Enter): 0 · 0.1초 남음, 0.2 · 0.3 · 0.45 · 0.6초 비워짐, 0.12초 간격으로 한 글자씩 치고 바로 Enter 두 번 다 남음. Run 단추도 같음 | 2026-11-12 새 브라우저 `edrule` · `edrule2` 시험, 녹화 t6 2구간 끝(비워짐) · 무음 리허설 rh5(남음) |
| 옮긴 도구 시험 합성 | rh1 4~5구간을 `encode.py --도구 neo4j … --silent`로 합성: h264 1920×1080 30fps, 화살표 overlay, 조각 2 · 이음새 통과, 92.9초. 안내 문서 탭 → 복사 → Neo4j 탭 → 붙여넣기 장면이 차례대로 보임 | 합성본 프레임 6장 |
