# 2회차 04 관계조회 다시 찍을 판 — 확정 요청

- 최종본: `새대본_다시찍을판.md`(3판, 이 폴더). 「2. 새 대본 전문」이 낭독하는 말이고, ▸는 그 자리에서 조작이 일어나는 곳, ‖는 쉼, ‖(따라 하기 N초)는 학생이 따라 할 시간입니다.
- 거친 검토: 1차 적대 검토 58건(`판정/새대본검토.md`) → 전문 새로 씀 → 2차 적대 검토 37건(`판정/새대본검토2.md`) → 모두 반영. 화면 사실은 클라우드 VM의 학생 첫 상태(새 실습 DB · 새 브라우저)에서 직접 확인(`판정/길뚫기_확인.md`, `판정/DB사실.json`).
- 낭독 약 8,600자(공백 빼고), 따라 하기 52곳 · 약 5분. 쉼을 넣으면 30분 안팎으로 봅니다(게시본 29:54, 배정 25분). 길이를 이유로 줄이지 않았습니다.

## 옛 게시본과 바뀐 곳

| 자리 | 옛 게시본(이 PC ego 촬영) | 새 판 |
|---|---|---|
| 말투 | 조작마다 한 문장(「~를 누르겠습니다」), 큐마다 끊김 | 강사가 하면서 이어 말하는 한 가닥. 당연한 조작(비우기 · 닫기 · 붙이기 · Run)은 처음 몇 번만 말하고 그 뒤는 흐름에 녹이거나 말하지 않음 |
| 여는 말 | 쿼리를 넣어 보자 | 오늘 끝에 답할 물음을 세움: 「쿨러가 뜨거워지는 것 같을 때 어떤 값을 보고, 어디까지면 괜찮은가」 → 13단계 표 한 줄(유온 · 48 · 65)로 답함 |
| 첫 쿼리 | 입력칸에 갑자기 나타남(행위 누락) | 안내 문서 탭으로 가서 2번 첫 칸 「복사」 → 돌아와 붙이기를 화면에 보임. 그 뒤는 「다음 칸」으로 말만 |
| 학생이 막히는 곳 | 없음(리허설 흔적 · 이미 닫은 창 위에서 찍음) | 처음 들어오면 뜨는 안내 창 둘(Work in tabs · Discover more actions)을 짚고 닫음. 돌린 글이 입력칸에 남아 그냥 붙이면 오류 → 「컨트롤 A로 다 고른 뒤 붙이기」를 한 번 까닭과 함께. 관계를 만든 뒤 아래 원이 잘림 → 화면 맞춤 |
| 이름 | 「연습용」 · 「장치」 · 「콜론」 · 「온도 센서」 · 영어 이름표를 우리말로만 | 이론 이름으로: 작은 예제 노드 · 구성 요소 · 쌍점 · 상태 변수 · 유온 센서. 정보 칸 이름표는 화면 글자 그대로(Asset · Component · Sensor · StateVariable · Part) |
| 관계 배경(왜) | 없음 | 설비 → 구성 요소(여러 부분이 모여 돎) → 센서(상태를 사람이 계속 볼 수 없어 잼) → 물리량(재는 대상) · 부품(고장 나면 갈아 끼움). 기준값이 물리량에 있는 까닭(기준이 하나라 한 번만 — 이론 14장), 냉각 효율이 가상인 까닭(계산값), 화살표 방향의 뜻 |
| 그래프 배치 | 「제 화면은 층을 지어 있고 여러분은 흩어져 있을 수 있어요」 | 처음 값은 흩어진 모양(Force-based)이라고 짚고 Hierarchical layout으로 바꿈, 줄마다 설비에서 건넌 횟수가 같은 것끼리라는 뜻 |
| 아래로 이어진 것 없는 구성 요소 | 「예비 펌프 하나」 | 셋(작동유 탱크 · 구동 모터 · 예비 펌프), 오늘 따라간 가지(오른쪽 셋)와 견줌 |
| 저장 | PNG 받기, 쿼리 탭, CSV 받기를 「여러분 화면엔 뜰 거예요」로 말만 | 받은 그림 파일을 열어 보임, 비어 있던 Queries가 왜 비었는지, 탭을 닫았다 다시 여는 까닭, CSV를 다른 컴퓨터에서 올리기로 되살릴 수 있음(확인함) |
| 끝말 | 오늘 한 일을 되풀이 | 이제 할 수 있게 된 일로 닫음(다음 실습 예고는 영상 V-13대로 넣지 않음) |

## 여쭐 것

1. **입력칸 바꿔 넣기**: 4단계에서 한 번 「입력칸 누르고 컨트롤 A로 다 고르신 다음 붙여 넣으세요」를 키 이름과 까닭(그냥 붙이면 남은 글 뒤에 붙어 오류)까지 말하고, 그 뒤로는 말하지 않습니다. 단축키 이름을 한 번 대는 자리인데, 이렇게 해도 될까요.
2. **따라 하기 시간**: 질의 설명이 있는 자리는 Run 뒤 5초, 말 없이 붙이고 돌리는 자리는 10초, 노드 누르기는 6초, 첫 복사 · PNG · 보관 글 붙이기는 8~10초로 두었습니다. 늘리거나 줄일 곳이 있을까요.
3. **영어 화면 글자**: 학생이 화면에서 찾아 눌러야 하는 것(Connect · Dismiss · Run · Hierarchical layout · Download as PNG · Queries · OK, got it)과 정보 칸 이름표 · 속성 이름(Asset · tag · virtual · limit · normal 등)은 영어 그대로 읽습니다. Drafts는 「왼쪽 목록」으로 바꿔도 되는데, 화면 글자와 맞추려고 남겼습니다. 이대로 괜찮을까요.
4. **안내 문서와 다른 곳**: 영상에 CSV 받기 · 다시 올리기, 입력칸 바꿔 넣기, 안내 창 닫기가 들어가는데 안내 문서(가이드)에는 없습니다. 영상이 확정되면 가이드를 영상에 맞춰 고치는 일로 넘기겠습니다(이 일 범위 밖, 남은 일).
5. **쿨러 팬**: 쿨러 팬은 오일 쿨러 밑이 아니라 설비에 바로 이어져 있습니다. 저장소에 그 설계 까닭이 적힌 곳이 없어 대본에서 따로 짚지 않았습니다. 그대로 둘까요.
