# 통합2-04-Neo4j-다시찍기

- 시작: 2026-11-12 · 상태: 끝
- 상태는 `진행` · `중단` · `끝` 셋 가운데 하나다. 일이 끝나면 「끝」으로 바꾸고 `<py> workspace/동기화.py 정리 --실행`으로 이 폴더를 지운다(클라우드는 지운 것을 커밋한다).

## 의도
통합 2회차 실습 04 「관계조회」(Neo4j Browser에서 사이퍼로 노드 만들고 고치고 지우기 → 설비 데이터 따라가기)을 새 대본으로 **다시 찍는다**. 다른 세션(통합2-이론)이 쉼넣기용으로 모든 큐를 새로 썼지만, 음성을 어차피 다 새로 사야 하고 쉼넣기로는 말과 조작이 엇갈리며 첫 쿼리를 복사하는 장면도 없어(행위 누락) 다시 찍는다. 이 PC의 ego는 Notion을 찍으므로 클라우드에서 동시에 찍는다(Neo4j는 VM 안에 띄운다). 사용자: 「다시 찍을 때 … 설명을 쉽게 최대한 쉽게 … 어색한 표현 없고 원테이크로 … 줄줄 하나의 실」 · 「리스크 없이 완벽한 버전」 · 「여러 개 한 번에 찍자」 · 「옮기면 되지 비슷하지 않나요」.

## 하는 일
1. 대본: `입력/04_새대본_화면그대로판.md`(쉼넣기용 — 큐마다 옛 조작 자리 제약)를 제약 없이 **다시 찍을 판**으로 다시 쓴다(꼴은 `입력/본보기_Notion_다시찍을판_확정.md`). `입력/04_걸린곳.md` 지적(유온 센서 이름 · 영어 레이블 이름표 · 저장한 그림 · 받은 파일)을 반영하고, 학생이 받은 실습 폴더의 안내 문서(`안내.html`)에서 **처음 쿼리를 복사하는 장면을 화면에 보인다**(그 뒤 쿼리는 「안내 문서 다음 칸 복사해서」로 말만). 독립 적대 검토 1회(`입력/새대본검토의뢰.md`) → 목록 고침 → 사용자 확정.
2. 녹화 도구 옮기기: `neo4j/record_graph_lesson.mjs`(ego)를 포털 클라우드 도구(`촬영/포털/촬영도구/`, Playwright)처럼 클라우드에서 돌게 옮긴다. Neo4j는 `CLAUDE.md` 7절 「사실 대조 그래프」대로 VM 안에 띄우고, 실습 데이터베이스는 학생 경로(받은 폴더의 안내 문서)와 같은 상태로 준비한다. 시험 녹화 한 토막으로 검증한 뒤 본녹화.
3. 길뚫기 → 큐 JSON · 음성 견적(사용자 승인 뒤 구매, 영상 V-4) → 구간마다 녹화하고 바로 확인(화면대조 · measure · 끝 상태, 문제는 그 구간만 즉시 다시) → 합성 → 사용자 청취.
4. 같은 시각에 다른 클라우드 세션들이 포털 세 편을 찍는다(`근거/2026-11-12_통합1-06-포털-다시찍기/` · `…통합2-05-포털-다시찍기/` · `…통합1-04-포털둘러보기-다시찍기/`). 그 폴더와 큐 · 음성 파일은 건드리지 않고, 공용 도구를 고치면 커밋 전에 `git pull`로 겹침을 본다.
5. 빼는 것: 다른 실습 영상, 시스템 코드 변경.
