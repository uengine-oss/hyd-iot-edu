# 통합1-08-ARROWS-다시찍기

- 시작: 2026-11-12 · 상태: 진행
- 상태는 `진행` · `중단` · `끝` 셋 가운데 하나다. 일이 끝나면 「끝」으로 바꾸고 `<py> workspace/동기화.py 정리 --실행`으로 이 폴더를 지운다(클라우드는 지운 것을 커밋한다).

## 의도
통합 1회차 실습 08 「관계그림」(ARROWS로 쿨러 고장 지식 그래프 그리기)을 새 대본으로 **다시 찍는다**. 말투를 편 전체로 새로 쓰므로 음성은 어차피 다 새로 사고, 쉼넣기로 고치면 화면이 19% 멈추고 말과 조작이 46곳 엇갈려서 다시 찍는다. 이 PC의 ego는 Notion을 찍으므로, 이 편은 클라우드에서 동시에 찍는다(클라우드 환경 네트워크 액세스 「전체」 — arrows.app 접속 가능). 사용자: 「다시 찍을 때 … 설명을 쉽게 최대한 쉽게 … 어색한 표현 없고 원테이크로 … 줄줄 하나의 실」 · 「리스크 없이 완벽한 버전」 · 「여러 개 한 번에 찍자」 · 「옮기면 되지 비슷하지 않나요」.

## 하는 일
1. 대본: `입력/08_새대본_다시찍을판초안.md`는 이 PC 작성자가 다시 찍을 판으로 쓴 초안이다(독립 검토 전). 독립 적대 검토 1회(`입력/새대본검토의뢰.md` — 그리기 실습은 영상 V-15 그리기 문단 「왜 이렇게 그리나」가 주인공, 학생이 따라 적을 값 빠짐없이) → 목록 고침 → 사용자 확정. 참고: `입력/08_화면그대로판_검토.md`(옛 판 검토 36건) · `입력/08_다시찍기판정.md` · `입력/08_걸린곳.md` · `입력/08_지금낭독.json`. 초안의 물을 곳(견줄 사건 값 셋을 화면 아래 글상자로 띄울지)은 띄우는 쪽으로 한다 — 도구에 글상자가 없으면 도구에 넣는다(hyd-task 0-3).
2. 녹화 도구 옮기기: `arrows/촬영도구/`(ego — CDP screencast · 페이지 안 포인터 · 그리기 함수를 감싸 원 자리 기록)를 포털 클라우드 도구(`촬영/포털/촬영도구/`, Playwright headless Chromium)처럼 클라우드에서 돌게 옮긴다. 조작 층은 그대로 쓰고 브라우저를 여는 앞부분만 바꾼다. 시험 녹화 한 토막으로 검증한 뒤 본녹화.
3. 길뚫기 → 큐 JSON · 음성 견적(사용자 승인 뒤 구매, 영상 V-4) → 구간마다 녹화하고 바로 확인(화면대조 · measure · 끝 상태, 문제는 그 구간만 즉시 다시) → 합성 → 사용자 청취.
4. 같은 시각에 다른 클라우드 세션들이 포털 세 편을 찍는다(`근거/2026-11-12_통합1-06-포털-다시찍기/` · `…통합2-05-포털-다시찍기/` · `…통합1-04-포털둘러보기-다시찍기/`). 그 폴더와 큐 · 음성 파일은 건드리지 않고, 공용 도구를 고치면 커밋 전에 `git pull`로 겹침을 본다.
5. 빼는 것: 다른 실습 영상, 시스템 코드 변경.
