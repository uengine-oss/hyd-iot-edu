# 통합반 3회차 온라인 장 구성 검토

개편 전 판은 `0af4462b`의 74장이다. `6bfcc89a`에서 구 5장 「경보에서 조치까지의 세 질문」을 5장 「유온 경보 뒤의 핀 오염 진단」과 6장 「핀 오염 진단 뒤의 조치 선택」으로 나눴다. 앞 장에서는 팬 진동과 냉각 효율로 원인을 좁힌다. 뒤 장에서는 원격 모드와 정지 여유로 후보의 허용과 선택을 따로 판단한다. 온라인 실라버스 28행에서 두 사고 단계를 구분한다.

| 비교 | 확인 결과 |
|---|---|
| 개편 전 `0af4462b` → 온라인 마감 `c34a238b` | 74장 → 75장. 번호 이동을 맞춰 기존 장의 화면 내용(쪽번호 제외) 49장, 발표자 노트 52장 변경. 기존 71개 낭독 구획 중 53개 변경, 6장 낭독 1개 신설. 화면·노트·낭독 중 하나 이상 바뀐 기존 장 57장, 셋이 같은 기존 장 17장. 이 수치는 두 커밋 사이의 비교다. |
| 현재 이론 본문 | 총 56장. 1편 5~20장 16장, 2편 22~41장 20장, 3편 43~62장 20장. 69장은 고정 복습이다. 나머지 19장은 도입·간지·실습 소개·마무리다. |
| 수량 판단 기준 | 덱 지침 D-1·D-4·D-6. 실라버스 행별로 학생의 판단과 화면 근거를 대조한다. 26→27장은 경계의 등호에서 실제 단위 환산으로, 54→55장은 납기 조건의 영향에서 생산 속도별 완료 시각 계산으로 넘어간다. |

## 1편 19~20장

- **검토 지적.** 19장의 그래프와 20장의 표가 같은 관측값으로 완화 및 세척 완료 기준을 반복했다.
- **19장.** 승인선 전후의 유온과 냉각 효율 곡선을 같은 시각에 읽는다. 재관측 종료값과 기준 미만 구간의 비율을 구분한다. 점검 지시가 남은 사실까지 확인한다.
- **20장.** 학생이 교대일지 초안 “경보 해제”, “완화 성공”, “핀 세척 완료”를 한 줄씩 확인하고 고친다. 해제 이벤트, 두 조건의 15분 연속 이력, 세척 수행 기록과 재가동 후 냉각 효율은 서로 다른 서명 근거다. 18장의 조치 종류에서 19장의 관측으로, 20장의 인계 판단에서 2편의 결정표로 잇는다.
- **수정 후 확인.** 20장 오른쪽 열을 넓혀 ‘해제’와 ‘뒤’만 단독 줄로 남던 문제를 고쳤다. 데이터와 대본을 공식 PDF 19~20쪽에서 대조했다. 전체 75장 겹침 및 낱말줄 후보 0개. 1편 제작 설정은 본문 추정 26.93분, 혼합 낭독 27분 2.410초, 강조 63곳과 문장경계 275곳이다. [실행 명령과 장별 점검](../../구성/통합반/03회차/장별점검.md)
