### 확정된 편의 무료 확인 및 향후 제작 명령

저장소 루트(Bash)에서 시작한다. 출력은 편마다 별도 절대 경로다. `R`은 해당 PPTX의 기준 PDF와 150dpi 그림을 둘 작업 위치다.

```bash
B=workspace/강의제작
K="$B/제작도구/검사"
T="$B/제작도구/기존제작/tools/video"
G="$B/제작도구/구성/통합반/03회차"
F="$B/산출물/통합반/이론/03회차"
PPTX="$F/통합반_03일차.pptx"
EP=01  # 01 또는 02
case "$EP" in
  01) SCRIPT="$F/대본/01_이론_조치절차와수행기준.md"; RANGE=1-20 ;;
  02) SCRIPT="$F/대본/02_이론_판단규칙.md"; RANGE=21-41 ;;
  *) exit 1 ;;
esac
NAME="통합반_03회차_$(basename "$SCRIPT" .md)"
CFG="$G/강조_${NAME}.json"
V=1PdAOcPlPTz12RwMyFVp
WORK="$PWD/작업/통합반03_${EP}편_제작"
OUT="$WORK/영상출력/$EP/영상"
R="$WORK/렌더"
mkdir -p "$R" "$OUT"
python3 "$K/판본검사.py" 통합3
python3 "$T/강조좌표.py" --검사 "$SCRIPT" "$CFG"
python3 "$T/강의영상.py" "$OUT" "$SCRIPT" --breath --dry
python3 "$T/음성견적.py" "$SCRIPT" --voice "$V"
python3 "$T/쉼옮기기.py" "$SCRIPT" --장 "$RANGE" --파형 --voice "$V" --출력 "$WORK/쉼확인.json"
# 지정 렌더러 환경에서 150dpi 페이지 준비

pdftoppm -r 150 -png "$R/통합반_03일차.pdf" "$R/s"
```

### 이후 승인된 제작 단계


입력 검증을 마친 해당 편으로 유료 제작 승인과 누계 크레딧 상한이 정해진 시점에 사용한다. 같은 Bash에서 아래 준비 명령의 변수를 유지한다. `CAP`은 대표 구획을 포함한 승인 누계 상한이다. 음성을 채운 뒤 파형 검사가 통과해야 굽는다.

```bash
: "${CAP:?승인받은 누계 크레딧 상한을 CAP에 설정}"
LEDGER="$WORK/음성기록_${EP}.json"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$LEDGER" "$SCRIPT" --voice "$V" --한도 1 --상한 "$CAP"
# 대표 구획의 실제 지출을 기록한 뒤 나머지를 생성한다.
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$LEDGER" "$SCRIPT" --voice "$V" --상한 "$CAP"
python3 "$T/쉼옮기기.py" "$SCRIPT" --장 "$RANGE" --파형 --voice "$V" --출력 "$WORK/구매후_쉼확인.json"
```

구매 후 쉼 목록의 미저장·미생성·조용한 지점 누락이 모두 0인지 확인한다. 150dpi 페이지를 기준 PDF에서 만들었으면 `강의영상.py`가 바로 그 페이지를 사용하도록 덱별 폴더에 두고 최종 PPTX의 해시를 저장한다. 다음 블록의 R에는 이 PPTX를 기준 렌더한 PDF에서 150dpi로 뽑은 75장의 s-NN.png가 있어야 한다. 이 출력은 검사용 작업 폴더에 둔다.

```bash
IMG="$T/슬라이드/$(basename "$PPTX" .pptx)"
mkdir -p "$IMG"
cp "$R"/s-*.png "$IMG/"
python3 - "$PPTX" "$IMG/stamp" <<'PY'
from pathlib import Path
import hashlib, sys
pptx, stamp = map(Path, sys.argv[1:])
stamp.write_text(hashlib.sha256(pptx.read_bytes()).hexdigest(), encoding="ascii")
PY
python3 "$T/강의영상.py" "$OUT" "$SCRIPT" --breath --voice "$V" --audio-ledger "$LEDGER" --pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
VIDEO="$OUT/$NAME.mp4"
SIDE="$(dirname "$OUT")/_작업/영상_자막_기록"
python3 "$T/검사/말머리_잘림.py" "$VIDEO"
```
