# 코딩 랩 개편 — 스펙

상태: 진행 중 — 온톨로지 파트 VS Code 랩 12개 완성(2회차 넷 끝남, 남은 여덟)

## 의도 (사용자 지시, 2026-11-03)
학생이 VS Code 코딩 랩에서 다음을 얻게 한다.
1. 모범적인 AI 활용 코딩법(바이브 코딩 일곱 단계, 명세 주도 개발 등)을 몸으로 익힌다.
2. 「이런 것도 있구나」 하는 현업 현상과, 만드는 과정 자체를 제대로 경험한다.
3. 정답이 있어서 뚝딱 만들어지는 실습이 아니다 — 현업 수준 난이도, 장난감 · 해피패스 금지.
4. AI와 주고받는 상호작용이 풍부하고, 학생이 생각하고 판단할 거리가 있다.

두 기둥(확정): ① 현업 규모 자료와 주 질문 경로 위 결정 지점 ② 체계적 과정 — 작업 규칙(가드레일)이 통째 요청을 돌려보내고, 가이드는 한 가지 일씩 · 구현은 기능 하나씩, 프롬프트는 다섯 요소 힌트(값 없음, 기본 화면에 보임 — 토글로 숨기지 않음, K-111), 강사가 영상에서 AI와 대화하며 프롬프트를 짜는 과정을 보여 준다.
지금 랩(3회차 이후)은 임시판 — 실라버스 그 행에서 다시 만든다. 순서는 실라버스 사슬(앞 랩 결과를 뒤 랩이 읽는다).
