## 녹화 차례

Git Bash, 촬영도구 폴더. `<C>` = 촬영준비 길 1의 학생 역 CODEX_HOME.

```bash
./run.sh up
SEG=wg-01 ./run.sh reset wg-reset.mjs   # 지난 시험 대화는 먼저 보관(길 4). ZIP 그대로 · 새 대화 · 터미널 하나 · 지난 사본(_wg-*) 지움
# Codex 없는 구간: 리허설 → 되돌리기 → (그 구간 음성 구매) → 녹화 → 사본
[PAGE=1] ./run.sh dry wg02c-d1 wg-02c.mjs
SEG=wg-02c ./run.sh reset wg-reset.mjs
[PAGE=1] ./run.sh rec wg02c-r1 wg-02c.mjs wg02b-r1
SEG=wg-02c ./run.sh reset wg-save.mjs
# Codex 요청 구간: 보내기 직전까지만 리허설 → 되돌리기(입력칸 비움) → 녹화(실제 요청) → 사본
WG_NOSEND=1 ./run.sh dry wg03a-d1 wg-03a.mjs
SEG=wg-03a ./run.sh reset wg-reset.mjs
CODEX_HOME=<C> ./run.sh rec wg03a-r1 wg-03a.mjs wg02d-r1
SEG=wg-03a ./run.sh reset wg-save.mjs
# → timing.json의 result.answer와 Codex가 고친 파일로 FIND와 대본 「Codex 답에 맞출 큐」(사실만)를 맞추고, 다음 view 구간의 음성을 산다
```
