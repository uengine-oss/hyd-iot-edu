# 3 · 4회차 이론 영상 갱신(2026-11-03 · 04) — 근거

클라우드 세션 작업 폴더(`작업/`, 어느 브랜치에도 올리지 않음)에서 다시 쓸 재료와 판정 근거만 옮겨 둔 것이다(사용자 지시 「흔적을 남겨 두라」). 산출물 정본은 `workspace/강의제작/산출물/`(덱 · 대본 · 영상), 이 폴더는 그 판정 · 측정의 근거다.

- 먼저 볼 것: `완료보고.md`(결론 · DoD 1~26 · 남은 것), `기록.md`(진행 · 결정 · 함정).
- 시간: `행별시간.md`(실라버스 행별 배정 · 계획 · 실측), `장별점검.md`(네 덱 307장 실측 · 강조 · 까닭), `대조표/`(실라버스 문장 ↔ 장 · 자막).
- 판정: `인수전표.json`(17개 산출물, `인수검사.py`로 검사), `판정/`(검토자 판정 · 고친 항목 확인 `감독확인.json` · DoD 22 · 23 출력), `노션/`(게시 링크 · 전후 차이 확인), `강조뺀목록/`.
- 도구(이 작업 폴더 기준 경로로 썼다): `도구/전표만들기.py` · `장별점검_생성.py` · `입고.py` · `강조미리보기.py`, 의뢰서 `의뢰_영상검토.md` · `의뢰_강조모양.md`.
- 근거 경로 가운데 `작업/…` · 렌더 그림 · 영상 출력은 그 VM에만 있었다(올리지 않음).
