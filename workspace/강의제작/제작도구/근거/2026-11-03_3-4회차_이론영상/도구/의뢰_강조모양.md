# 강조 다시 고르기 의뢰서(덱 하나 = 작업자 하나, 한 번에 끝낸다)

서브에이전트 생성 금지(직접 읽고 직접 한다). fable 모델 금지. 커밋 · push 금지. 한국어로 쓴다. 저장소 루트 `/home/user/hyd-iot-edu`, 명령은 거기서 `python3`. `작업/…`은 `작업/2026-11-03_3-4회차-이론영상-갱신/`.

## 왜(사용자 결정)

강조 모양이 동그라미 · 글씨에서 **동그라미 · 띠(반투명 노란 형광펜) · 밑줄 · 네모 · 화살표 · 글씨**로 넓어졌다. 「말할 때 밑줄이라든지 각각 특색에 상황에 맞게」 — 모양은 그 순간 대본이 하는 말에 맞춘다. 동그라미만 쓰던 앞 판은 촘촘한 글줄에서 타원이 이웃 글자를 가로질러 많이 뺐고(네 덱 합 117개), 대본이 이미 위치를 말하는 곳에도 들어가 있었다(사용자: 「왜 저 부분 강조를 해야 하나요」). 한 번에 끝낸다 — 뒤에 검토자가 한 번 보고 고칠 것만 목록으로 준다.

## 먼저 끝까지 읽을 것

1. `workspace/강의제작/지침/영상.md` 전문(Read로 140줄씩 — 훅이 다 읽기 전에는 강조 파일 쓰기를 막는다). 특히 V요-40 「4-1」의 모양 표와 넣지 않는 곳, V-120 · V-121 · V-134.
2. 도구 머리말 `workspace/강의제작/제작도구/기존제작/tools/video/강조표시.py` 1~25줄(설정 꼴: 띠 · 밑줄 · 네모는 `"상자":[x1,y1,x2,y2]`, 화살표는 `"시작":[x,y]` · `"끝":[x,y]`, 동그라미는 `"중심"` · `"반지름"`, 글씨는 `"중심"` · `"글"` · `"크기"`). 밑줄은 상자 아래 변 7px 밑에 그어진다. 띠는 상자 전체를 칠한다.
3. 맡은 덱의 대본 전편(`workspace/강의제작/산출물/<과정>/이론/NN회차/대본/`).

## 입력

- 계획(무엇을 언제 짚나): `작업/<덱키>/강조계획.json` — 표시마다 「영상」 · 「장」 · 「문장」 · 「낱말」 · 「끝문장」 · 「대상」.
- 지금 판(동그라미만): `workspace/강의제작/제작도구/구성/<과정>/<NN>회차/강조_<영상 이름>.json`. 뺀 것: 통합3은 `작업/렌더/강조확인/통합3/뺀목록.txt`, 다른 덱은 계획에 있고 지금 판에 없는 것. 강조가 다 빠진 장에 감독이 적은 까닭 `작업/도구/장별까닭.json`(참고).
- 장 그림: `workspace/강의제작/제작도구/기존제작/tools/video/슬라이드/<과정>_<NN>일차/s-NN.png`(2000×1125, 영상은 1920×1080으로 줄여 쓴다 — 좌표는 1920×1080 기준, 비율 0.96).
- 미리보기: `python3 작업/2026-11-03_3-4회차-이론영상-갱신/도구/강조미리보기.py <장그림 폴더> <강조.json> <출력 폴더> [--장 5,8]` — 영상 도구와 같은 그리기 함수로, 장마다 모든 표시를 번호와 함께 그린다. 출력은 `작업/렌더/강조확인/<덱키>/5_모양/`.

## 할 일 — 계획의 표시 하나하나에 대해

1. **필요한가**(V-134 · 4-1 「넣지 않는 곳」): 말로만 위치를 찾기 어려운 곳 · 한 화면에서 설명 대상이 바뀌는 곳 · 비교할 값과 갈림길이면 남긴다. 대본이 「왼쪽 · 맨 위 · 첫 줄」처럼 위치를 말하고 칸이 둘뿐이라 바로 찾는 곳, 퀴즈처럼 답을 알려 주는 자리는 뺀다(까닭을 적는다). 뺐던 표시도 새 모양이면 깨끗하게 짚을 수 있는지 다시 본다.
2. **모양**(4-1 표): 화면 글을 그대로 읽거나 줄 · 행 하나를 짚으면 띠, 한 줄 안의 낱말 · 값 하나면 밑줄, 둘레가 빈 대상 하나(노드 · 점 · 막대 · 아이콘)면 동그라미, 칸 · 카드 · 상자 하나면 네모, 흐름 · 방향이나 둘레가 꽉 찬 대상이면 화살표, 화면에 없는 말을 몇 글자 더하면 글씨. 두 값을 견주면 같은 모양 둘로 짝을 맞춘다.
3. **좌표**: 미리보기로 그려 보고 고친다. 띠는 대상 글자를 위아래 4~8px 여유로 덮되 이웃 줄을 덮지 않는다. 밑줄은 글자 아래 끝을 상자 아래 변으로(밑줄이 다음 줄 글자에 닿지 않게). 네모는 칸 테두리 바로 바깥 · 안쪽 여백. 화살표는 빈 곳에서 시작해 촉 끝이 대상 바로 앞에서 멈추고 글을 가로지르지 않는다. 화면 안(0~1920 · 0~1080).
4. **때**: 「장」 · 「문장」 · 「낱말」은 바꾸지 않는다(음성 시각이 거기서 나온다). 같은 때 떠 있는 표시는 둘까지 — 「문장」~「끝문장」이 겹치는 표시가 셋 이상이면 앞 표시의 「끝문장」을 다음 대상이 시작되는 문장으로 당긴다. 「끝문장」은 그 장 구획 안, 「문장」보다 뒤의 대본 문장 그대로(문장 끝 부호까지)여야 한다 — 바꿨으면 대본 구획에서 글자 그대로 찾아 확인한다.
5. 영상마다 `workspace/강의제작/제작도구/구성/<과정>/<NN>회차/강조_<영상 이름>.json`을 새로 쓴다: {"표시":[{"장","문장","낱말","끝문장"(없으면 빼도 됨),"모양", 모양별 칸, "대상"}]} — 계획 순서 유지, 「영상」 · 「중심_어림」 · 「반지름_어림」 칸은 넣지 않는다.
6. 뺀 표시 목록을 `작업/렌더/강조확인/<덱키>/뺀목록.txt`에 새로 쓴다(이번 판에서 영상에 나오지 않는 계획 표시 전부, 한 줄 = `계획번호|편|장|대상|까닭`, 계획번호는 1부터. 까닭은 「말의 「…」로 찾을 수 있다」처럼 학생이 어디를 어떻게 찾는지 구체적으로). 통합3은 앞 판 뺀목록을 `뺀목록_동그라미판.txt`로 이름을 바꿔 둔다.
7. 미리보기를 전 장 한 번 다시 그려 모두 본다(한 번). 끝으로 python으로: 세 파일(통합4는 두 파일) 표시 수 + 뺀 수 = 계획 수, 모든 「문장」 · 「끝문장」이 그 장 구획 대본에 글자 그대로 있는지, 장마다 동시에 떠 있는 표시 최대 수 ≤ 2를 확인한다.

**하지 않는 것**: 대본 · 덱 · 계획 파일 · 다른 덱 파일 고치기, `강조표시.py` · `강의영상.py` 실행(감독이 돌린다 — 같은 컴퓨터에서 영상 굽기가 돌고 있다), 렌더(soffice), 커밋. `ps`에 보이는 굽기 프로세스를 건드리지 않는다.
