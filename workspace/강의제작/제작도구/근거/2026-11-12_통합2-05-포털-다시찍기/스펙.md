# 통합2-05-포털-다시찍기

- 시작: 2026-11-12 · 상태: 끝
- 상태는 `진행` · `중단` · `끝` 셋 가운데 하나다. 일이 끝나면 「끝」으로 바꾸고 `<py> workspace/동기화.py 정리 --실행`으로 이 폴더를 지운다(클라우드는 지운 것을 커밋한다).

## 의도
통합 2회차 실습 05 「지식지도탐색」(포털 지식 지도에서 설비 → 구성 요소 → 센서 → 상태 변수 · 부품을 따라가고 Neo4j 예제와 견줌)을 새 대본으로 **다시 찍는다**. 지금 게시본(15:00)의 말을 다른 세션이 쉼넣기용으로 모든 큐를 새로 썼지만, 음성을 어차피 다 새로 사야 하고 쉼넣기로는 말과 조작이 엇갈리므로 다시 찍는다(사용자 「2회차 포탈도 같이 … 다 해야 하는 거 아닌가요」 · 「여러 개 한 번에 찍자」). 사용자: 「다시 찍을 때 … 설명을 쉽게 최대한 쉽게 … 어색한 표현 없고 원테이크로 … 줄줄 하나의 실 … 진짜 다시 찍는 거만큼 대본에 맞게 완벽하게」 · 「원래는 행위로만 해서 그렇지 설명을 하면서 … 자연스럽게」 · 「이번 촬영은 리스크 없이 완벽한 버전이어야 한다 … 이슈 있는데 놓쳐서 막 다시 찍고 그런 거는 없이 부드럽고 사람이 사용하는 것처럼 자연스럽게」.

## 하는 일
1. 대본: `입력/05_새대본_화면그대로판.md`(쉼넣기용 — 큐마다 옛 조작 자리 제약)를 제약 없이 **다시 찍을 판**으로 다시 쓴다. 꼴은 본보기 `입력/본보기_Notion_다시찍을판_확정.md`. `입력/05_걸린곳.md`의 화면 지적 · 첫 장면이 앞 실습(2회차 04 Neo4j)의 끝과 이어지는지 · 지식 지도의 실제 이름 · 값은 포털에서 다시 확인한다.
2. 독립 적대 검토 1회(`입력/새대본검토의뢰.md`) → 목록 고침 → 사용자 확정(최종본 파일 · 전후 비교 · 물을 곳).
3. 길뚫기(포털 촬영준비 「길」 클라우드) → 큐 JSON · 음성 견적(사용자 승인 뒤 구매, 영상 V-4) → 구간마다 녹화하고 바로 확인(화면대조 · measure · 끝 상태, 문제는 그 구간만 즉시 다시) → 합성 → 사용자 청취.
4. 빼는 것: 다른 실습 영상, 시스템 코드 변경(촬영을 막는 포털 결함은 따로 보고).
