# Notion 촬영준비

1회차 Notion 주제 갤러리(학습노트)를 이 PC의 ego로 찍는다(Notion 로그인이 필요해 클라우드에서는 찍을 수 없다). 명령은 Git Bash에서 [촬영도구/](촬영도구/)를 현재 위치로 두고 실행한다(`build.py`만 이 폴더에서). 파이썬은 `PYTHONUTF8=1 python`이고 PIL이 필요하다. 경로 값은 [config.json](촬영도구/config.json)에 있다. 규칙은 [영상](../../../지침/영상.md), 여러 도구 공통은 [README](../README.md)에 있다.

## 길

1. 확인 — 셋을 확인한다. ego lite와 Notion에 로그인돼 있다(사용자가 한다). config의 `work` 폴더와 `audio` 폴더가 있다(없으면 이어 찍기, `encode.py`, `build.py`가 돌지 않는다). 녹화 탭이 앞에 보인다.
2. 큐와 음성 — 큐는 구간 모듈 [segs/seg-25~39.mjs](촬영도구/segs/)의 `c.say('<큐 id>')` · `c.source(…)` · `c.line(…)`가 [source-cues.json](촬영도구/source-cues.json)에서 불러 쓴다. 새 문장은 [voice-jobs.json](촬영도구/voice-jobs.json)에 넣는다.
   ```bash
   PYTHONUTF8=1 python voice.py        # 새 큐만(audio 옆 음성내용검수/음성수정안.json이 있어야 돈다)
   PYTHONUTF8=1 python check-cues.py   # 끝 줄 'all cues have audio'가 아니면 녹화하지 않는다
   ```
3. 시작 상태 — 이어 찍을 때는 `run.sh rec`에 앞 구간 이름을 준다(그 구간 `end-state.json`의 페이지를 열고 화살표를 그 자리에 둔다). 녹화 밖에서 상태를 맞출 때는 실행 취소를 쓰지 않고 `./run.sh restore <종류>`를 쓴다. 종류는 다음과 같다.
   - `cut25`: 구간25의 3:05 직전 상태. 안내 상자 블록을 지우고, 소개 아래 빈 줄에 캐럿을 둔다.
   - `noteTail`: 구간25 끝 상태. 상자 글 끝에 캐럿을 둔다.
   - `cut27`: 구간27의 57.0s 직전 상태. 하위 페이지 「첫 페이지 꾸미기」를 휴지통으로 보내고, 「나의 페이지」 제목 아래에 캐럿을 둔다.
   - `reload`(업데이트 막대 제거, 상태 경계에서만 쓴다), `state`(읽기만 한다).
   - 처음부터 찍을 때는 `restore trashPage`(촬영 페이지를 하위 페이지째 휴지통으로 보낸다). Notion 휴지통으로 옮기는 일이므로 사용자에게 먼저 묻는다.
4. 찍기 — 구간마다 시작 상태 확인 → 녹화 → 끝 상태 저장 → 실측, 이 순서로 한다.
   ```bash
   ./full.sh n                                     # 처음부터: take-n25(새 촬영 페이지) → config page 바꿈 → n26 … n39
   ./chain.sh <앞 구간[:자른ms]> <번호 또는 이름:모듈> …   # 예: ./chain.sh take-37 37b:seg-37b.mjs 38 39
   ./run.sh rec <이름> <모듈> [앞 구간 | 앞 구간:자른ms | '{x:..,y:..}']
   ./run.sh measure <이름>
   ```
   `chain.sh`는 녹화 오류가 나거나, 오류 막대나 업데이트 막대가 찍힌 프레임이 있으면 멈춘다. `full.sh`는 거기에 더해 0.5초 넘는 끊김이 3회 이상이면 멈춘다. 실패한 조각에서 이어 찍을 때는 `<이름>:<자른ms>`를 주어 자른 시각의 화살표 위치에서 시작하고, 화면도 그 시점으로 맞춘다. 실행을 멈추게 하려면 `work`에 `STOP` 파일을 만든다.
5. 합성 — 조각 목록과 자르는 위치를 명령 인자로 남긴다(지금 판: `take-n25 take-n26:69268 take-n26b take-n27 … take-n38 take-n39:73207 take-n39c`).
   ```bash
   PYTHONUTF8=1 python encode.py Notion_학습노트_v11 take-n25 take-n26:69268 take-n26b … take-n39:73207 take-n39c
   ```
   다음 중 하나라도 있으면 멈춘다: 오류로 끝난 take를 자를 위치 없이 줌, 문장 중간 절단, 음성 겹침, 끝 시각이 0.1초 넘게 차이 남.
6. 연결 산출물 — 이 폴더에서 `PYTHONUTF8=1 python build.py`를 돌린다. `verification.json`, 음성 캐시, 수업원고, 행동목록을 읽어 두 과정의 대본, 가이드, ZIP, `정적검사.json`을 만든다.
7. 조각 고침 — 조각 하나를 고치려면 3의 시작 상태에서 다시 찍고, 5의 목록에서 그 이름만 바꾼다. 말만 틀렸으면 그 문장의 음성만 다시 만들어 `VOICE_OVERRIDES=<JSON>`(`[{segment, time, file}]`)으로 넣는다. 새 음성은 원래 문장의 끝에 맞춰 오른쪽 정렬되고, 원래보다 길면 멈춘다.

## 함정

- 작업 화면이 위 막대를 숨긴 채 열린다. 안내 문장을 말하는 동안 커서를 왼쪽 위로 옮겨, 막대가 나타나면 누른다(`seg-25.mjs`).
- 「새 페이지」를 누르거나 Enter로 상자를 빠져나오는 조작이 한 번에 먹지 않는다. 반영됐는지 확인하고 한 번 더 한다(`reclicks.jsonl`).
- 제목을 바꿀 때 End → Shift+Home이 일부만 선택한다. 제목을 마우스로 끌어 선택하고, 선택을 확인한 뒤 입력한다(`replaceTitle`).
- 블록 메뉴의 이름이 블록마다 다르다. 글 블록은 「삭제」, 하위 페이지 블록은 「휴지통으로 이동」이다. 화면 밖 블록은 손잡이가 나오지 않으니 휠로 가운데에 들인 뒤 다룬다.
- 하위 데이터가 있는 페이지에서는 페이지 메뉴의 「휴지통으로 이동」이 반응하지 않는다. 사용자 승인을 받은 뒤 Notion 커넥터로 옮긴다. 복원은 그 페이지의 「페이지 복원」으로 한다(개인 최상위 페이지는 API로 복원할 수 없다).
- 녹화 중에 Notion이 새 버전을 배포하면 「최신 버전으로 업데이트」 막대가 본문을 약 80px 민다. 녹화 전에 막대가 보이면 멈추고(ctrl), 상태 경계에서 `restore reload`를 쓴다. 막대의 링크가 화면 끝에 있으면 휠로 들인 뒤 누른다.
- Notion 서비스 장애 문구가 찍혔다. 공식 상태 페이지를 보고, 그 부분만 다시 찍는다.
- 구간 경계마다 Notion 화면이 다시 배치된다(ego가 스크립트 끝에 화면 크기를 풀고, 다음 구간이 다시 걸 때 생긴다). 구간들을 한 ego 실행 안에서 잇는 실행기가 필요하지만 아직 없다.
