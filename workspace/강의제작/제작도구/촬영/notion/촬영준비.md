# Notion 촬영준비

1회차 Notion 주제 갤러리(학습노트)를 이 PC ego로 찍는다(로그인이 필요해 클라우드 불가). Git Bash, [촬영도구/](촬영도구/)에서(`build.py`만 이 폴더), `PYTHONUTF8=1 python`(PIL 필요). 경로 값은 [config.json](촬영도구/config.json). 규칙은 [영상](../../../지침/영상.md), 공통은 [README](../README.md).

## 길

1. 확인 — ego lite · Notion 로그인(사용자), config `work` · `audio` 폴더가 있다(없으면 이어 찍기 · `encode.py` · `build.py`가 안 돈다), 녹화 탭이 앞에 보인다.
2. 큐 · 음성 — 큐는 구간 모듈 [segs/seg-25~39.mjs](촬영도구/segs/)의 `c.say('<큐 id>')` · `c.source(…)` · `c.line(…)`가 [source-cues.json](촬영도구/source-cues.json)에서 부른다. 새 문장은 [voice-jobs.json](촬영도구/voice-jobs.json)에.
   ```bash
   PYTHONUTF8=1 python voice.py        # 새 큐만(audio 옆 음성내용검수/음성수정안.json이 있어야 돈다)
   PYTHONUTF8=1 python check-cues.py   # 끝 줄 'all cues have audio'가 아니면 녹화하지 않는다
   ```
3. 시작 상태 — 이어 찍기는 `run.sh rec`에 앞 구간 이름(그 `end-state.json`의 페이지를 열고 화살표를 그 자리에). 녹화 밖에서 맞출 때는 실행 취소 없이 `./run.sh restore <종류>`: `cut25`(구간25 3:05 직전 — 안내 상자 블록 삭제, 소개 아래 빈 줄 캐럿) · `noteTail`(상자 글 끝 캐럿, 구간25 끝) · `cut27`(구간27 57.0s 직전 — 하위 페이지 「첫 페이지 꾸미기」 휴지통, 「나의 페이지」 제목 아래 캐럿) · `reload`(업데이트 막대 제거, 상태 경계에서만) · `state`(읽기 전용). 처음부터는 `restore trashPage`(촬영 페이지를 하위째 휴지통 — Notion 휴지통 이동이라 **사용자에게 묻는다**).
4. 찍기(구간마다 시작 상태 확인 → 녹화 → 끝 상태 저장 → 실측):
   ```bash
   ./full.sh n                                     # 처음부터: take-n25(새 촬영 페이지) → config page 바꿈 → n26 … n39
   ./chain.sh <앞 구간[:자른ms]> <번호 또는 이름:모듈> …   # 예: ./chain.sh take-37 37b:seg-37b.mjs 38 39
   ./run.sh rec <이름> <모듈> [앞 구간 | 앞 구간:자른ms | '{x:..,y:..}']
   ./run.sh measure <이름>
   ```
   `chain.sh`는 녹화 오류 · 오류/업데이트 막대 프레임에서, `full.sh`는 거기에 0.5초 넘는 끊김 3회 이상에서 멈춘다. 실패 조각에서 이을 때는 `<이름>:<자른ms>`로 자른 시각의 화살표에서 시작하고 화면도 그 시점으로 맞춘다. 멈추게 하려면 `work`에 `STOP` 파일.
5. 합성 — 조각 목록과 자르는 위치를 인자로 남긴다(지금 판: `take-n25 take-n26:69268 take-n26b take-n27 … take-n38 take-n39:73207 take-n39c`).
   ```bash
   PYTHONUTF8=1 python encode.py Notion_학습노트_v11 take-n25 take-n26:69268 take-n26b … take-n39:73207 take-n39c
   ```
   오류 take를 자른 위치 없이 줌 · 문장 중간 절단 · 음성 겹침 · 끝 시각 0.1초 넘는 차이면 멈춘다.
6. 연결 산출물 — 이 폴더에서 `PYTHONUTF8=1 python build.py`(`verification.json` + 음성 캐시 + 수업원고 · 행동목록 → 두 과정 대본 · 가이드 · ZIP · `정적검사.json`).
7. 조각 고침 — 조각 하나는 3의 시작 상태에서 다시 찍어 5의 목록에서 그 이름만 바꾼다. 말만 틀리면 그 문장만 다시 만들어 `VOICE_OVERRIDES=<JSON>`(`[{segment, time, file}]`, 원래 문장 끝에 오른쪽 정렬, 길면 멈춤).

## 함정

- 작업 화면이 위 막대를 숨긴 채 열림 → 안내 문장 동안 커서를 왼쪽 위로 옮겨 막대가 나타나면 누른다(`seg-25.mjs`).
- 「새 페이지」 · Enter로 상자 빠져나오기가 한 번에 안 먹음 → 반영을 확인하고 한 번 더(`reclicks.jsonl`).
- 제목 바꾸기 End → Shift+Home이 일부만 선택 → 제목을 마우스로 끌어 선택하고 확인 뒤 입력(`replaceTitle`).
- 블록 메뉴 이름이 다르다 → 글 블록 「삭제」, 하위 페이지 블록 「휴지통으로 이동」. 화면 밖 블록은 손잡이가 안 나옴 → 휠로 가운데에 들인 뒤.
- 페이지 메뉴 「휴지통으로 이동」이 하위 데이터가 있는 페이지에서 반응 없음 → 사용자 승인 뒤 Notion 커넥터로. 복원은 페이지의 「페이지 복원」(개인 최상위 페이지는 API 복원 불가).
- 녹화 중 Notion이 새 버전을 배포하면 「최신 버전으로 업데이트」 막대가 본문을 약 80px 민다 → 녹화 전에 보이면 멈춤(ctrl), 상태 경계에서 `restore reload`, 링크가 화면 끝이면 휠로 들인 뒤 누른다.
- Notion 서비스 장애 문구가 찍힘 → 공식 상태를 보고 그 부분만 다시.
- 구간 경계마다 Notion이 다시 배치된다(ego가 스크립트 끝에 화면 크기를 풀고 다음 구간이 다시 걸 때) → 구간들을 한 ego 실행 안에서 잇는 실행기가 필요하다(아직 없음).
