# 웹 VS Code 촬영준비

코딩 랩 · VS Code 장면을 공식 `code serve-web`으로 띄운 웹 VS Code를 이 PC ego 탭에서 찍는다(클라우드 불가). 서버는 저장소 루트 PowerShell, 음성 · 녹화 · 합성은 Git Bash [촬영도구/](촬영도구/). 규칙은 [영상](../../../지침/영상.md), 공통은 [README](../README.md).

## 길

1. 서버 — 8793에 다른 서버가 있으면 멈추고, 비어 있을 때만 같은 판본 · 포트 · 데이터로 켠다(PowerShell):
   ```powershell
   $r = (Resolve-Path '작업/2026-11-02_1회차-학생가이드-현행화/2회차_실습영상대조/독립촬영/v143').Path
   $commit = 'e646868227c3e3a9e3f24277c8c7220be42c0be7'
   $listener = Get-NetTCPConnection -LocalPort 8793 -State Listen -ErrorAction SilentlyContinue
   if ($listener) {
       $server = Get-CimInstance Win32_Process -Filter "ProcessId=$($listener.OwningProcess)"
       if ($server.Name -ne 'code-tunnel.exe' -or !$server.CommandLine.Contains($r) -or !$server.CommandLine.Contains($commit)) { throw '8793을 다른 서버가 사용 중' }
   } else {
       if (!(Test-Path "$r/access.txt" -PathType Leaf) -or !(Test-Path "$r/data/extensions/extensions.json" -PathType Leaf)) { throw '접속 파일 · 확장 프로필 확인' }
       $exe = Join-Path $env:LOCALAPPDATA 'Programs/Microsoft VS Code/bin/code-tunnel.exe'
       Start-Process -FilePath $exe -WindowStyle Hidden -ArgumentList "serve-web --commit-id $commit --host 127.0.0.1 --port 8793 --connection-token-file `"$r\access.txt`" --cli-data-dir `"$r\cli`" --server-data-dir `"$r\data`" --disable-telemetry --accept-server-license-terms"
   }
   ```
2. Codex 확장(사라졌을 때만) — 조합은 웹 VS Code 1.143.1 · 화면 확장 26.422.71525 · 실행 엔진 26.1021.22027(Windows). `& "$r/cli/serve-web/$commit/bin/code-server.cmd" --server-data-dir "$r/data" --install-extension openai.chatgpt@26.422.71525 --force`, 사용자 설정(JSON)의 `chatgpt.cliExecutable`에 `$r/app-server-26.1021.22027/codex.exe` 절대 경로(`/` 구분). 엔진 폴더를 잃으면 VSIX의 `extension/bin/windows-x86_64/` 전체를 그 자리에(VSIX는 `작업/_로컬/VSCode웹복구/`). 고친 뒤 같은 탭 새로고침.
3. 폴더 열기 — 학생처럼 ZIP을 `D:/HYD-Practice/<id>-<uuid8>`에 풀고 `http://127.0.0.1:8793/?tkn=<access.txt 값>&folder=` + `encodeURIComponent('/D:/...')`. 토큰 값은 로그 · 화면에 남기지 않는다. 신뢰는 상태 표시줄 Restricted Mode → 맨 위 `Trust` 글자를 좌표로 클릭, 판정은 `.statusbar-item`으로만. Welcome 닫기 `.tab .tab-actions .action-label`, 미리보기 탭 고정은 dblclick 이벤트 발송(ego에 `mouse.dblclick` 없음).
4. Codex · 터미널 — 오른쪽 Codex 탭(새 프로필 안내는 Next → Continue with current model), 촬영 전 새 대화. 복구 직후에만 짧은 질문 하나로 답이 오는지 본다. 터미널은 편집기 클릭 → `Control+Backquote` → `python --version`(Python 3.14.7). 웹판 표시 언어는 영어, 대사는 「왼쪽 탐색기(Explorer)」처럼 둘을 함께.
5. 음성 — `PYTHONUTF8=1 python voice.py [<큐 파일>]`(기본 `voice-jobs.json` — 지금 없으니 만든다, 동시 3개). 큐 파일 `*_큐.json`은 `id` · `segment` · `text`. 음성이 없으면 녹화가 「Voice cue missing」으로 멈춘다.
6. 찍기 — 구간 모듈 `segs/<이름>.mjs`(`vscode(ctx)`로 조작 층, `ctx.say(큐id, 조작, {at:'대사 속 구절'})`):
   ```bash
   ./run.sh rec <이름> <모듈> [앞 구간 | '{x:..,y:..}']
   SPACE=<녹화 공간> VP='{width:1536,height:864,dsf:1.5}' ./run.sh rec …   # 포털 구간(앞 구간 URL로 되돌아가지 않음)
   ./run.sh measure <이름>
   ```
   VS Code 구간과 포털 구간은 다른 ego 공간에서, 녹화 공간은 리허설 공간과 겹치지 않게. Codex 채팅은 웹뷰 iframe이라 `.part.auxiliarybar` 영역 비율 좌표로 누른다. 사용자가 넣은 결과는 실습 폴더 파일로 읽는다.
7. 합성 · 검사 — `FFMPEG=<ffmpeg> PYTHONUTF8=1 python encode.py <출력> <구간[:ms]> …`(문장 겹침 · 음성 교체 길이 초과면 멈춤) → `python ../../포털/촬영도구/verify.py <영상> <자막> [<폴더>]` · `scenes.py <영상> 3`.
8. 조각 고침 — 그 구간만 새 take 이름으로(`p22-2` → `p22-2b`) 앞 구간 끝 포인터에서 찍고, `encode.py` 인자에서 그 이름만 바꾼다.
9. Codex 요청 구간(첫 코딩 랩에서 처음 시험, 미검증) — 요청 입력 · 전송 → 응답 진행 · 편집 승인(`결과/` 아래만 Allow once)을 한 흐름으로 찍는다 → 끝난 응답 · 바뀐 파일 · 실행 출력을 DOM 글과 파일로 읽고 「결과 확인」 큐를 쓴 뒤 그 음성을 만든다 → 결과 확인 구간은 Codex를 다시 부르지 않고 이미 있는 응답을 굴려 보며 결과 파일 · 원자료를 연다. 첫 랩만 [시작 안내](../../실습시작/index.html)의 `실습시작.cmd`(과정 → 회차 → 실습 → 「새로 시작」)로 폴더가 열리는 조작을 짧게 보이고, 시작 도구가 여는 가이드는 띄우지 않는다.
10. 가이드 사진(영상 밖) — 같은 결과 파일을 네이티브 한국어 VS Code에서 computer use(보기 · 클릭)로 캡처한다.

## 함정

- 네이티브 VS Code에는 computer use가 `click` 등급뿐이라 입력할 수 없고, CDP 입력은 같은 제한의 우회라 쓰지 않는다 → serve-web + ego.
- Git Bash에서 띄우면 Codex가 `CODEX_HOME ... does not exist` → PowerShell에서 띄운다.
- 상대 경로 토큰 파일은 서버가 못 읽는다 → 절대 경로. 8765는 실습 시작 도구 포트와 겹친다.
- 폴더 복사로는 확장이 등록되지 않는다 → `--install-extension`.
- Codex 탭이 `The extension could not start its user interface`로 끝나거나 대화가 막힘 → 2의 화면 · 엔진 조합과 사용자 설정.
- `D:/...`를 그대로 넣으면 `C:\work\...`가 열린다 → `encodeURIComponent('/D:/...')`.
- 신뢰가 안 눌림(가려진 같은 이름 버튼 · Ctrl+Enter · Machine 설정 무효) → 맨 위 `Trust` 글자 좌표. 신뢰 창이 떠 있으면 캡처가 안 된다. 본문의 「Restricted Mode」 글에 신뢰 판정이 속는다 → `.statusbar-item`만.
- 1920×1080 metrics는 CSS 1280×720이라 패널이 답답 → 2304×1296.
- 웹판 한국어 팩(1.131)이 1.143과 안 맞아 글자가 엉뚱하게 바뀐다(「Welcome」→「새 터미널(&&N)」) → 웹판은 영어, 되돌리기는 localStorage의 nls · locale 키 삭제 뒤 새로고침.
- 한 공간을 리허설과 같이 쓰면 탭 앞뒤가 바뀌어 캡처가 빈다 → 녹화 공간을 따로.
- Docker + WSL로 여유 메모리 2 GB → 경고만, `measure.py` 프레임 간격으로 판정.
- 메뉴 클릭이 대사 끝까지 밀림 → `{at:'구절'}`. 두 번째 클릭이 앞 문장 끝에 같이 일어남 → 큐를 나눈다. 포털 「다시 계산」 클릭이 빗나감 → 「화면 안」은 본문 실제 높이 비율로(`segs/p31-common.mjs` `p.show`), 굴릴 때 화살표를 옮기지 않는다.
- 기본 앱으로 HTML 열기에서 시작 도구가 한 번 멈췄다 → 10초 제한 별도 프로세스와 수동 경로 안내를 넣음(실제 GUI 재확인은 남음).
