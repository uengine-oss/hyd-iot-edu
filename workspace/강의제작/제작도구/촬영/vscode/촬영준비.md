## 1. 바로 가는 길 — 웹 VS Code와 ego로 실습 재개

공식 `code serve-web`(같은 워크벤치, 확장 호스트·터미널은 이 PC에서 실행)을 ego 탭으로 열어 기존 ego 촬영 리듬을 그대로 쓴다. 이 길로 0절의 다섯 편(구간 `p22-*` · `p31-*` · `p33-*` · `i22-*` · `i31-*`)을 찍었다. 근거 폴더는 3절.

### 1-1. 2회차 서버에 다시 들어가기

이 PC의 제작자 리허설은 ego 공간 15 **HYD 2회차 실습 전용 20261102**의 웹 VS Code 탭(`127.0.0.1:8793`)에서 이어 간다. 학생 가이드에서 연 랩 폴더(4-2)를 이 탭에서 사용한다. 탭만 닫혔다면 1-3의 주소로 돌아간다.

PC를 재부팅했거나 연결이 끊겼을 때는 **저장소 루트의 제작자 PowerShell**에서 아래를 실행한다. 기존 서버가 있으면 프로세스와 프로필만 확인한다. 비어 있을 때만 같은 판본·포트·데이터로 서버를 켠다.

```powershell
$r = (Resolve-Path '작업/2026-11-02_1회차-학생가이드-현행화/2회차_실습영상대조/독립촬영/v143').Path
$commit = 'e646868227c3e3a9e3f24277c8c7220be42c0be7'
$listener = Get-NetTCPConnection -LocalPort 8793 -State Listen -ErrorAction SilentlyContinue
if ($listener) {
    $server = Get-CimInstance Win32_Process -Filter "ProcessId=$($listener.OwningProcess)"
    if ($server.Name -ne 'code-tunnel.exe' -or !$server.CommandLine.Contains($r) -or !$server.CommandLine.Contains($commit)) {
        throw '8793을 다른 서버가 사용 중입니다. 프로세스와 작업 폴더를 확인하세요.'
    }
    '2회차 서버 실행 중'
} else {
    if (!(Test-Path "$r/access.txt" -PathType Leaf) -or !(Test-Path "$r/data/extensions/extensions.json" -PathType Leaf)) {
        throw '기존 접속 파일과 확장 프로필을 먼저 확인하세요.'
    }
    $exe = Join-Path $env:LOCALAPPDATA 'Programs/Microsoft VS Code/bin/code-tunnel.exe'
    $argsWeb = "serve-web --commit-id $commit --host 127.0.0.1 --port 8793 --connection-token-file `"$r\access.txt`" --cli-data-dir `"$r\cli`" --server-data-dir `"$r\data`" --disable-telemetry --accept-server-license-terms"
    Start-Process -FilePath $exe -ArgumentList $argsWeb -WindowStyle Hidden
}
```

### 1-2. Codex 확장 복구(설치나 설정이 사라졌을 때만)

2회차에서 확인한 조합은 **웹 VS Code 1.143.1**, **화면 확장 26.422.71525**, **공식 26.1021.22027의 Windows 실행 엔진**이다. 화면 확장은 `$r/data/extensions/extensions.json`의 `openai.chatgpt` 항목에서 `version`과 `metadata.pinned = true`를 확인할 수 있다. 확장이 사라졌을 때만 1-1의 서버와 데이터 경로에 설치한다.

```powershell
& "$r/cli/serve-web/$commit/bin/code-server.cmd" --server-data-dir "$r/data" --install-extension openai.chatgpt@26.422.71525 --force
```

실행 엔진은 `$r/app-server-26.1021.22027/codex.exe`다. 브라우저 프로필의 **Preferences: Open User Settings (JSON)**에서 `chatgpt.cliExecutable`에 이 파일의 절대 경로를 지정한다(JSON에서는 경로 구분자로 `/` 사용). 엔진 폴더를 잃었으면 26.1021.22027 VSIX 안의 `extension/bin/windows-x86_64/` **내용 전체**를 그 자리에 복원한다. 화면용·엔진용 공식 VSIX는 두 판본 모두 이 PC 저장소의 `작업/_로컬/VSCode웹복구/`에 보관했다. 설정 변경 뒤에는 **같은 탭**을 새로고침하고 1-4에서 연결을 확인한다.

### 1-3. 실습 폴더 열기 · 신뢰 · 탭 정리

1. 학생 동선과 같게 ZIP을 `D:/HYD-Practice/<id>-<uuid8>`에 풀고 serve-web 주소로 연다.
2. 2회차 주소는 `http://127.0.0.1:8793/?tkn=<파일값>&folder=` + `encodeURIComponent('/D:/...')`이다. 도구가 `$r/access.txt`를 읽어 접속하고, `$r/student-path.txt`에 적힌 학생 절대 경로의 역슬래시를 `/`로 바꿔 드라이브 앞에 `/`를 붙인다. 토큰 값은 로그·인계문·화면에 남기지 않는다.
3. 신뢰: 상태 표시줄 Restricted Mode → 신뢰 창에서 실제 맨 위 요소인 `Trust` 텍스트를 좌표로 클릭. 신뢰는 `.statusbar-item`의 Restricted Mode로만 판정
4. 탭 정리: Welcome 닫기 = `.tab .tab-actions .action-label`. 미리보기 탭 고정은 dblclick 이벤트 발송(ego `mouse.dblclick` 없음).

### 1-4. Codex 준비

실습 대화는 오른쪽 **Codex** 확장 탭에서 진행한다. 아래 Terminal은 Python 등 랩 명령을 실행할 때 연다. 이 PC에서는 기존 ChatGPT 로그인을 사용했다. 새 프로필에서 시작 안내가 나오면 Next로 진행하고 모델 안내는 **Continue with current model**을 누른다. 복구 직후에만 파일·도구 사용이 필요 없는 짧은 질문을 한 번 보내 같은 패널에 답변이 표시되는지 확인한다. 촬영 시 모델 표시 기준은 3절을 확인하고, 촬영 전 새 대화를 열어 화면에 개인 대화 제목이 나오지 않게 한다(V-79).

### 1-8. 음성 만들기(녹화 전)

ElevenLabs만 쓴다. OpenAI 음성은 쓰지 않는다. 값(목소리 ID · 모델 · 설정)은 3절이고 [voice.py](촬영도구/voice.py)에 박혀 있다(도구 기본값을 바꾸지 않는다). 키는 환경변수 `HYD_ELEVENLABS_KEY_FILE`이 가리키는 파일에서만 읽고 출력하지 않는다(설정 예는 3절).

```bash
# Git Bash, 촬영도구/ 에서
PYTHONUTF8=1 python voice.py [<큐 파일, 촬영도구/ 기준>]   # 기본 voice-jobs.json. 같은 문장이 캐시에 있으면 다시 만들지 않는다
```

결과는 음성 캐시(`config.json` `audio`)의 `<큐id>.mp3` · `<큐id>.json`(text, duration_ms). 녹화의 `ctx.say(큐id)`는 이 캐시를 읽으므로 음성이 없으면 「Voice cue missing (생성 후 촬영)」으로 멈춘다 — 음성을 먼저 만든다. 이 폴더의 큐 파일(`*_큐.json`)은 `id` · `segment` · `text` 꼴이다. 촬영 전 길이 예상은 `python ../../시간계산.py estimate <큐 파일>`.

### 1-9. 찍기(구간 하나씩)

녹화 도구: `workspace/강의제작/제작도구/촬영/vscode/촬영도구/` — Notion 촬영도구(`ctrl.mjs`·`run.sh`·`chain.sh`·`voice.py`·`encode.py`·`measure.py`·`common.py`)를 복사해 Notion 전용 검사(업데이트 막대·검수 음성·restore)만 뺐다. `ui.mjs`는 v10 포인터·이동·gate를 그대로 옮기고 VS Code 조작(`clickSel`·`explorer`·`tab`·`codexInput`·`type`·`key`·`terminalOpen`)을 더했다. Codex 채팅은 웹뷰 iframe이라 `.part.auxiliarybar` 영역 비율 좌표로 누른다. 구간 모듈은 `segs/<이름>.mjs`(ctx를 받아 `vscode(ctx)`로 조작 층을 만들고 `ctx.say(큐id, 조작)`). 실전 2-2에서 `ui.mjs`에 `menuItem`(그림자 루트 포함 문맥 메뉴)·`explorerRow(이름, aria-level)`·`lineEnd`·`typeFast`·`scrollTo`·`selectValue`를 더했다.

```bash
# Git Bash, 촬영도구/ 에서 (run.sh 머리말 그대로)
./run.sh rec <이름> <구간 파일(segs/ 기준)> [앞 구간 이름 | '{x:..,y:..}']        # 구간 하나 녹화 → 실측. 앞 구간 끝 포인터에서 시작
SPACE=<ego 작업 공간> VP='{width:1536,height:864,dsf:1.5}' ./run.sh rec …       # VS Code 밖 화면(포털). 앞 구간 URL로 되돌아가지 않는다
./run.sh measure <이름>                                                        # 녹화 하나 다시 실측
```

- ego: 설치된 `ego-browser skill` 출력도 끝까지 읽는다(API는 설치 버전이 우선). ego lite 설치 · 로그인은 사용자가 한다.
- `run.sh`가 하는 일: `ctrl.mjs` · `ui.mjs` · `segs/*.mjs`를 `node --check`(ego는 문법 오류에 조용히 멈춘다), 다른 `ego-browser.exe`가 떠 있으면 시작하지 않음, 실행 스크립트를 UTF-8 `.mjs`로 쓰고 `ego-browser nodejs -e "await import('file:///<절대경로>.mjs')"`를 `< /dev/null`로 부름(같은 주소는 다시 실행되지 않아 실행마다 새 파일), 시간 초과(`TMO`초, 기본 900)면 ego NodeService만 정리, 끝나면 `measure.py`.
- 작업 공간: VS Code 구간과 포털 구간을 서로 다른 ego 공간에서 찍는다(이름은 3절). `SPACE`가 있으면 resumeUrl 생략. 같은 작업은 같은 공간을 쓰고, 다른 세션과 같은 공간 · 페이지를 동시에 조작하지 않는다. 사용자 마우스 · 키보드 · 전경 창은 쓰지 않는다.
- 캡처: 녹화는 `Page.startScreencast`로 프레임을 받는 즉시 저장 · ACK하며, 앞에 보이는 탭에서만 프레임이 온다 — ego 창은 최소화하지 말고, 그 창 안에서 작업 탭이 앞 탭이어야 캡처된다. 해상도는 녹화마다 `Emulation.setDeviceMetricsOverride`를 `config.json` `viewport`(포털 구간은 `VP`)로 설정한다(값 3절).
- 부하 문(값 3절): 화상회의가 돌면 `run.sh`가 멈추고, 메모리가 모자라면 경고만 하고 `measure.py`의 프레임 간격으로 판정한다.
- 진행 리듬(`ctrl.mjs` · `ui.mjs`): 모든 ego 호출은 하나의 직렬 큐로 보낸다. 표시 포인터는 페이지에 그린 SVG 화살표를 `element.animate`로 움직이고, 실제 입력은 같은 경로를 단계별 `mouse.move`로 보내며, 실제 입력이 다 끝날 때까지 화살표를 목표에 고정한다. 대상 안정 · 조작 · 다음 음성 시점은 3절. 녹화 시작 전에 조작 큐가 돌면 즉시 실패시키고, 긴 이동 · 긴 문자열 입력을 큐 한 항목에 넣지 않는다.
- 클릭 시점: `ctx.say(id, fn, {at:'대사 속 구절'})` — 그 구절 끝에 첫 클릭(ctrl.mjs). 여러 조작 중 첫 동작이 앞 문장에 있을 때 쓴다. 두 동작이 다른 문장에 있으면 큐를 나눈다(p31-21 / p31-21b).
- 포털 구간의 「화면 안」 판정·굴릴 자리는 본문 실제 높이 비율로(`segs/p31-common.mjs` `p.show`). 프로그램 굴리기라 화살표를 옮기지 않는다.
- 사용자가 ego 공간을 잡으면 「Control of this task space is with the user」로 멈춘다. 우회하지 않고 사용자 「계속」 뒤 `takeOverTaskSpace`. 사용자가 직접 배치 · 입력할 때는 녹화를 멈추고 `task.handOff()`로 넘긴 뒤 `takeOverTaskSpace(<번호>)`로 되찾고, 그 결과는 화면 캡처가 아니라 앱 저장 데이터(VS Code는 실습 폴더의 파일)로 읽는다.
- 구간 기록: 구간마다 시작 상태 확인 → 녹화 → 끝 상태(`end-state.json`) · 프레임 · 행동 시각(`timing.json`)이 `config.json` `work` 아래 `<이름>/`에 저장된다. 한 구간씩 찍고 바로 실측한다(이동별 최대 프레임 공백, 클릭 좌표 오차, 문장보다 늦은 조작, 마지막 프레임 — `measure.py`).
- take는 매번 새 이름으로 보존하고(예: `p22-2` 뒤 다시 찍은 `p22-2b`), 실패 · 잘못된 상태 take는 이름을 붙여 남기되 합성에 쓰지 않는다. 기존 MP4를 덮어쓰지 않는다.

### 1-10. 합성

ffmpeg는 PATH에 없다. 시스템 Python의 `imageio_ffmpeg`가 가진 `ffmpeg-win-x86_64-v7.1.exe`를 `FFMPEG`로 준다.

```bash
# Git Bash, 촬영도구/ 에서
FFMPEG="$(python -c 'import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())')" PYTHONUTF8=1 python encode.py <출력이름> <구간[:여기까지 쓸 ms]> ...
```

결과는 `config.json` `work` 아래 `<출력이름>_안치윤_1080p.mp4`(30 fps, libx264 crf 18, AAC 160k)와 `verification.json`(구간 · 큐 시각 · 클릭 오차 · 이동 프레임 공백). 문장 겹침 · 음성 교체 길이 초과면 멈춘다(V요-32).

### 1-11. 검사

### 4-2. 코딩 랩 동선(촬영 전 확인)

촬영 전에 받는 것은 검증한 시작본 · 화면에 보일 결과 · 판단할 사례와 근거 · 끝 리뷰에 쓸 학생용 완성본이다(영상 V맥-6). 학생 경로로 한 번 리허설해 실행 결과를 대조하고, 결함을 고친 뒤 연결 덱 → 실습 대본 · 큐 → 본촬영 → 편집 · 자막 → 촬영분을 쓴 가이드 · ZIP 순으로 간다. 기술 시험이나 리허설 장면은 본촬영 인수의 근거와 구별한다.

영상은 V-204대로 받은 실습 폴더를 VS Code에서 연 상태에서 시작한다. 첫 코딩 랩에서만 여는 조작을 짧게 보인다 — [시작 안내](../../실습시작/index.html)에서 받은 `실습시작.cmd`로 과정 → 회차 → 실습 → 「새로 시작」을 고르면 전용 폴더와 `START.md`가 VS Code에 열린다. 시작 도구가 브라우저에 여는 가이드는 영상에 띄우지 않는다(V-138). 선택한 실습 이름과 열린 폴더가 맞는지 확인한다.

웹 VS Code는 촬영용 전용 공간에서 로컬 학생 화면과 같은 어두운 테마·배율·배치를 맞춘다. 첫 설계 랩에서는 탐색기에 보이는 폴더와 가운데 편집기, AI 채팅 입력칸, 아래쪽 터미널을 **각각 처음 쓰는 바로 그때** 가리킨다. 어떤 파일을 열고 무엇을 입력하며 어디에 결과가 나타나는지 학생이 볼 수 있게 한다. 이어지는 구현 랩에서는 달라진 입력과 확인할 출력만 다시 짚는다. 다운로드·압축 해제·네이티브 폴더/신뢰 창은 4-3의 실화면으로 잇는다.

학생이 질문과 기대 결과를 정하고 AI에 작은 변경을 요청하는 장면부터, 바뀐 파일을 읽고 실행해 원자료와 대조하는 장면까지 이어 찍는다. 차이가 있으면 근거 행과 실제 출력을 제시해 수정하고 같은 질문과 다른 사례를 다시 실행한다. 저장한 결과를 다시 열고, 별도로 받은 완성본을 새 폴더에서 실행해 같은 업무 질문에 답하는 화면으로 마친다. 감독은 영상 V요-35의 범위만 1배속으로 재생하고, 직접 본 화면과 들은 범위를 구별해 기록한다.
