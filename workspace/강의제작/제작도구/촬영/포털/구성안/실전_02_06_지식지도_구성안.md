## ⑤ 사용자가 판단할 곳

1. **배정 10분 대비 계획 8.3분.** 확인한 화면 값으로 두 곳을 보강했다 — 발주 방법에 걸린 규칙 넷(리드타임 · 전결 · 불량률 · 승인 공급사, 화면 순서)이 볼 값은 공급사마다 다른 견적 값이다(r06-501b, 견적은 `SUPPLIED_BY` 관계 속성 — `scm_sync.py:3-8`), 재고를 검사하는 규칙은 지도에 있지만 수량은 CMMS에서 읽는다(r06-605). 더 넣을 후보(ERP 「예비품 가용 재고 − 재주문점」)는 같은 말의 되풀이라 넣지 않았다.
2. **옛 구성안(메인 결정: 대본 확정 때 이 판으로 바꿔 끼움) `포털/구성안/실전_02_2_지식지도_구성안.md`과의 대조.** 이어 쓴 것: 씰 키트 중심, 설비 세 대 바꾸기, 문서 경로(발주 방법 → 근거 절 → 구매 기준 문서), 「씰 키트 가용」 검색으로 재고 출처 확인, 끝 문장의 뜻. 바꾼 것: 행 원문이 「노드의 ID · 속성」에서 「노드에 보이는 이름 · 종류, 태그 · 품번 같은 식별정보와 속성」으로 바뀌어 `part:pump-seal` 아이디 검색(옛 3구간)을 빼고, 대신 센서 태그 한 번(구간 2)을 넣었다. 옛 구성안의 1~3구간 2분 · 6구간 3분 같은 분 배정은 이 큐로 다시 쟀다(위 표). 옛 구성안을 이 판으로 바꿔 끼울지.
3. **문서 경로를 발주 방법의 절차 단계로 잡았다**(옛 구성안은 「발주 방법 → 승인 공급사 규칙 → 근거 절」). 규칙에서 출발하면 규칙 상자 이름이 긴 설명 글이라 상세 칸에서 고르기 어렵고, 단계 → 절 → 문서 → 승인 공급사 절 ← 규칙 순서면 문서와 규칙을 한 줄로 잇는다. 어느 쪽으로 갈지.
4. **공급사 이름** — 메인 결정대로 화면 글자 그대로 읽는다(「비오이엠 순정」 「에이정밀 저가」 「씨트레이딩 최저가」, 화면 `A정밀 (저가)` · `B-OEM (순정)` · `C트레이딩 (최저가)`, `seed.sql:52-54`와 같음).
5. 통합반 ⑤의 3~5(식별자 낭독 · 영문 속성 키 · 설비 상세의 「교육용 …」 글자)는 이 편에도 같다.
6. 학생 묶음 `실전반/…/02일차_실습2_지식지도탐색.zip` · 가이드는 VS Code 기록 틀을 쓰는 옛 판이다. 새 영상과 같은 판으로 맞추는 일은 가이드 일로 남는다.
