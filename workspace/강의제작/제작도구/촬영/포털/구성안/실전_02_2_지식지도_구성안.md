# 실전반 2회차 실습 2 — 기준 설비 지식의 실제 연결 구조 확인하기

> 구성안 검토본. 사용자 확인 전. 대본·음성·녹화 승인으로 간주하지 않는다. 포털 도구 실습이며 `workspace/강의제작/지침/영상.md`(실습 영상)와 `workspace/강의제작/제작도구/촬영/포털/촬영준비.md`를 따른다.

## 1. 수업의 중심

**이론에서 배운 대상·속성·관계를 포털 화면에서 직접 보고 따라가며 확인한다.** 펌프 축 씰 키트를 찾아 속성과 연결을 살펴보는 체험이다.

- 여는 말은 이론에서 배운 개념 이름과 오늘 볼 대상을 짧게 잇는다. 정의·설계 이유를 다시 강의하지 않는다.
- 실라버스에 있는 설비·부품·문서 연결과 재고·공급 조건의 구분을 화면에서 확인한다. 교체 준비 문제나 구매 판단 과제를 별도로 세우지 않는다.
- 포털은 두 반 모두 체험·따라 하기다. 실전반이라는 이유로 난도·응용 과제·이론 설명을 더하지 않는다. 직접 만드는 과정에서 필요한 원리·설계 이유의 설명과 응용·활용은 VS Code 코딩 랩에서 다룬다.
- 설명은 지금 볼 곳 → 조작 → 나타난 결과의 뜻으로 이어진다. 화면을 이해하는 데 필요한 이유는 짧게 말한다. 숫자·조건은 이 상황의 설정으로만 다루며 구현의 「했다/하지 않았다」 보고, 「교육용·강의용·예시」 꼬리표, 문서 절 번호·식별자·속성 키 낭독을 쓰지 않는다.
- 포털 화면에서 시작해 부품 상세 화면에서 끝난다. VS Code 장면·학생 파일 작성·저장·다음 코딩 랩 예고는 없다. 앞 내용을 받아 잇는 역할은 뒤 실습이 맡는다.
- 무엇을 왜 볼지 말하기 시작하고 조작한다. 결과는 보인 뒤 설명한다. 첫 화면은 위치와 읽는 법을 안내하고 익숙한 조작은 줄인다. 몰라도 되는 설정·조건식은 안심시키고 볼 곳을 짚는다.

## 2. 실라버스 원문과 수정안

정본: workspace/강의제작/산출물/실라버스/피지컬AI_실라버스_최종본.xlsx, 「실전반 온라인 32H」 B21:D21. 배정 **10분**.

현재 제목: **기준 설비 지식의 실제 연결 구조 확인하기**.

현재 상세 전문:

> 포털 지식 지도에서 설비·구성 요소·부품·문서의 연결을 펼치고 노드의 ID·속성과 관계 방향을 확인한다. 한 부품을 사용하는 설비를 찾고, 연결이 있다는 사실과 실제 재고·공급 조건이 확보됐다는 판단을 구분한다. 이어지는 로컬 랩에서는 제공 공급 자료로 답할 질문을 정한다.

수정안(C21만, 제목·배정 시간 유지):

> 포털 지식 지도에서 설비·구성 요소·부품·문서의 연결을 펼치고, 부품 번호 등 대상을 구별하는 속성과 관계 방향을 확인한다. 한 부품을 사용하는 설비를 찾고, 연결이 있다는 사실과 실제 재고·공급 조건이 확보됐다는 판단을 구분한다.

수정 이유:

1. 상세 화면에는 그래프 ID가 표시되지 않는다. 부품 번호를 확인한 것으로 그래프 ID 확인을 대신했다고 말하지 않고, 화면에서 수행할 수 있는 활동을 정확히 적는다.
2. 마지막 문장의 질문 정하기는 2-3이 담당한다(T1-1). 22행에 이미 「부품별 사용 설비와 공급사별 승인 여부·단가·불량률·납기를 찾을 질문을 정한다」가 있어 중복 추가하지 않는다.

현재 엑셀은 미수정이다. 구성안 확인 시 위 변경을 함께 제시한다. 반영 직전 다른 작업의 미커밋 엑셀 변경을 확인하고 있으면 기다린다. 수정 직후 해당 파일만 경로 지정 커밋한다. 노션 동기화는 별도 게시 확인 후 수행한다.

## 3. 구성 흐름과 시간

배정 **10분 / 구성 시간 재산정 중 / 새 대본 계수 계산 미확인 / 새 영상 실측 미확인**.

이론 재설명·응용 물음·마무리 정리를 포함했던 16.0분 구성 견적은 철회한다. 이전 초안의 16.1분도 현재 구성의 계산·실측으로 쓰지 않는다. 아래 조작과 필요한 화면 설명의 길이를 다시 산정해 구성안 검토 카드에 제시한다. 구성안 확인 후 대본 전문을 작성하고 시간계산.py estimate로 계산한다.

내용을 자연스럽게 충분히 다루는 것이 먼저다. 배정에서 출발해 +10분까지 허용한다. 짧으면 빠진 내용·얕은 설명을 범위 안에서 보강하되 반복·대기·느린 타이핑·행 밖 활동으로 채우지 않는다. 다 구성한 결과 자연스럽고 최선이면 사유를 적고 마친다. 13분으로 맞추는 목표는 두지 않는다.

| 구간 | 설명과 화면의 흐름 | 화면에서 확인할 것 |
|---|---|---|
| 1. 오늘 볼 대상 | 이론에서 배운 대상·속성·관계를 짧게 받아 씰 키트의 연결을 살펴본다고 안내 | 포털 화면에서 바로 시작 |

| 3. 설비에서 부품 찾기 | 설비 → 주 펌프 → 씰 키트를 차례로 선택 | 종류·이름·부품 번호 |

실라버스의 마지막 구분도 표시된 정보와 추가로 확인할 정보가 무엇인지 짧게 짚는다. 재고 규칙 세 개 낭독, 구매 의사결정 강의, 같은 경로 반복, 별도 마무리 정리(Wrap-up)는 넣지 않는다. 각 조작에 필요한 위치 안내와 결과의 뜻은 빠뜨리지 않는다.

## 7. 경계와 다음 단계

- 기존 스택의 사건 기록을 삭제·초기화하지 않는다. 녹화 전 화면 흔적을 정리하고 시작 상태를 확인한다. 데이터 삭제가 필요해지면 실제 대상·이유를 별도로 보고한다.

- 다음: 구성안 검토 카드 확인 → 실라버스 해당 문장 반영·관련 자료 정리 → 대본 전문 작성·계수 계산·검토 카드 확인 → 비용 안내·음성·브라우저 녹화 → 가이드·패키지·검증. 한 번에 실전 2-2만 진행한다.
