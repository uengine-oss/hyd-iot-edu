# ARROWS 촬영준비

arrows.app 캔버스를 이 PC ego로 찍는다(클라우드 불가). Git Bash, 이 폴더에서 `PYTHONUTF8=1 python`. 규칙은 [영상](../../../지침/영상.md), 공통은 [README](../README.md).

## 길

1. 환경 — 환경변수 `HYD_ELEVENLABS_KEY_FILE` · `FFMPEG`만 맞추면 된다. `work` · `space`는 [촬영도구/config.json](촬영도구/config.json).
2. 큐 · 시간 · 배치 순서(녹화 전) — 큐 원본은 [build_ontology.py](build_ontology.py)의 `CUES`(조작 이름은 자료).
   ```bash
   python build_ontology.py cues ../../../../../작업/촬영/arrows/cues.json
   python ../시간계산.py estimate ../../../../../작업/촬영/arrows/cues.json
   python 촬영도구/plan_order.py <시작 구간>     # 배치가 바뀌었을 때: 겹침 · 그림 범위 축소가 없는 순서
   ./촬영도구/run.sh coords                       # 사용자가 ego에서 잡은 배치를 저장 좌표로 읽는다(화면 캡처 X)
   ```
3. 음성(바뀐 문장만) — `python 촬영도구/voice.py <구간번호 …>`.
4. 시작 상태(이어 찍을 때만, 녹화 밖) — `./촬영도구/run.sh restore <앞 구간> [출발원 도착원]`: 끝 상태 데이터를 새 그림으로 가져오기 → radius 70으로 → 상대 위치 확인 → 마지막 화살표 선택. 하나라도 다르면 멈춘다. 그림 주소가 바뀌니 첫 구간은 `run.sh rec`의 다섯째 인자 `relax`.
5. 구간 녹화(한 번에 한 구간, 이름은 매번 새로 — 같은 이름에 프레임이 있으면 멈춘다):
   ```bash
   TMO=<초> ./촬영도구/run.sh rec <이름> <구간> [시작큐] [앞 구간] [relax]
   python 촬영도구/measure.py <이름>
   ```
   실행 결과는 run.sh 끝줄이 비어 있을 수 있어 `<take>.log`의 `"error":null`로 판정한다.
6. 합성 — `FFMPEG=<ffmpeg.exe> python 촬영도구/encode.py <출력> <조각[:자를ms]> …`(오류로 끝난 take는 자를 ms를 꼭 준다, 녹음 뒤 큐 문장이 바뀌면 멈춘다). 결과 `<work>/<출력>/<출력>_안치윤_1080p.mp4` · `자막.srt` · `verification.json`.
7. 연결 산출물 — `python build_ontology.py sync`(대본 · 수업원고 · 예상시간 · 두 과정 대상_목록 · 관계_검토표 · ZIP, 해시는 [동기화판본.json](동기화판본.json)). 가이드 사진 · 문구는 `python build_student_guide.py [--video <mp4>] [--captures <폴더>]`.
8. 조각 고침 — 다시 합칠 조각이 없으면 앞은 게시본을 잘라 `../포털/촬영도구/join.py`로 잇는다(지금 판 앞 끝 632.23초). 음성 캐시가 없으면 게시본 소리를 자막 시각대로 잘라 큐마다 `audio/<id>.mp3` · `.json`으로 두고(크레딧 0), 새 문장만 `voice.py`. 화면이 틀어진 정도면 되돌리지 말고 수습 큐(번호를 따로, 예 `o091b`)로 그 화면에서 이어 찍는다.

큐 조작(`CUES`): `at 비율`(그 문장의 이 비율까지 다음 조작을 미룸) · `point 대상`(`look:원` · `props:원` · `node:원` · 패널) · `click` / `ctrlclick 대상`(`blank` · `node:이름` · `caption` · `type` · `labelPlus` · `labelInput` · `propPlus` · `propKey` · `propVal` · `customize` · `style:radius` · `style:node-color` · `reverse` · `export` · `tab:JSON|PNG|Cypher` · `done` · `logo` · `menu:New|newLocal|Import` · `importButton` · `panelToggle`) · `type 글자` · `key 키` · `grow 원 각도`(테두리를 빈 곳으로 끌어 새 원 + 화살표) · `edge` / `connect 출발 도착` · `layoutNorm [[이름, x비율, y비율]…] 기준원2` · `download 종류 이름` · `choose 종류` · `verify`(다시 연 그림의 원 · 관계 · 조건 수 대조) · `openLink` · `move 원 dx dy`. 쓰지 않는 것: `spread`(끝없이 축소) · `manual`(녹화 중 사용자 조작은 페이지에 안 들어감) · `place` · `arrange`.

## 함정

- 커서 이동에 0.7초 끊김 → 다른 작업이 끝난 뒤 ego 창을 최대화 · 앞으로.
- 스타일 · Label 칸에서 엔터 → 원이 하나 더 생김 → Tab으로 확정.
- 가장자리 원을 바깥으로 끌면 그림 자동 맞춤이 끝없이 축소 → 기존 원은 그림 범위 안에서만 옮기고, 공간은 테두리 끌기로 새 원을 가장자리 가까이 놓아 만든다.
- 테두리 끌기가 빈 곳 클릭이 됨 → 시작점은 반지름 × 1.09, 화살표 16px 안이면 피함. 새 원 · 조건 단 원은 위치를 150ms 두 번 읽고, 글자 22px 안이면 피함.
- 화살표를 눌렀는데 옆 화살표가 선택됨 → 출발 원 쪽 35% 지점을 누른다. 관계 이름이 잘림 → 원 중심 거리를 반지름 6.6배로.
- 빈 곳을 눌러도 선택이 안 풀림 → 원 · 화살표 · 글자에서 가장 먼 지점을 한 번의 페이지 평가로 고른다(원을 하나씩 찾으면 프레임이 400ms 끊김).
- 축소 화면에서 원을 못 찾음 → 가장 큰 반지름의 75% 이상만 원으로 본다.
- 녹화 밖 Ctrl+Z가 입력 칸으로 가고 원 스타일은 안 되돌아감 → `run.sh restore`(가져오기). Ctrl+Y는 안 된다.
- 다운로드 대기를 직렬 큐에 넣으면 클릭이 막힘 → `waitForEvent` · `waitForFileChooser`는 큐 밖. 내보내기 Download 버튼이 둘 → 첫 번째. `choose`는 같은 녹화 실행에서 받은 파일만 고른다 → 내려받기와 가져오기는 한 구간에.
- New로 만든 그림에 빈 원 1개 → 영상에서 선택해 Delete. Import는 radius를 50으로 넣고 새 주소를 만든다 → radius 70으로 되돌리고 `relax`.
- 여러 원 함께 선택은 Ctrl+클릭(Shift는 단일). 색은 STYLE node-color에 값 입력 후 Tab.
- `build_ontology.py`의 `VIDEO`는 끝 7초가 잘린 옛 판(`ARROWS-온톨로지-최종배치`)의 `verification.json`을 읽는다 → sync의 길이 표시는 실행해 확인한다.
