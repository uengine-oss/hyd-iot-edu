**3단계 — 음성.** 공통 큐를 `작업/촬영/neo4j/<판>-cues.json`으로 복사하고, 새 음성 폴더(`neo4j/음성/<음성 폴더>`)에는 앞 판 음성(`<큐 ID>.mp3` · `.json`)을 먼저 복사한다 — `voice.py`는 `.json`의 글이 같은 큐를 건너뛰어 바뀐 문장만 새로 산다. `voice.py`의 저장 폴더는 포털 설정값이라, 감싼 실행에서 `common.AUDIO`를 새 음성 폴더로, `FFMPEG`를 manifest의 ffmpeg로 바꾼 뒤 `voice.py <판>-cues.json`을 돌린다. 키는 `ELEVENLABS_API_KEY` 환경변수로만 넘기고 값을 출력 · 저장하지 않는다(V요-48). 음성 비용은 V목-11 · V맥-12대로 범위와 견적을 먼저 알린다.

**4단계 — 녹화(ego).**
- 설치된 `ego-browser skill` 출력을 끝까지 읽는다(API는 설치 버전이 우선). ego lite 설치 · 로그인은 사용자가 한다.
- 랩 DB를 켜고 학생 연결 파일(3절)의 주소로 연다. 기존 서비스 · DB를 먼저 확인하고 새로 만들지 않는다.
- 시작 상태: 학생 링크의 자동 연결 창에서 시작한다. 이전 입력 · 결과 · 오류 · 열린 메뉴는 `:clear` → 입력칸 비움 → 연결 해제 → 학생 주소로 다시 접속해 없앤다. 화면 정리에 DB 삭제 · 초기화를 쓰지 않는다. 연결 창 전체가 화면 안에 있어야 한다 — 녹화 코어가 잘리면 `Connection dialog clipped`로 멈춘다. 첫 실제 녹화 프레임으로 전체 연결 창 · 이전 결과 없음 · 메뉴 닫힘을 확인한다.
- 이어 찍기는 직전 결과 · 선택 · 패널 · 스크롤을 맞춘 **검증한 재개 상태**에서만 `continue:true` · `only:[큐 ID]` · `pointer:{x,y}`를 쓴다. 상태 복원과 녹화는 같은 호출에서 한다 — 호출이 바뀌면 배율과 그래프 배치가 바뀔 수 있다.
- 녹화 설정 JSON(키 `repo,evidence,take,space,host,readable,width,height,audio,cues`, 값은 3절)을 `작업/촬영/neo4j/`에 두고 take는 매번 새 이름으로 한다 — 같은 take에 프레임이 있으면 `Existing take preserved`로 멈춘다. 비밀값은 설정에 넣지 않는다. `cues`는 늘 준다 — 빠지면 녹화 코어가 옛 `통합반_그래프탐색_큐.json`을 읽는다.
- 부르는 법: 한 줄짜리 시작 `.mjs`(UTF-8)를 만들어 `ego-browser nodejs`로 부른다. 같은 주소는 다시 실행되지 않으니 `?<판>`을 바꾸고, 셸 안에서는 `< /dev/null`을 붙이며, 보내기 전에 `node --check`.

```bash
# <녹화설정>.mjs 내용(예: 작업/촬영/neo4j/common-graph-record02.mjs)
# globalThis.HYD_CONFIG_PATH='<저장소 절대경로>/작업/촬영/neo4j/<녹화설정>.json';await import('file:///<저장소 절대경로>/workspace/강의제작/제작도구/촬영/neo4j/record_from_config.mjs');
node --check 작업/촬영/neo4j/<녹화설정>.mjs
ego-browser nodejs -e "await import('file:///<저장소 절대경로>/작업/촬영/neo4j/<녹화설정>.mjs?v1')" < /dev/null
```

- 작업 공간은 `taskSpace(<설정 space>)`로 쥐고(페이지 `p1`) 같은 작업은 같은 공간을 쓴다. 다른 세션과 같은 공간 · 페이지를 동시에 조작하지 않는다. 사용자가 ego 공간을 잡고 있으면 우회하지 않고 「계속」을 받은 뒤 `takeOverTaskSpace(<번호>)`로 되찾는다(이 길에는 사용자가 직접 입력하는 장면이 없다 — 생기면 녹화를 멈추고 `task.handOff()`로 넘기고, 결과는 화면 캡처가 아니라 Neo4j 저장 데이터로 읽는다).
- 해상도: 녹화 코어가 호출마다 시작에서 `Emulation.setDeviceMetricsOverride`를 설정 `width` · `height`로 건다(호출이 끝나면 풀린다, 한 영상 안에서 바꾸지 않는다). 프레임은 `Page.startScreencast`(JPEG95, 최대 1920×1080)로 받는 즉시 저장 · ACK한다. 앞에 보이는 탭에서만 프레임이 오니 ego 창을 최소화하지 않는다.
- 진행 리듬: 모든 ego 호출은 하나의 직렬 큐(`serial`)로 보낸다. 표시 포인터는 페이지에 그린 SVG 화살표(`recording-pointer`)를 `element.animate`로 움직이고, 실제 입력은 같은 경로를 약 33ms 간격 `mouse.move`로 보내며 눌렀다 떼는 입력도 원본에 남긴다. 실제 입력이 끝날 때까지 화살표를 목표에 고정한다. 위치가 바뀌는 대상은 150ms 간격 두 번 같은 위치일 때 출발한다. 조작은 행동 문장이 끝나기 약 250ms 전에, 다음 음성은 행동 종료 + 250ms에 시작한다. 녹화 시작 전에 조작 큐가 돌면 즉시 실패시키고, 긴 이동 · 긴 문자열 입력을 큐 한 항목에 넣지 않는다.
- 녹화 전에 랩 DB · PC 부하를 보되 수치만으로 중단하지 않고 실제 반응 · 프레임 간격으로 판정한다.
- 그래프 대상: 선택 해제 → `Zoom to fit` → 캔버스에 실제 그려진 라벨 · 원 좌표(`graph_targets.mjs`가 `fillText` · `arc`를 감싸 기록) 관찰 → 안정 확인 → 실제 휠 · 빈 배경 드래그로 읽을 크기까지 확대 · 이동(`readable_graph.mjs`) → 클릭 · 속성 확인. 전체 지도는 개요, 읽는 대상은 근접 화면으로 나눈다. 문장별로 선택 해제 · 맞춤 · 이동 · 확대 · 클릭 시점을 나누어 발화 중에 한다.
- 진행은 `<take>/progress.json`(마지막 큐 · 완료 수 · 프레임 수), 완료 · 오류는 `timing.json`과 `end-state.json`으로 판단한다. 한 구간씩 찍고 바로 실측한다(이동별 최대 프레임 공백, 클릭 좌표 오차, 문장보다 늦은 조작, 마지막 프레임). 전체 지도 · 노드 · 속성 · 표 대표 화면은 원본 프레임으로 확인한다.
- 걸린 시간(실측): take02는 73큐를 769.8초(약 13분)에 찍었다.

**5단계 — 구간 고르기 · 합성.** [합성설정_예시.json](합성설정_예시.json)을 `작업/촬영/neo4j/<name>-manifest.json`으로 복사해 `repo · evidence · name · cues · audio · ffmpeg · source_description · takes · captures`를 지금 값으로 맞춘다.
- 실패 · 잘못된 상태 take는 이름을 붙여 남기되 합성에는 정상 부분만 쓴다: `before_cue`(그 큐 시작 250ms 전까지) 또는 명시적 `end_ms`. 오류 take에 끝 지점이 없으면 `select`가 멈춘다. 첫 준비 프레임이 이전 커서 상태면 실제 정상 프레임 번호를 `start_frame`으로 준다. 발화가 시작된 뒤를 임의로 자르지 않는다(V-182).
- 발화 중간 절단 · 큐 누락/중복 · 음성 불일치 · 저장 결과(CSV · PNG) 불일치면 멈춘다. 같은 `name`의 MP4가 있으면 `encode`가 `기존 영상 보존`으로 멈춘다 — 새 `name`을 쓴다. 영상 · 음성 길이가 0.1초 넘게 다르면 `encode`가 멈춘다(V-184).
