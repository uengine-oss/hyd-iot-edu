# Neo4j Browser 촬영준비

Neo4j Browser 화면(학생 링크로 여는 자동 연결 창에서 Cypher를 실행하고 그래프를 탐색하는 장면)을 찍는다. 정본은 클라우드 Playwright(아래 「클라우드」)이고, 옛 게시본은 이 PC의 ego로 찍었다(길 1~7, Git Bash에서 저장소 루트를 현재 위치로 두고 실행한다). 줄임: `<py>` = `PYTHONUTF8=1 .venv314/Scripts/python.exe`, `N=workspace/강의제작/제작도구/촬영/neo4j`, `E=작업/촬영/neo4j`. 규칙은 [영상](../../../지침/영상.md), 여러 도구 공통은 [README](../README.md)에 있다.

## 길

### 클라우드(정본) — bash와 `python3`, `$N/촬영도구/`의 `rec.sh`가 부른다

1. 실습 DB — 학생 ZIP을 작업 폴더(`작업/<날짜>_<제목>/lab/`)에 풀고, 학생처럼 랩의 준비 스크립트로 랩 DB 컨테이너(`hyd-student-…`)를 띄운다. 처음 상태는 20노드 · 19관계, 예제 레이블(연습장치 · 연습센서) 0개다. 리허설 · 끊긴 녹화가 남긴 예제 노드는 `docker exec <컨테이너> cypher-shell -a bolt://localhost:7687 "MATCH (n) WHERE n:연습장치 OR n:연습센서 DETACH DELETE n"`로 지운다(설비 데이터는 손대지 않는다). VM이 다시 켜지면 `dockerd`를 띄우고 `docker start <컨테이너>`를 하는데, 이때 Browser · Bolt 포트가 바뀌므로 `docker ps`로 다시 읽는다.
2. 글꼴 — 사용자가 올린 맑은 고딕을 `/usr/share/fonts/malgun/`에 두고, `/etc/fonts/local.conf`에 한국어(`lang` ko)와 `sans-serif`에서 Malgun Gothic을 앞세우는 규칙을 둔 뒤 `fc-cache -f`를 돌린다(`fc-match ':lang=ko'`가 Malgun이어야 한다. 규칙이 없으면 한글이 WenQuanYi로 그려진다). 고정폭(`monospace`)은 건드리지 않는다. 글꼴 파일은 커밋하지 않는다.
3. 브라우저 — `bash rec.sh down` → `bash rec.sh up`이 빈 임시 프로필로 새로 띄운다(처음 학생처럼 안내 창이 다시 뜨고 Queries가 빈다). `bash rec.sh prep open '<Browser 주소>/browser/?connectURL=bolt%3A%2F%2F127.0.0.1%3A<Bolt 포트>'`로 연결 창을 열고, `bash rec.sh prep guide <안내.html> s2`로 안내 문서 탭을 2절에 맞춘다. 화면은 `prep shot <png>`로 본다.
4. 큐 — 대본은 ▸ · ‖ · ‖(따라 하기 N초) 표시가 든 다시 찍을 판이다. 조작은 `$N/retake_ops.py`의 `RETAKE_OPS`에 큐 글 첫머리와 짝지어 적고(`build_retake_cues.py <대본> <안내.html> --목록`으로 덩이를 본다), `python3 $N/build_retake_cues.py <대본> <안내.html> $E/<판>-cues.json`으로 만든다. 첫머리가 어긋나면 멈춘다.
5. 리허설 · 녹화 — 설정 JSON(`take`(새 이름) · `cues` · `host`(Bolt 주소) · `guide`: `안내.html` · 시험이면 `silent`: 배수)을 `$E/`에 두고 `TMO=2400 setsid nohup bash rec.sh rec $E/<설정>.json &`로 띄운다. 끝나면 `measure.py --도구 neo4j`가 돈다. 음성 없는 리허설(`silent` 3)은 220큐에 약 17분이다.
6. 음성 — `ELEVENLABS_API_KEY=… python3 ../포털/촬영도구/voice.py $E/<판>-cues.json --음성 $N/음성/<폴더> --큐 <id,…>`(포털 길 5). 이 환경의 키 변수 이름이 다르면 실행할 때 그 이름으로 넘긴다.
7. 합성 — 포털 `encode.py --도구 neo4j <출력> <take[:ms]> …`(포털 길 7), 검사는 영상 길 17.

### 이 PC ego(옛 게시본)

1. 원고 — 큐 JSON을 손으로 고치지 않는다. `$N/build_common_cypher.py`의 `narration_polish`에 `큐 ID: 새 문장`을 넣고 `<py> $N/build_common_cypher.py`를 돌린다(두 큐 JSON을 통째로 다시 쓴다).
2. 대본 — `<py> $N/sync_integrated_script.py`를 돌려 두 과정의 대본(통합반 02회차 04, 실전반 02회차 05)을 만든다.
3. 음성 — 큐를 `$E/<판>-cues.json`으로 복사하고, 새 음성 폴더 `$N/음성/<폴더>/`에 앞 판 음성(`<큐 ID>.mp3`와 `.json`)을 먼저 복사한다. 그다음 `common.AUDIO`를 그 폴더로, `FFMPEG`를 바꿔 주는 감싼 실행으로 [포털 voice.py](../포털/촬영도구/voice.py) `<판>-cues.json`을 돌린다(글이 같은 큐는 건너뛴다). 감싼 실행 스크립트는 저장소에 없으니 만들어 쓴다.
4. 녹화(ego) — 랩 DB를 켜고(랩의 `lab_db.py`가 HTTP 200을 기다린 뒤 주소를 낸다), 학생 연결 파일의 주소로 연다. 이전 흔적은 `:clear` → 입력칸 비움 → 연결 해제 → 학생 주소로 다시 접속, 이 순서로 정리한다(DB를 지우거나 초기화하지 않는다). 연결 창 전체가 화면 안에 들어와야 한다(잘리면 `Connection dialog clipped`로 멈춘다).
   - 녹화 설정 JSON(키 `repo,evidence,take,space,host,readable,width,height,audio,cues`)을 `$E/`에 둔다. take는 매번 새 이름으로 짓고(같은 이름이면 `Existing take preserved`로 멈춘다), `cues`는 늘 준다. 비밀값은 넣지 않는다.
   - 시작 `.mjs`는 한 줄이다: `globalThis.HYD_CONFIG_PATH='<저장소 절대경로>/작업/촬영/neo4j/<설정>.json';await import('file:///<저장소 절대경로>/workspace/강의제작/제작도구/촬영/neo4j/record_from_config.mjs');`
   ```bash
   node --check $E/<설정>.mjs
   ego-browser nodejs -e "await import('file:///<저장소 절대경로>/작업/촬영/neo4j/<설정>.mjs?v1')" < /dev/null
   ```
   - 이어 찍기는 직전의 결과, 선택, 패널, 스크롤을 맞춘 상태에서만 `continue:true` · `only:[큐 ID]` · `pointer:{x,y}`를 주어 한다. 상태 복원과 녹화는 같은 호출에서 한다(호출이 바뀌면 배율과 그래프 배치가 바뀐다).
   - 그래프 대상은 선택 해제 → `Zoom to fit` → 캔버스에 그려진 라벨과 원의 좌표 관찰(`graph_targets.mjs`) → 안정 확인 → 실제 휠과 빈 배경 드래그로 읽을 수 있는 크기까지 키우기(`readable_graph.mjs`) → 클릭과 속성 보기, 이 순서로 다룬다. 전체 지도는 개요로만 보이고, 읽어야 할 대상은 가까이 키운 화면으로 보인다.
   - 진행 상황은 `<take>/progress.json`, 완료와 오류는 `timing.json`과 `end-state.json`에 남는다. 실측으로 73큐에 약 13분 걸렸다.
5. 구간 고르기와 합성 — [합성설정_예시.json](합성설정_예시.json)을 `$E/<name>-manifest.json`으로 복사해 값을 맞춘다. 실패한 take는 `before_cue`(그 큐 시작 250ms 전까지) 또는 `end_ms`로 정상 부분만 쓴다. 첫 프레임에 이전 커서가 남아 있으면 `start_frame`을 준다.
   ```bash
   for s in select check capture encode; do <py> $N/lesson_pipeline.py $E/<name>-manifest.json $s; done
   ```
   다음 중 하나라도 있으면 멈춘다: 발화 중간 절단, 큐 누락이나 중복, 음성 불일치, 저장 결과 불일치, 같은 `name`의 MP4가 이미 있음, 영상과 음성 길이가 0.1초 넘게 차이 남. `capture` 단계는 manifest의 `captures`에 적힌 단계 사진, 검수판, 이음매를 뽑는다.
6. 가이드와 패키지 — 사진은 `<py> $N/사진_만들기.py --work 작업/<작업>/영상프레임`이 최종본 영상(지금은 9판, 클라우드 녹화)의 프레임에 빨간 표시를 그려 두 과정 `images/`와 `capture-provenance.json`에 쓴다(시각 · 표시 좌표는 그 파일 한 곳, 표시 없는 옛 사진은 `$N/사진원본/`). 눈으로 본 뒤 `<py> workspace/강의제작/제작도구/실습시작/build_common.py --lab relations`를 돌린다.
7. 조각 고침
   - 말만 바꿨고 녹화 원본이 없으면 영상 길 18의 `촬영/포털/촬영도구/쉼넣기.py`로 게시본을 고친다(새 음성이 길면 그 자리 화면을 멈춰 시간을 만든다).
   - 녹화 원본이 있고 음성과 포인터 표시만 바꾸면 `polish_recording.py`를 쓴다(바뀐 음성 길이만큼 발화 끝 여유만 늘리거나 줄이고, 조작을 자르게 되면 멈춘다). 그다음 새 manifest로 5를 한다.
     ```bash
     <py> $N/repair_pointer_display.py $E/<움직임 보고서>.json $E/<보정 폴더> --motion <번호> …   # 필요할 때만
     <py> $N/polish_recording.py $E/<앞 판 manifest>.json $E/<새 판>-cues.json <새 음성 폴더> <새 이름> $E/<포인터 보정 목록>.json
     ```
   - 실패한 큐 뒤만 다시 찍으려면, 정상 큐까지의 원본을 두고 `before_cue`로 자른 뒤 같은 상태에서 `continue` · `only` · `pointer`로 이어 찍는다.

## 함정

- 클라우드: 구간마다 따로 찍으면 구간 사이 쉼(2.3초)이 녹화에 들어가지 않고(첫 큐가 take 시작 0.3초 뒤에 나온다), 녹화 뒤 음성만 바꾸면 길어진 말이 앞 말에 붙는다. 합본을 `쉼넣기.py`에 넣어 큐 파일의 이음(gap 600 잇기 · 1300 큐 · 2000 결과 · 2300 구간)대로 쉼을 맞추고 2.5초 넘게 서 있는 곳을 자른다(위 「영상」 줄).
- 클라우드: 녹화 뒤 음성만 바꿀 때 조작(바탕 끌기 · 키우기 · 누르기)이 긴 큐의 말을 크게 줄이면, 그 조작 동안 말 없이 화면만 움직인다. 움직이는 화면은 `쉼넣기.py`가 자르지 못해 계획의 「못 자른 곳」으로 나온다(r1108: 조작 10.6초에 말 2초 → 9.9초가 빔). 그런 큐는 조작을 풀어 말하지 않으면서 그 시간을 채우는 말(왜 그 대상을 보는지)로 쓴다.
- 클라우드: 처음 여는 브라우저에는 연결 직후 「Work in tabs」 안내 창이 뜨고 Dismiss로 닫기 전까지 남는다. 닫지 않으면 탭 더하기 단추가 눌리지 않는다. 새 탭에 처음 글을 넣으면 「Discover more actions」가 뜬다(OK, got it).
- 클라우드: 쿼리 · 명령을 넣고 0.2초 넘게 있다가 돌리면 입력칸이 비워지고, 넣자마자(0.1초 안) 돌리거나 한 글자씩 치고 바로 엔터를 누르면 돌린 글이 입력칸에 남는다. 그래서 학생 화면에는 `:clear`가 남을 수 있고 대본은 컨트롤 A로 고른 뒤 붙이라고 한다. 녹화기는 붙이기 전에 칸 전체를 고르고, 입력칸에 남은 글을 짚는 조작은 두지 않는다(녹화 빠르기에 따라 남기도 비기도 한다).
- 클라우드: 관계를 만든 뒤 아래쪽 원이 그림 끝에 잘린다(화면 맞춤으로 들인다). 배치의 처음 값은 Force-based이고, Hierarchical layout으로 바꾸면 뒤의 새 결과 카드에도 유지된다.
- 클라우드: 앞 카드는 머리만 보이게 접혀 내려가므로, 앞 카드를 짚을 때는 카드 머리(`neo4j$`)를 가리킨다. 새 탭이 생겼는지는 「Untitled Query」 글이 아니라 탭 닫기 단추 수로 본다.
- 클라우드: CSS 1600×900 × 1.2는 프레임이 1920×1079로 나온다. 1536×864 × 1.25로 찍는다. 연결 창은 그 높이에서 아래가 잘려 보여도 입력칸과 단추가 화면 안이면 된다.
- 클라우드: `pgrep -f`는 한글 경로를 못 잡는다. 녹화가 도는지는 `ps -eo args | grep "^node -e globalThis.HYD_CONFIG_PATH"`로 본다. 공용 포털 촬영도구 폴더에 `__pycache__`를 남기지 않게 `PYTHONDONTWRITEBYTECODE=1`을 준다(`rec.sh`가 준다).
- 호출이 바뀌면 metrics가 풀려 입력칸과 탭이 겹치고 클릭이 되지 않는다. 모든 호출의 시작에 같은 metrics를 걸고, 입력할 수 있는 상태인지 본다. 이름 편집은 탭을 더블클릭해서 한다.
- 커서만 부드럽고 그림은 끊긴다(실제 이동이 4점뿐이었다). 실제 이동을 약 33ms 간격으로 보내고, 누름과 뗌도 원본 입력으로 보낸다.
- 1080p인데 글씨와 그래프가 작다. CSS 1536×864로 UI를 키우고, 대상은 앱 안에서 확대하고 옮긴다.
- 「유온」 대신 「유온 센서」를 선택한다. 표시 이름이 정확히 일치하는 것을 먼저 고르고, 속성 id로 대조한다.
- 다음 노드를 찾지 못하거나 화면 밖을 클릭한다. 선택 해제 → 전체 맞춤 → 캔버스의 실제 좌표 관찰 → 안정 확인, 이 순서를 거친 뒤 옮기고 선택한다. 좌표 추측을 되풀이하지 않는다.
- 위아래로 놓인 두 노드 사이의 관계가 눌리지 않는다. 두 원 중심 사이의 35% 지점을 누른다.
- 공급 조건 표의 마지막 열이 화면 밖에 있다(5열). 공급사, 승인 여부, 조건 맵의 3열만 뽑는 질의로 바꾼다.
- `Page.captureScreenshot`이 시간 초과되고, 일반 screenshot과 첫 screencast 프레임은 잘린다. 화면 사진은 screencast 프레임으로 받고, 녹화 직전에 새 프레임으로 연결 창을 확인한다.
- 입력 커서가 결과를 가리고, 이동 공백이 최대 250ms 생긴다(해상도가 안정되기 전에 시계를 시작한 탓이다). 해상도가 안정된 뒤 시계를 시작하고, 입력 커서는 아래 여백으로 옮긴다(녹화 코어에 반영됐는지는 미확인).
