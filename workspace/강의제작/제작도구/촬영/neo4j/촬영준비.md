# Neo4j Browser 촬영준비

Neo4j Browser(학생 링크의 자동 연결 창 → Cypher 실행 · 그래프 탐색)를 이 PC ego로 찍는다(클라우드 불가). Git Bash, 저장소 루트, `<py>` = `PYTHONUTF8=1 .venv314/Scripts/python.exe`, `N=workspace/강의제작/제작도구/촬영/neo4j`, `E=작업/촬영/neo4j`. 규칙은 [영상](../../../지침/영상.md), 공통은 [README](../README.md).

## 길

1. 원고 — 문장은 큐 JSON을 손으로 고치지 않고 `$N/build_common_cypher.py`의 `narration_polish`에 `큐 ID: 새 문장`을 넣어 `<py> $N/build_common_cypher.py`(두 큐 JSON을 통째로 다시 쓴다).
2. 대본 — `<py> $N/sync_integrated_script.py` → 두 과정 대본(통합반 02회차 04 · 실전반 02회차 05).
3. 음성 — 큐를 `$E/<판>-cues.json`으로 복사하고, 새 음성 폴더 `$N/음성/<폴더>/`에 앞 판 음성(`<큐 ID>.mp3` · `.json`)을 먼저 복사한다 → `common.AUDIO`를 그 폴더로, `FFMPEG`를 바꾼 감싼 실행으로 [포털 voice.py](../포털/촬영도구/voice.py) `<판>-cues.json`(글이 같은 큐는 건너뛴다). 감싼 실행 스크립트는 저장소에 없다 — 만들어 쓴다.
4. 녹화(ego) — 랩 DB를 켜고(랩의 `lab_db.py`가 HTTP 200을 기다린 뒤 주소를 낸다) 학생 연결 파일의 주소로 연다. 이전 흔적은 `:clear` → 입력칸 비움 → 연결 해제 → 학생 주소로 다시 접속(DB 삭제 · 초기화 X). 연결 창 전체가 화면 안이어야 한다(잘리면 `Connection dialog clipped`).
   - 녹화 설정 JSON(키 `repo,evidence,take,space,host,readable,width,height,audio,cues`)을 `$E/`에, take는 매번 새 이름(`Existing take preserved`로 멈춤), `cues`는 늘 준다. 비밀값은 넣지 않는다.
   - 시작 `.mjs` 한 줄: `globalThis.HYD_CONFIG_PATH='<저장소 절대경로>/작업/촬영/neo4j/<설정>.json';await import('file:///<저장소 절대경로>/workspace/강의제작/제작도구/촬영/neo4j/record_from_config.mjs');`
   ```bash
   node --check $E/<설정>.mjs
   ego-browser nodejs -e "await import('file:///<저장소 절대경로>/작업/촬영/neo4j/<설정>.mjs?v1')" < /dev/null
   ```
   - 이어 찍기는 직전 결과 · 선택 · 패널 · 스크롤을 맞춘 상태에서만 `continue:true` · `only:[큐 ID]` · `pointer:{x,y}`, 상태 복원과 녹화는 같은 호출에서(호출이 바뀌면 배율 · 그래프 배치가 바뀐다).
   - 그래프 대상: 선택 해제 → `Zoom to fit` → 캔버스에 그려진 라벨 · 원 좌표 관찰(`graph_targets.mjs`) → 안정 확인 → 실제 휠 · 빈 배경 드래그로 읽을 크기까지(`readable_graph.mjs`) → 클릭 · 속성. 전체 지도는 개요, 읽는 대상은 근접 화면.
   - 진행은 `<take>/progress.json`, 완료 · 오류는 `timing.json` · `end-state.json`. 실측 73큐 약 13분.
5. 구간 고르기 · 합성 — [합성설정_예시.json](합성설정_예시.json)을 `$E/<name>-manifest.json`으로 복사해 값을 맞춘다. 실패 take는 `before_cue`(그 큐 시작 250ms 전까지) 또는 `end_ms`로 정상 부분만, 첫 프레임이 이전 커서면 `start_frame`.
   ```bash
   for s in select check capture encode; do <py> $N/lesson_pipeline.py $E/<name>-manifest.json $s; done
   ```
   발화 중간 절단 · 큐 누락/중복 · 음성 불일치 · 저장 결과 불일치 · 같은 `name`의 MP4 · 영상 · 음성 길이 0.1초 넘는 차이면 멈춘다. `capture`가 manifest `captures`의 단계 사진 · 검수판 · 이음매를 뽑는다.
6. 가이드 · 패키지 — `<py> workspace/강의제작/제작도구/실습시작/build_common.py --lab relations`.
7. 조각 고침
   - 말만, 녹화 원본 없음 — `$N/voice_patch.py`로 그 자리 소리만 바꾼다(게시 소리가 음성 캐시를 자막 시각에 놓은 것인지 먼저 확인 — 큐별 상관 1.0 · 0.3 ms 안. 새 음성은 원래 시작 자리, 길면 앞 빈 시간으로, 앞뒤 0.15초).
   - 녹화 원본 있음, 음성 · 포인터 표시만 — `polish_recording.py`(바뀐 음성 길이만큼 발화 끝 여유만 늘리거나 줄임, 조작을 자르게 되면 멈춤) → 새 manifest로 5.
     ```bash
     <py> $N/repair_pointer_display.py $E/<움직임 보고서>.json $E/<보정 폴더> --motion <번호> …   # 필요할 때만
     <py> $N/polish_recording.py $E/<앞 판 manifest>.json $E/<새 판>-cues.json <새 음성 폴더> <새 이름> $E/<포인터 보정 목록>.json
     ```
   - 실패 큐 뒤만 — 정상 큐 원본을 두고 `before_cue`로 자른 뒤 같은 상태에서 `continue` · `only` · `pointer`로 이어 찍는다.

## 함정

- 호출이 바뀌면 metrics가 풀려 입력칸 · 탭이 겹치고 클릭이 안 된다 → 모든 호출 시작에 같은 metrics를 걸고 입력 가능 여부를 본다. 이름 편집은 탭을 더블클릭.
- 커서만 부드럽고 그림은 끊김(실제 이동 4점) → 실제 이동 약 33ms 간격, 누름 · 뗌도 원본에.
- 1080p인데 글씨 · 그래프가 작다 → CSS 1536×864로 UI를 키우고 대상은 앱에서 확대 · 이동.
- 「유온」 대신 「유온 센서」를 선택 → 정확히 일치하는 표시 이름 우선, 속성 id 대조.
- 다음 노드를 못 찾거나 화면 밖을 클릭 → 선택 해제 → 전체 맞춤 → 캔버스 실제 좌표 관찰 → 안정 확인 뒤 이동 · 선택. 좌표 추측을 되풀이하지 않는다.
- 위아래 두 노드 사이 관계가 안 눌림 → 두 원 중심 사이 35% 지점.
- 공급 조건 표 마지막 열이 화면 밖(5열) → 공급사 · 승인 여부 · 조건 맵 3열 질의로.
- `Page.captureScreenshot` 시간 초과 · 일반 screenshot과 첫 screencast 프레임이 잘림 → 화면 사진은 screencast 프레임으로, 녹화 직전 새 프레임으로 연결 창을 확인.
- 입력 커서가 결과를 가리고 이동 공백 최대 250ms(해상도 안정 전에 시계 시작) → 해상도 안정 뒤 시계 시작, 입력 커서는 아래 여백으로(녹화 코어 반영 여부 미확인).
