# Neo4j Browser 촬영준비

Neo4j Browser 화면(학생 링크로 여는 자동 연결 창에서 Cypher를 실행하고 그래프를 탐색하는 장면)을 이 PC의 ego로 찍는다(클라우드에서는 찍을 수 없다). 명령은 Git Bash에서 저장소 루트를 현재 위치로 두고 실행한다. 줄임: `<py>` = `PYTHONUTF8=1 .venv314/Scripts/python.exe`, `N=workspace/강의제작/제작도구/촬영/neo4j`, `E=작업/촬영/neo4j`. 규칙은 [영상](../../../지침/영상.md), 여러 도구 공통은 [README](../README.md)에 있다.

## 길

1. 원고 — 큐 JSON을 손으로 고치지 않는다. `$N/build_common_cypher.py`의 `narration_polish`에 `큐 ID: 새 문장`을 넣고 `<py> $N/build_common_cypher.py`를 돌린다(두 큐 JSON을 통째로 다시 쓴다).
2. 대본 — `<py> $N/sync_integrated_script.py`를 돌려 두 과정의 대본(통합반 02회차 04, 실전반 02회차 05)을 만든다.
3. 음성 — 큐를 `$E/<판>-cues.json`으로 복사하고, 새 음성 폴더 `$N/음성/<폴더>/`에 앞 판 음성(`<큐 ID>.mp3`와 `.json`)을 먼저 복사한다. 그다음 `common.AUDIO`를 그 폴더로, `FFMPEG`를 바꿔 주는 감싼 실행으로 [포털 voice.py](../포털/촬영도구/voice.py) `<판>-cues.json`을 돌린다(글이 같은 큐는 건너뛴다). 감싼 실행 스크립트는 저장소에 없으니 만들어 쓴다.
4. 녹화(ego) — 랩 DB를 켜고(랩의 `lab_db.py`가 HTTP 200을 기다린 뒤 주소를 낸다), 학생 연결 파일의 주소로 연다. 이전 흔적은 `:clear` → 입력칸 비움 → 연결 해제 → 학생 주소로 다시 접속, 이 순서로 정리한다(DB를 지우거나 초기화하지 않는다). 연결 창 전체가 화면 안에 들어와야 한다(잘리면 `Connection dialog clipped`로 멈춘다).
   - 녹화 설정 JSON(키 `repo,evidence,take,space,host,readable,width,height,audio,cues`)을 `$E/`에 둔다. take는 매번 새 이름으로 짓고(같은 이름이면 `Existing take preserved`로 멈춘다), `cues`는 늘 준다. 비밀값은 넣지 않는다.
   - 시작 `.mjs`는 한 줄이다: `globalThis.HYD_CONFIG_PATH='<저장소 절대경로>/작업/촬영/neo4j/<설정>.json';await import('file:///<저장소 절대경로>/workspace/강의제작/제작도구/촬영/neo4j/record_from_config.mjs');`
   ```bash
   node --check $E/<설정>.mjs
   ego-browser nodejs -e "await import('file:///<저장소 절대경로>/작업/촬영/neo4j/<설정>.mjs?v1')" < /dev/null
   ```
   - 이어 찍기는 직전의 결과, 선택, 패널, 스크롤을 맞춘 상태에서만 `continue:true` · `only:[큐 ID]` · `pointer:{x,y}`를 주어 한다. 상태 복원과 녹화는 같은 호출에서 한다(호출이 바뀌면 배율과 그래프 배치가 바뀐다).
   - 그래프 대상은 선택 해제 → `Zoom to fit` → 캔버스에 그려진 라벨과 원의 좌표 관찰(`graph_targets.mjs`) → 안정 확인 → 실제 휠과 빈 배경 드래그로 읽을 수 있는 크기까지 키우기(`readable_graph.mjs`) → 클릭과 속성 보기, 이 순서로 다룬다. 전체 지도는 개요로만 보이고, 읽어야 할 대상은 가까이 키운 화면으로 보인다.
   - 진행 상황은 `<take>/progress.json`, 완료와 오류는 `timing.json`과 `end-state.json`에 남는다. 실측으로 73큐에 약 13분 걸렸다.
5. 구간 고르기와 합성 — [합성설정_예시.json](합성설정_예시.json)을 `$E/<name>-manifest.json`으로 복사해 값을 맞춘다. 실패한 take는 `before_cue`(그 큐 시작 250ms 전까지) 또는 `end_ms`로 정상 부분만 쓴다. 첫 프레임에 이전 커서가 남아 있으면 `start_frame`을 준다.
   ```bash
   for s in select check capture encode; do <py> $N/lesson_pipeline.py $E/<name>-manifest.json $s; done
   ```
   다음 중 하나라도 있으면 멈춘다: 발화 중간 절단, 큐 누락이나 중복, 음성 불일치, 저장 결과 불일치, 같은 `name`의 MP4가 이미 있음, 영상과 음성 길이가 0.1초 넘게 차이 남. `capture` 단계는 manifest의 `captures`에 적힌 단계 사진, 검수판, 이음매를 뽑는다.
6. 가이드와 패키지 — 사진은 `<py> $N/사진_만들기.py --work 작업/<작업>/영상프레임`이 게시본 영상의 프레임에 빨간 표시를 그려 두 과정 `images/`와 `capture-provenance.json`에 쓴다(시각 · 표시 좌표는 그 파일 한 곳, 표시 없는 옛 사진은 `$N/사진원본/`). 눈으로 본 뒤 `<py> workspace/강의제작/제작도구/실습시작/build_common.py --lab relations`를 돌린다.
7. 조각 고침
   - 말만 바꿨고 녹화 원본이 없으면 `$N/voice_patch.py`로 그 자리의 소리만 바꾼다. 먼저 게시본 소리가 음성 캐시를 자막 시각에 놓은 것인지 확인한다(큐별 상관이 1.0이고 어긋남이 0.3 ms 안). 새 음성은 원래 시작 자리에 두고, 길면 앞의 빈 시간으로 당기며, 앞뒤에 0.15초를 둔다.
   - 녹화 원본이 있고 음성과 포인터 표시만 바꾸면 `polish_recording.py`를 쓴다(바뀐 음성 길이만큼 발화 끝 여유만 늘리거나 줄이고, 조작을 자르게 되면 멈춘다). 그다음 새 manifest로 5를 한다.
     ```bash
     <py> $N/repair_pointer_display.py $E/<움직임 보고서>.json $E/<보정 폴더> --motion <번호> …   # 필요할 때만
     <py> $N/polish_recording.py $E/<앞 판 manifest>.json $E/<새 판>-cues.json <새 음성 폴더> <새 이름> $E/<포인터 보정 목록>.json
     ```
   - 실패한 큐 뒤만 다시 찍으려면, 정상 큐까지의 원본을 두고 `before_cue`로 자른 뒤 같은 상태에서 `continue` · `only` · `pointer`로 이어 찍는다.

## 함정

- 호출이 바뀌면 metrics가 풀려 입력칸과 탭이 겹치고 클릭이 되지 않는다. 모든 호출의 시작에 같은 metrics를 걸고, 입력할 수 있는 상태인지 본다. 이름 편집은 탭을 더블클릭해서 한다.
- 커서만 부드럽고 그림은 끊긴다(실제 이동이 4점뿐이었다). 실제 이동을 약 33ms 간격으로 보내고, 누름과 뗌도 원본 입력으로 보낸다.
- 1080p인데 글씨와 그래프가 작다. CSS 1536×864로 UI를 키우고, 대상은 앱 안에서 확대하고 옮긴다.
- 「유온」 대신 「유온 센서」를 선택한다. 표시 이름이 정확히 일치하는 것을 먼저 고르고, 속성 id로 대조한다.
- 다음 노드를 찾지 못하거나 화면 밖을 클릭한다. 선택 해제 → 전체 맞춤 → 캔버스의 실제 좌표 관찰 → 안정 확인, 이 순서를 거친 뒤 옮기고 선택한다. 좌표 추측을 되풀이하지 않는다.
- 위아래로 놓인 두 노드 사이의 관계가 눌리지 않는다. 두 원 중심 사이의 35% 지점을 누른다.
- 공급 조건 표의 마지막 열이 화면 밖에 있다(5열). 공급사, 승인 여부, 조건 맵의 3열만 뽑는 질의로 바꾼다.
- `Page.captureScreenshot`이 시간 초과되고, 일반 screenshot과 첫 screencast 프레임은 잘린다. 화면 사진은 screencast 프레임으로 받고, 녹화 직전에 새 프레임으로 연결 창을 확인한다.
- 입력 커서가 결과를 가리고, 이동 공백이 최대 250ms 생긴다(해상도가 안정되기 전에 시계를 시작한 탓이다). 해상도가 안정된 뒤 시계를 시작하고, 입력 커서는 아래 여백으로 옮긴다(녹화 코어에 반영됐는지는 미확인).
