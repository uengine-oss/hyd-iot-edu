## NEW terms — 오늘 다룬 핵심 개념과 주요 용어 정리
### 화면 내용
- 유형: 표
- 메시지: 공급 관계의 모델과 조건 판정에서 쓰는 용어를 정식 명칭과 한 줄 뜻으로 모은다.
- 머리: 용어 | 정식 명칭 · 풀이
- 요소:
  1. 클래스 · 인스턴스 | Class · Instance / 같은 정의를 따르는 대상의 유형과, 그 유형에 속하는 실제 대상 하나
  2. 스키마 | Schema / 클래스 · 속성 · 관계 · 제약을 일관되게 정한 지식 구조의 정의
  3. 식별자 | Identifier / 같은 대상을 하나로 가리키는, 바꾸지 않는 고유한 값
  4. 제약 | Constraint / 데이터가 지켜야 할 조건으로, 어긋난 데이터를 가려내는 기준
  5. SOP | Standard Operating Procedure / 작업의 순서와 전제 · 안전 · 금지 · 완료 기준을 정한 표준 작업 절차
  6. DMN · 결정표 | Decision Model and Notation · Decision Table / 입력 조건에 따른 출력을 규칙 행으로 정하는 의사결정 표준과 그 표
