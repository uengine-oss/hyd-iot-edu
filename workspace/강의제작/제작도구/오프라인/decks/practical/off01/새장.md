## NEW terms — 오늘 다룬 핵심 개념과 주요 용어 정리

- 요소:
  1. OT · IT | Operational Technology · Information Technology / 설비 제어(OT)와 정보 처리(IT)를 맡는 기술
  2. DMZ | Demilitarized Zone / OT·IT 간 데이터·명령의 출입을 검사하는 완충 구역
  3. PLC | Programmable Logic Controller / 센서 값을 읽고 논리대로 설비를 제어하는 산업용 장치
  4. MQTT | Message Queuing Telemetry Transport / 브로커로 발행자·구독자를 잇는 경량 메시지 규약
  5. SCADA | Supervisory Control and Data Acquisition / 설비 데이터 수집·감시·원격 제어를 맡는 시스템
  6. CEP | Complex Event Processing / 값·추세·지속 시간의 조합에서 이상을 알아채는 처리
  7. HITL | Human-in-the-Loop / 자동 처리 중간에 사람이 승인 · 거절로 결정하는 구조
  8. MES | Manufacturing Execution System / 생산 지시 · 실적 · 납기를 관리하는 제조 실행 시스템
  9. 데이터 리니지 | Data Lineage / 판단 결과에서 원천 계측값까지 되짚도록 남긴 데이터의 내력
  10. 온톨로지 | Ontology / 대상의 종류·속성·관계·제약을 명시적으로 정의한 공통 지식 모델
  11. 지식 그래프 | Knowledge Graph / 온톨로지의 정의에 맞춰 실제 대상과 관계를 채운 지식
