## NEW six — 여섯 개념이 푼 문제와 남기는 산출물
### 화면 내용
- 유형: 표
- 메시지: 에이전트를 업무에 맡기기까지 여섯 개념이 저마다 다른 문제를 풀고, 각각 확인할 수 있는 산출물을 남긴다.
- 머리: 개념 | 푼 문제 | 남기는 산출물
- 요소:
  1. Agent | 목표에 따라 도구를 골라 반복하고 / 근거가 모자라면 멈춘다 | 점검 요청 초안
  2. Skill | 반복할 절차와 판단 기준을 묶어 / 다른 자료에도 같게 쓴다 | 작업 지침 / 다음 협의 안건
  3. MCP | 다른 시스템과 자기 자료를 / 정해진 도구로 읽는다 | 연결 설정 / 조회 도구
  4. HITL | 묻고 멈출 자리와 / 사람이 정할 결정을 나눈다 | 질문 · 재개 기록 / 승인 · 거절 기록
  5. SDD | 바뀐 요구에서 지킬 것을 / 구현 전에 정한다 | spec.md
  6. **BDD** | 정한 대로 행동하는지 / 실행으로 확인한다 | 시나리오 · 판정 코드 / 회귀 기록
- 노트: [짚을 곳] 표 여섯 줄(만난 차례) → 셋째 열 산출물 → 위 셋과 아래 셋의 가름 / · 에이전트는 목표에 따라 도구를 골라 되풀이하고, 근거가 모자라면 멈춰요. 그 결과가 점검 요청 초안입니다. 스킬은 절차와 판단 기준을 묶어 다른 회의록에도 같게 쓰게 하고, MCP는 다른 시스템과 자기 자료를 정해진 도구로 읽게 합니다. / · HITL은 묻고 멈출 자리와 사람이 정할 결정을 나누고, 질문 · 재개 기록과 승인 · 거절 기록을 남겨요. SDD는 지킬 것을 구현 전에 spec.md로, BDD는 정한 대로 하는지를 시나리오 · 판정 코드 · 회귀 기록으로 확인합니다. / · 위 셋은 일을 해내게 하고, 아래 셋은 믿고 맡기게 합니다. 여섯이 함께 있어야 업무에 맡길 수 있어요. / [다음] 스킬과 MCP가 푼 문제를 가려 보겠습니다.
