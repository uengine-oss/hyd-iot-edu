### 강사 음성 구매

제작 의뢰에서 정한 상한을 `HYD_CREDIT_CAP`에 넣는다. 계정 조회에서 지정 목소리와 남은 크레딧을 확인하고 대표 구획 한 개의 실제 지출을 기록한 뒤 나머지를 구매한다. 생성 기록은 편별로 보관한다.

```bash
: "${HYD_CREDIT_CAP:?제작 의뢰에서 승인한 편별 크레딧 상한을 지정한다}"
"$PY" "$T/음성키.py" 계정 "$V"
"$PY" "$T/음성키.py" 실행 "$PY" "$T/음성사기.py" "$W/구매기록.json" "$S" --voice "$V" --상한 "$HYD_CREDIT_CAP" --한도 1
```

첫 구획 지출을 확인한 뒤 같은 기록에 이어 쓴다. 결과에서 파형이 없는 구획·쉼이 필요한데 조용한 자리가 없는 곳을 확인한 뒤 굽기로 넘어간다.

```bash
"$PY" "$T/음성키.py" 실행 "$PY" "$T/음성사기.py" "$W/구매기록.json" "$S" --voice "$V" --상한 "$HYD_CREDIT_CAP"
"$PY" "$T/쉼옮기기.py" "$S" --파형 --voice "$V" --출력 "$W/파형검사.json"
"$PY" - "$W/파형검사.json" "$S" "$T" "$V" "$W/구매기록.json" <<'PY'
import hashlib, json, sys
from pathlib import Path
check = json.loads(Path(sys.argv[1]).read_text(encoding="utf-8"))
if check["구획"] or check["조용한곳없음"] or check["요약"].get("파형_음성없음", 0):
    raise SystemExit("파형검사.json의 구획과 파형을 다시 확인한다")
sys.path.insert(0, sys.argv[3])
import 강의영상 as tool
ledger = json.loads(Path(sys.argv[5]).read_text(encoding="utf-8"))
for first, _, text in tool.slides_text(sys.argv[2]):
    key = tool.cache_key(text,sys.argv[4],tool.a.model,tool.a.speed)
    mp3 = tool.CACHE / (key+".mp3")
    record = ledger["completed"].get(key)
    if not (mp3.exists() and (tool.CACHE/(key+".json")).exists() and record and
            hashlib.sha256(mp3.read_bytes()).hexdigest() == record["sha"]):
        raise SystemExit(f"{first}장 음성 또는 구매기록을 확인한다")
PY
```

### 영상 굽기와 재생 검사

공통 지침의 제작 환경에서 맑은 고딕 일반·굵게, 지정 LibreOffice와 `pdftoppm`, `ffmpeg`, `ffprobe`를 준비한다. 명령은 편별 작업 폴더에 강조 전후 영상을 따로 만든다.

```bash
"$PY" "$T/강의영상.py" "$O" "$S" --breath --voice "$V" --audio-ledger "$W/구매기록.json" \
  --pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
"$PY" "$T/검사/말머리_잘림.py" "$O/$N.mp4"
"$PY" "$T/검사/장넘김_싱크.py" "$O/$N.mp4" "$R/${N}_시간표.md"
"$PY" "$K/자막대조.py" "$R" "$S"
mkdir -p "$W/강조후"
"$PY" "$T/강조표시.py" "$O/$N.mp4" "$C/강조_$N.json" "$W/강조후/$N.mp4" --확인 "$W/강조프레임"
```

강조 프레임의 대상과 말이 일치하는지, 자막·장 전환·말머리가 맞는지 최종 영상을 소리와 함께 확인한다. 구매·굽기 후의 강사 음성 및 완성 영상 측정치는 제작자가 기록한다.
