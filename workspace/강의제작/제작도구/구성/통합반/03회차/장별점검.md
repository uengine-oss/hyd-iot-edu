저장소 루트에서 Bash로 실행한다. 아래 함수는 선택한 편의 저장된 명령만 꺼낸다. 각 단계마다 준비 변수를 다시 설정하므로 새 터미널에서도 같은 파일과 음성 지출 장부를 사용한다. `음성`은 승인 상한을 설정한 후 같은 계정에서 실행한다. `굽기`는 구매와 파형 확인을 마친 뒤에 실행한다.

```bash
EP=03  # 01, 02 또는 03
CFG3=workspace/강의제작/제작도구/구성/통합반/03회차/제작입력.json
run_ep() (
  set -euo pipefail
  plan=$(python3 - "$CFG3" "$EP" "$1" <<'PYGEN'
import hashlib, json, pathlib, sys
data = json.loads(pathlib.Path(sys.argv[1]).read_text(encoding="utf-8"))
part = data["편"][sys.argv[2]]
for path, expected in [(data["덱"], data["덱_SHA256"]),
                       (part["대본"], part["대본_SHA256"]),
                       (part["강조설정"], part["강조설정_SHA256"])]:
    if hashlib.sha256(pathlib.Path(path).read_bytes()).hexdigest() != expected:
        sys.exit(f"판본 불일치 {path}")
stages = {"사전": ["비용없는사전확인"], "음성": ["승인후_강사음성"],
          "굽기": ["장그림준비", "영상제작"]}
commands = part["제작실행"]
for section in ["준비", *stages[sys.argv[3]]]:
    print(*commands[section], sep="\n")
PYGEN
  )
  bash -eu -o pipefail -c "$plan"
)
run_ep 사전
```

승인 상한을 받은 뒤 같은 셸에서 `export CAP=<승인한_누계_크레딧>`의 자리표시자를 승인 금액으로 바꾸고 `run_ep 음성`을 실행한다. 전 구획의 음성과 쉼 파형을 확인한 뒤 `run_ep 굽기`를 실행한다. 이 단계에서 말머리, 장넘김, 자막, 표시 프레임을 검사한다.
