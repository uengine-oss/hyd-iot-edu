음성은 `tools/video/음성_저장/`, 쉼은 `쉼_저장/`에 모두 있다(이번 개편의 음성 기록 누계 21,379크레딧, 끊긴 요청 한 번의 손실 약 292크레딧 별도). 같은 판으로 다시 구우면 새 크레딧은 0이다.

### 제작 때 실행할 명령

저장소 루트에서 편마다 한 셸로 실행한다. 출력 폴더는 제작 때 연 작업 폴더 아래에 편마다 따로, 절대 경로로 둔다. 굽는 동안 PPTX와 장 그림을 바꾸지 않는다. 키는 환경 변수 `ELEVENLABS_API_KEY`나 `음성키.py 실행`으로 넘기고, 키 값과 키 파일 경로는 적지 않는다. `CAP`은 사용자가 승인한 그 편 음성 기록의 누계 크레딧 상한이다(공통 C-5). 대본을 고치지 않았으면 음성 사기 두 줄은 새 구획 0으로 끝난다.

```bash
set -eu
G=workspace/강의제작
T="$G/제작도구/기존제작/tools/video"; K="$G/제작도구/검사"; C="$G/제작도구/구성/실전반/02회차"; D="$G/산출물/실전반/이론/02회차/대본"
V=1PdAOcPlPTz12RwMyFVp
W="$(pwd)/작업/<제작 작업 폴더>"
EP=01_이론_클래스와인스턴스      # 02_이론_스키마설계 · 03_이론_그래프저장과조회 · 04_이론_작업절차와판단조건
STEM="실전반_02회차_${EP}"; F="$W/영상출력/$EP"; OUT="$F/영상"; SIDE="$F/_작업/영상_자막_기록"
MARK="$C/강조_${STEM}.json"; LEDGER="$F/음성기록.json"
mkdir -p "$OUT"
sha256sum "$G/산출물/실전반/이론/02회차/실전반_02일차.pptx" "$D/$EP.md" "$MARK"   # 위 표의 해시와 같아야 한다
python3 "$K/판본검사.py" 실전2
python3 "$T/강의영상.py" "$OUT" "$D/$EP.md" --breath --dry
python3 "$T/강조좌표.py" --검사 "$D/$EP.md" "$MARK"
python3 "$T/음성견적.py" "$D/$EP.md" --voice "$V"
: "${CAP:?승인된 편별 누계 상한}"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$LEDGER" "$D/$EP.md" --voice "$V" --한도 1 --상한 "$CAP"
python3 "$T/음성키.py" 실행 python3 "$T/음성사기.py" "$LEDGER" "$D/$EP.md" --voice "$V" --상한 "$CAP"
python3 "$T/쉼옮기기.py" "$D/$EP.md" --출력 "$F/쉼파형.json" --파형 --voice "$V"   # 조용한곳없음 0
python3 "$T/강의영상.py" "$OUT" "$D/$EP.md" --breath --voice "$V" --audio-ledger "$LEDGER" --pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2
python3 "$T/검사/말머리_잘림.py" "$OUT/$STEM.mp4"
python3 "$T/검사/장넘김_싱크.py" "$OUT/$STEM.mp4" "$SIDE/${STEM}_시간표.md"
python3 "$K/자막대조.py" "$SIDE" "$D/$EP.md"
python3 "$T/강조표시.py" "$OUT/$STEM.mp4" "$MARK" "$F/강조/$STEM.mp4" --확인 "$F/강조프레임"
python3 "$T/입고.py" "$F" --시험
python3 "$T/입고.py" "$F"
```

네 편은 편마다 다른 `EP`로 위 블록을 따로 돌리고, 동시에 3편까지만 굽는다. 실측 장별점검표는 굽기 뒤 `장별점검_생성.py 실전2 --출력 "$C/장별점검_실측.md" --바탕 <이 표> --시간표 <네 편의 시간표를 모은 폴더>`로 따로 쓴다.
