# 랩 폴더와 파일 이름

프로젝트 구조와 학생용 문서 범위의 정본은 [코딩랩.md](../../../지침/코딩랩.md) K-5~K-7이다. 새 구조를 맡은 랩만 이전하며 다른 회차를 일괄 재생성하지 않는다.

- 프로젝트 폴더는 하는 일을 나타내는 영어 `kebab-case`로 짓는다. 예: `ontology-lab`, `graph-lab`.
- 내부 폴더·데이터·코드 파일·함수·변수는 영어 `snake_case`를 쓴다. 도구가 정한 `README.md`, `AGENTS.md` 등의 이름은 그대로 쓴다.
- CSV의 업무 열 이름과 기존 데이터 값·그래프 속성 키는 파일명 정리 때문에 바꾸지 않는다. 화면, 주석, 설명은 한국어로 쓴다.
- 이름은 역할이 드러나게 짓는다. 예: `equipment.csv`, `name_rules.py`, `render.py`, `lab_db.py`.
- 학생 안내는 루트 README 하나다. 자세한 실습 가이드는 프로젝트 밖에 두고, 생성 원본·정답·제작 기록은 학생 묶음에 넣지 않는다.
- 모델 접속은 값이 빈 `.env.example`만 제공한다. 실제 `.env`와 DB 연결 정보는 묶거나 커밋하지 않는다.
