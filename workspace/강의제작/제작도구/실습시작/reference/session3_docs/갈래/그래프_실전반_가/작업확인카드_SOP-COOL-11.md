# 작업 확인 카드 — SOP-COOL-11 팬 최대 운전

## 대상 작업

- SOP-COOL-11 팬 최대 운전 — 근거 문서 HM-8 1.1판(현행, 시행 2026-09-01) HM-8.5 · 설비 HYD-02(같은 모델 HYD-01 · HYD-03)

## 준비 조건

- HM-8 1.1 HM-8.5: 「원격 조치는 PLC 운전 모드가 REMOTE_AUTO일 때만 한다.」(후보 HM-8-M028)
- HM-8 1.1 HM-8.6: 「조치 후 예측 유온이 55 ℃ 이상이면 경보 해제에 실패할 수 있으므로 다른 조치와 비교한다.」(후보 HM-8-R26)

## 금지 · 제한

- HM-8 1.1 HM-8.5: 「현장에서 수동 조작이 들어와 REMOTE_MANUAL이면 원격 조치를 내리지 않는다.」(후보 HM-8-M029)
- HM-8 1.1 HM-8.5: 「펌프 부하는 60 % 아래로 내리지 않는다(최소 부하 인터록).」(후보 HM-8-M030)
- HM-8 1.1 HM-8.8: 「- 원격 조치(SOP-COOL-11~13)는 REMOTE_AUTO가 아닐 때 쓰지 않는다.」(후보 HM-8-M068)
- HM-8 1.1 HM-8.8: 「- 펌프 부하를 60 % 미만으로 설정하지 않는다.」(후보 HM-8-M072)
- HM-8 1.1 HM-8.5: 「100 % 연속 운전은 24시간 이내로 한다.」(후보 HM-8-R23)
- HM-8 1.1 HM-8.8: 「이미 24시간을 넘겼다면 팬 최대 운전 조치는 팬 수명 손실로 20만 원을 감점해서 비교한다.」(후보 HM-8-R30)
- HM-9 1.0 HM-9.1: 「펌프 부하는 6 0 % 아래로 내리지 않는다(최소 부하 인터록).」(후보 HM-9-M001)
- SR-04 2024 제4조: 「유압 설비의 실측 유온이 인터록 한계(65 ℃)를 넘으면 설비가 정지한다.」(후보 SR-04-M001)
- SR-04 2024 제4조: 「② 운전 중에는 인터록 한계에 다가가는 조치를 하지 않는다.」(후보 SR-04-M002)

## 작업 순서

1. PLC 운전 모드가 REMOTE_AUTO인지 확인한다. — HM-8 1.1 HM-8.5 「PLC 운전 모드가 REMOTE_AUTO인지 확인한다.」
2. 팬 속도를 100 %로 올린다. 100 % 연속 운전은 24시간 이내로 한다. — HM-8 1.1 HM-8.5 「팬 속도를 100 %로 올린다. 100 % 연속 운전은 24시간 이내로 한다.」
3. 15분 재관측으로 HM-8.6 회복 판정을 한다. — HM-8.5 SOP-COOL-11 단계 3 「15분 재관측으로 HM-8.6 회복 판정을 한다.」

## 완료 기준

- HM-8 1.1 HM-8.6: 「조치 뒤 15분 동안 TS1이 55 ℃ 미만이고 경보가 해제된 상태가 유지되면 완화에 성공한 것이다.」(후보 HM-8-M045)
- HM-8 1.1 HM-8.6: 「회복하지 않으면 결과 보고에 미달로 적는다.」(후보 HM-8-M046)

## 작업 직전 확인할 현재 값

- 쿨러 냉각 효율 CE · 유온 TS1(HYD-02) — 그래프에 없는 현재 값. 시계열(관측값)에서 읽는다. 문서의 기준값(완료 기준)과 구별한다.
- PLC 운전 모드 · 상태 — 그래프에 없는 현재 값. PLC 상태 수신(시계열)에서 읽는다.
