| CONDITION_OF | 연결 | Skill | 검토 결과 |
| DESCRIBES | 같은 단계의 원문 | Step | 검토 결과 |
| SUPPORTS | 연결 | Rule | 검토 결과 |
| EVIDENCE_FOR | 연결 | Cause · FailureMode | 검토 결과 |
| APPLIES_TO | 연결 | Asset · Component · Sensor · Part | 검토 결과 |
