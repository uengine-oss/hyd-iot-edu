# 문서 지식 검토 기록

> 강사 참조 — 두 번째 구현(규칙 기반)의 후보를 갈래 규칙으로 검토한 판이다.

## 목표와 질문

핀 세척(SOP-COOL-14) 작업지시 전에 작업 조건과 판정에 쓴 조건의 원문 근거를 확인하고, 같은 기능이 다른 문서에서 빠뜨리거나 지어내지 않는지 센다.

## 이 답을 쓰는 사람과 쓰는 곳

설비보전팀장(작업지시 승인).
