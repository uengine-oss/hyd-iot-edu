# 고침 의뢰 — {과정} {NN}회차 점검 목록만

서브에이전트 생성 금지 · 커밋 금지 · 한국어.
**목록에 있는 항목만 판정한다 — 새 지적 0, 목록 밖 문장은 글자 하나 바꾸지 않는다.** 원고를 직접 편집하지 않는다(도구만 쓴다). 실행은 한 번.

## 기준 — `workspace/강의제작/지침/대본.md`의 S-2(순서) · S-4(되풀이)
- 목록의 항목은 심각도와 상관없이 판정한다(음성 비용 때문에 규칙 어긋남을 남기지 않는다 — 대본.md 「함정」).
- 이 고침으로 생기면 안 되는 것: 지운 문장만 가진 정의 · 값이 사라짐, 「그 ~」 「이 ~」가 가리킬 것이 사라짐, 장 경계 첫 문장 · 끝 문장이 끊김, 장 첫 문장의 화면 위치어(S-3) · 자리 장의 자리 말(S-9)이 사라짐, 물음을 지워 답만 남음.
- 바뀐 장의 노트(S-12)는 대본과 같은 내용 · 순서 · 값(한 줄, ` / `가 줄바꿈, `[짚을 곳]` 시작 · `[다음]` 끝).

## 읽을 것(끝까지)
`{작업폴더}/입력/작업_{과정}_{NN}.md`. 세운 자리가 의심스러우면 `{작업폴더}/입력/{과정}_{NN}.md`에서 찾는다(앞 자리에 그 풀이가 없으면 지우면 안 된다).

## 판정 — `{작업폴더}/판정/{과정}_{NN}.json`
항목마다 하나: `적용` · `수정`(최소로 고친 `후` + 까닭) · `보류`(지적이 틀림 + 까닭) · `포함`(`대상`에 그 번호). 도구는 목록 순서로 적용한다.
```json
{"판정":{"T3-01":{"처리":"적용"},"T3-02":{"처리":"수정","후":"…","까닭":"…"},"T3-03":{"처리":"보류","까닭":"…"},"T3-04":{"처리":"포함","대상":"T3-03"}},
 "노트추가":[{"장":14,"노트전":"노트 글자 그대로","노트후":"…","까닭":"…"}]}
```

## 도구(저장소 루트)
`<py> workspace/강의제작/제작도구/검사/점검적용.py 시험 {작업폴더} {과정} {NN}` 실패 0까지 판정을 고친 뒤 `… 실행 …` 한 번.

## 보고(다섯 줄 안)
적용 · 수정 · 보류 · 포함 · 노트추가 수, 시험 · 실행 결과, 보류 까닭 요약, 판정 파일 경로.
