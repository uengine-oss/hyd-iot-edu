# 영상 검토 의뢰 — {덱키} 이론 영상

서브에이전트 생성 금지(직접 본다) · 커밋 · push 금지 · fable 금지 · 한국어.
**검토는 이번 한 번뿐이다 — 재검토 없음.** 영상 · 강조 설정 · 대본 · 덱 · 장별점검을 고치지 않고, `강의영상.py` · `강조표시.py` · soffice를 돌리지 않는다(ffprobe · 프레임 몇 장 뽑기는 된다). 쓰는 곳은 판정 파일 · 고칠목록뿐.

## 읽을 것(끝까지)
1. `workspace/강의제작/지침/공통.md` + `영상.md`.
2. 영상 출력 `{작업폴더}/영상출력/{편}/`(강조 뒤 `강조/*.mp4`, 자막 · 시간표 `_작업/영상_자막_기록/`, 확인 프레임 `확인/표시NN.png`), 강조 설정 `workspace/강의제작/제작도구/구성/{과정}/{NN}회차/강조_*.json`, 대본, 장 그림 `…/tools/video/슬라이드/{과정}_{NN}일차/`, 뺀 강조 `{작업폴더}/렌더/강조확인/{덱키}/뺀목록.txt`, `{작업폴더}/장별점검.md`.
3. 덱 · 대본 판정 `{작업폴더}/판정/{덱키}_*.json` — 대본 문장으로 정해지는 규칙은 그 판정을 근거로 재사용하고, 영상이 그 대본 그대로인지만 잰다.

## 볼 것(이 순서)
1. 강조: 확인 프레임 전부(4~6장 묶음 그림으로 보고 의심만 원본). 대상을 감싸는가 · 글을 가리거나 이웃 글자를 가로지르는가 · 화면 밖 · 동시 표시 헷갈림 · 「문장」 시각과 프레임이 맞는가.
2. 장별점검: 모든 장을 덮는가, 길이가 시간표 실측과 같은가(다섯 곳 이상), 2분 넘는 장의 대상이 그 그림에 있는가.
3. 기술: 대본 수 = 영상 수 · 이름 규칙 · 100 MiB 아래 · 말머리 잘림 0 · 장넘김 어긋남 0 · 영상 = 음성 길이(ffprobe) · `<py> workspace/강의제작/제작도구/검사/자막대조.py <자막 폴더> <대본 …>` 어긋남 0.
4. 강조 앞뒤 같음: 소리 길이 · 장면 수가 같고, 장 경계 세 곳이 시간표 시각에 넘어간다.
5. 나머지 규칙: 게시 · 커밋 뒤에만 볼 것과 사용자 청취는 `미확인`.

## 올린다 / 올리지 않는다
- 올린다: 실제로 본 결함 — 위치(영상 · 시각 · 장 · 표시 번호) · 근거(프레임 파일) · 고칠 방법. **원인 하나 = 한 건.**
- 올리지 않는다: 취향 · 「더 있으면 좋겠다」. 강조가 없다는 것만으로는 결함이 아니다.

## 출력
- 판정 파일(틀 그대로, 규칙마다 `상태` · `근거`).
- `{작업폴더}/판정/{덱키}_영상_고칠목록.json`: `{"고칠목록":[{"영상":"…","장":0,"표시":[0],"시각":"mm:ss","문제":"…","근거":"…","제안":"…","규칙":["V-n"]}],"못 본 것":[]}`
