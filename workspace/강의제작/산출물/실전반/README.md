# 실전반

회차마다 최신 판 하나다. 내용 상태는 각 산출물 문서(`workspace/강의제작/지침/`)와 영상 상태 표(`../영상/README.md`)가 갖는다. 「확정」 칸은 사용자가 그 판의 실물을 보고 말한 원문 · 날짜 · 판만 적는 확정 장부이고(공통 C-5), 원문이 없는 회차는 비워 둔다. 1회차는 통합반 1회차 본보기 판의 사본(표지 과정 칸만 다름)이고, 그 사용자 확정은 통합반 README 1회차 칸에 있다.
