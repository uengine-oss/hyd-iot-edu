# 설비·부품·공급 정보를 연결하는 온톨로지 설계하기

포털 지식 지도에서 본 부품·설비 연결에 공급 조건을 더합니다. 제공된 설비·부품 모델을 확장해 부품별 사용 설비와 공급사별 승인 여부·단가·불량률·납기를 찾습니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py`
