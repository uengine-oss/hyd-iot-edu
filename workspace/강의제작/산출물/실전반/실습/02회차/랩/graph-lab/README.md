# 부품의 사용 설비와 공급 정보를 조회하는 그래프 구현하기

설비·부품·공급 모델을 이 폴더 전용 그래프 DB(랩 DB)에 구현합니다. 부품별 사용 설비와 공급 조건을 돌려주는 조회 결과를 원자료와 대조합니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py`
