# 실전반 2회차 실습 4 — 부품의 사용 설비와 공급 정보를 조회하는 그래프 구현하기

> 촬영용 원고. 실제 AI 생성·실행 장면을 확보한 뒤 발화 시점을 맞춘다. 강사 참조 모델 검증과 본 촬영을 혼동하지 않는다.

## 모델과 질문 확인하기

앞 실습에서는 부품의 사용 설비와 공급 조건을 연결하는 모델을 만들었습니다. 이번에는 그 모델을 별도 그래프 DB에 적재하고 품번으로 사용 설비와 공급 선택지를 직접 조회하겠습니다. 원자료의 조건이 빠지지 않았는지, 같은 데이터를 다시 넣어도 중복되지 않는지 확인합니다. 실습 시작 도구에서 그래프 구현 자료를 열겠습니다. 앞 단계 완성 모델이 제공되므로 개인 결과가 없어도 시작할 수 있습니다.

> [조작] 실습 시작 도구에서 「실전반」 → 「온라인 02회차」 → 「부품의 사용 설비와 공급 정보를 조회하는 그래프 구현하기」 → 「새로 시작」을 누른다. 열린 VS Code에서 START.md를 확인한다. 입력 모델·원자료·질문을 확인한다. 개인 결과는 선택 입력이다. 새 작업용 별도 랩 DB 주소와 빈 상태를 확인하고 기존 예제·포털 DB를 사용하지 않는다.

공급 조건이 모델에 들어 있다는 것과 실제로 찾을 수 있다는 것은 다릅니다. 적재할 때 ID가 유지되고 관계가 빠지지 않아야 합니다. AI에게 현재 구조와 질문을 읽게 하고, 적재와 조회에서 확인할 것을 정하겠습니다.

## 적재와 조회 구현하기

> [요청 구성] 입력 모델을 바탕으로 적재와 부품별 조회를 요청한다. 같은 입력 재적재 시 중복 없음, 부품별 사용 설비·공급 조건, 비승인 표시, 없는 품번의 결과 구분을 완료 기준으로 전달한다. 구현 파일은 결과/load.cypher·query.cypher다. 정답 질의를 미리 제공하지 않는다.

생성된 적재문이 어떤 대상을 만드는지 먼저 보겠습니다. 이름이 아니라 식별자로 같은 대상을 구분하는지, 관계의 양 끝이 입력 모델과 맞는지 확인합니다. 전체 데이터를 지우는 문장은 필요하지 않습니다.

> [조작] 별도 랩 DB에 적재한 뒤 Neo4j Browser에서 생성된 질의를 실행한다. 응답이 나타난 뒤에만 결과를 설명한다.

## 원자료와 결과 대조하기

펌프 축 씰 키트가 쓰이는 설비와 공급 조건을 보겠습니다. 원자료에는 같은 품번의 견적이 네 줄 있습니다. 기준일에 남은 세 공급 조건이 각각 어느 견적에서 왔는지, 비승인 공급사의 표시가 남았는지 확인합니다. 값의 단위도 함께 읽겠습니다. 단가는 만원이고 불량률은 비율입니다.

> [조작] P-PMP-SEAL 조회로 반환된 설비 코드를 구성요소 목록 및 설비 대장의 행에서 각각 찾는다. 공급_조건.csv의 네 줄 중 기준일 전에 끝난 B-OEM 견적과 유효 견적을 구별하고, 반환된 공급 조건 세 행을 승인 목록과 대조한다. P-FAN-BRG로 바꿔 그 부품의 조건이 나오는지 확인한다. 존재하지 않는 품번은 결과 없음으로 확인한다. 승인 공급사만 보고 싶다면 조건을 명시한 별도 조회로 구분하고 원자료 행을 삭제하지 않는다.

견적에 적힌 납기와 실제로 도착하는 데 걸린 날을 비교해 볼게요. 입고 이력에서 같은 주문을 나눠 받은 행을 찾아보세요. 어느 날을 완료일로 보느냐에 따라 계산이 달라집니다.

> [조작] 입력/자료/입고_이력.csv의 주문·입고 기록을 열어 학생이 정한 완료 조건으로 공급사별 실측 납기를 구한다. 견적의 납기와 나란히 놓고, 완료 건이 없는 공급사의 결과를 0일과 구별한다. 수정본에서 바뀐 행·원래 ID를 대조해 반영하고 같은 질문을 재실행한다.

같은 적재문을 다시 실행하겠습니다. 다시 실행할 수 있다는 것뿐 아니라 대상 수와 관계 수가 그대로인지 보겠습니다. 실제로 차이가 생기면 그 부분의 ID와 적재 조건부터 확인하겠습니다.

> [조작] 재적재 전후 개수와 식별자별 중복을 대조한다. 오류가 있으면 실제 결과를 근거로 수정하고 사용 설비·공급 조회를 다시 실행한다. 실패 장면을 일부러 만들지 않는다.

## 조회 결과 저장과 재현

적재문과 조회문, 질문별 결과를 저장하겠습니다. 이 자료로 확인한 것은 사용 설비와 공급 조건입니다. 실제 구매 결정에는 현재 재고와 필요한 시점도 함께 봐야 합니다.

> [조작] 작업 폴더에서 검증 기록을 다시 열어 원자료 대조와 재적재 결과를 확인한다.

이제 별도로 제공되는 완성본에서도 같은 품번을 조회해 보겠습니다. AI 계정 없이 실행할 때도 직접 만든 결과와 같은 기준으로 확인할 수 있습니다.

> [조작] 학생용 완성본을 빈 폴더에 풀어 동봉 안내대로 별도 랩 DB에 적재한다. 같은 품번의 사용 설비와 공급 조건을 조회해 원래 실행 결과와 비교한다. 같은 자료를 다시 넣은 뒤 중복 여부를 확인한 화면으로 마친다.
