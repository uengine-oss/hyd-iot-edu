# 기존 기능과 추가 기능 검증 — 실습 폴더

과제는 [../START.md](../START.md)에 있습니다.

| 폴더 | 내용 |
|---|---|
| `source/` | 원자료(읽기만 함): 요청 · 센서 입력 · 사람의 답과 결정 · 온톨로지 · 매뉴얼, 새 대상 묶음(`새_대상/`) |
| `input/` | 앞 단계 완성 시작본: 긴급 확인 표시까지 된 점검 요청 기능과 그 명세 |
| `output/` | 내가 작성할 결과. 시험 골격 `tests/test_점검요청.py`와 기록 틀은 첫머리에 「제공 빈 틀」 표시 |

접속 키 · 비밀번호를 자료나 결과에 넣지 않습니다.
