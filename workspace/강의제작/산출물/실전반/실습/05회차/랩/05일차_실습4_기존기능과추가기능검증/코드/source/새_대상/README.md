# 새 대상 — 이번 주에 새로 들어온 점검 요청

교육용 가상 자료입니다. 수업용 설비(HYD-01~03)와 온톨로지의 이름만 쓰고, 값은 수업을 위해 만든 것입니다. 실제 설비의 기록이 아닙니다.

검증을 마친 점검 요청 기능을 처음 보는 요청 묶음에 적용해 보는 자료입니다. 칸과 뜻은 `../입력/요청_설명.md`, `../입력/입력_설명.md`, `../사람/쓰는_법.md`와 같습니다.

| 파일 | 내용 |
|---|---|
| `점검_요청.json` | 요청 R11~R16 |
| `센서_입력.json` | 사례 S12~S17 |
| `답변.json` | 이 묶음의 질문에 사람이 적은 답 |
| `승인.json` | 이 묶음의 요청에 사람이 적은 승인 · 거절 |

`../입력/`의 요청 R01~R10과 사례 S01~S11은 이 묶음에 들어 있지 않습니다. 두 묶음의 결과를 섞지 않습니다.
