# 실전반 08회차 — 같은 처리 건의 검토와 인수

> [제작 · 비낭독] 현재 실습용 대본 후보. 실제 교대 흐름의 검토·보완·인수 한 건은 시스템에서 확인했다. 학생별 편집·촬영은 미확인이다.

## 제공 흐름을 연결

`source/handover.bpmn`을 bpmn.io에서 열어 시작, 인계안 작성, 인계자 검토, 인수자 확인과 보완, 종료를 살펴봅니다. `source/mapping.json`을 보며 포털의 시작 입력, 역할과 작업을 연결합니다. 각 초안 작성 단계에는 앞에서 구성한 에이전트를 배정합니다.

> [조작] 제공 흐름을 포털에서 검사하고 별도 판본으로 등록한다. 대상 설비, 교대, 기준 시각과 메모를 입력해 한 처리 건을 시작한다. 기본 A·B·C 흐름은 변경하지 않는다.

## 두 사람이 확인하고 보완

인계자가 초안과 실제 조회 근거를 먼저 검토합니다. 인수자는 내용을 살펴보고 필요한 경우 보완 사유를 적어 같은 처리 건을 돌려보냅니다. 보완된 인계안을 인계자가 다시 검토한 뒤 인수자가 확인합니다.

> [확인] 설비·작업지시·부품·메모 네 영역에 확인된 사실, 불일치와 미확인이 구분되어 있는지 본다. 인수 확인은 전달 기록이며 정비 완료나 설비 조치가 아니라는 확인을 선택한다.

완료 뒤 처리 건 ID, 조회 기준 시각과 근거, 두 사람의 검토, 보완 사유와 남은 확인을 저장합니다. 멈춘 실행은 원래 기록과 도구 응답을 보존하고 강사와 원인을 확인합니다. 새 건을 반복 시작해 실패 기록을 덮지 않습니다.
