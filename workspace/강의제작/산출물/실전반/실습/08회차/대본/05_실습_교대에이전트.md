# 실전반 08회차 — 교대 인계 에이전트와 스킬

> [제작 · 비낭독] 현재 실습용 대본 후보. 화면의 실제 입력과 결과를 확인하며 진행한다. 학생 작성 에이전트의 새 촬영은 미수행이다.

## 무엇을 읽고 어떻게 남길지 정하기

이번 에이전트는 작업 메모를 그대로 사실로 옮기지 않습니다. 허용된 설비 이력과 업무 자료를 읽고 설비 상태, 열린 작업지시, 부품 상태, 메모를 구분해 인계안을 작성합니다.

> [요청] 설비·정비·재고·메모 네 영역을 확인하는 짧은 스킬을 작성해 주세요. 실제 조회한 도구와 결과를 근거로 남기고, 불일치와 확인이 필요한 항목을 구별하세요. 설비 조치·발주·정비 완료를 실행했다고 적지 마세요.

포털에서 에이전트의 역할과 목표, 스킬을 작성하고 수업에서 제공한 읽기 도구를 선택합니다. 이름과 설명은 알아보기 쉽게 쓸 수 있습니다. 모델과 도구 서버를 임의로 바꾸거나 쓰기 도구를 추가하는 것이 목표는 아닙니다.

> [확인] 기준 시각과 실제 조회 시각을 구분하는지, 열린 작업과 메모의 완료 주장, 입고 예정과 실제 재고를 따로 적는지 점검한다. 조회가 실패하면 데이터가 없다고 단정하지 않는다.
