HYD · 실습 가이드

검토 지식으로 작업 확인 카드 만들기

검토한 지식을 랩 DB의 기존 ID에 이어 핀 세척 작업 확인 카드를 만들고, 다른 작업 · 제공되지 않은 절 · 반복 적재를 확인해 저장합니다. 단계마다 「요청에 담을 것」 다섯 칸을 내 말로 채워 AI에게 요청하고(그대로 보내는 글이 아니며, 값은 원자료에서 찾습니다), 「증거」를 확인한 뒤 다음 단계로 갑니다. 막히면 「정답 보기」를 펼칩니다.

01 새 폴더 · 랩 DB 준비

포털 데이터 연결에서 현재 값을 문서의 기준값과 나란히 놓고 구분했습니다. 이번에는 검토한 문서 지식을 별도 랩 DB의 기존 ID에 잇고 핀 세척의 작업 확인 카드를 만듭니다. 사건은 포털에서 본 경보와 같은 종류의 다른 경보 한 건인 10월 27일 01:59(한국 시각) HYD-02 쿨러 성능 저하 경보이고, 그 판정 뒤에 남은 근본 조치가 핀 세척(SOP-COOL-14)입니다.

과정은 온톨로지 → 에이전트 → 프로세스 순서로 올라갑니다. 이 실습은 온톨로지 단계의 마지막 — 검토한 문서 지식을 그래프에 잇고 질문으로 확인하는 일 — 을 맡습니다.

받기 · 도구 「실습 시작」 도구에서 이 실습을 고릅니다. 폴더 신뢰 · 탐색기 · 터미널 · 결과 화면 · AI 채팅 · 편집 승인 창은 「문서에서 작업 조건과 근거를 추출하는 기능 만들기」 가이드와 같습니다. 명령은 직접 치지 말고 블록의 복사로 붙여 넣습니다. 필요한 것 VS Code와 Python, 로그인해 둔 Codex 또는 GitHub Copilot, 랩 DB를 켤 Docker Desktop.

왜 이 폴더 전용 랩 DB에서 하므로 포털에 영향이 없고, 먼저 수를 적어 두어야 뒤에서 늘어난 수를 셉니다.

할 일 python lab_db.py로 랩 DB를 켜고 python show_result.py를 실행해 설비 모델 · 조치 기준의 종류별 수를 결과/구축_기록.md 「적재 수」 첫 줄에 적습니다.

해결할 질문 이 답은 보전 야간조가 핀 세척 전에 카드로 준비 · 금지 · 완료를 원문으로 되짚고, 설비보전팀장이 승인할 때 씁니다.

  1. HYD-02 핀 세척 카드의 항목마다 내용과 원문 절 · 인용은?
  2. 다른 작업의 카드도 만들어지고, 원문이 없는 작업 · 절은 「결과 없음」으로 구별되는가?
  3. 다시 적재해도 수가 같은가? 공급 정보 · 작업 조건을 어디까지 답하고, 현재 값 · 승인 없이 정할 수 없는 것은?

말 풀이 적재는 대상 · 관계를 그래프 DB에 넣는 일이고, 기존 ID는 설비 모델 · SOP 구조 · 조건표가 이미 가진 대상의 ID, 승인 후보는 검토 결과에서 approved가 된 후보입니다. 정할 자리 · 계약은 문서에서 작업 조건과 근거를 추출하는 실습과 같은 뜻입니다. 작업 확인 카드는 작업자가 작업 전에 준비 · 금지 · 순서 · 완료와 그 원문 출처를 되짚는 표이고, 승인과 현재 상태 확인을 대신하지 않습니다.

명령 전에 Docker Desktop을 켜 둡니다.

정할 것 주소가 127.0.0.1의 이 폴더 전용인지 봅니다.

05 판단③ 다른 문서의 조건 · 반복 적재

왜 다른 문서의 조건은 그 문서의 적용 범위와 이 작업을 말하는 사내 문장이 어긋날 수 있어 사람이 정합니다.

할 일 핀 세척에 걸 다른 문서의 조건(시간 · 승인 · 준비)을 결과/다른문서_조건.csv에 잇는다 · 잇지 않는다로, 고른 것을 결과/정한_것.csv에 적고 python show_result.py를 두 번 실행해 수가 늘지 않는지 봅니다.

고친 파일은 Ctrl+S로 저장합니다(탭 이름 옆 ●가 사라지면 저장됨).

학생이 정할 것 — 지점의 종류 원자료만으로 하나로 정해지지 않아 내가 근거를 찾아 정할 지점입니다. 해당하는 행 · 절은 직접 찾고, 지점마다 고른 것 · 근거(파일:줄) · 바뀌는 답을 결과/정한_것.csv에 한 줄씩 적습니다.

  • 다른 문서의 조건 — 다른 문서의 조건 · 시간 · 승인을 핀 세척(SOP-COOL-14)에 이을지
  • 그래프 모양과 연결 — 어떤 종류 · 관계 · ID로 담고 어느 기존 ID에 이을지

질문 카드의 「(권장)」은 AI의 추천일 뿐이니, 직접 입력 칸에 내 결정과 근거 줄을 적어 보냅니다.

정할 것 적용 범위 절과 이 작업을 말하는 사내 문장을 열어 정하고, 잇지 않는 문장도 「아니오」 행으로 남깁니다.
