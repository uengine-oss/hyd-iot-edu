# 판정·성과 비교를 조치 검토 결과로 완성하기

포털에서 순위가 높아도 금지 조건에 걸리면 고를 수 없는 이유를 결과에서 찾았습니다. 이번에는 조치 조건표와 같은 꼴로 제공된 조건표로 사건과 지난 30일 경보를 원천 기록에서 직접 판정하고 견주어, 담당자가 읽고 바로 결정할 수 있는 조치 검토 결과로 완성합니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py`
