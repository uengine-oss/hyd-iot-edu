# 문서에서 작업 조건과 근거를 추출하는 기능 만들기

포털에서 본 문서 지식화 과정을 직접 만듭니다. 근거 있는 지식 후보를 받아 원문과 견줘 결정하고, 핀 세척 작업의 준비 · 금지 · 완료 조건을 모읍니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py`
