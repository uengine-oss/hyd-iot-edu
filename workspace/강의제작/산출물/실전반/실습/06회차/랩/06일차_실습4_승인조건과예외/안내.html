승인·거절과 승인 지연 알림을 갖춘 안전한 흐름 만들기

VS Code에서 이 폴더(이 안내 파일이 있는 폴더)를 열고 START.md를 함께 읽으세요. 이 안내는 START.md와 같은 내용입니다.

출발점이번에 할 것작업 순서기대 결과를 먼저 적을 사례 종류학생이 정할 것이번 범위 밖완료 조건저장과 다음 실습

실습3의 설비 이상 대응 초안에 승인·거절 분기, 반려 종료, 승인 지연 알림 타이머를 더합니다. 운전원이 거절하면 냉각 명령이 실행되지 않고, 승인이 늦어져 알림이 나가도 운전원 승인 작업은 취소되지 않고 계속 기다리는 구조를 그림과 저장한 파일 양쪽에서 확인합니다.

출발점

  • 코드/input/: 실습3에서 저장한 cooling-draft.bpmn과 element-map.md를 복사해 둡니다. 없으면 실습3의 기본 경로부터 그립니다.
  • 코드/source/reference/: 제공 참조 흐름(대조용, 고치지 않습니다).
  • 코드/condition-plan.md: 분기 조건·기본 흐름·기한을 적는 제공 빈 틀입니다.
  • 코드/element-map.md, 코드/review.md: 요소 대응과 확인 기록 빈 틀입니다.
  • 편집기: demo.bpmn.io

이번에 할 것

  • 운전원 승인 뒤에 배타 게이트웨이를 놓아 승인 갈래는 냉각 명령으로, 거절 갈래는 반려 종료로 보냅니다.
  • 운전원 승인 작업의 테두리에 경계 타이머 「승인 지연」을 붙이고 비중단형(점선 겹테두리)으로 정합니다. 타이머에서 「승인 지연 알림」 서비스 작업과 알림 끝 이벤트로 잇습니다.
  • 갈림의 조건, 반대편 기본 흐름, 승인 지연 기한 10분(PT10M)을 코드/condition-plan.md에 적습니다. 기한 입력 칸이 편집기에 없으면 조건 계획에만 적습니다.
  • 코드/output/cooling.bpmn으로 저장하고 XML에서 타이머 연결을 확인합니다.

작업 순서

  1. 코드/input/cooling-draft.bpmn을 열고 결과는 새 파일로 저장합니다.
  2. 승인·거절 갈림을 놓고 거절 갈래가 반려 종료에 닿게 잇습니다.
  3. 운전원 승인에 경계 타이머를 붙여 비중단형으로 바꾸고, 알림 작업과 알림 끝을 잇습니다. 타이머를 승인 뒤의 따로 떨어진 이벤트로 놓지 않습니다.
  4. 거절 갈래에서 냉각 명령으로 가는 선이 없는지, 알림 갈래가 운전원 승인으로 되돌아가거나 승인을 끝내지 않는지 따라갑니다.
  5. 저장한 XML에서 boundaryEvent의 attachedToRef가 운전원 승인 ID를 가리키고 cancelActivity="false"인지 확인합니다.
  6. 코드/condition-plan.md, 코드/element-map.md, 코드/review.md를 채우고 다시 열어 확인합니다.

기대 결과를 먼저 적을 사례 종류

그리기 전에 코드/review.md의 「예상」 칸을 먼저 적습니다.

  • 승인: 지나는 요소와 닿는 끝
  • 거절: 냉각 명령을 지나지 않고 닿는 끝
  • 승인 지연: 알림이 나간 뒤 운전원 승인 작업이 어떤 상태로 남는지
  • 선 이름과 실행 조건: 선에 「승인」이라고 적은 것과 조건 계획에 적은 조건의 차이

학생이 정할 것

거절 갈래에 거절 결과를 남기는 작업(예: 거절 보고)을 둘지, 게이트웨이에서 바로 반려 종료로 갈지 정합니다. 다음 담당자가 거절 사실과 사유를 어디서 읽게 될지를 기준으로 고르고, 이유를 코드/review.md에 적습니다.

이번 범위 밖

에이전트·역할·실행 기능 연결과 포털로 흐름을 보내는 일, 재관측 뒤 회복·미달 갈림(그리지 않아도 됩니다. 다음 비교 실습에서 기준 흐름의 해당 부분을 확인합니다), 병렬·하위 프로세스.

완료 조건

  • 코드/output/cooling.bpmn을 다시 열면 승인·거절 갈림, 반려 종료, 운전원 승인에 붙은 비중단형 경계 타이머와 알림 갈래가 있습니다.
  • 거절 갈래에 냉각 명령이 없고, 알림 갈래가 운전원 승인을 취소하지 않습니다.
  • 코드/condition-plan.md에 내 요소 ID 기준으로 승인 조건·기본 흐름·PT10M이 있습니다.

저장과 다음 실습

코드/output/cooling.bpmn과 기록 파일을 저장하고 다시 열어 확인하세요. 보관할 결과는 재부팅 전에 USB 또는 개인 클라우드에 복사하세요. 다음 실습에서는 이 그림을 포털에 등록된 기준 흐름·제공 매핑과 비교해 작업마다 대응하는 실행 기능을 표시합니다.
