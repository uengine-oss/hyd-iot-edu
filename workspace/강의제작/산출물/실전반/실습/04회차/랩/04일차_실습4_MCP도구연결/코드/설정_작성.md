# 수업에서 작성할 VS Code 설정

랩 폴더(START.md가 있는 폴더)를 VS Code로 열고, 그 폴더 아래에 `.vscode/mcp.json`을 직접 만듭니다. 다음은 경로를 채워야 하는 형식 예시이며 실행한 설정이 아닙니다. `PYTHON_ABSOLUTE_PATH`는 실제 Python 실행 파일, `CODE_ABSOLUTE_PATH`는 이 `코드` 폴더의 절대경로로 바꿉니다. Windows JSON 경로는 `/` 또는 이스케이프한 역슬래시로 적습니다.

```json
{
  "servers": {
    "notion": {"type": "http", "url": "https://mcp.notion.com/mcp"},
    "filesystem": {"type": "stdio", "command": "PYTHON_ABSOLUTE_PATH", "args": ["CODE_ABSOLUTE_PATH/서버/파일시스템_서버.py", "--read-only", "CODE_ABSOLUTE_PATH/업무자료"]},
    "git": {"type": "stdio", "command": "PYTHON_ABSOLUTE_PATH", "args": ["CODE_ABSOLUTE_PATH/서버/깃_서버.py", "--repository", "CODE_ABSOLUTE_PATH/업무자료"]},
    "time": {"type": "stdio", "command": "PYTHON_ABSOLUTE_PATH", "args": ["CODE_ABSOLUTE_PATH/서버/시간_서버.py", "--local-timezone", "Asia/Seoul"]},
    "inspection-notes": {"type": "stdio", "command": "PYTHON_ABSOLUTE_PATH", "args": ["CODE_ABSOLUTE_PATH/서버/점검메모_서버.py", "--folder", "CODE_ABSOLUTE_PATH/업무자료/점검"]}
  }
}
```

- `notion`: Notion이 제공하는 원격 MCP 서버입니다. 처음 연결할 때 브라우저에서 자기 Notion 계정으로 로그인하고 접근을 허용합니다. 로그인과 허용은 직접 하고, 비밀번호나 토큰을 이 파일·채팅·기록에 적지 않습니다. 연결 뒤 도구 목록에서 읽기 도구와 쓰기 도구(페이지 만들기 · 고치기 등)를 가르고, 쓰기 도구는 채팅의 도구 선택에서 끕니다.
- `filesystem`·`git`·`time`: 제공 서버입니다. 업무자료는 `python 코드/도구/자료_준비.py` 기본 실행으로 준비합니다. 기존 업무자료는 보존하며 `--다시`는 쓰지 않습니다.
- `inspection-notes`: 직접 구현하는 점검 메모 조회 서버(`서버/점검메모_서버.py`)입니다. 서버 이름과 읽을 폴더는 자기 설계에 맞게 바꿔도 됩니다.
- `구매팀_자료`는 파일 서버의 허용 범위 밖 접근을 확인하는 연습 자료입니다. 허용 폴더에 넣지 않습니다.

stdio 서버의 연결과 도구 목록은 `python 코드/도구/연결_점검.py`로 AI를 거치지 않고 직접 확인할 수 있습니다. http 서버(`notion`)는 이 프로그램이 확인하지 않으므로 VS Code 채팅의 도구 목록과 호출 기록으로 확인합니다.

Codex를 쓰면 Codex의 MCP 설정 위치와 형식을 먼저 확인하고 같은 서버를 적습니다.

참조: [VS Code MCP 서버 설정](https://code.visualstudio.com/docs/agent-customization/mcp-servers). HYD 포털의 서버 등록과 이 파일의 servers는 서로 다른 호스트 설정이며, 이 실습의 서버는 포털에 등록하지 않습니다.
