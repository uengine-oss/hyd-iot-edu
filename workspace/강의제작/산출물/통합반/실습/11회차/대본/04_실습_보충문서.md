# 통합반 11회차 — 제공 점검 문서 검토

> [제작 · 비낭독] 현재 실습용 대본 후보. 현재 포털의 제공 문서 검토 경로를 사용한다. 새 촬영은 미수행이다.

## 보충 문서를 원문과 대조

인계에 필요한 절차를 추가하겠습니다. 포털의 매뉴얼 지식화에서 제공된 `source/inspection-manual.md`를 선택합니다. 기존 쿨러·정비·구매 지식을 지우거나 교체하지 않고 보충 문서를 추가합니다.

> [조작] 문서를 준비해 추출 결과를 연다. 상태 확인, 열린 작업지시, 재고·입고 예정, 작업 메모 확인 절차의 원문 위치와 제안된 내용을 차례로 대조한다.

같은 제공 문서와 조건의 검토본을 사용할 수 있지만, 사람이 원문을 확인하고 적재하는 단계는 남아 있습니다. 문서에 없는 내용을 채워 넣지 않고, 빠졌거나 맞지 않는 부분은 검토합니다. 개인 문서를 같은 수업 경로로 임의 추출하지 않습니다.

> [확인] 검토한 항목만 적재하고 추가 문서와 절차의 출처를 조회한다. 기존 세 문서의 배치가 그대로인지 확인한다. 실패하거나 확인하지 못한 항목은 성공으로 기록하지 않는다.
