이번 과제의 정할 자리(「제공 빈 틀」 파일)를 여기서 채웁니다. `python show_result.py`가 채운 자리까지 적재 · 조회를 돌려 스키마 확장(`schema_ext.json`) · 적재 파일(`load.cypher`) · 조회문(`query.cypher`) · 남은 질문(`남은_질문.json`) · 내보내기(`지식_내보내기.json`)를 쓰고 `보기.html`에 보입니다.
내 앞 결과를 쓰면 `내_입력/`에 `입력/`과 같은 이름 · 같은 자리로 복사해 둡니다.
다시 열 때는 `python lab_db.py`로 랩 DB를 다시 켜고 `python show_result.py`를 실행해, `구축_기록.md`의 적재 수와 결과 화면을 함께 봅니다.
