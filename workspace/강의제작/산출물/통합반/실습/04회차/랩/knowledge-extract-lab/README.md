# 문서에서 근거 있는 지식을 추출하는 기능 만들기

포털에서 본 문서 지식화 과정을 직접 만듭니다. 문서를 나누는 단위와 수업 모델에 보낼 요청 글을 정해 근거 있는 지식 후보를 받고, 원문과 견줘 채택 · 수정 · 제외 · 보류를 기록합니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py`
