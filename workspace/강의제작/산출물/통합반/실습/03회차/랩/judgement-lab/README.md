# 설비 조건별 최적의 조치를 비교하는 판단 기능 만들기

결정표를 쿨러 성능 저하 경보에 대어 조치 후보를 판정하고, 포털의 조건별 손익 화면에서 본 것처럼 허용된 후보를 손익으로 견줍니다. 과정의 첫 단계인 온톨로지에 담은 판단 지식을 실제 경보에 써 보는 실습입니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py`
