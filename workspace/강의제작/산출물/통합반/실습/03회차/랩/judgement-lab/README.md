# 설비 조건별 최적의 조치를 비교하는 판단 기능 만들기

포털은 사실을 자동으로 모아 경보 한 건씩 판단했습니다. 이번에는 조치 기준 만들기와 같은 꼴로 제공된 조건표로 원천 기록에서 냉각 조치 후보를 직접 판정하고 주어진 비교 산식으로 견주며, 지난 30일 경보 전체로 기능을 검증합니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py`
