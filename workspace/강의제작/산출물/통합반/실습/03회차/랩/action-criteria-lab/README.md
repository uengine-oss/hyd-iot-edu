# 작업 절차와 판단 조건을 연결해 조치 기준 만들기

포털의 규칙 판단 화면과 조치 방법 화면의 연결된 지식에서 조치마다 허용 · 제외와 적용 규칙이 붙어 나오는 것을 봤습니다. 그 조치의 SOP와 판단 규칙을 HM-8 매뉴얼에서 직접 옮겨 만듭니다. 2회차에 다룬 설비 모델의 식별자에 걸어, 과정의 첫 단계인 온톨로지에 「이 설비에 무엇을 어떻게 하는가」를 더합니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py`
