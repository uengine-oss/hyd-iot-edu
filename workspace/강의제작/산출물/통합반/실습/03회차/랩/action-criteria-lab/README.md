# 작업 절차와 판단 조건을 연결해 조치 기준 만들기

포털의 조치 방법 · 판단 규칙 화면에서 본 근거를 HM-8 매뉴얼 원문에서 직접 찾습니다. 작업 절차(SOP 구조)와 판단 조건(조건표)으로 나누고 제공된 설비 모델(2회차 그래프 구현 실습과 같은 모델)의 ID에 잇습니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py`
