# 원인 후보와 다음 점검 계획

앞에서 배운 지식·현재값·출처 확인을 바탕으로, 제공된 4회차의 원인 후보와 문서 조건을 이번 사건의 관측값과 연결하는 원인·점검 계획 에이전트를 만듭니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py --inspect`
