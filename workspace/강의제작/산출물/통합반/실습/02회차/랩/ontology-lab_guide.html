01 폴더 열고 자료 확인하기

지금 받은 ZIP에는 랩 폴더와 이 가이드가 들어 있습니다. 내 입력은 터미널 명령과 Codex 채팅뿐이고, 파일은 Codex가 app/features/의 빈 틀에만 채웁니다.

할 일 ZIP을 풀고 VS Code 파일 → 폴더 열기로 안쪽 ontology-lab 폴더(run.py가 든 폴더)를 엽니다. 바깥 폴더를 열면 Codex가 정답이 든 가이드까지 읽습니다. 신뢰를 물으면 예, 작성자를 신뢰합니다를 고르고, 터미널 → 새 터미널에 명령 블록을 복사해 붙여 넣습니다(오타를 줄이려고). 명령은 Codex에게 실행을 맡겨도 됩니다.

터미널(PowerShell · 이 실습 폴더)

python run.py

확인 원자료 줄 수가 보이고 결과 화면이 열리면 됩니다. 안 열리면 Windows 탐색기에서 output/result.html을 엽니다. 이후 명령 뒤에는 그 화면에서 F5를 누릅니다.

그러면 모델이 정말 맞는지 가리려면 무엇을 더 물어볼까?

  • 처음 고르지 않은 설비
  • 예전 품번 · 원자료에 없는 품번
  • 이 입력들의 기대 답은 결과를 보기 전에 먼저
  • 「같음」이 아닌 줄 — 물은 값 · 기대 답 · 실제 답을 함께 보여 원인부터
  • 원인을 듣기 전엔 파일을 고치지 않게

요령 다를 때는 입력 · 기대 · 실제를 함께 보여 원인부터 묻습니다. 고쳐 달라고만 하면 AI가 결과를 맞추려고 엉뚱한 곳을 바꿉니다. 두 번 고쳐도 안 되면 「다시 해 줘」 대신 새 대화를 열어 알게 된 것을 담아 다시 부탁합니다. 틀린 시도가 쌓인 대화에서는 AI가 그 시도에 끌려 같은 자리를 맴돌기 쉽습니다.
