01 폴더와 출발점 확인

포털 지식 지도에서 오일 쿨러와 거기 붙은 센서가 어떻게 이어지는지 따라가 봤습니다. 이번에는 그 연결을 직접 만듭니다. 유압 설비 7대의 대장 · 구성 요소 · SCADA 태그 · 예비품 자료를 종류(이론의 클래스 — 대상의 갈래) · 속성 · 관계로 짠 온톨로지에 맞춰 지식 그래프로 정리해, 설비별 센서와 여러 설비가 함께 쓰는 부품을 답하게 합니다. 자료는 같은 센서 이름이 여러 설비에 쓰이고, 같은 장치를 다르게 부르며, 줄이 겹치거나 칸이 비어 있습니다. 읽기 · 환산 · 계약 꼴 · 물어보기는 제공 코드가 하고, 나는 결과가 갈리는 판단(ID와 관계 방향, 같은 장치 · 물리량으로 볼 근거, 빈 칸의 뜻, 같은 규격을 한 물품으로 볼지)을 정합니다.

줄기(온톨로지 → 에이전트 → 프로세스)에서 이 실습은 첫 단계 온톨로지의 설계를 맡습니다.

받기 노션 「가이드문서」에서 이 실습의 ZIP 내려받기를 눌러 받고, 받은 ZIP을 오른쪽 버튼으로 눌러 압축 풀기(Extract All)를 고릅니다. 풀린 폴더를 따라 들어가면 실습 폴더와 이 가이드(이름이 _guide.html로 끝나는 파일)가 나란히 있습니다. 가이드는 두 번 눌러 브라우저로 열고, VS Code에서는 파일 → 폴더 열기(File → Open Folder)로 실습 폴더를 엽니다 — 그 위 폴더를 열면 AI가 정답이 든 이 가이드까지 읽습니다. 이어서 할 때는 같은 실습 폴더를 다시 엽니다(ZIP을 새로 풀면 고친 파일이 없는 새 폴더입니다). 필요한 것 VS Code와 Python, 로그인해 둔 Codex 또는 GitHub Copilot.

왜 무엇이 주어졌고 이 답을 누가 쓰는지 알아야 AI에게 같은 출발점을 말할 수 있습니다.

할 일 탐색기에서 입력/ · 자료/ · 결과/ · START.md를 열고, 터미널에서 python show_result.py로 결과 화면을 처음 엽니다.

해결할 질문 아래 질문의 답은 보전팀이 설비별 센서를 찾고, 교체할 부품을 어느 설비와 함께 준비할지 정할 때 씁니다. 같은 부품을 구매팀은 호환 후보를 찾을 때, 창고는 품목별 재고를 셀 때 조회합니다.

  1. 설비별로 어떤 구성 요소에 어떤 센서 · 계산값 · 설정값이 붙어 있는가?
  2. 각 센서가 재는 물리량과 단위 · 정상값 · 한계(위로 넘는지, 아래로 떨어지는지)는 무엇인가? 설비마다 태그 이름이 달라도 같은 물리량을 재는 센서를 함께 찾을 수 있는가?
  3. 교체 부품별로 그 부품을 쓰는 설비와 구성 요소는 무엇인가? 다른 표기로 적힌 품번, 제조사 규격 번호, 원자료에 없는 품번으로 물으면 결과가 어떻게 구별되는가?

말 풀이 계산값은 계기 없이 다른 값으로 계산한 값, 설정값은 사람이 정해 넣는 목표 값, 사내 품번은 우리 회사 번호, 제조사 규격 번호(제조사 품번)는 만든 회사의 번호, 기준일은 자료를 뽑은 날, 정할 자리는 결과/에서 첫 줄에 「제공 빈 틀」이 있는 파일입니다.

터미널 → 새 터미널(Terminal → New Terminal)로 이 실습 폴더에서 터미널을 엽니다. 명령은 직접 치지 말고 블록의 복사로 붙여 넣은 뒤 Enter를 누릅니다(손으로 치면 오타가 납니다). 오류로 멈추면 명령과 출력 전문을 AI 채팅에 보내 까닭부터 묻습니다. 명령은 AI가 아니라 이 터미널에서 내가 실행합니다.

결과 화면 python show_result.py가 결과/보기.html을 새로 쓰고 처음 한 번 브라우저로 엽니다(안 열리면 탐색기에서 그 파일을 오른쪽 클릭 → Reveal in File Explorer → 두 번 클릭). 단계 띠의 「비어 있음 · 채움 · 오류」를 보고, 다시 실행한 뒤 F5를 누릅니다. 빨간 칸에는 멈춘 파일:줄과 까닭이 있습니다.

정할 것 질문 셋과 이 답을 쓰는 사람을 확인합니다.

02 파일을 바꾸지 않고 자료 파악

왜 모델에는 원자료에 있는 것만 담으므로, 합의하지 않은 해석으로 AI가 만들기 전에 자료부터 봅니다.

할 일 AI에게 파일을 바꾸지 말고, 내가 고른 설비 하나의 구성 요소 · 센서 · 교체 부품에 관한 줄을 자료마다 파일 · 줄로 짚게 하고, 그 줄을 직접 엽니다.

AI 채팅은 왼쪽 활동 표시줄의 Codex 아이콘(GitHub Copilot은 같은 창의 Chat 탭)으로 엽니다. 답에 나온 파일 · 줄은 편집기에서 직접 열어 보고, 「완료」라는 말 대신 실제 파일과 출력으로 확인합니다.

편집 승인 창(Allow ChatGPT to edit…?)에서는 경로가 결과/ 아래인 요청한 변경만 Allow once, 그 밖은 Deny를 누르고 까닭을 알립니다.

정할 것 같은 장치 · 센서를 다르게 적은 곳, 빈 칸 · 다른 표기, 두 번 나온 대상처럼 자료끼리 다른 곳을 묻습니다.

03 요구와 기대 답 정하기

왜 기대 답을 원자료에서 먼저 적어야 결과를 견줄 기준이 생깁니다. AI의 답을 옮기면 틀린 결과도 맞아 보입니다.

할 일 결과/요구사항.md에 질문 · 쓰는 사람 · 기준일 · 지킬 조건을, 결과/기대_답.csv에 고른 설비에서 센서가 붙은 구성 요소 셋의 센서(질문 1), 같은 물리량을 재는 센서 한 묶음(질문 2), 함께 쓰는 부품 · 다른 표기 · 없는 품번 하나씩의 사용 설비(질문 3)를 원자료에서 찾아 적습니다. 질문 1 항목은 지금은 원자료 이름으로 적고 5단계에서 고칩니다. 결정 지점은 결과/정한_것.csv에 적습니다. 다 적으면 AI에게 파일을 바꾸지 말고 되짚게만 합니다.

편집기에서 고친 뒤 Ctrl+S로 저장합니다(탭 이름 옆 ●가 사라지면 저장됨).

학생이 정할 것 — 지점의 종류 원자료만으로 하나로 정해지지 않아 내가 근거를 찾아 정할 지점입니다. 해당하는 행 · 절은 직접 찾고, 지점마다 고른 것 · 근거(파일:줄) · 바뀌는 답을 결과/정한_것.csv에 한 줄씩 적습니다.

  • 쓰는 사람에 따라 갈리는 답 — 같은 규격(제조사 품번)으로 등록된 서로 다른 사내 품번을 한 물품으로 볼지 — 그 규격이나 한쪽 품번으로 물었을 때 나와야 할 답이 호환 후보를 찾는 사람과 품목별 재고를 세는 사람에게 같은지
  • 빈 칸의 뜻 — 교체부품 칸이 비었거나 품명만 적힌 행을 예비품 목록(적용모델 · 쓰는곳)으로 이어 그 부품을 쓰는 설비로 볼지, 원자료가 품번을 말하지 않았으니 잇지 않을지

AI가 이 지점을 물으며 「(권장)」을 붙인 선택지 카드를 내도 추천일 뿐입니다. 근거 줄을 연 뒤 직접 입력 칸에 내 결정과 근거 줄을 적어 보냅니다.

정할 것 지점마다 내 선택과 근거를 정합니다. AI의 「권장」은 따르지 않고 원문 줄로 정하며, 못 정하면 미결로 적습니다.

def same_device(a, b):
    """근거: 현장 메모 24행(HYD-01 ~ 03은 같은 모델) · 35행(한일유압 설비는 태그 이름이 같음) —
    같은 모델에서 같은 태그가 붙은 자리는 같은 장치. 예비품 목록의 사내 품번 — 같은 교체 부품을 쓰는 자리는 같은 장치. 계통이 다르면 다른 장치."""
    if a['계통'] != b['계통']:
        return False
    if a['모델'] == b['모델'] and set(a['태그']) & set(b['태그']):
        return True
    return a['부품'] != '' and a['부품'] == b['부품']

import re


def loop(tag):
    """계장태그 「TT-231」 → ('TT', '1'): 재는 기능 글자와, 루프 번호에서 앞 두 자리(설비)를 뺀 나머지(현장 메모 35행)."""
    m = re.fullmatch(r'([A-Z]+)-\d\d(\d+)', tag)
    return m.groups() if m else None


def same_quantity(a, b):
    """근거: 재는것이 같으면 같은 물리량. 현장 메모 35행 — 한일유압 설비는 같은 태그 이름, 계장태그는 기능 글자와 루프가 같으면 같은 것을 잰다."""
    if a['재는것'] == b['재는것']:
        return True
    if a['제조사'] == b['제조사'] and a['태그'] == b['태그']:
        return True
    return loop(a['계장태그']) is not None and loop(a['계장태그']) == loop(b['계장태그'])


def quantity_name(members):
    """근거: 묶음에서 가장 많이 쓴 재는것(같은 수면 센서 목록에서 먼저 나온 것)."""
    names = [m['재는것'] for m in members]
    return max(names, key=lambda n: (names.count(n), -names.index(n)))


def kind_of(row):
    """근거: 센서_목록.csv 비고 「계기 없음」은 계산값, 수집방식 「설정값」은 설정값, 나머지는 계기가 잰 실측."""

    if '설정값' in row['수집방식']:
        return '설정값'
    return '실측'

def base_unit(quantity, units):
    """근거: 그 물리량에서 원자료가 가장 많이 쓴 단위(같은 수면 센서 목록에서 먼저 나온 것)."""
    return max(units, key=lambda u: (units.count(u), -units.index(u)))


def blank_unit(row, candidates):
    """근거: 같은 모델 · 같은 태그 · 같은 정상값 · 한계 · 한계구분의 줄이 단위 하나를 말할 때만 그 단위, 아니면 미확인(짐작하지 않음)."""
    key = ('모델', '태그', '정상값', '한계', '한계구분')
    same = {c['단위'] for c in candidates if all(c[k] == row[k] for k in key)}
    return same.pop() if len(same) == 1 else '미확인'
