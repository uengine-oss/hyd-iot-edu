# 현장 정보를 체계화하는 온톨로지 직접 설계하기

이론에서 배운 클래스 · 인스턴스 · 식별자로, 포털 지식 지도에서 살펴본 연결을 직접 설계합니다. 온톨로지 → 에이전트 → 프로세스로 이어지는 과정의 첫 단계로, 유압 파워팩 세 대의 원자료에서 설비별 센서와 함께 쓰는 부품을 찾는 온톨로지를 만듭니다.

```text
data/           실습 자료
app/features/   AI와 구현할 핵심 기능
app/ui/         결과 화면 — 제공
app/utils/      공통 처리 — 제공
output/         실행 후 생기는 결과
AGENTS.md       AI가 지킬 공통 규칙
```

실행: `python run.py`
