01 폴더와 출발점 확인

「현장 정보를 체계화하는 온톨로지 직접 설계하기」에서는 설비 · 센서 · 부품을 종류 · 속성 · 관계로 정의해 모델을 만들었습니다. 이번에는 제공된 설비 · 센서 · 부품 모델(또는 내가 만든 모델)을 이 폴더 전용 랩 DB(그래프 DB)에 적재하고, 질문마다 조회문을 만들어 원자료와 대조합니다. 스키마의 ID와 관계 방향이 그래프의 노드 · 관계로 어떻게 옮겨지는지 직접 봅니다.

그래프에 넣은 자료는 한 번으로 끝나지 않습니다. 수정본이 들어오면 전체를 지우고 다시 넣지 않고 필요한 대상만 고쳐야 다른 곳에서 쓰던 ID와 연결이 그대로 남고, 같은 적재를 다시 실행해도 대상이 늘지 않아야 믿고 다시 돌릴 수 있습니다.

과정은 온톨로지 → 에이전트 → 프로세스 순서로 올라갑니다. 이 실습은 첫 단계인 온톨로지의 구현과 검증 — 설계한 모델을 그래프 DB에 옮기고, 질문에 실제로 답하는지 원자료와 대조하는 일 — 를 맡습니다.

이 답은 보전팀이 지금 가동하는 설비의 예비품 준비를 정할 때 씁니다.

02 랩 DB 켜기

할 일 터미널에서 python lab_db.py를 실행해 이 폴더 전용 랩 DB를 켜고, 열린 Neo4j Browser에 연결합니다.

메뉴에서 터미널 → 새 터미널(Terminal → New Terminal)을 선택하세요. 아래쪽 터미널에 이번 실습 폴더의 경로와 입력 커서가 보이면 다음 명령을 쓰고 Enter를 누릅니다. 출력 마지막 줄을 읽고 질문에 대한 실제 답은 원자료 행과 따로 대조하세요.

「랩 DB 준비 완료」가 나오면 열린 Browser의 Protocol에서 bolt://를 선택하고 Connection URL에는 출력 주소의 127.0.0.1:포트 부분만 넣습니다. Database user는 neo4j, Password는 비워 두고 Connect를 누릅니다. 연결 정보는 랩_연결.json에도 저장됩니다. AI가 명령 실행 승인을 요청하면 이 폴더의 적재 · 조회 명령이고 주소가 랩_연결.json의 주소와 같은지 먼저 확인하세요.

개수 조회 Browser 위쪽 입력 칸에 붙여 넣고 실행합니다.

MATCH (n) RETURN labels(n)[0] AS 종류, count(*) AS 개수 ORDER BY 종류

정하거나 물을 것 출력된 주소가 127.0.0.1의 이 폴더 전용 주소인지 확인합니다.

명령

python lab_db.py

판단할 증거 「랩 DB 준비 완료」와 주소가 나왔고, Browser에서 개수 조회가 빈 결과(이 폴더 전용 DB가 아직 비어 있음)를 보입니다. 확인한 뒤 다음 단계로 갑니다.

활동 표시줄에서 사용하는 AI의 아이콘을 열고 패널 제목에서 Codex 또는 GitHub Copilot을 확인하세요. 패널 아래 입력칸에 이번 질문을 자기 말로 적고 보냅니다. 첫 요청에서는 파일을 바꾸지 말고 근거 행을 찾아 달라고 하세요. 답변에 나온 파일을 왼쪽 탐색기에서 열어 가운데 편집기의 실제 행을 읽습니다.

04 요구와 기대 답 정하기

할 일 질문 · 이 답을 쓰는 사람 · 지킬 조건과, 설비 하나의 구성 요소별 센서와 공용 부품 하나의 사용 설비, 수정본 반영 뒤 달라져야 할 것을 원자료에서 직접 찾아 기대 답으로 결과/검증_기록.md에 적습니다. 「학생이 정할 것」의 지점마다 고른 것과 근거 줄을 적습니다.

파일을 고친 뒤에는 Ctrl+S로 저장합니다. 탭 이름 옆 점(●)이 사라지면 저장된 것입니다.

학생이 정할 것 — 지점의 종류 원자료만으로는 하나로 정해지지 않아, 근거를 찾아 내가 정해야 결과를 업무에 쓸 수 있는 지점이 있습니다. 이번 자료에는 아래 종류의 지점이 있습니다. 어느 행 · 어느 절이 해당하는지는 탐색에서 직접 찾고, 지점마다 고른 것 · 근거(파일 · 줄) · 그 선택으로 바뀌는 답을 결과/검증_기록.md 「정한 것」 표에 적습니다.

  • 시점과 상태 — 수정본에서 상태가 바뀐 설비를 그래프에 어떻게 반영하고, 「지금 가동하는 설비」를 묻는 답에 어떻게 드러낼지(답에서 빠지는지, 상태와 함께 보이는지)

AI에게 이 지점을 대신 정하게 하지 않습니다. AI가 고를 것을 내놓거나 「권장」을 붙여도 그대로 따르지 말고, 원문 줄을 열어 내 선택과 근거를 말합니다. 못 정한 지점은 미결로 남깁니다.

정하거나 물을 것 지점마다 내 선택과 근거를 말합니다. AI가 고를 것을 내놓거나 「권장」을 붙이면 따르지 말고 원문 줄을 다시 열어 내 말로 정합니다. 못 정한 지점은 미결로 적습니다.

요청에 담을 것 아래 다섯 가지를 내 말로 채워 요청을 짭니다. 값은 원자료에서 내가 찾습니다.
