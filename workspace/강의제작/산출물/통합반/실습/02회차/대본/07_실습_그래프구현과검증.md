# [실습] 그래프 구현과 검증 · 약 39.5분

2회차 VS Code 랩 세 편 가운데 셋째 편(2026-11-24 확정 판에 적대 검토 2 `판정/적대검토2_07.md`와 사람 말 잣대의 적대 검토 3 `판정/적대검토3_07.md`를 반영하고 편 전체를 다시 윤문한 판 — 사용자 확정을 다시 받을 판). 시작 화면은 그래프 랩 폴더(`graph-lab`)가 열리고 신뢰된 웹 VS Code다. 강사의 입력은 터미널과 Codex 채팅 둘뿐이고, 파일은 Codex가 쓰며 강사는 열어 읽기만 한다. 랩 DB를 쓰는 명령은 강사가 터미널에서 직접 돌리고, 학생과 같은 글자로 친다. Codex가 채운 쿼리는 돌리기 전에 열어 조각마다 짚고, 무엇을 만들거나 찾거나 바꾸는지 한 문장으로 말한 뒤 돌려 결과와 맞춘다(영상 V-15). 이 편의 쿼리는 아직 실제로 받아 보지 않았다. 쿼리의 줄과 값을 말하는 큐는 모두 「녹화 답에 맞춤」이고, 조작 칸에 적은 쿼리 꼴은 그 큐가 무엇을 짚는지 보이려는 어림이다(완성본 `graph-lab-completed.zip`의 쿼리를 본떴다). 「녹화 전 맞춤」은 녹화 준비 때 화면 실물을 보고 글자를 맞춘다는 표시다. 결과 화면은 결과 화면 공간에서 F5로 새로 고쳐 보인다(촬영준비 길 6).
