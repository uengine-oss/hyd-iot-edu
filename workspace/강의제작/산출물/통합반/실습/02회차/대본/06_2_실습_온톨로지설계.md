# [실습] 온톨로지 설계 단계 격파 · 약 37분

2회차 VS Code 랩 세 편 가운데 둘째 편(2026-11-24 사용자 확정 판 8f27b755b624 뒤에 적대 검토 2 · 3(`판정/적대검토2_06-2.md` · `적대검토3_06-2.md`, 3은 「사람 강사가 입으로 하는 말인가」가 첫째 잣대)을 반영하고 편 전체를 다시 윤문한 판 — 고친 판은 다시 확정을 받는다). 시작 화면은 앞 편이 끝난 상태다. 설계 랩 폴더(`ontology-lab`)가 열린 웹 VS Code에 자료 파악 대화, 터미널, 결과 화면이 그대로 있다. 자료를 다시 파악하지 않고 설계부터 한다. 강사의 입력은 터미널과 Codex 채팅 둘뿐이고, 파일은 Codex가 쓰며 강사는 열어 읽기만 한다. Codex에 보내는 부탁은 조작 칸에 적은 글을 강사가 그 자리에서 자기 말로 넣는다. 터미널 명령은 학생과 같은 글자로 치고, 결과 화면은 결과 화면 공간에서 F5로 새로 고쳐 보인다(촬영준비 길 6). 「녹화 답에 맞춤」은 그 큐의 말을 녹화 때 받은 Codex 답에 맞춰 고친다는 표시이고, 「녹화 화면에 맞춤」은 녹화 준비 때 화면 실물을 보고 글자와 짚는 차례를 맞춘다는 표시다.
