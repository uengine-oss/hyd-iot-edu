# [실습] VS Code 랩 시작하기 — 바이브 코딩으로 일하는 법 · 약 34분

2회차 VS Code 랩 세 편 가운데 첫 편(2026-11-24 확정 뒤 고친 판에 적대 검토 2 · 3(`판정/적대검토2_06-1.md` · `적대검토3_06-1.md`)을 반영하고 맨 마지막에 다시 윤문한 판 — 확정 장부에 적힌 판과 다르다). 1 · 2장은 사용자가 직접 녹화한 Windows 화면 위에 입히는 말이고, 3장부터는 설계 랩 폴더(`ontology-lab`)가 열린 웹 VS Code다. 강사의 입력은 터미널과 Codex 채팅 둘뿐이고, 파일은 열어 읽기만 한다. 터미널 명령은 학생과 같은 글자로 친다. 조작 칸에서 「짚는다」는 커서를 올리고 강조(밑줄 · 테두리 · 띠)를 그린다는 뜻이다(영상 V-14). 「녹화 답에 맞춤」은 그 큐의 말을 녹화 때 받은 Codex 답에 맞춰 고친다는 표시이고, 「녹화 전 맞춤」은 녹화 준비 때 화면 실물을 보고 글자를 맞춘다는 표시다. 조작 칸의 「펜 그림: …」 · 「글상자: …」 · 「강조: …」는 화면 위에 그리거나 띄울 것과 그 때를 적은 것이다(녹화 도구의 그림 층). 표 · 파일 · 결과의 가로 한 줄은 「행」, 코드 · 메모 글의 한 줄은 「줄」로 말한다(「예 줄」은 요령의 이름이라 그대로 — 랩 가이드의 「줄」은 가이드를 다시 만들 때 영상 말에 맞춘다, 메인 결정 2026-11-24).
