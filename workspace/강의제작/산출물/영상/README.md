# 강의 영상

강의 영상의 **최신 판 하나씩**(정본이다. 학생은 이 판을 올린 유튜브 영상을 클래스룸에서 본다 — `workspace/강의제작/지침/배포.md`)과 그 자막의 목록이다. 같은 영상의 이전 판은 두지 않는다 — 새 판을 만들면 그 자리의 파일을 바꿔 끼우고 이 표의 그 행을 고쳐 쓴다.

- 자리: 영상 mp4의 자리와 Release 첨부 이름, 올리는 도구, 자막 · 시간표의 자리(`_작업/영상_자막_기록/`)는 영상 V-7이 정한다. Release에 아직 새 판이 없는 옛 영상은 이 폴더의 `통합반/` · `실전반/`에 남아 있다.
- 두 과정 공통 영상(1회차 전부, 2회차 실습 04 관계조회)은 통합반 파일 하나를 두 과정이 함께 쓴다(유튜브도 영상 하나를 두 반 클래스룸에 붙인다). 실전반 이름의 사본을 두지 않는다.
- 다시 만들 재료는 영상 파일이 아니다: 이론 영상은 대본 + 덱 + 음성 · 쉼 캐시(`workspace/강의제작/제작도구/기존제작/tools/video/음성_저장/` · `쉼_저장/`, 도구 `강의영상.py`), 실습 영상은 그 도구의 큐 + 촬영도구 + 음성 캐시(`workspace/강의제작/제작도구/촬영/<도구>/`)다. 이론 영상을 고칠 때 다시 만드는 범위는 `영상.md` 「길」 12이고, 실습 영상을 고치는 길은 「길」 17(녹화 원본이 있을 때) · 18(게시본만 있을 때)이다.
- 학생에게 낸 영상의 새 판은 유튜브에 새로 올리고 클래스룸 자료의 영상을 바꾼다(배포 길 11).
