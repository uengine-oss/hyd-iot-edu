# 강의 영상

학생이 노션에서 보는 강의 영상의 **최신 판 하나씩**과 그 자막이다. 같은 영상의 이전 판은 두지 않는다 — 새 판을 만들면 이 폴더의 파일을 바꿔 끼우고 이 표의 그 행을 고쳐 쓴다.

- 자리: 영상 `통합반/` · `실전반/`, 자막 · 시간표 `_작업/영상_자막_기록/`(영상과 같은 이름). workspace 브랜치에 올라간다(`python workspace/동기화.py commit "…"` → `push`).
- 두 과정 공통 영상(1회차 전부, 2회차 실습 04 관계조회)은 통합반 파일 하나를 두 과정 노션이 함께 가리킨다. 실전반 이름의 사본을 두지 않는다.
- 다시 만들 재료는 영상 파일이 아니다: 이론 영상은 대본 + 덱 + 음성 캐시(`workspace/강의제작/제작도구/기존제작/tools/video/강의영상.py`), 실습 영상은 그 도구의 큐 + 촬영도구 + 음성 캐시(`workspace/강의제작/제작도구/촬영/<도구>/`). 고칠 구간만 다시 찍어 자막 시각에 맞춰 끼울 수 있다.
- 노션의 영상 링크는 workspace 커밋 고정 주소라, 파일을 바꿔도 이미 걸린 링크는 그 판을 계속 연다. 새 판을 노션에 걸 때 링크를 새 커밋으로 바꾼다.
