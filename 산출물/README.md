# 산출물 — 수업에 그대로 쓰는 것

여기에는 학생과 강사가 수업에서 바로 쓰는 것만 둔다. 만드는 재료와 도구는 [`만들기/`](../만들기/README.md), 기준과 현황은 [`문서/교재/`](../문서/교재/1_목적과_방향.md)에 있다.

```
산출물/
├─ 교재/
│  ├─ PPTX/<과정>/        강의 덱
│  ├─ 대본/<과정>/        낭독 대본(최종본)
│  └─ 영상/               강의 영상 목록(영상 파일은 저장소에 올리지 않는다)
└─ 실습/<과정>/<회차_실습>/
   ├─ 코드/               학생이 받아 VS Code로 여는 폴더
   └─ 가이드.html          실습 가이드(Notion 실습은 가이드.pptx)
```

과정 폴더는 `통합반_온라인` · `실전반_온라인` · `통합반_오프라인` · `실전반_오프라인`이다.

| 폴더 | 내용 | 수 |
|---|---|---|
| `교재/PPTX/통합반_온라인/` | 통합반 온라인 강의 덱(1~11일차) | 11 |
| `교재/PPTX/실전반_온라인/` | 실전반 온라인 강의 덱(1~8일차) | 8 |
| `교재/PPTX/통합반_오프라인/` | 통합반 오프라인 강의 덱(1~10회차) | 10 |
| `교재/PPTX/실전반_오프라인/` | 실전반 오프라인 강의 덱(1~9회차) | 9 |
| `교재/대본/통합반_온라인/` | 통합반 온라인 낭독 대본(1~3회차는 새 기준 한 파일 `_대본.md`, 4~11회차는 옛 기준의 `_윤문2.md`) | 11 |
| `교재/영상/` | 강의 영상 목록 | — |
| `설치/` | 학교 전산실 설치 목록과 라이선스 증빙(`피지컬AI_교육_설치목록_라이선스증빙_유엔진솔루션즈.xlsx`: 버전 고정 설치 파일 링크 · 설치 명령어 · VS Code 확장 · 도커 이미지 · 이미지 안 라이브러리 · 열어야 할 주소, 행마다 제조사 공식 선언(원문) · 라이선스 원문 링크 · 인용, 「증빙 화면」 시트에 공식 페이지 캡처 49장(선언 문장 강조), 2026-10-15 공식 문서로 확인) | 1 |
| `실습/통합반_오프라인/` | 오프라인 실습. `05회차_실습2_원인_추론_에이전트`는 새 틀(`만들기/labs/STRUCTURE.md`), 나머지 19개는 옛 틀 | 20 |

- 파일 이름은 과정과 일차 · 회차를 그대로 쓴다(`통합반_05일차.pptx`, `통합반_05일차_대본_윤문2.md`).
- 여기서 직접 고치지 않는 것: 덱 PPTX(원고 `만들기/decks/`를 고쳐 다시 만든다), 새 틀 실습의 가이드(`만들기/labs/offline/<랩>/build_guide.py`가 만든다). 옛 틀 가이드와 대본은 여기 파일을 직접 고친다.
- 실습의 완성본과 제작 기록은 학생에게 나가지 않으므로 `만들기/labs/`에 둔다(`코드/` 안에 두면 Copilot이 읽는다).
- 무엇이 어디까지 됐는지는 `문서/교재/3_현황.md`에 있다.
