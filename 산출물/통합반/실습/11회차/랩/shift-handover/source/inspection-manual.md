# HI-01 설비 점검·이상 확인 보충 매뉴얼

판본: 1.0 / 수업용 가상 HYD 유압 파워팩 / 2026-10-27

## HI-1 적용 범위
이 자료는 HYD-01, HYD-02, HYD-03의 다음 교대 전 확인을 위한 보충 자료다. 기존 HM-8, PM-02, PR-07을 교체하지 않고 새 문서로 추가한다. 설비 운전·정비·발주는 기존 승인 절차를 따른다. 이 문서의 절차는 조회와 상태 확인용 참고 절차이며 자동 실행 후보나 새 고장 유형이 아니다.

## HI-1.1 설비 이상 표시와 관측 신선도 확인
### SOP-HI-01 설비 상태 조회 확인
1. 설비 식별자와 인계 기준시각을 확인하고 조회한 시각을 함께 기록한다.
2. 실제 시계열 스키마에서 관측 시각과 설비 식별 필드를 확인한 뒤 해당 설비의 최근 관측값을 조회한다.
3. 관측 시각이 없거나 조회가 실패하면 정상이라고 판단하지 말고 확인 필요로 남긴다. 과거 기준시각 상태를 복원할 수 없으면 현재 조회값과 구분한다.
4. 작업 메모의 이상 해소 주장과 관측값이 일치하는지 비교하고, 근거가 부족하면 다음 근무자가 확인할 항목으로 남긴다.

## HI-1.2 미완료 정비 작업지시 확인
### SOP-HI-02 열린 작업지시 대조 확인
1. 업무 DB의 실제 스키마에서 해당 설비 작업지시의 식별자, 상태, 예정시각, 완료시각 필드를 확인한다.
2. 해당 설비의 작업지시를 조회하고 시스템에 기록된 상태와 완료시각을 그대로 기록한다. 열려 있는 항목이 없다는 결론은 조회에 성공한 경우에만 적는다.
3. 작업 메모에 정비 완료라고 적혀 있어도 작업지시가 열려 있거나 완료시각이 없으면 불일치 또는 확인 필요로 남긴다.
4. 정비 이력을 임의로 닫지 말고 다음 근무자가 담당자에게 확인할 작업지시 식별자와 미확인 내용을 전달한다.

## HI-1.3 부품 대기와 실제 재고 확인
### SOP-HI-03 부품 입고 예정과 현재고 대조
1. 미완료 정비와 관련된 부품 번호를 실제 조회 근거에서 확인한다. 부품 연결 정보가 없으면 임의의 부품을 관련 부품으로 지정하지 않는다.
2. ERP의 해당 부품 현재고(on_hand), 예약(reserved), 입고 예정(on_order)과 발주 상태·입고 예정시각을 조회한다.
3. 입고 예정 수량을 현재고로 합산해 도착 완료라고 보고하지 않는다. 메모의 도착 예정 주장과 실제 현재고·입고 기록을 구분한다.
4. 부품의 실제 도착이나 사용 가능 여부를 확인할 근거가 없으면 확인 필요로 남기고, 발주·입고 처리·재고 변경은 하지 않는다.

## HI-1.4 기록의 해석
인계 확인은 다음 근무자가 전달 사항을 확인했다는 기록이다. 설비 정상 판정, 정비 완료, 부품 입고 또는 발주 승인 기록을 대신하지 않는다. 서로 모순된 기록은 둘 다 근거와 함께 남긴다. 인계자 검토와 인수자 확인 절차 자체를 SOP나 고장 유형으로 추출하지 않는다.
