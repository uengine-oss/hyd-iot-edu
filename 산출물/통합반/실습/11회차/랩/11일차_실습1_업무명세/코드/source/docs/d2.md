# D2 — 생산·정비 조율 회의 준비 절차

교육용 가상 SOP v1. 요청은 2026-10-20 오전 협의를 위한 자료 준비이며 회의실 예약이나 참석자 달력 조회가 아니다.

## 1. 범위 확인
요청의 설비 HYD-02, 점검 목적, 기준 시각과 사용 문서 판본을 확인한다. D1의 계획 조건, D3의 결정·미결 사항, production_windows.csv의 생산 사용 시간, resources.csv의 부품·작동유·인력 정보를 읽는다.

## 2. 지난 결정과 현재 정보 대조
지난 회의의 완료된 조치, 제안만 된 일, 이번에 결정할 일을 나눈다. 안건은 자료를 요약한 문장만 쓰지 않고 결정할 질문, 상충하는 조건, 확인할 담당과 원문 위치를 포함한다. 같은 안건의 후속 메모를 새로운 독립 업무로 중복 생성하지 않는다.

## 3. 후보 비교
주간 정지, 당일 야간, 다음 날 야간을 D1의 시간·기한·생산·자원 조건에 대조한다. 제외가 확정돼도 다른 미확인 조건을 지우지 않는다. 미확인 자원이 있는 후보를 추천 가능으로 올리지 않는다. 비교에서 쓰는 시간은 정비 작업 시간이지 회의 시각이 아니다.

## 4. 사람에게 넘길 자료
안건표, 후보별 판단과 이유, 출처·기준 시각, 추가 확인 목록을 작성한다. 담당자의 검토 결과는 요청 번호와 자료 판본에 연결한다. 검토 통과를 설비 정지나 정비 완료로 기록하지 않는다.

## 5. 후속 정보 반영
별도로 받은 followup.md가 있으면 원래 입력을 보존하고 변경된 조건만 다시 평가한다. 이전 보고서를 덮어쓰지 말고 전후 차이와 변경 근거를 남긴다. 달라지지 않은 제외 사유와 범위 제한은 유지한다.
