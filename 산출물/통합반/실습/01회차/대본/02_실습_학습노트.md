# 통합반 1회차 실습 1 — Notion 주제 갤러리 만들기

> 제작용 · 비낭독: 2026-10-22 촬영 준비판. 두 과정 공통. 이론① 지식 자산화 뒤 진행한다. 기존 완성본을 보강해 도입에서 보여 주고, 본 수업은 빈 페이지에서 따라 만든다. 설치·로그인은 촬영하지 않는다. 아래 발화는 실제 화면이 해당 상태일 때만 말한다. 단계 안에서도 메뉴 열기 → 항목 선택 → 입력 → 결과 확인을 한꺼번에 실행하지 않는다.

> 진행 원칙: 1920×1080 원본에 UI 약150%. 고정 확대 상태로 연속 진행한다. 설명할 위치로 이동하고 짧게 멈춘 뒤 클릭한다. 입력 중 포인터는 글 옆 여백에 둔다. 짧은 글은 자연스러운 속도로 직접 입력한다. 설명 중 다음 단계로 넘어가지 않으며, 음성이 길면 대사를 줄이지 조작을 앞당기지 않는다. 가상 학생 반응·일괄 붙여넣기·의도적인 실패·시간 채우기용 대기를 넣지 않는다.

> 구조: 학습노트 하나→여러 주제 카드→자유로운 내용·하위 페이지. 홈은 갤러리, 카드 안은 단·목차·토글·멘션·파일·템플릿 활용 예시. 이론/실습/실수노트 분리와 별도 자료 DB·관계형·롤업은 만들지 않는다. 기본·고급 기능의 학습 가치는 실제 주제 안의 탐색·정리·재사용으로 보여 준다.

## N01 · 만들 모습 먼저 보기

> 조작·비낭독: 기존 홈의 갤러리→Notion 익히기→첫 페이지 꾸미기→상단 경로로 복귀. 이미 쓰던 노트임을 구별한다.

앞에서 배운 것을 어디에 쌓아 둘지, 직접 만들어 보겠습니다. 여기가 제 학습노트입니다. 카드 하나가 하나의 주제예요. 카드를 열면 관련 내용을 적고, 안에 페이지를 더 만들 수도 있습니다.

오늘은 빈 페이지에서 이 구조를 만들어 볼게요. 저는 노션을 익히는 주제로 보여 드리겠습니다. 여러분은 관심 있는 주제에 맞게 내용을 바꾸시면 됩니다.

## N02 · 다운로드 위치와 첫 화면

> 조작: 공식 Notion 홈페이지에서 다운로드 메뉴와 데스크톱 앱 위치를 가리킨다. 설치 버튼을 누르거나 인증 화면으로 가지 않고 준비된 작업 화면으로 전환한다. 주소 철자를 낭독하지 않는다.

노션은 여기 공식 홈페이지에서 컴퓨터용 앱을 받을 수 있습니다. 설치한 뒤 구글 계정 등 원하시는 방법으로 로그인하시면 됩니다. 브라우저에서도 사용할 수 있고요. 이번에는 이 화면에서 진행하겠습니다.

로그인하면 이렇게 페이지를 관리하는 화면이 나옵니다. 저는 그동안 정리해 둔 자료가 있어서 왼쪽에 페이지가 많습니다. 여러분도 기록을 쌓으면 이 목록이 늘어나요. 지금은 왼쪽에서 페이지를 찾고, 오른쪽에서 내용을 편집한다는 것만 보시면 됩니다.

> 확인: 개인 자료 목록은 필요 범위만 보이게 사전 배치. 실제 화면과 다른 계정 상태를 설명하지 않는다. 다운로드 주소 https://www.notion.com/desktop.

## N03 · 빈 페이지와 제목

> 조작: 사이드바 새 페이지 버튼을 짚고 클릭 → 빈 페이지 선택 → 제목 입력란 클릭. 입력 `내 학습 노트`. Enter로 본문 이동. 각각 화면이 바뀐 뒤 다음 설명으로 간다.

왼쪽에서 새 페이지를 만들겠습니다. 여러 양식이 보이면 빈 페이지로 시작할게요. 여기 큰 글씨가 페이지 이름입니다. 내 학습 노트라고 적겠습니다.

제목 아래를 누르면 내용을 쓸 수 있습니다. 제목은 왼쪽 목록에도 표시되니까, 나중에 찾을 수 있는 이름으로 붙이면 됩니다.

> 확인: 본문과 페이지 제목을 구별한다. 같은 이름의 기존 완성본과 혼동하지 않도록 촬영용 빈 페이지를 작업 대상으로 고정한다.

## N04 · 표지와 아이콘 고르기

> 조작·비낭독: 아이콘 추가→책 선택. 커버 추가→갤러리에서 부드러운 색상의 이미지 선택→위치 조정. 기존 완성본과 같은 계열을 사용한다.

먼저 이 노트의 분위기를 정해 보겠습니다. 제목 위에서 아이콘을 넣고, 표지도 고를게요. 저는 차분한 색상의 이미지를 사용하겠습니다.

위치 조정에서는 그림을 위아래로 옮겨 잘리는 부분을 고를 수 있습니다. 제목과 겹치지 않는지 확인할게요. 나중에 주제 카드에도 같은 계열의 표지를 쓰면 전체가 정돈돼 보입니다.

## N05 · 안내문과 블록

> 조작·비낭독: 본문에 관심 있는 주제를 모으고, 배운 내용을 나만의 방식으로 쌓아 갑니다. 입력. 손잡이 위치 표시.

이 공간을 어떻게 쓸지 한 줄 적겠습니다. 관심 있는 주제를 모으고, 배운 내용을 나만의 방식으로 쌓아 갑니다.

줄 왼쪽에 마우스를 대면 작은 점들이 보입니다. 노션에서는 이런 글 한 덩어리나 그림, 목록을 블록이라고 부릅니다. 이 손잡이로 내용을 옮기거나 모양을 바꿀 수 있어요.

## N06 · 강조와 안내 상자

> 조작·비낭독: 나만의 방식만 선택해 굵게. 빈 줄 슬래시→콜아웃 선택→카드 하나에 주제 하나. 카드 안은 자유롭게 구성하세요. 입력.

강조할 말만 잡고 굵게를 누르겠습니다. 모든 글을 강조하기보다 중요한 부분만 보이게 하는 거예요.

아래에는 안내 상자를 넣겠습니다. 빈 줄에서 슬래시를 입력하면 블록 메뉴가 나옵니다. 콜아웃을 고르고, 카드 하나에 주제 하나. 카드 안은 자유롭게 구성하세요라고 적겠습니다.

## N07 · 주제 갤러리 만들기

> 조작·비낭독: 슬래시→갤러리 보기→새 데이터 소스. 이름 주제 모음. 단순 이미지 모음과 데이터베이스를 구별.

이제 주제들을 모을 자리를 만들겠습니다. 갤러리 보기를 찾고 새 목록으로 시작할게요. 이름은 주제 모음입니다.

이 목록을 데이터베이스라고 부릅니다. 여기서는 여러 주제 페이지를 모아 두는 곳이라고 생각하시면 됩니다. 갤러리는 그 페이지들을 카드 모양으로 보여 주는 방식이에요.

## N08 · 첫 주제 카드

> 조작·비낭독: 새로 만들기→Notion 익히기. 쓰기 아이콘과 표지 선택. 전체 페이지로 열기 위치 안내.

새로 만들기를 누르고 첫 주제 이름을 적겠습니다. 노션 익히기입니다. 카드를 열면 이렇게 안쪽 페이지가 나옵니다.

글이 길어지면 전체 페이지로 열어도 됩니다. 여기에 직접 내용을 적거나 하위 페이지를 넣을 수 있어요. 이 주제에도 아이콘과 표지를 맞추겠습니다.

## N09 · 주제 소개와 제목

> 조작·비낭독: 도입 글을 쓰고, 페이지를 연결하며 나에게 맞는 노트를 만들어 봅니다. 입력. 여기서 이어 보기 본문→전환→제목2.

어떤 내용을 모을지 한 줄 적겠습니다. 글을 쓰고, 페이지를 연결하며 나에게 맞는 노트를 만들어 봅니다.

그 아래에는 여기서 이어 보기라고 쓸게요. 왼쪽 메뉴의 전환에서 제목2를 고르면 글이 구획의 제목으로 바뀝니다. 이미 쓴 본문도 이렇게 바꿀 수 있습니다.

## N10 · 주제 안에 하위 페이지

> 조작·비낭독: 빈 줄 슬래시→페이지→첫 페이지 꾸미기. 상단 경로에 부모 주제 확인.

이 주제 안에 페이지를 하나 만들겠습니다. 슬래시를 입력하고 페이지를 고릅니다. 이름은 첫 페이지 꾸미기로 할게요.

위쪽 경로를 보시면 노션 익히기 안에 들어와 있습니다. 새로운 주제 카드가 아니라 같은 주제 안의 페이지입니다.

## N11 · 제목과 목록

> 조작·비낭독: 하위 페이지 도입 한 페이지 안에서도 글의 모양을 바꾸어 읽기 쉽게 정리할 수 있습니다. 제목2 오늘 써 본 방법. 글머리 목록3줄: 제목으로 구획 나누기/목록으로 정리하기/긴 설명 접어 두기.

먼저 이 페이지에서 할 일을 적겠습니다. 한 페이지 안에서도 글의 모양을 바꾸어 읽기 쉽게 정리할 수 있습니다.

오늘 써 본 방법이라는 제목 아래에는 목록을 넣을게요. 글머리 기호 목록을 고르고 한 줄씩 적습니다. 엔터를 누르면 다음 항목이 생겨요. 끝내려면 빈 항목에서 엔터를 한 번 더 누릅니다.

## N12 · 블록 이동과 실행 취소

> 조작·비낭독: 목록 손잡이→삽입선→순서 이동→비교 후 실행 취소. 일부러 실패하지 않는다.

순서를 바꾸려면 왼쪽 손잡이를 잡습니다. 옮길 자리에 선이 나타나면 놓을게요. 문장을 다시 쓰지 않아도 됩니다.

이번에는 처음 순서가 더 자연스럽네요. 실행 취소로 돌리겠습니다. 방금 한 편집을 되돌리는 기능입니다.

## N13 · 토글에 긴 설명 접기

> 조작·비낭독: 슬래시→토글 제목 제목과 굵은 글씨는 어떻게 다를까?→펼침→안쪽 설명 입력→접기·펼치기.

긴 설명은 필요할 때만 보이도록 접어 두겠습니다. 토글을 고르고 제목과 굵은 글씨는 어떻게 다를까라고 적을게요.

삼각형을 눌러 안쪽에 설명을 넣습니다. 제목은 문서의 구획을 만들고 목차에도 표시됩니다. 굵은 글씨는 문장 안에서 중요한 말을 강조할 때 씁니다. 접으면 제목만 남고, 다시 누르면 설명이 보입니다.

## N14 · 할 일 목록

> 조작·비낭독: 토글 밖 구분선→제목2 다음에 해 볼 것→할 일 목록2줄. 아직 수행하지 않은 항목은 체크하지 않는다.

아래에는 다음에 해 볼 것을 적겠습니다. 구분선을 넣고 제목을 쓴 뒤 할 일 목록을 고를게요. 앞에 네모가 생깁니다.

내 관심 주제로 카드 하나 더 만들기, 내용에 어울리는 하위 페이지 이름 붙이기라고 적겠습니다. 해 본 뒤에 체크하면 됩니다. 필요 없는 주제에는 이 목록을 넣지 않아도 됩니다.

## N15 · 목차로 이동

> 조작·비낭독: 하위 페이지 도입 아래 목차 추가→제목 목록→다음에 해 볼 것으로 이동. 짧은 홈에는 목차를 중복 추가하지 않는다.

이 페이지가 길어지면 목차로 이동할 수 있습니다. 위쪽에 목차를 넣어 볼게요. 제목으로 만든 부분이 자동으로 모입니다.

다음에 해 볼 것을 누르면 그 위치로 이동하네요. 굵게 표시한 본문과 제목의 차이를 여기서 볼 수 있습니다.

## N16 · 두 번째 하위 페이지

> 조작·비낭독: 상단 Notion 익히기→슬래시 페이지→페이지 연결하기. 번호 목록으로 카드 열기/페이지 선택/이름과 내용/상단 경로 복귀 작성.

위쪽 경로에서 부모 주제로 돌아가겠습니다. 방금 만든 페이지가 여기 보이네요. 같은 주제 안에 페이지 연결하기라는 페이지를 하나 더 만들겠습니다.

이번에는 순서를 남길 거니까 번호 목록을 쓰겠습니다. 카드를 열고, 빈 줄에서 페이지를 고르고, 이름과 내용을 넣습니다. 위쪽 경로로 돌아오면 됩니다.

## N17 · 웹 자료 링크

> 조작·비낭독: 페이지 연결하기 안의 Notion 글쓰기 도움말 문구 선택→링크→공식URL 붙여넣기→재열기. https://www.notion.com/help/writing-and-editing-basics

필요할 때 원문으로 갈 수 있게 도움말을 연결하겠습니다. 노션 글쓰기 도움말이라고 쓰고 이 글자에 주소를 넣을게요. 긴 주소는 붙여넣겠습니다.

눌러서 맞는 페이지가 열리는지 보겠습니다. 글을 다시 복사해 넣지 않아도 여기서 원문을 찾아볼 수 있습니다.

## N18 · 단으로 나누어 배치

> 조작·비낭독: 부모 주제에서 페이지 링크 두 개를 좌우 단으로 배치. 손잡이 드래그→세로 삽입선→놓음. 좁은 화면에서는 한 단 선택.

주제 안에서 두 페이지를 나란히 배치해 보겠습니다. 손잡이를 잡고 옆으로 옮겨 세로선이 보일 때 놓을게요.

왼쪽은 첫 페이지 꾸미기, 오른쪽은 페이지 연결하기입니다. 아래에 무엇이 들어 있는지 짧게 적겠습니다. 글이 너무 좁아지면 한 단으로 써도 됩니다.

## N19 · 다른 페이지를 멘션으로 연결

> 조작·비낭독: 첫 페이지 꾸미기 끝에서 @→페이지 연결하기 검색→정확한 하위 페이지 선택→열고 경로로 복귀.

관련된 페이지로 바로 가는 연결도 넣겠습니다. 골뱅이를 입력하고 페이지 연결하기를 찾아 고를게요. 이름이 링크로 들어왔습니다.

누르면 같은 주제의 다른 페이지로 이동합니다. 내용을 중복해서 적는 대신 필요한 위치에서 이렇게 연결할 수 있습니다.

## N20 · 두 번째 주제와 교재

> 조작·비낭독: 홈 새 카드 지식 자산화. 짧은 메모 입력. 안에 1회차 교재 · 지식 자산화 페이지→파일 블록→참고_교재_발췌.md 업로드→재열기. 기존확정발췌 내용변경금지.

홈에는 다른 주제를 더할 수 있습니다. 지식 자산화 카드를 만들고 짧은 메모를 적겠습니다. 내 말로 정리하면 무엇을 알고 무엇이 아직 모호한지 드러난다. 출처도 함께 남겨 두면 다시 확인하기 좋다.

이 주제의 교재는 안쪽 페이지에 넣겠습니다. 파일을 고르고 준비한 발췌를 올릴게요. 업로드가 끝나면 다시 열어 맞는 내용인지 확인합니다. 모든 주제를 앞의 카드와 같은 모양으로 만들 필요는 없습니다.

## N21 · 카드 표지와 크기 정리

> 조작·비낭독: 홈 갤러리 설정→레이아웃→카드 미리보기 페이지 커버→중간 크기. 제목만 표시. 같은 계열 배경 유지.

홈으로 돌아와 카드 모양을 정리하겠습니다. 레이아웃에서 카드 미리보기를 페이지 커버로 고를게요. 주제마다 고른 표지가 보입니다.

크기는 제목을 편하게 읽고 여러 주제를 둘러볼 수 있도록 맞추겠습니다. 색을 너무 많이 섞지 않고 같은 분위기로 두면 노트가 정돈돼 보입니다.

## N22 · 같은 주제를 표로 보기

> 조작·비낭독: 보기 추가→표 전체 주제. 새 데이터 소스 생성하지 않음. 같은 제목 열어 본문 일치 확인.

같은 주제를 표로도 볼 수 있습니다. 보기를 추가하고 표를 고를게요. 이름은 전체 주제입니다.

카드가 줄로 바뀌었지만 같은 내용이에요. 제목을 열면 앞에서 쓴 글이 나옵니다. 사본을 만든 것이 아니라 목록을 보여 주는 모양을 바꾼 겁니다.

## N23 · 검색·정렬과 표시 속성

> 조작·비낭독: 검색 Notion→카드 확인→검색 지우기. 표 이름 오름차순 정렬. 생성 일시 표시/숨김. 기존 분야·이해도 보존, 필수작성아님.

주제가 많아지면 목록 안에서 검색해 찾을 수 있습니다. 노션을 입력해 보고, 검색어를 지우면 전체로 돌아옵니다.

표에서는 이름순으로 정렬할 수도 있어요. 만든 날짜처럼 필요한 항목은 표시하고, 지금 보지 않을 항목은 숨기겠습니다. 숨기는 것과 삭제하는 것은 다릅니다.

## N24 · 주제 시작 템플릿

> 조작·비낭독: 새로 만들기 옆 메뉴→기존 새 주제 템플릿 편집. 표지·아이콘·간단한 안내·빈 메모/페이지자리 배치. 반복구조는예시이며이론/실습등강제분류없음.

마음에 드는 시작 모양을 다음에도 쓰고 싶으면 템플릿으로 남길 수 있습니다. 새로 만들기 옆에서 템플릿을 열겠습니다.

표지와 아이콘, 짧은 안내 정도만 준비할게요. 내용과 페이지 이름은 나중에 바꿀 수 있도록 비워 두겠습니다. 모든 주제를 같은 항목으로 채우라는 양식은 아닙니다.

## N25 · 템플릿으로 새 주제 시작

> 조작·비낭독: 템플릿 메뉴에서 새 주제 선택→실제 관심 주제명 입력→서식적용 확인. 별도기본설정강요없음. 촬영 전 실제생성확인은미확인으로기록.

목록으로 돌아와 방금 준비한 템플릿을 선택하겠습니다. 표지와 안내가 들어왔는지 확인할게요. 제목은 내가 정한 주제로 바꾸면 됩니다.

필요한 페이지를 추가하고 필요 없는 안내는 지우세요. 빈 페이지로 시작해도 되고, 자주 쓰는 모양만 가져와도 됩니다.

## N26 · 공유 대상과 권한

> 조작: 홈 상단 공유 → 현재 접근 범위·초대 입력·권한 선택 UI를 짚음. 이메일 입력·초대 발송·접근 범위 변경은 수행하지 않음. 이미 공개된 기존 원본과 새 개인 페이지 상태를 구별.

노트가 준비됐으니 다른 사람에게 보여 주는 위치도 보겠습니다. 오른쪽 위 공유를 누릅니다. 누구에게 보여 줄지, 보기만 허용할지 편집도 허용할지를 여기서 정합니다.

링크를 복사했다고 누구나 볼 수 있는 것은 아닙니다. 이 화면의 접근 범위를 함께 봐야 합니다. 내 기록을 보여 주기만 할 때는 읽는 권한부터 생각하면 됩니다. 지금은 초대를 보내지 않고 설정 위치를 확인하겠습니다.

## N27 · 게시와 댓글의 용도

> 조작: 공유의 게시 탭 또는 해당 판본의 게시 위치 열기. 현재 공개 여부 확인만 하고 게시·게시취소 실행하지 않음. 돌아와 기록의 문장 선택 → 댓글 위치 확인 후 취소. 타인 언급·알림 발송 없음.

웹페이지처럼 공개하는 기능은 게시입니다. 일부 사람과 함께 보는 공유와, 웹에 공개하는 게시를 구별해 두시면 됩니다. 여기서는 공개 범위를 바꾸지 않겠습니다.

함께 보는 사람이 문장에 의견을 남길 때는 댓글을 쓸 수 있습니다. 문장을 선택하면 이 위치에서 의견을 남길 수 있어요. 혼자 쓰는 학습노트에서는 앞서 만든 질문 목록으로도 충분합니다.

## N28 · 마지막에 파일로 내보내기

> 조작: 홈 페이지 메뉴 → 더 보기 안의 내보내기(판본에 따라 메뉴 직속) → HTML 선택 → 하위 페이지 포함 옵션 확인 → 촬영용 노트만 내보내기. 다운로드 완료 후 압축 안의 홈 HTML 열기. PDF 생성은 범위 밖.

마지막으로 노트 내용을 파일로 꺼내 보겠습니다. 페이지 메뉴에서 내보내기를 찾습니다. 이번에는 브라우저로 열어 볼 수 있는 HTML로 고를게요. 안쪽 기록도 함께 받을지 옵션을 확인하겠습니다.

다운로드한 파일을 열어 보겠습니다. 홈과 기록 내용이 들어 있는지 확인할게요. 이렇게 꺼낸 파일은 이 시점의 사본입니다. 노션에서 글을 고친다고 이 파일까지 자동으로 바뀌지는 않습니다.

> 확인: 촬영용 홈 범위만 내보내고 전체 개인 작업 공간은 내보내지 않음. 관계형·보기·템플릿까지 완전히 복원되는 백업이라고 설명하지 않는다. 실패 시 관측 오류를 말하고 미완료로 남긴다.

## N29 · 주제에서 자유롭게 확장하기

> 조작·비낭독: 홈→Notion 익히기→하위 두 페이지 경로 확인. 성공한조작만발화. 촬영·50분실측은미수행.

학습노트 안에 여러 주제가 있고, 주제 안에는 글과 하위 페이지가 있습니다. 표지와 배치를 맞추고, 필요한 곳에 연결도 넣었습니다.

이제 여러분의 주제로 바꿔 쓰시면 됩니다. 한 페이지에 적다가 길어지면 나누고, 자주 쓰는 구성은 템플릿으로 남겨 보세요. 나중에 다시 찾아 쓰기 편한 노트가 되면 됩니다.
