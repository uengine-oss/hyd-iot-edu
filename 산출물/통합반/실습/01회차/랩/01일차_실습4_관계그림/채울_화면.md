# 필요한 화면 — 빈자리

각 자리는 아래 장면과 확인 기준이 보이도록 채운다.

1. 자료 다운로드와 작업 공간 열기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 대상 목록·매뉴얼 발췌·관계 검토표와 빈 arrows.app 그림이 함께 보인다.
2. 설비와 증상에서 출발하기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 노드마다 종류가 표시되고, 각 관계를 이름과 방향대로 문장으로 읽을 수 있다.
3. 핀 오염의 증거와 조치 연결하기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 두 증거의 집계 구간(30초 평균·2분 평균)과 기준이 보이고, 완화(MITIGATED_BY)와 근본 조치(REMEDIED_BY)가 구분된다.
4. 팬 구동 불량 가지 추가하기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 공통 고장 유형은 하나로 유지되고, 같은 팬 진동 증거에 원인별 판별 조건과 팬 점검(HM-8.1) 근거가 따로 보인다.
5. 문장과 원문으로 대조하기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 관계 검토표에 원문 근거와 두 원인 비교가 채워지고, 실습 3 사건에서 확인한 범위와 문서 기준이 구분된다.
6. 같은 그림을 조건에 적용하기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 두 조건마다 따라갈 관계와 보류할 판단이 매뉴얼·교재 근거와 함께 검토표에 남고, 그림에 새 관계를 더하지 않았다.
7. 저장하고 다시 열기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 새 그림에서 다시 불러온 JSON에 이름·방향·원인별 조건·근거 주석이 남아 있다.
