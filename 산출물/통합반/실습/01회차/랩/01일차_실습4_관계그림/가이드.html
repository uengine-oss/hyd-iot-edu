납기가 가까운 냉각설비 이상 대응

원인 근거를 보고 조치를 선택한 뒤, 조건과 승인·실제 효과·정비·생산과 출하 확인까지 한 그림으로 연결합니다.

온라인 제작 참고용입니다. 아래 왼쪽 안내로 대상과 행동을 먼저 알리고, 설명하면서 오른쪽 조작을 수행한 뒤 결과를 확인합니다. 익숙한 기능은 짧게 안내하되 필수 입력과 과정은 생략하지 않습니다.

대상·속성·관계 입력 · 판단과 회복 기준 · 결과 검토 · 예상 시간 · 미촬영 화면 계획 · 기록

정본 기준: [실습 대본](../../../../../문서/교재/기준_실습대본.md)의 ‘자연스러운 진행과 유연한 조정’. 문장 고정 낭독보다 실제 화면과 문맥을 우선한다. 익숙한 기능의 정의는 반복하지 않고, 이번 대상·입력값·필수 선행 조작은 말한다.

아래 표는 왼쪽 발화로 대상과 행동을 먼저 알려 준 뒤, 설명을 이어 가면서 오른쪽 조작을 수행하고 화면의 결과를 확인한 뒤 다음 행으로 간다. 매 행의 발화 종료까지 기다리지 않는다. 서로 다른 행을 한꺼번에 실행하지 않는다. 결과 문장은 실제 표시가 맞을 때만 말한다. 틀리면 해당 칸을 짚고 수정할 내용을 먼저 말한 뒤 고친다.

표의 행 수가 고정 대기 횟수는 아니다. 짧게 안내하고 정상 속도로 조작한다. 화면이 이미 필요한 상태이면 중복 클릭과 그 안내는 함께 생략한다. 뒤의 결과를 미리 만들거나 필요한 과정을 잘라내지는 않는다.

입력값의 기호는 뜻으로 읽는다. 예: `CE < 70 % AND VS1 < 0.9`는 ‘냉각 효율 70퍼센트 미만이고 팬 진동 0.9 미만’. 정확한 입력 문자열은 조작 칸에 보존한다. 긴 식별자를 철자씩 낭독하지 않는다.

입력 후 바뀐 이름·속성을 눈으로 확인한다. 매번 ‘잘 들어갔습니다’를 덧붙이지 않는다. 판단이 바뀌는 지점의 결과는 말로 짚는다.

선택 해제는 그림 영역의 빈 곳을 클릭한다. 새 노드가 생기면서 배치가 바뀌면 이름으로 대상을 다시 찾고, 필요한 경우에만 위치를 짧게 덧붙인다. 고정 좌표나 확인하지 않은 색상은 낭독에 넣지 않는다.

겹침을 풀 때의 발화: ‘이름이 겹치네요. **[실제 이름]** 원의 가운데를 잡아 **[보이는 빈 위치]**로 옮길게요.’ → 대상·이동 방향 안내 후 설명 중 원 중심 드래그 → 이름·선 가독성 확인. 관계를 만드는 바깥 고리 드래그와 구별한다. 이 조정을 모든 노드에 강제하지 않는다.

커서는 후광 없는 흰 화살표·얇은 검은 테두리. 원본 1080p, 읽을 수 있는 약150% 글자·패널은 촬영 전에 준비한다. 프레임 지연을 설명의 여유로 계산하지 않는다.

이번 작업은 정적 원고 보강이다. 촬영·음성 생성·설비 실행은 하지 않았다. 기존 샘플의 기본 조작 근거를 재사용하며, 전체 그래프 배치와 가져오기 경로는 후속 확인 대상이다.

저장한 데이터 재열기 — 경로 확인 후 구체화

데이터가 제대로 저장됐는지 새 그림에서 다시 열어 볼게요. 이름만 남았는지 볼 게 아니라, 속성과 화살표 방향도 함께 확인하겠습니다.

**미확인 구간 — 아직 촬영 가능한 고정 큐가 아님.** 가져오기·새 그림 메뉴의 실제 이름과 파일 선택 경로는 기존 샘플에서 확인하지 않았다. 이번에는 브라우저를 조작하지 않으므로 버튼명을 지어내지 않는다. 후속 허용 단계에서 원본을 보존한 채 실제 메뉴→파일 선택→열기 순서를 확인하고, 각 클릭과 실제 파일명을 위와 같은 발화/행동 행으로 채운다. 이 메모를 묵음 조작이나 ‘알아서 재열기’로 대신하지 않는다.
재열기 확인: 아래 명세의 20개 노드·26개 관계 전체와 속성을 대조한다. 특히 원인 근거, 조건·승인, 명령/응답, 회복 조건, 정비 후 기준, 생산·품질 후속, 보류·재검토 경로를 확인한다. PNG는 글자 잘림과 관계 방향을 확인한다. 이상이 있으면 무엇을 고칠지 말한 뒤 해당 항목을 수정하고 저장한다. 실제로 확인한 뒤에만 다음 마무리를 사용한다.

한 사건의 판단부터 조치 뒤 확인까지 이어졌네요. 다음에 값이나 조건이 달라져도 어디를 다시 봐야 하는지 찾을 수 있어요. 이 그림을 바탕으로 대상과 관계를 더 정확하게 정리해 나가겠습니다.

정적 준비판입니다. 새 그림·가져오기 경로와 전체 배치·재열기는 미확인입니다. 촬영·음성·실행은 수행하지 않았습니다. 기존 교재 발췌의 두 원인 비교는 원문 참고 자료로 보존하며, 이번 작성 순서는 이 가이드와 대상 목록을 따릅니다.
