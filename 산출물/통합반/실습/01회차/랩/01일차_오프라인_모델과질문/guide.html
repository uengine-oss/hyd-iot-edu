앞 단계의 제공 모델로 시작합니다. 포털과 분리된 실습 폴더 전용 DB를 사용합니다.

01 모델 적재하기

Docker를 실행하고 VS Code 터미널에 입력하세요.

python offline_load.py

제공 모델은 노드 44개·관계 57개입니다. 「적재 완료」와 결과/적재_확인.json을 확인하세요.

02 질문 실행하기

python lab_db.py

열린 Browser의 Protocol에서 bolt://를 선택하고 Connection URL에는 출력 주소의 127.0.0.1:포트 부분만 넣으세요. Database user는 neo4j, Password는 비워 두고 Connect를 누릅니다.

질문.cypher에서 문장 하나를 복사해 Browser 입력칸에 넣고 Run을 누르세요.

설비 3대에 센서가 각각 5개씩 조회됩니다. 부품 3종은 각각 HYD-01·02·03과 연결됩니다.

03 다시 확인하고 저장하기

같은 적재 명령을 다시 실행해 44개·57개가 유지되는지 확인하세요. 질문 결과와 원자료에서 확인한 행을 결과/에 기록하세요.

개인 모델을 적용할 때는 제공 입력을 보관하고, 바꾼 종류·관계 이름에 맞춰 질문도 수정합니다. 대상 삭제·종류 변경을 확인할 때는 시작 도구에서 새로 시작해 별도 DB를 사용하세요.

보관할 파일은 재부팅 전에 USB 또는 개인 클라우드로 복사합니다.
