관련 대상을 묶어 그림을 확장하고, 모델과 실제 조회 결과를 원자료에 대조합니다.

01 관계 그림 확장하기

쿨러와 센서부터 시작해 고장·원인·조치를 관련 단위로 추가하세요. 각 단계의 사진에서 새로 연결할 대상을 확인합니다.

ARROWS 단계별 가이드

화살표를 문장으로 읽고, 저장한 JSON을 다시 열어 연결을 확인하세요.

02 최소 모델 만들기

시작 도구에서 통합반 → 온라인 02회차 → 「현장 자료를 질문에 답하는 모델로 만들기」를 선택하세요. 이 단계는 두 과정 공통입니다.

모델 작업 가이드

현장 목록으로 설비·센서·부품의 종류, 식별자, 속성, 연결을 정하고 schema.json·graph.json을 만드세요.

설비가 다른 TS1은 구별되고, 같은 품번의 부품은 공유됩니다. 질문의 답을 원자료와 대조하세요.

03 랩 그래프에 적재하고 질문하기

시작 도구에서 오프라인 01회차 → 「랩 그래프 적재와 질문」을 선택하세요. 앞 단계 완성 모델이 들어 있습니다.

제공 적재 절차와 확인 결과 · 수동 ZIP

04 포털의 기준 지도와 비교하기

학교 PC의 HYD 포털에서 지식 지도를 열고 설비를 선택하세요. 구성요소와 센서의 종류·속성·연결 방향을 개인 모델과 비교합니다.

같은 의미를 표현하는 부분과 다르게 표현한 부분을 짚어 보세요. 개인 모델은 포털에 자동 반영되지 않습니다.

05 모델과 질문 보완하기

아직 답하지 못한 질문 하나를 고르고 필요한 관계·속성을 원자료에서 찾으세요. AI에 변경할 범위와 확인 사례를 전달해 모델과 질의를 수정합니다.

수정한 질문과 기존 질문을 다시 실행하고, 결과가 달라진 이유를 자료로 설명하세요.

06 결과 보관하기

관계도 JSON, schema.json, graph.json, 질의와 확인 기록을 저장하세요. USB 또는 개인 클라우드에 복사한 뒤 복사본을 다시 열어 확인합니다.

다음 실습은 시작 도구에서 새로 선택합니다. 이전 개인 결과 없이도 제공 시작본으로 이어갈 수 있습니다.
