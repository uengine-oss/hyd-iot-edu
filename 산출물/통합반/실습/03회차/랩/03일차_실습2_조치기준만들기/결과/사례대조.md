# 사례 대조

> 제공 빈 틀입니다. 보관하지 말고 바로 채웁니다.

결정표를 손으로 대입한 판정입니다. 판단 입력은 원자료의 행(파일·시각)으로 확인해 적고, 근거에는 결정표의 rule_id와 원문 절을 적습니다.

| 사례 | 사례 종류 | 후보 | 판단 입력(값 또는 없음과 이유, 원자료 행) | 일치 규칙 | 경고 | 감점(만원) | 제외 사유 | 미확인 입력 | 판정 | 근거 |
|---|---|---|---|---|---|---:|---|---|---|---|
| | | | | | | | | | | |
