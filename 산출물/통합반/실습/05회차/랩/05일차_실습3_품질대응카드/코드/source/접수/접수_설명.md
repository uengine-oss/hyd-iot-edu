# 불량 접수 설명

`불량_접수.json`은 10월 5일부터 8일까지 들어온 접수 열두 건이다. 고객이 보낸 메일, 영업팀이 받아 적은 전화 메모, 출하 검사와 공정 검사, 구매품 입고 검사에서 올라온 것이 섞여 있다.

## 접수 한 건의 칸
| 칸 | 뜻 |
|---|---|
| `번호` | 접수 번호 (`Q01`~`Q12`). 들어온 순서다 |
| `접수_시각` | 접수한 시각 |
| `경로` | 접수가 들어온 길 (고객 메일, 전화 메모, 출하 검사, 공정 검사, 입고 검사) |
| `보낸_곳` | 접수를 보낸 곳. 대응 초안을 받을 곳이다 |
| `접수자` | 접수를 받아 올린 사람 |
| `본문` | 보낸 곳이 쓴 글, 또는 접수자가 받아 적은 글. 손대지 않은 원문이다 |

## 알아 둘 것
- 본문은 사람이 쓴 글이다. 로트 번호나 수량이 빠져 있기도 하고, 「아직 모른다」「내일 보내겠다」고만 적혀 있기도 하다.
- 본문에 원인이 적혀 있는 접수가 있다. 그것은 보낸 곳이나 접수자가 그렇게 본다는 말이다.
- 같은 로트에서 접수가 두 번 들어온 것이 있다.
- 품목과 설비: FG-AUTO-7(유압 브래킷)은 HYD-01, FG-IND-3(산업용 매니폴드)은 HYD-02, FG-AUTO-9(실린더 블록)은 HYD-03에서 만든다. P-CLR-CORE(쿨러 코어)는 사 오는 부품이다.

## 이번 실습의 판정 범위

접수 문장은 교육용 입력이다. 사진 첨부라는 문구만으로 실제 사진을 확인한 것으로 보지 않는다. 원인 분석 대장은 접수 번호로 연결하고 상태·종결일·근거를 남긴다. 같은 로트만으로 원인을 전파하지 않는다. Q02의 접수자 추정과 종결 조사 결과, Q04·Q09의 진행 중 조사, Q11의 별도 접수를 구별한다. 수량 정규식은 후보를 찾는 보조 수단이며 전체·검사·불량 수량의 뜻은 원문에서 확인한다. 모든 대응 문구는 검토 전 초안이다.
