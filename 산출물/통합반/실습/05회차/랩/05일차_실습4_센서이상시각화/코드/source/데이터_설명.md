# 교육용 가상 입력

이 CSV는 자료 제작 시 작성한 가상 입력이다. 실제 측정·조회·실행 결과가 아니다. 시간대는 +09:00, 온도 TS1은 degC, 압력 PS1은 bar이다. 09:03 온도는 누락이다. 연속 유효 관측의 상승과 누락 처리·단위 분리를 연습하며, 경보 판정·원인 추론의 증거로 쓰지 않는다. 실제 교육 환경 조회 자료를 사용하면 별도 input에 저장하고 기간·태그·시간대·출처를 기록한다.

## 인접·누락·중복 처리 기준

같은 설비·태그의 행을 시간순으로 정렬한다. 이 자료는 1분 간격이므로 두 유효 관측의 간격이 정확히 1분일 때만 인접 상승으로 연결한다. 빈 값이나 빠진 시각을 가로질러 연결하지 않는다. 중복 키는 설비·태그·시각이며 서로 다른 태그의 같은 시각은 중복이 아니다. 단위 불일치와 숫자 변환 오류를 별도로 보고한다. 09:03의 TS1 빈 값은 0이 아니다. 상승 표시는 경보 판정이나 원인 확정이 아니다.
