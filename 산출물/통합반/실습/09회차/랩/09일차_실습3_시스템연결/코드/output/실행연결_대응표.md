# 실행 연결 대응표

제공 빈 틀입니다. 내 그림 파일, 제공 기준 BPMN·매핑, 포털 화면에서 직접 확인한 값만 적습니다. 확인하지 못한 칸은 「미확인」으로 씁니다.

| 항목 | 내 그림 | 기준 흐름 |

## 작업별 대응

「예상」은 제공 매핑을 열기 전에 적습니다. 「대응 판정」에는 내가 정한 표시(예: 대응함 · 다르게 대응 · 대응 없음)를 씁니다.

| 내 요소 ID | 이름·종류·레인 | 예상(매핑 열기 전) | 대응하는 기준 요소 ID | 제공 매핑의 실행 기능(부품) | 담당(에이전트·역할) | 대응 판정 | 근거(파일·키·화면) |
|---|---|---|---|---|---|---|---|
| | | | | | | | |
