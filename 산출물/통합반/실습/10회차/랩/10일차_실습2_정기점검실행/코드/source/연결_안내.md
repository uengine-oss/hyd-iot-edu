# 참조 흐름 세 개 — bpmn.io 에서 열어 보고, 포털로 가져와 연결하기

수업 시나리오 A · B · C 가 실제로 도는 흐름 그림이다. [demo.bpmn.io](https://demo.bpmn.io) 의 "Open file"로 열리고, 포털 **흐름 가져오기**에 그대로 올릴 수 있다.
강사 스택이 쓰는 정의(`scripts/c3_flows.py`)와 같은 모양 · 같은 연결이다(`tests/test_student_reference_flows.py` 가 지킨다).

| 시나리오 | 그림 | 연결 값 | 흐름 이름 |
|---|---|---|---|
| A 긴급 대응 (HYD-01 쿨러 과열) | `cooling-emergency.bpmn` | `cooling-emergency.mapping.json` | 냉각 긴급 대응 |
| B 정기 점검 (HYD-02) | `pm-planning.bpmn` | `pm-planning.mapping.json` | 정기 정비 |
| C 재고 보충 (HYD-03 씰 키트) | `spare-purchase.bpmn` | `spare-purchase.mapping.json` | 예비품 구매 |

세 흐름의 승인 단계는 같다: 에이전트 제안 → 담당자가 **승인 또는 거절** → 승인하면 처리, 거절하면 처리 없이 "결과 보고: 거절"로 끝.
승인하지 않으면 그 자리에서 계속 기다리고, 10분(20배속에서는 실제 30초)이 지나면 "승인 지연 알림"만 나간다(자동 취소 없음).

## 가져와 연결하는 순서 (포털 → 흐름 가져오기)

1. `.bpmn` 파일을 고르고 **흐름 id** 를 내 것으로 적는다(예: `my_cooling`). `c3_…` 과 기준 흐름 id 는 쓰지 않는다.
2. **시작 조건**: "경보로 시작"을 고르고 아래 표의 경보 하나만 체크한다(처음에는 아무 경보도 선택하지 않는다).
3. **단계마다 부품 · 담당**을 아래 표대로 고른다. 에이전트 단계는 에이전트를, 승인 단계는 역할을 고른다.
4. **분기 조건 · 타이머**를 아래 표대로 넣는다.
5. **사전 검사**가 통과하면 **등록** → **배포**. 배포하면 그 경보는 가장 최근에 배포한 흐름이 연다(경보 → 흐름 표에 "내가 배포한 흐름"으로 보인다).
6. 다 쓰면 **기준 흐름으로 되돌리기** — 같은 사용 공간의 사용자 흐름 배포를 모두 내린다. 등록한 판본은 남지만 내 흐름 하나만 되돌리는 동작은 아니다. 기준 흐름이 다루지 않는 PM_DUE·SPARE_BELOW_MIN은 사람 검토 경로로 간다. 공용 환경의 범위와 복구 시점은 운영자와 맞춘다.

같은 사용 공간을 여럿이 같이 쓰면 **마지막에 배포한 사람의 흐름**이 그 경보를 가져간다.

| 승인 지연 (점선 타이머) | — | 기한 `PT10M` |

## 세부 설정도 화면에서 입력하기

1. 시스템 단계의 **부품**을 고르면 아래에 설정 폼이 열린다. 결과 보고는 **처리 결과 · 보고 제목 · 보고 내용**을 입력한다.
2. B의 **정비 요청**에는 **정비 예정 시간이 담긴 값**에 `alert.evidence.night_window_id`를 적는다. **공지 메일**의 받는 사람 · 제목 · 내용은 `pm-planning.mapping.json`의 `T_wo.config.mail`과 같이 입력한다.
3. C의 **ERP 발주**에도 공지 메일을 입력하고, **입고 확인**의 **바로 입고 처리**에서 **예**를 고른다.
4. **판단 · 제안**의 **에이전트 지시문**과 보고 제목 · 내용은 연결 값 파일을 보며 입력한다. `{asset}` 같은 표시는 실행할 때 처리 건 값으로 채워진다.
5. 승인 분기는 **승인 결과 → 같음 → 승인**, 회복 분기는 **설비 회복 여부 → 같음 → 예**로 입력한다. 반대쪽 선은 **그 밖의 경우**를 체크한다. 알림 기한은 분 단위로 `10`을 입력한다.
6. **검사**를 누르면 연결 설정을 저장하고 잘못된 단계와 사유를 표시한다. 고쳐서 다시 검사한 뒤 **판본 등록**을 누른다. 등록만으로 운영 흐름은 바뀌지 않는다. 배포는 **업무 프로세스**에서 등록한 흐름과 판본을 선택해 진행한다.

`*.mapping.json`은 정답 대조와 자동 검증용으로 그대로 보관한다. 화면에서 세 흐름을 연결하고 등록하는 데 API 호출은 필요하지 않다.
