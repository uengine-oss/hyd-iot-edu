# 모델을 그래프에 적재하고 질문으로 검증하기

앞 단계의 완성 모델에서 출발해 적재·조회 로직을 직접 작성합니다.

## 출발점

입력/에 앞 단계 완성 모델과 원자료가 있습니다. 이전 개인 결과 없이 시작할 수 있습니다. 개인 모델을 쓰려면 제공 입력을 보존하고 별도 폴더에 복사하세요.

## 이번에 해결할 질문

1. 설비별 구성 요소에는 어떤 센서가 연결되어 있는가?
2. 센서의 물리량·단위·정상값·한계는 무엇인가?
3. 같은 교체 부품을 사용하는 설비는 무엇인가?

## 작업

AI와 적재·조회문을 작성하세요. 같은 입력을 두 번 적재해도 대상과 관계가 늘지 않아야 합니다. 이름이 바뀌어도 같은 ID의 대상은 유지되어야 합니다. 전체 삭제문은 사용하지 마세요. 고칠 것이 생기면 필요한 대상만 수정하세요. 공용 부품의 사용 설비를 원자료와 대조하고, 다른 품번과 원자료에 없는 품번도 조회해 결과를 구별하세요.

AI에게 전달할 목표·입력·제약·확인 방법을 먼저 자기 말로 정리하세요. 관련 자료를 함께 읽고, 필요한 만큼 계획을 확인한 뒤 구현하세요. 결과는 직접 실행해 원자료와 대조하세요.

## 저장할 결과

## 확인

python lab_db.py
Neo4j Browser에서 작성한 적재문 실행 → 조회문 실행 → 같은 적재문 재실행

형식 검사나 실행 성공만으로 완료하지 않습니다. 질문별 원자료의 행과 실제 답을 대조하고, 수정한 점·확인하지 못한 점을 짧게 남기세요.

## 저장과 다음 실습

결과 폴더를 저장하고 다시 열어 확인하세요. 재부팅 전에 보관할 결과는 USB 또는 개인 클라우드에 복사하세요. 다음 실습도 독립 시작본을 제공하므로 개인 결과는 선택 입력입니다.
