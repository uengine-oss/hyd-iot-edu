01 시작하기

입력/에 앞 단계 완성 모델과 원자료가 있습니다. 이전 개인 결과 없이 시작할 수 있습니다. 개인 모델을 쓰려면 제공 입력을 보존하고 별도 폴더에 복사하세요.

VS Code에서 START.md를 열고 이번 요구를 확인하세요.

입력/   이전 단계 자료
자료/   현장 원자료(설계 실습)
결과/   이번에 만들 결과
AGENTS.md   작업 규칙

터미널에서 아래 명령을 실행하세요. Docker가 실행 중이어야 합니다.

python lab_db.py

「랩 DB 준비 완료」가 나오면 열린 Browser의 Connect URL에 출력된 bolt 주소를 넣으세요. Username은 neo4j, Password는 비워 둡니다. 연결 정보는 랩_연결.json에도 저장됩니다.

02 요구 정하기

  1. 설비별 구성 요소에는 어떤 센서가 연결되어 있는가?
  2. 센서의 물리량·단위·정상값·한계는 무엇인가?
  3. 같은 교체 부품을 사용하는 설비는 무엇인가?

자료에서 답의 근거를 찾고 AI에 전달할 목표와 제약을 정리하세요.

03 AI와 만들기

AI와 적재·조회문을 작성하세요. 같은 입력을 두 번 적재해도 대상과 관계가 늘지 않아야 합니다. 이름이 바뀌어도 같은 ID의 대상은 유지되어야 합니다. 전체 삭제문은 사용하지 마세요.

한 기능의 결과를 확인한 뒤 다음 작업을 요청하세요. 수정 요청에는 입력·기대 결과·실제 결과를 함께 전달하세요.

요청을 정리할 때 볼 항목

만들 결과 / 참고할 자료 / 바꾸지 않을 범위 / 성공을 확인할 사례

04 결과 확인하기

python lab_db.py
Neo4j Browser에서 작성한 적재문 실행 → 조회문 실행 → 같은 적재문 재실행
  • 설비가 다른 TS1은 구별되고 HYD-01의 중복 행은 하나로 처리됩니다.
  • CE가 물리 센서로 잘못 설명되지 않고, 한계 없음과 0이 구별됩니다.
  • 공용 부품은 품번으로 연결되며 사용 설비를 따라갈 수 있습니다.
  • 같은 입력을 재적재해도 노드·관계 수가 늘지 않습니다.

원자료와 실제 결과를 대조하세요. AI의 완료 메시지는 실행 결과를 대신하지 않습니다.

공유 부품 조회 예시입니다. 각 품번의 사용 설비를 원자료와 대조하세요.
