01 지식 지도 열기

학교 PC의 HYD 포털 열기

포털의 지식 지도를 열고 HYD-01을 선택하세요. 학교에서 별도 주소를 안내받았다면 그 주소를 사용합니다.

탐색_기록.md에 포털 주소와 확인 시각을 적습니다. 앞 실습의 예제 DB와는 별개의 기준 그래프입니다.

02 센서와 부품 찾기

자원 칸에서 오일 쿨러를 누르세요. 연결된 관계가 강조되고 상세 칸에 나가는 관계와 들어오는 관계가 나옵니다. 센서와 교체 부품을 눌러 ID·클래스·속성을 기록합니다. 검색으로 이름을 찾아도 됩니다.

이름만 적지 않고 대상 ID와 값을 함께 남깁니다. 화면에 표시되지 않은 항목은 미확인으로 둡니다.

03 관계 방향 읽기

쿨러와 센서, 쿨러와 부품 사이의 관계 이름을 시작 ID → 끝 ID로 적으세요. 화면에서 따라간 방향과 저장된 화살표 방향을 구별합니다.

04 같은 이름, 다른 대상

TS1이라는 이름이 센서와 상태 변수에 모두 보이면 두 노드의 ID와 클래스를 나란히 적으세요.

이름이 같아도 ID와 클래스가 다르면 다른 대상입니다. 센서는 재는 장치, 상태 변수는 재는 값의 종류입니다.

05 기준 지도와 다음 모델 비교

설비를 HYD-02로 바꿔 같은 센서 노드가 다시 이어지는지 확인하세요. 포털 기준 지도가 같은 모델의 세 설비를 어떻게 표현하는지 기록합니다.

다음 실습에서는 설비별 센서를 구별하는 모델을 직접 만듭니다. 그때 비교할 질문을 하나 적어 두세요.

06 기록 확인하고 저장하기

설비 → 구성요소 → 센서, 구성요소 → 부품 경로를 기록에서 다시 읽어 보세요. 빠진 시작·끝 ID는 화면으로 돌아가 확인합니다.

결과/에 탐색 기록을 저장하고 다시 엽니다. 다음 모델 설계는 별도 시작본을 사용합니다.
