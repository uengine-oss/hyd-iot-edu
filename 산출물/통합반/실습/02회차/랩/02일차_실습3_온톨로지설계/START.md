# 현장 자료를 질문에 답하는 모델로 만들기

현장 목록과 관계 그림을 대조해 설비별 센서와 공유 부품을 구별하는 모델을 만듭니다.

## 출발점

자료/의 CSV·현장 메모와 입력/관계그림.json에서 출발합니다. 이번 스키마·인스턴스는 아직 작성되지 않았습니다.

## 이번에 해결할 질문

1. 설비별 구성 요소에는 어떤 센서가 연결되어 있는가?
2. 센서의 물리량·단위·정상값·한계는 무엇인가?
3. 같은 교체 부품을 사용하는 설비는 무엇인가?

## 작업

종류와 개별 대상을 나누고, 식별자·속성의 자료형·필수 여부·관계 방향·연결 수를 정의하세요. 그 정의로 원자료의 인스턴스를 만드세요. 같은 센서 이름이 다른 설비에 쓰인 경우, 별칭, 중복 행, 빠진 값을 원자료에서 구분하고 어떻게 처리했는지 결과/자료_검토.md에 적으세요.

## 진행 방법

1. AI에게 파일은 바꾸지 말고 자료를 읽어 과제와 확인할 점을 정리해 달라고 요청하세요. 짚어 준 근거는 원자료에서 직접 확인합니다.
2. 목표·입력·지킬 조건과 내가 정한 결정을 자기 말로 결과/요구사항.md에 적으세요. 구현 전에 원자료에서 질문별 기대 답을 두세 개 직접 찾아 함께 적어 둡니다.
3. AI에게 계획을 먼저 받아 검토한 뒤 구현을 맡기세요. 한 번에 다 맡기지 말고 확인할 수 있는 단위로 나눕니다.
4. 완료라는 말 대신 실행한 명령과 실제 출력, 바뀐 파일을 확인하세요. 입력/·자료/는 바뀌지 않아야 합니다.
5. 적어 둔 기대 답과 실제 결과를 대조하고, 다르면 입력·기대·실제를 함께 전달해 고치세요.

## 저장과 다음 실습

결과 폴더를 저장하고 다시 열어 확인하세요. 재부팅 전에 보관할 결과는 USB 또는 개인 클라우드에 복사하세요. 다음 실습도 독립 시작본을 제공하므로 개인 결과는 선택 입력입니다.
