01 시작하기

창원1공장 유압 설비 7대의 대장·구성요소·SCADA 태그·예비품 자료를 하나의 설비 지식 모델(종류·속성·관계)로 정리합니다. 손으로 다 맞춰 볼 수 없는 양이므로 AI와 코드로 처리하고, 원자료와 자동으로 대조해 확인합니다.

자료/의 CSV 8개와 현장_메모.md, 입력/관계그림.json(앞 단계에서 그린 관계)에서 출발합니다. 이번 모델(스키마·인스턴스)은 아직 없습니다. 공급·입고 자료는 이번 질문 밖이며 모델에 넣지 않아도 됩니다.

결과/   이번에 만들 결과
AGENTS.md   AI 작업 규칙

02 요구 정하기

  1. 설비별로 어떤 구성 요소에 어떤 센서·계산값·설정값이 붙어 있는가?
  2. 각 센서가 재는 물리량과 단위·정상값·한계(위로 넘는지, 아래로 떨어지는지)는 무엇인가? 설비마다 태그 이름이 달라도 같은 물리량을 재는 센서를 함께 찾을 수 있는가?
  3. 교체 부품별로 그 부품을 쓰는 설비와 구성 요소는 무엇인가? 다른 표기로 적힌 품번이나 원자료에 없는 품번으로 물으면 결과가 어떻게 구별되는가?

자료에서 답의 근거를 찾고, AI에 전달할 목표·제약·내가 정한 결정을 정리하세요. 확인할 사례의 종류: 같은 태그 이름이 여러 설비에 있는 경우 / 이름이 다른데 같은 것을 재는 태그 / 같은 장치를 다르게 부른 이름 / 같은 대상이 두 번 나온 행 / 비어 있는 칸(단위·교체부품·정상값) / 단위 표기가 다른 값 / 계기 없는 계산값과 설정값 / 여러 설비가 함께 쓰는 부품과 한 설비만 쓰는 부품 / 품번 대신 품명·다른 표기로 적힌 칸 / 원자료에 없는 품번.

03 AI와 만들기

종류와 개별 대상을 나누고 식별자·속성의 자료형·필수 여부·관계 방향·연결 수를 정의한 뒤, 그 정의로 원자료 전체의 인스턴스를 만듭니다. 원자료를 읽어 대상을 만드는 코드는 `결과/`에 두어 다시 실행할 수 있게 합니다. 자료를 정리하며 내린 처리는 `결과/자료_검토.md`에 자료·행 단위로 남깁니다.

먼저 파일을 바꾸지 말고 자료를 읽게 하고, 계획을 받아 검토한 뒤 확인할 수 있는 단위로 나눠 맡기세요. 완료 보고에는 실행 출력 원문을 붙여 달라고 요청합니다. 파일 이름은 백틱(`)으로 감싸 입력하세요.

요청을 정리할 때 볼 항목

만들 결과 / 참고할 자료 / 내가 정한 결정 / 바꾸지 않을 범위 / 성공을 확인할 사례

04 결과 확인하기

python check.py
  • 질문마다 원자료에서 먼저 찾은 기대 답과 실제 결과를 나란히 적습니다.
  • 자료를 읽는 방식에 따라 답이 갈리는 지점은 내가 정한 결정과 근거 행을 함께 남깁니다.
  • 값이 없음·미확인·0을 구별합니다.

원자료와 실제 결과를 대조하세요. AI의 완료 메시지는 실행 결과를 대신하지 않습니다.
