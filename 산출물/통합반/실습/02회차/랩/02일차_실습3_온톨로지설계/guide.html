현장 자료를 질문에 답하는 모델로 만들기

현장 목록과 관계 그림을 대조해 설비별 센서와 공유 부품을 구별하는 모델을 만듭니다.

01 시작하기

자료/의 CSV·현장 메모와 입력/관계그림.json에서 출발합니다. 이번 스키마·인스턴스는 아직 작성되지 않았습니다.

VS Code에서 START.md를 열고 이번 요구를 확인하세요.

입력/   이전 단계 자료
자료/   현장 원자료(설계 실습)
결과/   이번에 만들 결과
AGENTS.md   작업 규칙

02 요구 정하기

  1. 설비별 구성 요소에는 어떤 센서가 연결되어 있는가?
  2. 센서의 물리량·단위·정상값·한계는 무엇인가?
  3. 같은 교체 부품을 사용하는 설비는 무엇인가?

자료에서 답의 근거를 찾고 AI에 전달할 목표와 제약을 정리하세요.

03 AI와 만들기

종류와 개별 대상을 나누고, 식별자·속성의 자료형·필수 여부·관계 방향·연결 수를 정의하세요. 그 정의로 원자료의 인스턴스를 만드세요. 같은 센서 이름이 다른 설비에 쓰인 경우, 별칭, 중복 행, 빠진 값을 원자료에서 구분하고 어떻게 처리했는지 결과/자료_검토.md에 적으세요.

한 기능의 결과를 확인한 뒤 다음 작업을 요청하세요. 수정 요청에는 입력·기대 결과·실제 결과를 함께 전달하세요.

요청을 정리할 때 볼 항목

만들 결과 / 참고할 자료 / 바꾸지 않을 범위 / 성공을 확인할 사례

04 결과 확인하기

python check.py
  • 설비가 다른 TS1은 구별되고 HYD-01의 중복 행은 하나로 처리됩니다.
  • CE가 물리 센서로 잘못 설명되지 않고, 한계 없음과 0이 구별됩니다.
  • 공용 부품은 품번으로 연결되며 사용 설비를 따라갈 수 있습니다.

원자료와 실제 결과를 대조하세요. AI의 완료 메시지는 실행 결과를 대신하지 않습니다.

05 저장하기

결과/schema.json, 결과/graph.json, 결과/요구사항.md, 결과/자료_검토.md

저장한 파일을 다시 열어 내용을 확인하고, 보관할 결과를 USB 또는 개인 클라우드에 복사하세요.

다음 실습은 시작 도구에서 새로 선택합니다. 개인 결과를 가져오지 않아도 시작할 수 있습니다.
