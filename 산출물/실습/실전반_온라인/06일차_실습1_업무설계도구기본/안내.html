실전반 6회차 실습 1 — 업무설계도구기본

[진행 — 낭독하지 않음] 강사 단독 진행용 대본이다. 아래 조작은 수업에서 수행할 절차이며 이번 제작에서 실행·접속·캡처하지 않았다. 예상 결과를 실제 결과처럼 읽지 않는다. 오류가 나면 실제 사유와 수정·재확인을 남긴다.

다운로드와 편집기 준비

업무설계도구기본 ZIP을 내려받아 압축을 풀고 VS Code에서 코드 폴더를 열겠습니다. output은 직접 만든 파일을 저장할 자리입니다. 교육 환경의 브라우저에서 demo.bpmn.io를 열고 새 다이어그램을 시작하겠습니다. 먼저 작은 그림을 직접 만들고 저장하는 데 집중하겠습니다.

요소 배치와 수정

팔레트에서 시작 이벤트를 놓고, 작업과 끝 이벤트를 추가하겠습니다. 시작에서 작업으로, 작업에서 끝으로 시퀀스 흐름을 연결합니다. 작업 이름을 ‘요청 확인’으로 바꾸고 위치를 옮겨 선이 따라오는지 보겠습니다. 선택한 작업의 문맥 메뉴에서 종류를 사용자 작업으로 바꾸고 사람 표식을 확인합니다.

선택한 요소의 이름과 종류, 들어오고 나가는 선을 확인하겠습니다. 편집기가 속성 패널을 제공하면 ID와 종류를 함께 읽습니다. 기본 데모에서 보이지 않는 속성은 있는 것처럼 설명하지 않고 저장한 XML의 해당 요소에서 확인하겠습니다. 실행 부품과 담당자는 뒤의 HYD 연결에서 지정합니다.

저장하고 다시 열기

다운로드 기능으로 BPMN XML을 저장하고 output/basics.bpmn으로 옮기겠습니다. VS Code에서 파일을 열어 startEvent, userTask, endEvent와 sequenceFlow의 sourceRef·targetRef가 그림의 요소 ID를 가리키는지 확인합니다. 식별자는 표시 이름과 다르므로 이름을 바꾸었다고 ID도 같아졌다고 보지 않겠습니다.

편집기의 Open file로 저장한 파일을 다시 열겠습니다. 요소 수와 이름, 연결 방향이 같은지 보겠습니다. 잘못된 연결은 편집기에서 고치고 저장한 파일을 다시 열어 확인합니다. 이제 이 기본 조작으로 승인과 반려가 나뉘는 업무를 그리겠습니다.
