# 공통 교재 화면 원문 발췌

실습에서 다시 확인할 교재 범위다. 문장을 고치지 않고 해당 장의 화면 내용을 가져왔다. 코드 실행 결과가 아니다. 그림 자체는 공통 PPTX의 같은 장을 참조한다. 실습의 10월14일 기록과 교재 예시 사건의 숫자를 섞지 않는다.

## 교재 37장
- 유형: 코드
- 메시지: PLC의 확인 응답은 명령 처리 결과를 알리며, 설비가 회복되었는지는 계측값을 다시 읽어 확인한다.
- 코드: # 명령: 11:14:57 / cmdId       CMD-1010-0001-b94a / asset       HYD-01 / incident    INC-1010-01-d55a / actions     FAN_SET fan_pct 100 / approvedBy  user:kim-op / expiresAt   11:16:57 /  / # PLC 확인 응답: 11:14:58 / cmdId       CMD-1010-0001-b94a / result      DONE / interlock   PASS /  / # 재관측 결과 / TS1         61.4 ℃ → 51.5 ℃ / alert       CLEAR
- 요소:
  1. 승인된 명령 | 11:14:56에 승인한 팬 최대 운전이다. 팬 속도를 60 %에서 100 %로 올린다.
  2. cmdId와 만료 시각 | cmdId는 같은 명령을 식별한다. PLC가 중복을 검사하며 expiresAt 뒤에는 실행을 거절한다.
  3. **확인 응답(ACK)** | Acknowledgement: 처리 결과의 확인이다. DONE은 실행 완료, PASS는 인터록 정상이다.
  4. 재관측 | 실행 응답은 회복 판정과 다르다. 유온의 회복 기준과 경보 CLEAR를 함께 확인한다.

## 교재 38장
- 유형: 코드
- 메시지: 데이터 리니지(Data Lineage)는 판단 결과에서 원천 계측값까지 되짚을 수 있게 남긴 내력이다.
- 코드: # 원천 데이터: 유온 TS1 (표 tag_1s) / 11:13:06   55.41 / 11:13:07   55.56 / 11:13:08   55.71 /  / # 가공 데이터: 유온의 기울기 (표 feat_1s) / 11:13:08   mean 55.71 · slope 양수(오르는 중) /  / # 이상 이벤트 / ALT-hyd01-0014-e0a1   COOLER_DEGRADATION /  / # 판단 결과 / DEC-1010-002-408b    원인 진단 · 조치 추천
- 요소:
  1. 원천 데이터 | 센서와 PLC가 만들고 브로커가 전달한 계측값이다.
  2. 가공 데이터 | 감지 서비스가 원천 데이터로 계산한 값이다. 기울기가 0보다 크면 유온이 오르는 중이다.
  3. **이상 이벤트** | 조건이 성립했을 때 감지 서비스가 남긴 경보이다.
  4. 판단 결과와 추적성 | 에이전트의 진단·추천과 승인 기록이다. 추적성(Traceability)은 결과에서 근거를 되짚는 성질이다.

## 교재 39장
- 유형: 표
- 메시지: 경보·사건·판단·명령·작업지시를 식별자로 연결하면, 실행 결과에서 판단 근거까지 거슬러 확인할 수 있다.
- 머리: 기록 | 식별자 | 남기는 것
- 요소:
  1. 경보(Alert) | ALT-hyd01-0014-e0a1 | 발생 조건과 / 당시의 값
  2. 사건(Incident) | INC-1010-01-d55a | 경보 처리의 / 진행 상태
  3. **판단(Decision)** | DEC-1010-002-408b | 원인 진단과 / 조치 추천
  4. 명령(Command) | CMD-1010-0001-b94a | 승인된 / 팬 속도 변경
  5. 작업지시(Work Order) | WO-1010-C058 | 쿨러 핀 세척 / 판단 기록 참조

## 교재 45장
- 유형: 표
- 메시지: 쿨러 사건의 처리 과정을 관찰하고, 작업지시가 참조하는 기록을 거슬러 조치의 근거를 확인한다.
- 머리: 입력 | 할 일 | 산출물·성공 기준
- 요소:
  1. 교재 예시의 처리 기록 | 경보: TS1 55.71 ℃ · CE 46.2 % / 진단·추천 → 승인 → 팬 속도 100 % 명령 / ACK 뒤 유온·CLEAR 재관측과 핀 세척 작업지시 확인 | 명령 처리와 완화, / 남은 정비 작업을 구별
  2. **참조 칸이 있는 기록 묶음** | 작업지시의 판단 참조 → 판단의 사건 참조 → 사건의 경보 참조 / 경보 조건·관측값과 원인 판별 근거까지 확인 | 기록별 참조를 표시한 / 근거 연결표
  3. 완성 연결표와 완료 기록 | 각 연결을 같은 참조로 확인 / 판단에 쓰인 증거와 경보 당시의 값을 구별 | 연결마다 참조가 맞고 / 조치의 까닭을 설명
