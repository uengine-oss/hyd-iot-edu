# 기록 추적기 시작 자료

목표는 작업지시가 어느 판단을 가리키는지 근거를 따라 확인하는 것입니다.
먼저 recorded/case_a.json을 열고 어떤 기록 묶음과 식별자가 있는지 파악합니다.
처음부터 구현을 요청하지 말고 판단_메모.md에 관찰한 항목과 궁금한 점을 적습니다.
수정할 곳은 trace_records.py의 check_link 함수 한 개입니다. 나머지 입출력과 검사 틀은 제공됩니다.
어떤 두 항목을 비교할지, 자료가 부족할 때 어떤 결론까지 말할 수 있을지 스스로 기준을 정합니다.
AI에는 모르는 부분을 하나씩 질문하고, 답을 자료에서 확인한 뒤 함수 하나만 구현합니다.
기준을 정한 뒤 테스트를 읽고 놓친 경우가 있는지 대조합니다. 테스트부터 정답 설명처럼 읽지 않습니다.
함수를 작성하기 전에 실행하면 NotImplementedError가 발생하도록 비워 둔 시작본입니다. 실제 장애가 아닙니다.
구현 후 python trace_records.py, python -m unittest -v로 확인하도록 구성했습니다. 이번 제작에서는 새 실행을 하지 않았습니다.
입력 자료는 수정하지 않습니다. 결과는 result에 저장됩니다.
