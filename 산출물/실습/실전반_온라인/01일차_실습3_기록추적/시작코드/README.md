# 작업지시의 판단 근거를 추적하는 도구

정비 담당자는 작업지시가 어느 판단에서 나왔는지, 그 근거를 어디까지 확인할 수 있는지 알고 싶다. 이 프로젝트의 자료와 기능을 먼저 조사하고 요구와 계획을 정한 뒤 구현한다.

제공 입력은 recorded/에 있다. 원문 발췌와 교육용 가림 자료를 구별하며 원본을 수정하지 않는다. 참조 비교 함수는 미구현이고 입출력·기존 검사는 제공된다. 비교 규칙을 정해 구현하고, 실제 근거 위치와 판정 한계를 연결한 result/evidence_report.md 생성 기능을 추가한다. 제공 완성본은 작업 공간 밖의 참고다.

확인할 일: 직접 참조의 존재·일치·불일치, 누락을 주변 정보로 추정하지 않음, 보고서의 출처와 실제 값 일치, 입력별 결과 분리, 정비 상태와 연결 판정 구별. 기존 네 검사는 보고서의 모든 내용을 검사하지 않으므로 원문과 별도 대조한다. 실행 결과는 수업에서 실제로 확인한 뒤 기록한다. 강사 가이드를 읽는 것이 선행 조건은 아니다.
