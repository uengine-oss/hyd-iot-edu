# 직접 작성한 앞 결과를 가져오기

앞 회차의 schema.json·graph.json, 조건표 CSV·판단기록, 이번 회차 판단기능의 rules.csv·id-map.csv·output/result.json을 input/에 원본 이름과 출처가 드러나게 복사한다. 이름이 겹치면 하위 폴더로 구별한다. 원본 위치·파일명·SHA-256·검토 상태를 review.md에 기록한다. 빈 작성 틀이나 제공 예시는 직접 작성 결과를 대신하지 않는다.

추출 실습은 이 자료로 기존 ID와 조건의 누락을 대조한다. 그래프 반영 실습은 여기에 추출 실습의 candidates.json·reviewed.json·review.md와 그때 사용한 source/ 원문·문서 목록을 같은 판본으로 가져온다. 패키지 원문과 해시가 다르면 추출에 사용한 원문 판본을 보존하고 근거 구간을 다시 확인한다.

조건표의 판단 결과는 프로그램 출력이며 자동으로 그래프 지식이 되지 않는다. 검토한 규칙만 매핑하고, 결과의 입력·판정은 검증 근거로 연결한다. 필요한 Skill·Step·Rule 관계가 앞 스키마에 없으면 원문과 공통 교재의 정의에 따라 확장안을 기록하고 검토 후 반영한다. 근거 없는 단계나 연결은 만들지 않는다. 인증 정보는 복사하지 않는다.
