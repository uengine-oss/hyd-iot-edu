실전반 6회차 실습 2 — 승인업무작도

[진행 — 낭독하지 않음] 강사 단독 진행용 대본이다. 아래 조작은 수업에서 수행할 절차이며 이번 제작에서 실행·접속·캡처하지 않았다. 예상 결과를 실제 결과처럼 읽지 않는다. 오류가 나면 실제 사유와 수정·재확인을 남긴다.

자료 다운로드와 앞 작업 이어받기

앞 요청 확인 흐름에 승인과 반려를 나누겠습니다. 각 결정이 어떤 업무 결과로 이어지는지 그려 보겠습니다. 실습 자료를 받아 압축을 풀고 VS Code에서 작업 공간을 열겠습니다.

[준비 · 비낭독] 승인업무작도 ZIP을 내려받아 압축을 풀고 VS Code에서 코드 폴더를 열겠습니다. 앞 실습의 basics.bpmn을 input에 복사하고 편집기에서 엽니다. 원본은 보존하고 승인 업무를 별도 파일로 만들겠습니다.

승인 업무 직접 그리기

시작 이름을 ‘정비 요청’으로 바꾸고 ‘요청 확인’ 사용자 작업 뒤에 배타 게이트웨이를 놓겠습니다. 게이트웨이 이름은 ‘승인 여부’, 나가는 두 선은 ‘승인’과 ‘반려’로 적고 각각 별도의 끝 이벤트로 연결합니다. 사람은 요청 확인 작업에서 결정을 내리고 게이트웨이는 그 결과에 따라 경로를 나눕니다.

시작에서 요청 확인을 거쳐 승인 종료로 가는 선을 따라가겠습니다. 다시 게이트웨이로 돌아와 반려 종료까지 읽겠습니다. 양쪽을 동시에 여는 병렬 게이트웨이와 혼동하지 않았는지 가위표를 확인합니다. 이름만 붙인 선이 실행 조건까지 갖춘 것은 아니며, 이 파일은 기본 작도를 익히는 결과입니다.

저장과 연결 검토

output/approval.bpmn으로 저장하고 다시 불러오겠습니다. 끊긴 선, 작업을 건너뛰는 선, 끝에 닿지 않는 갈래가 있으면 고칩니다. review.md에 각 경로의 시작·결정·끝을 적고 그림과 대조하겠습니다. 다음에는 이 승인 구조를 설비 이상 대응의 여러 역할에 배치합니다.
