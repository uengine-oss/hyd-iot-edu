실전반 8회차 — 제안에이전트

[제작 · 비낭독] 강사 원맨쇼. 실제 코드·테스트·AI·HYD/DB·브라우저·캡처는 미실행이다. 아래는 촬영 시 수행할 절차다. 실제 결과만 기록하고 목표 시간에 맞춰 늘리지 않는다.

기준 지식과 요청 이어 쓰기

앞에서 만든 명세와 지식 구조를 이번 작업 공간의 input에 연결하겠습니다. 이제 정비 시간 후보를 비교하고, 담당자가 결정해야 할 안건을 정리하는 에이전트를 구성합니다.

목표·스킬·입출력 계약 작성

목표에는 근거 있는 후보와 추가 확인을 제시한다고 적겠습니다. 스킬에는 기준 지식 읽기, 생산·자원 자료 대조, 조건별 판정, 안건과 보고서 작성 순서를 둡니다. 주간 생산을 옮기자는 제안은 실제 생산 해제의 근거가 아니며, 과거 세척 이력도 이번 점검의 완료 기록이 아닙니다.

[요청] 앞 명세와 지식 조회 결과를 기준으로 agent/goal.md와 agent/SKILL.md, 필요한 연결 구성을 작성해 주세요. 실제로 사용할 수 있는 읽기 도구와 입력·출력 계약부터 확인하세요. 후보별 시간 길이·기한·생산·자원을 각각 검사하고 근거를 남기세요. 적합 후보가 없으면 추천을 비우고 확인 안건을 내세요. 최초 D1~D5와 후속 D6를 섞지 마세요.

포털에 등록된 읽기 서버와 허용 도구를 확인하고 실제 이름과 입력을 연결하겠습니다. 로컬 파일이 포털 서버에서도 자동으로 보이는 것은 아니므로 준비된 읽기 경로를 확인합니다. 승인 카드가 요구하는 후보 식별자와 이유를 맞추고, 안건과 미확인은 보고서에서 잃지 않게 연결하겠습니다. 임의 점수로 후보를 그럴듯하게 순위 매기지 않고 명세의 적합 조건과 종료 시각 순서를 사용합니다.

최초 자료의 판단과 근거 대조

먼저 최초 요청을 넣겠습니다. 세 시간 후보가 각각 어떤 조건에서 제외되거나 보류되는지 원문과 대조합니다. 부품 실물에서 예약을 뺀 수량, 자정이 넘어가는 작업의 길이, 완료 기한을 결과에서 다시 계산해 보겠습니다. 도구 호출 성공만으로 판단까지 맞다고 보지는 않습니다.

[조작] D1~D5로 실제 제안·호출 기록·후보별 조건을 저장한다. 예상과 다르면 해당 입력·규칙·결과를 짚어 수정하고 같은 요청으로 확인한다. 결과를 미리 채우지 않는다. 실제 읽기 연결이 없으면 연결 미완료로 남긴다.

후속 확인을 반영하고 차이 검증

이번에는 같은 요청에 후속 확인 자료를 추가하겠습니다. 작동유와 야간 인력의 확인이 어떤 후보에 적용되는지 봅니다. 생산 계획이나 정비 기한은 바뀌지 않았으므로 그 이유로 제외됐던 후보까지 살아나면 잘못된 처리입니다.

새 보고서와 이전 보고서를 나란히 보겠습니다. 바뀐 판단에는 새 근거가 붙고, 유지된 판단은 기존 근거를 보존해야 합니다. 조건을 충족한 추천도 사람의 계획 검토를 거쳐야 하며 일정 등록이나 설비 정지를 실행한 것은 아닙니다.

목표·스킬·에이전트 ID·도구 계약과 두 판본의 결과를 저장하겠습니다. 다시 열어 원문에서 결론까지 이어지는지 확인한 뒤 이 출력 계약을 업무 흐름에 넘깁니다.
