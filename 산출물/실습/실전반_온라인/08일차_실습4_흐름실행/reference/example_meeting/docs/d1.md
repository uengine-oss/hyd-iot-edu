# D1 회의 운영 규칙 (예시본 · 가상 회사)

> 수업용 가상 문서다. 실제 회사 규정이 아니다. 내 구글 드라이브 `capstone-<내ID>/` 폴더에 올려 쓴다.

1. **필수 참석** — 필수 참석자 전원이 가능한 시간에만 회의를 확정한다.
2. **자료 공유** — 회의 자료는 회의 시작 48시간 전까지 참석자에게 공유한다.
3. **근무시간** — 회의는 근무시간 09:00~18:00 안에서만 잡는다.
4. **회의실** — 고객 회의는 6인 이상 회의실에서 한다.
5. **점심** — 12:00~13:00 에 걸치는 회의는 잡지 않는다.
6. **요청 마감** — 고객이 요청한 마감일을 넘기는 시간은 후보로 둘 수 있지만 감점한다.

이 문서로 답할 질문
- 필수 참석자 한 명이 안 되는 시간은 후보가 될 수 있는가?
- 내일 오전 회의를 잡으면 자료 공유 규칙을 지키는가?
- 4인실에서 고객 회의를 해도 되는가?
