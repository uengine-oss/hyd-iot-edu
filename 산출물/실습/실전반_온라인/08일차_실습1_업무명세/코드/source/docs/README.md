# 자료 범위와 출처

HYD-02 정기 점검의 생산·정비 조율을 위한 교육용 가상 입력이다. 설비·업무 연결은 저장소 문서/시스템/1_목적과_방향.md §3의 정기 점검 시나리오와 it/supabase/seed.sql의 HYD-02, MO-0930-0415, P-RTN-FLT를 참고했다. 날짜·연속 3시간·기한·예약 1개·인력과 작동유 상태는 이번 수업을 위한 별도 설계값이다. seed의 현재값이나 실제 조회 결과로 말하지 않는다.

D1(d1.md): 판단 기준. D2(d2.md): 준비 절차. D3(d3.md): 이전 회의의 결정과 미결. D4(production_windows.csv): 생산 담당이 확인한 후보 시간. D5(resources.csv): 창고·보전의 자원 상태. D6(followup.md): 같은 요청에 나중에 추가할 확인 근거. 최초 입력은 D1~D5이며 D6는 후속 비교 때만 추가한다. 모두 Asia/Seoul이다.

기준과 판본은 지식 구조에서 연결하고, 바뀌는 수량·일정·자원 상태는 요청의 입력 자료로 읽는다. 원문 위치를 잃지 않도록 파일·절 또는 행 식별자를 남긴다. 실제 제조 데이터·안전 기준·실행 성공 기록이 아니다.
