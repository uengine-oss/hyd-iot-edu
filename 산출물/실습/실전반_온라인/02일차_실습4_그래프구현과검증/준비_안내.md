# 그래프 구현 준비

실습3 결과/schema.json, graph.json을 이 폴더의 입력/에 복사한다. 강사가 제공한 별도 빈 랩 DB를 사용한다. 실습1 예제 DB나 HYD 기준 DB에 적재하지 않는다. 원본과 오류 검토용 사본을 구별하고 기존 DB 전체 삭제 명령을 사용하지 않는다.

Copilot에 두 입력을 지정해 적재.cypher와 조회.cypher를 만들도록 요청한다. 레이블별 id 유일 제약, id 기준 MERGE, 값 갱신, 관계 끝점 MATCH를 확인한다. 생성문을 검토한 후 랩 DB에만 실행하는 수업 흐름이다. 이 제작에서는 실행하지 않았다.

존재·형·단위·끝점·카디널리티와 원자료의 의미를 함께 확인한다. 제약 저장 성공만으로 의미가 맞다고 하지 않는다. 오류_검토용.json에서 관계의 물리량을 바꿔 발견·수정하는 활동은 파일 검토로 하고 잘못된 사본은 DB에 넣지 않는다.
