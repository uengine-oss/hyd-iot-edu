# 입력과 적용 범위

작업기준.md는 실전반2에서 쓴 팬 최대 운전 중심 입력이다. 다른 후보는 targets.csv의 SOP ID와 HM-8 원문의 적용 범위를 대조해 행을 확장한다. 기존 모델 ID는 id-map.csv에 적는다. reference_skill_id 빈칸은 임의로 채우지 않는다.

팬 감점은 SOP-COOL-11·12에만, 원격 모드 제외는 SOP-COOL-11~13에 적용한다. 압력·트립 규칙은 첨부 구조화 발췌를 근거로 쓴다. 작업지시와 제어의 kind를 구별한다. 실행 코드는 목록이므로 FAN_SET 포함 여부와 RESET 외 코드 존재를 목록으로 판정한다.

cases.csv는 경계·누락·복수 규칙 비교용 입력이며 실제 사건 기록이 아니다. 모든 후보의 예측값을 같게 놓아 규칙 적용 대상만 비교한다. HM-8.5의 팬 24시간 수행 제한과 감점 조건은 별개이며 후보 유지가 실행 허가는 아니다.
