# 두 작업 공간을 구분하기

이 ZIP은 가이드·확인표·참고 교재를 담은 실습 문서 묶음이다. HYD 서비스를 기동할 전체 저장소나 설치 프로그램을 포함하지 않는다.

## 강사의 사전 준비

- 수업에 사용할 HYD 전체 저장소 사본과 판본을 준비한다. 실습마다 새로 설계하거나 초기화하지 않는다.
- 저장소 루트에 `compose.yaml`, `ot`, `dmz`, `it`가 있는지 확인한다.
- 그 사본의 `문서/시스템/4_켜고_돌리는_법.md`와 실제 사용할 프로필·외부 작업자 조건을 확인한다.
- 배포 위치는 수업에서 정한 저장소·배포 자료를 사용한다. 이 문서는 확인하지 않은 다운로드 주소나 실행 구성을 만들어 제공하지 않는다.
- 설치·인증·다운로드·복구는 별도 준비 시간이다. 실제 저장소가 없으면 이 ZIP만으로 서비스 기동을 시연할 수 없다.

## 대본의 시작 흐름

1. 이번 실습 ZIP을 내려받아 압축을 풀고 VS Code로 연다.
2. `환경_확인표.md`에서 기록할 항목을 읽는다. 결론은 비어 있다.
3. 새 VS Code 창에서 사전에 준비한 수업용 HYD 저장소 루트를 연다.
4. 판본과 구성을 읽으며 무엇이 필요한지 스스로 정리한다. AI에는 이해되지 않은 항목 하나를 질문한다.
5. 시스템 명령은 전체 저장소 창에서, 근거·판정 기록은 실습 문서 창에서 다룬다.

이미 실행 중인 환경은 재기동 장면을 만들려고 내리지 않는다. 실제 실행은 이번 문서 제작에서 수행하지 않았다.
