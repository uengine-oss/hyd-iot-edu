# 제공 지표 자료의 연결

지표_정의.md는 원본 설명을 보존했다. 그 문서의 지표/는 현재 metrics/, 입력/판정_요청.json은 metrics/판정_요청.json에 해당한다. 결과/판정_결과.json은 제공하지 않는다. 직접 만든 함수에 후보별 예측값을 넣어 계산한 output/result.json을 사용한다. 원본 요청의 RUN은 이번 사례의 RUNNING과 같은 정상 상태 표기로 명시 변환하며 TRIP과 구별한다.

경계 테스트 cases.csv와 손실 비교용 판정_요청.json을 섞지 않는다. 손실 비교에서는 요청 C01의 후보별 예측값으로 별도 평가한다. 네 손실의 합과 감점 금액은 교육용 비교 기준이며 HYD 일곱 성분 점수와 다르다. 현재 값 조회나 현장 예측 검증 결과로 보지 않는다.
