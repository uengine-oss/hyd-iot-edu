# 관계 조회 준비

강사가 제공하는 별도 랩 Neo4j DB와 접속 정보를 사용한다. 기존 HYD DB가 아니다. 접속 주소와 DB명은 배포 담당자가 수업 전에 제공한다. 인증값은 이 파일에 쓰지 않는다.

예제_그래프.json은 it/neo4j/v2/instances.cypher의 HYD-01·구성 요소·계측 채널을 뽑은 교육용 부분집합이다. 시계열 실측값이 아니다. 예제_적재.cypher를 빈 랩 DB에 한 문장씩 적용한 뒤 조회한다. 이미 준비된 DB에는 식별자를 확인하고 기존 데이터와 섞지 않는다. 실습3~4의 직접 설계한 그래프는 다른 DB에 둔다.

예제에는 1개 설비, 6개 구성 요소, 5개 센서, 5개 상태 변수와 16개 관계가 있다. 쿨러 센서는 TS1·CE, 주 펌프 센서는 PS1·FS1, 팬 센서는 VS1이다. 나머지 구성 요소는 이 부분집합에서 센서가 없다. 이것은 입력자료 정의이며 실행 검증 결과가 아니다.
