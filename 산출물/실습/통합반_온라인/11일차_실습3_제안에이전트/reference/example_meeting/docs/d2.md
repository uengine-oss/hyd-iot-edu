# D2 분기 리뷰 준비 절차 (SOP 예시본 · 가상 회사)

> 수업용 가상 문서다.

1. **회의록 찾기** — 지난 분기 회의록을 찾는다.
2. **요약** — 계약 현황과 미결 이슈를 한 쪽으로 요약한다.
3. **안건 초안** — 미결 이슈로 안건 초안을 만든다.
4. **시간 후보** — 운영 규칙(D1)을 지키는 시간 후보 3개를 순위와 함께 낸다.
5. **초대** — 주관자 승인 뒤 초대를 보내고 자료 링크를 붙인다. 승인 전에는 초대 · 메일을 보내지 않는다.

이 문서로 답할 질문
- 시간 후보는 몇 개를 내는가?
- 초대는 언제 보내는가?
- 안건 초안은 무엇으로 만드는가?
