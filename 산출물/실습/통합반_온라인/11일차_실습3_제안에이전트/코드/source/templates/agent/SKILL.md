## 실제 연결 계약
포털 승인 카드의 proposal.options 항목과 slot·reason·score, recommended, losers, docs 등 실제 지원 계약을 확인해 매핑한다. slot은 고유하게, score가 필수면 명세의 종료 시각 우선 순서를 표시하는 순위값으로 정의하고 성능 점수처럼 설명하지 않는다. 근거 없는 후보를 채우지 않는다. HTTP(S) 링크만 받는 docs에는 로컬 경로를 억지로 넣지 않고 보고서의 원문 참조로 보존한다. 지원 부품과 반환 형식의 대조 결과를 별도 기록한다.

## 사람 검토와 범위
일정 등록·메일·정비 오더·설비 조작을 호출하지 않는다. 지침과 실제 도구 권한을 모두 확인한다.
