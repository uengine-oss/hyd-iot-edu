# 설비 이상의 원인을 추론하는 에이전트 — 완성본

통합반 5회차 실습 2에서 만드는 에이전트의 완성본이다. 경보가 뜬 설비 사례를 받아, 온톨로지에서 원인 후보와 증거 기준을 찾고 센서 집계값과 비교해 원인을 판정하고 점검 계획을 낸다.

## 실행

Python 3이 설치되어 있어야 한다. 이 폴더를 VS Code로 열고(「파일 → 폴더 열기」) 아래 둘 가운데 편한 쪽으로 실행한다.

| 방법 | 하는 일 |
|---|---|
| 실행 버튼 | `F5`를 누른다. 왼쪽 「실행 및 디버그」에서 「사례 열한 건」과 「S01 한 건」을 고를 수 있다. VS Code의 Python 확장이 필요하다 |
| 명령 | 「터미널 → 새 터미널」을 열고 `python agent.py`를 실행한다. 한 건만 보려면 `python agent.py S01` |

Python 확장이 없으면 `Ctrl+Shift+B`로도 실행된다.

이 완성본은 LLM 서버를 부르지 않는다. 서버가 실제로 보낸 답을 `recorded/replies.json`에 저장해 두었고, 실행하면 그 답을 순서대로 다시 받아 처리한다(화면 첫 줄에 `[재생]`이라고 나온다). 도구 실행, 호출 기록, 대조는 실제로 돈다.

저장된 것과 다른 요청에는 답하지 못한다. `agent_config.json`의 규칙이나 도구 목록, `cases/cases.json`을 바꾸면 「저장된 기록에 없는 요청」이라고 나오고 멈춘다.

## 볼 것

| 파일 | 내용 |
|---|---|
| `plan/plan.md` | 사례별 점검 계획. 원인별 판정, 점검 순서, 대조, 호출 기록 |
| `agent.py` | 에이전트. 도구를 알려 주고, 부른 도구를 실행하고, 기록하고, 멈추고, 답을 호출 기록에 대어 본다 |
| `tools.py` | 온톨로지와 사례를 조회하는 도구 넷 |
| `agent_config.json` | 에이전트의 목표, 허용 도구 목록, 판정 규칙, 호출 한도 |
| `ontology/`, `cases/` | 에이전트가 읽는 자료. 폴더마다 `README.md`가 설명한다 |
