# D3 지난 분기 회의록 (예시본 · 가상 회사 · 가상 인물)

> 수업용 가상 문서다. 고객사 "가온상사"와 사람 이름은 모두 지어낸 것이다.

- 일시: 3분기 리뷰 (가상)
- 참석: 김주관 · 박임원 · 이담당 · 최기술 (모두 가상)

## 1. 미결 이슈
1. 납품 지연 재발 방지책 — 다음 분기에 대책 결과를 보고하기로 함
2. 2분기 청구 오류 정정 — 정정 청구서 확인 필요
3. 신규 담당자 인수인계 — 고객 쪽 담당자가 바뀜

## 2. 다음 분기 확인 지표
- 납기 준수율
- 문의 응답 시간

이 문서로 답할 질문
- 이 고객의 미결 이슈는 몇 건인가?
- 다음 분기에 무엇을 확인하기로 했는가?
- 고객 쪽 담당자가 바뀌었는가?
