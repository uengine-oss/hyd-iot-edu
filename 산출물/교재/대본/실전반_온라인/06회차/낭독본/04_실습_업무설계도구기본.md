# 실전반 6회차 실습 1 — 업무설계도구기본


## 다운로드와 편집기 준비

정비 요청이 접수돼 담당자에게 넘어가는 흐름부터 만들겠습니다. 이 파일을 뒤에서 승인과 냉각 대응으로 확장할 겁니다. 실습 자료를 받아 압축을 풀고 VS Code에서 작업 공간을 열겠습니다.


## 요소 배치와 수정

팔레트에서 시작 이벤트를 놓고, 작업과 끝 이벤트를 추가하겠습니다. 시작에서 작업으로, 작업에서 끝으로 시퀀스 흐름을 연결합니다. 작업 이름을 ‘정비 요청의 설비·증상·요청자 확인’으로 바꾸고 위치를 옮겨 선이 따라오는지 보겠습니다. 선택한 작업의 문맥 메뉴에서 종류를 사용자 작업으로 바꾸고 사람 표식을 확인합니다.

선택한 요소의 이름과 종류, 들어오고 나가는 선을 확인하겠습니다. 편집기가 속성 패널을 제공하면 ID와 종류를 함께 읽습니다. 기본 데모에서 보이지 않는 속성은 있는 것처럼 설명하지 않고 저장한 XML의 해당 요소에서 확인하겠습니다. 실행 부품과 담당자는 뒤의 HYD 연결에서 지정합니다.

## 저장하고 다시 열기

다운로드 기능으로 BPMN XML을 저장하고 output/basics.bpmn으로 옮기겠습니다. VS Code에서 파일을 열어 startEvent, userTask, endEvent와 sequenceFlow의 sourceRef·targetRef가 그림의 요소 ID를 가리키는지 확인합니다. 식별자는 표시 이름과 다르므로 이름을 바꾸었다고 ID도 같아졌다고 보지 않겠습니다.

편집기의 Open file로 저장한 파일을 다시 열겠습니다. 요소 수와 이름, 연결 방향이 같은지 보겠습니다. 잘못된 연결은 편집기에서 고치고 저장한 파일을 다시 열어 확인합니다. 이 흐름만으로 정비 요청 처리가 완성된 것은 아닙니다. 다음 실습에서 같은 파일에 승인과 반려를 붙이고 냉각 대응까지 확장하겠습니다. 기본 조작을 별도 완성 과제로 늘려 잡지 않겠습니다.
