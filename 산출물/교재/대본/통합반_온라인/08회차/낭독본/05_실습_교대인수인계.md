# 통합반 8회차 — 교대인수인계


## 다운로드와 세 출처 준비

설비 이벤트·정비 이력·부품 정보를 연결해 다음 교대가 이어 확인할 인수인계 자료를 만들겠습니다. 실습 자료를 받아 압축을 풀고 VS Code에서 작업 공간을 열겠습니다.


앞 검증 결과를 가져오되 이번에는 출처마다 다른 대상 식별자와 기준 시점을 맞추는 데 집중하겠습니다.


## 같은 대상과 시각으로 연결하기

source의 세 자료를 열고 설비 식별자, 작업·요청 번호, 관측 또는 갱신 시각, 조회 시각을 확인하겠습니다. 같은 설비라고 모든 행을 곧바로 붙이지 않고, 어떤 요청과 기간을 인수인계할지 handover-plan.md에 적습니다. 정비 완료 표시는 정비 기록에서 확인하고, 경보 해제나 작업지시 등록만으로 세척 완료라고 적지 않습니다.

코딩 도우미에는 원래 필드 이름과 자료형을 유지해 세 출처를 읽고, 대상별 완료 작업·미완료 요청·주의 사항·근거 위치를 정리하는 코드를 요청하겠습니다. 앞 실습의 미확인 항목도 별도 출처로 붙입니다. 부품 재고가 0인 행과 자료를 읽지 못해 수량을 모르는 경우는 다른 상태로 둡니다. 사건 시각이 없는 자료는 임의 시각을 채우지 않고 그 한계를 적겠습니다.

## 인수인계 초안과 원문 대조하기

준비된 자료를 읽어 초안을 만들고, 각 항목이 어느 파일의 어느 행에서 왔는지 원문과 대조하겠습니다. 출처끼리 상태가 다르면 갱신 시각과 적용 기간을 확인하고 해결되지 않은 차이는 주의 사항으로 남깁니다. 자료에 없는 담당자·기한·완료 결과는 만들어 넣지 않습니다.

잘못 연결된 행이나 빠진 출처가 있으면 연결 조건을 수정하고 다시 생성해 같은 항목을 대조합니다. 하나의 출처를 읽지 못했을 때는 관련 업무가 없다고 쓰지 않고 해당 출처와 범위를 미확인으로 남깁니다. 데이터 패브릭의 관점은 이처럼 여러 출처를 연결하고 추적하는 데 적용합니다.

## 저장하고 다시 읽기

input의 원자료와 판본, 연결 코드, output/handover.md, 대조표를 함께 저장하겠습니다. 작업 공간을 다시 열고 인수인계 항목에서 근거 파일로 돌아갈 수 있는지 확인합니다. 읽은 자료의 범위와 남은 요청을 표시한 뒤 다음 이론에서 제작부터 검증까지의 과정을 정리하겠습니다.
