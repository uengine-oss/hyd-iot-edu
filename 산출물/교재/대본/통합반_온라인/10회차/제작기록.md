2. 9·26·37·44·46·56장: 재고 의미를 정정했다. HYD `available`은 현재고−예약+발주 중 수량이다. 초기에는 3−2+0=1, 6개 발주 후 3−2+6=7, 입고 후 9−2+0=7이다. 보충 필요 표시는 발주 때 꺼질 수 있지만 즉시 사용할 수 있는 재고는 입고 후 늘어난다. ‘가용 재고=실물 사용 가능 수량’과 ‘입고해야만 보충 필요 표시 해제’를 일반화하지 않는다. 입고 즉시 처리는 수업 시뮬레이션이며 실제 납기·도착·검수와 구분했다.
3. 10·13·14장: 공통 메시지 형식은 의미·단위 검증과 별개이며, 식별자의 접두 표기는 HYD 규칙이다. 중복 시작 방지는 같은 사용 공간·정의·경보 식별자 범위이며 서로 다른 요청까지 합치지 않는다. 기준 흐름 되돌리기는 같은 테넌트의 사용자 배포 전체에 영향을 준다. ‘내 흐름 하나만 되돌리기’라는 설명을 수정했다.
4. 15~19장: 알림 가지 종료와 처리 건 전체 완료를 구별한다. 거절 뒤 남은 업무의 담당·후속 판단을 설명한다. 17장 약 1분 재관측은 20배속 시연값이다. 최장 단계와 병목을 동일시하지 않고 반복 지연·유입량·대기 이유·미완료 건을 함께 보도록 했다. 승인 열림~닫힘은 대기+검토 경과이며 대기만 분리하려면 추가 시각이 필요하다. 프로세스 지표도 KPI로 선택할 수 있고 거절률 감소 자체가 목표는 아니다.
5. 20~29장: 재사용은 조건을 재검증하는 출발점이다. 일곱 요소·두 연결 자리·기한 10분은 이번 예제의 공통점이지 모든 업무의 법칙이 아니다. 그림 밖 기한·조건 연결은 HYD 작성 방식이며 BPMN은 타이머 식과 조건식을 정의에 담을 수 있다. 중단형=자동승인, 비중단형=알림만이라는 오해를 제거했다. 오더·메일의 일부 실패와 무조건 전체 재시도에 따른 중복도 설명했다. 도식상 승인과 실행 시 권한 확인을 구분했다.
6. 30~38장: 연속 실습 안내를 첫 이론으로 합쳤고 ‘앞 시간에 다 그렸죠’ 같은 선행학습 시점 오류를 고쳤다. 실제 실습은 0바이트다. 중단·재개는 비낭독 제작 표시로 분리했다.
7. 39~47장: 다섯 자리는 이 사례의 분석 틀이다. 변수 전달만으로 권한이 생기지 않으며 실행 시 현재 조건도 확인한다. 유온 55℃ 미만과 경보 해제를 함께 유지했다. 정비 오더 정상은 실제 현장 정비 완료가 아니다. 승인자의 내적 생각은 추측하지 않는다. 식별자의 연결은 추적 단서이며 기록의 진실성까지 보장하지 않는다.
8. 49~54장: 온톨로지·에이전트·프로세스는 근거 의미·후보 비교·업무 연결의 역할로 설명한다. 도구의 접근 목록과 실제 조회 이력, 분리된 도구와 서로 연관된 업무 사실을 구별한다. 에이전트에 파일 쓰기 도구가 전혀 없다는 과장을 제거하고 업무 실행 권한의 통제로 한정했다. 제품 하나를 빼면 무조건 업무 불가능이라는 설명 대신 그 역할을 무엇이 맡을지 묻는다. 개선은 원인 조사→수정→예외 포함 재검증→새 판본 배포로 연결한다.
9. 55~61장: 용어와 퀴즈를 정정 내용에 맞췄다. 재고 문제는 다른 재고 변화 없음, 승인 문제는 기존 승인 정책 유지라는 전제를 명시했다. 병목 문제는 조사할 첫 근거를 묻는다.
