# 통합반 11회차 — ProcessGPT시연 — 낭독 대본

ProcessGPT시연 ZIP을 내려받아 압축을 풀고 VS Code에서 코드 폴더를 열겠습니다. 앞 실습의 명세·흐름·처리 건 기록을 input에 연결하고 observation.md를 엽니다. 제공된 제품 구조 설명은 관찰할 기준이며 현재 접속 환경에서 기능이 작동했다는 기록이 아닙니다.

관찰표에 지식, 에이전트, 프로세스 정의, 실행 인스턴스, 사람 작업, 결과 제출을 먼저 적겠습니다. HYD에서 이 역할이 어디에 있었는지 앞 기록의 번호를 연결합니다. 이어서 수업에 준비된 제품의 주소와 판본, 계정에서 접근 가능한 범위를 확인합니다. 접속이나 권한이 준비되지 않았다면 실제 시연은 미확인으로 두고 제공 설명을 실제 화면을 본 것처럼 읽지 않겠습니다.

준비된 제품 화면에서 사용할 정의를 열고 작업 담당과 입력·결과 계약을 확인하겠습니다. 실행되는 인스턴스 한 건을 골라 현재 누구 차례인지, 에이전트가 결과를 내면 누가 다음 작업을 여는지, 사람에게 맡긴 작업은 어디에 모이는지 따라갑니다. 직접 새 실행을 하는 경우에는 수업용 읽기·제안 범위와 사람 확인 조건을 먼저 확인합니다.

화면에서 확인한 이름과 상태, 근거 위치를 관찰표에 직접 적습니다. 자연어로 만든 정의나 여러 에이전트 기능이 보이더라도 생성된 설계가 명세와 승인 조건을 지키는지 별도로 봅니다. 소개 문구와 실제 확인한 기능을 같은 칸에 적지 않겠습니다.

HYD와 이름이 다르면 역할과 입출력을 대조해 대응을 수정합니다. 완료 표시가 보여도 한 일과 하지 못한 일은 결과 기록에서 확인합니다. 권한, 감사 추적, 실패 처리 가운데 이번 화면에서 확인하지 못한 것은 미확인으로 남깁니다. 특정 메뉴가 없다는 이유만으로 제품 전체에 그 기능이 없다고 단정하지 않습니다.

관찰표와 비교한 정의·인스턴스 식별자, 자료 출처를 저장하겠습니다. 다시 열어 설명만 읽은 항목과 실제 화면에서 확인한 항목이 구분되는지 봅니다. 이 기록을 마지막 학습 노트에 연결하겠습니다.
