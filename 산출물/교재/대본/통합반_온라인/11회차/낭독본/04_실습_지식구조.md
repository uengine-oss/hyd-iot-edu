# 통합반 11회차 — 지식구조 — 낭독 대본

지식구조 ZIP을 내려받아 압축을 풀고 VS Code에서 이번 코드 폴더를 열고, 앞 실습의 spec.md·request.md와 출처 목록을 input에 복사하겠습니다. 이번 ZIP의 빈 양식으로 앞에서 작성한 명세를 덮어쓰지 않습니다. source/docs를 앞 명세에서 읽은 문서와 대조하고 실제 작성 파일은 output에 둡니다. source/templates는 형식 참고, reference/example_meeting은 완성 예입니다. 둘을 내가 직접 만든 지식으로 복사해 완료 처리하지 않습니다.

먼저 문서로 답할 질문을 적겠습니다. 어떤 미결 이슈를 안건으로 가져갈지, 자료는 언제까지 공유해야 하는지, 후보에 필요한 조건은 무엇인지입니다. 이 질문에 필요한 클래스·속성·관계를 schema.json에 작성하고, 문서의 개별 대상은 graph.json에 적겠습니다. 개념의 종류와 개별 회의·안건을 구별합니다.

강사 작업용 이름 공간을 정해 ns와 식별자 접두어를 함께 맞추겠습니다. demo나 s00의 참조 이름을 수업 기준 데이터에 덮어쓰지 않습니다. 각 인스턴스와 규칙에는 원문 문서와 절을 붙이고, 빠르게 바뀌는 참석 가능 시간은 고정 규칙처럼 지식에 넣지 않습니다. 코딩 도우미에는 앞 명세와 문서를 지정해 필요한 부분만 작성하도록 요청하겠습니다.

questions.cypher에 질문별 읽기 조회를 작성합니다. 제공 load_graph.py는 HYD 저장소 안에서 scripts/ontology_v2.py를 찾아 쓰는 도구이므로 ZIP의 코드 폴더만 열었다고 바로 실행되는 것으로 안내하지 않겠습니다. 수업에서 output에 작성한 schema.json·graph.json·questions.cypher와 source/templates/load_graph.py를 students의 전용 작업 폴더로 복사하고 해당 저장소의 도구·환경을 확인한 뒤 정적 검사, 전용 이름 공간 적재, 조회 순서로 진행합니다. 구체적인 명령은 source/runtime-guide.md의 자리 값을 실제 폴더로 채워 기록합니다.

조회 결과의 건수만 보지 않고 문서에서 먼저 적은 답과 대상·관계·출처를 대조하겠습니다. 0행이면 질의와 식별자, 실제 적재 여부를 확인하고, 잘못 연결된 관계는 근거를 보고 수정합니다. 수정 후 같은 질문을 다시 조회합니다. 연결이 없으면 조회 성공으로 적지 않고 파일 검사와 DB 조회의 완료 범위를 나눕니다.

스키마와 인스턴스, 조회문, 실제 조회 결과와 원문 대조 기록을 저장하겠습니다. 다시 열어 식별자에서 출처 문서까지 이어지는지 확인합니다. 이 결과와 조회할 수 있는 읽기 경로를 다음 에이전트 실습에서 사용하겠습니다.
