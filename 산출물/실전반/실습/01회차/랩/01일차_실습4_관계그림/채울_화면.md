# 나중에 채울 화면

실제 캡처를 만들지 않았습니다. 각 자리는 아래 장면과 판정 근거가 보이도록 채웁니다. 개인 정보·비밀값을 제외합니다.

## 04-01 · 대상과 근거 분리
대상 목록과 매뉴얼 근거 대목
확인 기준: 대상 이름·종류·출처 위치가 구분됩니다. 숫자만으로 원인 이름을 확정하지 않습니다.

## 04-02 · 기본 관계 그리기
이름과 방향이 보이는 핀 오염 기본 관계도
확인 기준: 각 관계를 문장으로 읽고 양 끝 대상 종류와 문서 근거를 설명합니다.

## 04-03 · 핀 오염 증거 연결
핀 오염의 두 증거 조건과 조치·출처
확인 기준: 순간값과 구간 평균을 혼합하지 않으며 완화와 근본 조치를 구분합니다.

## 04-04 · 팬 구동 불량 가지 추가
두 원인 가지와 각 증거·핀 세척/팬 점검의 차이
확인 기준: 공통 고장 유형은 유지하고 서로 다른 증거·조치·출처가 보입니다.

## 04-05 · 방향 검토와 저장
저장한 편집 파일·이미지와 재열기 확인 장면
확인 기준: 관계의 출발·도착·뜻·출처를 검토한 기록이 남고, 다음 회차에 사용할 편집 가능한 결과를 보존합니다.


## 04-START
다운로드 → 압축 해제 → VS Code 폴더 열기 → 입력·수정·결과 위치 확인.

- 응용 확인: 같은 그림에서 팬 진동 조건 충족/자료 미확보에 따라 따라가는 관계와 보류 이유를 짚고, 관계 검토표 및 매뉴얼을 함께 보여 준다. 실제 사진은 미촬영이다.
