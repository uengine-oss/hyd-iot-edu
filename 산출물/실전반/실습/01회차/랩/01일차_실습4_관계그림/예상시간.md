# ARROWS 발화·조작량과 시간 산정 상태 — 2026-10-23

대상: 현재 [전체 대본](../../대본/08_실습_관계그림.md). **아래 합산은 종전 순차 진행의 참고 계산이며 현행 수업 예상 시간이 아니다.** 현재 기준은 대상 안내 후 설명 중 조작하는 시간의 합집합이다. 실제 행동 타임라인이 없어 현행 전체 시간은 미측정이다. 짧은 샘플의 재생 시간을 전체 수업에 외삽하지 않았다.

| 항목 | 계산 | 예상 |
|---|---|---|
| 발화 | 한글 음절 + 숫자×1.6 + 영문×0.6 = 10682.8, 분당275음절 | 38.8분 |
| 안내가 끝난 뒤 조작·화면 확인 | 아래 정상 속도 범위, 발화와 겹치지 않음 | 13.5–25.7분 |
| 종전 순차 합산 참고 | 발화 + 조작·확인(중복 포함 가능) | **52.4–64.6분** |

조작 산정: 노드20개·관계26개·속성41개. 클릭 약280회에 이동 포함1.0–1.7초, 관계 드래그26회에1.2–2.2초, 입력1493문자를 초당4–7문자, 종류 확정 Enter20회에0.25–0.5초. 눈으로 결과를 확인하는87지점에0.5–1초를 별도 반영했다. 배치 조정2–5분, 저장 데이터 재열기·원본 대조2–4분을 더했다. 고정 대기를 실제 조작에 넣으라는 뜻이 아니다. 시스템 대기·음성 합성·렌더링·프레임 지연·학생 작업 대기는 제외했다.

발화 계산에서는 제목·제작 메모·조작 열·출처를 제외했다. 표의 발화 열과 설명 문단만 포함한다. 실제 화면에서 중복 클릭을 생략하면 그 안내도 함께 줄어든다. 아직 확인하지 않은 가져오기 경로의 구체적인 안내와 전체 배치 조정에 따라 범위가 달라질 수 있다. 이 계산은 중첩 시간을 빼지 않은 구판 방식이다. 현행 계획 시간에는 실제로 겹치지 않는 입력·응답·확인 시간만 더해야 한다.

이전 전체 원고는 후반 조작 안내가 비낭독 메모에 있었으므로 그 낭독 길이를 완결된 수업의 종전 시간으로 비교하지 않는다. 이번 값은 누락 안내를 채운 원고의 양을 확인하는 참고치다. 순차 진행을 촬영 지시로 사용하지 않는다. 50분에 맞추려고 지연·설명·노드를 추가하지 않는다. 촬영·전체 음성·실측은 미수행이다.
