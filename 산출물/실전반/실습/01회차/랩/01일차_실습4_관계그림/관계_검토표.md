## 같은 그림의 조건 적용

실제 관측 결과가 아닌 문서상 적용 비교다. 원문 조건을 확인하고 아래 빈칸을 작성한다.

| 조건 | 사용할 증거와 원문 기준 | 그림에서 따라갈 관계 | 지금 판단할 수 있는 것 / 보류할 것 | 추가 확인 자료 |
|---|---|---|---|---|
| 냉각 효율 저하, 팬 진동 2분 평균이 HM-8.4의 팬 구동 불량 조건을 충족 | | | | |
| 냉각 효율 저하, 팬 진동 자료 미확보 | | | | |

편집 가능한 관계 그림과 이 검토표를 다음 회차 스키마 설계의 입력으로 보관한다.
