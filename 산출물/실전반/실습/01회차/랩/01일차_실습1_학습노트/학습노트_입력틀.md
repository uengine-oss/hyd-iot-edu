# 주제 갤러리 입력 자료

두 과정 공통 · 2026-10-22 최신 완성본 대응. 필수 기입 양식이 아니라 따라 만들어 본 뒤 바꾸는 예시다. 짧은 문장은 직접 입력하고 긴 URL·파일 경로만 붙여넣는다. 한 번에 전부 입력하지 않고 원고의 해당 단계에서 사용한다.

## 홈 — N03~N07

이름: 내 학습 노트
소개: 관심 있는 주제를 모으고, 배운 내용을 나만의 방식으로 쌓아 갑니다.
파란 콜아웃 첫 줄(굵게): 하나의 주제에서, 나만의 지식으로
다음 줄: 카드 하나에 주제 하나. 카드 안에는 글과 자료를 자유롭게 담고, 내용이 늘어나면 하위 페이지로 나누세요.
목록 이름: 주제 모음. 갤러리 보기: 주제 카드. 홈에 큰 표지·대형 아이콘을 추가하지 않는다.

## Notion 익히기 — N08~N19

소개: 글을 쓰고, 페이지를 연결하며 나에게 맞는 노트를 만들어 봅니다.
파란 콜아웃 첫 줄: 짧게 적고, 필요한 만큼 연결하기
다음 줄: 한 페이지에서 시작해 내용이 쌓이면 하위 페이지로 이어 갑니다.
제목2: 나의 페이지
회색 왼쪽 영역: 01 · 글 정리하기 / 제목·목록·토글로 / 읽기 편하게 정리합니다.
회색 오른쪽 영역: 02 · 내용 연결하기 / 하위 페이지와 링크로 / 내용을 이어 갑니다.
각 영역 안에 첫 페이지 꾸미기 / 페이지 연결하기 하위 페이지를 넣는다.
마지막 토글: 나에게 맞게 바꾸려면 / 페이지 이름과 배치는 자유롭게 바꾸세요. 내용이 짧으면 한 페이지에 적어도 됩니다.

### 첫 페이지 꾸미기

소개: 한 페이지 안에서도 글의 모양을 바꾸어 읽기 쉽게 정리할 수 있습니다.
소개 아래 목차. 제목2: 오늘 써 본 방법
목록: 제목으로 내용의 구획 나누기 / 같은 성격의 내용은 목록으로 정리하기 / 긴 설명은 토글 안에 접어 두기
토글: 제목과 굵은 글씨는 어떻게 다를까?
설명: 제목은 문서의 구획을 만들고 목차에도 표시됩니다. 굵은 글씨는 문장 안에서 중요한 말을 강조할 때 씁니다.
구분선 뒤 제목2: 다음에 해 볼 것
할 일: 내 관심 주제로 카드 하나 더 만들기 / 내용에 어울리는 하위 페이지 이름 붙이기
마지막 제목2: 이어서 보기. 페이지 연결하기를 멘션으로 연결하고 공식 도움말을 연결한다.

### 페이지 연결하기

소개: 내용이 길어지면 같은 주제 안에서 페이지를 나눠 봅니다.
제목2: 하위 페이지 만들기
번호 목록: 주제 카드를 엽니다. / 빈 줄에서 슬래시를 입력하고 페이지를 고릅니다. / 페이지 이름을 붙이고 내용을 적습니다. / 위쪽 경로를 눌러 부모 주제로 돌아옵니다.
회색 안내: 페이지 이름은 내용에 맞게 자유롭게 붙이세요.
제목2: 필요할 때 찾아보기
링크 글자: Notion 글쓰기 도움말
주소: https://www.notion.com/help/writing-and-editing-basics
설명: 글과 블록을 다루는 방법이 필요할 때 공식 도움말에서 다시 확인합니다.

## 다른 주제의 완성 예시 — N20

예시/지식_자산화.md의 소개·콜아웃·두 단·짧은 메모를 순서대로 활용한다. 하위 페이지 1회차 교재 · 지식 자산화에 참고_교재_발췌.md를 넣는다. 발췌는 수정하지 않는다.
예시/이상_감지.md와 예시/에이전트_기초.md는 향후 내용을 쌓는 방식의 예시다. 실제 측정·실행 결과가 아니며, 이미 배운 것처럼 말하지 않는다. 수업에서 네 카드의 긴 본문을 모두 따라 쓰는 과제로 늘리지 않는다.
예시 파일의 columns/callout/toggle 표시는 배치 안내다. HTML 코드를 Notion에 입력하라는 뜻이 아니다. 원문을 통째로 붙여넣기보다 해당 블록을 만들고 안의 문장을 적는다.

## 그림과 보기 — N21~N23

카드 이미지: 파일과 미디어 속성. Notion 익히기=이미지/notion.png, 지식 자산화=이미지/knowledge.png, 이상 감지=이미지/signal.png, 에이전트 기초=이미지/agent.png.
카드 미리보기: 카드 이미지. 카드 크기: 작게. 갤러리 표시: 이름만.
전체 주제: 같은 데이터 소스의 표. 표시: 이름·분야·이해도.
분야: 선택 속성, 도구 / 학습 방법 / AI 실습.
이해도: 선택 속성, 설명 못함 / 대충 앎 / 설명 가능. 실제 본인 판단으로 선택하며 빈칸도 허용한다.
기존 완성본 선택값: Notion 익히기=도구·설명 가능, 지식 자산화=학습 방법·대충 앎, 이상 감지=AI 실습·설명 못함, 에이전트 기초=AI 실습·대충 앎. 수업 중 학생이 그대로 따라 고를 정답이 아니다.
카드 이미지 속성은 주제 본문에서 숨기되 파일 값은 보존한다. 홈·본문에 큰 표지를 추가하지 않는다.

## 템플릿 — N24~N25

이름: 새 주제. 예시/새_주제_템플릿.md의 소개·파란 안내·나의 기록·회색 두 단·마지막 토글을 사용한다. 기본 카드 이미지: 이미지/notion.png. 분야·이해도는 비운다.
템플릿 편집과 실제 새 카드 생성을 구별한다. 생성된 카드의 예시 제목은 나만의 독서 기록, 소개는 읽으면서 남기고 싶은 생각과 자료를 모읍니다. 왼쪽 영역은 기억할 문장 / 다시 읽고 싶은 문장과 그 이유를 적습니다.로 바꾸고, 오른쪽에 다음에 읽을 책 하위 페이지를 만들어 관심이 생긴 책을 한 권씩 적어 둡니다.를 입력한다. 본인 주제로 자유롭게 바꿔도 된다. 기존 완성본의 템플릿 편집 화면은 확인했으나 생성·기본값 적용의 전체 실습은 아직 미수행이다.

## 공유와 내보내기 — N26~N29

공유·게시·댓글의 위치와 권한을 구별한다. 사용자 기존 기록의 공개 범위 변경·초대 발송은 하지 않는다. 촬영용 노트의 HTML 내보내기에서 하위 페이지 포함을 확인한다. 전체 개인 작업 공간은 내보내지 않는다. 내보낸 파일은 그 시점의 사본이며 보기·템플릿까지 완전히 복구하는 백업으로 설명하지 않는다.
전체 실행·내보내기·사진·촬영은 미수행이다. 사진 자리는 채울_화면.md에 단계별로 남긴다.
