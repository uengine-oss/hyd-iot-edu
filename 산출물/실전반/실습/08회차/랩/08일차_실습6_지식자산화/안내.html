실전반 8회차 — 지식자산화

[제작 — 낭독하지 않음] 문서 작성 완료. 실제 실습·학생 코드·테스트·AI·HYD·DB·브라우저·캡처는 미수행이다. 아래는 강사가 수업에서 수행할 흐름이며 결과는 직접 확인한 뒤 기록한다.

다운로드와 앞 산출물 모으기

처음 만든 학습노트에 이번 제작 결과를 연결해, 다음 업무에서 명세와 검증 근거를 다시 찾을 수 있게 정리하겠습니다. 실습 자료를 받아 압축을 풀고 VS Code에서 작업 공간을 열겠습니다.

[준비 · 비낭독] 지식자산화 ZIP을 내려받아 압축을 풀고 VS Code에서 코드 폴더를 열겠습니다. 앞의 명세, 스키마와 인스턴스, 에이전트와 스킬, 흐름, 실행·시연 기록을 input에 연결합니다. 처음 만든 Notion 학습 공간도 함께 확인하겠습니다. 결과 파일의 위치만 모으지 않고 개념에서 근거와 산출물로 이어지게 정리할 겁니다.

내 문장으로 지식 노트 쓰기

knowledge-note.md에 지식·제안·승인·실행·완료의 구분을 제 문장으로 적겠습니다. 각 개념에는 참고 문서의 절과 이번에 만든 파일을 연결하고, 그 파일의 확인 결과와 미확인 범위를 붙입니다. ‘작동했다’는 말만 남기지 않고 어떤 입력과 판본을 어떤 기록으로 확인했는지 적겠습니다.

코딩 도우미에는 실제 산출물 목록과 확인 기록만 제공해 연결 초안을 정리하도록 요청합니다. 없는 실행을 만들어 넣거나 참조 예제의 결과를 내 작업 성과로 섞지 않았는지 제가 대조합니다. 잘못된 링크나 판본은 고치고 다시 열어 확인하겠습니다.

Notion에 기록하고 되짚기

수업 계정에서 Notion MCP 연결과 쓰기 대상의 권한을 사전에 확인한 경우에는 그 대상에만 기록하는 시연을 하겠습니다. 연결이 준비되지 않았으면 준비한 Markdown을 Notion에 직접 붙여 정리합니다. 로컬 파일 링크가 다른 기기에서도 자동으로 열리는 것은 아니므로, 필요한 산출물을 해당 학습 공간에 첨부하고 링크를 실제 첨부 자료로 바꿉니다.

저장한 페이지를 다시 열어 개념에서 출처로, 산출물에서 검증 근거로 찾아갑니다. 첨부가 빠졌거나 접근할 수 없으면 파일과 권한을 바로잡고 다시 확인합니다. 쓰기나 다시 열기를 못 했다면 로컬 초안 작성과 Notion 반영 완료를 구분해 남기겠습니다.

과정 마무리

로컬 노트와 자료 목록, 실제 저장한 페이지 위치, 남은 확인 항목을 보존하겠습니다. 이번에 할 수 있게 된 범위와 아직 연결이 필요한 부분을 구분한 뒤 복습과 퀴즈로 돌아갑니다. 다음에 같은 업무를 다시 맡을 때 이 자료에서 기준과 근거를 찾아 시작할 수 있게 남기겠습니다.
