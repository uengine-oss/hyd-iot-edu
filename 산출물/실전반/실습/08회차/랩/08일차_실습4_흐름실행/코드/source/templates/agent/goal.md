# 제조 조율 에이전트 목표 작성 양식

앞 명세를 읽고 목적·읽을 정보·산출물·보류 조건을 작성한다. 역할은 생산·설비보전의 점검 조율 지원이다. 서버 이름은 현재 포털의 등록·권한·도구 목록에서 확인한다. 예제 이름을 복사하지 않는다.

최초 D1~D5와 후속 D6를 구분한다. 후보 개수를 채우지 않고 실제 조건을 충족한 후보만 제안한다. 자료의 기준 시점, 같은 대상·기간인지, 변경 근거를 남긴다. 후보와 안건·추가 확인을 함께 보고하며 일정 등록·메일·설비 조작·정비 오더 생성은 하지 않는다.
