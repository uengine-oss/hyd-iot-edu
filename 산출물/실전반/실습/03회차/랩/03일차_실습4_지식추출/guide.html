현장 문서 묶음에서 작업 지식 후보를 추출하고 검토하기

판·상태·언어가 다른 현장 문서 묶음에서 작업 순서·조건·금지·완료 기준·기준값을 문서 ID·절·인용과 함께 뽑는 추출 기능을 만들고, 사람이 후보를 검토한 뒤 다른 문서에 다시 적용합니다.

01 시작하기

압축을 푼 폴더를 VS Code에서 열고 START.md와 입력/출력_계약.md를 읽으세요.

자료/문서_목록.csv   문서의 판·상태·해시
자료/원문/         문서 묶음(현행·폐기·보충·제조사 발췌)
입력/출력_계약.md   후보·검토 JSON 모양
입력/비교용_추출결과/  포털 승인 추출(비교용, 실제 실행 아님)
check_candidates.py  단계 점검·계약·인용 검사기
결과/            이번에 만들 것

터미널에서 python check_candidates.py를 실행해 지금 비어 있는 단계를 확인하세요. AI에게는 먼저 문서 목록과 원문들을 읽고 문서끼리 무엇이 다른지 설명하게 합니다. 이때는 파일을 만들거나 바꾸지 말라고 함께 말합니다.

02 요구 정하기

목표, 입력, 제약(원문 그대로의 인용, LLM 호출 없음, 비교용 결과 사용 금지), 확인할 사례를 자기 말로 정리하세요. 실행 전에 HM-8 원문에서 기대 후보 2~3건(절·종류·값)을 직접 골라 검토 기록 2절에 적습니다. 그중 하나는 한 문장이나 표의 한 행에 기준값이나 조건이 둘 이상 들어 있는 줄로 고릅니다.

START의 「정할 것」 두 가지는 원문과 문서 목록을 보고 직접 정합니다. AI의 계획이 이것을 대신 정했으면 되돌려 묻습니다.

03 AI와 만들기

작은 단위로 구현하고 실행합니다. 한 부분을 만들 때마다 HM-8로 실행해 출력을 원문과 비교한 뒤 다음으로 넘어갑니다. 완료라고 하면 실행한 명령과 출력 원문을 붙여 달라고 하세요.

수정 요청에는 어떤 원문 문장에서, 무엇을 기대했고, 실제로 무엇이 나왔는지를 함께 주세요. 파일 이름은 백틱(`)으로 감싸 보냅니다.

요청을 정리할 때 볼 항목

만들 결과 / 읽을 자료 / 바꾸지 않을 범위 / 지켜야 할 출력 계약 / 실행 전에 적은 기대 결과 / 확인하지 못하면 어떻게 표시할지 / 내가 정할 것(AI가 정하지 않게)

04 결과 확인하기

python check_candidates.py
python 결과/extract.py 자료/원문/HM-8_cooler-fan-manual.md --doc HM-8 --out 결과/후보/HM-8.json
python check_candidates.py 결과/후보/HM-8.json
python 결과/extract.py 자료/원문/PM-02_powerpack-pm-checklist.md --doc PM-02 --out 결과/후보/PM-02.json
python 결과/extract.py 자료/원문/OEM-HPP45A-MM_maintenance-excerpt.md --doc OEM-HPP45A-MM --out 결과/후보/OEM-HPP45A-MM.json
python check_candidates.py 결과/검토/HM-8_검토.json
python check_candidates.py

판단 원칙: 검사기는 인용이 원문 절 안에 그대로 있는지와 계약 구조만 확인합니다. 지식이 맞는지, 빠졌는지, 어느 문서를 근거로 삼을지는 원문과 문서 목록으로 판단합니다.

  • 인용 검사에서 실패한 후보는 원문을 바꾸지 말고 추출 함수를 고칩니다.
  • 실행 전에 적은 기대 후보가 실제로 나왔는지 대조합니다.
  • 다른 문서에 다시 실행하면 후보 수만이 아니라 누락과 근거 없는 생성을 사례로 세고, 고친 뒤 다시 센 수와 비교합니다.
  • 정한 것을 바꾸면 어떤 후보가 달라지는지 한 번 확인해 기록합니다.

비교용 추출 결과와 차이가 나면 어느 쪽이 원문과 맞는지 원문으로 판단합니다. 비교용 결과가 정답 목록은 아닙니다.

05 저장하기

결과/extract.py, 결과/후보/, 결과/검토/, 결과/검토_기록.md를 저장하고 다시 열어 확인하세요. 마지막에 python check_candidates.py를 인자 없이 실행해 「완료 아님」 항목이 남지 않았는지 봅니다.

보관할 결과는 USB 또는 개인 클라우드에 복사하세요. 다음 실습은 강사가 검토한 결과로 시작하므로 이번 결과가 없어도 진행할 수 있습니다.
