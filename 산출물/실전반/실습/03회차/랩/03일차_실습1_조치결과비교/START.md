# 조건을 바꿔 조치 결과 비교하기

1. 학교 PC에 준비된 HYD 포털에서 조건별 손익 화면을 엽니다. 기본 로컬 주소는 http://127.0.0.1:8088 입니다.
2. 설비와 이상 패턴을 고르고 기준 결과를 비교_기록.md에 적습니다. 허용·제외된 조치, 경고·감점, 적용 규칙, 예상 성과를 나누어 적습니다.
3. 시험값 하나만 바꿔 다시 계산하고 기준과 비교합니다. 바꾼 항목의 화면 이름·단위·기준값·시험값을 그대로 적습니다. 다음 시험 전에 기준값으로 되돌립니다.
4. 결과가 달라진 이유를 화면의 적용 규칙·근거에서 찾아 적습니다. 시험값을 바꾼 것은 실제 설비 조치가 아닙니다.
5. 결함 시뮬레이션 화면에서 같은 설비의 운전 모드를 현장 제어로 바꾸고(정비원이 현장 패널을 잡은 상황) 조건별 손익을 다시 불러옵니다. 점수나 손익 순위가 높던 후보가 규정상 제외되면, 선택할 수 없는 이유를 결과 화면의 규칙과 근거에서 찾아 적습니다. 순위와 선택 가능 여부를 다른 열에 기록하고, 끝나면 운전 모드를 원격 자동으로 되돌립니다. 운전 모드 전환은 시뮬레이터 조건이며 조치 승인·실행이 아닙니다.
6. kpi.csv의 세 설비 인터록 여유로 평균과 최솟값을 계산해 목표와 비교합니다. 측정값은 그대로이고 집계 방식에 따라 판단이 달라지는지 봅니다.
7. 기록을 결과/에 저장하고 다시 열어 확인합니다. 승인·실행 버튼은 누르지 않습니다.

보관할 파일은 재부팅 전에 USB 또는 개인 클라우드로 복사합니다. 다음 실습에서는 조건표를 읽어 후보를 판정하고 조치 검토 결과를 만드는 기능을 직접 만듭니다.
