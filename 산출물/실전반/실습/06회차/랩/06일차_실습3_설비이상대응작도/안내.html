쿨러 경보에서 보고까지 역할별 레인으로 설비 이상 대응 흐름 설계하기

VS Code에서 이 폴더(이 안내 파일이 있는 폴더)를 열고 START.md를 함께 읽으세요. 이 안내는 START.md와 같은 내용입니다.

출발점이번에 할 것작업 순서기대 결과를 먼저 적을 사례 종류학생이 정할 것이번 범위 밖완료 조건저장과 다음 실습

실습2의 승인 업무를 넓혀, 쿨러 경보가 오면 진단·조치 제안 에이전트가 판단하고 운전원이 승인한 뒤 PLC 명령을 내리고 효과를 재확인해 보고하는 흐름을 bpmn.io에서 그립니다. 다음 실습과 실행 연결 비교에서 이 그림을 그대로 쓰므로, 누가 어느 일을 맡는지가 레인과 작업 종류로 드러나야 합니다.

출발점

  • 코드/input/: 실습2에서 저장한 approval.bpmn을 복사해 둡니다. 없으면 실습2의 승인 여부 갈림부터 그립니다.
  • 코드/source/reference/: 제공 참조 흐름 「냉각 긴급 대응」의 BPMN과 연결 값입니다. 다 그린 뒤 대조할 때만 열고, 완성본으로 바꿔 쓰지 않습니다.
  • 코드/element-map.md: 내 요소 ID와 레인을 적는 제공 빈 틀입니다.
  • 코드/review.md: 확인 기록 빈 틀입니다.
  • 편집기: demo.bpmn.io

이번에 할 것

  • 풀 하나를 만들고 담당자·에이전트·시스템 세 레인으로 나눕니다. 풀을 셋 만들지 않습니다.
  • 쿨러 경보 시작(메시지 시작 이벤트) → 진단·조치 제안 → 운전원 승인 → PLC 명령 → 효과 재확인(재관측) → 결과 보고 → 끝을 레인에 나눠 놓고 잇습니다.
  • 작업마다 종류를 고릅니다. 사람이 하는 일은 사용자 작업, 시스템이 하는 일은 서비스 작업입니다. BPMN 표준에는 「에이전트 작업」이라는 종류가 없으므로 진단·제안은 표식 없는 작업으로 둡니다.
  • 코드/output/cooling-draft.bpmn으로 저장하고, 요소 ID·이름·종류·레인을 코드/element-map.md에 적습니다.

작업 순서

  1. 코드/input/approval.bpmn을 편집기에서 엽니다. 원본은 고치지 않고 결과는 새 파일로 저장합니다.
  2. 풀과 세 레인을 만들고, 기존 요청 확인 작업을 담당자 레인의 운전원 승인으로 옮깁니다.
  3. 경보 시작과 진단·조치 제안, 시스템 레인의 명령·재관측·보고를 놓고 순서대로 잇습니다. 레인을 건너가도 같은 풀 안의 순서는 시퀀스 흐름입니다.
  4. 추천에서 명령으로 바로 가는 선이 없는지, 명령 뒤에 재관측이 있는지 따라갑니다.
  5. 저장하고 다시 연 뒤, 제공 참조 흐름과 작업 이름·레인을 대조해 코드/element-map.md에 적습니다.

기대 결과를 먼저 적을 사례 종류

그리기 전에 코드/review.md의 「예상」 칸을 먼저 적습니다.

  • 레인 배치: 경보 시작·진단 제안·승인·명령·재관측·보고가 각각 어느 레인에 놓일지
  • 승인 위치: 추천과 명령 사이에 사람의 승인이 놓이는지
  • 재관측의 이유: 명령을 처리한 것과 설비가 실제로 회복한 것이 왜 다른 확인인지

학생이 정할 것

경보 시작 이벤트와 결과 보고, 작업지시 등록 같은 작업을 어느 레인에 둘지 정합니다. 참조 흐름과 다르게 놓아도 됩니다. 그 작업을 실제로 누가(사람·에이전트·시스템) 수행하는지를 기준으로 고른 이유를 코드/review.md에 적고, 다음 비교 실습에서 기준 흐름과 견줍니다.

이번 범위 밖

거절·회복 미달·승인 지연 경로(다음 실습), 실행 조건·기한 값, 에이전트·역할·실행 기능 연결, 포털로 흐름을 보내는 일.

완료 조건

  • 코드/output/cooling-draft.bpmn을 다시 열면 풀 하나에 레인 셋이 있고, 경보에서 끝까지 한 경로로 이어집니다.
  • 추천과 명령 사이에 운전원 승인이, 명령 뒤에 재관측이 있습니다.
  • 코드/element-map.md에 내 요소마다 ID·이름·종류·레인이 있습니다.

저장과 다음 실습

코드/output/cooling-draft.bpmn, 코드/element-map.md, 코드/review.md를 저장하고 다시 열어 확인하세요. 보관할 결과는 재부팅 전에 USB 또는 개인 클라우드에 복사하세요. 다음 실습에서는 이 초안에 승인·거절 분기와 승인 지연 알림을 더합니다.
