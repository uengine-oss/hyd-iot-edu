조치 조건과 판단 근거 정리하기

원문 조건을 조치 조건표로 옮기고, 경보 사례의 원자료로 경계값·겹치는 조건·값 없음을 확인합니다.

01 자료 읽기02 조건표 만들기03 사례 대조하기04 저장하고 다시 읽기

01 자료 읽기

VS Code에서 이 폴더를 열고 START.md와 입출력_계약.md를 읽으세요.

자료/   HM-8 매뉴얼, 규칙 발췌, 작업기준, HI-01, 수집 설명, 대상 후보
        경보 사례 48건의 원자료 4종(경보 목록, PLC 상태, 팬 카운터, 예측 결과)
결과/   이번에 만들 조건표.csv, 판단기록.md
check.py   단계별 구조 검사

원자료는 수업용 시뮬레이터 로직으로 만든 교육용 가상 자료입니다. 원천마다 수집 주기·단위가 다르고 값이 비는 이유도 다릅니다. 먼저 AI에게 파일을 바꾸지 말고 자료를 설명하게 하고, 그 설명을 실제 파일과 대조하세요. 파일 이름은 백틱(`)으로 감싸 적습니다.

02 조건표 만들기

AI에 목표·자료·제약·확인 사례를 자기 말로 전달하고 계획을 먼저 받으세요. 규칙 하나씩 결과/조건표.csv에 옮기고 python check.py로 형식을 확인합니다.

입력, 연산자, 기준값, 단위, 경계 포함 여부, 결과, 원문 근거를 나누세요. 여러 비교가 한 규칙을 이루면 같은 규칙 번호로 묶습니다.

이번 실습의 판단 지점: 규칙의 식과 설명 문장, 규칙 발췌와 HM-8, 원천 자료의 기록 방식이 서로 다른 답을 주는 곳이 있습니다. 그런 곳은 사람이 원문을 읽고 정해 판단기록.md에 결정·근거·바뀌는 사례를 적습니다. AI가 질문 카드로 물으면 「(권장)」은 추천일 뿐이니 원문 절을 직접 열어 확인하고 고릅니다. python check.py가 「옮기지 않은 규칙」을 알려 주면, 옮기거나 옮기지 않는 이유를 결정 표에 적습니다.

03 사례 대조하기

사례 종류마다 경보 사례를 고르고, 판단기록.md에 원자료 행·판단 입력·일치 규칙·판정을 적으세요. 조건표 입력을 원자료에서 만드는 방법도 표로 남깁니다.

경계값 바로 아래·같은 값·바로 위에서 판단이 원문과 맞는지 확인합니다. 여러 사유는 모두 남기며 감점은 규칙당 한 번만 반영합니다. 값이 없는 규칙은 왜 없는지와 함께 미확인으로 남기고, 알려진 제외 사유는 지우지 않습니다.

AI가 완료를 알리면 실행한 명령과 출력 원문을 붙여 달라고 요청합니다.

04 저장하고 다시 읽기

조건표의 각 행에서 원문 절을 찾을 수 있는지 확인하세요. 조건표.csv와 판단기록.md를 저장하고 다시 엽니다.

후보 유지는 실행 승인이 아닙니다. 이번 실습에서는 표와 기록만 작성합니다.

보관할 결과는 USB 또는 개인 클라우드에 복사하세요.

다음 회차에는 완성된 조건표로 경보 사례 전체의 조치 검토 결과를 만들고 매뉴얼 근거를 연결합니다.
