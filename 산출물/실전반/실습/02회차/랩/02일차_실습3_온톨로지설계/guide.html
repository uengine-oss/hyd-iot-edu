부품의 사용 설비와 공급 정보를 연결하기

제공된 설비·센서·부품 모델을 읽고, 공급 조건을 연결한 모델을 만듭니다. 공급사 선정·점수화는 하지 않습니다.

01 시작하기

입력/의 이전 모델을 출발점으로 사용합니다. 공급 정보는 아직 연결되어 있지 않습니다.

VS Code에서 START.md를 열고 이번 요구를 확인하세요.

입력/   이전 단계 자료
자료/   현장 원자료(설계 실습)
결과/   이번에 만들 결과
AGENTS.md   작업 규칙

02 요구 정하기

  1. 선택한 부품을 사용하는 설비와 구성 요소는 무엇인가?
  2. 그 부품의 공급사별 승인 여부·단가·불량률·납기는 무엇인가?
  3. 원자료에 없는 품번을 조회했을 때 결과 없음이 구별되는가?

자료에서 답의 근거를 찾고 AI에 전달할 목표와 제약을 정리하세요.

03 AI와 만들기

공급 조건을 어디에 표현할지 정하고, 기존 설비·부품 연결을 유지하면서 모델을 확장하세요. 같은 공급사라도 부품에 따라 조건이 다름을 반영하세요.

한 기능의 결과를 확인한 뒤 다음 작업을 요청하세요. 수정 요청에는 입력·기대 결과·실제 결과를 함께 전달하세요.

요청을 정리할 때 볼 항목

만들 결과 / 참고할 자료 / 바꾸지 않을 범위 / 성공을 확인할 사례

04 결과 확인하기

python check.py
  • P-PMP-SEAL의 사용 설비는 HYD-01·02·03입니다.
  • 공급 조건 3행을 원자료와 대조합니다. 비승인 공급사도 승인 여부를 표시해 구별합니다.
  • 다른 부품은 그 부품의 조건을 반환하고, 없는 품번은 결과 없음으로 나타납니다.
  • 가격·납기로 공급사를 자동 선정하지 않습니다.

원자료와 실제 결과를 대조하세요. AI의 완료 메시지는 실행 결과를 대신하지 않습니다.

05 저장하기

결과/schema.json, 결과/graph.json, 결과/요구사항.md, 결과/자료_검토.md

저장한 파일을 다시 열어 내용을 확인하고, 보관할 결과를 USB 또는 개인 클라우드에 복사하세요.

다음 실습은 시작 도구에서 새로 선택합니다. 개인 결과를 가져오지 않아도 시작할 수 있습니다.
