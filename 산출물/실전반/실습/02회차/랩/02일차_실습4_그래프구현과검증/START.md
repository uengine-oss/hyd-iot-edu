# 부품별 사용 설비와 공급 조건 조회하기

앞 단계의 완성 모델에서 출발해 적재·조회 로직을 직접 작성합니다.

## 출발점

입력/에 앞 단계 완성 모델과 원자료가 있습니다. 이전 개인 결과 없이 시작할 수 있습니다. 개인 모델을 쓰려면 제공 입력을 보존하고 별도 폴더에 복사하세요.

## 이번에 해결할 질문

1. 선택한 부품을 사용하는 설비와 구성 요소는 무엇인가?
2. 그 부품의 공급사별 승인 여부·단가·불량률·납기는 무엇인가?
3. 원자료에 없는 품번을 조회했을 때 결과 없음이 구별되는가?

## 작업

AI와 적재·조회문을 작성하세요. 같은 입력을 두 번 적재해도 대상과 관계가 늘지 않아야 합니다. 이름이 바뀌어도 같은 ID의 대상은 유지되어야 합니다. 전체 삭제문은 사용하지 마세요. 고칠 것이 생기면 필요한 대상만 수정하세요. P-PMP-SEAL을 확인 사례로 사용 설비와 공급 조건을 원자료와 대조하고, 다른 품번과 원자료에 없는 품번도 조회하세요. 비승인 공급사는 승인 여부와 함께 구별해 보여 주세요.

## 진행 방법

1. AI에게 파일은 바꾸지 말고 자료를 읽어 과제와 확인할 점을 정리해 달라고 요청하세요. 짚어 준 근거는 원자료에서 직접 확인합니다.
2. 목표·입력·지킬 조건과 내가 정한 결정을 자기 말로 결과/검증_기록.md에 적으세요. 구현 전에 원자료에서 질문별 기대 답을 두세 개 직접 찾아 함께 적어 둡니다.
3. AI에게 계획을 먼저 받아 검토한 뒤 구현을 맡기세요. 한 번에 다 맡기지 말고 확인할 수 있는 단위로 나눕니다.
4. 완료라는 말 대신 실행한 명령과 실제 출력, 바뀐 파일을 확인하세요. 입력/·자료/는 바뀌지 않아야 합니다.
5. 적어 둔 기대 답과 실제 결과를 대조하고, 다르면 입력·기대·실제를 함께 전달해 고치세요.
