# 그래프 구현 준비

실습3 결과/schema.json·graph.json·요구사항.md·자료_검토.md를 이 폴더의 입력/에 복사하고, 실습3의 자료/ 폴더를 입력/자료/로 가져온다. 앞서 작성한 판본을 사용하며 빈 양식으로 덮어쓰지 않는다. 강사가 제공한 별도 빈 랩 DB를 사용한다. 실습1 예제 DB나 HYD 기준 DB에 적재하지 않는다. 원본과 수정할 작업본을 구별하고 기존 DB 전체 삭제 명령을 사용하지 않는다.

Copilot에 두 입력을 지정해 적재.cypher와 조회.cypher를 만들도록 요청한다. 레이블별 id 유일 제약, id 기준 MERGE, 값 갱신, 관계 끝점 MATCH를 확인한다. 생성문을 검토한 후 랩 DB에만 실행하는 수업 흐름이다. 이 제작에서는 실행하지 않았다.

존재·형·단위·끝점·카디널리티와 원자료의 의미를 함께 확인한다. 제약 저장 성공만으로 의미가 맞다고 하지 않는다. 원자료의 설비별 센서·계측 대상·단위를 실제 조회와 대조한다. 실제 오류가 있으면 근거에 따라 수정하고 세 질문을 다시 확인한다. 정상 관계를 일부러 망가뜨리지 않는다.
