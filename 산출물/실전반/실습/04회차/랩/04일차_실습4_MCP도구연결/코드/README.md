# 코드 폴더

- `source/Notion_내보내기_표본/`: 자기 Notion 기록이 없거나 연결할 수 없을 때 쓰는 교육용 가상 내보내기 표본입니다. 읽기만 합니다.
- `input/meeting-actions/`: 앞 실습의 완성 시작본 회의 스킬입니다. 쓸 때는 랩 폴더의 `.github/skills/` 아래로 복사합니다.
- `서버/`: 제공 MCP 서버(`파일시스템_서버.py`·`깃_서버.py`·`시간_서버.py`, 공통 뼈대 `mcp_기본.py`)와 직접 구현할 골격 `점검메모_서버.py`.
- `도구/`: `자료_준비.py`(업무자료 폴더와 Git 이력 준비), `연결_점검.py`(stdio 서버의 연결 · 도구 목록 · 직접 호출 확인), `이력/`(준비에 쓰는 원본).
- `구매팀_자료/`: 파일 서버의 허용 범위 밖 접근을 확인하는 연습 자료입니다.
- `설정_작성.md`: `.vscode/mcp.json`의 형식 예시.
- `output/`: 다음 협의 안건과 연결 · 대조 기록을 저장합니다. 안의 기록 파일은 제공 빈 틀입니다.

과제는 [../START.md](../START.md)에 있습니다.
