# 변경 확인 기록

제공 빈 틀입니다. 기대는 구현하기 전에 spec.md와 원자료에서, 실제는 실행한 뒤에 적습니다. 결과에 맞추려고 먼저 적은 기대를 고치지 않습니다.

## 먼저 적은 기대

기대 칸을 쓴 시각:

| 사례 종류 | 요청(원자료 행 또는 연습 사본) | 기대 긴급 표시 | 기대 상태와 기존 칸 | 근거(spec.md의 줄 · 원자료 행) |
|---|---|---|---|---|
| | | | | |

## 정한 것

| 결정할 지점 | 정한 내용 | 근거 | 바뀌는 요청 |
|---|---|---|---|
| | | | |

## 변경 전후 대조

변경 전 결과: `코드/input/점검요청/결과/점검_요청.json` · 변경 뒤 결과: `코드/output/점검요청/결과/점검_요청.json`

| 요청 | 변경 전 상태 · 사례 · 근거 상태 | 변경 뒤 상태 · 사례 · 근거 상태 | 긴급 표시와 이유 | 기존 칸이 달라졌나 |
|---|---|---|---|---|
| | | | | |
