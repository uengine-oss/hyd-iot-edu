# 제공된 기존 비교 기록

원본 교재에 있던 과거 비교 사례다. 이번 제작에서 실행하거나 재현하지 않았다. 사례/읽는_법.md를 따라 기존 출력·변경 출력·바뀐 파일을 읽기만 한다. 이번 프로젝트의 성공·실패 증거로 사용하지 않는다.

## 현재 실습과 구별해서 읽기

이 폴더는 변경된 파일과 당시 결과를 모은 비교 자료이며 독립 실행 프로젝트나 최신 정답 구현이 아니다. 누락 파일을 복원하거나 예제 코드를 실행할 필요 없이 원문과 변경 차이를 읽는다. 사본1은 트립 패턴 표시, 사본2는 인터록 여유, 사본3은 정지 한계 근접도를 택했다. 사본2의 여유는 정상 100%·한계 0%, 사본3의 근접도는 정상 0%·한계 100%이므로 같은 숫자로 비교하지 않는다. 출력의 확인됨은 등록된 증거 기준의 지지이며 실제 원인의 입증이 아니다. SOP-PMP-03의 금지 문구와 승인 역할이 없는 절차는 실행 가능한 권고로 보지 않는다. 역할 문자열만 비교하거나 거절 사유만 검사한 기존 코드는 실제 HYD의 역할 구성원·등급·거절 권한 검증을 구현한 것이 아니다. 현재 실습은 분할 대본의 spec.md 작성 기준을 따른다. 기존 비교 프로그램의 결과 경로는 당시 기록의 경로다.
