## 최신 원천 갱신 — A065 (2026-10-05)

현재 모델상태가 포함된 plant.status는 매wall초1Hz로 발행한다. PLC mode/ACK 변경 시 즉시 발행과 MQTT retained/QoS1은 유지한다. 이전10초 주기에서는 실제 승인본과 명령전관측이10초 차이나 예측 악화 한계를 넘어 명령을 보류한 경우가 있었다(A064쿨러, 원본실패 보존). 동의 허용치나 인터록을 완화하지 않고 현재 모델상태의 갱신주기를 고쳤다.

실제 MQTT→Kafka→process HTTP에서 변경전23초간 세설비 각3timestamp·최대나이10.10초, 변경후 각24timestamp·최대간격1.003초·최대나이1.652초를 관측했다. 이는 해당 실행의 전달주기 증거이며 항상1초이내 배달을 보증하는 SLA는 아니다. 원천끊김/오래된시각 거절과 승인전 재검증은 계속 적용한다. 최신 전체검사922와 실제시나리오 범위는 HANDOFF A065를 따른다. 아래는 각 과거시점의 기록이다.
