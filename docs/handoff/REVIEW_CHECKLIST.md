## C. 클린코드
- 이름이 하는 일을 말한다(주변 코드 관례를 따름). 함수 하나 = 책임 하나, 과도하게 긴 함수 분리.
- 중복 제거(이미 있는 유틸 재사용), 죽은 코드·쓰지 않는 import·디버그 출력 제거.
- 주석은 주변 코드 밀도에 맞춘다. 코드와 어긋난 주석 금지.
- 매직 넘버는 이름 있는 상수로(단위 포함).
- 경계에서 입력 검증, 내부는 신뢰.

## D. 프로젝트 규칙
- 승인 전 에이전트는 조회·계산만. 사람 승인 1회 뒤 process가 실행.
- 사건 한 건 = 프로세스 인스턴스 하나.
- 포털 UI: 참고 화면(process-gpt-vue3·Dify 등) 모방, 카드 하나에 행동 1개, 보조 정보 접기, "학생이 10초 안에 할 일을 찾는가".
  화면 글은 한국어·일반인 눈높이, 내부 id·영문 잔재 금지.
- 처리 과정에 블랙박스 없음: 각 단계가 기록되고 화면에서 읽힌다.
- 참고 레포(ProcessGPT 모노레포 — 이 PC는 `/Users/uengine/process-gpt`)와 다른 곳은 ① 실제 결함인가 ② 요구를 못 채우는가만 묻는다.
- 비밀값을 출력·커밋·문서·로그에 남기지 않는다.
- TIME_SCALE=20 기준으로 흔들리지 않는다.
