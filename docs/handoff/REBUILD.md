## 1. 실행의 신뢰성 (R08/R10/R11/R12)

## 2. 원천 자료와 온톨로지 (R01/R02/R05/R06)

진행: 물리 원천 identity/AST DDL/SQL생성·배치 소유권 복원은 실제18/18+HTTP12/12+원천SQL8/8 범위에서 검증. 아래 SOP·새 원천 연결·동적 실행은 미완료.

- DDL 컬럼의 물리 식별은 연결/데이터베이스/스키마/테이블/컬럼을 구분한다. 파일명은 출처 증거이며 물리 데이터 소스 식별자를 대신하지 않는다. 동일 이름의 다른 스키마/원천을 시험한다(A004).
- 참고한 Catalog의 계약은 `ObjectResolutionRequest.datasource`, schema, quoted name, owner 경계를 구분한다. 그대로 연결할 수 있는 부분을 먼저 적용하고, HYD 의미 계층(System/InputData)과 물리 카탈로그(TABLE/COLUMN)의 역할 차이는 어댑터에서 명시한다. 제품에 이미 있는 추출/질의 검증을 단순 정규식 이름 추측으로 대체하지 않는다.
- 기존 `ingest_batch`는 최초 생성 노드만 표시하고 후속 업로드는 동일 노드 속성을 덮어쓴다. 원문→추출 제안→검토→적재 기록을 분리하고, 새 배치가 기존 노드/관계를 사용한 경우에도 배치 삭제가 다른 배치의 사실을 지우지 않도록 소유권/변경 이력을 설계한다.
- DDL preview/commit/SQL 생성이 동일한 원천 식별과 스키마를 전달해야 한다. `'ent' AS schema`는 제거 대상. quoted 식별자, 빈 선택, 중복 컬럼, 잘못된 연산자, 다중 테이블 관계와 오류를 검증한다.
- SOP 추출은 기존 온톨로지 스키마를 지키되 새 문서의 표/절/출처/사실을 보존한다. 생성 모델의 제안과 실제 적재를 구분하고, 적재 후 실제 질의로 연결을 확인하는 ontology-studio 루프를 적용한다.
- 수용 검사: 처음 보는 DDL/SOP 두 묶음, 같은 테이블명/다른 원천, 수정된 문서 재적재, 부분 실패와 배치 되돌리기, 인용에서 원문까지 역추적, 실제 DB 질의 결과 비교.

## 3. 실제 질의와 판단 (R03/R04/R06/R07/R09)

- 회의 289~350행의 SQL/PromQL 생성 요구를 결정론 도구 호출만으로 충족했다고 하지 않는다. 에이전트가 schema/metadata를 읽고 질의를 생성하며 도구가 검증·실행해 현재 값과 출처를 돌려주는 흐름을 구축한다.
- 승인된 DMN 규칙의 판정과 업무 에이전트의 질의·설명·대안 탐색을 구분한다. 모델이 규칙을 몰래 바꾸지 않게 하면서, 정의/지식/데이터를 바꾸면 결과가 달라지는지를 검증한다.
- 원본 neo4j-text2sql의 실행/검증/오류 수정 루프를 실제 코드로 추적한다(README만 읽은 현재 상태에서 기능 채택 완료라 쓰지 않음). 같은 HEAD의 robo-data-text2sql과 중복 구현으로 세지 않는다. A022에서 검증/수정 모듈 일부를 읽었고, HYD MCP가 ent 밖을 postgres로 조회하는 실제 반례를 확인했다. A022에서 전용 읽기 역할/AST 원천 제한을 적용했고 실제 DB+HTTP 49/49, 실제 Codex 두 정의/컬럼 오류수정을 확인했다. 연결 실패·PromQL·전체 도구 격리 검사는 남아 있다.
- 수용 검사: 납기/재고/규칙/원인 관계를 각각 변경, 없는 컬럼/연결 실패/빈 결과, 근거와 상반된 결과, 금지된 쓰기/승인 우회. 사용자 질문에 따라 다른 질의가 실제 실행됐는지 도구 trace로 확인한다.

## 4. 시스템 사용/운영 문서와 인계 (R13/R14 범위 정정)

세 설비 시나리오를 고정 정답의 시연으로 끝내지 않는다. 정의·자료·조건을 변경했을 때 입력→질의→판단→사람 선택→조치→관측 결과가 실제로 바뀌는 시스템을 구현·검증한다. 참고 레포의 관련 기능은 회의 요구/시스템 확장/미채택 후보로 구분하고 실행 불가능한 기능을 구현 완료처럼 표시하지 않는다. 포털과 시스템 사용/운영 문서에는 같은 검증 범위와 한계를 적고 다음 작업자가 이어갈 근거를 남긴다. 사용자 최신 정정에 따라 교재·슬라이드·시수표 제작/수정과 강의·학생 리허설, 강의 인계 대역 시험은 이 작업의 산출물/완료 조건에서 제외한다.
