## 추가 구현으로 해석하지 않는 항목

- B는 오더·공지 뒤 종료, C는 즉시 입고·재고 반영 뒤 종료다. 예약 대기·시운전·입고 대기·조치 미달·시운전 미달·납기 초과·고장 원인 입력 버튼을 추가할 근거가 없다. 기존 시나리오 이름과 흐름 결정을 유지한다.
- 50~52·61~63·70~74·80~83·112~114행은 VS Code에서 제작하는 실습이다. 이를 포털 신기능 요구로 바꾸지 않는다.
- 83행은 기존 설비 이벤트·정비 이력·부품 DB 조회 또는 동일 스키마 준비 자료를 조합한 인수인계서다. 새 데이터 플랫폼을 요구하지 않는다.
- Notion 학습노트는 7·117행의 필수 활동이다. 63행 학습 코치는 Markdown 또는 제공 매뉴얼 텍스트로 먼저 완주한다. 117행은 연결·쓰기 권한이 검증됐을 때만 MCP 연동을 시연하고, 미연결 환경에서는 Markdown을 Notion에 직접 정리한다. 선택인 것은 API/MCP 연동이며 학습노트 자체가 아니다.
- 옛 `2026-10-10/syllabus-gap.md`의 수치와 `syllabus-portal-underuse.md`의 메뉴 활용 제안은 최종본 기능 결함 판정으로 승계하지 않는다. 교재 및 lecture-deck 도구는 수정하지 않는다.
