## 8. 미검증 · 하지 않은 것

- **학생 대역이 Claude Code로 랩을 실제로 수행하는 것**은 하지 않았다(지시된 범위 밖). 안내의 「요구사항의 뼈대」만으로 Claude Code가 약속한 파일 이름 · 출력 모양을 만들어 내는지, 랩마다 걸리는 시간이 실라버스 시간(25~50분)에 맞는지는 모른다.
- **5일차 `agent.py`의 실제 AI 호출**: 한 번도 돌리지 않았다(키 없음). import와 "키가 없으면 멈춤"까지만 확인. 5-1~5-3 완주에 쓴 답 파일은 도구의 실제 반환값으로 조립한 기대 출력 예다.
- **6-1 · 6-4의 Skill을 Claude Code가 실제로 선택 · 수행하는지**: 하지 않았다. 결과 JSON은 손으로 쓴 예다.
- **6-2 · 6-3을 Claude Code의 MCP 클라이언트로 호출**: 하지 않았다. 같은 서버 설정(`uvx mcp-neo4j-cypher@0.4.1` stdio, 판단 MCP HTTP)을 fastmcp 클라이언트로 불러 확인했다. Claude Code가 `.mcp.json`의 `${이름}`을 셸 환경 변수로 채우는 동작은 안내에만 적었고 실측하지 않았다.
- **6-5 Notion**: 연결하지 않았다. 서버 패키지 이름(`@notionhq/notion-mcp-server`)과 환경 변수(`NOTION_TOKEN`)는 실물로 확인하지 못했다.
- **Windows · WSL 학생 PC**: 이 PC(macOS · colima)에서만 돌렸다. 안내의 `cp` · `set -a; source .env` 는 bash 기준이다.
- **화면 캡처가 든 실습가이드(PDF/HTML)**: 만들지 않았다. 랩 안내는 Markdown 한 쪽씩이다.
- 오프라인 반 · 실전반 시트에만 있는 요구 가운데 "랩용 매뉴얼 이름 ↔ DB 설비 ID · 센서 태그 매핑"(통합 오프 24)은 `day4/data/id_mapping.csv`와 센서 `tag`로, "도구 실패 · 누락 ID"(실전 55)는 5-3으로 담았다. 그 시트의 시간 배분에 맞춘 별도 안내는 만들지 않았다.
