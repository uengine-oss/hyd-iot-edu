## 반례와 변경

현재 `agentsvc/approval.py`가 현재 그래프 규칙·SOP·역할과 원천 데이터를 다시 읽는다. 읽기 API `/api/agent/approval-check` 자체에는 승인/실행 권한이 없다. process는 자신의 저장된 판단 스냅샷으로 검사하며 사용자 제공 facts를 신뢰하지 않는다.

## 규칙의 미확인과 사람의 검토

AND 조건 중 하나가 확실히 false이면 나머지 unknown은 해당 규칙을 발동시키지 않는다. 그렇지 않은 EXCLUDE/PENALTY 필수값 미확인은 실행 가능한 카드라고 표시하지 않는다. SELECT 미확인도 후보를 추가할 근거가 아니다.

WARN은 금지 규칙이 아니다. 미확인 변수/규칙/원문 주석을 카드의 경고에 표시하고, 승인 때도 같은 경고가 있었는지 비교한다. **새 미확인 경고가 생기거나 사라져도 기존 카드를 그대로 승인하지 않는다.** 원래 카드에 공개된 advisory 불확실성은 유지될 수 있다. 이 구분은 압력 예측이 없는 쿨러 카드에 `rule:ps1-warn`이 적용되는 실제 불일치에서 드러났다. 누락 예측을 임의 숫자로 채우거나 EXCLUDE를 WARN으로 바꾸지 않았다.

SOP actions/steps/approver/forecast/warnings/penalties와 납기·계약·로트 판단 입력이 바뀌면 새 검토가 필요하다. 현재 원인 판단의 타당성 재진단, 모든 병합 경보, 사용자 변경 제어값에 맞춘 동적 예측까지 구현됐다는 의미는 아니다.
