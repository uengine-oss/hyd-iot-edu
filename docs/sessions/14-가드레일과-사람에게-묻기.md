# 14. 가드레일과 사람에게 묻기 (3부, 180분: 설명 60 / 실습 90 / 정리 30)

## 이번에 할 것 / 끝나면 보이는 것
에이전트가 근거 없이 카드를 내면 서버가 막는다(가드레일). 에이전트가 모르는 것을 사람에게 물으면 작업이 멈추고, 사람이 답하면 같은 세션이 이어진다(사람에게 묻기, 화면 표기: HITL / 에이전트의 질문).
끝나면 가드레일 거부 1건과, 질문 → 답변 → 같은 작업 재개의 이벤트 기록 1건이 남는다.

## 준비
- 가드레일: `it/agent/agentsvc/guardrail.py`, `card.py`의 `_citations()`(`docs/student-guide.md` §5 과제 4).
- 사람에게 묻기: `it/agent-worker/worker/hitl.py`, `runner._pause`(`events.py` 17행 주석), 포털 **내 할일**의 "에이전트의 질문" 카드, API `POST /api/todolist/{id}/human-response`.
- 13회차처럼 호스트 워커 + `AGENT_BRIDGE=off`(질문 장면), 또는 `legacy`(가드레일 장면은 서버 안 에이전트로 충분).

## 실행 장면
1. [화면] 이상 확인 · 조치 → 쿨러 경보 트레이스의 `guardrail` 단계 → [관찰] `violations: []`이면 통과, 아니면 `FAILED`와 위반 목록 → [확인] 통과 조건(모든 조치·근거가 그래프 노드 id를 인용)을 `guardrail.py`에서 찾아 적는다.
2. [실험, 강사 PC] `card.py` `_citations()`에서 action id 하나를 빼고 `docker compose up -d --build agent` → 쿨러 주입 → [관찰] 트레이스 `guardrail` FAILED, 카드가 제출되지 않고 사건 감사에 `REJECTED_BY_GUARDRAIL` → [확인] 거부 1건. 실험 뒤 코드 원복·재빌드.
3. [화면, 워커 경로] 사람에게 묻는 작업을 만든다: `scripts/probe_codex_human.py`(머리말: 두 실행을 만들고 질문을 기다린다 → 포털에서 답 → 같은 세션으로 MCP 질의). Claude Code로 할 때는 정의의 `agentConfig`를 `{"cli": "claude-code"}`로 바꾸고 **`permission: "read_only"`는 넣지 않는다** — Claude Code에서 read_only는 계획 모드(`--permission-mode plan`, `cliagents/providers/claude_code.py` 66~70행)라 답을 받은 뒤 MCP 도구 호출이 "Cannot call … while in plan mode"로 막히고 작업이 보류된다 또는 추출 작업(9회차 7단계)에서 에이전트가 질문하도록 둔다 → [관찰] **내 할일**에 "에이전트의 질문" 카드, 작업 상태가 멈춤, 이벤트 `human_asked` 1행 → [확인] 질문 본문.
4. [화면] 질문 카드에 답을 적고 제출(`/human-response`) → [관찰] 워커가 같은 세션(`--resume`)으로 이어 가고 `tool_usage_*`가 다시 흐른다 → [확인] 답변 뒤 작업이 SUBMITTED → DONE, 다시 집을 때 임대 횟수가 올라가지 않는다(HANDOFF A114 A1).
5. [관찰] CLI별 차이: Claude Code는 권한 요청(`permission_request`)도 질문으로 올리고, Codex는 도구 거부가 작업 실패로 끝날 수 있다(커리큘럼 14회차 주석) → [확인] 수업에서 쓸 CLI를 하나로 정한다.
6. [화면] 실행 중 작업 취소: 인스턴스 상세의 에이전트 작업 행 → 취소(API `POST /api/todolist/{id}/cancel`) → [확인] 워커가 1초 안팎에 점유를 돌려주고 늦은 결과를 제출하지 못한다.

## 막혔을 때
- 가드레일 실험 뒤 카드가 계속 안 나온다: 코드 원복 후 `agent` 재빌드를 잊었다.
- 질문 카드가 안 뜬다: 워커 경로가 아니거나(`AGENT_BRIDGE=legacy`) 에이전트가 질문 없이 끝냈다. 질문을 강제하는 지시는 `probe_codex_human.py` 참고.
- 답했는데 재개가 안 된다: 포털 질문 카드는 `text`를 먼저, 없으면 `question`을 읽는다(A115 A12). 이벤트 상세에서 원문 확인.
