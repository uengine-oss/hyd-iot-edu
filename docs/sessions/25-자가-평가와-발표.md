## 실행 장면
1. [선택] 시나리오 하나(쿨러 / 펌프 / 팬) → [확인] 발표 순서 아홉 줄 메모.
2. [화면, 선택] 라이브 시연: 주입 → 경보 → 카드 → 선택 → ACK까지만(약 2분), 나머지는 기록 화면으로 → [확인] 시간 5분.
