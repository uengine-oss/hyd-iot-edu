# 19. 쿨러 열화 완주 (기준 시나리오) (5부, 180분: 설명 20 / 실습 130 / 정리 30)

## 이번에 할 것 / 끝나면 보이는 것
안내 없이 한 바퀴를 혼자 돈다: 주입 → 경보 → 카드 → 선택 → ACK → 경보 해제 → 재관측 → 정비 요청 → 종결. 걸린 시간을 적는다.
끝나면 완료된 실행 1건, 업무 DB의 정비 요청 행 1건(`ent.work_orders`), 단계별 시각표가 남는다.

## 준비
- RUNBOOK대로 전부 healthy, 결함 시뮬레이션 **전체 초기화**로 시작. 시계·메모.
- 확인에 쓰는 것: 포털 네 탭(결함 시뮬레이션 · 이상 확인 · 조치 · 프로세스 인스턴스 · 실시간 모니터링), Supabase Studio(`ent.work_orders`) 또는 `docker exec supabase_db_hyd-iot-edu psql -U postgres -c "select * from ent.work_orders order by created_at desc limit 1"`.
