# 16. 사람의 작업: 폼 제출과 권한 (4부, 180분: 설명 60 / 실습 90 / 정리 30)

## 이번에 할 것 / 끝나면 보이는 것
버튼 하나가 어디까지 가는지 본다. 운전원 역할로 조치를 고르면 거절(403), 생산관리자로 고르면 명령이 게이트웨이를 통과해 PLC가 응답한다. 정의를 새 버전으로 등록해 폼과 분기가 바뀌는 것도 실습한다.
끝나면 403 1건, ACK DONE 1건, 그리고 같은 입력이 버전마다 다른 결과로 끝난 기록이 남는다.

## 준비
- 포털 **프로세스 인스턴스 → 내 할일**, **결함 시뮬레이션 → 최근 제어 요청 결과**.
- 역할 표: `it/supabase/seed.sql` 66~73행(운전원 operator · 생산관리자 manager · 정비관리자 manager), 승인 권한 코드 `it/process/procsvc/decisions.py`, 선택 API `POST /api/todolist/{id}/select`(`{decision, option, by, role, …}`).
- 정의 변경 실습: `docs/definition-authoring.md`, 예제 `docs/examples/inspection-review-v1.json`·`v2.json`, 포털 **프로세스 인스턴스 → 고급 → 프로세스 정의 등록 · 버전 선택 · 실행**.

## 실행 장면
1. [화면] 쿨러 경보로 "조치 카드 선택" 작업이 열리면 → 역할 **운전원** → 카드 선택 → 제출 → [관찰] 오류 메시지(403, 승인 권한 부족) → [확인] 403 1건. 작업은 그대로 IN_PROGRESS.
2. [화면] 역할 **생산관리자** → 같은 카드(예 "팬 최대 + 부하 80 %", SOP-COOL-02) → **새 예측 검토**(선택) → 제출 → [관찰] 명령 작업이 돌고 **최근 제어 요청 결과**에 `PASS · CMD-…`, HYD-01 카드 "마지막 ACK … DONE" → [확인] ACK DONE 1건, 사건 상태 재관측 중.
3. [관찰] 타이머: 정의의 선택 시간초과는 PT10M(`anomaly_response.json` 133행; 20배속이면 벽시계 30초)이며 **즉석에서 줄이는 화면·API는 없다** → 짧게 보려면 `anomaly_response_v22.json`을 복사해 타이머를 바꾸고 새 버전으로 등록(6~7단계 절차) → 선택하지 않고 기다리면 책임자 호출 작업(화면 표기: task:escalate, 역할 생산관리자)이 열리고 감사에 `SELECT_TIMEOUT`(`instances.py` 652행) → [확인] SELECT_TIMEOUT 1건.
4. [화면] 고급 → 정의 등록: `inspection-review-v1.json` 파일 선택 → **이 정의 버전 등록**(처음이면 201, 같은 버전이 이미 있으면 "이미 등록됨") → `inspection_review @ 1` 선택, 시작 이벤트 ID 새 값, 시작 변수 `{}` → **선택한 정의 버전으로 실행** → [확인] 내 할일에 점수 폼(폼은 정의 버전 안에 고정돼 작업 항목 `GET /api/todolist/{id}`의 `form`으로 온다; `/api/forms/<id>`는 404).
5. [입력] 점수 7 제출 → [관찰] 종료 `accepted`, 변수 `score: 7` → [확인] 버전 1 결과.
6. [화면] `v2.json` 등록 → 새 이벤트 ID로 실행 → 점수 7만 넣으면 400 "필수 폼 필드가 비어 있습니다: note"로 거절, 메모를 채우면 `rejected`(v2 조건은 `score >= 10`) → [확인] 같은 7이 버전에 따라 다른 끝. v1 실행을 다시 열면 버전 1 폼·결과(`accepted`)가 유지된다.
7. [입력] 같은 id/버전에 조건만 고쳐 등록 → 409, 없는 버전 조회 404, 같은 이벤트 ID 재시작 409 → [확인] 세 오류 코드.

## 막혔을 때
- 403이 아니라 통과: 역할 선택이 생산관리자로 돼 있다. 또는 카드 옵션의 승인 역할이 운전원까지 허용(`t3_roles` 표 확인).
- PASS인데 ACK가 없다: 설비가 수동 모드(2회차). `curl 127.0.0.1:8090/api/gateway/log`.
- 정의 등록 400: 지원 범위는 사람 폼 · CLI 에이전트 · 등록된 서비스 도구 · 배타 분기 · 경계 타이머뿐(화면 안내, `definition-authoring.md` "작성 계약"). 게이트웨이 없는 분기는 거부(A115 A6).
