# 실습 가이드

이 문서는 이 폴더에 무엇이 있고 어디서부터 읽을지 알고 싶을 때 읽는다.

HYD 제조 AI 교육과정(경남대학교 피지컬AI 사관학교)의 실습 가이드(핸즈온 가이드)를 두는 곳이다. 이론 덱(`docs/교재/`)은 실습마다 간지와 「무엇을 하고 무엇이 만들어지는지」 한 장만 싣는다. 절차 · 명령어 · 화면은 여기의 가이드가 맡는다.

**가이드는 아직 없다.** 지금 있는 것은 형식뿐이다.

| 파일 | 내용 |
|---|---|
| `틀/실습가이드_틀.html` | 가이드 HTML의 빈 틀. 형식(스타일, 스크립트, 블록 구성)만 있고 본문은 자리표시 글이다. 브라우저로 바로 열린다 |
| `틀/형식.md` | 블록 종류와 클래스 이름, 언제 무엇을 쓰는지, 형식에 관해 정해진 것 |

착수 문서는 `docs/교재/인계/06_실습가이드_착수.md`다. 실습 가이드에 대해 정해진 것, 실습 160건의 목록, 착수 순서, 시작 전에 사용자에게 받아야 할 것이 거기에 있다. 가이드를 쓰기 전에 그 문서를 먼저 읽는다.

스킬은 둘이다. 경로는 저장소 루트 기준이다.

| 스킬 | 내용 |
|---|---|
| `.claude/skills/hyd-lab-guide/SKILL.md` | HYD 실습 가이드의 원칙과 작업 순서(착수 문서와 형식 문서의 요약). 덱의 실습 간지와 설명 장의 번호를 뽑는 `scripts/실습목록.py`가 함께 있다 |
| `.claude/skills/lecture-lab/SKILL.md` | 실습 자료의 일반 절차와 참고 문서(`references/`). HYD 스킬과 부딪치면 HYD 스킬을 따른다 |

스킬과 착수 문서 · 형식 문서가 다르면 문서가 맞다.

지킬 것 셋:

- 실제로 돌려 본 것만 쓴다. 명령어와 출력을 지어내지 않는다.
- 본보기의 형식을 그대로 따른다. 새 디자인을 만들지 않는다.
- 실습 하나를 먼저 만들어 사용자 확인을 받은 뒤 나머지를 만든다.
