# 학생용 포탈 UI/UX 개편 기준

## 사용자 요구와 범위

2026-10-01: 강의에서 학생이 직접 모든 기능을 사용한다. 불만이 많은 초보 사용자도 읽고 조작하고 오류에서 복구할 수 있어야 한다. 예쁜 화면이나 개별 padding 수정만으로 완료하지 않는다.

- 기존 9개 페이지, 실습 제어, 온톨로지 탐색/질의, 매뉴얼 적재, 스킬 편집, 전사 판단, 승인, 시스템 이력을 유지한다.
- L1~L9·MQTT·BPMN 등 학습 개념은 행동과 관찰 결과에 연결한다. 내부 제작 이력(`v3 설계서를 옮겼다`)은 학생 안내와 구분한다.
- 시뮬레이션·기업 시스템 목업·역할 선택 실습이라는 사실을 숨기거나 실운영 인증처럼 표시하지 않는다.
- 기존 실제 API/명령·승인 계약을 유지한다. 데이터나 결과를 보기 좋게 꾸며 만들지 않는다.

## 공통 구조

각 화면은 제목/한 문장 목적 → 직접 할 행동 → 현재 값/결과 → 근거와 심화 탐색 순서로 구성한다. 필요한 화면에만 ‘해보기 / 확인하기’ 안내를 제공한다. 원시 JSON은 심화 관찰로 펼치되 핵심 결과와 오류는 기본 표시한다.

2026-10-01 추가 확정: 발표자료와 대본은 이미 있다. 화면을 발표자료로 만들거나 설명 패널을 계속 추가하지 않는다. 초기 화면의 목적을 기준으로, ‘무엇을 보고 무엇을 할 수 있는가’를 설명하는 문구와 불필요한 제작·구현 설명을 구분한다. 설명을 전부 없애지도 않는다. T1/T2/T3 같은 내부 질의 식별자는 기본 버튼·단계명에서 앞세우지 않고 하는 일을 설명한다. Cypher 원문과 처리 기록은 직접 조회하는 기능에 보존한다. 새로운 내용·조작을 넣기 전에 현재 기능의 이해와 사용에 꼭 필요한지 판단한다.

2026-10-01 후속 요청: 화면을 일일이 찾아 이동하는 불편을 줄인다. 포탈에는 스크롤과 독립된 이전·다음 버튼, 현재 위치, 다음 화면 이름을 표시한다. 메뉴와 순차 이동이 같은 페이지 상태를 사용하며 기존 초안을 유지한다. 작은 화면은 접이식 메뉴를 제공하고, 목록을 선택하면 아래 상세 내용이 보이도록 이동한다. 캡처 모음은 한 창에서 좌우 이동·자동 재생·간격 선택·확대·검색 결과 순회를 제공한다. 포탈을 자동으로 조작하거나 승인하지 않는다.

간격은 4/8/12/16/24/32/48 토큰을 사용한다. 페이지 여백, 패널 안쪽 여백, 입력 높이, 행 간격은 의미별 토큰으로 묶는다. 왼쪽 열의 텍스트 시작선, 제목/설명 간격, 숫자/단위의 읽기 순서를 공통 규칙으로 관리한다. 본문 14~15px, 설명 13px, 주요 값 28~36px를 기준으로 실제 화면에서 검토한다. 작은 보조 글씨로 핵심 정보를 밀어내지 않는다.

## 검증

2026-10-01 전수 검수 추가 기준:

- 공통 padding 숫자만 바꾸지 않고 내용 길이·패널의 실제 폭에 따라 배치를 정한다. 원인·확률·관측 근거와 대안·승인 버튼은 같은 단위로 읽혀야 한다.
- 긴 비교 표는 열 제목과 대안 이름을 유지하며 내부에서 이동한다. 산정하지 않은 값은 실제 0과 구분한다. 기업 원천 값에는 읽을 이름·단위를 붙이고 원문을 보존한다.
- 설비 SVG는 개요와 확대 읽기를 구분한다. FUXA는 화면 전체를 축소해 글자와 입력창을 작게 만들지 않고 설비 카드가 다음 행으로 이동한다.
- 동일 판단/인시던트의 BPMN이 다시 그려져도 읽던 위치와 보기 모드·키보드 포커스를 유지한다. 새 기록을 선택할 때는 그 기록의 시작 위치를 보여 준다.
- 화면 시간은 브라우저 현지 시각으로 표시한다. API의 시간·상태·명령값을 변경하지 않고 표시 이름을 분리한다.
- 캡처는 실제 곡선·표·선택 데이터 렌더가 끝난 뒤 저장한다. 원본 173장과 대응하는 수정 후 173장을 개별 확인하고 번호·관찰·최종 파일 해시를 기록한다. 자동 기하 검사를 시각 검수의 대체 근거로 사용하지 않는다.

실제 Chromium에서 모든 화면, 긴 내용, 상세 펼침, 좁은 폭, 키보드, 연결 실패/복구, 입력 유지, 저장/재조회, 역할 거부/승인/PLC ACK/종결을 검증한다. 기존 숫자 기반 기하 검사는 보조 수단이며 각 화면의 위계와 가독성은 캡처를 직접 읽는다. 모든 사용자·브라우저에 대해 ‘완벽’을 보증하지 않는다.
