# 포탈 세부 UI 점검 (2026-10-01)

## 최신 · 원본 173장 전체 검수와 수정 후 대조 (2026-10-01)

이전 검수는 9개 페이지의 대표 화면 중심이었다. 이번에는 사용자가 지정한 `UIUX_캡처_2026-10-01_120504`의 **173개 원본을 모두 개별 이미지로 직접 확인**했다. 번호별 원본 관찰을 남기고, 수정 후 대응 사진 **173개 전부와 추가 9개**도 직접 읽었다. 173개는 페이지 수가 아니라 폭·스크롤 위치·상세·오류·FUXA를 포함한 기존 사진 집합이다.

- [173장 수정 후 사진](../UIUX_캡처_2026-10-01_173장_검수후/index.html) · [번호별 전후 비교](../UIUX_캡처_2026-10-01_173장_검수후/비교.html) · [추가 9장](../UIUX_캡처_2026-10-01_173장_검수후/추가검증/index.html)
- [173장별 관찰·수정·최종 판정](ui-visual-review-173.md) · [원본/최종 파일 해시](ui-visual-review-173.json)

주요 수정은 공통 데이터 표시·표·승인 카드·목록과 상세 배치·그래프 읽기·SCADA 생성기에 반영했다. 아키텍처의 과한 가로 간격, 좁은 패널의 원인 표, 승인 버튼이 오른쪽 밖으로 밀리는 구조, 영문 데이터 키와 단위 없는 수치, 긴 로그의 잘림, FUXA 전체 축소를 교정했다. 표를 끝까지 이동할 때도 대안 이름과 열 제목을 유지한다. 9개 페이지·실제 조작·온톨로지 영역 간 관계·원본 데이터는 유지했다.

이번 실행 결과는 `.evidence/visual-173/final/`에 고정했다. 단위 **137 통과**(기존 FastAPI 경고 2개), UI 조작 **12/12**, 목적·상세 **8/8**, 결함 회귀 **7/7**, 순차 이동 **36상태** 통과. 데스크톱 **108상태**에서 SVG 글자 겹침·박스 밖 글자·페이지 가로 넘침·조작 가림 후보와 JS 예외가 0이었다. 실제 UI 파이프라인 `INC-1001-21-570e`는 권한 거부 → 생산관리자 팬95/부하70 승인 → PLC ACK DONE → CLOSED까지 완료했다. FUXA 정상 입력·범위 거부·LOCAL 거부·오류 해제·기존 값 복원을 재검증했다.

기하 검사와 직접 시각 검토는 별도 근거다. 로딩 전 빈 Grafana 차트·선택 전 BPMN을 찍던 검사 조건도 수정했다. 마지막 비교 표 고정 열 변경은 해당 12상태와 별도 회귀로 재검증했다. 모든 기능을 마지막 CSS 변경 뒤 다시 시험했다고 세지 않는다. 로컬 Chromium과 모의 설비/기업 시스템 범위이며, 외부 LLM 필수 E2E·GCP·실기기·장시간 운영·학생 이해도는 이번 차수에서 재검증하지 않았다. 기존 단위136·LLM46/46 수치는 아래 이전 기록으로 구분한다.

## 이전 · 화면 목적과 가독성 재검증 (2026-10-01)

사용자는 설명 삭제나 내용 추가가 아니라, 초기 화면의 목적을 살리면서 학생이 이해·조작하기 쉬운 UI를 요구했다. 발표자료·대본은 별도로 있으므로 화면에 같은 설명을 반복하지 않는다. 온톨로지는 설비끼리의 목록이 아니라 고장·조치·매뉴얼·스킬·업무를 잇는 관계를 읽는 화면이다.

| 화면 | 확인한 문제와 수정 |
|---|---|
| 시스템 아키텍처 | 9개 레이어·16개 구성요소 유지. 역할과 구성요소 설명을 정렬하고 중복 안내·‘구현 비교’·‘그림 2 스키마’ 제거. 실제 실행하지 않는 제품명을 현재 구현처럼 보이게 하는 표시 제거. Redpanda 서비스 정상과 별도 Console 화면의 실행 여부를 구분하고, 연결할 수 없는 선택 도구 링크는 비활성화 |
| 온톨로지 | 첫 저장소 커밋 a676a11부터 노드 선택 시 1단계 이웃만 남기고 다른 영역을 흐리게 했다. 현재 API에는 처음 확인 당시 200노드·435관계 및 매뉴얼·스킬 경로가 실제로 있었다. 선택에 따른 간접 관계 감추기 제거, 글자·행 간격 확대, 선택한 선의 방향과 관계 설명 보완. 별도 설명 패널은 추가하지 않음 |
| 온톨로지 오류 | 불러오기 실패 후 탭을 다시 열면 캐시 지도를 정상 화면처럼 그리던 결함 재현. 실패 시 캐시와 옛 상세를 비우고 재진입 시 다시 조회하도록 수정 |
| 첫 화면 | 한글 단어 중간 줄바꿈 보완. 세 단계 설명을 학생 행동 중심으로 정리. 경보 발생이 곧 자동 제어인 것처럼 읽히던 문장을 실제 승인 흐름과 맞춤 |
| 결함 시뮬레이션 | 긴 명령 ID로 카드별 조작 높이가 달라짐 → 결과를 먼저 표시하고 ID는 툴팁에 유지. 결함·모드·수동 조작 구분과 실제 선택 모드 표시. 성능 비율에 % 단위 표시. 명령 거부 사유는 유지 |
| 이상 확인·조치 | 원인·권장 조치를 처리 기록보다 먼저 배치. 처리 기록은 펼쳐 확인하며 원본 출력은 그대로 보존 |
| 실시간 모니터링 | 5개 실제 Grafana 패널, 설비 변경, 유온·경보·조치 시점 표시와 좁은 화면 확인. 새로운 차트나 합성 데이터를 추가하지 않음 |
| 스킬 | name/description/detail 대신 목적 중심 입력명. 규정·조치·사용 대안 표현 보완, 긴 입력을 읽는 글꼴 개선. textarea의 접근 가능한 이름에 입력 내용이 붙던 문제도 수정 |
| 전사 의사결정 | 필수 규정 위반과 평가 불이익을 구분해 표시. 비교 결과 가까이에 승인 화면 이동 배치. 처리 과정은 펼침으로 제공하며 기업 시스템 조회 근거 유지 |
| 업무 프로세스 | 내부 질의 번호 대신 ‘고장 원인 분석’, ‘조치 방법 검토’, ‘제약 검증’ 표시. 전체 흐름/읽기 크기 전환·권한 거부·승인·결과 표시 재확인 |
| 공통 | 한글 줄바꿈, 긴 선택 항목의 flex 최소폭과 최대폭 수정. 모바일에서 긴 시나리오 선택기가 페이지를 넘치게 하던 문제 해결. 기존 9페이지·조회 9종·매뉴얼·스킬·승인 기능 유지 |

## 이전 · 학생용 디자인과 화면 이동 개편 (2026-10-01)

기존 9개 페이지와 실습 기능을 유지하면서 공통 디자인·안내·상태 표시를 개편했다. 이전 절의 “기존 디자인 유지”는 당시 작업 범위이며, 현재 요구는 세련된 교육용 포탈로의 개편이다. [설계 기준](ui-design-contract.md).

| 전체 UI의 일관성 | `tokens.css`에 의미별 여백·색·모서리·입력 높이 정의. 흰색 메뉴, 아이콘, 현재 위치, 제목·설명·카드·폼·표를 같은 규칙으로 구성. 외부 글꼴 다운로드 의존 제거 |

발견 후 교정: 최초 회귀 10/11은 화면 아래의 Grafana 패널이 아직 렌더되지 않은 상태를 검사한 문제였다. 스크롤로 각 차트를 실제로 보여 준 뒤 기존 내용 검사를 수행하도록 수정해 11/11을 확인했다. 초기 작은 화면 검사에서 820/768 온톨로지, 390 실행 결과의 넘침을 발견해 공통 grid 최소폭과 표 스크롤 구조를 교정했다. 기능을 삭제하거나 가로 넘침을 body 숨김으로 덮지 않았다.

검증 환경은 로컬 Chromium과 시뮬레이터다. 작은 화면 에뮬레이션은 실제 휴대기기·터치·스크린리더 완주 검증과 다르다. 모든 입력/브라우저 조합, 실제 PLC/ERP/GCP, 장시간 부하를 보증하지 않는다. 백엔드 단위136·LLM46/46은 이전 검증 근거이며 이번에 재실행한 것으로 세지 않는다. 테스트 판단·감사·매뉴얼 이력은 남는다.

재실행: `scripts/ui_regression.py`, `scripts/ui_pipeline.py`, `scripts/ui_fuxa.py`는 시뮬레이터를 바꾸므로 순서대로 실행한다. `scripts/ui_navigation.py <캡처 폴더>`는 초안과 판단 계산을 사용하며 승인/설비 제어는 하지 않는다. `scripts/ui_gallery.py <캡처 폴더>`는 목록 JSON을 읽어 뷰어만 갱신한다.

[스크립트](../scripts/ui_regression.py), [로그](../.evidence/ui-review/run.log), [결과](../.evidence/ui-review/results.json).
- **실제 UI 파이프라인 완주**: 결함 주입 → 새 인시던트 `INC-0930-05-0901` → 운전원 거부 → 생산관리자로 팬 95%·부하 70% 승인 → 요청 본문 일치 → PLC ACK DONE → CLOSED. [스크립트](../scripts/ui_pipeline.py), [기록](../.evidence/ui-review/pipeline.json), [종결 화면](../.evidence/ui-review/pipeline-closed.png), [영상 폴더](../.evidence/ui-review/pipeline-video/).
- **FUXA 실제 조작**: 모드 전환, 팬 80 입력·적용, 150 범위 거부, LOCAL에서 명령 거부, 다시 정상 입력 후 이전 오류 사라짐, 3개 화면 폭. 팬 값·모드는 시험 전 값으로 복원. [스크립트](../scripts/ui_fuxa.py), [기록](../.evidence/ui-review/fuxa.json), [로그](../.evidence/ui-review/fuxa.log).

## 재실행과 경계

```powershell
.venv/Scripts/python scripts/ui_regression.py
.venv/Scripts/python scripts/ui_pipeline.py
.venv/Scripts/python scripts/ui_fuxa.py
.venv/Scripts/python scripts/scenario_test.py --quick --require-llm
```

동시에 실행하지 않는다. 시뮬레이터 상태를 초기화하고 테스트 판단·감사·매뉴얼 이력 등을 남긴다. 스킬 내용과 FUXA 설정값은 복원한다. 브라우저는 Chromium이며 Playwright Chromium 설치와 실행 중인 로컬 Compose가 필요하다. FUXA 프로젝트 변경은 `python ot/fuxa/build_project.py` 후 `docker compose run --rm --no-deps fuxa-init`으로 반영한다. MQTT 표시 필드 변경은 plant-sim 재빌드가 필요하다.

화면의 배치·색 체계·탭 순서·승인 절차를 재설계하지 않았다. 모든 해상도·브라우저·키보드/보조기기 조합 또는 모든 입력값의 전수 검증은 아니다. 모바일은 검증 범위가 아니다. 시간 표시는 일부 기존 UTC 기록 방식을 유지한다. 로컬 시뮬레이터와 기업 시스템 목업의 반복 실행 근거이며, 다시간 부하·실제 PLC/ERP·GCP LiteLLM 운영 안정성을 보증하지 않는다.
