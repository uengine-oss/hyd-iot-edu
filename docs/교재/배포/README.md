# 교재 배포용 묶음

`교재_전체.zip` 하나에 과정별 폴더로 PPTX만 모았다. 원고(덱 MD)와 그림은 과정 폴더에 있다.

| zip 안의 폴더 | 내용 |
|---|---|
| `통합반_온라인/` | 통합반 온라인 1~11일차 PPTX 11개 |
| `실전반_온라인/` | 실전반 온라인 1~8일차 PPTX 8개 |
| `통합반_오프라인/` | 통합반 오프라인 1~10회차 PPTX 10개 |
| `실전반_오프라인/` | 실전반 오프라인 1~9회차 PPTX 9개 |

덱을 고쳐 PPTX를 다시 빌드하면 이 묶음도 다시 만든다(과정 폴더의 PPTX를 그대로 묶은 것이다).
