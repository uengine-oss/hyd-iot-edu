## SLIDE [N6] — 실습에서 더하는 지침과 보완되는 작업 목록
### 화면 내용
- 유형: 카드
- 아이콘: users, calendar-off, copy, alert-triangle
- 메시지: 예외를 다루는 지침이 스킬에 적혀 있어야, 조건이 겹친 회의록에서도 실행할 때마다 같은 모양의 작업 목록이 나온다.
- 요소:
  1. 담당자 중복 | 한 작업에 담당자가 여럿 적힌 경우의 처리 기준을 적는다 | 담당자
  2. 기한 미정 | 앞 실습의 미정 표시가 다른 조건과 겹친 작업에도 같게 적용되도록 기준을 적는다 | 기한
  3. 기존 작업과의 중복 | 이미 있는 작업과 겹치는 항목을 가려 다시 만들지 않는다 | 중복
  4. **도구 접근 실패** | 도구가 실패하면 확인하지 못한 작업을 미확정으로 표시하고 결과를 보완한다 | 미확정
- 노트: 넷째 실습에서는 앞 실습의 스킬에 예외 지침을 더합니다. 한 작업에 담당자가 겹쳐 적힌 경우, 기한이 정해지지 않은 채 다른 조건과 겹친 경우, 기존 작업과 겹치는 경우를 어떻게 처리할지를 스킬에 적습니다. 도구에 접근하지 못했을 때에는 확인하지 못한 작업을 미확정으로 표시하게 합니다. 끝나면 조건이 겹친 회의록에서도 같은 기준으로 만들어진 작업 목록이 남습니다.
### 제작 기준
오프라인 5회차 실라버스의 실습 「복합 조건에서도 일관된 결과 만들기」(담당자 중복 · 기한 미정 · 기존 작업과의 중복을 처리하는 지침, 도구 접근 실패 시 미확정 작업의 표시와 결과 보완)다. 통합반에 같은 실습이 없어 새로 썼다. 실패를 값 없음과 구분해 적는 기준은 본문의 「값이 없는 것, 실패한 것, 잘린 것의 구분」 장이 세운다.
