- 메시지: 요소를 놓고 잇기, 속성 읽기, 파일로 남기기를 익히면 다시 열어도 같은 그림이 나오는 .bpmn 파일 하나가 만들어진다.
- 요소:

  3. 파일로 남긴다 | 그림을 .bpmn 파일로 저장하고 다시 열어 같은 그림인지 확인한다 | 저장
  4. **만들어지는 것** | 직접 놓고 이은 요소가 담긴 .bpmn 파일 하나 | 결과물
- 노트: 이 실습에서는 BPMN 그림을 그리는 도구인 bpmn.io로 세 가지를 익힙니다. 앞에서 읽은 이벤트, 작업, 게이트웨이를 그림에 놓고 시퀀스 흐름으로 잇는 것, 놓은 요소의 속성을 읽는 것, 그림을 .bpmn 파일로 남기는 것입니다. 끝나면 직접 그린 그림이 담긴 .bpmn 파일 하나가 만들어지고, 다시 열면 같은 그림이 나옵니다. 이어지는 실습에서 그리는 프로세스도 이 형식의 파일로 남습니다.
