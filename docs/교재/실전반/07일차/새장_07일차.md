## SLIDE [N4] — Quiz 2. 승인 블록을 다시 쓸 때 바뀌는 자리
### 화면 내용
- 유형: 문답
- 메시지: 긴급 대응 프로세스의 승인 블록을 가져와 재고 보충 프로세스를 그리려 한다.
- 문장: 승인 블록에서 재고 보충에 맞게 바꾸는 것은?
- 요소:
  1. 승인 지연 타이머의 기한 10분
  2. 승인과 거절을 가르는 게이트웨이의 조건
  3. 거절했을 때 닿는 끝 이벤트
  4. 승인 역할과 승인 뒤에 이어지는 첫 작업
- 노트: 설계에서 그대로 두는 것과 바꾸는 것을 구분하는 문항입니다. 승인 블록의 요소와 기한과 조건 가운데 세 프로세스에서 같았던 것이 무엇이고, 바뀐 자리가 어디였는지를 떠올려 보시기 바랍니다.
### 제작 기준
승인 블록의 요소 일곱 · 기한 10분 · 조건 `approval == '승인'`이 세 흐름에서 같고, 다른 것은 승인자 역할과 승인 뒤 첫 단계뿐이다: 사실표 3.1 끝 · 5.1.5 표. 본문의 「승인 블록: 같은 일곱 요소와 바뀌는 두 자리」 · 「구조로 남기는 것과 값으로 정하는 것」 장으로 풀린다. 통합반 10일차의 Quiz 2(병목)는 이 일차가 병목을 다루지 않아 가져오지 않았고, 실전반 6일차의 문항과 겹치지 않게 새로 썼다.
