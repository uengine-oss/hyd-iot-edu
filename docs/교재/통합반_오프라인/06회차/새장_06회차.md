## SLIDE [N3] — 실습에서 잇는 도구와 완성되는 업무 항목
### 화면 내용
- 유형: 흐름
- 아이콘: file-text, git-compare, list-check, alert-triangle
- 메시지: 이 실습을 마치면 한 요청으로 만들어 저장한 업무 항목과, 도구가 실패했을 때 미완료로 표시한 항목의 기록이 남는다.
- 요소:
  1. 회의록을 읽는다 | 파일시스템 서버의 도구로 / 회의록 파일을 읽는다
  2. 변경을 확인한다 | Git 서버의 도구로 / 바뀐 자료를 확인한다
  3. **업무 항목을 만든다** | 회의록 스킬로 / 업무 항목을 만들어 / 저장한다
  4. 실패를 표시한다 | 도구가 실패한 항목은 / 미완료로 표시하고 / 고친 뒤 다시 실행한다
- 노트: 넷째 실습에서는 앞의 두 실습에서 연결한 서버와 직접 쓴 스킬을 한 요청으로 잇습니다. 회의록 파일을 읽고, Git에서 바뀐 자료를 확인하고, 업무 항목을 만들어 저장하는 데까지가 한 번의 요청입니다. 도중에 도구 호출이 실패하면 그 항목을 채우지 않고 미완료로 표시합니다. 원인을 고친 뒤 다시 실행해 미완료 항목이 채워지는 것까지 확인합니다.
### 화면 구성
네 칸 흐름. 셋째 칸 강조.
### 제작 기준
오프라인 06회차 실라버스의 넷째 실습 상세(「회의록 파일 읽기 → Git으로 변경된 자료 확인 → 업무 항목 생성 · 저장까지 한 요청으로 연결한다. 실제 도구 실패 시 미완료 항목을 표시하고 수정 후 재실행한다」)에서 하는 일 네 칸과 남는 것만 뽑았다. 실패를 빈 값으로 바꾸지 않는다는 원칙은 본문의 「값이 없는 것, 실패한 것, 잘린 것의 구분」 장이 받친다.
