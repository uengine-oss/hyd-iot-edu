# 완성 덱의 화면 확인 (고치지 않는다)

> 자리표시: `<저장소>`는 저장소 루트, `<작업 폴더>`는 저장소 밖의 임시 작업 폴더(본문의 「scratchpad」)다. 이 지시문이 쓰이는 단계는 같은 폴더의 `README.md`에 있다.

HYD 제조 AI 교육과정의 완성된 PPTX 덱을 전 장 눈으로 보고 **화면의 결함만** 찾는다. 내용 · 화법 검토는 이미 끝났다. 덱을 만든 작업자들이 검토 반영 뒤 고친 장만 다시 보았기 때문에, 최종본 전 장을 본 사람이 없다. 그 빈틈을 메우는 일이다.

저장소: `<저장소>`. scratchpad: `<작업 폴더>/화면확인/`

## 하는 법
덱마다(프롬프트가 알려 주는 목록):
1. 렌더: `cd <저장소> && uv run --no-project --with python-pptx --with pymupdf python .claude/skills/lecture-deck/scripts/deck2pptx.py <덱.md> <scratchpad/화면확인/이름.pptx> --render <scratchpad/화면확인/이름_r>` — **출력 PPTX는 반드시 scratchpad로**(저장소의 PPTX를 덮어쓰지 않는다). 렌더는 다른 작업과 차례로 돈다(기다린다. soffice를 죽이지 않는다).
2. 묶음: `uv run --no-project --with pillow python docs/교재/도구/시트.py <렌더 폴더> <scratchpad/화면확인/이름_sheet> --cols 3 --per 9` 로 9장 묶음을 만들어 **전부** 본다. 의심스러운 장은 원본 PNG를 따로 열어 확인한다.
3. 볼 것: 글자 넘침(상자 · 화면 밖으로 나감), 겹침(라벨끼리, 라벨과 그림, 글과 꼬리표), 잘린 글자, 읽기 어렵게 작은 글자, 그림이 깨지거나 비어 있음(그림 경로가 틀려 안 나옴), 화면의 절반 넘게 빈 장, 비스듬하거나 엉뚱한 곳을 가리키는 화살표, 관계도의 선이 글자를 가로지름, 코드 상자 아래가 잘림, 한글이 네모로 깨짐.
4. 보지 않는 것: 내용, 문장, 분량, 취향(여백이 조금 남는다, 글자가 조금 작다 정도는 적지 않는다).

## 산출물
scratchpad `화면확인/결과_<프롬프트가 주는 이름>.md`: 덱마다 `장 번호 | 제목 | 결함 | 심각도(상: 읽을 수 없거나 틀리게 보임 / 중: 눈에 거슬림)`. 결함이 없으면 「없음」. 못 본 장이 있으면 번호로 적는다.

## 지킬 것
저장소의 파일을 하나도 고치지 않는다. 커밋하지 않는다. 서브에이전트를 쓰지 않는다. 보고는 짧게: 덱별 결함 수와 「상」 전부.
