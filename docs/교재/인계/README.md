# 교재 인계 묶음

이 문서는 교재 작업을 처음 이어받은 세션이, 어느 문서부터 읽을지 고를 때 읽는다.

HYD 제조 AI 교육과정(경남대학교 피지컬AI 사관학교)의 이론 교재(PPTX 덱)를 만든 세션이 남긴 인계 문서다. 이 저장소만 있으면 이어서 할 수 있게 썼다. 그 세션의 작업 공간, 임시 폴더, 대화 기억은 남아 있지 않다고 전제한다.

## 처음 온 세션이 가장 먼저 할 일

1. 저장소 루트의 `CLAUDE.md`와 `docs/handoff/NOW.md`의 1절 「교재(슬라이드)」 줄, 4.7절 「교재 남은 일」을 읽는다.
2. 이 폴더의 `01_현황.md`를 읽어 지금 있는 것과 확인의 한계를 안다.
3. 아래 표에서 할 일에 맞는 문서를 고른다. 실습 가이드를 쓰러 왔다면 `06_실습가이드_착수.md`다.
4. 할 일에 맞는 스킬을 읽는다. 덱이면 `.claude/skills/hyd-course-deck/SKILL.md`, 실습 가이드면 `.claude/skills/hyd-lab-guide/SKILL.md`다. 스킬은 이 묶음의 순서와 명령을 요약한 것이고 도구(`scripts/`)가 함께 있다. 스킬과 이 묶음이 다르면 이 묶음이, 이 묶음과 제작 기준이 다르면 제작 기준이 맞다. 스킬 전체의 목록은 `.claude/skills/README.md`다.
5. 덱이나 기준 문서를 고치기 전에 `docs/교재/기준/제작기준.md`를 전체 읽는다. 규칙은 거기에만 있고 이 묶음은 규칙을 되풀이하지 않는다.
6. 커밋하기 전에 `02_덱_고치는_법.md` (라)절을 읽는다. 같은 브랜치에서 다른 세션이 포털과 기능을 고치고 있다.

## 이 묶음의 파일

| 파일 | 내용 |
|---|---|
| `01_현황.md` | 지금 있는 덱과 장수, 폴더, 원 덱과 조립 덱의 관계, 배포 묶음, 점검 이력, 확인의 한계 |
| `02_덱_고치는_법.md` | 한 장 고치기, 원 덱을 고친 뒤 따라오는 일, 도구의 제약, 커밋 규칙 |
| `03_덱_만드는_법.md` | 새 덱을 만드는 흐름, 전체 점검의 흐름, 실라버스가 바뀌었을 때, 배운 것 |
| `04_결정_기록.md` | 사용자가 정한 것과 그 까닭 |
| `05_남은_일.md` | 결정 대기, 확인하지 못한 것, 덱에 남은 흠, 하지 않은 일, 이 묶음을 쓴 뒤에 끝난 두 가지의 결과 |
| `06_실습가이드_착수.md` | 실습 가이드에 대해 정해진 것, 실습 전체 목록, 착수 순서, 시작 전에 받을 것 |
| `07_대본_영상_랩.md` | 낭독 대본과 윤문본, 강의 영상의 설정과 도구, 오프라인 랩 아홉 묶음의 상태, 다음에 할 일 |
| `지시문/` | 작업자에게 준 지시문 열다섯 개와 안내 |

이 묶음 밖에서 함께 쓰는 것:

| 어디 | 내용 |
|---|---|
| `.claude/skills/hyd-course-deck/` | 덱을 만들고 고치는 절차의 요약(`SKILL.md`)과 도구(`scripts/재조립.py`, `장수.py`, `배포묶음.py`) |
| `.claude/skills/hyd-lab-guide/` | 실습 가이드의 원칙과 작업 순서의 요약(`SKILL.md`)과 도구(`scripts/실습목록.py`) |
| `.claude/skills/lecture-deck/`, `.claude/skills/lecture-lab/` | 덱 MD → PPTX 도구와 형식 문서, 실습 자료의 일반 절차 |
| `docs/실습가이드/` | 실습 가이드의 틀과 형식 문서(가이드 본문은 아직 없다) |
| `lab/` | 오프라인 수업의 핸즈온 랩 묶음(시작 폴더 · 완성본 · 가이드), 만드는 기준, 가이드를 만드는 스크립트 |
| `video_lecture/` | 대본을 윤문하고 강의 영상을 만드는 스크립트 |

## 문서 사이의 약속

- 규칙은 `docs/교재/기준/제작기준.md`, 폴더 안내와 대응표는 `docs/교재/README.md`, 도구의 형식은 `.claude/skills/lecture-deck/`에 있다. 이 묶음은 그것을 가리키고, 거기에 없는 것만 적는다.
- 이 묶음에서 「조율자」는 작업을 나눠 주고 결과를 합친 세션(지금은 이 묶음을 읽는 세션), 「작업 폴더」는 저장소 밖의 임시 폴더, 「원 덱」은 통합반 온라인 덱, 「조립 덱」은 거기서 장을 가져와 만든 나머지 27개 덱이다.
- 숫자는 덱 MD에서 센 값이다. 덱을 고치면 `01_현황.md` 1절과 제작 기준 13절 · `docs/교재/README.md` 머리 문단 · `docs/handoff/NOW.md` 1절의 장수를 함께 맞춘다(`02_덱_고치는_법.md` (나) 6).
- 이 묶음도 낡는다. 문서의 말과 저장소의 실제가 다르면 저장소가 맞다. 다른 것을 찾으면 문서를 고친다.
