## 2. 운영 구성

- **배포:** 별도 강사 서버 없이 각 PC 이미지 + 마지막 날 강사 해제 코드([2_기준 「PC 이미지 배포와 강사 해제 코드」](2_기준.md#2026-10-27-최신-확정--pc-이미지-배포와-강사-해제-코드)). 공식 갱신 경로는 기존 폴더 `git pull`(또는 GitHub ZIP) → `시작.bat`. 켜는 법은 [4_켜고_돌리는_법](4_켜고_돌리는_법.md).
- **해제:** 강사 코드는 서명 검증·재시작 때 재검증, 이미지에는 공개키만. 해제 증명 서버는 컨테이너 내부 8081(공개 8080 `/internal/course-access`는 404). 강사 비밀키·코드 파일은 제작 PC `work/course-access-private/`(Git·Docker 제외)와 전달용 사본(옛3:158~162).
- **시작 스크립트:** 다른 폴더 설치와 Compose·Supabase 이름 자동 분리, 주인 없는 볼륨은 재사용하지 않음, 모호하면 멈춤(`scripts/prepare_ports.py`). 업무 DB 새 마이그레이션 적용, 수업 흐름 A/B/C·기본 지식 최초 1회, 중계 연결 확인. 프로젝트 `.env`의 중계 주소·키·모델을 저장소 `course/labs/offline/05-2-cause-agent`에 전달.
- **공통 적용기:** `scripts/apply_classroom_package.ps1` — 바뀌는 기존 파일 백업, 예외 시 원복, 기존 `.env`는 건너뜀.
- **키:** agent 컨테이너와 학생 워커에는 원본 키를 전달하지 않는다. 원본 키는 `.env`와 process에 있어 학생 직접 호출 우회는 막히지 않는다(결정상 수용, [2_기준](2_기준.md)·5_결정). 키 정책 조회(2026-10-27): 누적 USD 4.71428308, 만료 2026-11-22 22:56:40 UTC.
- **워커:** Claude Code CLI 컨테이너 1개 → 중계 `coding`, MCP 스키마 미리 전달(`ENABLE_TOOL_SEARCH=false`). Node.js 24.22.1(22.x·26.x 거부).
- **지식:** 제공 문서 4종(HM-8/PM-02/PR-07/HI-01) 강사 서명 캐시 `common/hydcommon/course_extractions.json`, 추출 정의 2.18. 교대 BPMN·매핑 `it/process/definitions/shift_handover.bpmn`·`.mapping.json`.
- **선택형 강사 관리 서버**(`classroom_*`, `compose.classroom.yaml`): 코드만 있고 운영 비활성(`agent_enabled` 기본 False, `HYD_CLASSROOM_AUTHORITY_ENABLED` 미지정). 필수 대상 아님.
- **실라버스:** 정본 `문서/교재/실라버스/피지컬AI_실라버스_최종본.xlsx` SHA-256 `01db4758…1ddc`(커밋 `48e73c7f` 이후). 시스템은 학생 포털 동선만 담당하고 VS Code 랩은 교재 작업.
- **의도적으로 남긴 것:** 질문 기록 연결용 시험 에이전트, 꺼진 학생 MCP 서버 구성 불러오기는 통째 되돌림, 추출 결과 버리기 버튼 없음, A 카드 예측 유효시간 시뮬 30분(실제 약 90초, 사용자 승인).
