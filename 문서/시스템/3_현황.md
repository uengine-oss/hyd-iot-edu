- **Windows 설치 · 실행 더블클릭.** `설치.bat`(→ `scripts/install_windows.ps1`): 학교 설치 목록 xlsx(2026-10-12)의 1~6번을 확인하고 없는 것만 그 목록의 판(Docker 4.87.0 · WSL 2.7.12 · VS Code 1.140.0 · Python 3.14.7 · Node.js 22.16.0 · Git 최신)으로 winget 설치한다(패키지 ID와 판이 microsoft/winget-pkgs에 있음을 확인). 이미 있는 판이 다르면 「다른 판」으로 알리고 바꾸지 않는다. Arduino IDE는 빼고 XG5000은 직접 설치한다. 복제 대비: `docker-users`에 Authenticated Users도 넣고, 공용 폴더(`C:\hyd-iot-edu`)의 저장소에 모든 계정 쓰기 권한 · Git `safe.directory`(system)를 준다(Linux PowerShell 7에서 경로 판정 · safe.directory 중복 방지만 시험). BIOS 가상화 확인, 학생 계정의 `docker-users` 그룹 추가. `시작.bat`: Docker Desktop이 꺼져 있으면 켜고 3분까지 기다린다. 검증 범위: PowerShell 7 문법 검사, 버전 확인 함수 여섯 경우, 1단계 Docker 자동 켜기 네 경우(가짜 docker). **Windows에서 실제로 돌려 보지 않았다.**
