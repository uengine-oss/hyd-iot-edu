# 세 원문 검토 기록

검토자는 **사용자 위임 Codex**다. 사람의 직접 검토나 특정 직원의 승인을 주장하지 않는다. 각 JSON은 `scripts/c3_ingest.py commit <문서> --review <파일>`이 받는 문서별 명시 검토 기록이며, 실제 완료된 추출의 식별자와 경고 확인·변경 사유·원문 인용을 갖는다. 실행 단계의 별도 승인 권한은 부여하지 않는다.

- HM-8 검토: 정확한 팬 절차 재참조, 다른 번호·권한의 조치 참고 보관, 회복 판정 원문 복원. 검토 기록 파일은 저장소에 올라오지 않았다(2026-10-23 확인: git 이력 전체에 없음).
- [PM-02 검토](PM-02.review.json): PLC 명령 추정 제외, 현장 패키지 참고 보관, 기존 오더 일정 변경, 명시 적용 범위·패키지·포함 부품, 실제 생산 오더 손실 조건.
- [PR-07 검토](PR-07-comparison.review.json): 실제 부품 범위와 순정·저가 승인·전체 최단 후 승인 여부 검사 정책, 원문 규칙 보존.

검토 기록이 있다는 사실만으로 실제 적재나 실행 성공을 뜻하지 않는다. 최신 독립 감사에서는 원문 좌표156개·검토 인용43개를 대조했고, 원래 추출 방식과 세대 연결을 보존했다. 실제 적재 영수증·현재 실행 가능 여부·실제 처리 결과는 [진행 기록](../delegated-completion-progress.md)과 [독립 감사](../final-delegated-review-independent-audit.md)에 별도로 기록한다. 운영 재고의 미등록 값을 만들지 않는다.
