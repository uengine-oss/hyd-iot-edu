## 재개 순서와 근거

1. 실제 Git 상태와 위 미커밋 102파일·보존 manifest를 확인해 새 시작 근거를 남긴다. 이론을 재검토하지 않는다.
2. 5·6회차의 기존 근거인 `근거/2026-10-19_05회차_두과정_내용검토.md`, `근거/2026-10-19_06회차_두과정_내용검토.md`를 활용해 이미 확인한 원문과 최신 적용·응용 기준의 미확인을 구분한다. 실라버스·구성표·원본 대응으로 같은 주제의 두 과정 배정을 찾는다. 같은 회차 번호가 같은 주제라고 가정하지 않는다.
3. 필요한 랩·입력·코드·시작본·참조본·가이드·실습 대본의 미확인 내용은 전체 맥락으로 읽고 실제 결함을 수정한다. 키워드·파일 개수·구문 검사만으로 내용 완료를 선언하지 않는다.
4. 이후 통합반7–11·실전반7–8의 미완료 실습을 주제 대응에 맞춰 진행한다. 이미 반영한 공통 수정은 근거를 재사용하되 전체 회차 완료로 간주하지 않는다. 통합10↔실전7, 통합11↔실전8은 공통 기반이다. 통합7·8과 실전5 등은 실라버스·원본 대응을 확인한다.
