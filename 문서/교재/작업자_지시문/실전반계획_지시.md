# 실전반 덱 계획 세우기 (읽기 단계 · 아무것도 고치지 않는다)

> 자리표시: `<저장소>`는 저장소 루트, `<작업 폴더>`는 저장소 밖의 임시 작업 폴더(본문의 「scratchpad」)다. 이 지시문이 쓰이는 단계는 같은 폴더의 `README.md`에 있다.

## 배경
HYD 제조 AI 교육과정에는 통합반(11일)과 실전반(8일)이 있다. 통합반 1~4일차 이론 교재(PPTX 덱)는 완성돼 있다. 실전반 2·3일차는 **통합반 2~4일차와 같은 주제를 절반쯤의 시간에** 다룬다. 실전반 덱을 새로 쓰지 않고 **통합반 덱에서 장을 골라 가져오고, 꼭 필요한 곳만 합쳐서** 만든다. 같은 일을 두 번 하지 않는 것이 원칙이다.

너는 **계획표만** 만든다. 다음 단계에서 스크립트가 「그대로 가져올 장」을 통합반 원고에서 뽑아 붙이고, 다른 작업자(Opus)가 「새로 쓸 장」만 쓴다. 그러므로 계획표는 기계가 읽을 수 있을 만큼 정확해야 한다(장을 가리킬 때 **일차와 장 번호와 제목**을 함께 적는다).

## 원칙
- **그대로 가져오는 것이 기본이다.** 통합반의 장이 그대로 쓸 수 있으면 `가져옴`으로 둔다(한 글자도 바꾸지 않는다). 새로 쓰는 장은 시간 때문에 여러 장을 한 장으로 줄여야 하는 곳에만 둔다. 새로 쓰는 장이 적을수록 좋은 계획이다.
- **핵심 내용과 전체 흐름을 지킨다.** 실전반 실라버스의 상세 교육 내용에 적힌 항목은 모두 다뤄져야 한다. 단원 안의 흐름(필요 → 개념 → 적용)과 통합반과 같은 사건(HYD-01 쿨러)의 이어짐을 지킨다. 줄이는 것은 깊이와 예의 수이지 주제가 아니다.
- **분량**: 단원의 이론 본문 장수 = 실라버스 분 수 ÷ 1.5 (±15 %). 시간 안에 다 설명할 수 있어야 한다.
- **줄이는 순서**: ① 같은 개념의 둘째 · 셋째 예 ② 구분 연습과 흔한 실수 ③ 한 그림의 단계 장 ④ 실라버스 상세에 없는 세부. 정의 · 영어 풀네임 · 핵심 값은 남긴다.
- 실습은 실습마다 2장(간지 「실습: 제목」 + 무엇을 하고 무엇이 만들어지는지 1장). 통합반에 같은 실습의 설명 장이 있으면 가져오고(실전반 실라버스의 실습 내용과 맞는지 확인), 다르면 새로 쓸 장으로 적는다.
- 틀: 표지(과정 `실전반 N일차`) → 학습목표 → 목차 → [간지 → 본문]… → 용어 정리 → 퀴즈 간지 → 퀴즈 3문항 → 정답. 표지 · 학습목표 · 목차 · 단원 간지 · 용어 정리 · 정답은 실전반 구성에 맞게 새로 써야 한다(새로 쓸 장으로 적는다). 퀴즈 문항은 통합반 것 가운데 실전반 내용으로 풀리는 것을 골라 가져온다.
- **일차를 가리키는 말을 조심한다.** 통합반 장 안의 「2일차의 결과물」「지난 시간」 같은 말은 실전반의 일차 구성과 다를 수 있다. 그런 말이 화면이나 노트에 든 장은 `가져옴·손질`로 표시하고 무엇을 무엇으로 바꿀지 적는다(실전반: 1일차 = 통합반 1일차와 같음 / 2일차 = 클래스 · 스키마 · 그래프 DB · 절차와 판단 조건 / 3일차 = 성과 평가 · 인제스천 · 전체 정리).
- 그림은 통합반의 그림 파일을 그대로 쓴다. 새 그림은 없다.

### (1) 단원 표
`단원(실전반 제목, 기술적 제목으로) | 실라버스 분 | 목표 본문 장수 | 계획 본문 장수 | 원천(통합반 몇 일차 어느 단원)`

### (2) 장 순서표 — 실전반 덱의 모든 장을 순서대로 한 줄씩
`순번 | 처리 | 원천(통합반 일차-장 번호 「제목」) 또는 새 장 ID | 메모`
- 처리: `가져옴` / `가져옴·손질`(바꿀 문구를 메모에) / `새로`(새 장 ID `N1`, `N2`…)
- 통합반 원고의 장 번호와 제목을 정확히 옮긴다(스크립트가 이 표로 장을 찾는다).

### (3) 새로 쓸 장 명세 — `새로`인 장마다
```
[N3] 제목(기술적 제목)
- 자리: 표지 / 학습목표 / 목차 / 간지 / 본문(필요 · 개념 · 견줌 · 적용 · 정리) / 실습 설명 / 용어 정리 / 정답
- 합치는 통합반 장: 3일차-07 「…」, 3일차-08 「…」 (없으면 「없음」)
- 유형: (카드 · 비교 · 흐름 · 단계 · 풀이 · 표 · 삽화 · 그림 · 관계도 · 파이프라인 · 코드 · 강조 가운데. 요소 수 한도는 `.claude/skills/lecture-deck/references/덱MD-PPTX형식.md`)
- 그림: 통합반의 기존 그림 파일(일차와 파일 이름) 또는 「없음」
- 화면에 반드시 남을 것: 용어(영문) · 정의 · 값 · 식별자
- 메시지가 말할 쓸모: (한 줄)
- 노트에 적을 짚는 순서
```

### (4) 가져오지 않는 통합반 장 — 단원별로 번호만 나열하고, 그 가운데 「빼기 아까운 장」이 있으면 이유와 함께 적는다.

### (5) 실라버스 대조 — 자기 일차의 이론 행 상세 교육 내용의 항목마다 어느 순번의 장이 다루는지. 없으면 계획을 고친다.

### (6) 위험한 곳 — 흐름이 끊길 수 있는 자리, 시간이 모자랄 것 같은 단원, 통합반과 실전반의 실습 내용이 달라 설명 장을 그대로 못 쓰는 곳.
