# 교재 제작·검토 작업 순서

1. [공통 기준](2_기준.md)과 [작업 상태](작업상태.md)에서 범위·판본·미완료를 확인한다. 상세 읽기와 근거 재사용은 공통 기준을 따른다.
2. 제작 시 [덱과 이론 대본](기준_덱과이론대본.md) 또는 [실습과 랩](기준_실습과랩.md)을 적용한다. 변경 이유와 원문 대응을 남긴다.
3. [검증과 마감](검증과마감.md)에 따라 전체 내용 확인, 수정, 동기화, 화면·정적 검사, 게시를 구별한다. 확정 내용을 반복 검토하지 않는다.
4. 덱 MD는 `제작용/온라인/decks/`, 회차 구성은 `제작용/구성/`에서 관리한다. 이론·실습 대본과 PPTX·랩·HTML은 `산출물/{과정}/{이론,실습}/NN회차`의 한 정본을 직접 갱신한다.
5. 변경 화면은 기존 디자인 토큰으로 만들고 PowerPoint에서 PNG로 직접 확인한다. PDF와 실제 실습은 실행하지 않는다.
6. 회차 산출물이 끝나면 경로를 지정해 커밋·푸시하고 원격을 확인한 뒤 다음 회차로 진행한다.

기존 방법서의 상세 제작·동기화·검증 절차는 담당 상세 문서로 이동했으며, [분리 대응 기록](근거/2026-10-19_기준분리_대응.json)에 이전 위치를 보존했다.
