처음 관련 작업을 맡을 때는 해당 행의 상세 기준을 읽는다. 동일 판본을 읽은 기록과 적용 근거가 있으면 재사용하고, 새 변경·근거 부족 범위만 확인한다. 작업 종류를 고르는 것이 관련 기준의 누락·의존성 생략을 허용하는 것은 아니다. 실습 보류 요청 중 이론 작업을 한다면 실습 제작·실행을 시작하지 않고 필요한 연결 사실만 참조한다.

## 한 번의 작업과 완료 기록

1. 작업 대상·종료 범위와 기존 완료 근거를 정한다. 확정 상태는 추측으로 변경하지 않는다.
2. 적용 기준의 항목별로 해당 산출물·위치와 확인 결과를 기록한다. 기존 마감 기록에 근거가 있으면 링크를 재사용한다. 본문·화면 검토와 기계 검사는 구분한다.
3. 실제 결함만 수정하고 영향받는 원본·파생물을 맞춘다. 같은 판본의 재독·재생성·재검사를 반복하지 않는다. 추가 확인은 새 수정·새 실패·구체적인 미확인에 한정한다.
4. 기록 상태는 `확인됨 / 기존 근거 재사용 / 수정 필요 / 미확인 / 적용 제외(이유)`로 둔다. 적용 항목에 수정 필요·미확인이 남으면 해당 범위의 전체 완료를 선언하지 않는다. 일부 미확인을 다른 확정 항목의 취소로 확대하지 않는다.
5. 허용된 산출물과 기록만 경로를 지정해 커밋·푸시한다. 근거·렌더·캐시는 로컬 evidence에 둔다. 다른 작업의 미커밋은 보존한다.

기존 마감 기록의 확인 근거를 활용하며 회차마다 새 체크리스트 사본을 만들지 않는다. 근거 기록의 최소 열은 아래와 같다.

| 작업·기준 위치 | 적용 산출물·장/구간 | 결과 | 확인 근거·판본 | 남은 조치 |
|---|---|---|---|---|
| 해당 담당 문서의 조항 | 실제 정본 위치 | 위 상태 중 하나 | 파일/장·검사 결과·해시 또는 커밋 | 없으면 없음 |

## 정본과 작업 도구

덱 MD는 `제작용/온라인/decks/`, 회차 구성은 `제작용/구성/`, 최종 산출물은 `산출물/{과정}/{이론,실습}/NN회차`다. 변경 화면은 기존 디자인과 형식을 유지하며 직접 PNG로 확인한다. 노트만 바뀌고 화면이 보존되면 화면을 다시 생성·렌더하지 않는다. PDF와 전체 회차의 실제 실습은 현재 허용 범위 밖이다. 최신 요청의 5종 약 5분 제작 검증 샘플은 공통 기준의 현재 요청 단계에 따른다.

이전 문서의 상세 조항 번호는 [이론 목차](기준_덱과이론대본.md)·[실습 목차](기준_실습과랩.md), 원문 이동 대응은 [이동 기록](근거/2026-10-19_산출물별_기준이동.json)에서 찾는다.
