# 교재 6. 남은 일 — 회차별 내용 검토와 촬영 확인

## 현재 적용 — 1–2회차 최종 확정

통합반·실전반 **1–2회차의 이론·이론 대본·교육 설계·랩·입력자료·온라인 제작 참고 가이드를 내용 최종본으로 확정했다.** 공통 교재·포털 실습을 유지하고 같은 주제 안에서 실전·응용한다. 1회차의 확정 근거는 재사용했다. 2회차는 통합반72장·4랩, 실전반107장·5랩이며 실라버스에 따른 단원 배정 차이를 유지했다.

2회차의 부품 조회 누락, 앞 관계 그림과 원자료의 인계, 입력 속성 불일치, 억지 오류 생성, 조건표의 복수 조건·감점·미확인 처리와 이론 연결을 수정했다. 발표자 노트·합본·낭독본·HTML·ZIP을 동기화·검증했다. 실습 대본은 내용·순서 정합 확정이며 촬영 때 발화·전환·속도만 튜닝할 수 있다.

실제 AI·코드·테스트·HYD/DB·브라우저 실습·캡처·촬영·전체 시간 실측은 미수행이다. **PDF 제작·검토는 제외**하고 기존 파일은 보존했다. 통합반3–11회차·실전반3–8회차는 내용 검토 대기다. 구체적 결함 없이 확정 구간을 반복 검토하지 않는다.

상세 범위·수정·검증·다시 여는 조건은 [1회차 마감](근거/2026-10-19_01회차_두과정_내용검토.md)과 [2회차 마감](근거/2026-10-19_02회차_두과정_내용검토.md)을 따른다. 다음 내용 검토 단위는 두 과정3회차다.

## 1–2회차 완료

공통 교재·포털 흐름과 같은 주제 안의 실전 응용을 반영하고 대본·노트·랩·HTML·ZIP 동기화를 마쳤다. 아래 구체적 재개 조건이 생기지 않으면 다시 검토하지 않는다. PDF는 최신 지시로 제외한다.

## 이후 내용 검토

사용자가 직접 새 세션에서 두 과정3회차부터 진행한다. 세부 시작 절차·입력 위치·누락 방지 항목은 [현재 인계](인계_통합반_회차별_점검.md)의 ‘새 세션의 첫 작업’을 따른다.

효율은 같은 판본의 확정 근거와 공통 원문을 재사용하고 불필요한 재생성·반복 수정을 줄이는 것이다. 효율을 이유로 미확인 회차를 일부만 읽거나 표본·키워드 검사로 전체 내용 검토를 대신하지 않는다. 해당 회차의 이론·전체 발화·화면·랩·입력자료·가이드를 빠짐없이 대조하고, 수정 후 앞뒤 연결과 영향을 받는 파생물까지 확인한다. 검토 범위표에 확인/근거 재사용/미확인을 구분하고, 누락이 없을 때만 회차를 확정한다. 기준 전독과 산출물 재검토는 구별한다.

3회차 통합반·실전반의 전체 이론/대본/덱/랩/자료/가이드를 읽고 구체적 결함만 수정한 뒤 파생물을 동기화·검증한다. 같은 방식으로 이후 회차를 확정하며, 1–2회차는 구체적 재개 조건 없이 반복 수정하지 않는다. 문서로 해결할 문제는 촬영으로 미루지 않는다.

## 다시 여는 조건

특정 개념·정답 오류, 필수 입력 누락, 필드/조건/참조 모순, 원본과 파생물 불일치, 실제 실행에서 재현된 절차 결함이 확인되면 해당 구간만 다시 연다. 실습 대본은 촬영 중 발화·조작 전환·속도 문제도 그 구간만 튜닝한다. 내용 수정 시 연관 노트·합본·낭독본·HTML·ZIP을 동기화·검증한다. 목표 시간이나 문체 취향만으로 전체를 재작성하지 않는다. 촬영 때 발견한 문서 결함은 문서에도 반영한다.

## 최종 GitHub 배포 정리 — 미수행

과정→운영 방식→회차→덱·대본·랩 구조로 정리하고 PDF는 활성 목록·최종 ZIP에서 제외한다. 현재 경로 이동과 기존 PDF 제거는 미수행이다. 원본 대응표·보존본을 확보하고 링크·제작 경로·ZIP을 함께 검증한다. 통합반 로컬 확정 수정의 게시 여부도 별도로 확인한다. 상세 구조와 절차는 현재 인계와 제작법에 있다.

## 별도 범위

오프라인 학생 배포 가이드의 실제 작업/결과 사진 확보와 전 과정 제작, 음성·영상, 포털/시스템 개발은 이번 온라인 확정으로 완료되지 않는다. 오프라인 가이드의 사진 중심·짧은 설명·확인점 및 복사/수정 가능한 프롬프트·스킬·명세 제작 절차는 현행 방법서에 복원했다. 기존 미커밋9개와 역사적 .evidence/before.json은 보존한다. 새 세션은 자동 생성하지 않는다.
