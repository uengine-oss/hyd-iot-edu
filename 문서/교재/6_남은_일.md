# 교재 남은 일

온라인 이론 전체(통합반1–11회차·실전반1–8회차)의 덱·대본·발표자 노트를 마감했다. 이론의 미완료 회차는 없다. 확정 판본은 현황과 회차별 근거를 재사용하고, 구체적인 오류나 새 요청이 있을 때 해당 범위만 다시 연다.

현재 먼저 할 일은 [5종 약 5분 샘플](인계_5분샘플_제작검증.md)의 제작 가능성 검증이다. arrows부터 실제 조작으로 산출물 제작·저장·결과 확인을 빠르게 보여 주고 나머지4종으로 넓힌다. 설명 대본·안치윤v5 음성은 실제 흐름에 추가한다. 이번 세션은 문서·인계만 동기화하며 새 세션에서 제작한다. 5편 모두 미완료이고 기존 arrows 시험·음성은 인계의 파일 상태를 따른다.

## 이론 강의 영상 — 도구 준비 완료, 음성 미생성 (2026-10-21)

- `제작용/기존제작/tools/video/강의영상.py`가 `산출물/<과정>/이론/NN회차/대본/*.md` 파일 하나를 영상 하나로 만든다. `--dry` 점검으로 51편 · 1,395구획 모두 장 번호가 덱 안에 있고 덱의 모든 장이 대본에 덮인다. 무음 가짜 음성으로 통합반1회차 01 조립을 시험해 장 넘김 시각과 그림이 맞음을 확인했다(실제 음성은 미생성).
- 첫 문장 49번 위반 2건을 고쳐야 만들 수 있다: `산출물/실전반/이론/03회차/대본/02_이론_문서에서검증된지식으로.md`(「이어서…」), `산출물/통합반/이론/03회차/대본/03_이론_성과평가와조치비교.md`(「이제…」).
- 전체 낭독 글자 수는 823,057자(통합반·실전반 51편)다. ElevenLabs 계정은 starter(월 40,000자)이고 2026-10-21 조회 때 남은 양이 10자였다(다음 초기화 2026-11-12 17:38 KST). 요금제 상향 또는 범위 결정이 먼저다.
- 맑은 고딕이 있는 로컬 Windows에서 만든다. 클라우드에는 글꼴이 없어 장 그림이 다른 글꼴로 그려진다.

## 샘플 뒤에 남은 교재 작업

기존 실습102파일은 보존한다. 1회차는 두 과정 공통이며 예전 차이안의 추가 응용 설계를 지금 진행하지 않는다. 환경 대본·가이드 반영, 촬영용 main 판본 확인, 후속 실제 코딩 랩의 가치·과정 차이,5·6의 응용 미확인과7 이후 미완료는 샘플 뒤 후속 작업으로 남긴다. 전체 회차의 실행·촬영 완료와 5분 샘플 성공을 혼동하지 않는다.
