# 교재 6. 남은 일

다음에 할 일과, 「확인했다」고 말하면 안 되는 것을 적는다. 기준일 2026-10-14.

## 0. 다음에 할 일 (차례대로)

통합반 1일차는 2026-10-14에 새 기준으로 덱과 대본을 다시 썼다(`3_현황.md` 0절). 그다음은 이렇다.

1. **사용자가 다시 쓴 1일차를 본다.** PPTX는 `course/slides/integrated/통합반_01일차.pptx`, 대본은 `course/scripts/integrated/통합반_01일차_대본[_2부 · _3부]_윤문2.md`다. 고칠 곳을 받아 고친다. 승인되면 이것이 2~11일차의 본보기가 된다.
2. 1일차의 길이(96.8분, 이론 배정 110분)는 그대로 두기로 했다(사용자, 2026-10-14). 채우지 않는다.
3. **승인된 1일차를 본보기로 2~11일차를 하루씩 같은 기준으로 다시 쓴다.** 순서는 1일차와 같다: 덱의 제목과 메시지만 이어 읽어 뼈대를 본다 → 재료를 차례로 소개하는 단원은 뼈대부터 다시 짜고, 물음으로 이어지는 단원은 늘어난 곳과 한 장에 둘을 설명하는 곳만 잡는다 → 대본을 새 덱에 맞춰 다시 쓴다 → 대본은 아스트라가, 덱은 작업하는 세션이 윤문한다 → 조립 덱, PPTX, 배포 묶음, 문서를 맞춘다(`4_만드는_법.md` 1부). 우리가 붙인 서비스 이름과 재료의 이름이 2~11일차 덱과 대본에도 나온다(세어서 보고한다).
4. **윤문:** 대본은 아스트라에게 「내용과 설명의 수준은 자료를 보고 이미 다 맞춰 놓은 완성본이다. 내용은 손대지 말고 윤문 작업만 해 달라」고 알려 한 번 보내고, 돌아오면 숫자, 이름, 굵게 표시, 문단 수, 음절 수, 끝말의 분포를 검사한다. 덱은 작업하는 세션이 직접 윤문하고 빌드로 넘침을 확인한다(`2_기준.md` 8절).
5. 영상은 사용자가 범위를 말하면 만든다. 1일차는 장 번호가 바뀌었으므로 쉼 자리를 다시 정한다.

그 뒤에 할 것:

1. 포털 자동 녹화를 시험한다(1일차 실습 3). 에이전트 단계까지 돌리려면 호스트 워커가 떠 있어야 한다.

5. 실전반: 통합반의 장을 가져온 덱이라 음성을 다시 쓸 수 있다. 통합반이 끝난 뒤에 계획한다.

## 1-1. 랩과 덱이 어긋나 정해 주어야 하는 것

| 무엇 | 왜 열려 있나 |
|---|---|
| 학생이 쓸 실습용 그래프 DB의 주소 | 덱은 분리된 DB라고만 한다. 수업 스택의 그래프 DB에는 기준 지식이 들어 있어 학생이 넣는 것과 식별자가 겹친다. 두 묶음은 DB가 비어 있지 않으면 준비 단계에서 멈춘다 |
| 랩의 스키마 이름 | 2회차 랩은 `MEASURES`, `MOUNTED_ON`을 쓰고 덱은 `OBSERVES`, `MONITORED_BY`로 설명한다 |
| 2회차 랩 스키마의 `USES_PART` | 이어받은 스키마는 `1:N`, 저장소의 확정 스키마는 `N:M`이다 |
| 4회차 실습 3의 판단 규칙 | 덱은 판단 규칙까지 조회한다고 하나 이어받은 후보에 규칙이 없어 랩에서 뺐다 |
| 4회차 실습 4의 개정 값 | 덱에 새 값이 없다. 랩은 48시간으로 했는데 HYD나 덱의 값이 아니다 |
| 6회차의 MCP 서버 | 덱은 공개 서버 셋이라고 하나 설치 방법이 저장소에 없다. 랩은 묶음 안에 파이썬으로 쓴 서버를 쓴다 |
| 6회차 랩의 중복 처리 | 덱은 「합치지 않고 표시」, 랩은 합친다 |
| 7회차 실습 4의 「오류를 수정」 | 완성본에 시나리오를 돌리니 어긋남이 나오지 않았다. 실패를 심지 않고, 사람의 승인 한 줄을 바꿔 회귀 편이 실패하는 것을 보게 했다 |
| 덱의 「모호한 한 문장이 기존 동작을 깨뜨린다」 | 7회차 랩에서 그 문장을 보내면 AI가 고치지 않고 되묻는 일이 잦았다 |
| 수업 문서 원문의 「교육용」 문구 | 매뉴얼 HM-8 원문에 있다. 포털에 올리는 문서와 같아야 해서 랩에서 고치지 않았다 |

| 무엇 | 상태 |
|---|---|
| 덱의 값은 실행 중인 시스템으로 다시 확인하지 않았다 | 저장소 코드와 2026-10-10 실행 기록(사실표가 옮긴 것)이 근거다. 그 기록의 상당수는 gitignore인 `.evidence/`에 있어 저장소에는 요약만 있다 |
