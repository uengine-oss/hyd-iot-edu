# 교재 6. 남은 일 — 회차별 내용 검토와 촬영 확인

## 현재 적용 — 1회차 최종 확정

통합반·실전반 **1회차의 이론·이론 대본·교육 설계·랩·입력자료·온라인 제작 참고 가이드를 최종 확정했다.** 교재 78장과 포털 실습은 동일하다. 대본은 과정별 진행에 맞추며, 실전반 관계 그림 랩은 같은 그림에서 팬 진동 조건 및 자료 미확보 상황을 적용·판단한다. 별도 근거 추적 코드 과제는 현재 배포에서 제외했다.

발표자 노트·합본·낭독본·HTML·ZIP은 원본과 동기화했다. 실습 대본은 확정 랩과 내용·순서가 일치하며 촬영 때 발화·전환·속도만 추가 튜닝할 수 있다. 실제 AI·코드·테스트·HYD/DB·브라우저 실습·캡처·촬영·전체 시간 실측은 미수행이다. 통합반 2–11회차·실전반 2–8회차는 내용 검토 대기다.

최신 사용자 지시로 **PDF 제작·검토는 작업 대상에서 제외한다.** 이미 생성된 파일은 보존하되 이후 확정 조건으로 삼거나 추가 작업하지 않는다. 같은 판본에서 이미 확인·확정한 내용은 근거를 재사용하고, 변경된 부분·영향받은 연결과 파생물·아직 확인하지 않은 부분만 검증한다. 구체적 결함 없이 확정 구간을 반복해서 열지 않는다.

상세 범위·수정 이유·검증·다시 여는 조건은 [1회차 마감](근거/2026-10-19_01회차_두과정_내용검토.md)을 따른다. 1회차는 마감했으며 다음 내용 검토 단위는 두 과정 2회차다.

## 1회차 완료

공통 교재·포털 흐름과 같은 주제 안의 실전 응용을 반영하고 대본·노트·랩·HTML·ZIP 동기화를 마쳤다. 아래 구체적 재개 조건이 생기지 않으면 다시 검토하지 않는다. PDF는 최신 지시로 제외한다.

## 이후 내용 검토

2회차 통합반·실전반의 전체 이론/대본/덱/랩/자료/가이드를 읽고 구체적 결함만 수정한 뒤 파생물을 동기화·검증한다. 같은 방식으로 이후 회차를 확정하며, 1회차는 구체적 재개 조건 없이 반복 수정하지 않는다. 문서로 해결할 문제는 촬영으로 미루지 않는다.

## 다시 여는 조건

특정 개념·정답 오류, 필수 입력 누락, 필드/조건/참조 모순, 원본과 파생물 불일치, 실제 실행에서 재현된 절차 결함이 확인되면 해당 구간만 다시 연다. 실습 대본은 촬영 중 발화·조작 전환·속도 문제도 그 구간만 튜닝한다. 내용 수정 시 연관 노트·합본·낭독본·PDF·HTML·ZIP을 동기화·검증한다. 목표 시간이나 문체 취향만으로 전체를 재작성하지 않는다. 촬영 때 발견한 문서 결함은 문서에도 반영한다.

## 별도 범위

오프라인 학생 배포 가이드의 실제 작업/결과 사진 확보와 전 과정 제작, 음성·영상, 포털/시스템 개발은 이번 온라인 확정으로 완료되지 않는다. 오프라인 가이드의 사진 중심·짧은 설명·확인점 및 복사/수정 가능한 프롬프트·스킬·명세 제작 절차는 현행 방법서에 복원했다. 기존 미커밋9개와 역사적 .evidence/before.json은 보존한다. 새 세션은 자동 생성하지 않는다.
