# 교재 6. 남은 일 — 확정 후 촬영 확인

## 현재 판정 정정 — 회차별 전체 내용 검토 진행

사용자 확인에 따라 이전의 두 과정 전체 최종 확정 선언을 철회한다. 이전 작업은 기존 내용 검토 기록 수용·일부 내용 집중 검토·전체 정적 정합 검사였으며, 현재 원본 전체를 직접 읽고 대조한 최종 내용 검토가 아니었다. 완료한 국소 수정과 정적 검사 결과는 유지한다.

통합반1회차와 실전반1회차를 한 묶음으로 이론·덱·대본·랩·자료·가이드를 전부 읽고 대조하여 수정·동기화·검증한 뒤 해당 회차만 확정한다. 현재1회차 검토 중이며 나머지 회차는 전체 내용 검토 대기다. 실제 실행·촬영은 계속 미수행이다. 회차가 같아도 실라버스 배정과 실습 차이를 보존하며 동일 내용으로 강제하지 않는다.

## 다시 여는 조건

특정 개념·정답 오류, 필수 입력 누락, 필드/조건/참조 모순, 원본과 파생물 불일치, 실제 실행에서 재현된 절차 결함이 확인되면 해당 구간만 다시 연다. 실습 대본은 촬영 중 발화·조작 전환·속도 문제도 그 구간만 튜닝한다. 내용 수정 시 연관 노트·합본·낭독본·PDF·HTML·ZIP을 동기화·검증한다. 목표 시간이나 문체 취향만으로 전체를 재작성하지 않는다. 촬영 때 발견한 문서 결함은 문서에도 반영한다.
