# 교재 남은 일

온라인 이론 전체(통합반1–11회차·실전반1–8회차)의 덱·대본·발표자 노트를 마감했다. 이론의 미완료 회차는 없다. 확정 판본은 현황과 회차별 근거를 재사용하고, 구체적인 오류나 새 요청이 있을 때 해당 범위만 다시 연다.

현재 먼저 할 일은 [5종 약 5분 샘플](인계_5분샘플_제작검증.md)의 제작 가능성 검증이다. arrows부터 실제 조작으로 산출물 제작·저장·결과 확인을 빠르게 보여 주고 나머지4종으로 넓힌다. 설명 대본·안치윤v5 음성은 실제 흐름에 추가한다. 이번 세션은 문서·인계만 동기화하며 새 세션에서 제작한다. 5편 모두 미완료이고 기존 arrows 시험·음성은 인계의 파일 상태를 따른다.

## 이론 강의 영상 — 통합반 1회차 01편 제작, 청취 승인 대기 (2026-10-21)

- 통합반 1회차 `01_이론_지식자산화`를 만들었다(10:29.7, 크레딧 1,779 사용). 사용자가 듣고 승인하면 다음 범위(1일차 02 · 03편)를 정한다. `--dry` 실측으로 02편 18,252자, 03편 15,800자다. 01편은 4,449자에 1,779 크레딧(글자당 약 0.4)이 들었으니 두 편은 약 13,600 크레딧으로 이번 달 남은 38,221 안에 든다.
- 같은 방법으로 따라 만든다: 목소리는 이 계정의 「안치윤」 `--voice tlxL9ilynpbOVf9sZXKh`(도구 기본값은 옛 계정 음성이라 반드시 지정), 쉼 값 `--pause-short 0.15 --pause-mid 0.45 --pause-long 0.8 --pause-question 0.5 --pause-para 0.4 --gap 1.2`, 쉼 자리는 세션이 문장을 읽고 채운다. 순서는 스킬 `hyd-lecture-video`.
- 클라우드에서 만들 때는 맑은 고딕(`MALGUN.TTF` · `MALGUNBD.TTF` · `MALGUNSL.TTF`)을 사용자가 올려 `/usr/share/fonts/truetype/malgun/`에 설치하고 `fc-cache -f` 한다. 글꼴은 저장소에 넣지 않는다.
- 첫 문장 49번 위반 2건을 고쳐야 그 편을 만들 수 있다: `산출물/실전반/이론/03회차/대본/02_이론_문서에서검증된지식으로.md`(「이어서…」), `산출물/통합반/이론/03회차/대본/03_이론_성과평가와조치비교.md`(「이제…」).
- 전체 낭독 글자 수는 823,057자(통합반·실전반 51편)다. 글자당 약 0.4 크레딧이면 약 33만 크레딧이라 starter(월 40,000)로는 여러 달이 걸린다. 전체를 만들려면 요금제 상향 또는 범위 결정이 먼저다.

## 샘플 뒤에 남은 교재 작업

기존 실습102파일은 보존한다. 1회차는 두 과정 공통이며 예전 차이안의 추가 응용 설계를 지금 진행하지 않는다. 환경 대본·가이드 반영, 촬영용 main 판본 확인, 후속 실제 코딩 랩의 가치·과정 차이,5·6의 응용 미확인과7 이후 미완료는 샘플 뒤 후속 작업으로 남긴다. 전체 회차의 실행·촬영 완료와 5분 샘플 성공을 혼동하지 않는다.
