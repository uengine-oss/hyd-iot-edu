# 교재 6. 남은 일 — 회차별 내용 검토와 촬영 확인

## 현재 적용 — 1–3회차 내용 확정

두 과정 3회차의 전체 내용 검토·수정 및 산출물 동기화를 마쳤다. 통합반67장·3랩, 실전반100장·5랩이다. 1–2회차는 확정 근거를 재사용했고 내용 재검토·수정하지 않았다. 실습 대본은 내용·순서 정합 확정이며 촬영 때 발화·전환·속도만 튜닝할 수 있다.

[3회차 마감](근거/2026-10-19_03회차_두과정_내용검토.md)에 수정·검증·미수행 범위를 기록했다. 실제 실습·촬영·PDF 제작/검토는 미수행이다. 다음 내용 검토 단위는 두 과정4회차이며 통합반4–11·실전반4–8은 검토 대기다. 각 회차를 마무리하면 해당 산출물을 커밋·푸시하고 다음 회차를 준비한다. 전달 파일은 과정/회차 안에서 이론과 실습으로 구분하고 제작용 파일은 섞지 않는다.


## 1–2회차 완료

공통 교재·포털 흐름과 같은 주제 안의 실전 응용을 반영하고 대본·노트·랩·HTML·ZIP 동기화를 마쳤다. 아래 구체적 재개 조건이 생기지 않으면 다시 검토하지 않는다. PDF는 최신 지시로 제외한다.

## 이후 내용 검토

다음은 두 과정4회차다. 3회차 마감 근거를 재사용하고 완료 검토를 반복하지 않는다. 세부 시작 절차·입력 위치·누락 방지 항목은 [현재 인계](인계_통합반_회차별_점검.md)의 ‘새 세션의 첫 작업’을 따른다.

효율은 같은 판본의 확정 근거와 공통 원문을 재사용하고 불필요한 재생성·반복 수정을 줄이는 것이다. 효율을 이유로 미확인 회차를 일부만 읽거나 표본·키워드 검사로 전체 내용 검토를 대신하지 않는다. 해당 회차의 이론·전체 발화·화면·랩·입력자료·가이드를 빠짐없이 대조하고, 수정 후 앞뒤 연결과 영향을 받는 파생물까지 확인한다. 검토 범위표에 확인/근거 재사용/미확인을 구분하고, 누락이 없을 때만 회차를 확정한다. 기준 전독과 산출물 재검토는 구별한다.

4회차 통합반·실전반의 전체 이론/대본/덱/랩/자료/가이드를 읽고 구체적 결함만 수정한 뒤 파생물을 동기화·검증한다. 같은 방식으로 이후 회차를 확정하며, 1–2회차는 구체적 재개 조건 없이 반복 수정하지 않는다. 문서로 해결할 문제는 촬영으로 미루지 않는다.

## 다시 여는 조건

특정 개념·정답 오류, 필수 입력 누락, 필드/조건/참조 모순, 원본과 파생물 불일치, 실제 실행에서 재현된 절차 결함이 확인되면 해당 구간만 다시 연다. 실습 대본은 촬영 중 발화·조작 전환·속도 문제도 그 구간만 튜닝한다. 내용 수정 시 연관 노트·합본·낭독본·HTML·ZIP을 동기화·검증한다. 목표 시간이나 문체 취향만으로 전체를 재작성하지 않는다. 촬영 때 발견한 문서 결함은 문서에도 반영한다.

## 회차별 전달 산출물과 게시 — 최신 사용자 지시

각 회차를 완료하면 PPTX·대본·랩·HTML 가이드 등 해당 회차 산출물을 커밋·푸시하고 다음 회차를 준비한다. 이미 끝낸 내용 검토를 반복하지 않는다. 상세 기준 전체는 계속 적용하며 최신 지시 일부만 적용하는 방식으로 축소하지 않는다.

각 반의 회차 안에서 이론(PPTX·이론 대본)과 실습(실습 대본·랩 자료·HTML·다운로드 ZIP)으로 구분한다. 제작용 덱 원고·도구는 만들기/, 기준·사실표·검토 기록은 문서/교재/에 유지하고 전달 파일과 섞지 않는다. 3회차 전달 위치는 산출물/교재/{통합반,실전반}/온라인/03회차/{이론,실습}이다. 기존 제작·동기화 원본은 보존한다.

이번 게시 대상은 두 과정3회차다. 전체19회차의 폴더 전환은 진행하지 않으며 생성했던 초안은 로컬 evidence에 분리했다. 1–2회차 확정본을 다시 검토하거나 게시 구조 정리를 위해 수정하지 않는다. PDF는 생성·검토하지 않고 기존 파일을 보존하되 이번 전달 폴더와 ZIP에는 넣지 않는다. 통합반3은 정확한 통합반 정본의 출처·해시를 확인하여 게시하며 두 작업 루트를 통째로 합치지 않는다.

## 별도 범위

오프라인 학생 배포 가이드의 실제 작업/결과 사진 확보와 전 과정 제작, 음성·영상, 포털/시스템 개발은 이번 온라인 확정으로 완료되지 않는다. 오프라인 가이드의 사진 중심·짧은 설명·확인점 및 복사/수정 가능한 프롬프트·스킬·명세 제작 절차는 현행 방법서에 복원했다. 기존 미커밋9개와 역사적 .evidence/before.json은 보존한다. 새 세션은 자동 생성하지 않는다.
