# 최종 실라버스 전체 흐름·가치·지원 범위 검토 — 2026-10-27

최신 상세 활동·현재 시스템 지원·실제 랩 보강은 [C63 대조 결과](2026-10-27_실라버스_실제랩과지원범위.md)를 따른다. 아래 C62 시간·배정은 유지한다. 이 문서의 이전38회차·211행 검토를 실제 전체 랩 실행 검증으로 해석하지 않는다.

## 최신 C62 시간·강사 정정

이전 가변 시간표는 사용자의 최신 결정으로 폐기했다. 현재는50분 수업·10분 휴식×4교시, 이론 교시50분이며 실행 중심 회차에 새 이론을 억지로 추가하지 않는다. 공개 정본·실명 배정본 동기화와19회×4교시·합계200분을 확인했다. 주강의 교시 합계는 총괄27교시, 온톨로지·에이전트 담당25교시, 에이전트 담당24교시다. 보조 시간은 별도로 집계하며 주강의와 합쳐 균등하다고 주장하지 않는다. 실명별 시수는 전달 파일·로컬 배정 근거에만 보관한다. 아래25~40·60~75분 배정표는 C61 당시의 검토 이력이며 현행 시간표가 아니다.

현재 정본 SHA-256: `75f339dde9a79faebcff640b73db47e953a8e1b984a8d0a44877a98f2bfd6d69`.


## 범위와 판정

온라인 통합11·실전8, 오프라인 통합10·실전9의 총38회차, 이론·실습211행의 제목·상세내용을 순서대로 읽었다. 단어 검색만으로 전체 내용 확인을 대체하지 않았다. 최초 도입, 선수 개념, 입력·행위·결과, 다음 활용, 중복, 권한, 로컬/포털 경계, 시간과 강사 역할을 대조했다. 온라인 시간·날짜는 그대로 보존했다. 이 검토는 실제 수업 리허설·학생 완주 검증이 아니다.

## 발견한 결함과 실제 수정

- 첫날 HYD 전체 구조·목표·포털 시연 누락: 이론에서 전체 구조를 이해하고 실습에서 실제 포털 시연→ARROWS 관계도→Cypher→작은 모델 적재로 이어지게 복원했다. 온라인 Notion을 반복 제작하는 긴 시간을 추가하지 않고 결과를 학습노트에 연결한다.
- 회차별 활동이 나열되던 문제: 첫 활동에 앞 학습과 오늘 목적, 마지막 활동에 구체적인 다음 활용을 반영했다. 별도 도입·예고10분 행은 만들지 않았다.
- 문서 지식 활동의 제목과 권한 불일치: 등록하기를 등록 결과·원문 검토로 정정했다. 일반 포털 임의 등록·MCP 서버 추가를 요구하던 이론 문장도 수정했다.
- 이전 개인 결과가 필수처럼 읽히던 내용: 제공된 이전 단계 완성 시작본을 사용하는 표현으로 바꿨다. 학생 이전 결과는 선택 입력이며 초기화 PC에서도 이어갈 수 있어야 한다.
- 통합반 질문·작성·검토·명세·BDD를 한 날 모두 새로 구현하는 부담: 질문·재개를 직접 구현하고 작성·검토 결과는 제공 자료로 비교하도록 조정했다. 핵심 기능 변경과 검증을 보존했다.
- 마지막 두 오프라인 회차의 교대 완주 중복: 앞 회차는 구성·등록·입력 대응 확인, 마지막 회차는 실제 검토·보완·인수 확인에 집중한다. 마지막 단위는 교대50분+ProcessGPT20분으로 확보했다.
- 이론50분·모든 실습50분의 기계적 배정: 이론25~40분, 직접 제작·검증45~75분 등 내용별 편성으로 변경했다. 마지막 실행 중심 회차는 별도 이론0분이다.
- 실전반8명: 자료 비교·단독 결과 확인 블록6개의 상시 보조 배정을 제외했다. 첫 도구 사용·코딩·권한 연결에 보조를 집중한다. 질문과 결과 해석에 참여할 여유를 활용하며 인원만으로 실제 시간 단축을 단정하지 않는다.
