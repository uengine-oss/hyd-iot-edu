## 실제 원인과 해결

| 현상 | 확인한 원인·대응 |
|---|---|
| 주소를 입력한 뒤 protocol이 바뀜 | `localhost:7627` 입력/붙여넣기 뒤 실제 UI가 neo4j://로 바뀜을 확인. 연결 전에 bolt://로 다시 선택·검증하는 수습을 ui004r로 촬영했다. 실수를 연출한 것이 아니다. |
| MATCH만 입력된 상태에서 문법 오류 | Enter가 부분 쿼리를 실행했다. Escape 후 Shift+Enter 줄바꿈으로 두 줄 입력과 실행 결과 확인. 실패 원본 take01/02 보존. |
| Protocol 메뉴가 저수준 클릭으로 안 열림 | 실제 combobox를 고수준 `page.click`으로 열고 보이는 option을 선택. 위치 안정화·직렬 ACK·커서 이동은 공통 촬영 도구 방식 재사용. |
| 합성 길이 검사만0.1초 초과 실패 | ffmpeg progress의 마지막 패킷 시각을 전체 길이로 사용한 검사 문제. wrapper에서 ffprobe stream duration으로 검사했고0.1초 허용치는 유지. 기존 공통 도구 원본은 미수정. |
| 측정 클릭 수가 반복 누적 | 기존 페이지 이벤트 리스너가 재촬영 때 중복 등록되고 공통 encode는 마지막 구간 clicks만 집계함. 해당 합성본 clicks를 전체 구간 통계로 사용하지 않는다. 후속 녹화기에서 이전 리스너 제거·구간별 집계가 필요. |
