# 2회차 시작 멘트와 첫 사용 안내

## 결정과 실제 적용

C49·C50을 `기준_실습대본.md`에 반영했다. 통합반은 VS Code 첫 사용을 상세히 안내하고 반복 설명을 줄이며, 실전반은 기본 UI 설명을 생략한다. Neo4j 등 다른 도구의 첫 사용은 공통으로 안내한다. 시간을 고정하지 않으며 문체·길이는 내용과 실제 조작에 맞춘다.

승인 Excel `실라버스/피지컬AI_실라버스_최종본.xlsx`의 두 온라인 시트 B/C17~25를 직접 읽어 대조했다. Excel은 변경하지 않았다.

| 대본 | 앞 내용 → 이번 작업 | 반영 |
|---|---|---|
| 두 과정 관계 조회 | 그래프/Cypher 이론 → 제공 예제의 센서·물리량·부품 조회 | 과정별 준비 도입, 공통 연결·UI·첫 입력, 파일 저장 안내 |
| 두 과정 지식 지도 | Cypher 조회 → 포털에서 연결 탐색 | 도입 수정, 실습 DB/기준 지도 구분 |
| 통합반 설계 | 조회·지도 탐색 → 질문에 맞는 스키마/인스턴스 | 도입 수정, 첫 AI 채팅 설명·실제 근거 대조 |
| 실전반 설계 | 조회·지도 탐색 → 부품 사용 설비/공급 조건 모델 | VS Code UI 설명 없이 요구와 원자료로 진입 |
| 두 과정 그래프 구현 | 앞 설계 → 적재·조회·원자료 대조·중복 확인 | 과정별 질문과 제공 독립 시작본을 명시 |
| 실전반 조건표 | 바로 앞 SOP/DMN 이론 → 경고·감점·제외 조건표 | 그래프 실습에서 바로 넘어온 것으로 말하지 않음 |

제작 원본은 `제작용/실습시작/도입/`와 `sync_entry_scripts.py`다. 기존 `sync_runtime_scripts.py`의 마지막에 적용하므로 기존 동기화가 도입을 구문안으로 덮어쓰지 않는다. 대본 9편에 반영했다. 랩 과제·학생 정답 경계·학생 ZIP·가이드 배포 판본은 이번에 변경하지 않았다.

## 실제 UI 확인

기존 ego 공간3을 찾을 수 없었고 목록도 비어 있었다. 기존 복구 승인에 따라 공간4 `hyd practice ui introduction 20261026`을 열었다. p1은 공통 예제 DB Browser이며 원본 실행은 `.evidence/practice-20261026/browser-52.mjs`~`browser-56.mjs`에 있다.

연결 창 자동 표시, 연결 후 소개 카드, 접힌 패널을 Open Sidebar로 펼치기, Database overview에서 노드20/관계19·레이블5종·관계4종을 실제 확인했다. 연결 창이 먼저 나오는 경우와 패널을 펼쳐야 하는 경우의 발화를 원고에 반영했다. 첫 화면에서 소개 카드를 몰래 지우거나 패널을 접어 백지로 시작하지 않는다. 첫 쿼리의 반환 열은 기존 실제 캡처의 component/sensor_id/tag와 맞췄다.

실제 화면 `.evidence/practice-20261026/neo4j-first-ui-rehearsal.jpg`를 열어 패널과 입력칸 배치를 확인했다. 이 파일은 UI 리허설 근거이며 완성 가이드 캡처나 새 본 영상이 아니다. 현재 신규 음성 생성·개정 전체 영상 촬영은 하지 않았다.
