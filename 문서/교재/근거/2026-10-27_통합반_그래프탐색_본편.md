# 통합반 첫 Cypher — 그래프 탐색 본편

## 적용 범위와 판단

C50 첫 UI, C51 과정별 영상, C52 깨끗한 시작에 C53 전체 연결과 자연스러운 그래프 상호작용을 적용했다. 사용자 지시는 관계를 이해하는 실습이며 모든 Neo4j 기능이나 고정 분량·클릭 수를 채우라는 뜻이 아니다. 실전반·포털 로직·Notion·이론은 이번 변경 범위 밖이다.

전체 지도→쿨러 노드→센서·관계→물리량→TS1 경로→같은 속성 표→한계 조건→부품→센서 수 대조→전체 지도와 예비 펌프→PNG·질의 CSV 저장으로 구성했다. CREATE/MERGE는 이 조회 영상에 임의로 추가하지 않았다. 이론 전체나 온라인2 전체 완료로 세지 않는다.

## 실제 수행과 수습

기존 촬영DB 하나(HTTP9792/Bolt9793)를 재사용했다. 신규 컨테이너 없음. 주소는 이번 실행값이지 학교 고정값이 아니다. 연결창부터 시작하고 앞 카드 정리·패널 접기/펼치기를 실제로 보여 줬다. 그래프는 Hierarchical layout과 Zoom to fit을 실제 UI로 선택했다. Canvas의 렌더 좌표를 관찰해 마우스를 이동·클릭하고 Node/Relationship details 값을 확인했다. 숨은 그래프 상태를 조작하지 않았다.

`neo4j-forest-take01`은 저장 시작에서 숨은 Stream 편집기를 선택해 중단됐다. 가시 편집기 좌표 클릭으로 고쳐 `neo4j-forest-tail`의 저장·재열기·CSV를 촬영했다. 원본은 보존하고 오류 전 발화 경계까지만 사용했다. 오래된 UI 도입의 ‘노드 하나부터’ 문장을 ‘전체 연결부터’로 수정하고 `neo4j-forest-ui-fix2`를 촬영했다. fix1의 :clear 잔여 입력은 사용하지 않았다. 이전 촬영본·음성·evidence를 삭제하지 않았다.

첫 합성에서 잘라낸 구간의 첫 새 프레임이 3.566초 뒤에 도착해 정지 시간이 누락되는 문제가 길이 검사로 검출됐다. 경계 직전 실제 프레임을 원래 timestamp와 함께 포함해 다음 프레임까지 유지하도록 수정했다. 실패 영상은 failed-length.mp4로 보존했다. 분할 영상은 움직임이 없더라도 경계부터 첫 프레임까지의 시간을 생략하면 안 된다.

`forest-review-0..5.jpg`로 전체 설명 단계 화면을 확인했다. `forest-seams.jpg`로 구간 경계를 확인했다. 전체 직접 청취·사용자 기기에서 재생·네이티브 다운로드/VS Code 준비 장면은 미확인이다. 저장 구간 연결부 커서 위치 차이와 첫 연결 안내 중 최대116.7ms 프레임 간격1건은 남아 있다. 의미·클릭 결과는 유지되며 ‘끊김0’으로 보고하지 않는다. 30fps 출력은 원본의 실제 프레임 간격 검증을 대신하지 않는다.

가이드 브라우저 확인: 이미지9개 로드 성공, 9단계 제목, 가로 넘침 없음. 단계별 기대 노드·관계·속성·행 수와 저장 결과를 표시했다. 조회 답안을 학생 구현 코드에 미리 채우지 않았다.
