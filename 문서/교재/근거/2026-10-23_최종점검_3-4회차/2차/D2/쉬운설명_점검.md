# 쉬운 설명 점검 — 실전반 4회차 01편 SLIDE 1~28 (마지막 손질 D2, 1차 D 표를 이어받아 갱신)

기준: 학생은 IT · 제조 시스템 배경이 거의 없다. 앞 회차(실전반 1~3회차 이론 대본, 공유 문단은 통합반 1~4회차도)에서 이미 푼 말은 다시 풀지 않는다. 「처음 나온 장」은 손질본 낭독 본문에서 처음 소리 나는 장. 「1차 N」은 `final4/D/변경목록.md` 번호, 「D2-N」은 이번 `변경목록.md` 번호. 1차가 「앞 회차」라고 적은 곳은 표본으로 다시 찾아 확인했다(업무 DB 2회차 02편 65행, JSON 3회차 02편 223행, 에이전트 1회차 02편 417행, 납기 · 긴급 오더 1회차 03편 143행, 공동 2순위 1회차 03편 405행, 재관측 1회차 02편 37장 · 03편 421행 — 모두 맞음).

이번에 새로 푼 용어: 없음. 1차가 푼 다섯(MCP · SKILL.md · 로컬 · 진행 설명 · 로트)은 모두 사실 · 앞뒤 말과 맞고 길이도 한 마디 안팎이라 그대로 두었다. MCP 풀이가 들어간 문장만 같은 말 되풀이(「잇는 … 이어갑니다」)를 없애려고 다듬었다(D2-1, 풀이 「MCP라는 표준으로 연결」은 유지). 원호의 뜻(5장)은 의심 3을 반영해 고쳤다(D2-3). 1차가 놓친 용어를 새로 찾아 확인한 것: Git · 처리 건 · 에이전트 단계 · 표의 열 · 출하 · 업무 값 · 「질문하는 AI와 일하는 AI」 — 모두 앞 회차 · 같은 장 · 바로 앞 문장이 받쳐 손대지 않았다(표 끝 「새로 본 것」).
