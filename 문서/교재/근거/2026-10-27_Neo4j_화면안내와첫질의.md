# Neo4j 화면 안내·첫 질의·그래프 비교 수행

학생 링크 `http://127.0.0.1:7628/browser/`로 연결한 화면에서 이어 촬영했다. 첫 화면은 연결 창이 자동 표시되는 흐름을 유지한다. 과거 localhost 촬영본을 이 흐름에 섞지 않는다.

## 윤문과 실제 촬영

- `화면과첫질의_큐.json`: 소개 카드 → 접힌 패널을 설명하며 펼치기 → Database overview → 레이블/관계 유형 → 입력칸/Run → MATCH/RETURN 작성 → Shift+Enter 줄바꿈 → 실행 → CE/TS1 두 행 해석.
- `표에서그래프_큐.json`: 같은 패턴의 관계에 r을 붙이고 RETURN c,r,s 실행 → 실제 Graph 표시 → Component1/Sensor2, 관계2를 확인한 다음 설명.
- 첫 결과 발화는 추상적인 ‘행과 개수를 나누어 보자’에서 ‘쿨러 하나에 센서 두 개가 연결돼 두 행으로 나온다’로 고쳤다. 원맨쇼 구어체·실제 입력·검증을 연결했다.
- `sync_entry_scripts.py`가 실제 촬영 큐의 첫 질의/결과 발화를 두 과정 대본에 반영한다. 첫 화면 원본도 실제 패널 열기 순서로 수정했다.

이 수치가 전 구간 음성 청취·전체 이음매·사용자 재생 확인을 대신하지 않는다. 그래프 입력 구간은 결과 렌더가 끝나기 전에 끝났고 결과 설명 구간은 렌더 뒤 시작하므로 그 경계의 로딩 연속성을 추가 확인해야 한다. 이 파일은 내부 검토용이며 공개 게시하지 않았다.

## 이어 갈 지점

접속 take04는 학생 첫 상태(자동 접속 창·이전 결과0·접힌 패널)를 검사하고 성공했다. 클릭 오차는 전체 수집 기록 기준 축별 최대0.934 CSS px로 수정됐다. `neo4j-real-intro-review02` 합성은200.868초이며 접속→패널→표 입력 경계의 화면 상태를 나란히 확인했다(`real-intro-joins.jpg`). 다만 접속 구간 이동에서117/117/350ms 공백이 남아 최종판으로 전달하지 않았다. 나머지153.894초 정상 구간을 다시 찍지 않는다. 접속 take03는 패널 복원이 실패한 뒤 시작됐으므로 합성에서 제외했다. 현재 실제 페이지는 take04의 연결 직후·패널 접힘 상태다.

접속 구간 클릭 위치 수정 재검증, 접속 끝과 패널 열기 시작 상태 일치 확인, 그래프 구간 로딩 경계 확인 후 합성한다. 접속 복원에서 실제 버튼 제목은 `Collapse Sidebar`였다. `Close Sidebar` 조건은 버튼을 찾지 못하며, 모달의 Close 버튼은 입력 차단 오류가 있어 실패했다. 실패한 복원 뒤 촬영을 자동으로 시작하면 안 된다. 이후 시작 검사는 기존 결과 유무뿐 아니라 패널 개폐·접속 창 전체 표시도 포함해야 한다.

남은 본 실습은 설비→물리량 경로, WHERE의 값 없음 필터, 부품 조회, 센서 집계 대조, 질의/결과 저장이다. 해당 실습 전부를 완료로 표시하지 않는다. 학교 초기화·VS Code·AI 완주는 기존 미확인을 유지한다. 결정 C49·C50의 실제 적용 근거이며 Notion·학생 ZIP·포털 로직은 변경하지 않았다.
