# 3회차 레이아웃 보완과 교재 경로 정리

2026-10-19. 기존 전체 내용 확정 후 사용자가 지적한 표 중심 구성 문제를 보완했다. 표 사용·반복 기준은 이후 모든 회차에 적용한다. 1·2회차 내용은 다시 검토하지 않았다.

기존 글꼴·색·제목·메시지·프레임을 유지했다. 비교·용어·정답 등 표가 적절한 곳은 유지했다. 위치 지시 발화와 덱·PPTX 노트를 동기화했다. 3회차는 통합반67장·실전반100장, 랩3·5개 그대로이며 랩 내용은 이번 시각 수정으로 바꾸지 않았다. 이론 추정은 기존 산식에서 통합반120.4분·실전반138.2분이며 실제 진행 시간 실측이 아니다.

변경 없는 화면은 통합반64장·실전반96장, 통합반4의 의존 갱신 외68장이 이전 PPTX XML과 바이트 일치한다. 노트67·100·69장은 분할 이론 원문과 모두 일치한다. 변경 화면은 PowerPoint 직접 PNG로 확인했으며 KPI 가장자리 배치를 수정해 다시 확인했다.

정본은 `산출물/{통합반,실전반}/{이론,실습}/NN회차`다. 제작 원고·도구·구성은 `제작용/`으로 분리했다. 19회차 위치 정리와 이후 회차 내용 확정은 다르며 4회차 이후는 검토 대기다. 1·2회차 PPTX4개는 확정 원본과 바이트 일치한다. 분할 대본을 정본으로 두고 별도 합본·낭독 사본은 반복 게시하지 않는다. 이전 중복 전달 폴더·PDF·구버전 온라인 덱은 Git 이력과 로컬 evidence에 보존했다.

산출물 Markdown·HTML 링크 누락0, 19회차 구성의 덱·PPTX·대본 경로 정상, 랩 ZIP84개 내부 바이트 일치, Python/JSON 정적 파싱 오류0, 활성 산출물 PDF0개를 확인했다. ZIP에는 해당 랩과 해당 실습 대본을 실제 상대경로로 담았다.

근거는 `.evidence/day03-layout-20261019/`의 before, changes.json, layout-check.json, canonical-files.json, publication-check.json 및 PNG다. 이전 통합반 루트는 보존용이며 앞으로 현재 저장소의 정본만 갱신한다.

PDF 생성·검토, 실제 AI·학생 코드/테스트·서비스·브라우저 실습·촬영은 수행하지 않았다. 다음 작업은 두 과정4회차 전체 내용 점검이며 마감 뒤5회차 새 세션 인계를 준비한다.
