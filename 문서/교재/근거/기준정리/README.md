# 기준 정리 장부

교재 기준 문서 정리 · 스킬화 · 레포 청소(인계: [인계_기준정리와레포청소](../../인계_기준정리와레포청소.md))의 작업 장부다. 원문 문장 하나도 장부 없이 사라지지 않게 한다.

| 파일 | 내용 | 만드는 것 |
|---|---|---|
| [새구조.md](새구조.md) | 새 문서 · 절 코드, 「갈곳」 표기법, 알려진 충돌 | 손으로 |
| `장부.tsv` | 원본 문장마다 한 행: 번호 · 파일 · 줄 · 쓰임 · 절 · 원문 · 갈래 · 갈곳 · 핵심어 · 메모 | `제작용/기준정리/장부.py`(다시 돌려도 갈곳은 이어받고, 사라진 원문은 「원본변경」으로 남김) |
| `분류/` | 묶음별 입력 · 분류 결과, 분류 [의뢰서](분류/의뢰서.md) | `제작용/기준정리/분류.py 나누기 · 합치기` |
| `자원목록.tsv` | 레포 리소스 단위별 파일 수 · 마지막 커밋 · 살아 있는 참조 수 · 같은 바이트 사본 | `제작용/기준정리/자원조사.py` |
| `자원판정.tsv` · `자원판정_보고.md` | 리소스마다 유지 · 삭제후보 · 합침후보 · 재생성물 · 판단불가와 근거 | 적대적 판정 |
