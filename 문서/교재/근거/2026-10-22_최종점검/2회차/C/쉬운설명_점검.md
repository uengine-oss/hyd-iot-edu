## 흐름(쉬운 것 → 어려운 것) 점검

- 07 단원은 저장 모양(39 표와 그래프 → 40 노드 · 레이블 · 속성 → 41 제약) → 질의의 뜻(42) → 표기(43) → 한 단계 조회(44~47) → 여러 단계 · 조건 · 집계(48~51) → 방향(52) 순서로, 앞 장의 말(행, 절, 찾은 행)로 다음 장을 쌓는다. 순서를 바꿀 곳은 없었다. 다만 「절」(44)이 정의 없이 46 · 49의 설명 낱말이 되고 있어 5번으로 44에서 세웠고, 56의 「뒤로 넘길 행」은 그 위(49 「찾은 행」)에 얹어 9번으로 풀었다.
- 08 단원(53~57)은 CREATE → MERGE → SET → 관계 생성 → 적재 · 조회 · 검사로 이어지며, 새 말은 그 장에서 정의된다. 「적재」만 풀이 없이 장 제목이 되어 10번.
- 66~72 마무리는 새 용어를 세우지 않는다(67은 앞 풀이를 모음).
