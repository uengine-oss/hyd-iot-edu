## 사용자 결정과 편성

사용자가 확인한17분9초 설비 활용 영상을 실전반으로 사용하고, 통합반은 이론의 기본 문법을 작은 예제에서 실행·변경·비교한 뒤 설비 활용으로 연결한다. 통합반 전체 대사를 실전반과 통일하지 않는다. 같은 화면·같은 사실은 재사용하되 앞에서 배운 내용을 받는 대사는 별도로 쓴다. 약10분에 억지로 맞추지 않는다. 기존 제작 당시 파일명의 통합반은 과거 배정이다.

Excel 정본 sheet1/2의19~23행을 읽기 전용 대조했다. 통합반 이론은 MATCH·WHERE·RETURN·CREATE·MERGE를 포함한다. 첫 조회 실습의 편성25분/15분, 뒤 구현40분은 유지한다. 최신 사용자 요청으로 첫 통합반 영상에 작은 생성·수정 연습을 추가하며, 뒤의 실제 모델 설계·적재·반복 검증을 대체하지 않는다. Excel 자체는 수정하지 않았다.

## 자동 음성 검사와 남은 확인

기존 활용 영상 전체는 ElevenLabs scribe_v1으로 실제 MP4 음성을 받아써72발화와 대조했다(`continuous-v3-full-audit/`). 낮은 문자 일치 대부분은 영어 식별자·숫자 표기 차이이며 한 곳의 ‘센서 노드/센서 모드’는 받아쓰기 불확실성으로 남는다. 받아쓰기를 직접 청취로 표시하지 않는다. 통합반 새 합본의 실제 MP4 전체 음성을 받아써104발화 모두 대조했다(`integrated-context-v2-full-audit/normalized-review.json`). 영어 이름·숫자 표기를 정규화한 문자 일치율은 모두0.95 이상이며104개 모두 음성이 있다. 새 기본 구간의 유온/이온 받아쓰기 차이는 발음인지 인식 오류인지 직접 청취로 확인하지 못했다. 문자 일치율을 발음·억양·자연스러움의 완전 통과로 해석하지 않는다.

실제 원본 이동 공백은 통합반100ms 초과5곳, 최대295ms. 커서 이동의 작은 공백을 출력30fps만으로 없다고 하지 않는다. 기존 선택 발화의 단어 단위 클릭 시점은 일부 앞뒤 차이가 남아 전 구간 완벽 싱크로 확정하지 않는다. 전체 주관적 직접 청취·사용자 최종 승인·네이티브 준비/학교 환경 검증은 미확인이다. 영상은 로컬 검수본이며 공개 영상 게시·Notion 편집은 하지 않았다.
