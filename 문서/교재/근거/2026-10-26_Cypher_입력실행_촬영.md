# 공통 Cypher 입력·실행 촬영

승인 Excel의 실습 제목은 유지했다. 이 기록은 온라인2 공통 Neo4j 실습의 첫 조회 구간이며, 과정별 VS Code 랩 완주나 전체 영상 완료를 뜻하지 않는다.

## 수행과 산출물

- `제작용/촬영/neo4j/조회입력_큐.json`: 입력칸 선택 → MATCH/RETURN 입력 → Run 클릭 → 두 센서 결과 확인. 새 발화3개189자, 기존 nq006 재사용.
- ElevenLabs 지정 음성/모델로 새 음성3개를 생성했다. 각각8.48·13.12·3.92초, 결과 설명 포함 발화39.36초. 비용 발생을 알린 뒤 사용자 제공 키 파일을 실행 프로세스에서만 읽었다. 키 값은 기록하지 않았다.
- ego 기존 공간2가 없어졌고 목록도 비어 있었다. 사용자의 기존 새 공간 생성 승인에 따라 공간3 `hyd practice 20261026 recovery`를 생성했다. p1 `http://localhost:7628/browser/`, 전용 실습 DB `bolt://localhost:7627`에 연결했다.
- 실제 키 입력 후 편집기 문자열을 대조하고 Run을 클릭했다. 결과 두 행의 `sen:ce`, `sen:ts1`을 확인한 뒤 결과 발화를 배치했다. 이번 쿼리는 조회만 수행했다.
- 원본 `.evidence/practice-20261026/relations-input-take01/`: 307프레임,41.013초, 실제 클릭2개. 클릭 표시 오차는 x최대0.83/y최대0.53 CSS픽셀, 클릭 시 이동 애니메이션 종료 확인.
- 합성 `.evidence/practice-20261026/relations-input-preview01/relations-input-preview01_안치윤_1080p.mp4`:40.940초,30fps, 음성4개, 자막. 영상·음성 길이 및 끝까지 디코드 통과.

## 품질 판정과 수정할 부분

**부분 리허설 결과이며 최종 영상으로 확정하지 않는다.**

1. 첫 프레임만1551×1080, 나머지306프레임은1920×1080이었다. 첫 합성은 홀수 폭으로 실패했다. 발화·조작 전72.773ms만 제외하고 합성했으며 원본과 `leading-trim.json`을 보존했다. 다음 촬영은 프레임 해상도 안정 확인 후 발화 시계를 시작한다.
2. 이동6회 중3회에100ms 이상 공백(100·183·250ms)이 있었다. 최대250ms로 추가 확인 대상이다. 촬영 전후 여유 메모리는 약2.1GB였다. 메모리가 원인이라고 확정하지 않으며, 기준에 따라 이 상태에서 추가 촬영하지 않는다.
3. 입력 중 프레임000156에서 커서가 `Component` 일부를 가렸다. 다음 입력 구간은 클릭 후 편집기 아래 여백으로 이동하고 입력한다. 결과 프레임000303은 두 행과 TS1을 짚는 커서가 읽힌다.
4. 이번 합성의 직접 청취·사용자 재생 확인은 미확인이다. 기존 결과 설명15.192초의 정상 근거는 유지한다. 문제 있는 입력 구간을 포함한 이번 합본으로 기존 정상 구간을 대체하지 않는다.
