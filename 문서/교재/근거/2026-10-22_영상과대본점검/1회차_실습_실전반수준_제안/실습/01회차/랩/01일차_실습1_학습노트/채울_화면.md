# 필요한 화면 — 빈자리

각 자리는 아래 장면과 확인 기준이 보이도록 채운다. 개인 페이지·계정 정보는 제외한다.

1. 자료 다운로드와 작업 공간 열기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 편집할 수 있는 수업용 작업 공간과 입력틀의 자리가 보인다.
2. 과정 홈과 기록 목록 만들기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 세 구획·목차와 분야·이해도·작성일 속성이 함께 보인다.
3. 기록 양식과 첫 설명 작성하기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 자료를 덮고 쓴 설명과 확인한 출처가 구분되고, 바꾼 내용에 이유와 원문 위치가 남는다.
4. 실습 결과 연결하고 다시 찾기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 같은 기록이 전체 목록과 재학습 보기에 사본 없이 보이고(이해도에 맞게 나오거나 빠짐), 출처 링크가 근거 자료로 열리며, 기대한 결과와 실제 확인 결과가 나뉘어 있다. 권한 때문에 열리지 않으면 열람 미확인으로 적는다.
