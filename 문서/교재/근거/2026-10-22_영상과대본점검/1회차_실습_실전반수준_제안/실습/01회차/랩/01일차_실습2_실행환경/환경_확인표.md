# 환경 확인표

- 프로젝트 판본(브랜치·커밋):
- 수업 설정 대조(환경 준비 안내의 값과 같은가, 비밀값 제외):
- 실행 명령의 근거 문서:

| 역할·서비스 | 종류(상시·일회성·호스트) | 기대 상태·근거 위치 | 관측 상태·종료 코드 | 접속·응답 확인 | 확인 시각 | 판정 | 남은 문제·다음 확인 |
|---|---|---|---|---|---|---|---|
| 업무 저장소 | | | | | | | |
| 상시 서비스 | | | | | | | |
| 초기화 작업 | | | | | | | |
| 프로세스 | | | | | | | |
| 호스트 워커 한 개 | | | | | | | |
| 포털·계측 갱신 | | | | | | | |

기대 상태는 compose.yaml에서 찾는다. `restart: unless-stopped`는 계속 떠 있어야 하는 서비스, `restart: "no"`는 한 번 돌고 끝나는 작업이다. healthcheck가 정의된 서비스는 그 결과까지 본다.

판정: 성공 — 해당 범위의 기준을 충족하는 근거가 있다. 실패 — 수행 결과가 기준에 맞지 않는다. 미확인 — 수행했으나 판정 근거가 부족하다. 미수행 — 확인 절차를 수행하지 않았다.

서비스 실행·상태 검사·화면 접속·계측 갱신을 각각 구분한다. 준비됨·Up·서비스 개수만으로 성공 처리하지 않는다. 종료 표시만으로 실패 처리하지 않는다.
