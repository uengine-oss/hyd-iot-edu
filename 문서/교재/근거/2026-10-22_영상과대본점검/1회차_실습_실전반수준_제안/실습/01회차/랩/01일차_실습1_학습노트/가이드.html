통합반 1회차 실습 1 — 학습노트 만들기

제작용 · 비낭독: 이론① 11장 뒤 진행한다. 아래 조작·입력·확인·오류 분기는 낭독하지 않는다. 발화는 강사가 직접 작업하며 말한다. 화면은 아직 캡처하지 않았으며 확인 문장은 해당 결과를 실제로 확인하면서 말한다. 이 대본에는 고정 실습 시간이 없다.

자료 다운로드와 작업 공간 열기

조작: 회차 안내의 실습 1 ZIP을 내려받고 압축을 푼다. VS Code의 파일 > 폴더 열기로 풀린 폴더를 연다. `학습노트_입력틀.md`와 `참고_교재_발췌.md`를 확인한 뒤 Notion의 수업용 작업 공간을 연다.

배운 개념에서 출처와 적용 결과를 다시 찾아갈 수 있는 학습노트를 만들겠습니다. 실습 자료를 받아 압축을 풀고 VS Code에서 작업 공간을 열겠습니다.

[준비 · 비낭독] 이번에는 앞으로 배운 내용을 쌓아 둘 노트를 만들겠습니다. 먼저 실습 자료를 내려받아 압축을 풀고, 이 폴더를 VS Code에서 열겠습니다. 입력틀은 작성할 항목을 확인할 때 쓰고, 실제 기록은 Notion에 남기겠습니다.

자료에는 앞에서 본 지식 자산화 설명이 들어 있습니다. 첫 기록을 쓴 뒤 이 자료와 비교하겠습니다. 지금은 입력틀에서 어떤 자리가 필요한지만 보고 Notion으로 넘어갈게요.

과정 홈과 기록 목록 만들기

조작: Notion에 새 페이지를 만들고 제목을 `내 학습노트`로 정한다. 개념 정리·참고 자료·실습 결과를 제목 블록으로 나누고 맨 위에 목차 블록을 넣는다. 각 구획에는 관련 기록의 하위 페이지나 데이터베이스를 둔다. 개념 정리 아래 데이터베이스를 만들고 분야·이해도·작성일 속성을 추가한다. 이해도 값은 설명 못함 / 대충 앎 / 설명 가능으로 둔다. 메뉴 이름은 설치된 판본에서 해당 기능을 찾아 사용한다.

과정 홈부터 만들겠습니다. 제목은 내 학습노트로 하고, 개념 정리와 참고 자료, 실습 결과를 나누어 놓겠습니다. 세 구획은 제목 블록으로 구분하고 위에 목차를 넣겠습니다. 목차에서 해당 구획으로 이동한 뒤 필요한 하위 기록을 열 수 있게 만드는 겁니다.

개념 정리에는 기록 목록을 만듭니다. 한 줄을 열면 내용을 쓸 수 있는 페이지가 됩니다. 분야는 학습 방법으로 넣고, 이해도와 작성일도 붙이겠습니다. 나중에 같은 분야를 모아 보거나 아직 설명이 어려운 기록을 찾는 데 쓸 항목입니다.

기록 양식과 첫 설명 작성하기

조작: 데이터베이스에 새 템플릿을 만든다. 본문에 내 설명 / 참고 자료와 해당 부분 / 비교 후 바꾼 내용과 이유 / 아직 모르는 질문을 넣는다. 기본 템플릿으로 지정한 뒤 새 기록을 만들고 양식이 적용되는지 확인한다.

기록할 때마다 같은 제목을 다시 적지 않도록 양식을 만들겠습니다. 내 설명, 참고 자료와 해당 부분, 비교 후 바꾼 내용과 이유, 아직 모르는 질문을 넣습니다. 무엇을 왜 고쳤는지 남겨 두면 나중에 이 설명을 다시 따져 볼 수 있습니다. 이제 이 양식으로 새 기록을 열어 보겠습니다.

첫 제목은 지식 자산화입니다. 자료를 잠깐 덮고 이렇게 써 볼게요. 배운 내용을 내 말로 남기고, 출처와 해 본 일을 연결해서 나중에 다시 확인하고 쓸 수 있게 하는 것입니다.

입력: 첫 설명은 위 발화를 직접 입력한다. 참고 자료 구획에 교재 이름과 5~9장 위치를 적고 제공된 발췌 파일을 첨부한다. 개념 기록에서 그 참고 자료로 연결한다.

이제 자료를 다시 보겠습니다. 제 설명에는 나중에 찾아 쓴다는 목적이 들어 있습니다. 다만 내 말로 썼다는 이유만으로 정확해지는 것은 아니죠. 설명이 맞는지 출처와 비교하고, 잘못 이해한 부분은 고쳐야 한다는 문장을 보태겠습니다.

비교할 때는 앞에서 본 세 가지로 나눠 보겠습니다. 사실과 다르게 쓴 문장이 있는지, 말은 이어지는데 뜻이 흐릿한 문장이 있는지, 쓰다가 막힌 곳이 있는지요. 틀리거나 흐릿한 곳은 지금 고치고, 바꾼 내용과 이유를 원문 위치와 함께 적습니다. 그대로 둔 문장도 원문과 맞춰 봤다는 걸 남기겠습니다. 막힌 곳은 그럴듯하게 채우지 않고 아직 모르는 질문으로 옮깁니다.

입력: 보탠 문장, 보탠 이유, 근거 위치(교재 9장 참고 자료와 출처 · 검색과 보완 행)를 비교 후 바꾼 내용과 이유에 적는다. 실제로 막힌 곳이 없으면 아직 모르는 질문을 꾸며 쓰지 않는다.

참고 자료에는 문서 이름만 적지 않고 어느 부분을 봤는지도 남깁니다. 이 개념 기록에서 자료를 열어 같은 설명으로 돌아갈 수 있게 연결하겠습니다.

실습 결과 연결하고 다시 찾기

조작: 실습 결과 구획에 `학습노트 만들기` 기록을 만든다. 한 작업과 기대한 결과를 먼저 적고 지식 자산화 개념 기록에 연결한다. 실제 확인 결과는 다시 찾기를 해 본 뒤 채운다. 이해도가 설명 가능이 아닌 기록을 모으는 재학습 보기를 만들고, 같은 기록이 전체 목록과 재학습 보기에 사본 없이 함께 보이는지 확인한다. 과정 홈으로 돌아가 기록을 검색하고 첨부한 출처를 다시 연다.

실습 결과에는 방금 한 일을 남기겠습니다. 과정 홈과 목록, 양식을 만들었고, 첫 설명을 출처와 비교해 고쳤다고 적습니다. 개념 설명은 이미 있으니 다시 복사하지 않고 그 기록을 연결합니다. 그리고 이 노트가 무엇을 할 수 있어야 하는지 기대한 결과를 먼저 적겠습니다. 개념에서 출처를 열 수 있고, 실습 기록에서 개념으로 돌아갈 수 있어야 합니다. 실제로 되는지는 조금 뒤에 확인하고 채우겠습니다.

이해도는 자료를 덮은 채 질문을 바꿔 물어보고 정하겠습니다. 정의를 외운 건지 내 것이 된 건지는 다른 말로 물었을 때 드러나니까요. AI가 보기 좋게 정리해 준 문서와 내 말로 쓴 기록은 무엇이 다를까요? 이 질문에 막힘없이 답하면 설명 가능으로 두고, 막히면 대충 앎으로 두고 막힌 말을 아직 모르는 질문에 적겠습니다. 보여 주기 위해 일부러 이해도를 낮추지는 않겠습니다.

재학습 보기도 확인하겠습니다. 설명 가능으로 정했다면 이 기록은 여기에 나오지 않아야 하고, 대충 앎으로 정했다면 나와야 합니다. 같은 기록이 전체 목록에도 그대로 있는지, 따로 복사된 건 아닌지도 함께 보겠습니다.

마지막으로 과정 홈으로 돌아가 지식 자산화 기록을 찾습니다. 여기서 참고 자료를 열고, 실습 결과에서도 같은 개념으로 돌아가 보겠습니다. 확인한 내용은 실습 기록의 실제 확인 결과에 적겠습니다. 열리지 않은 링크가 있으면 됐다고 쓰지 않고, 어디까지 열렸는지 그대로 남깁니다. 기록을 다시 찾고 근거를 확인할 수 있으면 이번에 만들려던 노트의 연결을 갖춘 겁니다. 다음에는 시스템 구조를 배우면서 이 노트에 각 부분의 역할을 남기겠습니다.

확인: 새 기록에 양식이 들어가는가 / 분야·이해도로 찾을 수 있는가 / 개념에서 출처를 열 수 있는가 / 실습 기록에서 개념으로 돌아갈 수 있는가 / 바꾼 내용마다 이유와 원문 위치가 있는가 / 정한 이해도에 맞게 재학습 보기에 나오거나 빠지는가 / 기대한 결과와 실제 확인 결과가 나뉘어 있는가.
오류 분기 · 해당할 때만: 새 페이지가 비어 있으면 기본 템플릿의 적용 보기를 확인한다. 링크가 다른 페이지로 열리면 실제 참고 자료 페이지 링크를 다시 연결한다. 확인하지 못한 항목은 미확인으로 남긴다. 공개 게시·학생 제출 대기·불필요한 꾸미기는 진행 조건으로 두지 않는다.
