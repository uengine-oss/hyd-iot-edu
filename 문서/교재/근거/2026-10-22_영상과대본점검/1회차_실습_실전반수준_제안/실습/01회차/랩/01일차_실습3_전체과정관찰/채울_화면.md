# 필요한 화면 — 빈자리

각 자리는 아래 장면과 확인 기준이 보이도록 채운다. 지금 관찰한 사건의 ID·값만 쓴다.

1. 자료 다운로드와 기록할 자리 열기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 빈 근거 연결표·관찰 기록과 실습 2에서 유지한 포털·워커 연결 상태가 보인다.
2. 경보에서 사건 찾기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 경보 당시 값과 계속 바뀌는 현재 값이 구분되고, 사건이 참조하는 경보 ID가 보인다.
3. 진단과 추천의 근거 확인: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 원인 후보마다 태그·집계 구간·판별 기준·실제 값과 선택한 조치·대안이 보인다.
4. 승인과 명령 처리 확인: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 승인 전 명령 기록 유무, 승인 기록, 같은 명령 ID의 ACK가 차례로 보인다.
5. 완화와 정비 작업 구별하기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 재관측의 유온·경보 상태와 핀 세척 작업지시의 현재 상태가 따로 보인다.
6. 작업지시에서 근거로 거슬러 가기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 연결표의 각 행에서 참조 값과 도착 기록 ID를 원기록과 대조한 판정이 보인다.
