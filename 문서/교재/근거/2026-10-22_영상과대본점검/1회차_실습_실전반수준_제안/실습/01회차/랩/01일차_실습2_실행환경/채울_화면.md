# 필요한 화면 — 빈자리

각 자리는 아래 장면과 확인 기준이 보이도록 채운다. 비밀 설정값·토큰·키는 제외한다.

1. 자료 다운로드와 프로젝트 열기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 실습 자료 창과 HYD 프로젝트 창이 구분되고, 프로젝트 루트의 compose.yaml과 ot·dmz·it 폴더가 보인다.
2. 도구와 배포 설정 확인: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 도구 버전 출력과 Docker 엔진 연결(`docker info`)을 따로 판정한다. 버전 출력만으로 서비스 정상이라 하지 않는다.
3. 업무 저장소와 서비스 기동: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 업무 저장소 준비 → 서비스 기동 → 호스트 워커 한 개의 순서와 각 단계의 준비 확인이 보인다.
4. 상태와 접속 결과를 확인표에 남기기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 상시 서비스의 실행·상태 검사와 초기화 작업의 종료 코드·로그를 나눠 판정하고, 확인표에 기대/관측/근거/판정이 채워진다. 미확인 항목이 있으면 그대로 보인다.
5. 다음 실습으로 이어가기: 해당 조작과 결과가 보이는 화면. 미촬영.
   - 확인 기준: 확인표의 판정으로 실습 3 선행 조건의 충족 여부가 드러난다.
