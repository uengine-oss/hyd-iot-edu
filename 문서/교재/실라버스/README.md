# 실라버스 정본과 적용 상태

실라버스의 고정 · 변경 범위는 [기준_공통](../기준_공통.md) 맨 앞 「범위와 시간」, 두 과정의 차이는 G2, 오프라인 Notion 선택 실습은 [기준_실습_도구](../기준_실습_도구.md) T3이 정본이다. 온라인은 유지하며 개별 산출물의 적용 완료는 별도 검증한다.

C67 최종 편성: 온톨로지 구축 완주와 에이전트의 다양한 활용·구현·검증을 기준으로 전체 흐름을 재검토했다. 정본은 `피지컬AI_실라버스_최종본.xlsx` 네 시트다. 온라인 시간·날짜는 유지하며 영상 길이의 상한으로 쓰지 않는다. 오프라인은50분 수업·10분 휴식×4교시로 편성했다. 이론이 있는 회차는 첫 교시50분이며 마지막 실행 중심 회차는 실습 안에서 설명한다. 기본200분+휴식40분이며 실제 진행은 강사가 조절한다.

온라인1회차는 공통이다. 이후 공통 도구는 같은 실습을 사용할 수 있으나 대본의 설명 초점을 과정별로 둔다. VS Code는 구현 요구·활용 결과도 구분한다. 포털의 일반 BPMN 임의 배포·새 도구 추가를 요구하지 않는다. 직접 작도와 기존 등록 흐름의 실행을 구분하고, 마지막 교대만 현재 허용된 제공 BPMN 편집·등록 범위를 사용한다. 자세한 규칙은 [기준_공통](../기준_공통.md) G2가 정본이다.

C66(VS Code 최종 흐름)에 따라 외부 MCP·직접 만든 도구·자기 Notion 퀴즈·실제 문서 추출을 복원했다. 포털 경계와 독립 랩의 허용 범위를 구분한다. C63의 실제 랩·지원 범위 대조와 후속 제작 요구를 반영했다. 제공 추출 후보 검토·실전 활용 출력·ABC의 업무 결과 해석·교대 인수인계 연결을 학생 행위로 구체화했다. 랩 코드·개별 대본·영상은 편성 수정에서 변경하지 않았다. Notion 최종 반영·강사 배정 첨부·기존 자료 다운로드는 C64 게시 기록을 따른다. 온라인1과 촬영된 Cypher는 공통 유지하며 실전 설명을 억지로 어렵게 만들지 않는다.

## 배정과 검증

강사 배정은 오프라인에만 둔다. 공개 정본은 실명을 제외하며, 사용자 전달 파일에만 날짜·주강사·보조강사를 연결한다. 초반 이론·BPMN은 총괄 강사, 온톨로지는 해당 전문 강사, 에이전트는 담당 강사가 맡고 직접 제작 활동에 보조강사를 배치했다.

네 시트의 공개본·배정본 내용 일치, 온라인 시간·날짜 보존, 온라인 강사 제거, 오프라인19회의 내용별 수업 단위와200분 합계를 확인했다. 이는 편성값이며 학생 수행 실측이 아니다. 기존 대본·가이드·영상·Notion 첨부의 최신 반영은 별도 작업이다. [변경·검증·남은 반영](../근거/2026-10-27_실라버스_수업단위와강사배정.md).

최신 전체 흐름·시간·지원 범위 검토: HYD 도입·실제 포털 시연 복원,38회차 연결, 실전반8명 운영 및 선택적 보조 배정.

최신 시간·배정은 C62를 따른다. 온톨로지 이론과 BPMN은 총괄 강사, 온톨로지 실습·에이전트는 두 실습 강사가 분담한다. 교대의 에이전트 구성은 해당 전문 강사가 맡는다.
