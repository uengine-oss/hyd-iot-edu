# 실라버스 정본과 적용 상태

2026-10-27 최종 편성 수정. 정본은 `피지컬AI_실라버스_최종본.xlsx` 네 시트다. 온라인 시간·날짜는 유지하며 영상 길이의 상한으로 쓰지 않는다. 오프라인은 같은 과정의 온라인 주요 실습을 선별하고 활동별 시간을 배정했다. 이론은 온라인 선행학습을 고려해25~40분으로 배정했으며 마지막 실행 중심 회차는 실습 안에서 설명한다. 기본200분+휴식40분이며 실제 진행은 강사가 조절한다.

온라인1회차는 공통이다. 이후 공통 도구는 같은 실습을 사용할 수 있으나 대본의 설명 초점을 과정별로 둔다. VS Code는 구현 요구·활용 결과도 구분한다. 포털의 일반 BPMN 임의 배포·새 도구 추가를 요구하지 않는다. 직접 작도와 기존 등록 흐름의 실행을 구분하고, 마지막 교대만 현재 허용된 제공 BPMN 편집·등록 범위를 사용한다. 자세한 규칙은 [공통 기준](../2_기준.md)이 정본이다.

## 배정과 검증

강사 배정은 오프라인에만 둔다. 공개 정본은 실명을 제외하며, 사용자 전달 파일에만 날짜·주강사·보조강사를 연결한다. 초반 이론·BPMN은 총괄 강사, 온톨로지는 해당 전문 강사, 에이전트는 담당 강사가 맡고 직접 제작 활동에 보조강사를 배치했다.

네 시트의 공개본·배정본 내용 일치, 온라인 시간·날짜 보존, 온라인 강사 제거, 오프라인19회의 내용별 수업 단위와200분 합계를 확인했다. 이는 편성값이며 학생 수행 실측이 아니다. 기존 대본·가이드·영상·Notion 첨부의 최신 반영은 별도 작업이다. [변경·검증·남은 반영](../근거/2026-10-27_실라버스_수업단위와강사배정.md).
