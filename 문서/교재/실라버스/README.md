## 제공 파일과 남은 제작

공개 Git의 정본은 강사 실명을 제외한다. 사용자 제공 전체일정 원본을 보존하고, 같은 내용에 날짜·주강사·보조강사를 연결한 개편본 XLSX를 두 Notion 학습 포털에 실제 파일로 첨부했다. 기존 활동을 분할한 행은 대응 활동의 강사 배정을 이어받으며 강사별 총 시수는 새 시간표에 따라 달라진다.

새 활용 랩·입력·가이드·대본·ZIP·캡처는 다음 제작 단계다. 기존 산출물의 확정 근거는 보존하고 새 편성 적용 완료와 구별한다. 선행 자료 조기 제공·별도 랩 DB 등 환경 준비·학생 수행 시간은 [남은 일](../6_남은_일.md)을 따른다. [검증 및 게시 근거](../근거/2026-10-26_실라버스_동기화.md).
