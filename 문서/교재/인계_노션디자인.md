## 확인과 주의점

21개 페이지를 다시 읽어 본문의 GitHub 자료 링크·Notion 파일 첨부 참조 보존을 확인했다. 속성(수업 날짜·주제·회차 등)은 원래 값과 같았다. 기존 본문의 이모지 제목은 간결하게 바꾸고 핵심 설명은 주제색 콜아웃으로 옮겼다. 회차 화면·카드·홈을 실제 브라우저에서 확인했다. 여백 후속 수정은 마지막 피드백에 따른 별도 적용으로 기록한다.

Notion 커넥터 문서의 heading `{color=...}` 구문은 현재 연결에서 글자로 노출되어 제거했다. 인라인 span/콜아웃의 색은 실제 화면에 적용된다. 일반 빈 줄은 제거될 수 있으므로 실제 표시를 확인한다. 브라우저 첫 화면이 잠시 이전 캐시를 표시할 수 있어 로딩 뒤 최신 상태를 확인한다. API 성공만으로 시각 검수를 대신하지 않는다.

변경 전 응답: `.evidence/notion-design-before.json`. 링크·스타일 검증: `.evidence/notion-design-verification.json`. 화면: `.evidence/notion-design-cards.png` 및 후속 여백 검수 화면. 로컬 evidence는 공개 Git에 올리지 않는다. 새 디자인을 이유로 기존 촬영용 Notion 학습노트나 확정 실습 영상을 재제작하지 않는다.
