# 인계 — 기준 문서 정리 · 스킬화 · 레포 청소

2026-10-28, A 교재 세션이 남긴다. **오프라인 이론 덱 재작업([인계_오프라인이론덱.md](인계_오프라인이론덱.md))보다 먼저 한다.**

## 왜

사용자: 「문서가 그렇게 많나, 이해가 안 됨」 「이론 덱, 대본 공통, 실습 랩 코드, 촬영 방식 길뚫기, 실습 가이드 — 이것만 있으면 되지 않나」 「최적화, 레포 청소」 「열화 · 누락 없이 하나씩 제대로」.

현재 기준 문서 9개 약 19만 자(`2_기준` 3.8만 · `기준_이론덱` 4.2만 · `기준_실습대본` 2.7만 · `기준_이론대본` 2.2만 · `검증과마감` 2.1만 · `기준_실습랩` 1.8만 · `기준_실습가이드` · `실전반_기준` · `4_만드는_법`), 교재 폴더 문서 32개. 규칙 안에 사용자 인용 · 날짜 · 경위, 적용하지 않는 옛 절차(PDF, 아스트라 위임 등), 같은 규칙의 다른 값, 인계 파일 속 규칙이 섞여 세션이 기준을 놓친다.

이미 확인된 충돌(정리 때 최신 결정으로 하나만 남긴다):
- 오프라인 「다음 회차 연결」(2_기준 112줄) ↔ 기준_이론덱 29-2번 · 기준_이론대본 43번의 단원 밖 예고 금지 → 지금은 C70 예외 조항(표지 노트 · 마지막 장 노트)으로 덧댐.
- 기준_이론덱 14절 표지 「과정: … N회차」 ↔ C70 「화면에 회차 번호 금지」 → 예외 조항으로 덧댐.
- 낭독 속도: 기준_이론대본 39번 · 검증과마감 120줄 「분당 275음절」, 인계_영상과대본점검 69줄 「422자/분」, 실측 「분당 약 297음절 + 장당 1.3초」(`제작용/오프라인/decks/시간.py`, 강사 복제 음성 영상 292장).

## 목표 구조

기준은 다섯 개, 규칙만 짧게(이력 · 인용 · 날짜는 `5_결정_기록.md`로):

| 기준 | 담는 것 |
|---|---|
| 이론 덱 | 덱의 틀, 장 쓰는 법, 화면 금지어, 과정 · 온라인/오프라인 차이 |
| 대본 · 노트(공통) | 말투, 길이 · 시간 산식(실측 템포 하나), 노트 꼴 |
| 실습 랩 코드 | 목적 · 제공 범위 · 학생 구현 · 검증 |
| 촬영 | 도구별 길뚫기 · 녹화 · 음성 · 합성 |
| 실습 가이드 | 학생용 가이드의 구성과 말투 |

기록(기준 아님): 1 목적과 방향 · 3 현황 · 5 결정 기록 · 6 남은 일 · 인계. 인계에는 규칙을 쓰지 않고 기준 번호만 가리킨다.
스킬: 다섯 갈래마다 하나(기존 `hyd-course-deck` · `hyd-lab-guide` · `hyd-lecture-video` · `hyd-portal-video` · `lecture-*`를 이 구조로 정리). 스킬 = 짧은 체크리스트(SKILL.md, 기준 번호만 가리킴) + 그 갈래 기준 문서 하나. 같은 규칙을 두 곳에 쓰지 않는다. 스킬 끝에 「체크리스트 항목마다 지켰는지」 대조 보고를 넣는다.

## 방법(열화 · 누락 없이)

1. **목록(수정 없음):** 레포 문서 · 스크립트 · 산출물을 쓰임새로 분류(기준 · 기록 · 인계 · 도구 · 산출물 · 잔재). 기준 문서 9개 + CLAUDE.md · AGENTS.md의 교재 규칙 + 인계 · 결정 문서 속 규칙을 **문장마다 번호를 붙인 장부**로(파일:줄 · 원문 · 갈래). 장부는 레포 파일(`문서/교재/근거/기준정리_장부.md` 등)로 두고 단계마다 갱신한다.
2. **갈 곳:** 장부의 모든 행에 하나 — 「새 기준 ○번으로 옮김」 「○번과 같아 합침」 「충돌, 최신 결정 ○○을 따름」 「이력이라 결정 기록으로」 「폐기(까닭)」. **합침 · 충돌 · 폐기 목록을 사용자에게 확인받는다(확인 1).**
3. **갈래 하나씩 새로 쓰기:** 이론 덱 → 대본 · 노트 → 실습 랩 코드 → 촬영 → 실습 가이드. 한 갈래를 끝내고 4 · 5를 통과해야 다음.
4. **누락 검사(기계, 모두 0이어야 통과):** 장부의 모든 행에 갈 곳이 있다 / 「옮김 · 합침」 행의 핵심 낱말이 새 문서에 실제로 있다 / 옛 문서를 가리키는 링크 · 스킬 · CLAUDE.md · AGENTS.md 참조가 남지 않았다. 검사 스크립트는 일부러 한 행을 빼서 잡히는지 확인한다.
5. **열화 검사:** 갈래마다 옛 규칙 ↔ 새 규칙 대조표를 사용자에게 보인다(뜻이 약해진 곳, 「항상」→「가능하면」 등)(확인 2).
6. **스킬 정리:** 다섯 스킬이 새 기준만 가리키게. 옛 스킬 · 중복 스킬은 합친다.
7. **레포 청소:** 잔재 후보(다 쓴 인계 · 옛 지시문 · 쓰지 않는 도구 · 중복 산출물) 목록을 확인받은 뒤 지운다(확인 3). 다른 세션(B 실습)의 파일 · `other-pc` · `replay-mode` 브랜치는 건드리지 않고 목록만 넘긴다. 커밋은 경로 지정, 삭제는 git으로 되돌릴 수 있게.

사용자 확인은 1 · 2 · 3 세 번뿐이고, 나머지는 묻지 않고 진행한다. 끝나면 3_현황 · 6_남은_일 · 인계를 갱신하고 오프라인 덱 재작업으로 넘어간다.
