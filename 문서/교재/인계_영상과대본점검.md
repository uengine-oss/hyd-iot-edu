## 3. 절대 규칙 — 어기면 산출물이 무효다

- **키(ELEVENLABS_API_KEY 등)를 어느 브랜치 · 파일에도 커밋 · 저장 · 출력하지 않는다.** 저장소는 공개다. 새 계정(pro) 키는 세션마다 사용자에게 받는다 — 키 한 줄만 든 텍스트 파일을 채팅에 올려 달라고 하거나(올린 파일은 `/root/.claude/uploads/<세션>/` 아래에 생긴다), 환경 설정의 `ELEVENLABS_API_KEY`를 새 계정 키로 바꿔 달라고 한다. 파일이면 **실행할 때만** 읽는다: `ELEVENLABS_API_KEY="$(tr -d '[:space:]' < <올린 파일>)" python3 …`. 세션 환경변수(옛 계정)가 먼저 잡히므로 새 계정을 쓸 땐 명령마다 덮어쓴다. 채팅에 붙인 키를 디스크에 쓰는 동작은 자동 권한 검사가 막는다 — 우회하지 않는다. 사용자 발화 기록을 저장소에 옮길 때 키 문자열은 지운다.
- **맑은 고딕 글꼴 파일을 저장소에 올리지 않는다.** 사용자에게 받아 `/usr/share/fonts/truetype/malgun/`에 두고 `fc-cache -f`. 덱 빌더의 `--render`는 맑은 고딕이 없으면 멈춘다(대체 글꼴 렌더는 화면 위치 대조용일 뿐 글겹침 판정 근거가 아니다).
- **3회차 이후는 사용자가 지시하기 전에 저장소의 실전반 대본 · 덱을 고치지 않는다.** 시안은 세션 scratchpad에서 만든다.
- **1회차와 통합반 대본 · 덱 · 영상을 이 재편으로 건드리지 않는다.** 3회차는 다른 PC 세션 소관 — 지시 전에 손대지 않는다.
- **음성 전에**: 대본 화면 대조, 덱 렌더 PDF로 `python3 제작용/기존제작/tools/deck/글겹침.py <덱.pdf>` 0곳(PyMuPDF 필요).
- **영상마다**: `python3 제작용/기존제작/tools/video/검사/말머리_잘림.py <영상>` → 「앞이 말소리인 자리 0」, `python3 제작용/기존제작/tools/video/검사/장넘김_싱크.py <영상> <시간표.md>` → 「못 맞춘 기대 0 · 기대 밖 바뀜 0」, 바뀐 장은 프레임을 뽑아 눈으로 본다.
- **영상 작업 중 `course/videos/<과정>/seg_*` · `tmp.wav` · `list.txt`를 지우거나 커밋하지 않는다**(stop 훅이 untracked로 알려도 둔다). 진행 확인은 `ps aux | grep tools/video`(한글 `pgrep`은 못 찾고, 영상 경로 `pkill`은 자기 셸까지 끈다). 한 출력 폴더에 조립을 둘 돌리지 않는다. 조립은 백그라운드 실행 제한을 1시간 이상 준다(10분 제한으로 끊긴 적 있음).
- **영상 작업 중 브랜치를 바꾸지 않는다** — 다른 브랜치 일은 `git worktree add --detach <폴더> origin/main`. 검사는 other-pc에서.
- **영상 한 편은 100 MiB 아래**(GitHub 한도). 실전반 2회차 04편이 97.6 MiB였다.
- 커밋은 경로 지정(`git add .` 금지).
