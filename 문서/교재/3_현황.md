# 교재 현황

## 2026-10-22 갱신 — 현재 우선순위

현재 범위는 완성된 Notion 학습노트의 촬영 전 자료 동기화다. **학습노트 하나 → 여러 주제 카드 → 자유로운 내용·하위 페이지**를 유지한다. 홈은 큰 표지 없이 작은 이미지 카드로, 전체 주제 표는 이름·분야·이해도가 보이게 구성했다. 주제별 예시와 재사용 템플릿을 포함한 두 과정 공통 29단계 대본·입력·가이드 HTML·ZIP을 동기화했다. 디자인·입력 정본은 촬영 준비 문서에 연결한다. 승인된 2분40초대 샘플처럼 위치 안내→조작·입력→결과 확인을 나누고, 반복 설명만 줄인다. 이론/실습/실수노트 분류나 별도 자료 DB를 강제하지 않는다. 본 촬영·전체 음성 생성·50분 실측은 미수행이다.

현재 정적 동기화 판정과 후속 실행 미확인은 [Notion 촬영 준비 근거](근거/2026-10-22_Notion_촬영준비.md), 원고와 준비물은 [촬영 준비](../../제작용/촬영/notion/촬영준비.md)에 있다. 이론 확정·기존 후속 실습·시스템 미커밋은 보존한다. Claude와 사용자 전경 작업은 조작하지 않는다. 아래 과거 샘플/VM 조사 기록은 당시 이력이며 현재 시작 순서를 뜻하지 않는다.

2026-10-20. 온라인 이론 전체 확정과 기존 실습 내용·정적 근거는 유지한다. 현재 우선순위는 arrows.app·bpmn.io·Neo4j Browser·VS Code·Notion 각각 약 5분의 실제 제작 가능성 검증 샘플이다. 빠르게 산출물을 만들고 저장·결과를 확인하는 과정을 보여 주며 설명 대본·음성은 실제 흐름에 추가한다. arrows의 짧은 녹화 시험과 음성 파일만 있고 5분 완성 영상은 없다. 이번 인계 세션은 문서만 동기화했다. [샘플 인계](인계_5분샘플_제작검증.md)와 [작업 상태](작업상태.md)를 따른다.

강의 영상(2026-10-21): 통합반 1회차 이론 세 편(01 지식자산화 10:46.4, 02 시스템구조 43:32.6, 03 온톨로지 38:01.4)을 안치윤 복제 음성(eleven_v4)으로 만들었다. 크레딧 16,394. 영상마다 넣은 쉼 앞 말머리 잘림 0곳, 화면 전환과 시간표의 장 시작 시각 일치(01 10곳 · 02 33곳 · 03 32곳), 소리와 화면 길이 일치를 쟀다. 소리는 사용자 청취 판정 대기. 음성 전에 대본을 장 화면 · 실습 대본과 대조해, 화면에 없는 것을 가리키는 말(점선 · 두 점 · 그래프 · 화살표 글자 · 이 그림 · 마지막 화살표 · 오른쪽 순서)과 실습 목적을 비튼 안내(자료 내려받기 · 첫 기록 · 그림 파일 저장)를 고쳤다. 같은 덱을 쓰는 실전반 1회차 대본도 같은 문장을 맞췄다. 덱 71장 기본 관계도에 「구성 요소」를 넣었다(두 과정 PPTX · 원고 MD · 실습4 발췌와 ZIP). 영상 도구 결함 셋을 고쳤다: 쉼이 다음 말머리를 자르던 것, 1.1 같은 숫자 가운데서 문장을 끊던 것, 구획 길이 오차가 쌓여 자막 · 시간표가 영상보다 앞서던 것. 낭독 추정(가중 음절 · 분당 275, [1회차 근거](근거/2026-10-19_01회차_두과정_내용검토.md)의 이론 합 99.5분)과 실제 영상: 01 11.7→10.8분, 02 47.5→43.5분, 03 40.7→38.0분, 합 99.9→92.3분(-7.6분, 약 8% 짧음). 추정의 99.5→99.9분은 이번 대사 수정분이다. 시간을 맞추려고 쉼을 늘리지 않았다(39번). 실전반 1회차 세 편(2026-10-22)은 본문이 통합반과 같아 통합반 음성 캐시로 만들었다(크레딧 0, 길이 같음, 잘림 0 · 넘김 일치). 같은 날 1 · 2회차 대본 · 덱 최종 점검(결함 · 윤문 · 쉬운 설명)을 반영해 **1회차 영상 6편은 지금 대본과 다르다** — 바뀐 장만 음성을 새로 사서 다시 만든다. 전 · 후는 [근거/2026-10-22_최종점검](근거/2026-10-22_최종점검/). 영상 목록은 [course/videos/README.md](../../course/videos/README.md).
