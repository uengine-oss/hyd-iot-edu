## 이번 질문: 확답(짧게)

파일은 고치지 않는다. 답(-o)만 짧게 쓴다. 사용자에게 그대로 보여 준다.

사용자: 「억지로 내용을 추가해서 어색하거나 그런 거 안 넣겠다는 거지? 그래서 실라버스 · 시간 조율한 것 등등 다 결정된 대로 진행하겠다는 건지 확답을 달라.」

다음 각각에 「예 / 아니오 + 한 줄」로 답해라. 아니오거나 조건이 있으면 그 조건을 분명히.
1. 시간을 채우려고 억지로 내용을 덧붙이거나, 같은 설명을 되풀이하거나, 장 뒤에 보충을 붙이지 않는다.
2. 실라버스의 행 · 제목 · 상세 항목은 그대로 두고, 시간은 41번(이론 합 10분 마지노선, 늘어나는 것은 의미 있을 때만) 안에서 조율한다.
3. 오늘 결정된 것(실습 구조 설명 → 행위 → 결과 리뷰 → 완성본과 단계 시간 자율, Notion 50분 고정, 복습 · 퀴즈는 이론 합에 포함하고 학습 대기는 따로 셈, 수치 · 영어 · 식별자 규칙, Cypher 쿼리 같은 배우는 이름은 흐리지 않음)을 그대로 따른다.
4. 마지노선보다 모자라면 억지로 채우지 않고, 근거 있는 깊이나 판단 활동만 찾고, 그래도 모자라면 사용자에게 보고한다.
5. 전문성(정식 용어 · 정의 · 값)은 화면에 지키고, 어려움은 대본의 설명 순서로 낮춘다.
6. 진행 순서: 2회차 대표 단원 예시 → 사용자 확인 → 2회차 전체 → 1회차 → 3회차.
참고: 시간 도구 `만들기/tools/deck/대본시간.py`는 방금 고쳤다(이론 합 = 본문 + 마무리, 마지노선 판정, `> [대기 N초] 목적` 학습 대기 따로 집계).
