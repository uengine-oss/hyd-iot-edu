**④ 압축된 장의 틀과 조립 방식**

**단원 메타데이터 생성안은 채택할 만하다. 다만 ‘목표 한 줄·용어·퀴즈 후보’만으로는 부족하다.** 필수 추가 항목은 안정된 식별자, 선수 개념, 실라버스 상세 항목 대응, 퀴즈의 근거 장, 사건 식별자다.

본문을 과정별로 다시 생성하는 방식이 아니라 **검토된 공통 장을 선택하고, 허용된 도입·정리 장만 정해진 규칙으로 생성하는 방식**을 권고한다.

빈칸을 둔 것은 이번 작업에서 모든 실습 안내의 공통 ID와 상세 항목 ID를 새로 작성하지 않았기 때문이다. 그 목록과 오프라인 전용 활동의 고유 장 수는 **미확인**이다.

조립 도구는 다음 순서로 동작하는 것이 적절하다.

1. 시간표의 단원·실습 ID를 해석한다.
2. 선수 개념과 실라버스 상세 항목의 누락을 확인한다.
3. 공통 본문과 공통 노트를 변경 없이 가져온다.
4. 허용된 표지·목표·목차·용어·퀴즈를 생성한다.
5. 공통 ID와 배포 장 번호의 대응표, 대본 대응표를 만든다.
6. 선택한 문항의 근거가 실제 조립본에 있는지 확인한다.
7. 공통 장의 내용이 과정마다 달라지지 않았는지 비교한다.

부족한 정의를 자동 문장 생성이나 과정별 패치로 메우면 안 된다. 필요한 공통 단원이 빠졌다는 오류를 내고 편성을 검토해야 한다.

현행 조립은 제목과 원문 문자열에 의존한다. 새 구조에서는 제목을 바꿔도 유지되는 ID로 전환해야 한다. 특히 `str.replace`식 손질 목록은 공통 본문 조립 경로에서 제거하는 것이 맞다.

**유형별 한 장의 구성**

아래 한도는 빌더의 `COUNTS` 값이다. 최대치는 채워야 할 목표가 아니다. 본문 공통으로 제목 한 줄, 메시지 한 문장, 노트 보통 3~4문장·최대 5문장을 적용한다.

| 유형 | 빌더 요소 수 | 압축된 장의 채우는 방식 |
|---|---:|---|
| 흐름 | 2~6 | 하나의 입력→결과 경로. 각 단계는 이름과 짧은 결과로 두고 전이 이유는 대본 |
| 카드 | 2~4 | 같은 질문에 대한 동등한 구성요소·대안. 정의와 핵심 차이를 화면에 남김 |
| 비교 | 정확히 2 | 같은 기준으로 비교하는 두 대상. 서로 다른 기준의 설명을 양쪽에 섞지 않음 |
| 표 | 2~9 | 정의·판정 기준·실제 값의 대응. 장문 문단을 셀에 숨기지 않음 |
| 단계 | 3~5 | 순서가 본질인 절차. 단계 이름·완료 결과는 화면, 수행 이유는 대본 |
| 강조 | 0~3 | 한 결론이나 경계. 실제 근거 없이 구호 한 줄로 쓰지 않음 |
| 그림 | 0~4 | 그래프·화면·도판이 주인공. 핵심 관측점만 짚음 |
| 삽화 | 0~16 | 대상 이름·관계·실제 값 라벨. 설명 문장을 그림 주변에 붙이지 않음 |
| 풀이 | 2~6 | 한 개념의 정의와 구성. 낱말 하나당 장을 만들지 않고 하나의 의미 체계로 묶음 |
| 구조 | 2~12 | 영역과 구성요소의 배치. 실용적으로 7~9개 안팎을 먼저 검토하고 최대치까지 채우지 않음 |
| 파이프라인 | 3~7 | 같은 데이터가 지나가는 경로. 역할·입출력 중심, 필수 아이콘 사용 |
| 관계도 | 2~8 | 작은 관계 묶음. 방향과 정본 관계명을 유지 |
| 코드 | 0~4 | 실제 메시지·레코드·쿼리 중심. 핵심 필드 2~4개를 설명하고 나머지는 묶어서 해설 |
| 문답 | 2~5 | 질문과 선택지. 선택지 수와 정답·오답 근거를 함께 관리 |
| 표지 | 0 | 기관·과정·제목·부제와 승인된 아이콘 체계 |
| 목차 | 2~9 | 실제 편성된 표시 단원·실습 목록 |
| 간지 | 0 | 고정 단원 번호·이름·구분. 시간·다음 수업 안내 없음 |

추가 적용 원칙은 다음과 같다.

- 제목 28pt·메시지 16pt 등 기존 디자인을 유지한다. 글자를 줄여 압축하지 않는다.
- 16개 라벨을 사용하는 승인 지도는 이미 삽화 한도에 닿는다. 여기에 Evidence·AnomalyPattern·Step을 모두 덧붙이지 않는다.
- 지도에 없는 AnomalyPattern·Evidence는 새 60~61에서 보존한다. 지도 한 장으로 관련 개념 전부를 대체하지 않는다.
- 실제 값에는 단위·대상·필요한 시각을 남긴다. 짧게 만들기 위해 수치의 의미를 결정하는 단위를 제거하지 않는다.
- 노트에는 공통 최소 해설만 둔다. 과정별 장문 설명은 별도의 강사 대본에서 관리한다.

메타데이터 방식의 핵심 보완은 **자동 작성보다 자동 선택·조합에 가깝게 만드는 것**이다. 생성 도구가 목표·정답·용어 설명을 매번 새로 쓰면 공통 교재의 검토 범위가 다시 늘어난다.

**과정별 대본**

| 구분 | 대본 구성 | 분량 판단 |
|---|---|---|
| 공통 PPTX 노트 | 정의·그림 읽는 순서·핵심 값·판단 경계의 최소 해설 | 모든 과정 동일. 3~4문장 중심, 최대 5문장 |
| 통합반 온라인 | 공통 핵심+이유와 단계별 풀이+필요한 보충 사례 | 가장 자세한 설명. 실라버스 행별 추정 시간을 보고 |
| 실전반 온라인 | 공통 핵심+실제 사례를 이해하는 데 필요한 풀이 | 중복·보충을 줄임. 필수 정의와 실패 조건은 유지 |
| 통합반 오프라인 | 공통 핵심+학생 결과물 확인에 필요한 설명 | 실습 직전 필요한 판단 기준 중심 |
| 실전반 오프라인 | 같은 공통 핵심을 해당 편성에서 읽음 | 단원 조합이 다르므로 통합반 오프라인보다 장마다 반드시 짧게 만들 필요는 없음 |

저장은 `핵심 / 풀이 / 보충`의 세 블록을 권고한다. 출력은 과정별로 **바로 읽을 수 있는 완성 대본**을 만들어야 한다. 강사가 현장에서 보충 문장을 골라 읽도록 두지 않는다.

원본 실라버스의 이론 합계는 통온 **905분**, 실온 **635분**, 통오 **355분**, 실오 **325분**이다. 그러나 통온·실온의 첫날은 모두 110분이고 마지막 두 복습은 모두 60분이다. 따라서 전체 대본의 기본 길이 관계와 **모든 행을 같은 비율로 줄이는 규칙**을 구분해야 한다.

분당 260음절은 추정 도구로만 사용한다. 실제 낭독 시간, 그림을 가리키는 시간, 퀴즈 대기 시간은 아직 **미확인**이다.
