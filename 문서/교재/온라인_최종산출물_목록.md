# 온라인 산출물 목록 — 회차별 확정 상태

## 현재 적용 — 1–2회차 최종 확정

통합반·실전반 **1–2회차의 이론·이론 대본·교육 설계·랩·입력자료·온라인 제작 참고 가이드를 내용 최종본으로 확정했다.** 공통 교재·포털 실습을 유지하고 같은 주제 안에서 실전·응용한다. 1회차의 확정 근거는 재사용했다. 2회차는 통합반72장·4랩, 실전반107장·5랩이며 실라버스에 따른 단원 배정 차이를 유지했다.

2회차의 부품 조회 누락, 앞 관계 그림과 원자료의 인계, 입력 속성 불일치, 억지 오류 생성, 조건표의 복수 조건·감점·미확인 처리와 이론 연결을 수정했다. 발표자 노트·합본·낭독본·HTML·ZIP을 동기화·검증했다. 실습 대본은 내용·순서 정합 확정이며 촬영 때 발화·전환·속도만 튜닝할 수 있다.

실제 AI·코드·테스트·HYD/DB·브라우저 실습·캡처·촬영·전체 시간 실측은 미수행이다. **PDF 제작·검토는 제외**하고 기존 파일은 보존했다. 통합반3–11회차·실전반3–8회차는 내용 검토 대기다. 구체적 결함 없이 확정 구간을 반복 검토하지 않는다.
