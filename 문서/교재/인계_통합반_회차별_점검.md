# 회차별 두 과정 내용 검토 인계 — 현재 진입점

## 현재 적용 — 공통 범위 정정

교재·포털 실습은 동일하다. 대본·랩은 같은 주제 안에서 과정별 진행 및 실전·응용에 맞춘다. 불필요한 차별화와 별개 주제 추가는 하지 않는다. [현행 기준](2_기준.md)을 따른다. 통합반·실전반 1회차는 이전 내용 대조·정적 검증을 완료했으나, 최신 사용자 결정에 따른 **교재·포털 실습 공통화와 같은 주제 안의 실전·응용 범위 정정**을 다시 열었다. 이번 문서 동기화는 기준·현황 정정이며 산출물 재수정·재검증 완료를 뜻하지 않는다. 다른 구체적 결함 없는 내용까지 반복 수정하지 않는다. 통합반 2–11회차·실전반 2–8회차는 전체 내용 검토 대기이며 실제 실행·촬영·시간 실측은 미수행이다.

## 사용자 직접 새 세션 재개 — 최종 인계

상세 범위·수정 이유·검증·다시 여는 조건은 [1회차 마감](근거/2026-10-19_01회차_두과정_내용검토.md)을 따른다. 먼저 1회차의 최신 공통 범위 정정을 반영·검증한다. 그다음 두 과정 2회차 전체 내용 검토로 진행한다.

이번 세션에서 계속 진행하며 새 세션을 자동 생성하지 않는다. 재개 시 실제 Git HEAD·브랜치·원격·미커밋을 읽는다.

## 완료와 계속할 작업

1회차의 이전 내용 검토·파생물 동기화 근거는 보존한다. 최신 사용자 결정에 따른 공통 범위와 같은 주제 안의 실전·응용 차이를 정정하고 관련 산출물을 재검증해야 한다. 실습 대본의 촬영 발화·전환·속도 튜닝 가능 상태는 유지한다. 전체 내용 검토 범위와 수정 이유는 1회차 마감 보고를 읽는다. 다음은 1회차 공통 범위 정정·재검증이며, 완료 후 두 과정 2회차 전체 내용 검토다. 전체 과정 마감으로 기록하지 않는다.

모든 대본은 본인이 실제 하는 말로 쓰고 조작/촬영 메모는 낭독 밖에 둔다. 목표 시간 채우기·반복 설명·억지 난이도를 넣지 않는다. 제조 업무의 조건·근거·구현·검증·PBL 재사용을 유지한다. 온라인은 학생 가이드 미제공, 오프라인 배포 가이드는 실제 작업/결과 사진 중심의 짧은 설명·확인점과 복사 가능한 프롬프트/스킬/명세로 구별한다. 사진은 후속 촬영 범위다.

실제 AI·코드·테스트·HYD/DB·브라우저 실습·캡처는 하지 않는다. 실행 가능성·실제 화면·전체 시간은 남은 일의 촬영 항목이다. 문서에서 찾은 오류·누락은 지금 수정한다. 구체적 오류·입력/조건/참조 모순·파생물 불일치·실행 결함이 생기면 해당 구간만 다시 연다.

현행 기준·제작 절차·현황·남은 일 및 근거/2026-10-19_온라인_랩_후속개정.md와 온라인_최종산출물_목록.md를 먼저 읽는다. 복원된 세부 제작 절차를 역사로 다시 밀어내지 않는다. 기존 미커밋 9개와 역사 .evidence/before.json을 보존하고 교재 변경만 커밋·푸시한다.

## 마감 시 Git 상태

작업 중 외부 Git 정리가 반영되었다. 실전반은 develop의 3b85158, 통합반은 archive/integrated-recovered-20261019의 3f88ff6에서 분리된 HEAD다. 기존 미커밋 수정은 보존 커밋에 포함되었고 CLAUDE.md에는 main/develop만 유지하는 새 운영 지침이 추가되었다. 이 작업은 해당 변경을 되돌리지 않는다. 통합반의 추가 마감 문서 수정은 이 경로에 보존하며 삭제된 작업 브랜치를 재생성하거나 보존 태그를 이동하지 않는다.
