통합반6은72장·4랩, 실전반6은80장·7랩이다. `제작용/구성/{과정}/06회차/구성.json`에서 분할 대본·덱·PPTX·진행 순서를 확인한다. 실전반 원본 배정은 `제작용/구성/실전반/06회차/원본대응.json`이다. 통합반6의 스킬·MCP 공통 이론은 실전반4 마감 판본과 대응하므로 동일 내용을 다시 전독하지 말고 해시·대응을 확인하여 근거를 재사용한다. 과정 고유 도입·연결·정리, 학습코치 등 고유 실습과 미확인 범위는 전체 확인한다. 실전반6의 BPMN·업무 설계·실행 연결은 별도로 확인한다.

## 진행과 마감

같은 판본으로 이미 확인한 작업은 반복하지 않고 변경 범위와 미확인 내용을 이어서 처리한다. 전체 내용 확인·윤문·수정·동기화를 효율을 이유로 생략하지 않는다. 화면 전 장 확인과 내용 검토는 별도다. 과거 전체 조립·합본 생성기를 바로 실행하지 않는다. 현재 분할 대본을 기준으로 필요한 파생물만 동기화한다. `제작용/온라인/tools/deck/회차노트동기화.py`는 구성.json을 받아 덱·PPTX 노트만 맞춘다.

실제 실습·AI·학생 코드/테스트·서비스·DB·브라우저 실습·캡처·PDF는 실행하지 않는다. PPTX 직접 PNG 내보내기와 화면 확인, 코드 AST·JSON 등 정적 검사는 가능하다. 실행 성공·촬영·청취·전체 시간 실측을 주장하지 않는다. [남은 촬영 확인](6_남은_일.md)은 별도 범위다.

각 회차의 산출물·제작 원본·관련 기록을 마무리한 뒤 커밋·origin/develop 푸시하고 다음 회차를 준비한다. 새 세션·다른 작업자를 자동 생성하지 않는다.
