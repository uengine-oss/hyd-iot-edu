# 두 과정 교재 작업 인계

현재 진행은 [작업 상태](작업상태.md), 확정 회차는 [현황](3_현황.md), 적용 규칙은 [공통 기준](2_기준.md)에서 확인한다. 이 문서에 규칙과 상태 전문을 복사하지 않는다.

활성 저장소는 `D:/work/study/hyd-portal-latest-20261014`의 `develop`이다. 두 과정 산출물은 [통합반](../../산출물/통합반/README.md)·[실전반](../../산출물/실전반/README.md)에 있다. 제작 원고·도구는 `제작용/`, 구성은 `제작용/구성/{과정}/NN회차/구성.json`이다. 구성의 상대 경로로 대본·PPTX·덱을 찾는다.

이전 통합반 복구 루트의 분리된 HEAD·태그·미커밋은 보존한다. 교재 정본은 출처 확인 후 현재 저장소로 이전했으며 과거 루트에 재동기화하지 않는다. 과거 루트의 구버전으로 새 정본을 덮지 않는다.

1·2회차 내용은 다시 검토하지 않는다. 3회차는 사용자가 확인한 표 중심 구성 문제의 변경 범위만 다시 열었다. 다음 작업은 두 과정 4회차이며 통합반 69장·3랩, 실전반 132장·4랩이다. 통합반4의 이론 중 실전반3에 배정된 부분은 해당 확정 근거를 재사용하고 차이와 미확인 부분을 검토한다. 실전반4는 통합반5·6의 배정을 원본대응으로 확인한다.

실제 실습·AI·학생 코드/테스트·서비스·브라우저 실습·캡처·PDF는 실행하지 않는다. 새 세션이나 다른 작업자를 자동 생성하지 않는다. 각 회차 마감 후 커밋·푸시한다.
