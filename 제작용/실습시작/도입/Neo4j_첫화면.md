## Neo4j Browser에서 연결하고 화면 살펴보기

지금 열린 화면이 Neo4j Browser입니다. 데이터베이스에 쿼리를 보내고 답을 확인하는 도구예요. 먼저 연결부터 하겠습니다. 왼쪽 위에 연결된 인스턴스가 없다는 표시가 있고, 가운데에는 Connect to instance가 있습니다. 이 버튼을 누르겠습니다.

> [조작] 연결 전 상태를 가리킴 → Connect to instance 클릭. 연결 창이 자동으로 뜬 실제 화면에서는 첫 발화를 “지금 열린 화면이 Neo4j Browser입니다. 데이터베이스에 쿼리를 보내고 답을 확인하는 도구예요. 연결 창이 먼저 열렸네요. 여기에 실습 DB의 접속 정보를 넣겠습니다”로 바꾼다. 이미 연결된 촬영 세션은 별도 준비 상태로 복원한 뒤 촬영하며, 학생에게 연결 절차가 없는 것으로 보이지 않게 한다.

연결 창의 프로토콜은 볼트로 고르겠습니다. 그 아래 Connection URL에는 방금 터미널에 나온 호스트와 포트 번호를 넣습니다. 주소 앞의 볼트 표시는 위에서 이미 골랐으니 입력칸에는 중복해서 넣지 않겠습니다. 사용자 이름은 네오포제이이고, 이번 로컬 실습 DB는 비밀번호를 비워 둡니다. Connect를 누를게요.

> [조작] Protocol에서 `bolt://` 선택 → Connection URL에 실제 `호스트:포트` 입력 → Username `neo4j`, Password 빈칸 확인 → Connect 클릭. 실제 연결 성공 전 다음 발화를 하지 않는다. 처음 안내창이 뜨면 “새 탭 소개가 나왔네요. 지금은 Stream에서 진행할 거라 Dismiss를 눌러 닫겠습니다”라고 말하며 닫는다.

> [연결 후 발화] 왼쪽 위에 접속 주소와 데이터베이스 이름이 나타났습니다. 방금 준비한 실습 DB에 연결된 상태입니다. 포털의 지식 지도와는 별도이므로 여기에서 하는 조회가 포털 화면을 바꾸지는 않습니다.

> [실제 화면 분기] 왼쪽 패널이 접힌 경우 “왼쪽 패널부터 펼치겠습니다. Stream 왼쪽의 Open Sidebar 버튼을 누를게요”라고 말하며 연다. 소개 카드가 보이면 “가운데는 처음 접속했을 때 나오는 소개입니다. 지금은 준비된 실습 데이터를 사용하겠습니다”라고 짚고, 첫 쿼리 결과를 이 아래에 이어 보여 준다. 소개 카드나 기존 결과를 화면 밖에서 지워 백지로 만들지 않는다.

화면에서 쓸 곳을 먼저 짚어 볼게요. 왼쪽은 데이터 정보와 저장한 쿼리를 찾는 영역입니다. 지금 열린 Queries는 쿼리 목록이에요. 아직 저장한 것이 없으면 비어 있어도 괜찮습니다. 왼쪽 위 Database overview를 눌러 이 DB에 어떤 종류의 데이터가 있는지 보겠습니다.

> [조작] Queries 제목·빈 목록을 가리킴 → Database overview 버튼을 위치와 함께 짚고 클릭 → 실제 표시된 레이블·관계 유형 확인. 버튼 이름이 툴팁으로만 보이면 가리켜 표시한 뒤 누른다.

> [데이터 정보가 나온 뒤 발화] 여기에 보이는 레이블은 노드의 종류이고, 관계 유형은 노드를 잇는 연결의 종류입니다. 이론에서 본 구성 요소와 센서를 실제 예제에서도 구분해 둔 거예요. 이 목록의 이름을 쿼리에 사용하게 됩니다.

위쪽의 달러 표시 옆이 쿼리 입력칸입니다. 문장을 적고 오른쪽 Run을 누르면 아래에 결과가 생깁니다. 결과가 표라면 열 제목은 요청한 항목이고, 한 행은 조건에 맞게 찾은 조합입니다. 노드와 관계 자체를 요청하면 그래프로 연결을 볼 수도 있어요. 먼저 표로 센서 식별자와 태그를 확인한 뒤 그래프로 바꿔 보겠습니다.

> [조작] 입력칸 → Run → 결과가 나타날 아래 영역을 차례로 가리킨다. 첫 조회까지 왼쪽 패널을 유지한다. 실제 폭이 부족해 접어야 할 때만 “쿼리를 넓게 보려고 왼쪽 패널을 접겠습니다. 이 버튼으로 다시 펼칠 수 있어요”라고 말하며 접는다. 화면 밖에서 미리 접지 않는다.

이제 쿨러에 연결된 센서를 찾아볼게요. 위쪽 입력칸을 누르겠습니다.
