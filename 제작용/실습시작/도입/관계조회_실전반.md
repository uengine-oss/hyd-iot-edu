## 자료를 내려받고 작업 공간 열기

앞 이론에서 노드와 관계를 사이퍼로 표현하고, 매치·웨어·리턴으로 조회하는 방법을 살펴봤습니다. 이번에는 준비된 설비 예제에서 직접 쿼리를 실행하겠습니다. 쿨러의 센서부터 시작해 물리량과 교체 부품까지 찾고, 조건과 반환 항목을 바꿨을 때 결과가 어떻게 달라지는지 확인하겠습니다.

실습 시작 도구에서 실전반, 온라인 2회차, 관계 조회를 선택해 새로 시작하겠습니다. 열린 폴더의 START.md에서 준비 절차를 확인하고, 이 폴더의 터미널에서 예제 준비 명령을 실행하겠습니다.

> [조작] 해당 항목 선택 → 새로 시작 → 작업 폴더·START.md 확인 → Docker 실행 상태에서 `python prepare_example.py` 실행. VS Code 기본 UI 소개는 하지 않는다. 실제 준비 결과를 기다린다.

> [결과가 표시된 뒤 발화] 노드 20개와 관계 19개가 준비됐습니다. 브라우저를 여는 명령을 실행하고, 출력된 주소로 접속하겠습니다.

> [조작] `python lab_db.py` 실행 → 출력의 Browser 주소와 Bolt 값을 보여 줌 → Browser로 전환. 학생별 포트는 실행 결과를 사용한다.
