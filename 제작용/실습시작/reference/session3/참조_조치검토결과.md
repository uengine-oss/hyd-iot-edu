# 조치 검토 결과

비교값은 지표_정의.md의 교육용 네 손실(비용·생산·품질·에너지)과 규칙 감점의 합계(만원)다. 실제 HYD 성과 점수(일곱 성분)가 아니며, 순위는 승인 요청을 검토할 순서일 뿐 실행 승인이 아니다.

## A (사례)

### A · SOP-COOL-11 — 유지
- 이유: 맞은 규칙과 미확인 규칙 없음
- 원문 출처: HM-8.5 SOP-COOL-11
- 추가 확인: 실행 직전 적용 조건 재확인: PLC 운전 모드가 REMOTE_AUTO일 때만 원격 조치를 한다. (HM-8.5)
- 추가 확인: 실행 직전 적용 조건 재확인: PLC가 트립 상태이면 리셋 외 제어 명령은 거부된다. (규칙발췌 rule:trip-reset-only(시드 HM-9.4))
- 추가 확인: 제한: 팬 100 % 연속 운전은 24시간 이내로 한다. (HM-8.5 SOP-COOL-11 단계 2)
- 추가 확인: 제한: 팬 100 % 연속 운전이 24시간을 넘었으면 팬 수명 손실 20만 원을 감점해 비교한다. 감점은 시간 제한을 풀어 주지 않는다. (HM-8.8)
- 추가 확인: 완료 기준: 조치 뒤 15분 동안 TS1 55 ℃ 미만이고 경보 해제 상태가 유지된다. 회복하지 않으면 결과 보고에 미달로 적는다. (HM-8.6)
- 승인: 운전원(HM-8.5). 비교 순위는 실행 승인이 아니다. 실행하려면 운전원의 승인과 실행 전 확인이 필요하다.
