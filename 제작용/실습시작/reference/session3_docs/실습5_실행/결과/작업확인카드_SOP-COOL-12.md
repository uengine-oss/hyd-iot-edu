## 남은 질문

- HM-8은 적용 설비를 ID로 정하지 않는다. 그래프의 HYD-01~03 설비·구성요소와 SOP-COOL-12를 연결하지 않았다. 어느 설비에 적용하는지 확인 필요.
- HM-8.8의 prohibition 「팬 100 % 연속 운전이 24시간을 넘으면 팬 수명이 줄어든다.」(HM-8-100)는 절차 ID 없이 적혀 이 작업에 연결하지 않았다. 적용 여부를 원문으로 확인 필요.
- HM-8.8의 prohibition 「펌프 부하를 60 % 미만으로 설정하지 않는다.」(HM-8-105)는 절차 ID 없이 적혀 이 작업에 연결하지 않았다. 적용 여부를 원문으로 확인 필요.
- 적재하지 않은 후보 HM-8-047(제외, HM-8.5): 「현장에서 수동 조작이 들어와 REMOTE_MANUAL이면 원격 조치를 내리지 않는다.」 — 같은 문장이 금지 후보(HM-8-048)로 이미 있다. 「REMOTE_MANUAL이면」은 금지의 적용 범위이지 실행 전 충족할 조건이 아니다.
- 검토 때 기록한 누락 HM-8.8 「이미 24시간을 넘겼다면 팬 최대 운전 조치는 팬 수명 손실로 20만 원을 감점해서 비교한다.」 — 「~다면」 조건을 규칙이 읽지 못했다. 「팬 최대 운전 조치」가 SOP-COOL-11만인지 팬 100 %를 쓰는 SOP-COOL-12까지인지 원문이 ID로 정하지 않아 추가하지 않고 남은 질문으로 둔다.
