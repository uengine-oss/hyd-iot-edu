# Notion 학습 포털 디자인

2026-10-26 사용자 요청: 단조롭고 구분하기 어려운 카드·표지·이모지·본문 스타일을 차분하게 개선한다. 수업 내용·일정·자료 링크·포털 시스템 로직은 변경하지 않는다.

- 지식 그래프: 청록 연결 구조. AI 에이전트: 남보라 작업 코어와 도구. 업무 프로세스: 황토색 분기 흐름.
- 홈 표지와 19회차 카드, 세 주제 아이콘은 직접 만든 기하학 도형이다. 회차별 부제·번호로 같은 주제 안에서도 구분한다.
- `build.py`는 PNG 자산을 재생성한다. Windows 맑은 고딕 설치를 사용하며 폰트 파일은 배포하지 않는다.
- `pages.json`은 실제 Notion 페이지와 자산 대응표다. 자산은 커밋 고정 raw URL로 연결한다.
- 기존 전체 강의/주제별 필터·날짜·자료 탭을 보존하고, 본문은 제목 위계·강조 색상·표시만 맞춘다.
- 참고: [Notion Course Site 템플릿](https://www.notion.com/templates/category/free-course-site-templates), [Student Dashboard Lite](https://www.notion.com/templates/student-dashboard-lite). 템플릿 자체를 복제하거나 기존 콘텐츠 위에 적용하지 않는다.
- 적용 전 페이지 응답은 로컬 `.evidence/notion-design-before.json`에 보관한다. 실제 적용·화면 확인 결과는 후속 기록으로 남긴다.
- 최신 사용자 기준: 통합반 홈과 통합반 05회차의 직접 수정 배치를 따른다. 큰 섹션 제목 바로 아래에 구분선, 번호형 소주제는 본문 크기+굵게, 소주제와 설명 사이에는 선 없이 연결하고 항목 사이는 여백으로 구분한다. 메인 상단 중복 구분선은 제거한다. 카드 이미지와 섹션별 표식·옅은 배경은 유지한다. 상세 적용·검증은 `문서/교재/인계_노션디자인.md`를 따른다.
