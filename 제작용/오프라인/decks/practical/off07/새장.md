  2. 오케스트레이션 | Orchestration / 중앙의 조정자가 작업의 순서와 호출을 이끄는 방식

  4. BPMN | Business Process Model and Notation / 도형과 선의 뜻을 정해 업무 프로세스를 그리는 표기 표준
  5. 배타 게이트웨이 · 기본 흐름 | Exclusive Gateway · Default Flow / 조건이 참인 한 갈래로만 보내는 갈림, 그리고 어느 조건도 맞지 않을 때 가는 선
  6. 풀 · 레인 | Pool · Lane / 참여자 하나의 영역과, 그 풀 안에서 활동을 나누는 칸
  7. 경계 이벤트 | Boundary Event / 작업 테두리에 붙어, 그 작업이 진행 중일 때 생기는 일에 반응하는 이벤트
  8. 프로세스 엔진 · 인스턴스 | Process Engine · Process Instance / 정의를 읽어 실행하는 소프트웨어, 그리고 정의에 따라 수행되는 한 건(처리 건)
  9. 토큰 · 프로세스 변수 | Token · Process Variable / 흐름의 현재 위치를 나타내는 표식, 그리고 처리 건이 지닌 이름 붙은 값

  3. 명령은 처리됐고 시스템이 회복을 관측 중이라, 회복과 결과 보고는 아직 확인 전이다
  4. 재관측이 진행 중이니 오류로 보고 담당자가 연결 값을 고친다
