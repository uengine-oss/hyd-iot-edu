## SLIDE 08 — 질문과 재개: 같은 요청 번호에 잇는 답
### 화면 내용

- 메시지: 답은 질문을 낸 요청 번호에만 이어 붙이고, 빠진 업무 정보를 채울 뿐 승인이나 권한을 만들지 않는다.
- 코드: // 점검 요청 한 건의 진행 (예시) / REQ-A  「유압 쪽에 경보가 났습니다」 / ① 조회로 설비를 정할 수 없다 /    → 질문 1: 대상 설비는?        상태: 질문 대기 / ② 답 「HYD-01」                → REQ-A에 기록, 다시 확인 /    → 맞는 사례가 둘이다 /    → 질문 2: 어느 경보 건인가?    상태: 질문 대기 / ③ 답 받음                       → REQ-A 판단 재개 /  / // 하지 않는 일 / REQ-B에 온 답을 REQ-A에 쓰지 않는다 / 「급하니 승인한 걸로」 → 승인으로 받지 않는다
- 요소:
  1. **먼저 조회한다** | 도구로 정할 수 있는 값은 묻지 않는다. 묻는 것은 빠지거나 어긋난 값뿐이다.
