## NEW terms — 오늘 다룬 핵심 개념과 주요 용어 정리
### 화면 내용
- 유형: 표
- 메시지: 사람의 결정, 명세, 행동 검증에서 풀어 쓴 용어의 정식 명칭과 뜻을 한곳에 모은다.
- 머리: 용어 | 정식 명칭 · 풀이
- 요소:
  1. HITL | Human-in-the-Loop / 자동 처리의 정해진 지점에 사람의 확인과 결정을 넣는 방식
  2. 명세 | Specification / 구현 전에 목표 · 입력 · 출력 계약 · 금지 조건 · 수용 기준을 정해 둔 문서
  3. 계약 · 깨는 변경 | Contract · Breaking Change / 주고받는 항목의 이름 · 형식 · 뜻의 약속과, 그 셋 가운데 하나를 바꿔 읽는 쪽을 깨는 변경
  4. 신선도 · 표본 | Freshness · Coverage / 값이 판단 시점에서 얼마나 묵었는지와, 구간을 채울 만큼 값이 들어왔는지
  5. 수용 기준 | Acceptance Criteria / 실행 결과로 참 · 거짓을 가를 수 있게 적은 완료 조건
  6. Gherkin | Given · When · Then 서식 / Feature 아래 Scenario를 전제 · 행동 · 기대 결과로 나눠 적는 서식
  7. 경계값 분석 | Boundary Value Analysis / 판정이 갈리는 기준값의 바로 아래 · 같은 값 · 바로 위를 입력으로 고르는 방법
  8. 회귀 시험 | Regression Test / 바꾼 뒤 기존 시나리오를 다시 실행해 행동이 그대로인지 확인하는 시험
- 노트: [짚을 곳] 표 여덟 줄 위에서부터, 정식 명칭은 화면에 맡기고 뜻만 / · HITL = 자동 처리의 정해진 지점에 사람의 확인과 결정을 넣는 방식 / · 명세 = 구현 전에 목표 · 입력 · 출력 계약 · 금지 조건 · 수용 기준을 정해 둔 문서, 계약 = 항목의 이름 · 형식 · 뜻의 약속, 깨는 변경 = 그 셋 중 하나를 바꿔 읽는 쪽을 깸 / · 신선도 = 값이 얼마나 묵었나, 표본 = 구간을 채울 만큼 값이 들어왔나 / · 수용 기준 = 참 · 거짓으로 가르는 완료 조건, Gherkin = Given · When · Then으로 나눠 적는 서식 / · 경계값 분석 = 기준값의 바로 아래 · 같은 값 · 바로 위, 회귀 시험 = 바꾼 뒤 기존 시나리오까지 다시 실행

### 화면 구성
표 한 장(용어 | 정식 명칭 · 풀이). 둘째 칸의 첫 줄이 정식 명칭, 둘째 줄이 풀이다.

### 제작 기준
기준 14절 용어 정리. 온라인 실전반 5회차 69장의 아홉 줄 가운데 이 덱의 장이 다루는 HITL · 계약 · 깨는 변경 · 경계값 분석 · 회귀 시험을 같은 풀이로 옮겼다. 이 덱에 근거 장이 없는 감사 기록 · 가드레일 · 바이브 코딩과 SDD · BDD는 뺐고, 「SDD · 명세」 줄은 명세만, 「수용 기준 · BDD」 줄은 수용 기준만(이 덱 수용 기준 장의 풀이) 남겼다. 신선도 · 표본은 온라인 실전반 4회차 65장의 풀이, Gherkin은 이 덱 시나리오 장의 풀이로 더했다.
