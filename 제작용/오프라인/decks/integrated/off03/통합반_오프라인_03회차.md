## SLIDE 06 — SOP와 DMN의 차이
### 화면 내용
- 유형: 비교
- 아이콘: list-numbers, table
- 메시지: 절차의 순서는 SOP에 두고, 지금 해도 되는지를 가르는 조건은 DMN의 결정표로 옮겨 현재값에 대어 본다.
- 요소:

  2. **DMN(Decision Model and Notation)** | 업무 의사결정을 정의하는 OMG의 표준 / 원문: 「원격 조치(SOP-COOL-11~13)는 REMOTE_AUTO가 아닐 때 쓰지 않는다.」 / 옮긴 조건: plc_mode != REMOTE_AUTO → 제외 / 판단 시점의 값과 견주어야 참 · 거짓이 정해진다 | 조건
- 노트: [짚을 곳] 왼쪽 SOP → 오른쪽 강조한 DMN의 원문 → 옮긴 조건 → 두 칸의 마지막 줄 / · 조건이 여러 절에 문장으로 흩어져 있으면: 급할 때 놓치고, 「24시간을 넘겼다면」이 정확히 24시간을 포함하는지 사람마다 다르고, 무엇을 확인했는지 남지 않는다 / · SOP는 어떻게 작업하나(순서), DMN = 업무 의사결정을 정의하는 표준(국제 표준 단체 OMG). 결정표로 어떤 입력 조건에 어떤 답을 낼지 표로 / · 「원격 자동이 아닐 때 원격 조치를 쓰지 않는다」 → 비교할 것 운전 모드, 기준 원격 자동, 다르면 제외(출력 = 조건이 맞을 때 내는 답). 원격 자동이면 안 맞고, 수동이면 맞는다 / · 조건은 판단 시점의 값과 견주어야 참 · 거짓이 정해진다. 순서 문장은 값 없이 읽힌다 / · 서로를 대신하지 않는다: 절차에도 모드 확인 단계가 남는다. 쿨러 사건에서도 승인 순간 시스템이 모드 · 상태를 다시 읽어 원격 자동 · 운전 중을 확인한 뒤 명령을 보냈다 / [다음] 입력 데이터(InputData)와 값의 출처

## SLIDE 12 — 범위와 복수 조건: AND · OR
### 화면 내용
- 유형: 코드
- 메시지: 범위는 하한과 상한의 두 검사를 한 행에 AND로 묶고, 하나만 맞아도 되는 조건은 같은 출력의 행 둘로 나눈다.
- 코드: ── 범위: 두 검사를 한 행에 ── / 55 < ts1  AND  ts1 < 65 /   50 ℃ 맞지 않음 · 60 ℃ 맞음 · 66 ℃ 맞지 않음 /  / ── 실제 AND 행: rule:ac-pm-due-options ── / pattern == 'PM_DUE' /   AND hours_since_pm >= 1800 /   → SELECT  SOP-PM-11 ~ 14 /   입력 PM_DUE · 1,950 h  → 맞음 /   입력 PM_DUE · 1,700 h  → 맞지 않음 /  / ── OR: 같은 출력의 행 둘 ── / 행 1  조건 A  → 출력 X / 행 2  조건 B  → 출력 X
- 요소:
  1. 하한 · 상한 | 범위의 두 끝. 끝마다 포함 여부를 따로 정한다.
  2. **AND** | 한 행에 적은 검사는 모두 맞아야 출력을 낸다.
  3. OR | 행을 나누어 적는다. 두 행이 함께 맞을 수도 있다.
  4. 범위와 경보 | 55~65 ℃ 구간만으로 경보가 나지 않는다. 경보는 냉각 효율 70 % 미만과 상승 추세도 본다.
- 노트: [짚을 곳] 코드 맨 위 범위 예 → 가운데 실제 AND 행(정기 정비)과 두 입력 → 맨 아래 OR(행 둘), 오른쪽 넷째 점 / · 범위: 하한보다 큰지 · 상한보다 작은지를 따로 검사하고 둘 다 맞아야 = AND. 50 ℃ 안 맞음, 60 ℃ 맞음, 66 ℃ 안 맞음. 끝마다 포함 여부를 부호로 / · 이 온도 범위는 묶는 법의 예일 뿐 — 그 구간만으로 쿨러 경보가 나지 않는다(경보는 냉각 효율 70 % 미만 · 상승 추세도 본다) / · 실제 AND 행(정기 정비): 패턴이 정비 도래 + 지난 정비 뒤 운전시간 1,800 h 이상 → 정비 방안 후보 선택. 1,950 h는 맞고 1,700 h는 안 맞음(패턴이 같아도) → 예방 정비는 도래했을 때만 후보 / · OR: 하나만 맞아도 같은 결과면 조건을 두 행으로 나누고 같은 출력을 둔다. 둘이 함께 맞으면 두 행 모두 결과를 낼 수도 / · 원문이 「그리고」인지 「또는」인지부터 가린다 / [다음] 후보 선택 · 제외 · 감점 · 경고 · 순위의 출력
