## NEW terms — 오늘 다룬 핵심 개념과 주요 용어 정리
### 화면 내용

- 메시지: 본문에서 풀어 쓴 약어와 그래프를 다루는 말의 정식 명칭과 뜻을 한곳에 모은다.
- 머리: 용어 | 정식 명칭 · 풀이
- 요소:
  1. OT · IT | Operational Technology · Information Technology / 설비를 움직이는 운영 기술과, 데이터를 다루는 정보 기술
  2. DMZ | Demilitarized Zone / OT와 IT 사이에서 드나드는 데이터와 명령을 검사하는 완충 구역
  3. PLC | Programmable Logic Controller / 센서 값을 읽고 정해진 논리로 설비를 직접 제어하는 산업용 제어기
  4. SCADA | Supervisory Control and Data Acquisition / 설비 데이터를 모아 감시하고 원격으로 제어하는 시스템
  5. HITL | Human-in-the-Loop / 자동 처리 중간에 사람이 승인 · 거절로 결정하는 구조
  6. MES | Manufacturing Execution System / 생산 지시 · 실적 · 납기를 관리하는 제조 실행 시스템
  7. 클래스 · 인스턴스 | Class · Instance / 공통 특성을 가진 대상의 유형과, 그 유형에 속하는 실제 개별 대상
  8. 레이블 | Label / 그래프 DB에서 노드의 종류를 나타내는 이름
  9. Cypher 쿼리 | Cypher Query / 노드와 관계의 패턴으로 그래프 DB를 조회하고 만드는 질의 문장

### 화면 구성
표 한 장(용어 | 정식 명칭 · 풀이). 둘째 칸의 첫 줄이 정식 명칭, 둘째 줄이 풀이다. 풀이는 뜻 한 줄이고 HYD에서의 자리나 예는 두지 않는다.

### 제작 기준
기준 14절 용어 정리. 온라인 통합반 1회차 73장의 여섯 줄(이 덱에서 풀어 쓰지 않은 HMI · MQTT 제외)과 2회차 67장의 레이블 · Cypher 쿼리 두 줄을 같은 풀이로 옮겼다. 클래스 · 인스턴스는 25장 노트가 쓰는 말이라 04단원 간지 노트에서 정의하고, 2회차 67장의 두 풀이를 한 줄로 묶었다.
