# 1회차 두 과정 차이안과 환경 준비 구성

> 폐기된 설계안(2026-10-22). 1회차는 두 과정 공통이고 랩 난이도는 실전반에 맞춘다(문서/교재/2_기준.md 「두 과정의 공통 범위와 차이」). 이 문서의 「실전반 차이안」 열은 따르지 않는다. 환경 준비 흐름안만 참고한다.

2026-10-20. 설계안이며 랩 코드·대본·HTML·ZIP 반영 완료가 아니다. 실제 실습·AI 호출·서비스/DB·clone·촬영·시간 실측은 하지 않았다. 확정 이론은 재검토하지 않았다.

## 확인한 현재 구성

두 과정 구성.json과 실습 README는 학습노트 → 실행환경 → 전체과정관찰 → 관계그림의 네 실습을 배정한다. 현재 1회차 랩 폴더에 독립적인 학생 구현 코드·코딩 시작본은 없다. VS Code는 자료 열기·기록과 준비한 HYD 프로젝트의 실행 창으로 사용한다. 예전 기록 추적 코드 과제는 2026-10-19 마감에서 제외됐다. 이를 다시 꺼내 과정 차이를 만들지 않는다.

근거: [기존 마감](../../문서/교재/근거/2026-10-19_01회차_두과정_내용검토.md), [통합반 구성](통합반/01회차/구성.json), [실전반 구성](실전반/01회차/구성.json), 각 과정 [통합반 실습](../../산출물/통합반/실습/01회차/README.md)·[실전반 실습](../../산출물/실전반/실습/01회차/README.md)의 원고·입력자료. 구성표는 배정 확인용으로만 사용했다.

## 환경 준비의 촬영용 흐름안

1. Git은 수업 저장소 받기·판본 확인, VS Code는 폴더·터미널·이후 코딩, Docker Desktop/WSL은 서비스 실행, Python·Node.js는 해당 실행 도구에 필요하다고 짧게 소개한다. 설치는 돼 있다고 가정한다. Notion·관계그림 도구의 사용법은 해당 실습에서 다룬다.
2. VS Code의 터미널 종류와 현재 폴더를 한 번 짚고, 촬영용 별도 작업 위치에 main을 clone한다. 준비된 저장소를 여는 경우에는 받기 설명을 반복하지 않는다. 이 저장소의 develop 작업 폴더를 옮기지 않는다.
3. 아래 명령은 Windows PowerShell 터미널을 선택한 촬영용 후보이며 지금 실행하지 않았다. 저장소 주소는 현재 origin과 일치한다. 촬영 시 main의 실제 실행 안내와 파일 존재를 확인한 뒤 확정한다.

```powershell
git clone --branch main --single-branch https://github.com/uengine-oss/hyd-iot-edu.git hyd-iot-edu
cd hyd-iot-edu
code .
git branch --show-current
.\시작.bat
```

4. clone은 프로젝트를 받는 명령, 폴더 이동은 작업 위치를 정하는 명령, `code .`은 그 폴더를 VS Code로 여는 명령이라고 필요한 만큼 설명한다. `code`가 등록되지 않은 환경에서는 파일→폴더 열기를 사용한다. 새 VS Code 창에서는 저장소 루트 터미널임을 확인하고 기동한다. 짧은 명령과 이후 바이브 코딩 요청은 직접 타이핑하며 긴 clone 명령은 붙여넣어도 된다.
5. 현재 develop의 README·시작.bat은 시작 스크립트를 통해 설정 준비·업무 저장소·서비스를 기동하고 빈 호스트 포트를 선택한다. 이 역할을 짧게 설명하고 실제 완료 출력과 오류를 확인한다. 상시 서비스·일회성 작업·호스트 워커의 상태를 구별한다. 설치 완료를 서비스 정상으로 간주하지 않는다. 버전·상태 확인 명령은 필요한 경우만 추가한다.
6. 포털은 시작 완료 메시지의 실제 주소로 연다. 포털의 시스템 구성/아키텍처 위치는 촬영 시 실제 메뉴로 확인하고 “앞에서 본 구조를 여기서 다시 볼 수 있습니다” 정도로 연결한다. 이론 전체를 반복하지 않는다.
7. 준비 완료는 저장소 판본·작업 폴더·기동 결과·실제 접속 주소·포털 접속 및 다음 실습에 필요한 준비 상태가 근거로 남았을 때 판단한다. 주소·성공값·소요 시간을 미리 채우지 않는다. 계측 갱신과 진단 지식 준비는 필요한 범위에서 별도로 판정한다.

## main 게시와 환경 조건의 대기

이번 시작 HEAD와 로컬 origin/develop은 `dfe10fac851881c1376804597ed83656104522a7`이다. 원격 조회 결과 main은 `98cceaae916757d557bbfa49c31f0861bf4a3ad6`으로 서로 다르다. 원격 main의 파일 내용·최신 기동 절차는 이번에 검증하지 않았다. 최신 교재·Windows 기동 변경이 촬영용 main에 반영됐는지 별도 배포 확인이 필요하다. 지금 merge·checkout·push main·clone을 수행하지 않는다. 실제 main 판본 확인 전에는 위 명령으로 기동이 성공한다고 확정하지 않는다.

설치돼 있다는 전제와 수업용 설정·인증·진단 지식이 마련됐다는 전제는 다르다. 현재 학교 설치 안내는 구조판에서 원인 진단 보류가 정상일 수 있다고 설명한다. 완전한 사건 흐름을 보여 줄 강사 환경은 필요한 지식·흐름·인증을 별도로 준비해야 한다. 실제 값은 열거나 기록하지 않는다. 환경 준비 구간에서 매뉴얼 적재나 전체 초기화를 추가해 해결하지 않는다.
