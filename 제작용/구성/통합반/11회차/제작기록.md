## 생성과 검증

분할 원본에서 합본·단위별/전체 낭독본·구성표를 재생성했다. 64장·59블록의 누락/중복/순서/제목 대응, 이론 경계, 0바이트 실습6개, 대기80초, 제작 표시의 낭독 제외를 검사했다. 동일 입력 재생성 해시는 같고 PPTX 발표자 노트는 해당 발화와 일치한다. 쌍으로 묶인 실습 둘째 장에는 중복 발화를 넣지 않았다.

기존 deck2pptx 감사를 통과했다. 메시지를 한 문장으로 정리하고 54장 긴 머리말과59장 HITL 설명 넘침을 수정했다. LibreOffice 별도 프로필·맑은 고딕으로64장 전체를 PDF/PNG 렌더해 전 장 컨택트시트와 수정 화면을 확인했다. 페이지 밖 텍스트는 없다. 33장 장치자리와40장 세영역 SVG의 점선 두 요소를 실제 끊어진 경로로 보정했다. figures/fix_svg_dashes.py는 재실행 가능하며, 기존 삽화 생성기를 그대로 돌리면 최신 그림과 점선이 되돌아갈 수 있어 무심코 재생성하지 않는다.

대본 PDF는 ReportLab·맑은 고딕으로27쪽이다. 추출 본문 전체가 낭독본과 일치하고 제작 표시·대기 문구는 없다. 전 페이지 컨택트시트와 첫 페이지를 확인했으며 긴 이론 제목의 한 글자 줄바꿈을 글꼴 크기 조절로 고쳤다. 실제 PowerPoint 앱 화면은 미확인이고 LibreOffice 결과다. 증거는 기본 폴더 `.evidence/value-review/day11/`, `.evidence/d11-render/`에 있다. 변경 전 파일은 선택 반영 스크립트가 backup에 보관하며 모든 반영 대상 해시를 확인한다.

- 실제 학생/강사 외부 화면 실습·ProcessGPT 시연·Notion 연동은 이번에 실행하지 않았다. 여섯 실습 파일은 요청대로 미작성이다. 개인 업무 예제는 실제 도구 계약·권한·입출력 자리의 사전 준비가 필요하다.
