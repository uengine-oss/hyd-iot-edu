# 실전반 온라인 1회차 문서 제작

원본 교재: C: 교재 작업 폴더의 b1c146d 기반 2026-10-18 통합반 검토본. 공통 43·45·47장의 검토 수정을 반영했고 그림은 보존한다. 현재 수정·배포 기준은 D:의 `산출물/`이다. `.evidence/practical01/output/`은 이전 체크포인트이므로 그대로 덮어쓰지 않는다.

사용자 변경 지시에 따라 직접 실습·브라우저 조작·화면 캡처는 하지 않는다. 가이드에는 나중에 채울 화면 자리와 필요한 장면·확인 기준을 제공한다. 실습 서비스나 모델을 실행한 것처럼 보고하지 않는다.

- `templates/`: 최종 윤문한 가이드·화면 목록. 수정 원본을 고친 뒤 `build_guides.py`로 배포한다. 학생용 가이드 밖에 둔다.
- `guide_source.json`: 최초 구성 설계의 활동·질문·힌트·요청 예시. 최종 문장은 templates를 우선한다.
- `finish_documents.py`: 최초 전환에 사용한 일회성 제작 기록. 다시 실행하지 않는다. 대본에 중복 설명을 넣을 수 있다.
- `build_practice_pdf.py`: 공개 경로의 실습 대본 네 개를 PDF로 생성하고 텍스트 일치·렌더를 확인한다. 실습을 실행하는 도구가 아니다.
- `검토기록.md`: 가이드와 실습 대본의 윤문·사실 경계 검토.

이론 PPTX·PDF와 실습 대본 PDF는 분리한다. 실제 실습 발화를 PPTX 발표자 노트에 덧붙여 장 대응을 깨뜨리지 않는다. 대본 수정은 `산출물/교재/대본/실전반_온라인/01회차/`에서 수행한다.

완성본 코드가 있는 온라인 랩은 `01일차_실습3_기록추적/코드/`다. 키 없이 파일을 읽는 참조 비교 도구이며 전체 포털을 구현한 것으로 설명하지 않는다. 나머지 활동에는 불필요한 코드를 추가하지 않고 입력틀·검토표를 제공한다.
