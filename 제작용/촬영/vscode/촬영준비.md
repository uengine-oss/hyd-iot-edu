첫 사용 발화는 [실습 대본 기준](../../../문서/교재/기준_실습대본.md)의 C49·C50 반영판을 따른다. 통합반은 관계 조회 준비에서 파일·터미널·저장을, 설계에서 첫 AI 채팅을 안내한다. 실전반은 VS Code 기본 UI 설명을 생략하고 과제·자료·판정으로 진입한다. [2회차 적용 근거](../../../문서/교재/근거/2026-10-26_2회차_도입과첫사용.md). 실제 UI 촬영 확인 전에는 새 도입의 화면 적용 완료로 표시하지 않는다.

[실습 촬영 안내](../../../문서/교재/방법_ego_실습영상_촬영.md)와 [실습 시작 검증](../../../문서/교재/근거/2026-10-26_실습시작과독립랩.md)을 먼저 읽는다.

다운로드·압축 해제·별도 작업 폴더·START/가이드·과정별 입력은 준비했다. 실제 다운로드본의 시작 모듈로 `D:/dev/Microsoft VS Code/Code.exe`를 찾아 폴더와 START 열기를 호출했다. 이 호출 성공과 실제 창·신뢰·AI 작업 성공은 구별한다.

학생 작업 위치는 `D:/HYD-Practice`다. 사용자가 이 폴더를 신뢰에 추가했다고 답했지만, 현재 Windows UI 도구로 Restricted Mode 해제를 독립 확인하지 못했다. 신뢰를 자동 해제하거나 전역 보안 설정을 끄지 않았다. 학교 초기화 이미지에 신뢰가 포함되는지도 미확인이다.

Windows computer-use SKILL.md를 읽었으며 요구된 `@oai/sky`용 `node_repl` 도구가 현재 목록에 없다. 사용자 물리 마우스나 전경 창을 별도 우회 도구로 가져오지 않는다. ego 웹 화면의 성공을 네이티브 VS Code 촬영 성공으로 대신하지 않는다.

촬영 전에 확인할 실제 동선: 시작 도구에서 과정/회차/실습 선택 → VS Code의 폴더와 START → AI가 작업 규칙/자료를 읽음 → 학생이 목표·제약·확인 사례를 작성 → 계획 검토 → 부분 구현/실행 → 원자료 대조/필요한 수정 → 저장/복사본 재열기. 막연한 요청도 자동으로 정답을 완성하도록 과제 로직이나 완성 프롬프트를 넣지 않는다. AI가 첫 시도에 맞췄다면 고의 오류를 만들지 않는다.

## 통과한 길 — VS Code 웹(serve-web) + ego (2026-10-28 로컬 Windows 실측)

Claude 데스크톱 앱 computer use는 VS Code를 `click` 등급으로만 준다(입력·키·우클릭·붙여넣기 금지, 설정으로 올릴 수 없음, 「권한 우회 모드」와 무관). 네이티브 VS Code에 CDP(`--remote-debugging-port`)로 입력하는 것은 같은 제한의 우회라 쓰지 않는다. 대신 공식 `code serve-web`(같은 워크벤치, 확장 호스트·터미널은 이 PC에서 실행)을 ego 탭으로 열어 기존 ego 촬영 리듬을 그대로 쓴다. 사용자 마우스·키보드·전경 창은 쓰지 않는다(ego 창은 최소화하지 말고, 그 창 안에서 작업 탭이 앞 탭이어야 캡처된다).

| 단계 | 통과한 값·명령 | 실패했던 원인 |
|---|---|---|
| 서버 | **PowerShell**에서 `$env:HOME='C:\Users\roede'; $env:CODEX_HOME='C:\Users\roede\.codex'` 뒤 `code.cmd serve-web --host 127.0.0.1 --port 8790 --connection-token-file <절대경로>\token.txt --accept-server-license-terms --server-data-dir <근거>\data --disable-telemetry`. 토큰은 파일에서만 읽고 출력하지 않는다 | Git Bash에서 띄우면 `HOME=/c/Users/..`가 넘어가 Codex가 `CODEX_HOME ... does not exist`로 종료. 상대 경로 토큰 파일은 서버 자식 프로세스가 못 읽음. 8765는 실습 시작 도구 기본 포트와 겹침 |
| 확장 | `~/.vscode/cli/serve-web/<commit>/bin/code-server.cmd --server-data-dir <data> --install-extension openai.chatgpt` (한국어 팩도 같은 방식). 폴더 복사는 등록되지 않음 | — |
| 열기 | `http://127.0.0.1:8790/?tkn=<파일값>&folder=` + `encodeURIComponent('/D:/...')` (드라이브 앞 `/` 필수) | `D:/...` 그대로 넣으면 드라이브가 빠져 `C:\work\...`를 열고 Codex 시작 실패 |
| 신뢰 | 상태 표시줄 Restricted Mode → 신뢰 창에서 실제 맨 위 요소인 `Trust` 텍스트를 좌표로 클릭 | 같은 이름의 가려진 버튼 클릭·Ctrl+Enter는 안 먹음. Machine 설정의 `security.workspace.trust.enabled`는 반영 안 됨. 신뢰 창이 떠 있는 동안 캡처 시간 초과 |
| 배율 | ego 150%에서 `setDeviceMetricsOverride` 2304×1296 dsf1 → CSS 1536×864, 캡처 2304×1296(실제 VS Code 125% 느낌). 1920×1080은 CSS 1280×720이라 패널이 답답함. 클릭 좌표는 CSS = 캡처 픽셀/1.5 | — |
| Codex | 로그인 불필요(`~/.codex` 공유, 로그 `authenticatedAccountPresent=true authMethod=chatgpt`). 첫 안내 Next 4회. 「GPT-6.1 Sol」 홍보 창은 **Continue with current model**. 입력창 아래 `GPT-6 Luna Medium` 화면 확인. 한국어 `keyboard.type` 입력·Enter 전송 → 5초 응답 확인 | 촬영 전 새 대화로 바꿔 사용자의 기존 Codex 대화 제목 목록이 화면에 나오지 않게 한다 |
| 터미널 | 편집기 클릭 → `Control+Backquote` → `keyboard.type` + Enter. `python --version` → `Python 3.14.7` 확인. 기본 셸은 PowerShell(Git Bash로 바꾸려면 프로필 설정) | — |
