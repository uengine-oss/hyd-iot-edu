# ARROWS 전체 수업 — 현재 인계

2026-10-22. 최신 요청은 **공통 기준을 개별 대본에 적용·윤문하고 예상 시간·가이드·인계를 동기화하는 정적 작업**이다. 촬영·브라우저 조작·음성 생성은 보류한다.

## 이번 반영

- [전체 원고](수업원고.md): 첫 기능 설명부터 20노드·26관계의 판단→조치 선택→조건·승인→응답→실제 효과→정비→생산·품질 확인까지 연결했다. 모든 입력과 관계 생성에 발화와 대응 조작을 나란히 기록했다. 대상 안내 후 설명 중 조작하며 발화 종료를 매번 기다리지 않는다.
- Property의 키·값 입력을 실제 발화에 넣었다. 반복된 주의 문구는 보류·재검토 경로로 모아 입력 속성을41개로 정리했다. 필수 판별·승인·회복 조건은 유지했다.
- [예상 시간](예상시간.md): 낭독량과 조작량을 별도 기록한다. 종전 약52–65분은 순차 합산 참고치이며 현재 예상 시간이 아니다. 설명 중 조작하는 타임라인의 합집합은 미측정이며 시간 채우기용 행동을 추가하지 않는다.
- 같은1회차 공통 실습인 두 과정의 `산출물/{과정}/실습/01회차/대본/08_실습_관계그림.md`, 해당 랩 가이드·입력·검토표·화면 계획·예상 시간·ZIP을 동기화했다. 원문 교재 발췌는 원문 참고로 보존한다. 이론 덱을 새로 확정하거나 수정한 작업은 아니다.
- [그림](최종_시나리오_관계그림.png), [명세](완성결과.md), [구조 JSON](시나리오_구조.json)은 같은 입력을 사용한다. 그림은 제작 참조도, JSON은 중립 명세이며 실제 ARROWS 내보내기 파일이 아니다.

## 다음 작업의 경계

2026-10-23 확정: ARROWS도 반드시 기능·결과 단위로 분할 촬영한다. 구간 종료 때 페이지·그림·선택·배치·원본·타임라인을 보존하고 쉬었다가 같은 상태의 다음 행동부터 이어간다. 성공 구간을 다시 만들거나 전체 수업을 처음부터 다시 촬영하지 않는다. 첫 구간은 N01–N02의 대상·속성·첫 관계, 이후 N03–N04 원인 판단, N05–N08 조치 비교, N09–N12 승인·효과 확인, N13–N17 후속·종료, N18–N20 예외, 저장·재열기로 잇는다. 각 경계는 실제 결과 확인을 마친 지점으로 조정하며 고정 시간을 채우지 않는다.

사용자의 실행 허용 전에는 촬영·음성·브라우저를 시작하지 않는다. 대본의 문구·호흡은 실제 화면에 맞춰 조정할 수 있지만 필수 입력·조건과 대상·행동 안내→설명 중 조작→실제 결과 확인 순서는 유지한다. 공통 규칙은 [실습 대본 기준](../../../문서/교재/기준_실습대본.md)의 ‘자연스러운 진행과 유연한 조정’을 따른다.

새 그림/가져오기 메뉴·파일 선택의 구체적인 경로는 미확인이다. 후속 허용 단계에서 해당 경로를 확인해 대본의 미확인 구간을 실제 안내로 채운다. 전체 배치·저장 데이터 재열기·전체 진행 시간도 실제 확인 전에는 완료로 표시하지 않는다. 사진 가이드는 현재 장면 계획만 있으며 실제 사진은 없다.

기존 기본 조작의 샘플 근거는 재사용한다. 같은 목적의 짧은 샘플을 관행적으로 다시 찍지 않는다. 전체 음성·동기화·프레임·청취·재생은 이번 작업에서 검사하지 않았다.
