## 음성 준비와 촬영 의존성

사용자가 지정한 `D:/임시/gnu-class-key.txt`로 ElevenLabs 인증·지정 음성·eleven_v4 접근을 확인했다. 키는 파일에서 실행 프로세스로만 전달했으며 값은 출력·제작물·Git에 남기지 않았다. `.env`는 열지 않았다.

`관계조회_음성큐.json`은 공통 발화11개,1,189자다. 발화 추정2.7분, 실제 생성159.2초. `.evidence/practice-20261026/relations-audio/`의 개별 파일을 보존하며 합본은 `관계조회_음성준비본_v2.mp3`를 사용한다. 개별·합본 디코드는 확인했고 청취·실제 화면 조작·음성 동기화는 미확인이다. 큐의 ops는 아직 비어 있으므로 전체 시연 시간으로 사용하지 않는다.

공통 관계 조회용 실제 예제는 `.evidence/practice-20261026/common-query-runtime/02회차/랩/02일차_실습1_관계조회/랩_연결.json`의 전용 DB다. 준비·조회5항목·재준비20노드/19관계를 검증했다. 기존 47노드 강사 모델과 섞지 않는다.

현재 도구 목록에 Windows node_repl/sky 실행 도구가 없어 네이티브 VS Code 조작은 별도 미확인이다. 조회 결과 설명 녹화와 단계별 표 캡처는 확인했다. Page.captureScreenshot 대신 screencast 프레임을 사용한다.

입력·실행·결과 확인40.940초 합성을 추가했다. 실제 입력/Run/두 센서 결과는 성공했지만 이동 최대250ms 공백과 입력 커서 가림으로 최종판 미확정이다. 당시 여유 메모리 약2.1GB에서 멈췄으나, 최신 사용자 지시로 수치만으로 중단하지 않고 실제 반응 측정 후 촬영을 재개했다. 다음 촬영은 해상도 안정 확인 후 시계를 시작하고 입력 커서를 아래 여백으로 옮긴다. 정상 결과 설명 구간은 유지한다. 정확한 파일·시점·수정 범위는 [입력실행 촬영 근거](../../../문서/교재/근거/2026-10-26_Cypher_입력실행_촬영.md)를 따른다. 음성 직접 청취·전체 영상·사용자 재생은 미확인이다.
