# 에이전트 기초

Notion 반영본 · 2026-10-22 · https://app.notion.com/p/3bcf0e285bb4805e9b50e7c429248a5d
기존 기록·자료를 보존한 작성 예시. 실제 설비 실행 결과가 아니다.

설비 기록을 찾아 정리하는 에이전트의 역할을 생각해 본 학습 예시입니다.

<callout icon="📖" color="blue_bg">
<b>답변뿐 아니라, 필요한 자료를 찾아오는 과정까지</b><br />목표를 받고 자료 조회 같은 도구를 사용한 뒤, 얻은 결과를 바탕으로 답변을 만드는 흐름을 예로 듭니다. 실제 시스템을 실행한 결과는 아닙니다.
</callout>

## 요청에서 결과까지

1. <b>대상 확인</b> — 설비 이름이 모호하면 먼저 대상을 확인합니다.
2. <b>기록 조회</b> — 허용된 자료에서 해당 설비의 점검 기록을 찾습니다.
3. <b>내용 정리</b> — 기록의 출처와 확인할 항목을 함께 제시합니다.
4. <b>사람이 검토</b> — 원문과 맞는지 보고 다음 행동을 결정합니다.

<toggle>
자료를 찾지 못했다면?

“현재 조회 범위에서는 기록을 찾지 못했습니다.”라고 밝히고, 설비 이름이나 조회 범위를 다시 확인합니다. 없는 점검 결과를 만들어 채우지 않습니다.
</toggle>

<toggle>
어디까지 맡길까?

이 예시에서는 조회와 정리까지 맡깁니다. 설비 제어나 실제 작업 지시는 별도의 권한과 확인 절차가 필요한 다른 범위입니다.
</toggle>
