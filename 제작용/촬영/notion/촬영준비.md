## 1. 바로 가는 길

v11을 실제로 만든 길이다. 녹화 도구는 [촬영도구](촬영도구/)(`run.sh rec|restore|measure`, `chain.sh` 연속, `full.sh` 새 페이지부터, `encode.py` 합성)다. 명령은 Git Bash에서 [촬영도구](촬영도구/) 폴더(`build.py`만 이 폴더)에서 돌린다. 경로 값은 모두 [config.json](촬영도구/config.json)에서 온다(3절).

**0. 시작 전 확인** — 하나라도 아니면 멈추고 알린다. 촬영 허용 요청이 있기 전에는 실행·음성·촬영을 시작하지 않는다.

| 확인 | 어떻게 |
|---|---|
| ego lite 설치 · Notion 로그인 | 사용자가 한다. 설치된 `ego-browser skill` 출력을 끝까지 읽는다(API는 설치 버전이 우선) |
| 녹화 원본 폴더 · 음성 캐시 | config `work` · `audio` 폴더가 있다(이 PC에는 없다 — 0절) |
| ffmpeg · Python | 환경변수 `FFMPEG` 또는 PATH의 ffmpeg, `PYTHONUTF8=1 python`(PIL 필요, `measure.py`) |
| PC 부하 | Zoom · Teams가 꺼져 있고 여유 메모리 3 GB 이상 — 아니면 `run.sh rec`가 `LOAD:`로 멈춘다. 다른 ego 명령이 돌고 있으면 `BUSY:`로 멈춘다 |
| ego 창 | 녹화 탭이 앞에 보인다(앞에 보이는 탭에서만 프레임이 온다 — 창을 최소화하지 않는다) |

**1. 큐 원고와 음성.** 큐 원고는 구간 모듈 [segs/seg-25~39.mjs](촬영도구/segs/)이고, 모듈 안 `c.say('<큐 id>')` · `c.source(…)` · `c.line(…)`가 [source-cues.json](촬영도구/source-cues.json)의 큐를 부른다. 반복 안내의 다른 표현은 [voice-variants.json](촬영도구/voice-variants.json) → [variants.py](촬영도구/variants.py)가 `<id>-r<n>` 큐로 바꿨다(한 번만 — 이미 반영돼 다시 돌리면 멈춘다). 새 문장은 [voice-jobs.json](촬영도구/voice-jobs.json)에 모은다. 음성 비용 견적을 먼저 알린다(V요-42).

```bash
PYTHONUTF8=1 python voice.py        # 새 큐만 ElevenLabs로(같은 문장이 캐시에 있으면 안 만듦) + fix-* 검수 음성 복사
PYTHONUTF8=1 python check-cues.py   # 끝 줄 'all cues have audio'가 아니면 녹화하지 않는다
```

결과: config `audio` 아래 `<큐 id>.mp3` · `<큐 id>.json`(text · duration_ms). `voice.py`는 키를 환경변수 `HYD_ELEVENLABS_KEY_FILE`(3절)이 가리키는 파일에서만 읽고 출력하지 않으며, `audio` 옆 `음성내용검수/음성수정안.json`이 있어야 돈다.

**2. 시작 상태.**
- 처음부터: 기존 촬영 페이지를 휴지통으로 옮긴다(사이드바에 같은 이름이 하나 더 찍히지 않게) — Notion 휴지통 이동이니 사용자에게 묻고 한다. `./run.sh restore trashPage`(config `page`를 하위 페이지째 휴지통으로, 영구 삭제 아님). 메뉴가 반응 없으면 2절 함정표. 25구간 모듈이 녹화 전에 Notion 다운로드 페이지(`https://www.notion.com/ko/desktop`)를 연다.
- 이어 찍기: `run.sh rec`에 앞 구간 이름을 주면 녹화 전에 그 구간 `end-state.json`의 페이지를 열고 화살표를 그 자리에 다시 그린다(화면에 남지 않음). 녹화 밖에서 상태를 맞출 때는 실행 취소 없이 `./run.sh restore <종류>`:

| 종류 | 하는 일 |
|---|---|
| `cut25` | 구간25 3:05(N06-v002 직전) — 안내 상자 블록 「삭제」, 소개 아래 빈 줄 하나에 캐럿, 사이드바 닫힘 |
| `noteTail` | 안내 상자 안에 생긴 빈 줄을 Backspace로 지워 상자 글 끝에 캐럿(구간25 끝 상태) |
| `cut27` | 구간27 57.0s 직전 — 「노션 익히기」 주제에서 하위 페이지 블록 「첫 페이지 꾸미기」를 휴지통으로, 「나의 페이지」 제목 아래 빈 줄에 캐럿(주제 주소는 `take-26/end-state.json`) |
| `trashPage` | 촬영 전용 페이지를 하위 페이지째 휴지통으로(처음부터 다시 찍을 때만) |
| `reload` | 새로고침(「최신 버전으로 업데이트」 막대 제거). 대화상자가 닫히니 상태 경계에서만 |
| `state` | 읽기 전용 — 블록 목록 · 캐럿 · 사이드바 · 오류 문구 |

**3. 찍기.** 구간마다 시작 상태 확인 → 녹화 → 끝 상태 · 프레임 · 행동 시각 저장 → 바로 실측이다.

```bash
./full.sh n          # 처음부터: take-n25(새 촬영 페이지를 만든다) → config.json page를 새 페이지 id로 바꿈 → take-n26 … take-n39
./chain.sh <앞 구간 이름[:자른ms]> <번호 또는 이름:모듈> ...   # 예: ./chain.sh take-37 37b:seg-37b.mjs 38 39 → take-37b, take-38, take-39
./run.sh rec <이름> <모듈(segs/ 기준)> [앞 구간 이름 | 앞 구간:자른ms | '{x:..,y:..}']   # 구간 하나 녹화 → 실측
./run.sh measure <이름>                                     # 녹화 하나 다시 실측
```

- 멈춤: `chain.sh`는 녹화 오류 · 오류/업데이트 막대 프레임(`banner_frames`)이 있으면, `full.sh`는 거기에 한 구간에서 0.5초 넘는 끊김 3회 이상이면 그 구간에서 멈추고 뒤 구간을 시작하지 않는다. 사소한 움직임 · 프레임 차이로는 멈추지 않는다.
- 실패 조각에서 이을 때는 앞 구간을 `<이름>:<자른ms>`로 줘서 자른 시각의 화살표 위치에서 시작하고, 화면도 자른 시점 상태로 맞춘 뒤 찍는다. v11의 `take-n26b` · `take-n39c`가 이렇게 이은 조각이다(뒷부분 모듈 `seg-26b.mjs` · `seg-39c.mjs`). v11을 찍은 정확한 명령 줄은 이 PC에 실행 기록이 없어 미확인이다.
- 결과(config `work` 아래): `<이름>/frames/*.jpg` · `frames.jsonl` · `timing.json`(프레임 · 큐 · 이동 · 오류) · `end-state.json`(URL · 클릭 · 포인터 통계) · `end-snapshot.txt` · `recording-start.json`, 실행 로그 `<이름>.log`. 이미 프레임이 있는 이름에는 찍지 않는다(take는 매번 새 이름, 실패 take도 이름을 붙여 남기되 합성에 쓰지 않는다). 기존 MP4를 덮어쓰지 않는다.
- 실측(`measure.py`): 이동별 최대 프레임 공백 · 출발 지연, 100ms 넘는 공백, 클릭 좌표 오차, 문장보다 늦은 조작, 오류 문구 · 업데이트 막대 프레임 수, 마지막 이동 위치 · 마지막 프레임.
- 시간: 구간 하나 = 그 구간 영상 길이(v11 15구간 합 41:58.5) + 준비. 한 번 실행의 시간 초과는 `TMO`(기본 900초) — 넘으면 ego의 NodeService(스크립트 실행기)만 정리하고, 끊긴 명령이 실제로 실행됐을 수 있으니 `restore state`로 확인한다.
- 녹화 중에는 같은 PC에서 무거운 계산 · 인코딩 · 검사를 하지 않는다. 멈추게 하려면 config `work` 폴더에 `STOP` 파일을 만든다(다음 큐에서 오류로 멈춤).

ego 녹화가 하는 일([run.sh](촬영도구/run.sh) · [ctrl.mjs](촬영도구/ctrl.mjs) · [ui.mjs](촬영도구/ui.mjs)):
- 호출: 스크립트를 UTF-8 `.mjs`로 저장해 `ego-browser nodejs -e "await import('file:///<절대경로>.mjs?<판>')"`로 부른다. 같은 주소는 다시 실행되지 않으니 판 표시(`run.sh`는 시각)를 바꾸고, 셸 안에서는 `< /dev/null`을 붙인다. 보내기 전에 `node --check`(`run.sh`가 모든 모듈을 검사하고 문법 오류면 보내지 않는다 — ego는 문법 오류에 조용히 멈춘다).
- 작업 공간: `taskSpace(config space)`의 탭 `p1`을 쥐고 같은 작업은 같은 공간을 쓴다. 다른 세션과 같은 공간 · 페이지를 동시에 조작하지 않는다.
- 해상도 · 프레임: 녹화 스크립트마다 `Emulation.setDeviceMetricsOverride`를 config `viewport` 값(1536×864, deviceScaleFactor 1)으로 설정한다(스크립트가 끝나면 풀리고, 한 도구 안에서는 바꾸지 않는다). `Page.startScreencast`(JPEG 85, 최대 1920×1080, 모든 프레임)로 받은 프레임은 즉시 ACK · 저장하고, 1920×1080이 아닌 프레임이 오면 멈춘다.
- 진행 리듬: 모든 ego 호출은 하나의 직렬 큐로 보낸다. 표시 포인터는 페이지에 그린 SVG 화살표(`recording-pointer`)를 `element.animate`로 움직이고, 실제 입력은 같은 경로를 단계별 `mouse.move`로 보내며, 실제 입력이 다 끝날 때까지 화살표를 목표에 고정한다. 위치가 바뀌는 대상은 150ms 간격 두 번 같은 위치일 때 출발한다. 조작 시점은 큐 문장 가운데 조작 동사(누르 · 클릭 · 선택 · 입력 · 적 · 닫 · 열 · 엔터 · 가져가)가 있는 마지막 문장을 글자 비율로 추정해, 그 문장이 끝나기 약 250ms 전에 실행하고 다음 음성은 행동 종료 + 250ms에 시작한다. 녹화 시작 전에 큐가 돌면 즉시 실패시키고(`Cue … before recording began`), 긴 이동 · 긴 문자열 입력을 큐 한 항목에 넣지 않는다.
- 녹화 전 점검: 서비스 상태와 PC 부하를 보되 수치만으로 중단하지 않고 실제 반응 · 프레임 간격으로 판정한다. 화면에 「최신 버전으로 업데이트」가 있으면 녹화 전에 멈춘다.
- 사용자가 직접 배치 · 입력할 때: 녹화를 멈추고 `task.handOff()`로 넘긴 뒤 `takeOverTaskSpace(<번호>)`로 되찾는다. 그 결과는 화면 캡처가 아니라 Notion에 저장된 내용으로 읽는다. 사용자가 ego 공간을 잡고 있으면 우회하지 않고 「계속」을 받은 뒤 되찾는다.

**4. 합성.** 구간별 원본 시간을 그대로 두고(배속 · 중간 컷 없음) 구간 경계만 잇는다. 쓰는 조각과 자르는 위치는 `encode.py` 실행 인자로 남긴다: `take-n25 take-n26:69268 take-n26b take-n27 … take-n38 take-n39:73207 take-n39c`.

```bash
PYTHONUTF8=1 python encode.py Notion_학습노트_v11 take-n25 take-n26:69268 take-n26b take-n27 … take-n38 take-n39:73207 take-n39c
```

- `…` 자리의 정확한 조각 목록은 v11 `verification.json`의 `segments`에 있다(이 PC에 없음 — 4절).
- 결과(config `work`/`Notion_학습노트_v11/`): `Notion_학습노트_v11_안치윤_1080p.mp4`(30fps, libx264 crf 18, AAC 160k) · `자막.srt` · `narration.wav` · `frames.concat` · `verification.json`(구간 · 큐 시각표 · 클릭 오차 · 이동 공백).
- 멈추는 경우(멈추면 원인을 고친다): 오류 난 take를 자른 위치 없이 줌, 자른 위치가 문장 중간, 음성 겹침, 영상 · 음성 끝 시각이 구간 합계와 0.1초 넘게 다름.
- 녹화 뒤 화면과 다른 대사는 그 문장만 다시 만들어 `VOICE_OVERRIDES=<JSON 파일>`(`[{segment, time, file}]`)로 바꿔 넣는다 — 원래 문장 끝에 맞춰 오른쪽 정렬하고, 원래보다 길면 멈춘다.

**6. 연결 산출물.** 확정 영상의 말한 문장 · 조작 시각을 두 과정 대본 · 가이드 · 시간 · ZIP에 넣는다(이 폴더에서).

**7. 게시.** 원격 push와 Notion 게시는 사용자에게 묻고 한다.
- workspace: `python scripts/workspace.py commit "메시지"`로 workspace에 올린다(브랜치를 바꾸지 않고 앞 커밋 위에 쌓음, 키 검사 0이어야 붙음). push(`git push origin workspace`)는 사용자에게 묻고 한다. 영상 한 편은 100 MiB 아래(v11 81,786,124바이트). 파일은 `course/videos/{통합반,실전반}/<과정>_01회차_02_실습_학습노트.mp4`와 자막, 그리고 `course/videos/README.md` 표.
- Notion: 두 과정 1회차 페이지 「📂 강의 자료 → 🎬 강의 영상」 PRACTICE 01 칸에 그 커밋에 고정한 링크 세 가지(영상 열기 · MP4 내려받기 · 페이지 안 재생 토글)를 다른 영상과 같은 모양으로 넣고 다시 열어 확인한다. Notion 파일 업로드는 한 번에 20 MiB라 영상은 링크로 건다. 유튜브는 쓰지 않는다.
