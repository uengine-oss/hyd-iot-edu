# 학습노트 디자인 시안 — 2026-10-22

상태: 사용자의 후속 요청에 따라 홈의 표, 나머지 세 주제와 실제 `새 주제` 데이터베이스 템플릿까지 동일 디자인을 적용했다. 촬영·음성 제작 없음. 대본·입력·HTML·ZIP은 이 완성본에 맞춰 동기화했다. 전체 실습과 촬영 완료를 뜻하지 않는다.

## 참고한 실제 갤러리

- [STUDY DASHBOARD — Shantierra](https://www.notion.com/ko/templates/study-dashboard-698): 파란 안내 영역과 구획 간 반복되는 정렬을 참고. 트래커 구조는 가져오지 않았다.
- [Study Planner for Students — JONGHYUN Notio World](https://www.notion.com/ko/templates/study-planner-for-students-free): 연한 배경색으로 관련 구역을 묶는 방법을 참고. 목표·오답·성적 등의 기능은 추가하지 않았다.
- 템플릿 상품의 이미지나 본문을 복사하지 않았다. 카드 그림은 `design/covers.py`로 만든 자체 도형 이미지다.

## 실제 적용

- [홈](https://app.notion.com/p/3bcf0e285bb4806f93c1cc2ace1f0836): 큰 표지와 상단 대형 아이콘 제거. 기존 소개 보존, 파란 안내 상자, 작은 갤러리 카드 네 개. 카드에 청회색·크림색·황갈색 포인트를 공통 적용하고 주제별 도형은 다르게 제작했다.
- [Notion 익히기](https://app.notion.com/p/401f0e285bb4811e9a6af46bfc26d991): 표지와 대형 아이콘 제거, 짧은 소개와 파란 핵심 안내, 같은 크기의 회색 두 단 영역에 기존 하위 페이지를 배치. 설명 줄바꿈과 제목 길이를 맞췄다. 자유 구성 안내는 마지막 토글로 모았다.
- 갤러리 미리보기는 새 파일 속성 `카드 이미지`를 사용한다. 본문 표지와 분리하여 카드 그림 때문에 글이 아래로 밀리지 않게 했다. 파일 속성은 페이지 본문에서 숨긴다.
- 네 주제와 새 주제 템플릿에 공통 색과 두 단 구성을 적용했다. 나머지 세 주제의 예시 내용은 아래 후속 반영과 카드본문 원본에 있다. 기존 기록·이미지·학습 속성 값·하위 페이지는 보존했다.

## 후속 반영 — 주제별 내용과 템플릿

- 전체 주제 표: 이름·분야·이해도 표시. 기존 선택 값 보존.
- 이상 감지: 가상의 냉각수 펌프 변화 상황, 비교 기준과 맥락, 확인 순서 예시. 기존 빈 틀은 하단 `기존 작성 내용` 토글 안에 보존.
- 에이전트 기초: 점검 기록 조회 요청, 자료 확인과 정리 흐름, 자료가 없을 때의 응답 예시. 기존 코드·이미지·완료 체크 항목은 하단 토글 안에 보존.
- 지식 자산화: 기존 도입·메모·교재 하위 페이지 보존. 자기 말로 적기와 출처 연결, 짧은 작성 예시 추가.
- 새 주제: 실제 데이터베이스 템플릿의 표지·대형 아이콘 제거, 파란 안내와 회색 두 단 적용, 기본 카드 이미지 지정. 자유 구성 안내 보존. 분야·이해도는 임의로 채우지 않는다.
- 본문 원본은 `카드본문/`에 저장했다. 각 페이지 fetch에서 두 단과 토글 구조, 기존 이미지·체크 항목·하위 페이지를 확인했다.
- 실제 화면 근거: `.evidence/notion-redesign-20261022/{signal,agent,knowledge,template}-filled.png`. 템플릿 화면의 편집 배너를 확인했다. 새 카드 생성 실습·촬영은 하지 않았다.
