# {{과정}} 1회차 실습 1 — Notion 주제 갤러리 만들기

> 제작용·비낭독: 일반 문단은 실제 강사 대사다. 실행 표시는 행동 대응 위치이며 음성 전체 종료를 기다리라는 뜻이 아니다. 대상을 먼저 짚고 행동을 안내한 시점부터 설명하며 조작한다. 다음 메뉴는 실제 나타난 뒤 안내하고 결과 대사는 결과가 나타난 뒤 말한다. 실제 음성의 조작 시작 지점은 촬영 큐에서 정하며 준비 원고의 줄바꿈만으로 자동 실행하지 않는다.

> 촬영: 기능별로 분할하고 같은 페이지·내용·선택·스크롤 상태에서 이어 간다. 필요한 학습 조작은 모두 담고 정상 구간을 다시 찍지 않는다. 1920×1080·UI150%, 후광 없는 흰 화살표, 실제 클릭 위치 일치. 커서 순간이동 금지와 실제 움직임 프레임이 최우선이다. 설명하면서 자연스러운 속도로 이동·입력하고 고정 대기나 느린 조작으로 분량을 늘리지 않는다. 사용자 작업·Claude에 간섭하지 않는다.

> 화면 근거: 기존 home-final.png에서 파란색 새로 만들기 버튼과 오른쪽 아래 화살표, 목록 오른쪽의 회색 돋보기·설정 아이콘을 확인했다. 색상은 해당 상태에서만 말하며 테마가 다르면 실제 화면에 맞춰 바꾼다. 전체 메뉴 동선은 실행 미확인이다. 위치가 다른 메뉴는 확인 후 대사를 수정하고 없는 메뉴를 있는 것처럼 읽지 않는다. 새 페이지 생성 UI의 분기는 실제 해당하는 문장만 사용한다.

> 준비: 공식 다운로드 https://www.notion.com/desktop, 공식 도움말 https://www.notion.com/help/writing-and-editing-basics. 완성본과 새 작업 노트를 구별한다. 이미지·교재 발췌는 실습 폴더에 준비한다. 설치·로그인은 위치와 방법만 소개한다. 개인 원본·공개 권한은 바꾸지 않는다. 자동 생성된 빈 예시 정리가 필요하면 촬영용 새 목록에 한해 해당 행동을 먼저 말하고 수행한다.

> 시간: 예상시간.md의 순차 합산치는 구판 기록이다. 현재 기준은 발화와 조작이 겹친 시간을 한 번만 계산한다. 기존 영상55분34초는 새 리듬의 예상값이 아니다. 새 촬영 큐의 겹침·화면 응답을 측정해 영향 구간부터 재산정한다. 이번 수정은 제작 지침이며 새 영상·음성을 만들지 않았다.
