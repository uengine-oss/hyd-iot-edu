# 촬영 — 도구별 촬영준비

실습 영상 · 이론 강의 영상의 규칙(무엇을 만들고 무엇을 통과해야 끝인가)은 [영상](../../문서/교재/영상.md)이 갖는다. 찍을 때는 그 도구의 촬영준비 하나만 연다 — 도구 하나 = 촬영준비 하나이고, 여러 도구가 함께 쓰는 음성 · ego 녹화 · 구간 기록 · 게시 구현값도 그 도구의 말로 각 촬영준비에 들어 있다.

촬영준비는 모두 같은 꼴이다: 0 지금 상태와 재개 지점 → 1 바로 가는 길 → 2 함정표 → 3 값 → 4 아직 안 뚫린 길. 새로 뚫은 길 · 만난 함정 · 바뀐 값은 그 촬영준비에 바로 적는다(영상 V-239).
