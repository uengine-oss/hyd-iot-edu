# 촬영 도구 — 공통 구현 세부

실습 영상의 원칙 · 순서 · 검사는 [기준_실습](../../문서/교재/기준_실습.md)과 그 종류 기준([기준_실습_도구](../../문서/교재/기준_실습_도구.md) · [기준_실습_코딩랩](../../문서/교재/기준_실습_코딩랩.md))이 정한다. 이 문서는 여러 도구가 함께 쓰는 구현 · 설정값만 적는다. 도구 하나의 값 · 함정 · 상태는 그 도구의 `<도구>/촬영준비.md`에 있다.

## 음성

- ElevenLabs만 쓴다. 모델 `eleven_v4`, 목소리 「안치윤」 `1PdAOcPlPTz12RwMyFVp`, stability 0.5 · similarity 0.75(도구 기본값을 바꾸지 않는다). OpenAI 음성은 쓰지 않는다.

## ego로 찍기

- 설치된 `ego-browser skill` 출력도 끝까지 읽는다(API는 설치 버전이 우선). ego lite 설치 · 로그인은 사용자가 한다.
- 스크립트는 UTF-8 `.mjs`로 저장해 `ego-browser nodejs -e "await import('file:///<절대경로>.mjs?<판>')"`로 부른다. 같은 주소는 다시 실행되지 않으니 판 표시를 바꾸고, 셸 안에서는 `< /dev/null`을 붙인다. 보내기 전에 `node --check`.
- 작업 공간은 `taskSpace(<번호 또는 이름>)`로 쥐고 같은 작업은 같은 공간을 쓴다. 다른 세션과 같은 공간 · 페이지를 동시에 조작하지 않는다.
- 해상도는 녹화 스크립트마다 `Emulation.setDeviceMetricsOverride`를 도구 `config.json` 값으로 설정한다(스크립트가 끝나면 풀리고, 한 도구 안에서는 바꾸지 않는다). 녹화는 `Page.startScreencast`로 프레임을 받는 즉시 저장 · ACK하며, 앞에 보이는 탭에서만 프레임이 온다(ego 창을 최소화하지 않는다).
- **진행 리듬:** 모든 ego 호출은 하나의 직렬 큐로 보낸다. 표시 포인터는 페이지에 그린 SVG 화살표를 `element.animate`로 움직이고, 실제 입력은 같은 경로를 단계별 `mouse.move`로 보내며, 실제 입력이 다 끝날 때까지 화살표를 목표에 고정한다. 위치가 바뀌는 대상은 150ms 간격 두 번 같은 위치일 때 출발한다. 조작은 행동 문장이 끝나기 약 250ms 전에 실행하고 다음 음성은 행동 종료 + 250ms에 시작한다. 녹화 시작 전에 조작 큐가 돌면 즉시 실패시키고, 긴 이동 · 긴 문자열 입력을 큐 한 항목에 넣지 않는다. 녹화 전에 서비스 상태와 PC 부하를 보되 수치만으로 중단하지 않고 실제 반응 · 프레임 간격으로 판정한다.
- **사용자가 직접 배치 · 입력할 때:** 녹화를 멈추고 `task.handOff()`로 넘긴 뒤 `takeOverTaskSpace(<번호>)`로 되찾는다. 그 결과는 화면 캡처가 아니라 앱 저장 데이터로 읽는다. 사용자가 ego 공간을 잡고 있으면 우회하지 않고 「계속」을 받은 뒤 되찾는다.

## 구간 녹화와 기록

- 구간마다 시작 상태 확인 → 녹화 → 끝 상태(`end-state.json`) · 프레임 · 행동 시각(`timing.json`) 저장. 한 구간씩 찍고 바로 실측한다(이동별 최대 프레임 공백, 클릭 좌표 오차, 문장보다 늦은 조작, 마지막 프레임).
- take는 매번 새 이름으로 보존하고, 실패 · 잘못된 상태 take는 이름을 붙여 남기되 합성에 쓰지 않는다. 기존 MP4를 덮어쓰지 않는다.

## 게시

- 커밋 전 `git fetch origin other-pc && git merge origin/other-pc`. 여러 세션이 같은 폴더를 쓰면 브랜치를 바꾸지 말고 임시 인덱스로 커밋을 만든다(`GIT_INDEX_FILE` → `read-tree` → `commit-tree` → push). 영상 한 편은 100 MiB 아래.
- 노션 학습 포털의 두 과정 회차 페이지 「🎬 강의 영상」 탭에는 그 커밋에 고정한 링크 세 가지(영상 열기 · MP4 내려받기 · 페이지 안 재생 토글)를 다른 영상과 같은 모양으로 넣고 다시 열어 확인한다. Notion 파일 업로드는 한 번에 20 MiB라 영상은 링크로 건다. 유튜브는 쓰지 않는다.
