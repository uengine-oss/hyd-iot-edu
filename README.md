# hyd-iot-edu

HYD 제조 AI 교육과정(경남대학교 피지컬AI 사관학교)의 시스템과 교재다. 유압 설비의 값이 올라와 저장되고, 이상이 감지되면 에이전트가 근거를 모아 조치를 추천하고, 사람이 승인하면 시스템이 실행한다. 이 시스템으로 온톨로지, 에이전트, 업무 흐름을 가르친다.

| 시스템(포털, 설비)을 켜거나 고친다 | [`문서/시스템/1_목적과_방향.md`](문서/시스템/1_목적과_방향.md) |

기본 문서는 다음 순서이며 교재 상세 기준은 덱·실습·검증으로 나뉜다: 1 목적과 방향, 2 기준, 3 현황, 4 만드는 법(켜고 돌리는 법), 5 결정 기록, 6 남은 일.

## 학교 PC에 설치하고 켜기

저장소 루트의 더블클릭 파일 셋이 전부다: `설치.bat`(실습 프로그램, 없는 것만) → `시작.bat`(실습 스택 켜기) → `끄기.bat`.
설치된 프로그램은 버전과 관계없이 건너뛰며 버전을 맞추기 위한 재설치·업데이트·삭제를 하지 않는다. Python도 Anaconda 등 기존 설치를 유지하고, 없을 때만 3.13.4를 설치한다. 설치 여부 확인은 실행 호환성 검증과 별개다.
실행 점검은 `시작.bat` 완료 뒤 `점검.bat`으로 한다. 다른 프로그램이나 Docker 컨테이너가 포트를 쓰고 있으면 시작할 때 빈 포트로 옮긴다(업무 DB·메일 포함). 포털과 점검은 같은 포트 표(`.hyd-runtime/ports.json`)를 사용하며, 포털 접속 주소는 시작 완료 메시지에 나온다. 복제 PC도 `시작.bat`을 실행하면 그 PC에 맞게 포트를 다시 확인한다.
Git·Docker·Python의 사용자별 설치 경로도 찾는다. 강사가 저장소 밖에 보관한 접속 설정 파일로 점검하려면 `점검.bat -LlmEnvFile "설정 파일의 전체 경로"`를 사용한다. 파일에는 `OPENAI_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` 세 항목을 `이름=값` 형식으로 적는다. 옵션 없이 실행하면 기존 실습 폴더의 `.env`를 사용한다.
순서와 확인할 화면, 막혔을 때, 하나씩 직접 설치하는 법(명령마다 어느 창인지 · 복사 버튼)은 [`산출물/설치/학교PC_설치확인/학교PC_설치확인.md`](산출물/설치/학교PC_설치확인/학교PC_설치확인.md)에 있다. GitHub에서 열어 따라 한다.
XG5000 4.73은 `설치.bat`이 설치하지 않는다. 가이드 E-7의 4.73 파일 링크로 직접 설치한다. C 드라이브 여유는 40 GB 이상을 권한다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `문서/교재/` | 교재의 기준과 인계 문서, 덱 제작 기준, 대본 작성 지침, 사실표, 실라버스 |
| `문서/시스템/` | 시스템의 기준과 인계 문서, 참조 문서(`참조/`), 검증 기록(`검증_기록/`) |
| `course/` | 기존 오프라인·학생 랩과 영상 자료. 현재 온라인 정본은 산출물/에서 확인 |
| `제작용/` | 교재 덱 원고·그림·도구·회차 구성과 제작 기록 |
| `산출물/` | [통합반](산출물/통합반/README.md)·[실전반](산출물/실전반/README.md)의 이론·실습별 회차 산출물 |
| `ot/` `dmz/` `it/` `common/` | 시스템의 코드. 망의 영역대로 나뉜다(현장, 완충 구역, 사무). `common/`은 공용 토픽과 스키마 |
| `scripts/` `tests/` | 시스템의 도구와 시험. `scripts/live/`는 실제 스택에서 쓰는 도구 |
| `students/` | 종합 랩의 출발본(`_template/`)과 세 시나리오의 참조 흐름(`flows/`) |
| `.claude/skills/` | 덱과 랩을 만드는 스킬 |

이름 규칙: 코드와 도구가 읽는 폴더는 영어로, 사람이 읽는 문서와 그 폴더는 한글로 둔다. 덱, 대본, 원고의 파일 이름은 한글이다(`통합반_05일차.md`).

## 지키는 것

- 공개 저장소다. 키, 사람 이름, 메일, 절대 경로, 내부 주소, 음성과 영상 파일을 올리지 않는다.
- `.env`는 열지 않는다.
- 브랜치는 `main`과 `develop` 둘만 쓴다. 커밋은 경로를 지정한다.
- 문서를 새로 늘리지 않는다. 옛 지침과 쓰이지 않는 파일을 남기지 않는다.

세션이 지키는 그 밖의 규칙은 [`CLAUDE.md`](CLAUDE.md)에 있다.
