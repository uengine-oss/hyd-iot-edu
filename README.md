# hyd-iot-edu

HYD 제조 AI 교육과정(경남대학교 피지컬AI 사관학교)의 시스템과 교재다. 유압 설비의 값이 올라와 저장되고, 이상이 감지되면 에이전트가 근거를 모아 조치를 추천하고, 사람이 승인하면 시스템이 실행한다. 이 시스템으로 온톨로지, 에이전트, 업무 흐름을 가르친다.

## 어디부터 읽는가

문서는 `문서/` 한 곳에만 있다.

| 하려는 일 | 읽을 곳 |
|---|---|
| 교재(강의 덱, 낭독 대본, 강의 영상, 실습 랩)를 만든다 | [`문서/교재/1_목적과_방향.md`](문서/교재/1_목적과_방향.md) |
| 시스템(포털, 설비)을 켜거나 고친다 | [`문서/시스템/1_목적과_방향.md`](문서/시스템/1_목적과_방향.md) |

두 폴더 모두 문서 여섯 개가 같은 순서다: 1 목적과 방향, 2 기준, 3 현황, 4 만드는 법(켜고 돌리는 법), 5 결정 기록, 6 남은 일.

## 폴더

| 폴더 | 내용 |
|---|---|
| [`산출물/`](산출물/README.md) | **수업에 그대로 쓰는 것만.** 교재(`교재/PPTX` · `교재/대본` · `교재/영상`)와 실습(`실습/<과정>/<회차_실습>/`의 `코드/` + `가이드.html`) |
| [`만들기/`](만들기/README.md) | 산출물을 만드는 재료와 도구. 덱 원고 · 그림 · 조립 스크립트(`decks/`), 실습의 완성본 · 실행 기록 · 가이드 생성기 · 촬영 대본(`labs/`), 도구(`tools/`), 배포 zip(`dist/`) |
| `문서/교재/` | 교재의 기준과 인계 문서, 덱 제작 기준, 대본 작성 지침, 사실표, 실라버스 |
| `문서/시스템/` | 시스템의 기준과 인계 문서, 참조 문서(`참조/`), 검증 기록(`검증_기록/`) |
| `ot/` `dmz/` `it/` `common/` | 시스템의 코드. 망의 영역대로 나뉜다(현장, 완충 구역, 사무). `common/`은 공용 토픽과 스키마 |
| `scripts/` `tests/` | 시스템의 도구와 시험. `scripts/live/`는 실제 스택에서 쓰는 도구 |
| `students/` | 종합 랩의 출발본(`_template/`)과 세 시나리오의 참조 흐름(`flows/`). 시스템 코드와 시험이 이 경로를 읽는다 |
| `.claude/skills/` | 덱 · 랩 · 영상을 만드는 스킬 |
| `.astra/` | 옛 방식의 참고: 아스트라(Codex)에 교재 작업을 맡기던 때의 작업 공간. 지금 절차가 아니다 |

## 무엇을 고치려면

| 고칠 것 | 고치는 곳 | 다시 만드는 법 |
|---|---|---|
| 강의 덱(PPTX) | `만들기/decks/integrated/dayNN/*.md`(모든 반 공통 원 덱) | 스킬 `hyd-course-deck`(`문서/교재/4_만드는_법.md` 1부). PPTX를 직접 고치지 않는다 |
| 낭독 대본 | `산출물/교재/대본/` | 직접 고친다(`문서/교재/4_만드는_법.md` 3부) |
| 새 틀 실습의 가이드 | `만들기/labs/offline/<랩>/build_guide.py` | 그 파일을 실행한다 |
| 옛 틀 실습의 가이드 | `산출물/실습/통합반_오프라인/<회차_실습>/가이드.html` | 직접 고친다 |
| 배포 zip | — | `배포묶음.py`(스킬 `hyd-course-deck`) |

이름 규칙: 사람이 찾는 폴더(`산출물/`과 그 안, `만들기/`, `문서/`)는 한글로, 도구와 코드가 읽는 폴더(`만들기/` 안, 실습의 `코드/` 안, 시스템 코드)는 영어로 둔다. 덱, 대본, 원고의 파일 이름은 한글이다(`통합반_05일차.md`).

## 지키는 것

- 공개 저장소다. 키, 사람 이름, 메일, 절대 경로, 내부 주소, 음성과 영상 파일을 올리지 않는다.
- `.env`는 열지 않는다.
- 브랜치는 `main`과 `claude/hyd-handoff-work-xziutz` 둘만 쓴다. 커밋은 경로를 지정한다.
- 문서를 새로 늘리지 않는다. 옛 지침과 쓰이지 않는 파일을 남기지 않는다.

세션이 지키는 그 밖의 규칙은 [`CLAUDE.md`](CLAUDE.md)에 있다.
