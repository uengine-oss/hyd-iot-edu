# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 입력, 사람, 온톨로지, 결과, 검증, 사례 폴더와 요청_처리.py가 보이게. 검증 폴더는 펼쳐 둔다.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
3. 1단계 요청에 대한 Copilot의 답. 세 사본을 견준 표와, 그 아래 「문장에 없어서 사본마다 다르게 정해진 것」 목록이 보이게(길면 두 장).
4. spec.md의 미리 보기를 연 VS Code 화면. 「금지 조건」 절과 「수용 기준」 절의 앞부분이 보이게.
5. 한 문장 요청에 Copilot이 아무것도 고치지 않고 답한 화면. 「정해 주셔야 할 것」 목록과 「규칙이 막는 것」에 테두리를 얹는다.
6. 긴급 조건이 더해진 spec.md의 미리 보기. 요구사항의 「긴급」 소절(기준 표와 가르는 차례 표)이 보이게.
7. Copilot이 터미널 명령 실행의 허용을 묻는 화면. 명령 글자(python 검증/견주기.py)와 「허용/계속」 버튼이 보이게.
8. 결과 md의 미리 보기와 입력 json을 좌우로 나란히 연 VS Code 화면. 결과 쪽은 R04의 「상태: 승인_대기」와 그 아래 「긴급」 줄이, 입력 쪽은 S01의 TS1 줄(60.7)이 보이게.
9. 위 요청에 Copilot이 아무것도 고치지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 방법을 제안하는 부분에 테두리를 얹는다.
10. 되돌려 준 뒤 Copilot이 긴급_기준.json의 바뀐 줄을 보여 주는 화면(threshold 줄이 바뀐 표시)과, 거짓이던 문장이 참으로 돌아왔다는 답이 보이게.
11. 검증/시나리오.json을 연 VS Code 화면. R04 건의 주어진_것(사람의 답 두 건, 사람의 결정 null, 긴급을 가르는 값 60.7)과 기대(승인_대기, true)가 보이게.
