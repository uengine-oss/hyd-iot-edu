# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 회의록, 결과 세 폴더가 펼쳐져 보이게.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
3. 위 요청에 대한 Copilot의 답. 회의록_1의 「정해진 것」 정리와, 답의 끝에서 「정해 주셔야 할 것」을 묻는 부분이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
4. 2단계 요청에 대한 Copilot의 계획. 「만드는 순서」와 「정해 주셔야 할 것」이 보이게. 요청하지 않았는데 들어온 단계와, 다시 물어 온 항목에 테두리를 얹는다.
5. Copilot이 SKILL.md를 만들면서 허용을 묻거나 변경을 보여 주는 화면. 파일 경로와 「유지/허용」 버튼이 보이게.
6. 새 채팅 단추의 위치와, 입력 칸에 / 를 쳤을 때 meeting-actions가 목록에 뜬 화면.
7. 결과 md 파일과 회의록 원문을 좌우로 나란히 연 VS Code 화면.
8. 위 요청에 Copilot이 회의록을 고치지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 방법을 제안하는 부분에 테두리를 얹는다.
9. Copilot이 SKILL.md에 「따로 챙길 것」을 더한 변경 화면. 새로 생긴 절이 초록색으로 표시되고, 다른 절은 바뀌지 않은 것이 보이게.
10. 되돌려 준 뒤 Copilot이 SKILL.md의 바뀐 부분을 보여 주는 화면(바뀐 줄이 초록색으로 표시된 화면).
