# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 입력, 사람, 검증, 결과 폴더와 spec.md, 요청_처리.py가 보이게. 검증 폴더는 펼쳐 둔다.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
3. 위 요청에 대한 Copilot의 답. 여섯 건을 금지 조건에 대어 본 표, 「여섯 건으로는 확인되지 않는 금지 조건」, 답의 끝에서 정해 달라고 묻는 부분이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
4. 2단계 요청에 대한 Copilot의 계획. 시나리오.feature에 적을 글(R04 편이 보이게), 문장의 꼴과 하는 일을 적은 표, 「확인받고 싶은 것」이 보이게. 아래 네 곳에 테두리를 얹는다.
5. Copilot이 터미널 명령 실행의 허용을 묻는 화면. 명령 글자(python 검증/시나리오_실행.py)와 「허용/계속」 버튼이 보이게. 파일을 만들 때의 「유지/허용」 물음도 뜬다면 한 장 더.
6. 결과/검증_결과.md의 미리 보기에서 「긴급 R07」 편(값이 묵은 건)의 표. Given의 「TS1 avg 120초 값은 60.1이다」 · 「신선도는 한도를 넘었다」와 Then의 「긴급은 null이다」가 보이게. 그 세 줄에 테두리를 얹는다.
7. 위 요청에 Copilot이 프로그램을 고치지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 방법을 제안하는 부분에 테두리를 얹는다.
8. 원인을 따라간 Copilot의 답. 「원인은 요청_처리.py가 아니라 써 넣으신 R04의 승인」이라고 말한 부분과, 「통과로 되돌리는 길」을 견준 표가 보이게.
9. 결과/검증_이력.md의 미리 보기. 다섯 줄(6편 통과, 11편 통과, 12편 통과, 12편 가운데 1편 실패, 12편 통과)이 보이게.
10. 되돌려 준 뒤의 결과/검증_결과.md 미리 보기. 맨 위에 생긴 「금지 조건마다 확인하는 편」 표와 「시나리오 없음」 줄이 보이게.
