# 쿨러 청소 작업 잠금 표지(LOTO) 절차서

게시: 2026-10-08 (안전환경)
적용: 유압 파워팩 쿨러의 핀 청소와 팬 점검

## 작업 전

1. 작업 내용을 교대 조장에게 알린다.
2. 팬 전원 차단기를 내린다.
3. 차단기에 잠금장치를 채우고 표지를 건다. 표지에는 작업자의 이름과 날짜를 적는다.
4. 팬이 멈춘 것을 눈으로 확인한다.

## 작업 뒤

5. 공구와 덮개가 제자리에 있는지 확인한다.
6. 잠금장치와 표지는 채운 사람이 직접 푼다.
7. 차단기를 올리고 팬이 도는 것을 확인한다.
8. 교대 조장에게 작업이 끝났음을 알린다.
