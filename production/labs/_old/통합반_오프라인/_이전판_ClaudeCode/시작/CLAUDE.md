# 이 실습 폴더의 규칙

이 폴더는 「회의록을 작업 목록으로 바꾸는 스킬」을 만드는 실습 폴더다. 아래 규칙은 이 폴더에서 하는 모든 작업에 적용된다.

## 하면 안 되는 것
1. `회의록/` 폴더의 파일은 읽기만 한다. 고치거나 지우거나 새로 만들지 않는다.
2. 회의록에 적혀 있지 않은 담당자, 날짜, 결정을 지어내지 않는다. 풀이해서 채운 값이 있으면 풀이했다는 사실과 원래 표현을 함께 밝힌다.
3. 요청받지 않은 파일을 만들지 않는다. 필요하다고 판단되면 만들기 전에 먼저 묻는다.
4. 이 실습에서는 프로그램과 스크립트를 만들지 않는다. 만드는 것은 `SKILL.md`와 결과 파일뿐이다.
5. 계획을 먼저 말해 달라는 요청을 받으면 계획만 말하고, 확인을 받기 전에는 파일을 만들지 않는다.

## 정해져 있는 것
- 스킬의 이름은 `meeting-actions`이고, 파일은 `.claude/skills/meeting-actions/SKILL.md` 하나다.
- 결과 파일은 `결과/` 폴더에 둔다. 파일 이름은 `<회의록 파일 이름>_작업목록.md`와 `<회의록 파일 이름>_작업목록.json`이다(예: `결과/회의록_1_작업목록.md`).
- 작업 한 건에는 네 가지가 있다: `할일`, `담당자`, `완료시점`, `근거`. JSON의 칸 이름도 이 네 낱말을 그대로 쓴다. `근거`는 회의록 원문의 문장을 그대로 옮긴 것이다.

## 정해져 있지 않은 것
아래는 이 규칙이 정하지 않는다. 요청하는 사람이 정해 주며, 요청에 없으면 정하지 말고 묻는다.
- 담당자나 완료 시점이 회의록에 없을 때 무엇이라고 적을지
- 「다음 주 금요일」처럼 날짜가 아닌 표현을 어떻게 다룰지
- 담당자가 둘 이상이거나 같은 일이 두 번 나올 때 어떻게 표시할지
- 결론이 나지 않은 안건을 어디에 둘지

## 말하는 방식
- 한국어로 답한다.
- 만든 파일과 고친 파일의 경로를 답의 끝에 적는다.
