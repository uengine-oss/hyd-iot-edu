# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 문서, 결과 세 폴더가 펼쳐져 있고 검사.py가 보이게.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
3. 위 요청에 대한 Copilot의 답. 절차 일곱 편의 표, 같은 뜻의 문장을 여러 절에서 모은 부분, 답의 끝에서 「정해 주실 것」을 번호로 묻는 부분이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
4. 2단계 요청에 대한 Copilot의 계획. 조건을 한 줄에 하나씩 적은 표(구분, 원문, 절, 이어지는 조치)와 끝의 「확인이 필요한 것」이 보이게. 다시 물어 온 항목에 테두리를 얹는다.
5. Copilot이 결과/schema.json을 고치면서 허용을 묻거나 변경을 보여 주는 화면. 파일 경로와 「유지/허용」 버튼이 보이게.
6. Copilot이 터미널 명령 실행의 허용을 묻는 화면. 명령 글자(python 검사.py)와 「허용/계속」 버튼이 보이게. 파일을 고칠 때의 「유지/허용」 물음도 뜬다면 한 장 더.
7. 결과/graph.json과 문서/HM-8_쿨러팬_정비매뉴얼.md를 좌우로 나란히 연 VS Code 화면. graph.json 쪽은 Condition 노드 다섯 줄이, 매뉴얼 쪽은 HM-8.5가 보이게.
8. 위 요청에 Copilot이 조건을 더하지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 길을 제안하는 부분에 테두리를 얹는다.
9. 되돌려 준 뒤 Copilot이 따라가기.py의 바뀐 부분을 보여 주는 화면(바뀐 줄이 초록색으로 표시된 화면).
