이제 결과/후보.json 을 원문에 대어 보는 대조.py 를 만들어 줘. 내가 후보를 하나하나 읽기 전에, 프로그램으로 가릴 수 있는 어긋남은 먼저 걸러 두려는 거야.

검사는 아래 넷이다.
1. 출처마다 인용이 그 문서의 그 구간 안에 글자 그대로 있는가. 공백이나 줄바꿈만 달라도 어긋난 것으로 본다.
2. 수치의 값과 단위가 그 항목의 인용 안에 있는가.
3. 후보의 클래스와 관계의 type 이 schema.json 에 있는가. 관계의 a 와 b 가 후보의 id 이거나 graph.json 의 id 인가.
4. 등록됨이 true 인 후보의 id 는 graph.json 에 있고, false 인 후보의 id 는 graph.json 에 없는가.

대조.py 한 파일만 만들고 한 번 실행해서 결과/대조_결과.md 를 써 줘. 어긋난 것이 나와도 후보.json 은 고치지 말고 무엇이 어긋났는지만 알려 줘.
