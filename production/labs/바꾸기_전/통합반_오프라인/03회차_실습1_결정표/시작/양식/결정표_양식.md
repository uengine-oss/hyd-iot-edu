# 규정 적합성 결정표 — 양식

이 결정표가 답하는 물음은 하나다.

> 후보 가운데 규정상 쓸 수 없거나, 감점하거나, 경고를 붙일 것은 무엇인가?

대상 설비는 유압 설비 HYD-01이고, 고장 유형은 쿨러 냉각 성능 상실, 확인된 원인은 쿨러 핀 오염이다.

## 조치 후보 넷

| 절차 번호 | 이름 | 종류 | 승인 |
|---|---|---|---|
| SOP-COOL-11 | 팬 최대 운전 | 원격 설비 제어 | 운전원 |
| SOP-COOL-12 | 팬 최대 운전과 부하 80 % | 원격 설비 제어 | 운전원 |
| SOP-COOL-13 | 부하 70 %와 야간 핀 세척 | 원격 설비 제어 | 운전원 |
| SOP-COOL-14 | 쿨러 핀 세척 | 현장 정비 작업 | 설비보전팀장 |

## 입력 목록

결정표의 `입력` 칸에는 이 목록의 이름만 쓸 수 있다. 조치를 판단하는 때에 실제로 얻을 수 있는 값이 이것뿐이기 때문이다.

| 입력 | 뜻 | 값 | 어디서 오는가 |
|---|---|---|---|
| `plc_mode` | PLC 운전 모드 | `REMOTE_AUTO`(원격 자동) · `REMOTE_MANUAL`(원격 수동) · `LOCAL`(현장 제어) | 운전 화면(SCADA) |
| `plc_state` | 설비 상태 | `RUN`(운전 중) · `TRIP`(보호 정지) | 운전 화면(SCADA) |
| `ts1` | 지금의 유온 | 숫자(℃) | 센서 TS1 |
| `ps1` | 지금의 토출 압력 | 숫자(bar) | 센서 PS1 |
| `fan100_hours` | 팬 100 % 연속 운전 시간 | 숫자(h) | 시계열 기록 |
| `forecast_ts1` | 조치 후 예측 유온 | 숫자(℃) | 조치를 했을 때의 예측 계산 |
| `forecast_ps1` | 조치 후 예측 토출 압력 | 숫자(bar) | 조치를 했을 때의 예측 계산 |
| `standby_ready` | 예비 펌프를 쓸 수 있는가 | `true` · `false` | 정비 관리 시스템(CMMS) |
| `order_due_h` | 긴급 오더의 납기까지 남은 시간 | 숫자(h) | 생산 관리 시스템(MES) |

`forecast_ts1`과 `forecast_ps1`은 「이 조치를 하면 어떻게 될 것인가」의 예측이어서 같은 상황에서도 후보마다 값이 다르다. 나머지는 설비와 업무의 지금 상태여서 상황 하나에 값이 하나다.

## 표의 열

| 열 | 뜻 |
|---|---|
| 규칙 | 행의 번호(R1, R2, …) |
| 입력 · 비교 · 기준값 · 단위 | 조건. 「입력 값을 기준값과 이 기호로 견준다」로 읽는다. 기호는 `==` `!=` `>` `>=` `<` `<=` 여섯 가지다. 단위가 없는 값이면 단위 칸은 비운다 |
| 판정 | 조건이 맞을 때 이 행이 내는 것. `제외` · `감점` · `경고` 가운데 하나 |
| 감점_만원 | 판정이 `감점`인 행에서 깎는 금액(만 원). 다른 판정이면 비운다 |
| 대상 | 이 행을 대어 볼 후보. 절차 번호를 `;`로 이어 적거나, 넷 모두이면 `모든 후보`라고 적는다 |
| 근거_절 · 원문 | 이 행이 나온 문서의 절 번호와 문장 |

## 세 판정의 뜻

| 판정 | 뜻 | 후보에 남는가 |
|---|---|---|
| 제외 | 해서는 안 된다 | 남지 않는다 |
| 감점 | 해도 되지만 대가가 있다 | 남고, 손실만큼 깎여 다른 후보와 견주어진다 |
| 경고 | 해도 되지만 알고 해야 한다 | 남고, 승인하는 사람이 알아야 할 사항이 붙는다 |
