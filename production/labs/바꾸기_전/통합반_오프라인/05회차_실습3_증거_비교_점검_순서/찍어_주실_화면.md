# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 온톨로지, 입력, 결과 네 폴더와 도구.py, 에이전트.py, 에이전트_정의.json이 보이게.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 새 대화 버튼에 빨간 테두리를 얹는다.
3. 위 요청에 대한 Copilot의 답. 열두 건의 표, 「같은 말인데 이어서 할 일이 다른 사례」를 가른 부분, 답의 끝에서 정해 달라고 묻는 부분이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
4. 2단계 요청에 대한 Copilot의 계획. 에이전트.py에 더할 것, 「이 계획대로면 나올 결과」 표, 「정해 주셔야 하는 것」이 보이게. 아래 네 곳에 테두리를 얹는다.
5. Copilot이 에이전트.py의 바뀐 부분을 보여 주며 유지할지 묻는 화면 또는 터미널 명령 실행의 허용을 묻는 화면. 파일 이름(에이전트.py)과 명령 글자(python 에이전트.py)가 보이게.
6. Copilot이 추가 확인과 점검 순서를 만든 뒤의 답. 사례마다 증거 상황을 적은 표와 「요청 글을 적은 틀」이 보이게.
7. 점검_계획.md의 미리 보기와 증거_비교.md의 미리 보기를 좌우로 나란히 연 VS Code 화면. 두 쪽 모두 N10이 보이게(왼쪽은 「추가 확인」과 「점검 순서」, 오른쪽은 표의 세 줄).
8. 위 요청에 Copilot이 결과를 바꾸지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 방법을 제안하는 부분에 테두리를 얹는다.
9. 에이전트_정의.json에서 센서_집계를 뺀 뒤 터미널에서 python 에이전트.py를 실행한 VS Code 화면. 왼쪽에 고친 json, 아래에 터미널, 오른쪽에 결과 md의 N01(증거 상황 부족, 추가 확인 「읽는 도구 없음」)이 보이게.
10. 되돌려 준 뒤 Copilot이 에이전트.py의 바뀐 부분을 보여 주는 화면(바뀐 줄이 초록색으로 표시된 화면).
