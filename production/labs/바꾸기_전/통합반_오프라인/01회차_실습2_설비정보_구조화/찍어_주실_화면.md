# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 자료(관계도 폴더까지 펼침), 결과가 보이게.
2. 설비_계기_목록.md를 편집기에 열고 미리 보기를 옆에 띄운 화면. 표의 머리줄과 1~18번 줄이 보이게.
3. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
4. 위 요청에 대한 Copilot의 답. 목록의 묶음 표와, 답의 끝에서 「정해 주셔야 할 것」을 묻는 부분이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
5. 2단계 요청에 대한 Copilot의 계획. 식별자 표와 관계 제안 표, 「정해 주셔야 하는 것」이 보이게(길면 두 장). 다시 물어 온 항목에 테두리를 얹는다.
6. Copilot이 schema.json을 만들면서 허용을 묻거나 변경을 보여 주는 화면. 파일 경로와 「유지/허용」 버튼이 보이게.
7. 채팅 위쪽의 새 채팅 단추의 위치. 단추에 빨간 테두리를 얹는다.
8. graph.json과 설비_계기_목록.md 미리 보기를 좌우로 나란히 연 VS Code 화면. graph.json 쪽은 sen:ts1과 sv:ts1 노드가 보이게.
9. 대조표.md의 미리 보기 화면. 「판정」 칸이 보이고, 「다르게 표현」인 줄에 테두리를 얹는다.
10. 원본 자료를 고쳐 달라는 요청에 Copilot이 고치지 않겠다고 답한 화면. 규칙을 든 문장에 빨간 테두리를 얹는다.
11. 「이번 한 번만 예외로 해 줘」에 대한 Copilot의 답. 예외를 두지 않는다는 규칙을 든 문장에 빨간 테두리를 얹는다.
12. 되돌려 준 뒤 Copilot이 schema.json과 graph.json의 바뀐 부분을 보여 주는 화면(바뀐 줄이 초록색과 빨간색으로 표시된 화면).
13. 대조표_2조.md의 미리 보기 화면. 「판정」 칸이 보이고, 「방향 반대」와 「파일에 없음」인 줄에 테두리를 얹는다.
14. 파일만으로 답하게 한 요청에 대한 Copilot의 답. 따라간 노드와 관계가 차례로 적힌 부분과, 유량의 한계가 없다고 답한 부분이 보이게.
