# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 결과, 자료 세 폴더가 펼쳐져 있고 결과 폴더의 schema.json, graph.json이 보이게.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
3. 위 요청에 대한 Copilot의 답. 클래스별 노드 수를 정리한 표와, 답의 끝에서 「정해 주셔야 하는 것」을 번호로 묻는 부분이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
4. 2단계 요청에 대한 Copilot의 계획. 관계마다 카디널리티를 제안한 표와, 끝의 「확인해 주실 것」이 보이게. 다시 물어 온 항목에 테두리를 얹는다.
5. Copilot이 결과/schema.json을 고치면서 허용을 묻거나 변경을 보여 주는 화면. 파일 이름과 「유지/허용」 버튼이 보이게.
6. 자료를 고쳐 달라는 요청에 Copilot이 고치지 않겠다고 답한 화면. 규칙을 근거로 든 문장에 테두리를 얹는다.
7. 결과/graph.json과 자료/공급_조건.csv를 좌우로 나란히 연 VS Code 화면. graph.json에서 SUPPLIED_BY 관계 일곱 줄이 보이게.
8. 세 물음에 대한 Copilot의 답. 물음마다 답과, 노드와 관계를 따라간 길이 보이게. 셋째 물음에서 「속성만으로는 답할 수 없다」고 한 부분에 테두리를 얹는다.
9. 되돌려 준 뒤 Copilot이 결과/schema.json과 결과/graph.json의 바뀐 부분을 보여 주는 화면(바뀐 줄이 초록색으로 표시된 화면).
