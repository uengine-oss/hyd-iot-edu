# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창과 웹 브라우저 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 지난_시간, 결과 세 폴더가 펼쳐져 있고 지난_시간 폴더의 schema.json, graph.json이 보이게.
2. Neo4j Browser에 들어간 뒤 위의 두 문장을 실행한 화면. 입력 칸과, 결과에 0이 나온 것이 보이게. 입력 칸과 실행 단추에 빨간 테두리를 얹는다.
3. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
4. 위 요청에 대한 Copilot의 답. 클래스별 노드 수와 관계 유형별 관계 수의 표, 제약으로 막는 것과 질의로 검사하는 것을 나눈 부분, 끝에서 「정해 주셔야 하는 것」을 번호로 묻는 부분이 보이게(길면 두세 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
5. 2단계 요청에 대한 Copilot의 계획. 02_적재.cypher의 본보기 문장(MERGE … SET, MATCH … MERGE)과, 끝의 「확인해 주실 것」이 보이게. 본보기 문장의 MERGE 괄호 안과 「확인해 주실 것」에 테두리를 얹는다.
6. Neo4j Browser에서 01_제약.cypher를 실행한 뒤 위의 SHOW CONSTRAINTS 문장을 실행한 화면. 결과 표에 lab_ 로 시작하는 제약 11행이 보이게.
7. Neo4j Browser에 02_적재.cypher 전체를 붙여넣어 실행한 화면. 문장마다 성공했다는 표시가 줄지어 보이게. 문장의 수(89)가 보이면 함께.
8. Neo4j Browser에서 조회 2를 실행한 화면. 입력 칸의 질의와, 결과 표의 한 행(펌프 축 씰 키트, P-PMP-SEAL, A정밀 (저가), 35)이 보이게.
9. Neo4j Browser에서 위 CREATE 문장을 실행해 빨간 오류가 난 화면. 오류 글의 already exists 부분이 보이게 테두리를 얹는다.
10. 먼저 다 지우는 문장을 넣어 달라는 요청에 Copilot이 넣지 않겠다고 답한 화면. 규칙을 근거로 든 문장과, 대신 다시 실행하라고 한 부분에 테두리를 얹는다.
11. Neo4j Browser에서 위 질의를 실행해 그래프 보기로 본 화면. HYD-01, 구성 요소 셋, 센서 다섯, 상태 변수 다섯과 그 사이의 관계가 보이게.
