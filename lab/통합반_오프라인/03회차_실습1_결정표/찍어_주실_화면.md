# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 문서, 양식, 입력, 결정표, 결과 여섯 폴더가 보이고 문서 폴더가 펼쳐져 있게.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
3. 위 요청에 대한 Copilot의 답. 조건 문장을 모은 표, 옮기기 어렵다고 본 문장의 표, 답의 끝에서 정해 달라고 묻는 목록이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
4. 2단계 요청에 대한 Copilot의 답. 나올 행의 표, 비교 기호를 고른 까닭, 옮기지 않는 문장의 표, 확인해 달라는 항목이 보이게. 기호의 까닭에 적힌 원문의 낱말(아닐 때 · 넘겼다면 · 이상이면)에 테두리를 얹는다.
5. 결정표.csv와 매뉴얼의 HM-8.8을 좌우로 나란히 연 VS Code 화면. 표의 R2 행과 매뉴얼의 「이미 24시간을 넘겼다면…」 문장에 테두리를 얹는다.
6. 위 요청에 대한 Copilot의 답. 더할 행의 후보 표에서 채우지 못한 칸(「물음」이라고 적힌 칸)과, 정해 달라는 목록이 보이게. 채우지 못한 칸에 테두리를 얹는다.
7. 제외_사유.md의 미리 보기와 운전_상황.json을 좌우로 나란히 연 VS Code 화면. 미리 보기는 S5의 표와 「남는 후보」 줄이 보이게.
8. 위 요청에 Copilot이 결정표를 고치지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 방법을 제안하는 부분에 테두리를 얹는다.
9. 되돌려 준 뒤 Copilot이 제외_사유.md의 바뀐 부분을 보여 주는 화면(더해진 줄이 초록색으로 표시된 화면).
