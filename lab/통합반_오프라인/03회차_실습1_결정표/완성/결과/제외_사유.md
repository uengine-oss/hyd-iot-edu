# 제외 사유

`입력/운전_상황.json`의 여섯 상황마다 `결정표/결정표.csv`의 여섯 행(R1~R6)을 대어 본 기록이다.

- 표에는 판정이 `제외`인 행에 걸린 후보만 적는다. 한 후보가 제외 행 둘에 걸리면 걸린 행마다 한 줄씩 적는다.
- 감점이나 경고만 맞은 후보는 빠지는 것이 아니므로 표에 넣지 않고, 표 아래 「남는 후보」에 그 규칙 번호를 괄호로 붙인다.

## S1

쿨러 과열 경보가 뜬 때의 값. 팬은 60 %로 돌고 있었다.

`plc_mode` REMOTE_AUTO · `plc_state` RUN · `fan100_hours` 0

제외되는 후보가 없다.

남는 후보: SOP-COOL-11, SOP-COOL-12, SOP-COOL-13, SOP-COOL-14(R3)

## S2

팬을 100 %로 올린 지 24.1시간째.

`plc_mode` REMOTE_AUTO · `plc_state` RUN · `fan100_hours` 24.1

제외되는 후보가 없다.

남는 후보: SOP-COOL-11(R2), SOP-COOL-12(R2), SOP-COOL-13, SOP-COOL-14(R3)

## S3

`plc_mode` REMOTE_MANUAL · `plc_state` RUN · `fan100_hours` 0

| 후보 | 걸린 규칙 | 조건 | 대어 본 값 | 근거 절 | 원문 |
|---|---|---|---|---|---|
| SOP-COOL-11 | R1 | `plc_mode != REMOTE_AUTO` | REMOTE_MANUAL | HM-8.8 | 원격 조치(SOP-COOL-11~13)는 REMOTE_AUTO가 아닐 때 쓰지 않는다. |
| SOP-COOL-12 | R1 | `plc_mode != REMOTE_AUTO` | REMOTE_MANUAL | HM-8.8 | 원격 조치(SOP-COOL-11~13)는 REMOTE_AUTO가 아닐 때 쓰지 않는다. |
| SOP-COOL-13 | R1 | `plc_mode != REMOTE_AUTO` | REMOTE_MANUAL | HM-8.8 | 원격 조치(SOP-COOL-11~13)는 REMOTE_AUTO가 아닐 때 쓰지 않는다. |

남는 후보: SOP-COOL-14(R3)
