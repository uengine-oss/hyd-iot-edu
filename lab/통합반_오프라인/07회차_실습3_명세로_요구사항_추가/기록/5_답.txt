`긴급_기준.json`을 명세의 표대로 만들고 `요청_처리.py`를 고쳤습니다. 긴급 묶음의 열세 문장은 모두 참이고, 거짓은 없습니다. 에이전트, 도구, 허용 목록, 점검 계획 결과는 고칠 일이 없었고, 실행 전후의 내용이 같은 것도 확인했습니다.

## 고친 것

- **`긴급_기준.json`**: 여섯 칸을 표의 값 그대로 적었습니다(`COOLER_DEGRADATION`, `TS1`, `avg`, `120`, `gte`, `60`).
- **`요청_처리.py`**:
  - 실행할 때마다 기준 파일을 읽습니다.
  - `_긴급` 함수가 명세의 차례대로 가립니다: 사례 미정이면 `null`, 경보 패턴이 다르면 `false`, 신선도·값·관측을 못 읽으면 `null`, 그 밖에는 기준과 비교.
  - 값과 신선도는 `도구.센서_집계`로만 읽습니다.
  - 결과 항목의 `상태` 바로 다음에 `긴급`을 넣었습니다.
  - md 요청 절의 「상태」 줄 아래에 「긴급」 한 줄을 넣었습니다.
  - 질문, 승인, 「사람이 할 일」을 만드는 부분은 손대지 않았습니다.

명세에 글자 그대로는 없는데 넣은 것이 하나 있습니다. 기준 파일이 객체가 아니거나, 여섯 칸 가운데 빠진 것이 있거나, `expect`가 `lt`·`gt`·`gte`가 아니면 까닭을 알리고 결과를 쓰지 않습니다. 「읽지 못하면 결과를 쓰지 않는다」를 그렇게 풀었습니다.

## `python 검증/견주기.py`의 출력

`python 요청_처리.py`는 한 번 실행했고 화면에 나온 것은 없습니다. 그 뒤 견주기의 출력입니다.

```
변경 전: 검증/변경_전/요청_처리.json
변경 후: 결과/요청_처리.json

항목 수: 10건 → 10건
항목의 순서: 같다

R01  기존 칸은 그대로다
      + 더해진 칸 긴급: null
R02  기존 칸은 그대로다
      + 더해진 칸 긴급: false
R03  기존 칸은 그대로다
      + 더해진 칸 긴급: true
R04  기존 칸은 그대로다
      + 더해진 칸 긴급: true
R05  기존 칸은 그대로다
      + 더해진 칸 긴급: false
R06  기존 칸은 그대로다
      + 더해진 칸 긴급: false
R07  기존 칸은 그대로다
      + 더해진 칸 긴급: false
R08  기존 칸은 그대로다
      + 더해진 칸 긴급: null
R09  기존 칸은 그대로다
      + 더해진 칸 긴급: false
R10  기존 칸은 그대로다
      + 더해진 칸 긴급: false

요약: 기존 칸이 달라진 항목 0건 · 없어진 칸 0개 · 더해진 칸 1개 (긴급) · 항목의 순서 같다
```

견주기는 이 출력 앞에 한 번 더 돌았습니다. 프로그램 실행 명령이 한 차례 막힌 줄 모르고 먼저 돌린 것이라 그때는 「더해진 칸 0개」가 나왔고, 위 출력은 프로그램을 실행한 뒤의 것입니다. 견주기는 읽기만 합니다.

## 긴급 묶음의 수용 기준

| 문장 | 결과에서 본 값 | 판정 |
|---|---|---|
| AC-38 | R03: 사례 `S01`, `긴급` `true` | 참 |
| AC-39 | R03: `상태` `확정`, `승인` 있음 | 참 |
| AC-40 | R04: 사례 `S01`, `긴급` `true` | 참 |
| AC-41 | R04: `상태` `승인_대기` | 참 |
| AC-42 | R05: 사례 `S07`, `긴급` `false` | 참 |
| AC-43 | R02: 사례 `S06`, `긴급` `false` | 참 |
| AC-44 | R01: 사례 `null`, `긴급` `null` | 참 |
| AC-45 | 열 건 모두 `상태`, `긴급`, `사례`의 차례 | 참 |
| AC-46 | 열 건의 값: `true` 2건, `false` 6건, `null` 2건 | 참 |
| AC-47 | 견주기에서 R01~R10 열 줄이 모두 「기존 칸은 그대로다」 | 참 |
| AC-48 | 요약 줄이 문장에 적힌 글자와 같음 | 참 |
| AC-49 | md의 R03 절: `- 상태: **확정**` 바로 아래가 `- 긴급: **예**` | 참 |
| AC-50 | md 「승인을 기다리는 요청」의 차례: R02, R04, R05 | 참 |

`결과/요청_처리.md`는 고치기 전과 대어 보면 「긴급」 줄 열 개가 더해진 것 말고 달라진 줄이 없습니다. 기존 수용 기준 AC-01~37은 이번에 다시 대어 보지 않았습니다. 다만 견주기가 기존 일곱 칸이 열 건 모두 그대로라고 하므로, json 값에 걸린 문장은 달라질 것이 없습니다.
