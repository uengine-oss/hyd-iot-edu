# 사례: 한 문장으로 온 변경 요청

이 폴더는 같은 요청 한 문장을 세 번 보낸 기록이다. 읽기만 한다.

## 어떻게 만든 것인가
- 지금 이 폴더의 프로그램, 입력, 사람이 쓴 두 파일, 온톨로지, 결과를 그대로 복사한 사본 셋을 만들었다. 규칙 파일과 명세는 넣지 않았다.
- 사본마다 새 대화를 열어 `모호한_요청/요청.txt`의 한 문장만 보냈다. 다른 말은 덧붙이지 않았다.
- 세 사본이 받은 문장은 글자 하나 다르지 않다.

## 들어 있는 것
사본마다 `답.md`(돌아온 답)와, 그 사본에서 **바뀐 파일만** 들어 있다. 들어 있지 않은 파일은 고치기 전과 같다.

| 폴더 | 바뀐 파일 |
|---|---|
| `모호한_요청/사본1/` | `요청_처리.py`, `요청_처리.json` (`요청_처리.md`는 바뀌지 않았지만 견주어 보라고 넣어 두었다) |
| `모호한_요청/사본2/` | `요청_처리.py`, `요청_처리.json`, `요청_처리.md`, `도구.py`, `에이전트_정의.json` |
| `모호한_요청/사본3/` | `요청_처리.py`, `요청_처리.md`, `도구.py`, `에이전트_정의.json`, `에이전트.py`, `점검_계획.json` (`요청_처리.json`은 바뀌지 않았지만 견주어 보라고 넣어 두었다. `점검_계획.md`도 바뀌었으나 싣지 않았다) |

## 견주는 법
고치기 전의 요청 처리 결과는 `검증/변경_전/요청_처리.json`이고, 고치기 전의 점검 계획은 `결과/점검_계획.json`이다. 터미널에서 아래처럼 실행하면 항목마다 칸마다 달라진 곳이 나온다.

```
python 검증/견주기.py 검증/변경_전/요청_처리.json 사례/모호한_요청/사본2/요청_처리.json
python 검증/견주기.py 검증/변경_전/요청_처리.json 사례/모호한_요청/사본3/요청_처리.json
python 검증/견주기.py 결과/점검_계획.json 사례/모호한_요청/사본3/점검_계획.json
```
