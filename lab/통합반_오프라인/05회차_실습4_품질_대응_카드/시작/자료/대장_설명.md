# 원인 분석 대장 설명

`원인_분석_대장.json`은 품질팀이 접수된 불량의 원인을 조사한 기록이다. 조사 한 건이 한 줄이다.

| 칸 | 뜻 |
|---|---|
| `분석_번호` | 조사 한 건의 번호 |
| `접수` | 이 조사가 다루는 접수 번호의 목록. 같은 로트의 접수 여럿을 한 조사가 다루기도 한다 |
| `상태` | `종결` 또는 `진행` |
| `원인` | 상태가 `종결`이면 조사로 확인한 원인, `진행`이면 조사하고 있는 가설 |
| `근거` | 종결이면 원인을 확인한 근거, 진행이면 아직 끝나지 않은 일 |
| `담당` | 조사를 맡은 사람 |
| `종결일` | 조사를 끝낸 날. 진행이면 비어 있다 |

- 접수가 들어왔다고 조사가 바로 열리는 것은 아니다. 대장에 없는 접수가 있다.
