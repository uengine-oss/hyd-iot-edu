# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 기준, 접수, 자료, 결과 다섯 폴더와 에이전트_정의.json이 펼쳐져 보이게.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
3. 위 요청에 대한 Copilot의 답. 차례를 한 줄씩 적은 부분, Q01과 Q03을 손으로 만든 표, 답의 끝에서 정해 달라고 묻는 부분이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
4. 2단계 요청에 대한 Copilot의 계획. 도구.py와 에이전트.py에 둘 것, 3번 결정이 어떤 카드를 내는지 미리 알린 부분, 「더 정해 주셔야 하는 것」이 보이게. 아래 네 곳에 테두리를 얹는다.
5. Copilot이 터미널 명령 실행의 허용을 묻는 화면. 명령 글자(python 에이전트.py Q01)와 「허용/계속」 버튼이 보이게. 파일을 만들 때의 「유지/허용」 물음도 뜬다면 한 장 더.
6. 결과 md의 미리 보기와 접수 json을 좌우로 나란히 연 VS Code 화면. 결과 쪽은 Q03 카드의 「원인 근거」와 「대응 초안」이, 접수 쪽은 Q03의 본문이 보이게.
7. 위 요청에 Copilot이 접수를 고치지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 방법을 제안하는 부분에 테두리를 얹는다.
8. 6단계 요청에 대한 Copilot의 답. 바뀐 카드를 앞뒤로 견준 표와 「제가 정한 것」이 보이게.
9. 접수/불량_접수.json의 맨 끝에 Q13을 붙여넣은 편집기 화면. Q12를 닫는 } 뒤의 쉼표, Q13의 여섯 칸, 맨 끝의 ] 가 보이게. 쉼표와 ] 에 테두리를 얹는다.
10. 되돌려 준 뒤 Copilot이 에이전트.py의 바뀐 부분을 보여 주는 화면(바뀐 줄이 초록색으로 표시된 화면).
