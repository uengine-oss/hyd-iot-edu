## Q01 카드

| 칸 | 값 |
|---|---|
| `품질_유형` | QT-01 / 치수 불량 / 단서: 공차, 내경 |
| `추가_확인_항목` | 없음 |
| `원인_상태` | 미확정 |
| `원인_근거` | 내용 빈 글, 출처 `없음` |
| `갈래` | `조사_요청` |
| `담당_부서` | 품질팀 |
| `대응_초안` | [가나자동차 수입검사 앞] 접수 Q01(치수 불량) 건입니다. 원인은 아직 확인되지 않았습니다. 품질팀에 원인 조사를 요청했으며, 원인이 확인되면 조치와 함께 알려 드리겠습니다. |
| `호출_기록` | `분류_기준()` → `유형_기준(QT-01)` → `대응_틀(조사_요청)` |

`입고 검사`가 QT-06에도 걸렸지만 단서 가짓수가 2 대 1이라 QT-01로 정해졌습니다.

## 알아 두실 것

- **도구는 지금 셋입니다.** 말씀대로 `원인_분석`은 만들지 않았습니다. 규칙의 「도구는 넷이고 이름은 아래와 같다」에서 하나가 아직 빠져 있는 상태이고, 허용 목록에 더하신 뒤 붙이면 넷이 됩니다.
- **실행으로 결과 파일 두 개가 생겼습니다.** `결과/` 폴더에 Q01 카드 한 장만 든 json과 md가 있습니다. 다음에 실행하면 덮어씁니다.
- **미분류 카드의 `단서` 칸은 제가 임시로 채웠습니다.** 똑같이 걸린 유형들의 단서를 모두 넣고, 걸린 것이 없으면 빈 목록으로 둡니다. 규칙에도 정해 주신 것에도 없는 부분이라, 다르게 두고 싶으시면 알려 주세요. Q01에는 영향이 없습니다.
