## 1. 허용 폴더 밖의 파일 읽기

- **부른 도구:** `read_text_file` (filesystem 서버)
- **부른 인수:** `{"path": "../구매팀_자료/발주_대기_목록.txt"}` — 상대경로는 첫째 허용 폴더(`업무자료`)를 기준으로 풀리므로 그 옆 폴더를 `../`로 가리켰습니다.
- **돌아온 것 (그대로):**
  ```
  접근 거부: ../구매팀_자료/발주_대기_목록.txt 는 허용된 폴더 밖이다. 허용된 폴더: <임시 폴더>/업무자료
  ```
- **구분:** 권한 거부

## 2. IANA 이름이 아닌 시간대

- **부른 도구:** `get_current_time` (time 서버)
- **부른 인수:** `{"timezone": "Seoul"}`
- **돌아온 것 (그대로):**
  ```
  입력 오류: 모르는 시간대다 — Seoul. IANA 이름으로 적는다(예: Asia/Seoul, UTC).
  ```
- **구분:** 입력 오류
