# 서버 비교

세 MCP 서버(`filesystem`, `git`, `time`)에서 도구를 두 개씩 불러 본 기록이다. 부른 도구만 적었다.

## 적은 방식

- 부른 때: 2026-10-13 02:20 무렵(Asia/Seoul, `get_current_time`이 돌려준 값 기준)
- 돌아온 결과가 다섯 줄을 넘으면 앞의 다섯 줄만 옮기고 칸 끝에 줄였다고 적었다. 빈 줄도 한 줄로 셌고 `(빈 줄)`로 적었다.
- 표 안에서는 줄마다 따로 감쌌고, 결과에 든 `|`는 표가 깨지지 않게 `\|`로 적었다. 그 밖의 글자는 돌아온 그대로다.
- `읽기 전용` 칸은 서버 파일의 머리말과 도구 정의를 따랐다.

## 부른 기록

### filesystem

| 서버 | 도구 | 필수 인수 | 읽기 전용 | 부른 인수 | 돌아온 결과 |
|---|---|---|---|---|---|
| filesystem | `list_directory` | `path` | 예 | `{"path": "회의록"}` | `[FILE] 2026-10-06_정기회의.txt`<br>`[FILE] 2026-10-08_주간협의.txt` |
| filesystem | `read_text_file` | `path` | 예 | `{"path": "회의록/2026-10-08_주간협의.txt"}` | `주간 생산·보전 협의 메모 (10월 2주차)`<br>(빈 줄)<br>`2026-10-08(목) 오전 10시~10시 40분, 회의실 B`<br>`참석 — 강도현, 한서윤, 오민재, 류다은, 문태오`<br>`(메모: 오민재)`<br>— 줄였다: 31줄 가운데 앞의 5줄 |

### git

| 서버 | 도구 | 필수 인수 | 읽기 전용 | 부른 인수 | 돌아온 결과 |
|---|---|---|---|---|---|
| git | `git_status` | 없음 | 예 | `{}` | `## main`<br>` M 회의록/2026-10-08_주간협의.txt`<br>`?? 점검/3호기_쿨러_핀_점검_기록.txt` |
| git | `git_log` | 없음 | 예 | `{}` | `커밋 42f785f \| 2026-10-13 \| 문태오 \| 쿨러 점검 메모에 3호기 점검 완료와 1호기 필터 망 시험 설치를 적는다`<br>(빈 줄)<br>`M	점검/쿨러_점검_메모.md`<br>`커밋 adf41f1 \| 2026-10-08 \| 한서윤 \| 쿨러 점검 메모를 만든다: 청소 주기 변경과 호기별 핀 점검`<br>(빈 줄)<br>— 줄였다: 18줄(커밋 5건) 가운데 앞의 5줄 |

### time

| 서버 | 도구 | 필수 인수 | 읽기 전용 | 부른 인수 | 돌아온 결과 |
|---|---|---|---|---|---|
| time | `get_current_time` | `timezone` | 예 | `{"timezone": "Asia/Seoul"}` | `{`<br>`  "timezone": "Asia/Seoul",`<br>`  "datetime": "2026-10-13T02:20:05+09:00",`<br>`  "day_of_week": "화요일"`<br>`}` |
| time | `convert_time` | `source_timezone`, `time`, `target_timezone` | 예 | `{"source_timezone": "Asia/Seoul", "time": "14:00", "target_timezone": "UTC"}` | `{`<br>`  "source": {`<br>`    "timezone": "Asia/Seoul",`<br>`    "datetime": "2026-10-13T14:00:00+09:00",`<br>`    "day_of_week": "화요일"`<br>— 줄였다: 13줄 가운데 앞의 5줄. 잘린 뒤쪽에 `target`(UTC)과 `time_difference`가 있다 |

## 세 서버가 어떻게 다른가

### 도구 이름을 짓는 방식

- `filesystem`과 `time`은 서버 이름 없이 `동작_대상`으로 짓는다(`list_directory`, `read_text_file`, `get_current_time`, `convert_time`).
- `git`은 모든 도구에 `git_`을 앞에 붙이고 뒤에 git 명령의 이름을 둔다(`git_status`, `git_log`).

### 필수 인수

- `filesystem`은 부른 두 도구 모두 `path`가 필수다.
- `git`은 부른 두 도구 모두 필수 인수가 없다(볼 저장소는 서버를 띄울 때 정해진다).
- `time`은 인수가 전부 필수이고, 서버에 기본 시간대가 있어도 `timezone`을 넘겨야 한다.

### 돌아온 결과의 모양

- `filesystem`은 꾸밈없는 글이다(폴더는 한 줄에 하나씩 `[FILE]` 표시, 파일은 내용 그대로).
- `git`도 글이지만 git 명령의 출력 모양이다(상태 부호 ` M`·`??`, `커밋 번호 | 날짜 | 쓴 사람 | 메시지` 줄과 바뀐 파일 줄).
- `time`은 JSON 객체다.

### 다시 불러도 결과가 같은지

- `time`의 `get_current_time`은 부를 때마다 달랐다(앞서 `02:19:24`, 이번 `02:20:05`).
- `time`의 `convert_time`은 같은 인수로 두 번 불러 결과가 같았다. 다만 날짜를 오늘로 보므로 날이 바뀌면 `datetime`의 날짜가 달라진다.
- `filesystem`과 `git`은 이번에 한 번씩만 불러서 다시 부른 결과를 견주지 못했다. 서버 설명으로는 파일과 저장소가 바뀌지 않는 한 같아야 하지만 확인한 것은 아니다.
