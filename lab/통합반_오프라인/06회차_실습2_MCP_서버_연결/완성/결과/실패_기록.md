# 실패 기록

실패한 호출의 기록이다. `돌아온 것`은 돌아온 오류 문장 그대로다. 실패한 호출을 다른 방법으로 대신하지 않았다.

| 시도 | 부른 도구와 인수 | 돌아온 것 | 구분 |
|---|---|---|---|
| `업무자료` 옆의 `구매팀_자료/발주_대기_목록.txt`를 읽는다 | filesystem `read_text_file` `{"path": "../구매팀_자료/발주_대기_목록.txt"}` | 접근 거부: ../구매팀_자료/발주_대기_목록.txt 는 허용된 폴더 밖이다. 허용된 폴더: <임시 폴더>/업무자료 | 권한 거부 |
| 시간대를 `Seoul`로 넣어 지금 시각을 얻는다 | time `get_current_time` `{"timezone": "Seoul"}` | 입력 오류: 모르는 시간대다 — Seoul. IANA 이름으로 적는다(예: Asia/Seoul, UTC). | 입력 오류 |
| git 서버를 멈춘 뒤 최근 커밋 세 건을 본다 | 부르지 못했다. 부르려던 것은 git `git_log` `{"max_count": 3}`이다. git 서버의 도구가 도구 목록에서 사라져 호출 자체를 보낼 수 없었다 | 서버가 돌려준 것은 없다(호출을 보내지 못했으므로 오류 문장도 없다). 받은 것은 도구 목록 쪽의 알림뿐이다: "The following deferred tools are no longer available (their MCP server disconnected)" — `git_diff`, `git_show`, `git_log`, `git_status` | 서버 미연결 |
