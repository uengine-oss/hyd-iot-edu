# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 문서, 지난_시간, 결과 폴더와 대조.py가 보이고 문서 폴더의 여섯 파일이 펼쳐져 있게.
2. 1단계 요청에 대한 Copilot의 답. 달라진 줄을 판본 1과 판본 2로 나란히 보인 표, 그 줄을 인용한 항목의 번호, 답의 끝에서 정해 달라고 묻는 부분이 보이게. 아래 세 곳에 ①②③ 테두리를 얹는다.
3. 2단계 요청에 대한 Copilot의 계획. K-004 단계 2의 칸마다 지금 값과 반영 뒤의 값을 견준 표, 판본별 출처의 수, 끝의 「더 정해 주셔야 할 것」이 보이게. 출처의 수와 다시 물어 온 항목에 테두리를 얹는다.
4. Copilot이 터미널 명령 실행의 허용을 묻는 화면. 명령 글자(python 대조.py)와 「허용/계속」 버튼이 보이게.
5. 결과/후보.json과 문서/HM-8_cooler-fan-manual_개정.md를 좌우로 나란히 연 VS Code 화면. 왼쪽은 K-004 단계 2의 출처와 이전 칸, 오른쪽은 HM-8.5의 SOP-COOL-11이 보이게.
6. 결과/개정_조회.md를 미리 보기로 연 VS Code 화면. 맨 위의 세 수와 「이전 기준과 새 기준」 표가 보이게. K-004 단계 2의 두 줄에서 판본 칸에 테두리를 얹는다.
7. 위 요청에 Copilot이 지우지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 방법을 제안하는 부분에 테두리를 얹는다.
8. 되돌려 준 뒤 Copilot이 개정_조회.py의 바뀐 부분을 보여 주는 화면(바뀐 줄이 색으로 표시되고, 나머지 검사는 바뀌지 않은 것이 보이게).
