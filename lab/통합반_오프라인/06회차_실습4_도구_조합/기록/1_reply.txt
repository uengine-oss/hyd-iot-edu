규칙 파일과 스킬 파일을 읽었고, 두 서버의 도구를 확인한 뒤 자료 폴더와 변경 기록을 살펴봤습니다. 파일은 만들지 않았습니다.

## 읽은 규칙과 스킬

- **규칙(`.github/copilot-instructions.md`)**: `회의록/`과 `자료/`는 읽기만 하고, 파일은 `filesystem` 서버로, 변경 기록은 `git` 서버로만 확인합니다. 도구가 실패하면 터미널 등으로 돌아가지 않고 `변경확인`을 `미완료`로 적습니다. 결과는 `결과/<회의록 파일 이름>_업무항목.md`와 `.json` 두 개이며, 작업 한 건에 `자료`, `변경확인`, `변경기록` 세 칸을 더합니다.
- **스킬(`meeting-actions`)**: 회의록 하나에서 작업(`할일`, `담당자`, `완료시점`, `근거`), 미결 안건, 따로 챙길 것(담당 미정, 기한 미정, 중복)을 뽑는 방법입니다. 이 폴더에서는 스킬이 말하는 `_작업목록` 파일은 만들지 않습니다.

## 서버의 도구와 넘길 값

**`filesystem` 서버 (5개)**

| 도구 | 하는 일 | 넘길 값 |
|---|---|---|
| `list_allowed_directories` | 서버가 드나들 수 있는 폴더 목록 | 없음 |
| `list_directory` | 폴더 하나의 내용(`[DIR]`, `[FILE]`) | `path` (필수) |
| `read_text_file` | 글 파일 하나의 내용 | `path` (필수), `head` (선택, 앞에서 읽을 줄 수) |
| `search_files` | 폴더 아래 글 파일에서 낱말이 든 줄 찾기 | `path` (필수), `query` (필수) |
| `get_file_info` | 파일·폴더의 크기, 고친 시각, 종류 | `path` (필수) |

`path`는 절대경로이거나 첫째 허용 폴더(`회의록/`)를 기준으로 한 상대경로입니다.

**`git` 서버 (4개)**

| 도구 | 하는 일 | 넘길 값 |
|---|---|---|
| `git_log` | 커밋 이력(번호, 날짜, 사람, 메시지, 바뀐 파일) | `max_count` (선택, 없으면 10), `path` (선택) |
| `git_status` | 마지막 커밋 뒤에 고친·새로 생긴·지워진 파일 | 없음 |
| `git_show` | 커밋 하나의 내용과 바뀐 줄 | `revision` (필수, 커밋 번호나 `HEAD`, `HEAD~1`) |
| `git_diff` | 아직 커밋하지 않은 변경을 줄 단위로 | `path` (선택) |

`git` 서버의 `path`는 저장소 기준 상대경로입니다.

**파일을 바꾸는 도구는 없습니다.** 아홉 개 모두 읽거나 조회하는 도구이고, 쓰기·고치기·지우기·커밋 도구는 두 서버 어디에도 없습니다.

## 변경 기록에 올라가지 않은 파일

**한 개 있습니다: `교육/쿨러_점검_교육자료.md`.**

- `git` 서버의 `git_status`가 `?? 교육/`을 돌려줬습니다. `교육/` 폴더가 통째로 새로 생겨 아직 커밋되지 않았다는 뜻이고, 그 안의 파일은 이것 하나입니다.
- `git` 서버의 `git_diff`는 `(커밋하지 않은 변경 없음)`을 돌려줬습니다. 이미 기록에 올라간 파일 가운데 고쳐 놓고 커밋하지 않은 것은 없습니다.
