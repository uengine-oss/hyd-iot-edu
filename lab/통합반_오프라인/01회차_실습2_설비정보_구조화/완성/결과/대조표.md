# 관계도와 파일의 대조표

`자료/관계도/화살표_목록.md`의 화살표 15개를 `결과/graph.json`과 번호 순서대로 대조한 것이다. 「파일의 표현」 칸에는 `graph.json`에 실제로 있는 것을 「시작 id -[관계 이름]-> 끝 id」의 꼴로 적었다.

| 번호 | 관계도의 화살표 | 파일의 표현 | 판정 | 까닭 |
|---|---|---|---|---|
| 1 | HYD-01 -[가진다]-> 오일 쿨러 | `asset:hyd-01 -[HAS_COMPONENT]-> comp:oil-cooler` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 「가진다」에서 `HAS_COMPONENT`로 바뀌었다. |
| 2 | HYD-01 -[가진다]-> 쿨러 팬 | `asset:hyd-01 -[HAS_COMPONENT]-> comp:cooler-fan` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 영문으로 바뀌었다. |
| 3 | 유온 센서 TS1 -[붙어 있다]-> 오일 쿨러 | `sen:ts1 -[MOUNTED_ON]-> comp:oil-cooler` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 「붙어 있다」에서 `MOUNTED_ON`으로 바뀌었다. |
| 4 | 냉각 효율 CE -[붙어 있다]-> 오일 쿨러 | `sen:ce -[MOUNTED_ON]-> comp:oil-cooler` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 냉각 효율 CE는 파일에서 `virtual`이 `true`인 Sensor 노드 `sen:ce`(tag `CE`)다. |
| 5 | 유온 센서 TS1 -[종류다]-> 센서 | 관계 없음. `sen:ts1` 노드의 `labels`가 `["Sensor"]` | 다르게 표현 | 「센서」라는 노드와 「종류다」에 해당하는 관계가 파일에 없다. 종류는 노드가 아니라 클래스(`labels`)로 적혀 있다. |
| 6 | 유온 센서 TS1 -[한계]-> 65 ℃ | `sen:ts1 -[MEASURES]-> sv:ts1`, 그리고 `sv:ts1` 노드의 속성 `limit: 65`, `unit: "℃"` | 다르게 표현 | 「65 ℃」라는 노드와 「한계」에 해당하는 관계가 파일에 없다. 한계는 센서가 재는 상태 변수 `sv:ts1`의 속성으로 적혀 있어, 다른 노드를 거쳐 속성에 닿는다. |
| 7 | 오일 쿨러 -[쓴다]-> 쿨러 코어 | `comp:oil-cooler -[USES_PART]-> part:p-clr-core` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 「쓴다」에서 `USES_PART`로 바뀌었다. |
| 8 | 유온 센서 TS1 -[보여 준다]-> 유온 상승 | `sen:ts1 -[SHOWS]-> sym:oil-temperature-rise` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 「보여 준다」에서 `SHOWS`로 바뀌었다. |
| 9 | 냉각 효율 CE -[보여 준다]-> 냉각 효율 저하 | `sen:ce -[SHOWS]-> sym:cooling-efficiency-drop` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 영문으로 바뀌었다. |
| 10 | 유온 상승 -[가리킨다]-> 쿨러 냉각 성능 상실 | `sym:oil-temperature-rise -[INDICATES]-> fm:cooler-cooling-performance-loss` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 「가리킨다」에서 `INDICATES`로 바뀌었다. |
| 11 | 냉각 효율 저하 -[가리킨다]-> 쿨러 냉각 성능 상실 | `sym:cooling-efficiency-drop -[INDICATES]-> fm:cooler-cooling-performance-loss` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 영문으로 바뀌었다. |
| 12 | 쿨러 핀 오염 -[일으킨다]-> 쿨러 냉각 성능 상실 | `cause:cooler-fin-fouling -[CAUSES]-> fm:cooler-cooling-performance-loss` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 「일으킨다」에서 `CAUSES`로 바뀌었다. |
| 13 | 쿨러 냉각 성능 상실 -[완화된다]-> 팬 최대 운전 | `fm:cooler-cooling-performance-loss -[MITIGATED_BY]-> skill:fan-maximum-run` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 「완화된다」에서 `MITIGATED_BY`로 바뀌었다. |
| 14 | 쿨러 냉각 성능 상실 -[일어난다]-> 오일 쿨러 | `fm:cooler-cooling-performance-loss -[OCCURS_IN]-> comp:oil-cooler` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 「일어난다」에서 `OCCURS_IN`으로 바뀌었다. |
| 15 | 쿨러 핀 오염 -[관련된다]-> 쿨러 코어 | `cause:cooler-fin-fouling -[RELATED_TO]-> part:p-clr-core` | 같음 | 같은 두 대상을 같은 방향으로 이었다. 관계 이름만 「관련된다」에서 `RELATED_TO`로 바뀌었다. |
