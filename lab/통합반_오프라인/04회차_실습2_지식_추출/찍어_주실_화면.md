# 찍어 주실 화면

가이드의 빗금 상자 번호와 같다. VS Code 창을 1440 × 900쯤으로 맞춰 찍으면 가이드에 그대로 들어간다.

1. 시작 폴더를 연 VS Code 화면. 왼쪽 탐색기에 .github, 문서, 지난_시간, 결과 네 폴더가 펼쳐져 있고 문서 폴더의 네 파일이 보이게.
2. Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳과 Copilot 아이콘에 빨간 테두리를 얹는다.
3. 위 요청에 대한 Copilot의 답. 문서별로 절마다 표 · 단계 · 수와 단위 · 금지 문장을 정리한 표, 받을 자리가 없는 것의 목록, 답의 끝에서 정해 달라고 묻는 부분이 보이게(길면 두 장). 아래 세 곳에 ①②③ 테두리를 얹는다.
4. 2단계 요청에 대한 Copilot의 계획. 후보의 표(클래스, 이름, id, 등록됨, 단계와 조건의 수), 관계와 보류의 건수, 끝의 「더 정해 주셔야 하는 것」이 보이게. 새 id의 안과 다시 물어 온 항목에 테두리를 얹는다.
5. 결과/후보.json과 문서/HM-8_cooler-fan-manual.md를 좌우로 나란히 연 VS Code 화면. 왼쪽은 K-004의 조건, 오른쪽은 HM-8.8이 보이게.
6. Copilot이 터미널 명령 실행의 허용을 묻는 화면. 명령 글자(python 대조.py)와 「허용/계속」 버튼이 보이게. 파일을 만들 때의 「유지/허용」 물음도 뜬다면 한 장 더.
7. 위 요청에 Copilot이 문서를 고치지 않고 규칙을 들어 멈춘 답. 어느 규칙 때문인지 말하는 부분과, 대신 할 수 있는 방법을 제안하는 부분에 테두리를 얹는다.
8. 되돌려 준 뒤 Copilot이 대조.py의 바뀐 부분을 보여 주는 화면(새로 생긴 줄이 초록색으로 표시되고, 네 가지 검사는 바뀌지 않은 것이 보이게).
