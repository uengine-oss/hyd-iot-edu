# 통합반 오프라인 5회차 · 실습 2 — 설비 이상의 원인을 추론하는 에이전트 (50분)

경보가 뜬 사례를 받으면 모델이 도구로 온톨로지와 센서 값을 읽어 후보 원인을 가리고 점검 순서를 내는 에이전트를 만든다.

## 무엇이 어디에 있나

| 경로 | 누가 보나 | 내용 |
|---|---|---|
| `가이드.html` | 학생 | 실습 가이드. 브라우저로 연다(파일 하나) |
| `시작/` | 학생 | VS Code로 여는 폴더. 자료와 규칙 파일, `connect.py`, `connection.txt` |
| `완성/` | 학생 · 강사 | 끝까지 마친 상태. 사례 열한 건의 결과 포함 |
| `찍어_주실_화면.md` | 강사 | 가이드의 「화면 1~10」 자리에 넣을 사진 목록 |
| `기록.md`, `기록/` | 강사 · 제작 | 실제로 돌린 결과, 요청 글 원문, 확인하지 못한 것 |

## 수업 전에 준비할 것

- 학생마다 모델 접속 정보 세 값(`OPENAI_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`)을 나눠 준다. 학생은 `시작/connection.txt`의 등호 뒤에 적고 저장한다. 값을 적은 `connection.txt`는 저장소에 올리지 않는다.
- 학생 PC에서 모델 서버에 닿는지 확인한다: `시작/`에서 `python connect.py`.
- Python 3(표준 라이브러리만 쓴다), VS Code, GitHub Copilot 채팅.

## 완성본을 돌려 보려면

`완성/connection.txt`에 접속 정보를 적고 `python agent.py`를 실행한다. 열한 건에 1분쯤 걸린다.
