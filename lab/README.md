# lab — 실습 묶음

실습 하나가 폴더 하나다. 폴더마다 같은 네 가지가 들어 있다.

| 이름 | 누가 쓰나 | 내용 |
|---|---|---|
| `시작/` | 오프라인 학생 | 실습을 시작하는 폴더. 규칙(`.github/copilot-instructions.md`)과 입력 자료가 미리 들어 있다 |
| `완성/` | 온라인 학생, 강사 | 실습을 끝까지 마친 상태. AI가 만든 결과 파일까지 들어 있어 AI 없이 열어 볼 수 있다 |
| `가이드.html` | 오프라인 학생 | `시작/`에서 출발해 `완성/`에 이르는 길. 파일 하나로 열린다 |
| `기록/`, `기록.md` | 제작자 | 가이드를 쓰려고 실제로 돌린 요청과 답의 원문, 걸린 시간, 확인하지 못한 것 |
| `찍어_주실_화면.md` | 제작자 | 가이드의 사진 자리에 넣을 VS Code 화면의 목록 |

- 가이드는 오프라인 실라버스의 실습 행을 기준으로 쓴다. 온라인에만 있는 실습은 `완성/`만 둔다.
- 가이드는 학생이 같은 주제의 온라인 일차를 듣고 왔다고 보고 개념을 다시 설명하지 않는다.
- 수업 도구는 VS Code의 GitHub Copilot 채팅이다. 가이드의 요청 글은 `기록/`의 원문에서 옮긴 것이고, Copilot의 답은 사진으로 싣는다.
