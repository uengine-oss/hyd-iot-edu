채팅을 열고, 두 가지를 확인한다

VS Code 오른쪽에 Copilot 채팅이 보이지 않으면 맨 위 가운데의 Copilot 아이콘을 눌러 연다. 입력 칸 아래에 두 가지가 적혀 있다. 방식은 에이전트, 모델은 GPT-6 Luna인지 본다. 다르면 그 글자를 눌러 바꾼다.

사진 ① — 찍어 주실 화면Copilot 채팅이 열린 VS Code 전체 화면. 입력 칸 아래의 방식(에이전트)과 모델(GPT-6 Luna) 표시가 보이게. 그 두 곳에 빨간 테두리를 얹는다.

입력 칸 아래 두 곳이 사진과 같으면 된다.

오른쪽 위의 「복사」를 누르고, 채팅 입력 칸을 한 번 누른 다음 붙여넣고(Ctrl+V) Enter를 누른다.

Copilot에게 보낼 요청
이 폴더의 규칙과 회의록 폴더의 파일을 모두 읽어 줘. 회의마다 '정해진 것'과 '정해지지 않은 것'을 나눠서 정리하고, 정해진 것에는 누가 언제까지 하는지가 회의록에 적혀 있는지도 표시해 줘. 아직 파일은 만들지 마.
붙여넣는 곳 → Copilot 채팅 맨 아래 입력 칸
무엇을 읽는가규칙 파일과 회의록 두 편. 읽을 대상을 내가 정해 준다.
어떤 모양으로 답하는가「정해진 것 / 정해지지 않은 것」으로 나누게 했다. 뒤에서 내가 원문과 견주기 쉽다.
하지 말 것이 요청에서 가장 중요한 문장이다. 이 한 줄이 없으면 읽자마자 만들기 시작한다.
Copilot 채팅 · 답

돌아온 답에서 세 가지를 찾는다

답은 30초쯤 뒤에 온다. 문장은 사람마다 다르게 나오므로 옆 사람과 글자가 같을 필요는 없다. 아래 세 가지가 내 답에도 있는지만 본다.

사진 ② — 찍어 주실 화면위 요청에 대한 Copilot의 답. 회의록_1의 「정해진 것」 표와, 답의 끝에서 「정해 주셔야 할 것」을 묻는 부분이 보이게. 아래 세 곳에 ①②③ 테두리를 얹는다.
①

담당자나 날짜가 「없음」인 일준비 단계에서 내가 회의록을 읽으며 적어 둔 안건 번호와 같은가. 예: 예비품 발주는 담당도 납기도 정해지지 않았다.

②

결론이 나지 않은 안건「경보 기준 온도」처럼 의견만 오가고 끝난 안건이 「정해진 것」에 섞여 있지 않은가.

③

AI가 나에게 되묻는 것답의 끝에 「정해 주셔야 할 것」이 있는가. 몇 가지인지 세어 둔다. 다음 단계에서 이 물음에 내가 답한다.

AI가 되묻는 까닭폴더의 규칙 파일에 「정해져 있지 않은 것은 스스로 정하지 말고 묻는다」고 적어 두었기 때문이다. 규칙이 없었다면 AI는 이 자리들을 알아서 채웠을 것이고, 무엇이 어떻게 정해졌는지는 결과를 뜯어보아야 알 수 있다.
파일이 생겨 버렸다면탐색기에 새 파일이 보이면 요청의 마지막 문장이 빠진 것이다. 생긴 파일을 지우고, 요청을 다시 복사해 보낸다.
내가 읽은 것과 다르다면「다시 해 줘」라고 하지 않는다. 「5번 안건의 담당이 원문과 달라. 원문에는 "한서윤과 오민재가 같이 맡는다."라고 적혀 있어.」처럼 어디가 어떻게 다른지를 말한다.
