# 강의 영상

영상 파일은 용량과 강사 음성 때문에 저장소에 올리지 않는다. 만드는 도구는 `production/tools/video/`에 있다.

**지금의 덱과 대본으로 만든 영상은 아직 없다.**

통합반 1일차는 2026-10-14에 덱과 대본을 새 기준으로 다시 썼다(95장). 그 전에 만든 1일차 영상 9편은 옛 덱과 옛 대본으로 만든 것이어서 쓰지 않는다. 영상은 사용자가 범위를 말하면 새로 만든다. 영상 하나는 실라버스 행 하나이고, 행과 장의 대응은 각 대본 맨 위의 「이 일차의 구성」 표에 있다.

2~11일차와 실전반 영상도 아직 만들지 않았다.
